## Title

LYNX SHARE

## Short description

免費開源的DAW，一個程式提供三種工作流程：FL Studio風格的模式（Channel Rack、Piano Roll、Playlist、Mixer）、Ableton Live風格的片段啟動，以及BandLab和FL Studio Mobile風格的簡易單一視窗模式。可開啟.flp、.als、.flm、.dawproject、GarageBand的.band和BandLab的.blx專案，並可匯出.flp、.als、.dawproject和.flm。

## Description

LYNX SHARE是一款免費開源的數位音訊工作站，用來製作節拍和歌曲。它在一個程式裡提供三種工作流程，可隨時切換，不會改變專案：

• FL Studio風格的模式（預設）：帶步進音序器的Channel Rack、模式、Piano Roll、帶編曲的Playlist，以及帶插入、傳送和側鏈的Mixer。
• Ableton Live風格的片段啟動：片段和場景的格線、工作階段混音器，以及片段檢視和裝置檢視。
• 簡易工作流程，把BandLab易上手的單一視窗風格和FL Studio Mobile的工作方式結合在一起：音軌和時間軸、循環、打擊墊和快速錄音，還有引導式的第一首歌。

第一次啟動會詢問你來自哪裡，並開啟相應的版面。

它在任何PC上都能保持輕快。

• 輕巧：無鎖音訊引擎將軌道與混音軌分散到所有 CPU 核心，自動略過閒置的軌道，長音訊則直接從硬碟串流讀取。
• 完整：超過 100 款內建樂器與效果器——合成器（波表、FM，以及LYNX Model的敲擊樂器物理模型）、鼓機、取樣器、EQ、壓縮器、限幅器、殘響、延遲、音準修正、視覺化工具等等——外加可作用於任何旋鈕的調變器（LFO、包絡跟隨器、步進音序器等）。
• 你的外掛：支援 VST3、CLAP 與 VST2 樂器和效果器，每個外掛都可選擇在獨立的沙箱程序中執行，外掛當掉也不會拖垮整個工作階段。
• 你的專案：開啟FL Studio專案（.flp），包括模式、音符、混音器、自動化和取樣；開啟並儲存Ableton Live 11/12組合（.als），包括Session片段；開啟並儲存DAWproject檔案（.dawproject），可用於Bitwig、Studio One、Cubase等應用程式；可匯出.flp回到FL Studio，也可為FL Studio Mobile儲存.flm副本；可匯入FL Studio Mobile專案（.flm，部分支援）、GarageBand專案（.band，部分支援）、BandLab專案（.blx，部分支援）和MIDI檔案。
• Tracker 模組：.mod、.xm、.s3m 和 .it 檔案連同取樣、模式和速度一起開啟，內建的追蹤器可以編輯音符。
• 更快地編排：用於整段歌曲部分的段落軌、自帶音符的軌道片段、可隱藏或停用軌道以節省 CPU、能找到每個動作的指令搜尋，以及並排開啟兩個專案並可在其間複製貼上。
• 一起做音樂：把專案作為一個檔案傳出，或與最多三位朋友即時編輯，端對端加密。
• 音訊編輯：Melodyne等ARA 2外掛可直接在音訊片段上運作，複音音符編輯器可移動並重新調音和弦中的單一音符，音訊也可轉換為MIDI。
• 低延遲：支援 ASIO（包括適用於任何裝置的 LYNX SHARE 自家 ASIO 驅動程式）以及 WASAPI 共用與獨占模式。
• 錄製音訊與 MIDI（也支援 MPE）、編輯音訊、自動化任何參數，輸出為 WAV、FLAC、MP3、OGG、AIFF、M4A 或分軌（stems）。
• 離線可用：不需帳號，在你同意之前不會連線。
• 介面語言：繁體中文、簡體中文、英文、葡萄牙文、西班牙文、法文、德文、日文、韓文等 15 種語言。

不需帳號、沒有訂閱、沒有廣告，也沒有遙測。LYNX SHARE 是自由軟體（GNU AGPL-3.0），原始碼公開於 GitHub。

LYNX SHARE是獨立專案，與Image-Line或Ableton無關聯，也未獲其認可。FL Studio和FL Studio Mobile是Image-Line Software的商標；Ableton和Live是Ableton AG的商標。其他產品名稱是其各自所有者的商標。

LYNX SHARE 目前為 Alpha 版：難免有不夠完善之處，遇到問題請到 GitHub 回報。

8. 輸出 WAV、FLAC、MP3、OGG、AIFF、M4A 與分軌
