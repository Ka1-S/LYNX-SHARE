## Title

LYNX SHARE

## Short description

한 프로그램에 세 가지 레이아웃을 갖춘 무료 오픈 소스 DAW: FL Studio 스타일 패턴(Channel Rack, Piano Roll, Playlist, Mixer), Ableton Live 스타일 클립 실행, 그리고 BandLab과 FL Studio Mobile 스타일의 간단한 단일 창 모드. .flp, .als, .flm, .dawproject, GarageBand .band, BandLab .blx 프로젝트를 열고, .flp, .als, .dawproject, .flm으로 내보냅니다.

## Description

LYNX SHARE는 비트와 곡을 만들기 위한 무료 오픈 소스 디지털 오디오 워크스테이션입니다. 한 프로그램에 세 가지 레이아웃이 있으며, 프로젝트를 바꾸지 않고 언제든지 전환할 수 있습니다.

• FL Studio 스타일 패턴(기본): 스텝 시퀀서가 있는 Channel Rack, 패턴, Piano Roll, 어레인지가 있는 Playlist, 인서트·센드·사이드체인이 있는 Mixer.
• Ableton Live 스타일 클립 실행: 클립과 씬의 그리드, 세션 믹서, 클립 보기와 장치 보기.
• BandLab의 쉬운 단일 창 스타일과 FL Studio Mobile의 작업 방식을 섞은 간단한 레이아웃: 트랙과 타임라인, 루프, 패드, 빠른 녹음, 그리고 안내에 따라 만드는 첫 곡.

처음 시작하면 어디서 오셨는지 묻고 알맞은 레이아웃을 엽니다.

어떤 PC에서도 가볍고 빠르게 돌아가도록 만들었습니다.

• 가벼움: 락프리(lock-free) 오디오 엔진이 채널과 믹서 트랙을 CPU 코어 전체에 분산하고, 쉬고 있는 채널은 건너뛰며, 긴 오디오는 디스크에서 스트리밍합니다.
• 풍부한 구성: 신스(웨이브테이블, FM, 말렛 악기를 물리 모델로 만든 LYNX Model), 드럼 머신, 샘플러, EQ, 컴프레서, 리미터, 리버브, 딜레이, 피치 보정, 비주얼라이저 등 100개가 넘는 내장 악기와 이펙트, 그리고 모든 노브에 쓸 수 있는 모듈레이터(LFO, 엔벨로프 팔로어, 스텝 시퀀서 등).
• 내 플러그인 그대로: VST3, CLAP, VST2 악기와 이펙트를 호스팅하며, 플러그인마다 별도의 샌드박스 프로세스에서 실행할 수 있어 플러그인이 크래시가 나도 세션은 멈추지 않습니다.
• 내 프로젝트: FL Studio 프로젝트(.flp)를 패턴, 노트, 믹서, 오토메이션, 샘플과 함께 엽니다. Ableton Live 11/12 세트(.als)를 Session 클립까지 포함해 열고 저장하며, Bitwig, Studio One, Cubase 등 다른 앱을 위한 DAWproject 파일(.dawproject)도 열고 저장합니다. .flp로 FL Studio에 다시 내보내고, FL Studio Mobile용 .flm 사본도 저장하고, FL Studio Mobile 프로젝트(.flm, 일부), GarageBand 프로젝트(.band, 일부), BandLab 프로젝트(.blx, 일부)와 MIDI 파일을 가져옵니다.
• 트래커 모듈: .mod, .xm, .s3m, .it 파일을 샘플, 패턴, 템포와 함께 열고, 내장 트래커로 노트를 편집합니다.
• 더 빠른 어레인지: 곡의 부분 전체를 다루는 섹션 레인, 자기 노트를 가진 트랙 클립, CPU를 아끼는 트랙 숨기기와 비활성화, 모든 동작을 찾는 명령 검색, 복사와 붙여넣기가 되는 나란한 프로젝트 두 개.
• 함께 음악 만들기: 프로젝트를 파일 하나로 보내거나, 최대 세 명의 친구와 실시간으로 편집합니다. 종단 간 암호화됩니다.
• 오디오 편집: Melodyne 같은 ARA 2 플러그인이 오디오 클립 위에서 바로 작동하고, 폴리포닉 노트 에디터로 코드 안의 개별 음을 옮기고 음높이를 다시 맞출 수 있으며, 오디오를 MIDI로 변환할 수 있습니다.
• 낮은 레이턴시: ASIO(어떤 장치에서도 쓸 수 있는 LYNX SHARE 자체 ASIO 드라이버 포함), WASAPI 공유 모드와 독점 모드.
• 오디오와 MIDI 녹음(MPE 포함), 오디오 편집, 모든 파라미터 오토메이션, WAV·FLAC·MP3·OGG·AIFF·M4A 또는 스템으로 렌더링.
• 오프라인 작동: 계정이 없고, 허락하기 전에는 아무것도 온라인으로 연결되지 않습니다.
• 인터페이스: 한국어, 영어, 포르투갈어, 스페인어, 프랑스어, 독일어, 일본어, 중국어 등 15개 언어 지원.

계정도, 구독도, 광고도, 텔레메트리도 없습니다. LYNX SHARE는 자유 소프트웨어(GNU AGPL-3.0)이며 소스 코드는 GitHub에 공개되어 있습니다.

LYNX SHARE는 독립 프로젝트이며 Image-Line이나 Ableton과 제휴하거나 그들의 보증을 받지 않았습니다. FL Studio와 FL Studio Mobile은 Image-Line Software의, Ableton과 Live는 Ableton AG의 상표입니다. 기타 제품명은 각 소유자의 상표입니다.

LYNX SHARE는 알파 버전입니다. 다듬어지지 않은 부분이 있을 수 있으니, 문제가 있으면 GitHub에 알려 주세요.

## What's new

LYNX SHARE 0.1.31.2는 시작 페이지 충돌의 유력한 원인, 도킹된 VST3 플러그인 위에서의 "LYNX 우선" 키보드 설정, 첫 마디만 반복하던 늘린 클립, FL 프로젝트로 만든 오토메이션 레인, FL이 거부하던 내보낸 .flp, Browser의 FL 기본 신스 프리셋, 그리고 작은 문제 몇 가지를 고칩니다.

LYNX SHARE 0.1.31.1은 0.1.31에서 보고된 문제를 고칩니다: 컨트롤에 보이는 FL 프로젝트 오토메이션, 더 이상 열리지 않던 플러그인 창, Device 뷰, 파일 이름에 폴더가 있는 내보내기, 악기 트랙의 클립, 힌트 바 충돌, 시작 시 메모리.

LYNX SHARE 0.1.31: 트래커 모듈(.mod, .xm, .s3m, .it)도 여는 내장 트래커. 마림바, 비브라폰, 실로폰, 글로켄슈필, 튜뷸러 벨, 칼림바의 물리 모델 LYNX Model. JSFX 이펙트와 악기 스크립트. 맞는 레이아웃을 설정하는 환영 카드와 최근 프로젝트가 있는 시작 페이지. 모든 명령을 찾는 검색. 복사와 붙여넣기가 되는 두 프로젝트 나란히 보기. 섹션 레인, Smart Tempo가 있는 코드 레인, 트랙 버전. 오토메이션 쓰기 모드, 오토메이션 캡처, 모든 노브용 모듈레이터. FL Studio Mobile .flm 내보내기. 클립 실행 레이아웃에는 Live의 랙 디바이스 인라인 표시와 Macro Map, Solo / Cue. 간단한 레이아웃에는 덕킹 기준과 에코 센드. 믹서 인서트의 ARA 플러그인. FL에 더 가깝게 재생되는 FL Studio 프로젝트. 그리고 보고된 약 30건의 문제 수정.

## Features

1. 한 프로그램에 세 가지 레이아웃: 기본은 FL Studio 스타일 패턴, Ableton Live 스타일 클립 실행, 또는 BandLab과 FL Studio Mobile 스타일의 간단한 레이아웃
2. FL Studio(.flp와 zip), Ableton Live(.als), FL Studio Mobile(.flm), DAWproject, GarageBand, BandLab 프로젝트와 MIDI 파일을 열고, .flp, .als, .dawproject, .flm 사본으로 저장합니다
3. 100개 이상의 내장 악기와 이펙트
4. VST3, CLAP, VST2 플러그인 호스팅, 별도 프로세스 샌드박스 실행 선택 가능
5. 저지연 오디오: ASIO, WASAPI 공유 및 독점 모드
6. 오래된 PC에서도 가볍게 돌아가는 멀티코어 엔진
7. 오디오와 MIDI 녹음, 오디오 에디터, 오토메이션 클립
8. WAV, FLAC, MP3, OGG, AIFF, M4A, 스템으로 내보내기
9. 한국어를 포함한 15개 언어 인터페이스
10. 무료 오픈 소스(AGPL-3.0): 계정 불필요, 광고 없음, 텔레메트리 없음
11. ARA 2 플러그인 호스팅, 폴리포닉 노트 에디터, 오디오-MIDI 변환
12. 트래커 모듈(.mod, .xm, .s3m, .it)을 열고 내장 트래커에서 노트 편집
13. LYNX Model: 마림바, 비브라폰, 실로폰, 글로켄슈필, 튜뷸러 벨, 칼림바의 물리 모델
14. 모든 노브에 쓰는 모듈레이터: LFO, 엔벨로프 팔로어, ADSR, 스텝, 랜덤, 매크로, 키트랙, 벨로시티
15. 섹션 레인, 트랙 숨기기와 비활성화, 모든 명령을 찾는 검색
16. 온라인 세션: 최대 세 명의 친구와 프로젝트를 실시간으로 편집, 종단 간 암호화
17. 오프라인 작동: 계정 없음, 허락하기 전에는 연결 없음
