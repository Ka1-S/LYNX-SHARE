## Title

LYNX SHARE

## Short description

1つのプログラムに3つのワークフローを備えた無料・オープンソースのDAW。FL Studio風のパターン (Channel Rack、Piano Roll、Playlist、Mixer)、Ableton Live風のクリップ起動、BandLabとFL Studio Mobileのスタイルのシンプルな1ウィンドウモード。.flp、.als、.flm、.dawproject、GarageBandの.band、BandLabの.blxのプロジェクトを開け、.flp、.als、.dawproject、.flmに書き出せます。

## Description

LYNX SHAREは、ビートや曲を作るための無料・オープンソースのデジタルオーディオワークステーションです。1つのプログラムに3つのワークフローがあり、プロジェクトを変えずにいつでも切り替えられます。

• FL Studio風のパターン (既定): ステップシーケンサー付きChannel Rack、パターン、Piano Roll、アレンジ対応のPlaylist、インサート・センド・サイドチェーン付きのMixer。
• Ableton Live風のクリップ起動: クリップとシーンのグリッド、セッションミキサー、クリップビューとデバイスビュー。
• シンプルワークフロー: BandLabの親しみやすい1ウィンドウのスタイルにFL Studio Mobileの作り方を組み合わせ、トラックとタイムライン、ループ、パッド、すばやい録音、ガイド付きの最初の1曲を用意しています。

最初の起動で、どこから来たかを尋ね、合ったワークフローを開きます。

どんなPCでも軽快に動くよう作られています。

• 軽快：ロックフリーのオーディオエンジンがチャンネルとミキサートラックをCPUの各コアに分散。鳴っていないチャンネルは処理をスキップし、長いオーディオはディスクからストリーミング再生します。
• 充実：シンセ (ウェーブテーブル、FM、LYNX Modelのマレット楽器の物理モデル)、ドラムマシン、サンプラー、EQ、コンプレッサー、リミッター、リバーブ、ディレイ、ピッチ補正、ビジュアライザーなど、100種類以上の内蔵インストゥルメントとエフェクトに加え、あらゆるノブに使えるモジュレーター (LFO、エンベロープフォロワー、ステップシーケンサーなど)。
• お気に入りのプラグインも：VST3、CLAP、VST2のインストゥルメントとエフェクトをホスト。各プラグインを個別のサンドボックスプロセスで動かすこともでき、プラグインがクラッシュしてもセッションは落ちません。
• あなたのプロジェクト: FL Studioのプロジェクト (.flp) をパターン、ノート、ミキサー、オートメーション、サンプルごと開けます。Ableton Live 11/12のセット (.als) をSessionのクリップも含めて開いて保存でき、Bitwig、Studio One、Cubaseなどのアプリ向けにDAWprojectファイル (.dawproject) も開いて保存できます。.flpとしてFL Studioへ書き出せ、FL Studio Mobile用に.flmのコピーも保存でき、FL Studio Mobileのプロジェクト (.flm、一部)、GarageBandのプロジェクト (.band、一部)、BandLabのプロジェクト (.blx、一部)、MIDIファイルもインポートできます。
• トラッカーモジュール：.mod、.xm、.s3m、.it ファイルをサンプル、パターン、テンポごと開き、内蔵トラッカーでノートを
編集できます。
• 速いアレンジ：曲のパート全体を扱うセクションレーン、自分のノートを持つトラッククリップ、CPUを節約するトラックの非表示と無効化、あらゆるアクションを探せるコマンド検索、2つのプロジェクトを並べて開いてコピー＆ペースト。
• みんなで音楽を作る：プロジェクトを1つのファイルとして送るか、最大3人の友人とエンドツーエンドの暗号化でライブ編集。
• オーディオ編集: MelodyneなどのARA 2プラグインがオーディオクリップ上でそのまま動作し、ポリフォニックのノートエディターでコード内の単音を動かしたりピッチを修正したりでき、オーディオをMIDIに変換できます。
• 低レイテンシー：ASIO（どのデバイスでも使えるLYNX SHARE独自のASIOドライバーを含む）、WASAPIの共有モードと排他モードに対応。
• オーディオとMIDI (MPEにも対応) のレコーディング、オーディオ編集、あらゆるパラメーターのオートメーション、WAV・FLAC・MP3・OGG・AIFF・M4A・ステムへの書き出し。
• オフラインで動作：アカウントは不要で、あなたが許可するまで何もオンラインに接続しません。
• インターフェース：日本語、英語、ポルトガル語、スペイン語、フランス語、ドイツ語、中国語、韓国語など15言語に対応。

アカウント登録、サブスクリプション、広告、テレメトリーは一切ありません。LYNX SHAREはフリーソフトウェア（GNU AGPL-3.0）で、ソースコードはGitHubで公開しています。

LYNX SHAREは独立したプロジェクトであり、Image-LineやAbletonとは提携しておらず、承認も受けていません。FL StudioとFL Studio MobileはImage-Line Softwareの、AbletonとLiveはAbleton AGの商標です。その他の製品名は各所有者の商標です。

LYNX SHAREはアルファ版です。粗削りな部分もありますので、問題を見つけたらGitHubでご報告ください。

## Features

1. 1つのプログラムに3つのワークフロー: 既定はFL Studio風のパターン、Ableton Live風のクリップ起動、またはBandLabとFL Studio Mobileのスタイルのシンプルワークフロー
2. FL Studio (.flp、zipも)、Ableton Live (.als)、FL Studio Mobile (.flm)、DAWproject、GarageBand、BandLabのプロジェクトとMIDIファイルを開き、.flp、.als、.dawproject、.flmのコピーとして保存
3. 100種類以上の内蔵インストゥルメントとエフェクト
4. VST3、CLAP、VST2プラグインをホスト。個別プロセスでのサンドボックス実行も可能
5. 低レイテンシーのオーディオ：ASIO、WASAPI共有モード・排他モード
6. 古いPCでも軽快に動くマルチコア対応エンジン
7. オーディオとMIDIのレコーディング、オーディオエディター、オートメーションクリップ
8. WAV、FLAC、MP3、OGG、AIFF、M4A、ステムへの書き出し
9. 日本語を含む15言語のインターフェース
10. 無料のオープンソース（AGPL-3.0）：アカウント不要、広告なし、テレメトリーなし
11. ARA 2プラグインのホスティング、ポリフォニックのノートエディター、オーディオからMIDIへの変換
12. トラッカーモジュール (.mod、.xm、.s3m、.it) を開き、内蔵トラッカーでノートを編集
13. LYNX Model: マリンバ、ビブラフォン、シロフォン、グロッケンシュピール、チューブラーベル、カリンバの物理モデル
14. あらゆるノブに使えるモジュレーター: LFO、エンベロープフォロワー、ADSR、ステップ、ランダム、マクロ、キートラック、ベロシティ
15. セクションレーン、トラックの非表示と無効化、あらゆるコマンドを探せる検索
16. オンラインセッション: 最大3人の友人とプロジェクトをライブ編集。エンドツーエンドの暗号化
17. オフラインで動作: アカウント不要、許可するまで接続なし
