## Title

LYNX SHARE

## Short description

パターンとクリップ起動のワークフローを備えた無料・オープンソースのDAW。Channel Rack、Piano Roll、Playlist、Mixer、クリップグリッドを搭載。.flp、.als、.flmのプロジェクトを開けます。

## Description

LYNX SHAREは、ビートや曲を作るための無料・オープンソースのデジタルオーディオワークステーションです。ふたつの作業スタイルをひとつにしました。既定のFL Studio風パターンワークフロー (ステップシーケンサー付きChannel Rack、パターン、Piano Roll、アレンジ対応のPlaylist、インサート・センド・サイドチェーン付きのMixer) と、設定ひとつで切り替えられる、シーン付きのAbleton Live風クリップグリッドです。どんなPCでも軽快に動くよう作られています。

• 軽快：ロックフリーのオーディオエンジンがチャンネルとミキサートラックをCPUの各コアに分散。鳴っていないチャンネルは処理をスキップし、長いオーディオはディスクからストリーミング再生します。
• 充実：シンセ、ドラムマシン、サンプラー、EQ、コンプレッサー、リミッター、リバーブ、ディレイ、ピッチ補正、ビジュアライザーなど、100種類以上の内蔵インストゥルメントとエフェクト。
• お気に入りのプラグインも：VST3、CLAP、VST2のインストゥルメントとエフェクトをホスト。各プラグインを個別のサンドボックスプロセスで動かすこともでき、プラグインがクラッシュしてもセッションは落ちません。
• あなたのプロジェクト: FL Studioのプロジェクト (.flp) をパターン、ノート、ミキサー、オートメーション、サンプルごと開けます。Ableton Live 11/12のセット (.als) をSessionのクリップも含めて開いて保存でき、.flpとしてFL Studioへ書き出せ、FL Studio Mobileのプロジェクト (.flm、一部) とMIDIファイルもインポートできます。
• 手軽に始められます: シンプルワークフローでは、初心者向けにトラックとタイムラインがひとつになったウィンドウ、スタータービート、ワンクリックで演奏できるインストゥルメントが使えます。
• 低レイテンシー：ASIO（どのデバイスでも使えるLYNX SHARE独自のASIOドライバーを含む）、WASAPIの共有モードと排他モードに対応。
• オーディオとMIDIのレコーディング、オーディオ編集、あらゆるパラメーターのオートメーション、WAV・FLAC・MP3・OGG・ステムへの書き出し。
• インターフェース：日本語、英語、ポルトガル語、スペイン語、フランス語、ドイツ語、中国語、韓国語など15言語に対応。

アカウント登録、サブスクリプション、広告、テレメトリーは一切ありません。LYNX SHAREはフリーソフトウェア（GNU AGPL-3.0）で、ソースコードはGitHubで公開しています。

LYNX SHAREは独立したプロジェクトであり、Image-LineやAbletonとは提携しておらず、承認も受けていません。FL StudioとFL Studio MobileはImage-Line Softwareの、AbletonとLiveはAbleton AGの商標です。その他の製品名は各所有者の商標です。

LYNX SHAREはアルファ版です。粗削りな部分もありますので、問題を見つけたらGitHubでご報告ください。

## Features

1. 3つのワークフロー: 既定はパターンベース (Channel Rack、Piano Roll、Playlist、Mixer)、シーン付きクリップグリッド、または初心者向けのシンプルワークフロー
2. FL Studio (.flp)、Ableton Live (.als)、FL Studio Mobile (.flm) のプロジェクトとMIDIファイルを開き、.alsと.flpで保存
3. 100種類以上の内蔵インストゥルメントとエフェクト
4. VST3、CLAP、VST2プラグインをホスト。個別プロセスでのサンドボックス実行も可能
5. 低レイテンシーのオーディオ：ASIO、WASAPI共有モード・排他モード
6. 古いPCでも軽快に動くマルチコア対応エンジン
7. オーディオとMIDIのレコーディング、オーディオエディター、オートメーションクリップ
8. WAV、FLAC、MP3、OGG、ステムへの書き出し
9. 日本語を含む15言語のインターフェース
10. 無料のオープンソース（AGPL-3.0）：アカウント不要、広告なし、テレメトリーなし
