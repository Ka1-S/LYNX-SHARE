Shell Channelは、ミキサーのインサート用のLYNX SHARE独自のドラムチャンネルストリップです。5つのセクションにそれぞれ電源スイッチがあり、下にあるシェブロンをドラッグして処理の順番を決めます。レイテンシーは4.1 msと通知されます。

Controls

ControlWhat it does
ゲートOpen、Close、Range、Hold、Attack、Releaseと、隣のメーター。
トランジェントシェイパーGain、Speed、Amountと、InvertおよびListenのボタン。
低域エンハンサーAmount、周波数(Hz)、Drive。
高域エンハンサーDrive、周波数(kHz)、Amount。
リッスンマイク・コンプComp、メイクアップゲイン、Mixと、Narrow bandボタン。
Input Gain左側のゲインと、レベルメーター。
Output Mix and Gain右側のドライとウェットのバランスと出力ゲイン、およびレベルメーター。

Tips

  • 処理の順番は120通りあり、下のシェブロンをドラッグして設定します。
