Utilityは、レベルとチャンネルのルーティングのための小さなツールです。インサートに追加して、ゲインを変えたり、バランスをずらしたり、チャンネルを入れ替えたり混ぜたりできます。

Controls

ControlWhat it does
ゲイン出力ゲイン。
バランス左右のバランス。
L -> L左の入力から左の出力へ。
R -> L右の入力から左の出力へ。
L -> R左の入力から右の出力へ。
R -> R右の入力から右の出力へ。

Tips

  • L -> RとR -> Lを高く、ほかを低くすると、チャンネルが入れ替わります。
