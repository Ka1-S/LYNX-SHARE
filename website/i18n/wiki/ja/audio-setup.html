設定ウィンドウのオーディオページでは、音の出力先と録音の入力元を選びます。オプション › オーディオ設定... で開きます。セットアップウィザード (オプション › セットアップウィザード (言語、オーディオ、プラグインフォルダー)...) でもオーディオ出力をテストできます。

音を出す

  1. オプション › オーディオ設定... を開きます。
  2. ドライバー を選びます。ボックスの下の注記に、そのドライバーの向いている用途が書かれています。
  3. 出力デバイス を選びます。
  4. テストサウンドを再生 をクリックします。
  5. 状態 の欄を読みます。動作中のドライバー、サンプルレート、出力レイテンシーが表示されます。デバイスが開いていない場合は 開いているオーディオデバイスがありません: 出力デバイスを選択してください。 と表示されます。

ドライバー

ドライバー ボックスには、お使いのシステムのドライバーの種類が並びます。

システムドライバー働き
WindowsWindows Audio (共有)他のプログラムの音も鳴り続けます。Windowsがすべてのプログラムを一定の間隔でミックスするため、バッファーはその間隔より小さくできません
WindowsWindows Audio (共有、低レイテンシー周期)共有ですが、Windowsにより短いミックス周期を要求します。対応しているドライバーは一部だけです
WindowsWindows Audio (排他、最低レイテンシー)LYNX SHAREがデバイスを単独で使います。再生中は他のプログラムが無音になります
WindowsDirectSound (レガシー)レイテンシーの高い、古いWindowsのオーディオ経路です。他のドライバーがうまく動かないときに使います
WindowsASIO低レイテンシーのドライバーです。メーカー製のASIOドライバーは、そのメーカーのデバイスで動作します
WindowsLYNX ASIO (内蔵)LYNX SHARE独自のASIOドライバーで、どのデバイスでも再生と録音に使えます。ドライバー設定... で共有モードか排他モードか、使うデバイスを選びます
macOSCore Audioシステム標準のオーディオで、他のプログラムと共有されます
LinuxPipeWire (ネイティブ)LYNX SHAREがPipeWireと直接やり取りします。System default は、システムのサウンド設定で選んだ出力に従います
LinuxJACK / PipeWire起動中のJACKサーバー、または pipewire-jack を使うPipeWire向けです
LinuxALSAサウンドカードと直接やり取りします。default や pipewire はデバイスを共有し、hw: デバイスはカードをLYNX SHAREだけで使います

Linuxでは、初回起動時にPipeWire、JACK、ALSAのうち、デバイスのある最初のものが開きます。選んだ内容は保存されます。

音が出ないとき

  • まず 状態 を見ます。デバイスが開いていなければ、出力デバイスを選びます。
  • 別のドライバーを試します。Windowsでは、Windows Audio (共有) なら他のプログラムの音が鳴り続け、DirectSound (レガシー) は他のドライバーがうまく動かないときのためにあります。
  • ミキサーのマスターフェーダーと、ツールバーの マスター ノブを確認します。
  • パターンモードでは、現在のパターンだけが鳴ります。空なら何も聞こえません。L を押すとソングモードになります。
  • Linuxで音が途切れる場合は、オーディオスレッドがリアルタイム優先度を得られたかどうかが 状態 に表示されます。対処法はトラブルシューティングにあります。

知っておくと便利なこと

  • ASIOはWindowsにしかありません。
  • Windows Audio (共有) では、最小のバッファーはシステムのミックス間隔です。お使いのデバイスでの値は、ドライバー ボックスの下の注記に出ています。レイテンシーをもっと下げるには、排他モードかASIOドライバーを使います。
  • PipeWireでは、バッファーは32～2048サンプル、サンプルレートは44.1～192 kHzです。PipeWireが独自のレートを保つ場合は、LYNX SHAREのストリームがリサンプリングされます。
  • PipeWireで名前を指定したデバイスを取り外すと、LYNX SHAREは System default に切り替わり、バッファーサイズはそのまま保たれます。
  • 状態 には、オーディオのCPU負荷も表示され、音切れ (バッファーアンダーラン) も数えられます。
  • ウィンドウを開かなくても、ドライバーとデバイスの一覧を表示できます。コマンドラインの --devices をご覧ください。
