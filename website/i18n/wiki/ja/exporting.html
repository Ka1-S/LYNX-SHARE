LYNX SHAREから出ていくものはすべて ファイル › エクスポート を通ります。オーディオ形式 (WAV、MP3、OGG、FLAC、AIFF、M4A) は、1つのエクスポートウィンドウを共有します。MIDI、FL Studioのプロジェクト、Ableton Live セット、DAWprojectファイル、Zip圧縮したプロジェクトは、同じメニューにそれぞれ専用の項目があります。

曲をWAVにエクスポートする

  1. ファイル › エクスポート › WAVファイル... を選びます。
  2. レンジ は ソング (プレイリスト)、ファイル は 1ファイル (ミックス) のままにします。
  3. ビット深度 を選びます。16ビット、24ビット、32ビット (浮動小数点) のいずれかです。
  4. テール を 残りを残す にすると、最後の小節の後もリバーブやリリースが鳴り切ります。
  5. エクスポート... をクリックし、名前とフォルダーを選んで、レンダリングが終わるのを待ちます。
  6. 終わると、LYNX SHAREがファイルの保存先とピークレベルを知らせます。

Ctrl+R は、最後にエクスポートした形式でウィンドウを開きます。Ctrl+Shift+R はMP3でウィンドウを開きます。

ステムとトラック

ファイル には、ステムのモードが3つあります。

  • ミキサーインサートごと (ステム): 音が出るインサートごとに1ファイル。
  • チャンネルごと (ステム): 鳴るチャンネルごとに1ファイル。
  • チャンネルごと、楽器のみ (センドとバスなし)。

フルミックスも出力 にチェックを入れると、ステムと並んでミックスも書き出されます。下の行に、書き出されるファイル数が表示されます。

曲にセクションレーンのセクションがあるときは、セクションごとに 1 ファイル でセクションごとに切り分け、各ファイルにセクション名を付けます。ステムの場合は、セクションごとに1組ずつ書き出されます。

ファイル › エクスポート › Playlist のすべてのトラック と Playlist のすべてのトラックグループ は、プレイリストのトラックごと、またはグループごとに1ファイルを書き出します。ミキサーのメニューにある ディスク録音 › 録音待機中のトラックをWAVファイルにレンダリング... (Alt+R) は、録音待機中のインサートだけを対象にエクスポートウィンドウを開きます。

FL Studio、Ableton Live、DAWprojectへのエクスポート

.flp はFL Studio 2026のプロジェクトです。サンプラー、オーディオクリップ、FL Studio自身のジェネレーターとエフェクト、サードパーティのプラグイン、パターン、プレイリスト、ミキサー、オートメーションが、設定ごと移ります。FL Studioにないものについては、オーディオにレンダリング（同じ音） と 最も近い FL プラグインを使う（編集可能のまま、音が変わる場合あり） から選びます。後者を選ぶと、LYNX専用のインストゥルメントは省かれます。曲の位置に追従するモジュレーターはオートメーションクリップになります。同期したLFOはFL Studioのクリップ LFOに、ステップ、ランダムソース、マクロはポイントになります。フォロワー、エンベロープ、キートラック、ベロシティは省かれます。レポートには、レンダリングされたもの、置き換えられたもの、省かれたものが一覧されます。詳しくはFL Studioから移る方へをご覧ください。

.als には、チャンネルごとのMIDIトラック、オーディオトラック、グループ、リターン、センド、ラックとDrum Rack、状態付きのVST2とVST3プラグイン、マーカー、ボリューム、パン、テンポのオートメーションが入ります。LYNX SHARE独自のインストゥルメントとエフェクトは変換されませんが、そのトラックとノートは保たれます。例外はHelixで、LiveのWavetableになります。エフェクトのパラメーターのオートメーションと、インサート間のルートは省かれます。詳しくはAbleton Liveから移る方へをご覧ください。

.dawproject には、トラック、フォルダー、クリップ、ノート、ワープマーカー付きのオーディオ、オートメーション、テンポ、マーカー、センド付きのミキサー、状態付きのVST3、VST2、CLAPプラグインが入ります。LYNX SHARE独自のインストゥルメントとエフェクトは、LYNX SHAREでもう一度開けるように書き出されます。クリップグリッド、ほかのアレンジメント、ノートごとの細かな情報の一部は省かれ、レポートに一覧されます。

ファイル › FL Studio Mobileプロジェクト(.flm)としてコピーを保存... は、FL Studio Mobile用の .flm を書き出し、サンプルを隣の <name> Samples フォルダーにコピーします。保存の前に、ファイル › 古いLYNX用にコピーを保存... と同じように、コピーで失われるものがウィンドウに一覧表示されます。.flm には、ノートとパターン(FL Studio Mobileではトラックごとに1つのパターン)、テンポ、1小節の拍数、キーとコードセット、ミキサーのレベル、パン、ミュート、ソロ、バスへのセンド、FL Studio Mobile独自のインストゥルメント(MiniSynth、SuperSaw、GMSynth、Transistor Bass、およびFL StudioのMiniSynthとTransistor Bass)、ドラムキットになるドラムサンプラー、複数のインストゥルメントを持つラックになるレイヤー、ミックス付きのすべてのPocket(FLM)エフェクト、レベル、パン、ピッチ、リバース付きのオーディオクリップが残ります。DW Sampler(ゾーン付き)と3x Oscのほか、ミキサーのレベルとパン、Pocket(FLM)エフェクト、DW SamplerとGMSynth自身の値のオートメーションクリップも書き出されます。それ以外のインストゥルメント(今のところFL Studio MobileのSlicerとSoundFont Playerを含む)はノートがFL Studio MobileのMiniSynthに残り、FLMのモジュールがないエフェクトと、シンセ自身のノブやサードパーティ製プラグインなど他の対象のオートメーションは省かれます。すべて一覧に載ります。

知っておくと便利なこと

  • MP3、OGG、M4A、32ビットWAVでは ディザー がグレーアウトされ、WAV以外のすべての形式ではテンポとマーカーのオプションがグレーアウトされます。
  • プレイリストの選択範囲 で、プレイリストに選択範囲がないと、曲全体がレンダリングされます。ウィンドウが警告します。
  • マスターインサートがミュートされていると、ファイルが無音になるとウィンドウが警告します。
  • このミックスでビデオも書き出す は、プロジェクトにビデオトラックがあるときだけ表示され、FFmpegが必要です。
  • ハードウェア経由でリアルタイムにレンダリング は、プロジェクトに有効なハードウェアインサートがあるときだけ表示されます。このエクスポートは曲の長さと同じ時間がかかります。
  • インサートをオーディオクリップにバウンスするオーディオへのレンダリングは、このバージョンでは、置き換え前のインサートより約5 dB大きく再生されます。
