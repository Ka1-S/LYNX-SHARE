Fruity Filter adalah filter state-variable untuk slot insert mixer. Alih-alih memilih satu jenis filter, kamu mengatur level output low-pass, band-pass, dan high-pass lalu dicampur bersama. Cocok untuk sweep dan pembentukan nada sederhana.

Controls

ControlWhat it does
CutoffTitik tengah filter. Terbuka penuh secara bawaan.
ResonansiPenekanan di sekitar cutoff.
Low passLevel output low-pass.
Band passLevel output band-pass. Mati secara bawaan.
High passLevel output high-pass.
x2Menjalankan filter dua kali secara seri untuk slope yang lebih curam.
TengahMenghilangkan DC offset dari output.

Tips

  • Naikkan Low pass dan High pass bersamaan dengan Band pass di nol untuk respons mirip notch.
  • Koefisien filter tidak bergantung pada sample rate proyek.
