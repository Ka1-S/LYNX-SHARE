Keyboard Controller mengatur outputnya ke nilai yang kamu gambar untuk tuts yang terakhir dimainkan. Ia tidak mengeluarkan suara; kamu menautkan outputnya ke kontrol lain. Kamu menggambar nilainya dengan mouse di atas keyboard.

Controls

ControlWhat it does
Key valuesBatang di atas keyboard; tinggi tiap batang adalah output untuk tuts itu.
Note offNilai yang dituju output saat tidak ada tuts yang ditahan.
Release otomatisSaat tidak ada tuts yang ditahan, output menuju nilai note-off.
RampNilai setiap tuts naik dari 0 di tuts terendah sampai 1 di C10.
InversiMembalik setiap nilai.
BersihkanMengatur nilai setiap tuts ke 0.

Tips

  • Proyek FL yang diimpor mempertahankan nilai Keyboard Controller.
