Fruity Multiband Compressor membagi input menjadi band rendah, mid, dan tinggi, masing-masing dengan filter sendiri, menjalankan compressor peak dengan make-up gain pada tiap band, lalu menjumlahkannya lewat gain output dan soft limiter opsional. Plugin ini memuat pengaturan plugin FL Studio dari proyek .flp yang diimpor.

Controls

ControlWhat it does
IIR / FIRJenis filter band. IIR memakai filter orde ke-4. FIR memakai filter linear-phase dengan latensi 52 sample, yang dilaporkan untuk kompensasi delay.
LimiterMenyalakan soft limiter di output.
Gain (left)Gain output setelah ketiga band dijumlahkan.
CrossoverEmpat knob di bawah grafik band: batas atas band rendah, batas bawah dan batas atas band mid, dan batas bawah band tinggi.
A / M / BPer band. A mengompresi band, M me-mute-nya, dan B meneruskannya tanpa kompresi.
ThresPer band. Level di mana band mulai dikompresi.
RatioPer band. Rasio kompresi.
KneePer band. Seberapa bertahap kompresi dimulai di sekitar threshold.
Att / RelPer band. Waktu attack dan release compressor band.
Gain (band)Per band. Make-up gain setelah compressor.

Tips

  • Tiap band difilter dari input secara terpisah, jadi keempat knob crossover tidak saling bergantung.
  • Beralih antara IIR dan FIR mengosongkan filter.
