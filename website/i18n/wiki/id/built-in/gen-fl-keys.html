FL Keys adalah generator keyboard sampel yang dibangun di atas engine plugin FL dengan nama yang sama. Ia memainkan set wavetable seperti Grand Piano lewat envelope eksponensial, overdrive lembut, low-pass muffle, treble shelf, LFO tremolo atau auto-pan, dan stereo delay pendek. File wavetable dibaca dari instalasi FL Studio milikmu sendiri dan tidak disertakan. Instance baru dimulai dari preset plugin di instalasi FL Studio milikmu sendiri, jadi menambahkannya butuh FL Studio terinstal; kalau tidak, menu Add mencantumkannya sebagai membutuhkan FL Studio. Pada impor .flp, kalau engine tidak bisa memuat set itu, channel beralih ke sampler bersegmen.

Controls

ControlWhat it does
Name displayMenampilkan set wavetable yang dipakai, di kanan atas.
DecaySeberapa cepat not meluruh selama tuts ditahan. Pada minimum, not tidak meluruh.
ReleaseSeberapa cepat not memudar setelah tuts dilepas.
PanKedalaman LFO. Di atas tengah kedua sisi bergerak bersamaan (tremolo); di bawahnya keduanya bergerak berlawanan arah (auto-pan).
StereoLebar stereo delay dan sebaran kiri ke kanan not di sepanjang keyboard.
OverdriveJumlah overdrive lembut pada tiap not.
LFOLaju LFO tremolo atau auto-pan.
TrebleGain treble shelf: cut di bawah tengah, boost di atasnya.
StretchMeregangkan penyetelan not di atas middle C, makin jauh dari situ makin besar.
Muffle and its VelMuffle mengatur cutoff low-pass per not. Knob Vel di sampingnya mengatur seberapa banyak velocity membuka filter itu.
Hardness and its VelHardness menggeser grup sample mana yang dimainkan sebuah tuts, hingga enam tuts ke kedua arah. Knob Vel di sampingnya menambah pergeseran untuk velocity di atas 40.
SensSensitivitas velocity: pangkat yang diterapkan pada volume not.
TunePenyetelan, satu semiton ke kedua arah.
DetuneMen-detune tuts satu sama lain dalam pola tetap per tuts.

Tips

  • Hingga 32 voice bermain sekaligus; di luar itu voice paling pelan yang berbunyi berakhir lebih dulu.
  • Set yang ditandai untuk resampling, seperti Roto Organ, tidak di-resample saat rate proyek berbeda dari 44,1 kHz.
