Fruity HTML NoteBook tidak memproses audio. Ia menyimpan alamat sebuah halaman, baik file .html lokal maupun alamat web, supaya kamu bisa menyimpan catatan, lirik, atau referensi di samping proyek. Ia ditambahkan seperti efek insert.

Controls

ControlWhat it does
AddressFile .html lokal atau alamat web dari halaman tersebut.
TelusuriMemilih file .html lokal.
Buka di browserMembuka alamat itu di browser bawaanmu.

Tips

  • Halaman lokal ditampilkan di dalam editor sebagai teks berformat, tautan dibuka di browsermu.
  • LYNX SHARE tidak pernah mengambil halaman web sendiri, alamat web selalu dibuka di browsermu.
