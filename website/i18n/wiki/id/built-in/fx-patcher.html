Patcher memungkinkan kamu menghubungkan efek, instrumen, dan plugin VST3 atau CLAP dengan kabel di dalam satu slot mixer. Grafnya punya node input dan node output. Proyek FL Studio yang memakai Patcher terbuka sebagai graf yang sama.

Controls

ControlWhat it does
MapTampilan graf, tempat plugin menjadi node dan kabel membawa audio, not, dan nilai kontrol.
SurfaceHalaman berisi knob, slider, tombol, check box, dan pad XY milikmu sendiri.
EditMemungkinkan kamu memindahkan, mengganti nama, atau menghapus kontrol Surface.
+Menambahkan kontrol ke Surface.
Tambah pluginKlik kanan di Map untuk menambahkan plugin.
Sesuaikan ke jendelaMenskalakan tampilan agar seluruh graf terlihat.

Tips

  • Seret dari pin output ke pin input untuk menghubungkan dua node.
  • Klik ganda sebuah node untuk membuka editornya.
