Emphasizer adalah limiter look-ahead dengan satu knob utama. Input gain menyuapi detektor peak, pengurangan gain diterapkan pada sinyal yang tertunda 2 ms, dan hasilnya di-clip lalu dikirim ke gain output. Plugin ini memuat pengaturan Emphasizer FL Studio dari proyek .flp yang diimpor dan melaporkan look-ahead 2 ms untuk kompensasi delay.

Controls

ControlWhat it does
Gain inputGain sebelum limiter, 0 dB sampai +24 dB.
EmphasisBesarnya, 0 sampai 100 persen. Menskalakan level yang dilihat detektor peak.
OutputLevel output, sampai 0 dB.
Soft clippingMengganti hard clip pada skala penuh setelah limiter dengan soft clip yang mulai di bawahnya.
Penyamaan levelMembagi output dengan input gain, jadi menaikkan Input gain tidak menaikkan level.
BypassCrossfade ke sinyal dry yang tertunda, bukan beralih secara tegas.

Tips

  • Dengan Penyamaan level menyala, Input gain bisa dinaikkan untuk men-drive limiter lebih keras tanpa output menjadi lebih keras sebesar itu.
  • Strip meter di kanan menampilkan level.
