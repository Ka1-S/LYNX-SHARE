Pocket Tremolo menggerakkan level suara di antara gain minimum dan maksimum dengan LFO. Offset fase antara kiri dan kanan mengubahnya menjadi auto-pan. Ia adalah mesin tempat proyek FL Studio Mobile (.flm) memuat modul Tremolo-nya, dengan setiap nilai disalin apa adanya, dan juga bisa ditambahkan ke slot mixer mana pun.

Controls

ControlWhat it does
RateKecepatan LFO saat Sinkron mati, 0,1 Hz sampai 20 Hz.
Sinkron ratePanjang siklus LFO saat Sinkron menyala: 1/8, 1/4, 3/8, 1/2, 3/4, beat, 2 beat, 4 beat, 8 beat, atau 16 beat.
Jumlah maks.Gain tertinggi dari siklus, 0 sampai 100 %. Mengaturnya di bawah Jumlah min. menarik minimum ikut turun.
Jumlah min.Gain terendah dari siklus, 0 sampai 100 %. Mengaturnya di atas Jumlah maks. mendorong maksimum ikut naik.
Offset faseFase awal LFO untuk kedua channel, 0 sampai 360.
Offset stereoFase tambahan untuk channel kanan, 0 sampai 360. Pada 180 kedua sisi bergerak berlawanan arah.
SinkronAktif memakai Sinkron rate dan mengikuti posisi lagu. Mati memakai Rate.
BentukMembengkokkan gelombang dengan eksponen. Terbaca 0 sampai 100, 50 membiarkannya tidak bengkok.
HalusPerpaduan antara gelombang garis lurus (0) dan versinya yang membulat seperti sine (100).
SkewPosisi puncak di dalam siklus. Terbaca -100 sampai +100, 0 berarti naik dan turun simetris.
LebarBagian siklus yang dihabiskan di dekat maksimum dibandingkan minimum. Terbaca 0 sampai 100, 50 berarti seimbang.

Tips

  • Ayunan gain mencapai 99 % dari rentang antara Jumlah min. dan Jumlah maks.
  • Gain dihaluskan oleh filter di sekitar 333 Hz, jadi bentuk bertepi tajam tidak menimbulkan bunyi klik.
