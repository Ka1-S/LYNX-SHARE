Fruity Love Philter punya delapan unit. Tiap unit punya level input, filter, waveshaper, dan output dengan pan dan volume, dan bisa menyuapi unit berikutnya. Per unit, articulator memodulasi pan, volume, cutoff, resonansi, level low, band, dan high serta mix waveshaper dari envelope pattern, LFO, kontrol Mod X dan Mod Y, dan envelope follower. Plugin ini memuat pengaturan plugin FL Studio dari proyek .flp yang diimpor.

Controls

ControlWhat it does
Unit switches and tabs 1 to 8Saklar di atas mengaktifkan tiap unit. Tab memilih unit yang ditampilkan.
IN: VOLLevel input plugin ke unit ini. Nilai negatif membalik fase.
Filter type and modePemilih jenis memilih filter. Mode mengatur jumlah tahap secara seri: Off, Single, Dual, Triple, Alt dual, atau Alt triple. Off hanya menyisakan gain, pan, dan waveshaper.
CUT / RESCutoff dan resonansi (atau lebar) filter unit.
ENVKedalaman articulator cutoff.
L / B / HLevel output low-pass, band-pass, dan high-pass dari jenis SVF.
ALTRespons resonansi atau lebar alternatif dari filter.
WS: AMP, MIX, MODEWaveshaper: gain ke shaper, mix-nya dengan sinyal yang belum dibentuk, dan kurva unipolar atau bipolar.
OUT: PAN, VOLPan dan level unit di output plugin.
NEXTSeberapa banyak output unit ini menyuapi unit berikutnya. Pada nol unit berjalan paralel.
Articulator editorTab PAN, VOL, CUT, RES, LOW, BAND, HIGH, WS, dan WMIX memilih target, dan PAT, LFO, MOD X, MOD Y, dan IEF memilih sumber yang kurvanya digambar di bawah.
X / Y padMengatur Mod X dan Mod Y. SMOOTH menghaluskan perubahannya.
VOL / LFO / IEF slidersLevel master, level LFO master, dan level ke envelope follower.
IEF: USE1, ATT, RELAttack dan release envelope follower. USE1 membuatnya mengikuti output unit 1, bukan input plugin.
CENTERMenghapus offset DC dari output.
OVERSAMPLINGOrde oversampling engine. Digandakan saat rendering.

Tips

  • Hanya unit pertama yang aktif pada instance baru.
  • Output setiap unit yang aktif dijumlahkan, jadi dengan NEXT di nol beberapa unit bekerja sebagai filter paralel.
