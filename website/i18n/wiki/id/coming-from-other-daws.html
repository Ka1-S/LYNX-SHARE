LYNX SHARE punya tiga tata letak. Kalau kamu datang dari Logic, Cubase, Reaper, Pro Tools, atau Studio One, mulailah dengan tata letak sederhana dengan Mixer di dekatmu: satu track per instrumen atau suara di linimasa, seperti yang kamu kenal. Tata letak Pattern, cara kerja FL Studio, tersedia kalau kamu ingin pattern.

Langkah pertamamu

  1. Pilih tata letak. Saat LYNX SHARE pertama kali dijalankan, sebuah kartu sambutan menanyakan dari mana kamu datang. Klik Logic, Cubase, Reaper, Pro Tools, atau Studio One: tata letak sederhana terbuka di kartu New track-nya, dan Mixer muncul bersama track pertamamu. Nanti, Tampilan › Gaya tata letak › Alur kerja sederhana beralih ke sana kapan saja, dan F9 membuka Mixer.
  2. Tambahkan track. + Tambah trek menawarkan Vokal / audio, Instrumen, Drum, Sampler, Gitar / bass, Impor, dan Loop. Mainkan track instrumen dengan tombol komputer, keyboard di layar, atau keyboard MIDI.
  3. Rekam. Pilih perangkat audiomu di Opsi › Pengaturan audio..., lalu lihat Rekam suaramu.

Yang sama

  • Track di linimasa dengan clip audio, MIDI, dan otomasi.
  • Perekaman audio dan MIDI, dengan take loop dan comping.
  • Mixer dengan insert, send, sidechain, grup, dan kompensasi delay.
  • Plugin pihak ketiga: VST3 dan CLAP di semua sistem, Audio Units di macOS, LV2 di Linux, VST2 di Windows dan Linux.
  • Ekspor lagu, stem per track, dan MIDI.

Yang berbeda

  • Track dan insert mixer terpisah. Di tata letak sederhana, setiap track baru mendapat channel dan track mixer sendiri. Di tata letak Pattern, kamu mengarahkan channel ke insert sendiri, seperti di FL Studio.
  • Pattern. Di tata letak Pattern, not berada di pattern yang kamu taruh di Playlist, dan satu pattern bisa memuat beberapa instrumen.
  • Tombolnya mengikuti FL Studio. Ctrl+Z membatalkan satu langkah, dan jika ditekan lagi akan mengulanginya. Ctrl+Alt+Z mundur lebih jauh.
  • Tidak ada impor proyek dari Logic, Cubase, Reaper, atau Pro Tools. Pindahkan proyek dengan file DAWproject, stem, atau MIDI (di bawah).

Memindahkan proyek

  • Cubase, Studio One, dan Bitwig: simpan file DAWproject (.dawproject) di sana lalu buka dengan File › Buka.... Track, folder, clip, not, audio beserta penanda warp-nya, otomasi, tempo, penanda, mixer dengan send, serta plugin VST3, VST2, dan CLAP dengan statusnya ikut masuk. File › Ekspor › DAWproject (.dawproject)... berjalan ke arah sebaliknya.
  • Logic, Reaper, dan Pro Tools: ekspor tiap track sebagai file audio atau MIDI dari awal lagu ke satu folder. Di LYNX SHARE klik + Tambah trek, lalu Folder... di samping Impor: setiap file menjadi track yang dimulai dari awal.
  • Keluar lagi: jendela ekspor menulis satu file per insert mixer atau per channel, dan File › Ekspor › File MIDI... menulis not-nya.
