Pengelola plugin

  1. Pilih Opsi › Pengelola plugin.... Ia mencantumkan setiap plugin yang ditemukan LYNX, lengkap dengan vendor, format, dan filenya.
  2. Folder plugin... menunjukkan tempat LYNX mencari: folder VST3 dan CLAP standar, plus folder apa pun yang kamu tambahkan.

Pindai plugin

  1. Klik Cari plugin baru. Setiap file diperiksa di proses terpisah, jadi plugin yang crash tidak bisa menjatuhkan LYNX: plugin itu dicantumkan di Failed.
  2. Cari berdasarkan nama, vendor, atau format; bintang menjadikan plugin favorit.

Muat plugin

  1. Di Mixer, pilih sebuah track dan klik slot kosong.
  2. Pilih Plugin (VST/VST3/CLAP), lalu Plugin lainnya..., cari plugin berdasarkan nama dan klik Tambah.
  3. Plugin terbuka di jendelanya sendiri. Tekan Play untuk mendengarnya.
