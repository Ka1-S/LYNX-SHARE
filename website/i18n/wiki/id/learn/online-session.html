Mulai sesi (host)

  1. Buka proyek yang ingin kamu bagikan.
  2. Pilih File › Sesi online › Mulai sesi live....
  3. Ketik namamu. Di bawah Tamu boleh menyunting, biarkan Hanya channel, pattern, insert, dan barisnya sendiri (disarankan) atau pilih Semuanya.
  4. Klik Awal.

Undang temanmu

  1. LYNX SHARE menampilkan kode undangan sesi. Klik Salin.
  2. Kirim kode itu ke sampai 3 orang, lewat chat atau e-mail.
  3. File › Sesi online › Tampilkan kode undangan... menampilkannya lagi nanti.

Bergabung (tamu)

  1. Pilih File › Sesi online › Gabung ke sesi live....
  2. Ketik namamu, tempel kode undangan, lalu klik Gabung.
  3. Tunggu sampai host mengizinkanmu masuk. Proyek host terbuka.

Izinkan mereka masuk (host)

Saat seseorang meminta bergabung, klik Izinkan masuk, atau Nanti saja.

Bekerja bersama

  • Setiap perubahan yang dibuat siapa pun sampai ke semua orang. Setiap tamu mendapat warna sendiri, serta track dan insert mixer miliknya.
  • File › Sesi online › Obrolan sesi... membuka chat.
  • Host memilih File › Sesi online › Akhiri sesi live untuk mengakhirinya. Proyek tetap di komputer host, dan para tamu menyimpan apa yang tertulis di jendela mulai: bagian mereka sendiri atau salinan lengkap.

Perlu diketahui

  • Sampai 4 orang ikut serta, termasuk kamu.
  • Semuanya dienkripsi end-to-end dengan kode undangan. Relay LYNX SHARE hanya meneruskannya.
  • Tidak ada internet? File › Sesi online › Kirim proyek... membuat file paket sebagai gantinya. Lihat Sesi online.
