Simpan sebagai

  1. Pilih File › Simpan sebagai... dan beri nama proyek. Proyek LYNX (.lynx) menyimpan pattern, Mixer, plugin beserta pengaturannya, dan menunjuk ke sample dan rekamannya, yang tetap menjadi file tersendiri.
  2. Setelah itu File › Simpan (Ctrl+S) menyimpan menimpanya. File yang digantikan masuk ke cadangan.

Simpan versi baru

  1. Mencoba ide? File › Simpan versi baru (Ctrl+N di tata letak Pattern, seperti di FL Studio; Ctrl+Alt+S di setiap tata letak) menyimpan proyek sebagai My beat_2, di samping yang pertama, dan kamu terus bekerja di dalamnya.
  2. LYNX juga menulis cadangan saat kamu bekerja, jadi crash atau kesalahan tidak terlalu merugikan.

Versi dan cadangan

  1. File › Versi... mencantumkan versi tersimpan dan cadangan proyek ini, yang terbaru di atas.
  2. Pilih satu dan klik Buka sebagai salinan: ia terbuka sebagai proyek baru yang belum disimpan, dan file aslinya tidak berubah. Label... menambahkan catatan padanya.
  3. File › Kembalikan ke cadangan terakhir... mengganti proyek yang terbuka dengan cadangan terbarunya. File proyeknya sendiri baru berubah saat kamu menyimpan.

Pindahkan proyek ke komputer lain

  1. Sample dan rekaman adalah file di samping .lynx, bukan di dalamnya. File › Kumpulkan semua dan simpan menyalin yang berasal dari luar folder proyek ke dalamnya lalu menyimpan; centang File › Selalu kumpulkan dan simpan untuk melakukannya setiap kali menyimpan.
  2. File › Ekspor › Paket loop zip... menulis satu .zip berisi proyek dan setiap file yang dipakainya: salin file itu ke komputer lain.
  3. File › Buka folder proyek menunjukkan di mana proyek dan file-filenya berada.

Lihat juga Undo dan riwayat.
