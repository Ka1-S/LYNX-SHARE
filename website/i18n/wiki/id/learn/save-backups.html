Simpan sebagai

  1. Pilih File › Simpan sebagai... dan beri nama proyek. Proyek LYNX (.lynx) menyimpan semuanya: pattern, Mixer, plugin beserta pengaturannya.
  2. Setelah itu File › Simpan (Ctrl+S) menyimpan menimpanya. File yang digantikan masuk ke cadangan.

Simpan versi baru

  1. Mencoba ide? File › Simpan versi baru (Ctrl+Alt+S) menyimpan proyek sebagai My beat_2, di samping yang pertama, dan kamu terus bekerja di dalamnya.
  2. LYNX juga menulis cadangan saat kamu bekerja, jadi crash atau kesalahan tidak terlalu merugikan.

Versi dan cadangan

  1. File › Versi... mencantumkan versi tersimpan dan cadangan proyek ini, yang terbaru di atas.
  2. Pilih satu dan klik Buka sebagai salinan: ia terbuka sebagai proyek baru yang belum disimpan, dan file aslinya tidak berubah. Label... menambahkan catatan padanya.
  3. File › Kembalikan ke cadangan terakhir... mengganti proyek yang terbuka dengan cadangan terbarunya. File proyeknya sendiri baru berubah saat kamu menyimpan.

Lihat juga Undo dan riwayat.
