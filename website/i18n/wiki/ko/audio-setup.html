설정 창의 오디오 페이지에서 소리가 나갈 곳과 녹음이 들어올 곳을 정합니다. 옵션 › 오디오 설정...로 엽니다. 설정 마법사(옵션 › 설정 마법사(언어, 오디오, 플러그인 폴더)...)에서도 오디오 출력을 테스트할 수 있습니다.

소리 내기

  1. 옵션 › 오디오 설정...를 엽니다.
  2. 드라이버를 고릅니다. 상자 아래의 설명에 그 드라이버의 쓰임새가 나옵니다.
  3. 출력 장치를 고릅니다.
  4. 테스트 사운드 재생를 클릭합니다.
  5. 상태 섹션을 확인합니다. 실행 중인 드라이버, 샘플 레이트, 출력 레이턴시가 표시됩니다. 장치가 없으면 열린 오디오 장치가 없습니다. 출력 장치를 선택하세요.가 나옵니다.

드라이버

드라이버 상자에는 시스템에서 쓸 수 있는 드라이버 유형이 나열됩니다.

시스템드라이버기능
WindowsWindows 오디오(공유)다른 프로그램의 소리가 그대로 유지됩니다. Windows가 모든 프로그램을 일정한 간격으로 믹싱하므로 버퍼를 그 간격보다 작게 할 수 없습니다
WindowsWindows 오디오(공유, 저지연 주기)공유 방식이지만 Windows에 더 짧은 믹싱 주기를 요청합니다. 일부 드라이버만 지원합니다
WindowsWindows 오디오(독점, 최저 레이턴시)LYNX SHARE가 장치를 혼자 사용합니다. 재생하는 동안 다른 프로그램은 소리가 나지 않습니다
WindowsDirectSound(레거시)레이턴시가 높은 예전 Windows 오디오 경로입니다. 다른 방식이 모두 안 될 때 씁니다
WindowsASIO저지연 드라이버입니다. 제조사의 ASIO 드라이버는 해당 제조사의 장치에서 작동합니다
WindowsLYNX ASIO(내장)모든 장치에서 재생과 녹음에 쓸 수 있는 LYNX SHARE 자체 ASIO 드라이버입니다. 드라이버 설정...에서 공유/독점 모드와 장치를 고릅니다
macOSCore Audio다른 프로그램과 공유하는 시스템 자체 오디오입니다
LinuxPipeWire(네이티브)LYNX SHARE가 PipeWire와 직접 통신합니다. System default는 시스템 사운드 설정에서 고른 출력을 따릅니다
LinuxJACK / PipeWire실행 중인 JACK 서버, 또는 pipewire-jack이 있는 PipeWire용입니다
LinuxALSA사운드 카드와 직접 통신합니다. default나 pipewire는 장치를 공유하고, hw: 장치는 카드를 LYNX SHARE가 단독으로 사용합니다

Linux에서는 처음 시작할 때 PipeWire, JACK, ALSA 중 장치가 있는 첫 번째를 엽니다. 한 번 고른 설정은 저장됩니다.

소리가 나지 않을 때

  • 먼저 상태를 봅니다. 열린 장치가 없으면 출력 장치를 고릅니다.
  • 다른 드라이버를 써 봅니다. Windows에서 Windows 오디오(공유)는 다른 프로그램의 소리를 유지해 주고, DirectSound(레거시)는 다른 방식이 안 될 때를 위한 것입니다.
  • 믹서의 마스터 페이더와 툴바의 마스터 노브를 확인합니다.
  • 패턴 모드에서는 현재 패턴만 재생됩니다. 비어 있으면 아무 소리도 나지 않습니다. L을 눌러 송 모드로 바꿉니다.
  • Linux에서 소리가 끊기면 상태에 오디오 스레드가 실시간 우선순위를 받았는지 표시됩니다. 해결 방법은 문제 해결에 있습니다.

알아 두기

  • ASIO는 Windows에만 있습니다.
  • Windows 오디오(공유)에서 가장 작은 버퍼는 시스템의 믹싱 간격입니다. 드라이버 상자 아래의 설명에 사용 중인 장치의 수치가 나옵니다. 레이턴시를 더 낮추려면 독점 모드나 ASIO 드라이버를 쓰세요.
  • PipeWire에서는 버퍼가 32~2048샘플, 샘플 레이트가 44.1~192 kHz입니다. PipeWire가 자체 샘플 레이트를 유지하면 LYNX SHARE의 스트림을 리샘플링합니다.
  • PipeWire에서 이름을 지정한 장치를 뽑으면 LYNX SHARE는 System default로 돌아가고 버퍼 크기는 유지합니다.
  • 상태에는 오디오 CPU 부하도 표시되고, 소리 끊김(버퍼 언더런)도 집계됩니다.
  • 창을 열지 않고도 드라이버와 장치 목록을 볼 수 있습니다. 명령줄의 --devices를 참고하세요.
