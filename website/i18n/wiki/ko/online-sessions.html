다른 사람과 함께 프로젝트를 작업하는 방법은 두 가지이며, 모두 파일 › 온라인 세션에 있습니다. 패키지는 친구에게 보내는 파일로, 친구가 파트를 만들어 돌려보냅니다. 네트워크, 계정, 서버가 필요 없습니다. 라이브 세션은 LYNX SHARE 릴레이를 통해 모두를 인터넷으로 연결하며, 모든 변경이 모두에게 전달됩니다. 한 프로젝트에는 본인을 포함해 최대 4명이 참여할 수 있습니다.

친구에게 프로젝트 보내기

  1. 프로젝트를 열고 파일 › 온라인 세션 › 프로젝트 보내기...를 선택합니다.
  2. 본인의 이름과 친구의 이름을 입력합니다.
  3. 세션이 끝날 때 친구가 갖게 될 것을 자신의 파트만(권장)와 프로젝트 전체 사본 중에서 고릅니다.
  4. .lynxpack 파일을 저장합니다.
  5. 이메일, 공유 폴더, USB 메모리 등 편한 방법으로 파일을 보냅니다.

패키지에는 프로젝트, 프로젝트가 쓰는 모든 샘플과 녹음, 서드파티 플러그인을 쓰는 파트의 오디오 렌더링("대역 사운드")이 들어 있습니다. 친구는 같은 플러그인이 없어도 그 파트를 들을 수 있습니다.

파트를 녹음해서 돌려보내기

친구가 하는 일입니다.

  1. 파일 › 열기...으로 .lynxpack을 엽니다. 요약에 보낸 사람, 그리고 어느 믹서 인서트와 플레이리스트 트랙이 내 것인지 표시됩니다. 열기을 클릭합니다.
  2. 내 인서트와 플레이리스트 트랙에 내 채널, 패턴, 오디오를 추가합니다. 호스트의 자료는 그대로 둡니다.
  3. 파일 › 온라인 세션 › 내 파트 돌려보내기...를 선택하고 새 패키지를 호스트에게 보냅니다.

게스트마다 색상 하나, 믹서 인서트 20개, 플레이리스트 트랙 16개가 주어집니다.

파트 병합하기

호스트가 하는 일입니다.

  1. 보냈던 프로젝트를 엽니다.
  2. 파일 › 온라인 세션 › 파트 병합...를 선택하고 친구가 돌려보낸 패키지를 고릅니다.
  3. 친구의 채널, 패턴, 노트, 클립, 인서트가 친구의 색상으로 추가됩니다. 내 것은 하나도 바뀌지 않습니다.

병합은 실행 취소 한 단계입니다. 같은 친구의 더 새로운 파트는 이전 파트를 대체합니다.

라이브 세션 시작하기와 참가하기

호스트가 세션을 시작합니다.

  1. 프로젝트를 열고 파일 › 온라인 세션 › 라이브 세션 시작...을 선택합니다.
  2. 이름을 입력합니다.
  3. 게스트 편집 범위에서 자신의 채널, 패턴, 인서트, 행만(권장) 또는 전체을 고릅니다. 세션이 끝나면 게스트가 보관하는 것에서는 자신의 파트 또는 전체 사본을 고릅니다.
  4. 시작를 클릭하고, 초대 코드를 복사해서 최대 3명에게 보냅니다.
  5. 누군가 참가를 요청하면 입장 허락을 클릭합니다.

게스트가 참가합니다.

  1. 파일 › 온라인 세션 › 라이브 세션 참가...을 선택합니다.
  2. 이름을 입력하고 초대 코드를 붙여넣은 뒤 참가을 클릭합니다.
  3. 호스트가 입장시킬 때까지 기다립니다. 호스트의 프로젝트가 열립니다.

라이브 세션 중

세션이 진행되는 동안 파일 › 온라인 세션 메뉴에 다음 명령이 있습니다.

명령기능
세션 채팅...채팅을 엽니다. 메뉴 항목에 읽지 않은 메시지 수가 표시됩니다
호스트의 트랜스포트 따라가기게스트용: 재생, 정지, 위치가 호스트를 따라갑니다
참가자 및 권한...호스트용: 각 사람이 바꿀 수 있는 것과 끝날 때 각자 갖게 될 것을 정합니다
게스트와 플러그인 공유...호스트용: 게스트가 쓸 수 있는 내 플러그인을 정합니다. 메뉴 항목에 공유 중인 개수가 나옵니다
초대 코드 보기...호스트용: 복사 버튼과 함께 코드를 다시 보여 줍니다
라이브 세션 종료호스트용. 모두 나가고 코드가 더 이상 작동하지 않습니다
라이브 세션 나가기게스트용. 프로젝트에서 내 파트는 내게 남습니다

참가자 및 권한...에서는 사람마다 네 가지 역할 중 하나를 받습니다. 자신의 채널, 패턴, 인서트, 행, 자신의 파트 + 템포 및 프로젝트 설정, 전체, 듣기만(편집 없음)입니다. 권한을 꺼도 아무것도 삭제되지 않습니다.

다른 사람에게 없는 플러그인

플러그인이 내 컴퓨터에 설치되어 있지 않은 채널이나 인서트는 대역 사운드를 재생하며, 채널 랙과 믹서에 주황색 R 배지가 표시됩니다.

  • 패키지에서 대역 사운드는 패키지를 저장할 때 만든 오디오 렌더링입니다. 옮긴 클립은 따라가지만, 내게 없는 플러그인의 노트를 고친 것은 반영되지 않습니다. 그 플러그인을 가진 사람에게 새 패키지를 요청하세요.
  • 라이브 세션에서는 누군가에게 없는 플러그인을 쓰는 파트를 그 플러그인을 가진 사람이 렌더링해서 다른 사람들에게 오디오로 스트리밍합니다.

게스트와 플러그인 공유하기

라이브 세션에서 호스트는 호스트에게만 있는 플러그인을 게스트가 쓰게 할 수 있습니다.

호스트는 이렇게 합니다.

  1. 파일 › 온라인 세션 › 게스트와 플러그인 공유...를 고릅니다.
  2. 공유할 플러그인을 체크합니다. 플러그인 검색로 목록을 좁힐 수 있습니다. 체크하기 전에는 아무것도 공유되지 않습니다.

게스트는 이렇게 합니다.

  1. 채널이나 이펙트 슬롯의 플러그인 메뉴를 엽니다. 공유된 플러그인이 On <host>'s computer 아래 맨 앞에 나옵니다.
  2. 하나를 고릅니다. 그 창에 플러그인의 파라미터가 슬라이더로 나열되며 파라미터 검색가 있습니다.
  3. 노트를 추가하고 슬라이더를 움직입니다. 호스트의 컴퓨터가 렌더링하는 동안 창에 Updating...이 표시되고, 끝나면 최신 상태가 표시됩니다.
  • 플러그인은 호스트의 컴퓨터에 그대로 있고 호스트의 라이선스로 실행됩니다. LYNX SHARE는 플러그인, 플러그인의 파일, 프리셋, 라이선스를 절대 보내지 않습니다.
  • 게스트는 노트와 값을 잠시 뒤에 따라가는 렌더링을 듣습니다. 실시간으로 재생되는 것이 아니며, 게스트는 플러그인 자체의 창을 받지 않습니다.
  • 호스트가 자리를 비우면 마지막 렌더링이 재생됩니다. 세션이 끝나면 공유도 멈추고 마지막 렌더링은 남습니다.
  • 듣기만(편집 없음) 역할의 게스트는 공유된 플러그인을 쓸 수 없습니다.
  • 일부 플러그인 라이선스는 원격으로라도 다른 사람이 플러그인을 조작하는 것을 허용하지 않습니다. 공유하기 전에 각 라이선스를 확인하세요.

네트워크로 가는 것

패키지는 파일입니다. 어디에도 업로드되지 않습니다.

라이브 세션은 세션 안에 있는 동안만 연결됩니다. 모든 데이터는 릴레이 relay.lynx-share.com을 거치며, 초대 코드에서 나온 키로 종단 간 암호화됩니다. 릴레이는 데이터를 읽지 못한 채 전달만 합니다. 릴레이가 보는 것은 IP 주소, 접속한 시간, 지나간 바이트 수입니다. 세션의 다른 사람들은 내 이름, 편집 내용, 내 파트가 쓰는 샘플, 재생 중인지 녹음 중인지를 봅니다. IP 주소는 보지 못합니다. 자세한 내용은 개인정보 처리방침에 있습니다.

알아 두기

  • 자신의 파트만는 음악가 사이의 배려이지 복제 방지가 아닙니다. 패키지는 평범한 zip입니다.
  • 양쪽이 같은 LYNX SHARE 버전을 써야 합니다. 버전이 다르면 패키지 요약이 경고합니다.
  • 연결이 끊긴 게스트는 자동으로 다시 연결되며 편집 내용도 유지됩니다.
  • 세션 중에 호스트의 LYNX SHARE가 닫히면 다음에 시작할 때 세션 재개를 제안하고, 게스트는 자동으로 다시 연결됩니다.
  • 세션 도중 게스트의 LYNX SHARE가 닫히면, 다음에 시작할 때 다시 들어갈지 묻습니다. 다시 들어가기을 고르면 같은 사람으로, 맡은 파트와 바꿔 둔 내용을 그대로 갖고 돌아옵니다. 12시간 동안 가능합니다.
  • 0.1.26부터 Linux 버전도 라이브 세션을 호스트할 수 있습니다.
  • 라이브 세션에서 실행 취소와 다시 실행은 내 편집만 되돌립니다.
  • 초대 코드가 있는 사람은 누구나 참가를 요청할 수 있지만, 호스트가 입장시킨 뒤에야 들어옵니다.
