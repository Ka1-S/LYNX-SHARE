Pocket SuperSaw는 최대 8보이스의 버추얼 아날로그 신디사이저입니다. 각 보이스는 서브 옥타브 소우가 있는 1개에서 12개의 디튠된 소우파 묶음이거나, 하드 싱크처럼 스윕되는 펄스 열인 SuperSync 오실레이터입니다. FL Studio Mobile 프로젝트(.flm)가 SuperSaw 모듈을 불러올 때 쓰는 엔진이며, 플러그인 선택기에도 Pocket SuperSaw로 있습니다. 새 채널은 FL Studio Mobile의 기본값에서 시작합니다. 페이지는 FL Studio Mobile 고유의 패널이 아니라 파라미터마다 노브가 하나씩 있는 단순한 목록(모두 59개)입니다.

Osc re-trig phases, Osc phases offsetre-trig가 켜져 있으면 모든 노트가 소우를 같은 위상에서 시작하므로 비팅이 노트마다 같습니다. 꺼짐: 노트마다 무작위 위상에서 시작합니다.
SuperSync mode, Osc sync, Osc sync pulse width, Osc sync attack / decay / sustain / release, Osc sync EG amount, Osc sync kbd dirSuperSync 오실레이터와 싱크 양을 스윕하는 전용 엔벨로프입니다.
Filter cutoff, Filter resonance, Filter kbd, Filter vel최대 20 kHz의 4폴 래더 로우패스 필터이며 키보드 트래킹과 벨로시티 트래킹이 있습니다.
Filter EG attack / decay / sustain / release, Filter EG amount필터 엔벨로프입니다. 양은 양극성이며 -100 %에서 +100 %입니다.

Arp rate, Arp range, Arp mode아르페지에이터입니다. Off, Up, Down, Up-down, Up-down (ends twice), Random이 있으며 최대 3옥타브까지 확장됩니다.
Monophonic mode, Number of voices, Slide held mode, Slide time, Slide time static보이스 하나 또는 최대 8개로 연주하는 방식과 노트가 글라이드하는 방식입니다.
Transpose, Pitch bend range-12에서 +12 반음으로 트랜스포즈합니다. 피치 휠은 1에서 12 반음만큼 벤드합니다.
Distortion, Output trimtanh 디스토션과 -18에서 0 dB의 출력 트림입니다.
Delay time, Delay feedback, Delay mix, Delay filter1/4 beat에서 1 beat까지의 템포 싱크 스테레오 딜레이이며, 루프에 로우패스 또는 하이패스 필터가 있습니다.
Mod wheel amount, Mod wheel dest모드 휠이 움직이는 대상입니다. Cutoff, Resonance, Sync, Pulse width, Detune, Level, Pan, LFO amount, LFO rate입니다.

Tips

  • 모든 노브를 오토메이션할 수 있습니다. 소우는 대역 제한되어 있어 높은 노트에서도 앨리어싱이 생기지 않습니다.
  • 시작 위상과 Random LFO는 각 인스턴스가 가진 생성기에서 나오므로, 렌더가 FL Studio Mobile의 렌더와 샘플 단위로 일치하는 일은 없습니다. 에너지와 스펙트럼은 일치합니다.
  • 채널의 피치 노브, 파인 튠, Mono와 Porta, 피아노 롤의 슬라이드 노트는 FL Studio의 제너레이터와 같은 방식으로 보이스에 작용합니다.
