Slicex는 A와 B 두 덱에 각각 샘플을 불러와 영역으로 자르고, 영역마다 키 하나로 연주합니다. .flp에서 FL Studio의 Slicex 설정을 열고 내보낼 때 다시 기록합니다. 새 인스턴스는 빈 덱으로 시작하며 FL 설치본의 파일은 필요하지 않습니다. 자체 영역이 없는 WAV 파일은 불러올 때 타격을 기준으로 슬라이스됩니다.

CROSSFADE레이어된 영역 사이의 커브입니다. none, linear, balanced curve, unbalanced curve, adding 중에서 고릅니다.

ARTICULATOR아티큘레이터 그룹 8개 중 하나를 고릅니다. 그 FILTER에는 종류(LP, BP, BS, HP), 모드(OFF, x1, x2, x3)와 ENV, CUT, RES 휠이 있습니다.
PAN, VOL, CUT, RES, SPEED, START커브 편집기가 보여 주는 대상입니다.
ENV, LFO, VEL, MOD X, MOD Y, RAND표시할 아티큘레이터의 부분입니다. 엔벨로프, LFO, 또는 벨로시티, 모듈레이션 X, 모듈레이션 Y, 랜덤니스에서 오는 맵입니다.
TEMPO, GLOBALTEMPO는 커브의 시간이 템포를 따르게 합니다. GLOBAL은 LFO 위상이 곡과 함께 돌게 합니다.
ATT, DEC, SUS, REL엔벨로프의 어택, 디케이, 릴리스 시간을 조절하고 서스테인 레벨을 옮깁니다.
SPD, TNS, SKEW, PWLFO 속도, 텐션, 스큐, 펄스 폭입니다.
Deck tool rowLoop, Play / pause, Stop, File, Regions, Select, Zoom 메뉴, 단일 또는 이중 덱 표시, 현재 덱(A 또는 B)입니다.
파일New, Load sample..., 덱의 WAV를 영역과 함께 저장하는 Save sample as...입니다.
영역Add region..., Add marker..., Set loop, Delete, Rename all..., Set all cut groups to..., Freeze all입니다.
건반키를 연주하고 어느 키에 영역이 있는지 보여 줍니다. 메뉴에는 Assign current region to this key와 Select region assigned to this key가 있습니다. 옆의 숫자는 기준 옥타브를 정합니다.
옵션Sample start covers whole length, Link velocity to volume, Loop half of regions, HQ envelopes입니다.

Tips

  • 덱에 샘플을 놓으면 불러옵니다. 마커는 덱의 WAV에 저장되므로 WAV 파일만 자동 슬라이스로 마커를 얻습니다.
  • 영역의 메뉴에는 Delete, Clone as region, Turn into marker, Rename..., Trigger note, Zoom on이 있습니다.
  • 색이 짝수인 노트는 덱 A를, 홀수인 노트는 덱 B를 연주합니다. 색 14와 15는 거꾸로 연주됩니다.
  • FL의 Snap 메뉴와 View 메뉴는 아직 없고, File 메뉴와 Regions 메뉴에는 위에 나열한 항목만 있습니다.
