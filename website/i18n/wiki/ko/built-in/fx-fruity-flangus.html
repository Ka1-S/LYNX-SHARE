Fruity Flangus는 멀티 보이스 모듈레이션 딜레이입니다. 양쪽에 Order 설정만큼의 딜레이 보이스가 생기고, 각 보이스는 자기 LFO로 스윕되며, 보이스들은 드라이 신호와 섞입니다. 가져온 .flp 프로젝트에서 FL Studio 플러그인의 설정을 불러옵니다.

Controls

ControlWhat it does
보이스차수이며, 1에서 9까지입니다. 한쪽당 보이스 수입니다.
깊이LFO가 보이스의 딜레이를 얼마나 크게 스윕하는지 정합니다.
속도LFO의 속도입니다.
Del보이스의 기본 딜레이입니다.
확산스프레드입니다. 보이스 LFO의 시작 위상이 서로 얼마나 어긋나는지 정합니다.
크로스양방향입니다. 각 보이스를 반대쪽 채널로 얼마나 보낼지 정합니다.
드라이양방향입니다. 처리되지 않은 신호의 레벨입니다.
웻양방향입니다. 보이스의 레벨입니다.

Tips

  • Order, Depth, Speed, Delay, Spread, Cross를 바꾸면 보이스가 다시 설정됩니다. 새 보이스는 LFO 위상 0에서 시작합니다.
