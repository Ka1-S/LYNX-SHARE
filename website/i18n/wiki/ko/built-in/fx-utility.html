Utility는 레벨과 채널 라우팅을 다루는 작은 도구입니다. 인서트에 추가해 게인을 바꾸거나, 밸런스를 옮기거나, 채널을 바꾸고 섞을 수 있습니다.

Controls

ControlWhat it does
게인출력 게인입니다.
밸런스왼쪽과 오른쪽의 밸런스입니다.
L -> L왼쪽 입력이 왼쪽 출력으로 갑니다.
R -> L오른쪽 입력이 왼쪽 출력으로 갑니다.
L -> R왼쪽 입력이 오른쪽 출력으로 갑니다.
R -> R오른쪽 입력이 오른쪽 출력으로 갑니다.

Tips

  • L -> R과 R -> L을 높이고 나머지를 낮추면 채널이 서로 바뀝니다.
