Patcher로는 믹서 슬롯 하나 안에서 이펙트, 악기, VST3나 CLAP 플러그인을 케이블로 연결할 수 있습니다. 그래프에는 입력 노드와 출력 노드가 하나씩 있습니다. Patcher가 들어 있는 FL Studio 프로젝트는 같은 그래프로 열립니다.

Controls

ControlWhat it does
Map그래프 보기입니다. 플러그인이 노드이고, 와이어가 오디오, 노트, 컨트롤 값을 전달합니다.
Surface직접 만든 노브, 슬라이더, 버튼, 체크 박스, XY 패드를 놓는 페이지입니다.
편집Surface 컨트롤을 옮기거나 이름을 바꾸거나 삭제할 수 있게 합니다.
+Surface에 컨트롤을 추가합니다.
플러그인 추가Map에서 오른쪽 클릭해 플러그인을 추가합니다.
창에 맞추기전체 그래프가 보이도록 보기를 맞춥니다.

Tips

  • 출력 핀에서 입력 핀으로 드래그하면 두 노드가 연결됩니다.
  • 노드를 더블 클릭하면 에디터가 열립니다.
