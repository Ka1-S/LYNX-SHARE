Emphasizer는 메인 노브가 하나인 룩어헤드 리미터입니다. 입력 게인이 피크 검출기로 들어가고, 게인 리덕션은 2 ms 지연된 신호에 적용되며, 결과는 클리핑되어 출력 게인으로 갑니다. 가져온 .flp 프로젝트에서 FL Studio Emphasizer의 설정을 불러오고, 2 ms 룩어헤드를 딜레이 보정을 위해 보고합니다.

Controls

ControlWhat it does
입력 게인리미터 앞의 게인이며, 0 dB에서 +24 dB까지입니다.
엠퍼시스양이며, 0에서 100퍼센트까지입니다. 피크 검출기가 보는 레벨을 조정합니다.
출력출력 레벨이며, 최대 0 dB입니다.
소프트 클리핑리미터 뒤 풀스케일의 하드 클립을 그보다 낮은 곳에서 시작하는 소프트 클립으로 바꿉니다.
레벨 매칭출력을 입력 게인으로 나누므로, Input gain을 올려도 레벨이 올라가지 않습니다.
바이패스딱 끊어 전환하는 대신 지연된 드라이 신호로 크로스페이드합니다.

Tips

  • Level matching을 켜면 Input gain을 올려 리미터를 더 세게 걸어도 출력이 그만큼 커지지 않습니다.
  • 오른쪽의 미터 스트립에 레벨이 표시됩니다.
