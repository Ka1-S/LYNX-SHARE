드라이버와 출력

  1. 옵션 › 오디오 설정...를 여세요.
  2. 드라이버를 고르세요. Windows에서는 LYNX ASIO(내장) 드라이버가 어떤 장치와도 작동하며 따로 드라이버가 필요 없습니다. 오디오 인터페이스 전용 ASIO 드라이버, FL Studio ASIO, Windows 오디오(공유) 또는 Windows 오디오(독점, 최저 레이턴시)도 있습니다. Mac에서는 Core Audio, Linux에서는 PipeWire 또는 ALSA입니다.
  3. 출력 장치는 LYNX 소리를 듣는 곳입니다. System default는 컴퓨터가 쓰는 출력을 따라갑니다.
  4. 입력 장치 항목은 녹음할 입력(마이크, 기타 입력)입니다. 샘플 레이트 값은 보통 44100 또는 48000 Hz입니다.

버퍼 크기

  1. 버퍼 크기: 버퍼가 작으면 건반을 칠 때 반응이 빠르고, 크면 CPU에 더 여유가 생깁니다.
  2. 지직거리거나 소리가 끊기나요? 값을 올리세요. 연주할 때 소리가 늦나요? 값을 내리세요.

소리 테스트

  1. 테스트 사운드 재생는 선택한 출력으로 짧은 소리를 재생합니다.
  2. 어디서든 도움말 › 오디오 출력 테스트...으로 같은 일을 할 수 있습니다.

녹음한 테이크가 늦나요?

  1. 오디오 인터페이스는 소리를 받아들이고 다시 내보내는 데 잠깐 시간이 걸리므로, 테이크가 조금 늦게 놓일 수 있습니다.
  2. 같은 Audio 페이지의 녹음 레이턴시 보정 아래에서 케이블로 출력을 입력에 연결하고(또는 인터페이스의 루프백을 쓰고) 왕복 지연 측정 버튼을 클릭하세요.
  3. LYNX가 클릭 소리를 몇 번 재생해 얼마나 늦게 돌아오는지 재고, 그다음부터 녹음한 테이크를 박자에 맞게 놓습니다.

오디오 설정과 문제 해결도 참고하세요.
