세션 시작하기(호스트)

  1. 공유할 프로젝트를 엽니다.
  2. 파일 › 온라인 세션 › 라이브 세션 시작...을 선택합니다.
  3. 이름을 입력합니다. 게스트 편집 범위에서 자신의 채널, 패턴, 인서트, 행만(권장)를 그대로 두거나 전체을 고르세요.
  4. 시작를 클릭합니다.

친구 초대하기

  1. LYNX SHARE가 세션의 초대 코드를 보여 줍니다. 복사를 클릭하세요.
  2. 채팅이나 이메일로 최대 3명에게 코드를 보냅니다.
  3. 나중에 파일 › 온라인 세션 › 초대 코드 보기...로 다시 볼 수 있습니다.

참여하기(게스트)

  1. 파일 › 온라인 세션 › 라이브 세션 참가...을 선택합니다.
  2. 이름을 입력하고 초대 코드를 붙여넣은 다음 참가을 클릭합니다.
  3. 호스트가 입장을 허용할 때까지 기다립니다. 그러면 호스트의 프로젝트가 열립니다.

입장 허용하기(호스트)

누군가 참여를 요청하면 입장 허락 또는 나중에를 클릭하세요.

함께 작업하기

  • 누가 바꾸든 모든 변경이 모두에게 전달됩니다. 게스트마다 색과 자기만의 트랙, 믹서 인서트가 주어집니다.
  • 파일 › 온라인 세션 › 세션 채팅...으로 채팅을 엽니다.
  • 호스트가 파일 › 온라인 세션 › 라이브 세션 종료을 선택하면 끝납니다. 프로젝트는 호스트의 컴퓨터에 남고, 게스트는 시작 창에서 안내한 대로 자기 파트나 전체 사본을 갖습니다.

알아 두기

  • 나를 포함해 최대 4명이 참여합니다.
  • 모든 내용은 초대 코드로 종단간 암호화됩니다. LYNX SHARE 릴레이는 전달만 합니다.
  • 인터넷이 없나요? 파일 › 온라인 세션 › 프로젝트 보내기...가 대신 패키지 파일을 만듭니다. 온라인 세션을 참고하세요.
