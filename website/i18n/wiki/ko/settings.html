설정 창에는 오디오, MIDI, 일반, 테마, 파일, 프로젝트, 정보의 일곱 페이지가 있습니다. 앞의 다섯은 프로그램에 속합니다. 프로젝트와 정보는 열려 있는 프로젝트에 속하며 프로젝트와 함께 저장됩니다. 각 페이지는 옵션 메뉴 맨 위에 자기 항목이 있습니다.

설정 바꾸기

  1. 옵션 메뉴를 열고 일반 설정... 같은 페이지를 고릅니다.
  2. 위쪽의 다른 탭을 클릭하면 다른 페이지로 넘어갑니다.
  3. 설정을 바꿉니다. 바로 적용되지만, 언어와 인터페이스 글꼴은 LYNX SHARE를 다시 시작할 때 적용됩니다.

F10은 MIDI 페이지를, F11은 정보 페이지를 엽니다.

MIDI

옵션 › MIDI 설정...

설정기능
입력 장치장치마다 끄거나, MIDI 채널 하나만 듣게 하거나, 선택한 채널 대신 채널 랙의 고정 채널을 연주하게 할 수 있습니다
장치 목록 새로 고침장치를 다시 찾습니다
마스터 동기화 전송Song Position Pointer가 있는 MIDI 클럭 또는 MIDI Time Code를 출력 장치로 보냅니다. 오프셋(ms)로 늦게 또는 일찍 보냅니다
All notes off 전송초기화할 때와 내보낸 뒤에 장치로 all notes off를 보냅니다
외부 클럭 동기화LYNX SHARE가 고른 입력의 MIDI 클럭(템포, 시작, 계속, 정지, 위치)을 따라갑니다
벨로시티MIDI 장치에서 들어오는 노트용: 연주한 그대로, 소프트, 하드, 고정
퍼포먼스 모드 채널이 채널의 노트가 퍼포먼스 모드에서 플레이리스트 클립을 실행합니다
송 마커 점프이 채널의 노트는 연주되지 않고 곡을 마커로 이동시킵니다
픽업(테이크오버 모드)컨트롤러가 파라미터의 현재 값에 도달한 뒤에야 파라미터를 움직입니다
링크이 프로젝트의 컨트롤러 링크, 그다음 전역 링크이며, 연결 제거와 모두 제거이 있습니다

설정기능

Live 세트의 세션 클립가져온 Live 세트의 세션 클립이 갈 곳: 클립 그리드 또는 어레인지먼트 뒤의 플레이리스트
언어, 인터페이스 글꼴다음에 시작할 때 적용됩니다

노트 이름, 검은 건반영어식, 독일식, 계이름 표기와 샤프 또는 플랫 표기
플러그인 스타일내장 플러그인 창의 모양: 자동, 또는 모든 플러그인에 하나의 스타일
애니메이션, 애니메이션 속도인터페이스 애니메이션, 그리고 재생 헤드와 미터가 움직이는 빈도
GPU로 그리기(Direct2D)그래픽 드라이버가 충돌하거나 화면이 깜박이면 끕니다
시작스플래시 화면, 시작 사운드, 시작할 때마다 백그라운드에서 새 플러그인 찾기
편집타이핑 키보드 피아노, 채널 에디터 열어 두기, 탐색 시간 기억하기, 늘린 패턴 클립 반복하기
최대 실행 취소 단계25~1000
백업백업 사본을 저장하는 주기, 프로젝트당 보관 개수, 백업 폴더 열기
플러그인을 별도 프로세스에서 실행플러그인이 충돌해도 LYNX SHARE는 멈추지 않습니다. 기본값은 꺼짐입니다
누락된 플러그인을 LYNX SHARE 대체 플러그인으로 교체기본값은 켜짐입니다. 프로젝트에는 원래 플러그인이 남아 있습니다
충돌 보고서충돌이나 멈춤 뒤에 묻기(기본값), 항상 보내기, 보내지 않기
자동으로 업데이트 확인시작할 때 업데이트를 확인하며, 지금 확인도 있습니다
