이 페이지에서는 드럼 패턴, 멜로디, 편곡, 믹스, 내보낸 파일까지 전체 과정을 한 번 따라 합니다. 각 부분은 해당 창을 자세히 다루는 페이지로 연결됩니다. 어느 단계에서든 소리가 나지 않으면 오디오 설정을 보세요.

드럼 패턴 만들기

  1. 파일 › 템플릿으로 새로 만들기 › 비어 있음 메뉴를 선택합니다. 프로젝트는 킥, 클랩, 햇, 스네어, 신스 채널 다섯 개로 시작하며 스텝은 없습니다.
  2. 채널 랙이 보이지 않으면 F6 키를 누릅니다.
  3. 킥 행에서 스텝 몇 개를 클릭합니다. 끌면 여러 개가 그려지고, 우클릭하면 지워집니다.
  4. Space 키를 누릅니다. 트랜스포트가 패턴 모드이므로 패턴이 반복 재생됩니다. Space 키를 한 번 더 누르면 멈춥니다.
  5. 클랩, 햇, 스네어 행에도 각자의 스텝을 넣습니다.
  6. F2 키를 눌러 패턴의 이름과 색상을 정합니다.

없는 소리를 추가하려면 마지막 행 아래의 + 채널 추가 상자를 클릭하고 메뉴에서 악기를 고릅니다. 가지고 있는 샘플을 쓰려면 Alt+F8 키로 브라우저를 열고, 오디오 파일을 클릭해 소리를 들어 본 다음 더블 클릭해 새 채널로 추가합니다.

멜로디 쓰기

  1. F4 키를 누릅니다. LYNX SHARE가 다음 빈 패턴으로 이동하고 이름을 묻습니다.
  2. 신스 채널의 이름을 우클릭하고 피아노 롤 항목을 선택합니다.
  3. 연필(P)로 그리드를 클릭해 노트를 추가합니다.
  4. 노트를 끌면 이동하고, 노트의 끝을 끌면 길이가 바뀝니다. 우클릭하면 노트가 삭제됩니다.
  5. 편집하는 동안 Space 키를 눌러 패턴을 들어 봅니다.

Ctrl+T 키를 누르면 타이핑 키보드가 피아노로 바뀌므로, 먼저 Z부터 M까지와 Q부터 P까지의 키로 음을 시험해 볼 수 있습니다. P 같은 글자 단축키를 쓰기 전에 다시 꺼야 합니다.

패턴 배치하기

  1. F5 키를 눌러 플레이리스트를 표시합니다.
  2. 플레이리스트 왼쪽의 피커 패널에서 드럼 패턴을 클릭합니다. 이제 이 패턴이 클립 소스입니다.
  3. 연필(P)로 트랙을 클릭해 패턴을 배치합니다. 더 오른쪽을 다시 클릭하면 한 번 더 배치됩니다. 브러시(B)로 끌면 클립이 끝에서 끝으로 이어 붙어 칠해집니다.
  4. 피커에서 멜로디 패턴을 클릭하고 다른 트랙에 배치합니다.
  5. L 키를 눌러 송 모드로 바꾼 다음 Space 키를 누릅니다. 플레이리스트가 송 위치부터 재생됩니다. 눈금자를 클릭하면 위치가 정해집니다.

믹스하고 이펙트 추가하기

  1. F9 키를 눌러 믹서를 표시합니다. 처음의 채널 다섯 개는 이미 인서트 1~5로 재생되고 있으며, + 채널 추가 메뉴에서 추가한 채널은 빈 인서트를 차지합니다. 채널 랙에서 채널의 라우팅 상자에 있는 숫자가 어느 인서트인지 알려 줍니다.
  2. 채널을 각자의 빈 인서트로 옮기려면 채널 랙에서 채널을 선택하고 Ctrl+L 키를 누릅니다. 각 인서트는 채널의 이름과 색상을 이어받습니다.
  3. 인서트의 페이더를 끌어 레벨을 정합니다.
  4. 인서트를 클릭해 선택합니다. 오른쪽의 이펙트 패널에 슬롯 열 개가 표시됩니다.
  5. 빈 슬롯을 클릭하고 이펙트를 고릅니다. 슬롯의 이름을 클릭하면 이펙트 창이 표시되거나 숨겨집니다. 슬롯의 라이트는 이펙트를 바이패스합니다.

곡 내보내기

  1. 먼저 Ctrl+S 키를 눌러 프로젝트를 저장합니다.
  2. 파일 › 내보내기 › Wave 파일... 메뉴를 선택합니다. 다른 형식은 같은 메뉴에 MP3 파일..., OGG 파일..., FLAC 파일...이 있습니다.
  3. 범위 항목을 송(플레이리스트) 값으로 설정합니다. 다른 선택지는 현재 패턴과 플레이리스트 선택 영역입니다.
  4. 나머지 옵션은 그대로 둡니다.
  5. 내보내기... 버튼을 클릭하고 파일 이름을 정한 다음 렌더링이 끝나기를 기다립니다.

알아 두면 좋은 점

  • 패턴 모드에서는 현재 패턴만 들립니다. 편곡한 뒤에 곡이 조용하다면 트랜스포트가 송 모드인지 확인하세요.
  • 트랜스포트가 송 모드이고 플레이리스트에 클립이 있으면 내보내기 창은 송(플레이리스트) 값으로 시작합니다. 그렇지 않으면 현재 패턴으로 시작합니다.
  • 메트로놈 클릭은 내보내기에 절대 들어가지 않습니다.
  • 내보내기 창 아래쪽에는 곡의 길이(마디), 총 시간, 파일에 필요한 디스크 공간이 표시됩니다.
  • 새 프로젝트에는 기본적으로 마스터 인서트에 리미터가 있습니다. 들리는 소리와 내보내는 소리에 포함됩니다.
  • 실행 취소는 Ctrl+Z입니다. 한 번 더 누르면 그 단계를 다시 실행합니다. Ctrl+Alt+Z는 더 이전으로 돌아갑니다.
