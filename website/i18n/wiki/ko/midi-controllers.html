LYNX SHARE는 모든 MIDI 입력 장치의 노트와 컨트롤러 움직임을 받습니다. 장치는 설정의 MIDI 페이지에서 구성합니다. 옵션 › MIDI 설정... 또는 F10입니다. 하드웨어가 없어도 타이핑 키보드와 터치 키보드로 노트를 연주할 수 있습니다.

키보드 연결하기

  1. 키보드를 꽂고 옵션 › MIDI 설정...(F10)를 엽니다.
  2. 입력 장치에서 키보드를 찾아 체크합니다. 목록에 없으면 장치 목록 새로 고침를 클릭합니다.
  3. 두 상자는 모든 MIDI 채널과 선택한 채널 연주로 둡니다.
  4. 설정을 닫고 채널 랙에서 채널을 선택합니다.
  5. 연주합니다. 선택한 채널에서 소리가 납니다.

컨트롤러 프로필

컨트롤러 프로필은 연결할 것 없이 장치의 트랜스포트 버튼, 페이더, 노브, 패드, 표시등, 디스플레이를 설정합니다.

  1. 옵션 › MIDI 설정...(F10)를 열고 입력 장치 아래에서 장치를 체크합니다.
  2. 컨트롤러 유형을 자동 감지로 그대로 둡니다. 괄호 안의 이름은 장치의 포트 이름에서 찾은 프로필입니다.
  3. 일반 컨트롤러로 나오면 목록에서 프로필을 직접 고릅니다.
  4. 상자 옆의 줄을 읽어 보세요. Feedback to는 표시등, 모터 페이더, 디스플레이 텍스트를 받는 출력 포트의 이름입니다.

위치 값을 보내는 노브와 페이더는 소프트 테이크오버를 씁니다. 컨트롤의 값에 도달한 뒤에야 그 컨트롤을 움직입니다. 직접 연결한 컨트롤은 연결이 그대로 유지됩니다. 컨트롤러 프로필 폴더는 직접 만든 프로필(*.lynxctl)용 폴더를 열고, 장치 목록 새로 고침는 프로필을 다시 읽습니다.

MPE 컨트롤러

MPE는 첫 단계에 있습니다. MPE 컨트롤러는 노트마다 자기 피치 벤드, 음색(CC 74), 압력으로 연주합니다.

  1. MIDI 페이지에서 장치의 모든 MIDI 채널 상자를 열고 MPE 컨트롤러를 고릅니다.
  2. 옆에 나타나는 상자에서 멤버 채널을 채널 2부터 Channels 2-16까지 중에서 고릅니다.
  3. 연주합니다. 녹음하려면 녹음을 참고하세요.
  • 녹음된 노트는 각각 값을 하나씩만 유지합니다. 벤드는 미세 피치로, 음색은 Mod X로, 가장 강한 압력은 Mod Y로 남습니다. 곡선은 아닙니다.
  • 내장 악기 중에서는 Sampler와 내장 신스가 이 값을 따릅니다.
  • 서드파티 플러그인은 플러그인 창의 래퍼 설정에서 MIDI 아래의 MPE가 켜져 있을 때 MPE를 받습니다. 그러면 노트마다 자기 MIDI 채널, 2번부터 16번으로 나갑니다.
  • 실제 MPE 컨트롤러로는 아직 시험해 보지 않았습니다.

MIDI Map Mode와 Key Map Mode

클립 실행 워크플로에서는 Ableton Live처럼 클립, 씬, 버튼을 매핑할 수 있습니다. 둘 다, 그리드, 송 스위치 옆의 MIDI와 키 버튼이 모드를 켜며, Ctrl+M과 Ctrl+K도 같습니다.

  1. MIDI Map Mode는 Ctrl+M, Key Map Mode는 Ctrl+K를 누릅니다. 매핑할 수 있는 모든 요소가 색으로 표시되며, MIDI는 파랑, 키는 주황입니다.
  2. 요소를 클릭합니다. 클립 슬롯, 씬, 트랙의 정지 버튼, 모든 클립 정지, 재생, 정지, 녹음, 세션 녹음, 메트로놈, 또는 Session 믹서나 Device View의 노브입니다.
  3. MIDI 장치의 컨트롤을 움직이거나 키를 누릅니다. Key Map Mode에서는 컴퓨터 키를 누릅니다. 요소에 할당이 표시됩니다. 예를 들어 1/19(채널과 컨트롤러)입니다.
  4. 브라우저 자리에 매핑 목록이 나옵니다. Channel, Note/Control 또는 Key, Path, Name, Min, Max입니다. Min이나 Max를 드래그하거나, 더블 클릭해 값을 입력하세요. 행을 우클릭하면 범위 반전와 Delete가 있습니다.
  5. 같은 키를 다시 누르면 모드가 끝납니다.

타이핑 키보드

Ctrl+T 또는 옵션 › 타이핑 키보드 피아노로 컴퓨터 키보드를 피아노로 바꿉니다. Z부터 M까지의 줄과 Q부터 P까지의 줄이 선택한 채널을 연주합니다.

  • 켜져 있는 동안은 글자 키와 숫자 키가 노트입니다. 피아노 롤과 플레이리스트의 글자 한 개짜리 도구 키는 꺼져 있을 때만 작동합니다.
  • 항상 피아노 롤의 벨로시티로 연주합니다. MIDI 페이지의 벨로시티 설정은 MIDI 장치용입니다.
  • 같은 스위치가 옵션 › 일반 설정...에도 있습니다.

터치 키보드

보기 › 터치 키보드(Alt+F7)는 마우스나 터치스크린으로 연주하는 피아노를 엽니다. 채널 랙에서 선택한 채널을 연주하며, 그 이름이 오른쪽에 표시됩니다.

설정기능
-와 +한 옥타브 내리기/올리기
건반 크기작은 건반, 중간 건반, 큰 건반
벨로시티: 터치 위치건반 위쪽 근처를 누르면 약하게, 아래쪽 근처를 누르면 세게 연주됩니다
벨로시티: 고정모든 노트를 슬라이더로 정한 벨로시티로 연주합니다
노트 이름건반에 이름을 표시합니다

MIDI 동기화

MIDI 페이지의 출력 장치는 트랜스포트를 하드웨어와 다른 소프트웨어로 보냅니다. 장치의 마스터 동기화 전송를 체크하고 MIDI 클럭(Start, Continue, Stop, Song Position Pointer 포함) 또는 MIDI Time Code를 고릅니다. 오프셋(ms)는 양수면 동기화를 늦게, 음수면 일찍 보냅니다. All notes off 전송는 초기화할 때와 내보낸 뒤에 장치로 그 메시지를 보냅니다.

외부 클럭 동기화는 반대로 동작합니다. LYNX SHARE가 고른 입력의 MIDI 클럭을 템포, Start, Continue, Stop, Song Position Pointer까지 따라갑니다. 외부 동기화 오프셋(밀리초)는 양수면 LYNX SHARE가 늦게, 음수면 일찍 재생됩니다. 상태에 클럭이 동작 중인지 표시됩니다.

알아 두기

  • 외부 클럭 동기화의 입력을 고르면 그 장치가 입력 장치에서 켜집니다.
  • 연결된 MIDI 컨트롤러로 템포를 움직여도 오디오 클립의 길이는 바뀌지 않습니다. 최종 템포는 직접 입력하거나 설정하세요.
  • 연주를 녹음하려면 녹음을 참고하세요. 들어오는 노트를 피아노 롤에서 스케일에 맞춰 스냅할 수 있습니다.
  • 플러그인으로 보내는 MIDI CC, 채널 애프터터치, 피치 벤드는 MIDI 컨트롤러 오토메이션(CC, 애프터터치, 피치 벤드)로 오토메이션할 수 있습니다.
  • 페달로 붙잡은 노트는 페달을 놓는 순간까지 녹음됩니다.
  • 오토메이션 클립은 컨트롤러로 컨트롤을 움직이는 동안에는 컨트롤을 되찾지 않습니다. 다음에 재생이 시작되면 컨트롤이 다시 오토메이션을 따릅니다.
  • 리모트 컨트롤 설정에서 만든 노트 연결은 .flp 내보내기에 기록되지 않습니다.
  • Ctrl+M과 Ctrl+K는 클립 실행 워크플로에서만 맵 모드를 시작합니다. Map Mode에는 아직 매크로 매핑과 노트 범위가 없습니다.
