LYNX SHARE는 패턴 워크플로로 시작합니다. 채널 랙, 패턴, 플레이리스트로 이루어진 구성입니다. 클립 실행 워크플로는 선택 사항이며, 플레이리스트 옆에 장면이 있는 클립 그리드를 추가합니다. LYNX SHARE는 .als 세트를 읽고 씁니다. Ableton과는 제휴 관계가 없습니다.

Live 세트 열기

  1. 파일 › 열기... (Ctrl+O) 메뉴를 선택하고 .als 파일을 고릅니다. Live 11과 Live 12에서 저장한 세트를 읽을 수 있습니다.
  2. 클립 그리드로 작업하려면 보기 › 레이아웃 스타일 › 클립 실행 워크플로 메뉴를 선택합니다. 세트의 세션 클립과 장면이 여기에 들어옵니다.
  3. 플레이리스트 제목 표시줄의 Grid / Both / Song 스위치로 그리드, 플레이리스트, 또는 둘 다 표시합니다.
  4. 파일 › 저장 메뉴를 선택합니다. .lynx 파일을 어디에 쓸지 묻습니다. .als 파일은 바뀌지 않습니다.

보기 › 레이아웃 스타일 › 패턴 워크플로 (기본) 메뉴를 선택하면 되돌아갑니다. 같은 선택이 옵션 › 일반 설정... 메뉴에도 있습니다. 어느 레이아웃에서든 패턴과 채널 랙을 계속 쓸 수 있습니다.

클립 그리드

슬롯 하나에는 패턴 클립이나 오디오 클립이 들어갑니다.

  • 트랙은 한 번에 클립 하나만 재생합니다. 실행한 클립이 재생 중인 클립을 대체합니다.
  • 실행하면 실행 퀀타이즈의 다음 스텝까지 기다립니다.
  • 레가토는 새 클립을 대체된 클립이 도달해 있던 위치에서 시작합니다. 루프는 클립마다 지정합니다.
  • 장면은 삽입, 삭제, 이름 변경을 할 수 있습니다.
  • 클립을 실행한 트랙은 플레이리스트로 돌아가기 항목을 누를 때까지 플레이리스트에서 소리가 나지 않습니다. 옵션을 켜면 트랜스포트가 멈출 때 트랙을 돌려줍니다.

팔로 액션은 클립이 정해진 마디 수나 횟수만큼 재생된 뒤에 실행됩니다. 액션은 액션 없음, 정지, 다시 재생, 이전, 다음, 처음, 마지막, 아무거나, 기타입니다. 스위치 하나로 그리드 전체의 팔로 액션을 켜고 끕니다.

.als에서 가져오는 것

  • MIDI, 오디오, 그룹, 리턴 트랙, 템포, 박자, 로케이터, 루프, 믹서 설정(볼륨, 팬, 뮤트, 솔로, 센드)과 그 오토메이션.
  • 같은 플러그인이 설치되어 있으면 VST2와 VST3 플러그인과 그 상태. 서드파티 플러그인을 참고하세요.
  • 세션 클립과 장면은 실행 모드, 퀀타이즈, 레가토, 루프, 팔로 액션, 정지 버튼과 함께 클립 그리드로 들어옵니다. 장면마다 한 섹션씩 플레이리스트에 배치하려면 옵션 › 일반 설정... 메뉴의 Live 세트의 세션 클립 옵션을 바꿉니다.
  • 워프 마커.

.als로 내보내기

  1. 파일 › 내보내기 › Ableton Live 세트 (.als)... 메뉴를 선택합니다.
  2. 저장 대상 항목에서 Live 12 또는 Live 11 (Live 12에서도 열림) 옵션을 고릅니다.
  3. 샘플 항목에서 샘플을 세트의 프로젝트 폴더로 복사할지, 현재 위치를 그대로 참조할지 고릅니다.
  4. 폴더를 선택합니다. 세트는 <name> Project/<name>.als로 저장됩니다.

알아 두면 좋은 점

  • Live 자체 디바이스 중 많은 수는 설정과 오토메이션과 함께 LYNX SHARE 자체의 것으로 들어옵니다. EQ Eight, EQ Three, Channel EQ, Compressor, Glue Compressor, Multiband Dynamics, Limiter, Gate, Utility, Reverb, Delay, Echo, Auto Filter, Saturator, Overdrive, Chorus-Ensemble, Redux, Auto Pan, Drum Buss, Simpler, Drift, Operator(FM 제외)입니다. 나머지는 빠지고 가져오기 보고서에 나열됩니다.
  • Instrument Rack과 Audio Effect Rack은 체인, 존, 매크로와 함께 들어오고, Drum Rack은 LYNX SHARE의 Drum Rack이 됩니다. Live의 MIDI Effect Rack은 아직 변환되지 않으며 가져오기 보고서에 나열됩니다.
  • 제외된 항목은 가져오기 보고서에 나열됩니다.
  • Live는 내보낸 세트에서 겹치는 오디오 클립을 잘라 냅니다.
  • Live 세트의 워프 마커는 가져올 때 유지되고, 내보낼 때 다시 기록됩니다.
