보기 › 레이아웃 스타일에는 패턴 워크플로 (기본), 클립 실행 워크플로, 간단한 워크플로 세 항목이 있습니다. 같은 선택이 옵션 › 일반 설정의 워크플로 항목에도 있습니다. 선택한 내용은 프로그램을 닫아도 유지됩니다.

패턴 워크플로는 채널 랙, 패턴, 플레이리스트로 작업하는 방식입니다. 클립 실행 워크플로는 플레이리스트 옆에 씬이 있는 클립 그리드를 더합니다. 패턴과 채널 랙도 그대로 쓸 수 있습니다.

그리드에서 클립 실행하기

  1. 보기 › 레이아웃 스타일 › 클립 실행 워크플로를 선택합니다. 플레이리스트 옆에 클립 그리드가 나타납니다.
  2. 빈 슬롯을 우클릭하고 여기에 패턴 넣기를 선택한 뒤 패턴을 고릅니다. 빈 슬롯을 더블 클릭하면 현재 패턴이 들어갑니다.
  3. 클립 왼쪽의 삼각형을 클릭하면 실행됩니다. 트랜스포트가 멈춰 있으면 재생이 시작됩니다.
  4. 장면 열에서 씬의 삼각형을 클릭하면 그 행의 모든 클립이 실행됩니다.
  5. 모든 클립 정지를 클릭하면 모두 멈춥니다.
  6. 플레이리스트로 돌아가기를 클릭하면 트랙이 다시 플레이리스트 클립을 재생합니다.

화면에서 달라지는 점

  • 클립 그리드가 플레이리스트 옆에 표시됩니다. 플레이리스트 트랙이 열, 씬이 행입니다.
  • 플레이리스트 제목 표시줄에 둘 다, 그리드, 송 스위치가 생깁니다. 그리드는 그리드만, 송은 플레이리스트만 보여 줍니다.
  • 처음에는 채널 랙이 숨겨져 있습니다. F6이나 툴바 버튼으로 표시합니다.
  • 플레이리스트의 오토메이션 레인이 켜집니다.
  • 창 레이아웃은 스타일마다 따로 저장되므로, 각 스타일은 마지막으로 두었던 모습으로 돌아옵니다.
  • 그리드 아래의 믹서 버튼은 Ableton Live처럼 Session 믹서를 표시하거나 숨깁니다. 입력/출력(오디오 입력, 모니터, 오디오 출력), 센드, 트랙 딜레이, 활성화 버튼, 솔로, 암 버튼, 미터가 있는 각 트랙의 볼륨, 그리고 메인 스트립이 있습니다.
  • 그리드 아래의 그루브는 Groove Pool을 표시합니다. 노트에 그루브 적용는 그루브를 MIDI 클립의 노트에 기록합니다.
  • MIDI와 키 버튼은 MIDI Map Mode와 Key Map Mode를 시작합니다. MIDI 컨트롤러를 참고하세요.

그리드

실행한 클립은 바로 시작하지 않습니다. 다음 실행 퀀타이즈 지점을 기다리며, 그때까지 삼각형이 깜박입니다. 그리드 아래쪽 상자에서 전역 실행 퀀타이즈를 정하며, 전역로 설정된 모든 클립이 이 값을 씁니다. 정지도 같은 방식으로 기다립니다.

클립을 우클릭하면 클립의 설정이 나옵니다.

빈 슬롯을 우클릭하면 정지 버튼 (씬이 여기서 이 트랙을 정지)가 나옵니다. 빈 슬롯 왼쪽의 사각형을 클릭하면 그 트랙이 멈춥니다. 씬을 우클릭하면 씬 삽입, 아래에 씬 추가, 씬 삭제, 씬 이름 변경...과 씬의 템포가 나옵니다.

클립은 메뉴에서 잘라내기, 복사, 붙여넣기, 복제(Ctrl+D)할 수 있고, 슬롯 사이에서 또는 플레이리스트와 사이에서 드래그할 수 있습니다. 브라우저에서 드래그한 패턴이나 샘플, 또는 밖에서 놓은 오디오 파일은 놓은 슬롯을 채웁니다. 씬의 메뉴에는 복제와 장면 캡처 후 삽입도 있는데, 지금 재생 중인 클립을 새 씬에 넣습니다. 보기 › 장면 템포와 박자표는 씬마다 템포와 박자표를 표시합니다.

슬롯 메뉴에는 그리드 전체에 적용되는 옵션도 두 개 있습니다. 트랜스포트가 멈추면 트랙을 플레이리스트로 되돌리기와 그리드 전체의 팔로우 액션입니다.

Ableton Live 세트

Live 세트를 열면 세션 클립과 씬이 실행 설정과 함께 클립 그리드에 들어갑니다. 파일 › 내보내기 › Ableton Live 세트 (.als)는 그리드를 세션 클립으로 다시 씁니다. 옵션 › 일반 설정의 Live 세트의 세션 클립에서 플레이리스트, 어레인지먼트 뒤를 고르면 대신 플레이리스트에 놓습니다.

간단한 워크플로

보기 › 레이아웃 스타일 › 간단한 워크플로는 첫 곡을 위한, 트랙과 타임라인이 있는 하나의 창입니다. 보기 › 트랙 독은 타임라인 아래에 선택한 트랙용 도크를 표시하며, 이펙트, 악기, 건반, 에디터 탭이 있습니다. 이 워크플로에서는 도움말 메뉴에 첫 곡 투어와 시작 화면...이 있으며, 후자는 7단계 첫 곡, 데모 곡, 빈 프로젝트를 제공합니다. 간단한 레이아웃을 참고하세요.

보기 메뉴의 가사와 메모와 레퍼런스 매칭..., 믹서 인서트 메뉴의 클린 보이스는 모든 레이아웃에 있습니다. 간단한 워크플로에서는 클린 보이스가 트랙 메뉴에도 있습니다.

되돌아가기

보기 › 레이아웃 스타일 › 패턴 워크플로 (기본)를 선택합니다. 패턴 워크플로에서 쓰던 창 레이아웃이 돌아오고, 오토메이션 레인도 이전 설정으로 돌아갑니다. 그리드의 클립은 프로젝트에 남아 있습니다.

알아 두기

  • 클립을 실행한 트랙은 플레이리스트로 돌아가기를 누를 때까지 플레이리스트에서 소리가 나지 않습니다. 트랜스포트가 멈추면 트랙을 플레이리스트로 되돌리기 옵션을 켜면 정지할 때마다 자동으로 돌려놓습니다.
  • 그리드의 새 키(B, Q, Ctrl+M, Ctrl+K 등)는 클립 실행 워크플로에서만 이렇게 동작합니다. 패턴 워크플로에서는 FL Studio의 의미를 그대로 유지합니다.
  • 6/8박자의 씬은 한 마디를 세 박으로 재생합니다. 박자 계산이 4분음표를 기준으로 하기 때문입니다.
  • 팔로우 액션은 클립에만 있고 씬에는 없습니다.
  • 클립 실행 워크플로에서 직접 켠 오토메이션 레인은 되돌아갈 때 유지되지 않습니다.
  • 패턴 워크플로를 선택하면 그리드의 내용은 전혀 불러오지 않습니다.
