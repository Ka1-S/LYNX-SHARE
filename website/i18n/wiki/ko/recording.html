트랜스포트의 녹음 버튼이나 R 키로 녹음을 켭니다. 처음에는 창이 떠서 무엇을 녹음할지 묻습니다. 오디오는 플레이리스트에 오디오 클립으로 들어갑니다. 노트는 현재 패턴에 들어갑니다. 움직인 컨트롤은 오토메이션이 됩니다.

마이크나 악기 녹음하기

  1. 옵션 › 오디오 설정...를 열고 입력 장치를 고릅니다.
  2. 믹서(F9)를 열고 빈 인서트를 선택합니다.
  3. 인서트의 이펙트 슬롯 위에 있는 입력 상자를 클릭하고 입력을 고릅니다. 스테레오 쌍이 먼저 나오고, 단일 채널에는 (모노)가 붙습니다.
  4. 입력 상자 옆의 녹음 대기 버튼을 클릭합니다.
  5. R을 누르고 오디오, 플레이리스트에 오디오 클립으로을 고릅니다.
  6. 재생이 저절로 시작되지 않았다면 재생을 누르고 연주합니다.
  7. 정지를 누릅니다. 테이크는 플레이리스트의 오디오 클립이 됩니다.

Shift+R은 4~6단계를 키 하나로 처리합니다. 선택한 인서트를 녹음 대기로 만들고, 오디오만 녹음하며, 재생을 시작합니다. 다시 누르면 정지합니다.

노트 녹음하기

노트는 MIDI 키보드, 타이핑 키보드(Ctrl+T), 터치 키보드에서 들어와 현재 패턴의 선택한 채널로 갑니다. MIDI 컨트롤러를 참고하세요.

  • 녹음 노트 섞기(Ctrl+B)는 오버더빙과 교체 중 하나를 정합니다. 켜면 새 노트가 패턴의 노트에 더해집니다. 끄면 녹음한 채널의 기존 노트가 지워집니다.
  • 녹음한 노트를 전역 스냅에 퀀타이즈은 녹음 옵션에 있습니다.
  • 스텝 입력(Ctrl+E)는 정지한 상태에서 작동합니다. 연주하는 노트가 스냅 한 칸씩 이어서 패턴에 들어갑니다.
  • MIDI 캡처(Ctrl+Shift+Alt+R)는 녹음이 꺼져 있었더라도 방금 연주한 노트를 패턴에 넣어 줍니다.

녹음하는 동안 움직인 컨트롤은 송 모드에서는 오토메이션 클립으로, 패턴 모드에서는 패턴 이벤트로 기록됩니다. 오토메이션을 참고하세요.

루프 녹음과 테이크

루프 녹음를 켜면 녹음이 송 모드에서는 루프 구간을, 패턴 모드에서는 패턴을 반복합니다. 끄면 녹음은 그대로 쭉 진행합니다.

오디오 루프 녹음에서 한 번 돌 때마다 녹음된 것이 다음 빈 플레이리스트 트랙에 놓이고, 그 트랙들은 하나의 그룹이 됩니다. 정지한 뒤 무엇이 재생될지는 녹음 노트 섞기가 정합니다. 끄면 모든 패스가 뮤트되고, 켜면 모두 재생됩니다. 그룹의 트랙을 우클릭하고 이 테이크로 컴프 만들기를 선택하면 패스들로 테이크 하나를 만듭니다. 녹음 옵션의 루프 녹음 후 마지막 패스만 재생는 트랙 하나로 되돌립니다.

녹음 파일이 저장되는 곳

  • 저장된 프로젝트는 테이크를 프로젝트 파일 옆의 Audio/Recorded에 보관합니다.
  • 저장하지 않은 프로젝트는 음악 폴더의 LYNX/Recordings에 녹음합니다.
  • 테이크는 오디오 장치의 샘플 레이트로 된 24비트 또는 32비트 부동소수점 WAV 파일입니다. 형식과 테이크 이름은 옵션 › 오디오 설정...의 녹음에서 정합니다.
  • 녹음 폴더 열기는 녹음 버튼의 우클릭 메뉴에 있습니다. 파일 › 사용하지 않는 녹음 삭제 후 저장...는 프로젝트가 더 이상 쓰지 않는 테이크를 제거합니다.

알아 두기

  • 입력이 없는 녹음 대기 인서트는 아무것도 녹음하지 않습니다. LYNX SHARE가 알려 주고 입력 상자를 가리킵니다.
  • 드라이브의 여유 공간이 30초 미만이면 녹음이 시작되지 않고, 10분 미만이면 경고합니다.
  • 녹음 대기 중인 것이 없을 때 옵션 › 입력 오디오 녹음는 처음 두 입력 채널을 새 인서트에 녹음합니다.
  • macOS에서는 처음 녹음할 때 시스템이 마이크 접근 권한을 묻습니다.
  • 녹음 중에 LYNX SHARE가 닫히면 다음에 시작할 때 복구한 테이크를 플레이리스트에 놓겠냐고 묻습니다.
