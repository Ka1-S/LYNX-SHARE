Apri il brano

  1. Copia il brano sul computer: un .flm di FL Studio Mobile, un progetto BandLab scaricato come .blx o un .band di GarageBand.
  2. Scegli File › Apri... (Ctrl+O) e selezionalo, oppure trascinalo sulla finestra.

Cosa ottieni

  • Il brano si apre nel layout semplice, con una traccia per strumento, il tempo, i pattern o le regioni e il mix.
  • Premi Play per ascoltarlo.
  • Clicca una traccia per modificarla nel dock sotto la timeline.

Cosa non è potuto arrivare

  • Quando qualcosa ha dovuto cambiare, si apre un breve report insieme al brano. Qui, il MiniSynth di FL Studio Mobile suona con uno dei suoni di synth di LYNX SHARE.
  • Aiuto › Ultimo report di importazione del progetto mostra di nuovo quel report.
  • Gli strumenti che l'app del telefono tiene per sé suonano con i suoni integrati di LYNX SHARE.

Di nuovo sul telefono

  • File › Salva una copia come progetto FL Studio Mobile (.flm)... scrive un .flm che puoi aprire in FL Studio Mobile.
