Salva con nome

  1. Scegli File › Salva con nome... e dai un nome al progetto. Un progetto LYNX (.lynx) conserva i pattern, il Mixer, i plugin e le loro impostazioni, e rimanda ai suoi sample e alle sue registrazioni, che restano file a sé.
  2. Da quel momento File › Salva (Ctrl+S) salva sopra. Il file sostituito va nei backup.

Salva nuova versione

  1. Stai provando un'idea? File › Salva nuova versione (Ctrl+N nel layout Pattern, come in FL Studio; Ctrl+Alt+S in ogni layout) salva il progetto come My beat_2, accanto al primo, e continui a lavorare lì.
  2. LYNX scrive anche dei backup mentre lavori, quindi un crash o un errore costa poco.

Versioni e backup

  1. File › Versioni... elenca le versioni salvate e i backup di questo progetto, dalla più recente.
  2. Scegline una e clicca Apri come copia: si apre come un nuovo progetto non salvato, e i file restano come sono. Etichetta... le aggiunge una nota.
  3. File › Ripristina l'ultimo backup... sostituisce il progetto aperto con il suo backup più recente. Il file del progetto cambia solo quando salvi.

Sposta un progetto su un altro computer

  1. Sample e registrazioni sono file accanto al .lynx, non al suo interno. File › Raccogli tutto e salva copia nella cartella del progetto quelli che stanno fuori e salva; spunta File › Raccogli e salva sempre per farlo a ogni salvataggio.
  2. File › Esporta › Pacchetto di loop zippato... scrive un unico .zip con il progetto e tutti i file che usa: copia quel file sull'altro computer.
  3. File › Apri la cartella del progetto mostra dove si trovano il progetto e i suoi file.
