Fruity HTML NoteBook non elabora audio. Tiene l'indirizzo di una pagina, un file .html locale o un indirizzo web, così puoi conservare appunti, testi o riferimenti accanto al progetto. Si aggiunge come un effetto insert.

Controls

ControlWhat it does
AddressIl file .html locale o l'indirizzo web della pagina.
SfogliaSceglie un file .html locale.
Apri nel browserApre l'indirizzo nel tuo browser predefinito.

Tips

  • Le pagine locali compaiono nell'editor come testo formattato, i link si aprono nel tuo browser.
  • LYNX SHARE non scarica mai pagine web da solo: gli indirizzi web si aprono sempre nel tuo browser.
