Un processore di note VFX dal Patcher di FL Studio, senza suono proprio. Esegue uno script Python sulle note che lo raggiungono. LYNX SHARE lo esegue con un Python integrato (pocketpy) con i moduli math, random, re, time e sys. Gli script non possono aprire file.
