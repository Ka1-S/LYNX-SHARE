Emphasizer to limiter z look-ahead i jednym głównym pokrętłem. Wzmocnienie wejściowe zasila detektor szczytów, redukcja wzmocnienia jest stosowana do sygnału opóźnionego o 2 ms, a wynik jest clipowany i wysyłany do wzmocnienia wyjściowego. Wczytuje ustawienia FL Studio Emphasizer z zaimportowanego projektu .flp i zgłasza 2 ms look-ahead do kompensacji opóźnienia.

Controls

ControlWhat it does
Gain wejściaWzmocnienie przed limiterem, od 0 dB do +24 dB.
EmfazaIlość, od 0 do 100 procent. Skaluje poziom, który widzi detektor szczytów.
WyjściePoziom wyjściowy, do 0 dB.
Soft clippingZastępuje twardy clip przy pełnej skali po limiterze miękkim clipem, który zaczyna się poniżej niej.
Dopasowanie poziomuDzieli wyjście przez wzmocnienie wejściowe, więc podniesienie Input gain nie podnosi poziomu.
BypassPłynnie przechodzi do opóźnionego sygnału dry zamiast przełączać twardo.

Tips

  • Przy włączonym Level matching można podnieść Input gain, by mocniej wysterować limiter, bez zwiększania głośności wyjścia o tyle samo.
  • Pasek mierników po prawej pokazuje poziomy.
