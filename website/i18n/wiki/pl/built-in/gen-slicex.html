Slicex wczytuje sample na każdy z dwóch decków, A i B, tnie go na regiony i gra każdy region z klawisza. Otwiera ustawienia Slicex z FL Studio z pliku .flp i zapisuje je z powrotem przy eksporcie. Nowa instancja startuje z pustymi deckami i nie potrzebuje żadnych plików z instalacji FL. Plik WAV, który nie niesie własnych regionów, jest przy wczytaniu cięty na swoich uderzeniach.

Controls

ControlWhat it does
Master slidersMaster level, Master randomness level, Master LFO level i Master pitch, od minus 1200 do 1200 centów.
MODULATIONPad X / Y z kółkami X i Y. SMOOTH wygładza modulację.
LAYERINGJak regiony na tym samym klawiszu grają razem: All, All (gain-compensated), Velocity-mapped, Modulation X-mapped, Modulation Y-mapped, Random, Cycle lub Song time-synced. SAME DECK nakłada tylko regiony tego samego decka.
CROSSFADEKrzywa między nałożonymi regionami: none, linear, balanced curve, unbalanced curve lub adding.
REGION SETTINGSBieżący region, jego OUT (przesunięcie ścieżki wyjścia) i CUT (grupa cięcia) oraz cztery rzędy: AMP (panorama i głośność), FILTER (cutoff i rezonans), SPEED (pitch) i START (delay i początek sampla). Każdy rząd ma numer grupy ART i ilość.
ARTICULATORWybiera jedną z 8 grup artykulatorów. Jej FILTER ma typ (LP, BP, BS, HP), tryb (OFF, x1, x2, x3) i kółka ENV, CUT i RES.
PAN, VOL, CUT, RES, SPEED, STARTCel, który pokazuje edytor krzywej.
ENV, LFO, VEL, MOD X, MOD Y, RANDCzęść artykulatora, która jest pokazana: jego obwiednia, jego LFO albo mapa z velocity, modulacji X, modulacji Y lub losowości.
TEMPO, GLOBALTEMPO sprawia, że czas krzywej podąża za tempem. GLOBAL sprawia, że faza LFO biegnie razem z utworem.
ATT, DEC, SUS, RELSkalują czasy attack, decay i release obwiedni i przesuwają jej poziom sustain.
SPD, TNS, SKEW, PWSzybkość LFO, tension, skew i szerokość impulsu.
Deck tool rowLoop, Play / pause, Stop, menu File, Regions, Select i Zoom, widok jednego lub dwóch decków oraz bieżący deck, A lub B.
PlikNew, Load sample... i Save sample as..., które zapisuje WAV decka wraz z jego regionami.
RegionyAdd region..., Add marker..., Set loop, Delete, Rename all..., Set all cut groups to... i Freeze all.
KlawiaturaGra klawiszami i pokazuje, które mają regiony. Jego menu ma Assign current region to this key i Select region assigned to this key. Cyfra obok ustawia oktawę bazową.
OpcjeSample start covers whole length, Link velocity to volume, Loop half of regions i HQ envelopes.

Tips

  • Upuść sample na deck, by go wczytać. Tylko plik WAV dostaje markery z automatycznego cięcia, bo markery są zapisane w WAV decka.
  • Menu regionu ma Delete, Clone as region, Turn into marker, Rename..., Trigger note i Zoom on.
  • Nuty o parzystym kolorze grają deck A, a nuty o nieparzystym kolorze deck B. Kolory 14 i 15 grają odwrócone.
  • Menu Snap i View z FL jeszcze tu nie ma, a menu File i Regions mają tylko wymienione wyżej pozycje.
