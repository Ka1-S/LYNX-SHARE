Menedżer pluginów

  1. Wybierz Opcje › Menedżer pluginów.... Pokazuje każdy plugin znaleziony przez LYNX, z producentem, formatem i plikiem.
  2. Foldery pluginów... pokazuje, gdzie LYNX szuka: w standardowych folderach VST3 i CLAP oraz w każdym dodanym przez ciebie.

Szukaj pluginów

  1. Kliknij Znajdź nowe pluginy. Każdy plik jest sprawdzany w osobnym procesie, więc plugin, który się wysypie, nie zawiesi LYNX: trafi do sekcji Nieudane.
  2. Szukaj po nazwie, producencie lub formacie; gwiazdka dodaje plugin do ulubionych.

Wczytaj plugin

  1. W Mixerze zaznacz ścieżkę i kliknij pusty slot.
  2. Wybierz Plugin (VST/VST3/CLAP), potem Więcej wtyczek..., znajdź plugin po nazwie i kliknij Dodaj.
  3. Plugin otworzy się we własnym oknie. Naciśnij Odtwórz, żeby go usłyszeć.
