Нотный процессор VFX из Patcher в FL Studio без собственного звука. Он меняет свойства звучащих нот, пока они звучат. В нем 16 артикуляторов, каждый для одного цвета ноты и диапазона клавиш.

Controls

ControlWhat it does
ВключитьOff: ноты проходят без изменений.
Low, HighДиапазон клавиш артикулятора.
ЦельVelocity, высота, панорама, Mod X или Mod Y.
Envelope, LFOПереключают между двумя формирователями цели.
Envelope on, LFO onВключает формирователь для цели.
ТемпСинхронизирует форму с темпом песни.
БазаБазовый уровень цели.
Env, LFOСтепень огибающей и LFO, отрицательные значения инвертируют.
Attack, Decay, Sustain, ReleaseСтупени огибающей.
СкоростьСкорость LFO.
Tension, Skew, Pulse widthФорма LFO.

Tips

  • Поставьте его перед инструментом в Patcher, чтобы добавить движение удерживаемым нотам.
