Keyboard Controller устанавливает свой выход равным значению, которое вы нарисовали для последней сыгранной клавиши. Он не издает звука; вы связываете его выход с другим элементом управления. Значения рисуются мышью над клавиатурой.

Controls

ControlWhat it does
Key valuesСтолбцы над клавиатурой; высота каждого столбца — это выход для этой клавиши.
Note offЗначение, к которому выход переходит, когда ни одна клавиша не удерживается.
АвторелизКогда ни одна клавиша не удерживается, выход переходит к значению note-off.
РампаЗначение каждой клавиши растет от 0 на самой низкой клавише до 1 на C10.
ИнвертироватьПереворачивает все значения вверх ногами.
ОчиститьУстанавливает значение каждой клавиши в 0.

Tips

  • Импортированные проекты FL сохраняют значения Keyboard Controller.
