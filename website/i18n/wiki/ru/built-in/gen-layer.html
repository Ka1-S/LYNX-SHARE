Layer — канал без собственного звука. Добавьте его в Channel Rack, выберите, какие каналы будут его дочерними, и каждая нота, отправленная в Layer, сыграет эти дочерние каналы. Используйте его, чтобы наслаивать инструменты, делить клавиатуру между звуками или чередовать сэмплы.

Controls

ControlWhat it does
Задать дочерниеКаналы, выбранные в Channel Rack, становятся дочерними для этого Layer.
Показать дочерниеВыбирает дочерние каналы этого Layer в Channel Rack.
НаслоениеМеню для разделения, сброса, группировки или удаления дочерних каналов.
СлучайноКаждая нота играет один случайно выбранный дочерний канал. Если выключено, играют все.
По очередиДочерние каналы играют по очереди, по одному на ноту (round robin).
КроссфейдРучка Fade движется от первого дочернего канала к последнему, смешивая соседние.
FadeПозиция кроссфейда между дочерними каналами.
УровеньУровень канала Layer.
Пан.Панорама канала Layer.
ВысотаВысота канала Layer.

Tips

  • Внутри Patcher у Layer есть пин Children: соедините его кабелем с генераторами, которые он должен играть.
  • Layering > Split children дает каждому дочернему каналу одну клавишу, начиная с корневой.
