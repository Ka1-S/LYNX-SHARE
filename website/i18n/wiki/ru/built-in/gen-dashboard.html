Dashboard — канал без собственного звука. Вы раскладываете свою панель элементов управления и связываете каждый с ручкой в другом месте проекта. Он также может отправлять MIDI. Dashboard из FL Studio в проектах .flp открываются как такая же панель.

Controls

ControlWhat it does
ПравкаРежим правки: тяните элемент, чтобы переместить его, щелкните правой кнопкой, чтобы переименовать, изменить размер или удалить.
ДобавитьДобавляет ручку, слайдер, кнопку, флажок или XY-пад.
MIDIЗадает порт, канал, программу и банк, по которым Dashboard отправляет данные.
Отправлять MIDIДля каждого элемента: отправляет control change, RPN, NRPN, channel pressure или сообщения нот.
ПереименоватьДает элементу собственное имя.
РазмерМеняет размер элемента.

Tips

  • Новый Dashboard стартует с двумя ручками, Knob 1 и Knob 2.
  • Каждый элемент — это выход: щелкните правой кнопкой по ручке, Link to internal controller.
