Fruity Filter — фильтр состояний для слотов инсертов Mixer. Вместо выбора одного типа фильтра вы задаете уровень выходов ФНЧ, полосового и ФВЧ, и они смешиваются. Подходит для свипов и простой коррекции тембра.

Controls

ControlWhat it does
СрезЦентр фильтра. По умолчанию открыт полностью.
РезонансАкцент вокруг среза.
ФНЧУровень выхода ФНЧ.
ПолосовойУровень полосового выхода. По умолчанию выключен.
ФВЧУровень выхода ФВЧ.
x2Пропускает сигнал через фильтр дважды последовательно для более крутого наклона.
ЦентрУбирает смещение DC на выходе.

Tips

  • Поднимите ФНЧ и ФВЧ вместе при нулевом полосовом, чтобы получить отклик, похожий на режекторный.
  • Коэффициент фильтра не зависит от частоты дискретизации проекта.
