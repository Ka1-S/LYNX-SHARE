EQUO — плагин для слота эффекта, построенный на 31 полосовом фильтре в треть октавы. При импорте проекта .flp он открывает настройки плагина EQUO из FL Studio. В нем восемь банков плюс мастер-банк, и у каждой полосы своя громкость, панорама и посыл.

Controls

ControlWhat it does
ShiftСдвигает полосы.
МиксБаланс обработанных полос.

Громк.Выходная громкость.
БанкВыбирает мастер-банк или один из восьми банков.
Vol / Pan / SendВыбирает, какое значение редактируют слайдеры полос.
Только посылОтправляет полосы только в выбранный инсерт.
Режим добавленияСкладывает сигналы полос вместо замены входа.
ОверсэмплингОверсэмплинг обработки.
ШиринаШирина полос.
ОтправитьИнсерт, который получает посылы полос.

Tips

  • Посылы полос идут в инсерт, выбранный в поле Send.
