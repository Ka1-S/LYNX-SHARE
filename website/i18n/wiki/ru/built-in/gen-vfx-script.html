Процессор нот VFX из Patcher FL Studio без собственного звука. Он запускает скрипт на Python для нот, которые до него доходят. LYNX SHARE запускает его во встроенном Python (pocketpy) с модулями math, random, re, time и sys. Скрипты не могут открывать файлы.

Controls

ControlWhat it does
ИнтерфейсЭлементы управления, которые определяет скрипт, и его выходные контроллеры.
СкриптРедактор исходного кода.
ЖурналСообщения и ошибки скрипта.
Справочник APIФункции и свойства, доступные скрипту.
Apply (Ctrl+Enter), Run againЗапускает отредактированный скрипт.
ВернутьВозвращается к скрипту, который сейчас работает.
ПерезапуститьЗапускает скрипт заново.
ОчиститьОчищает журнал.

Tips

  • LYNX SHARE запускает не более 15 скриптов одновременно.
  • Нажмите кнопку ошибки, чтобы перейти к строке с ошибкой.
