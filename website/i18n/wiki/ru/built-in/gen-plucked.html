Plucked — движок для Plucked из FL Studio. Каждая нота возбуждает струну, смоделированную линией задержки, поэтому звучит как щипковая струна. Он играет импортированные проекты и свои пресеты.

Controls

ControlWhat it does
СпадКак долго звенит струна. От 0 до 256, по умолчанию 128.
ЦветПодмешивает шум в возбуждение. От 0 до 128, по умолчанию 64.
Норм.Нормализует спад для каждой высоты. По умолчанию включено.
ГейтNote-off заглушает голос. Если выключено, нота звенит, пока не затухнет сама.
РасширитьЗапускает вторую, отдельно возбуждаемую струну для правого канала.

Tips

  • Случайный seed у каждого экземпляра свой, поэтому два рендера одних и тех же нот не идентичны по сэмплам рендеру FL Studio, который берет seed от часов.
