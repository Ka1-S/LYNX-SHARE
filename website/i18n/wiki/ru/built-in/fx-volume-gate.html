Volume gate — эффект для слота инсерта Mixer. Он открывает и закрывает громкость по паттерну из 32 шагов, который вы рисуете. Обычно его используют для рубленых, заикающихся ритмов или в стиле транс-гейта на падах, аккордах и целых миксах.

Controls

ControlWhat it does
Шаги32 столбца, каждый задает, сколько звука проходит на этом шаге. Новый гейт начинается с половины доли включенным и половины доли выключенным.
АтакаКак быстро растет громкость, когда шаг открывается. По умолчанию около 2 мс.
РелизКак быстро падает громкость, когда шаг закрывается. По умолчанию около 43 мс.
МиксБаланс между обработанным гейтом и необработанным звуком.

Tips

  • Рисуйте шаги мышью, а по столбцам щелкайте правой кнопкой для готовых паттернов.
  • Увеличьте Attack и Release для более мягкой пампинг-накачки, уменьшите для жестких обрезаний.
