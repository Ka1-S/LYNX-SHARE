LYNX SHARE сохраняет проекты в файлы .lynx. Он также открывает проекты других программ, загружает обычные аудиофайлы и экспортирует аудио, MIDI и проекты для других программ. В таблице перечислены все форматы версии 0.1.26 alpha.

Проект, открытый из формата другой программы, считается импортом. Файл › Сохранить тогда спрашивает, куда записать файл .lynx, а исходный файл никогда не меняется.

Открытие проекта другой программы

  1. Выберите Файл › Открыть... (Ctrl+O).
  2. Укажите файл .flp, .als, .flm, .mid или .zip.
  3. Для .flp выберите Справка › Last FL Studio import report, чтобы прочитать, что было приближено или пропущено.
  4. Выберите Файл › Сохранить и укажите, куда записать файл .lynx.

Из командной строки

В Windows программа называется LYNX.exe. В macOS и Linux — LYNX.

LYNX.exe project.lynx                       open a project (.lynx, .flp, .als, .flm or .mid)
LYNX.exe --export project.flp out.flac      render the song (wav, flac or ogg)
LYNX.exe --stems project.flp base.wav       one WAV per mixer insert that has sound
LYNX.exe --export-flp project.lynx out.flp  write an FL Studio project

--export, --stems и --export-flp принимают на входе и .als.

Что полезно знать

  • Аудиофайлы длиннее 30 секунд читаются потоком с дискового кэша.
  • .flp, .als или .flm при сохранении никогда не записываются. Новые файлы создают команды экспорта.
  • Файлы .wv только для чтения.
  • Сначала .zip распаковывается в папку, затем открывается проект внутри.
