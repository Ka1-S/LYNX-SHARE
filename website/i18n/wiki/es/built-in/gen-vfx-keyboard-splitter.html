Un procesador de notas VFX del Patcher de FL Studio sin sonido propio. Tiene 16 zonas. Una nota suena en cada zona cuyo nivel en esa tecla y velocidad sea mayor que cero, por la salida de esa zona.

Controls

ControlWhat it does
TecladoPágina que dibuja el nivel de cada zona sobre las teclas.
VelocidadPágina que dibuja el nivel de cada zona sobre la velocidad.
TransponerDesplaza las notas de una zona, en semitonos, de -48 a 48.
Todo el tecladoPone la zona en todo el rango a nivel pleno.
BorrarVacía la zona.
Asignación manualMientras está activado, las teclas tocadas se toman y no suenan. Cada tecla termina la zona actual y empieza la siguiente.

Tips

  • Manual mapping necesita teclas ascendentes; una tecla más baja o igual se ignora.
  • Cuando empieza la zona 16, el mapeo se desactiva y esa zona llega hasta el final del teclado.
