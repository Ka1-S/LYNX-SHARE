Fruity HTML NoteBook no procesa audio. Guarda la dirección de una página, ya sea un archivo .html local o una dirección web, para que puedas tener notas, letras o referencias junto al proyecto. Se añade como un efecto de insert.

Controls

ControlWhat it does
AddressEl archivo .html local o la dirección web de la página.
ExplorarElige un archivo .html local.
Abrir en el navegadorAbre la dirección en tu navegador predeterminado.

Tips

  • Las páginas locales se muestran dentro del editor como texto con formato; los enlaces se abren en tu navegador.
  • LYNX SHARE nunca descarga páginas web por sí mismo: las direcciones web siempre se abren en tu navegador.
