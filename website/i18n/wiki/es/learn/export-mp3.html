Abre la ventana Exportar

  1. Elige Archivo › Exportar › Archivo MP3..., o pulsa Ctrl+Shift+R.
  2. Archivo › Exportar › Archivo WAV... abre la misma ventana con WAV elegido; Ctrl+R la abre con el último formato que usaste.

Formato y calidad

  1. La fila de formato muestra el que elegiste. WAV conserva todos los detalles (para masterizar o usar en otro programa); MP3 hace un archivo pequeño para compartir.
  2. Para MP3 elige el Tasa de bits: 320 kbps suena mejor.
  3. En Qué renderizar elige la canción entera, el patrón o el tramo que seleccionaste.
  4. Guardar también escribe otros formatos a partir del mismo renderizado, por ejemplo WAV y MP3 a la vez.

Exportar

  1. Pulsa Exportar... y elige dónde guardar. LYNX renderiza más rápido que en tiempo real.
  2. Cuando termina, la barra de ayuda muestra dónde está el archivo.
