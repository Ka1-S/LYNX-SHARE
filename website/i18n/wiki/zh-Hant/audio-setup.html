設定視窗的音訊頁面用來選擇聲音從哪裡輸出，以及錄音從哪裡輸入。用 選項 › 音訊設定... 開啟。設定精靈（選項 › 設定精靈（語言、音訊、外掛資料夾）...）也會測試音訊輸出。

讓聲音出來

  1. 開啟 選項 › 音訊設定...。
  2. 選一個 驅動程式。選單下方的說明會告訴你這個驅動程式適合做什麼。
  3. 選一個 輸出裝置。
  4. 按一下 播放測試音。
  5. 看 狀態 區塊。它會顯示正在執行的驅動程式、取樣率和輸出延遲，或是 未開啟音訊裝置：請選擇輸出裝置。

驅動程式

驅動程式 選單列出系統上的驅動程式類型。

系統驅動程式作用
WindowsWindows Audio (shared)其他程式仍然有聲音。Windows 以固定的間隔混合所有程式，所以緩衝區不能小於這個間隔
WindowsWindows Audio (shared, low-latency period)仍是共享，但會要求 Windows 使用較短的混合週期。只有部分驅動程式支援
WindowsWindows Audio (exclusive, lowest latency)LYNX SHARE 獨佔裝置。播放時其他程式會沒有聲音
WindowsDirectSound (legacy)Windows 的舊式音訊路徑，延遲很高。其他方式都不行時才用
WindowsASIO低延遲驅動程式。廠商的 ASIO 驅動程式可搭配自家裝置使用
WindowsLYNX ASIO (built in)LYNX SHARE 自己的 ASIO 驅動程式，適用任何裝置，可播放也可錄音。驅動程式設定... 用來選擇共享或獨佔模式以及裝置
macOSCore Audio系統自己的音訊，與其他程式共用
LinuxPipeWire (native)LYNX SHARE 直接與 PipeWire 溝通。System default 會跟隨系統聲音設定中選的輸出
LinuxJACK / PipeWire用於執行中的 JACK 伺服器，或搭配 pipewire-jack 的 PipeWire
LinuxALSA直接與音效卡溝通。default 或 pipewire 會共用裝置，hw: 裝置則讓 LYNX SHARE 獨佔音效卡

在 Linux 上，第一次啟動時會開啟 PipeWire、JACK、ALSA 之中第一個有裝置的。儲存過的選擇會保留。

沒有聲音時

  • 先看 狀態。如果沒有開啟任何裝置，請選擇輸出裝置。
  • 試試別的驅動程式。在 Windows 上，Windows音訊（共享） 讓其他程式保有聲音，DirectSound（舊版） 則是在其他方式都失敗時使用。
  • 檢查混音器裡的主控推桿，以及工具列上的 主控 旋鈕。
  • 在樣式模式下只會播放目前的樣式。如果它是空的，就聽不到聲音。按 L 切換到歌曲模式。
  • 在 Linux 上，如果聲音斷斷續續，狀態 會顯示音訊執行緒是否取得了即時優先權。解決辦法在疑難排解。

須知

  • ASIO 只有 Windows 上才有。
  • 使用 Windows音訊（共享） 時，最小的緩衝區就是系統的混合間隔。驅動程式 選單下方的說明會給出你裝置的數值。要更低的延遲，請用獨佔模式或 ASIO 驅動程式。
  • 使用 PipeWire 時，緩衝區範圍是 32 到 2048 個取樣，取樣率範圍是 44.1 到 192 kHz。如果 PipeWire 維持自己的取樣率，它會對 LYNX SHARE 的串流重新取樣。
  • 使用 PipeWire 時，如果拔掉了某個指定的裝置，LYNX SHARE 會退回 System default，並保留緩衝區大小。
  • 狀態 也會顯示音訊 CPU 負載，並統計中斷次數（緩衝區欠載）。
  • 不必開啟視窗也能列出驅動程式和裝置。見命令列中的 --devices。
