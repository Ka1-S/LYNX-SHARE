Kepler 是複音產生器，建立在同名 FL 外掛的引擎上：八個聲部，各有一個振盪器（鋸齒波、帶脈寬調變的脈衝波、副方波和噪音）和階梯式低通濾波器，之後是高通濾波器和合唱，另有 LFO、一個波封和琶音器。LFO 波形和噪音表在執行時從你自己的 FL Studio 安裝中的引擎 DLL 讀取，該安裝必須是支援的版本，這些表並未隨附。找不到該檔案時，編輯器會顯示通知，通道保持靜音，設定則保留。新的實例從你自己的 FL Studio 安裝中該外掛的預設集開始，因此新增它需要安裝 FL Studio；否則「新增」選單會將它列為需要 FL Studio。匯入 .flp 時若沒有該檔案，通道會改用較簡單的合成器轉換。

Controls

ControlWhat it does
Hold, Octave, Volume保持按鈕、-1、0 或 +1 的八度移位，以及主音量。
琶音開啟按鈕、模式（Up、Up/dn 或 Down）、範圍（1、2 或 3）、同步和速率。
LFO速率附同步開關、Delay、Auto 或 Man 觸發模式附 Trig 按鈕，以及相位開關和用於重新觸發相位的推桿。
DCO: LFO, PWMLFO 是 LFO 作用在振盪器上的量。PWM 設定脈寬，可由 LFO 驅動、手動設定（Man）或由波封驅動。
DCO: Pulse, Saw, Sub, Noise切換脈衝波、鋸齒波和副波的按鈕、副波電平推桿和噪音電平推桿。
HPF頻率設定高通濾波器。
VCF低通濾波器的頻率（截止）和 Res（共振）、附 + 或 - 極性開關的 Env 量、LFO 量，以及 Kybd（琴鍵跟隨）。
VCA放大器跟隨波封（Env）或琴鍵門限（Gate）。
波封波封的 A、D、S 和 R 推桿。
合唱Off、I、II 或 I+II。

Tips

  • 切斷群組不會切斷這個產生器。
  • 自振盪的預設集相對於 FL 渲染，相位可能會漂移。
