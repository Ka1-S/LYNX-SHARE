Fruity Love Philter 有八個單元。每個單元都有輸入電平、濾波器、波形整形器，以及帶聲像和音量的輸出，並且可以饋入下一個單元。每個單元的發音器可以從樣式波封、LFO、Mod X 和 Mod Y 控制項，以及波封跟隨器來調變聲像、音量、截止、共振、低、帶通和高通的電平，以及波形整形器的混合。它會從匯入的 .flp 專案載入 FL Studio 外掛的設定。

Controls

ControlWhat it does
Unit switches and tabs 1 to 8上方的開關啟用各個單元。分頁選擇顯示的單元。
IN: VOL外掛輸入進入此單元的電平。負值會反轉相位。
Filter type and mode類型選擇器選擇濾波器。模式設定串聯的階段數：Off、Single、Dual、Triple、Alt dual 或 Alt triple。Off 時只剩增益、聲像和波形整形器。
CUT / RES單元濾波器的截止和共振（或寬度）。
ENV截止發音器的深度。
L / B / HSVF 類型的低通、帶通和高通輸出的電平。
ALT濾波器的替代共振或寬度響應。
WS: AMP, MIX, MODE波形整形器：進入整形器的增益、與未整形訊號的混合，以及單極或雙極曲線。
OUT: PAN, VOL單元在外掛輸出中的聲像和電平。
NEXT此單元的輸出有多少饋入下一個單元。為零時各單元並聯運作。
Articulator editor分頁 PAN、VOL、CUT、RES、LOW、BAND、HIGH、WS 和 WMIX 選擇目標，PAT、LFO、MOD X、MOD Y 和 IEF 選擇來源，其曲線畫在下方。
X / Y pad設定 Mod X 和 Mod Y。SMOOTH 讓它們的變化滑動。
VOL / LFO / IEF sliders主電平、主 LFO 電平，以及進入波封跟隨器的電平。
IEF: USE1, ATT, REL波封跟隨器的起音和釋放。USE1 讓它跟隨單元 1 的輸出，而不是外掛輸入。
CENTER移除輸出的直流偏移。
過取樣引擎的過取樣階數。渲染時會加倍。

Tips

  • 新實例中只有第一個單元是啟用的。
  • 每個啟用單元的輸出都會加總，所以 NEXT 為零時，數個單元就像並聯濾波器一樣運作。
