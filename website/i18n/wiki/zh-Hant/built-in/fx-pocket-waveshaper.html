Pocket Waveshaper 讓聲音通過七種曲線之一來使它失真。曲線之前有兩個濾波器，之後有三頻段音色區，LFO 可以移動兩個形狀控制項。FL Studio Mobile 專案（.flm）的 Waveshaper 模組就是載入這個引擎，所有數值原樣複製，它也可以加到任何混音器插槽。

Controls

ControlWhat it does
形狀曲線：Soft、Tanh、Crossover、Fold、Octaver、Rectify 或 CrossFold。
自動增益開啟時，以緩慢的跟隨器讓塑形後訊號的電平與輸入電平相符。
X / Y所選曲線的兩個參數。它們改變什麼，取決於形狀。顯示 0 到 100。
驅動進入曲線的增益，0 dB 到 40 dB。顯示 0 到 100。
後置增益塑形後訊號的增益，-18 dB 到 +18 dB。
立體聲擴展在曲線之前，給左右訊號加上符號相反的偏移，讓兩側的失真不同。四次方律，顯示 0 到 100。
混合乾訊號與塑形後訊號的等功率混合。顯示 0 到 100。
High cut / Low cut曲線之前的雙極點濾波器，各為 20 Hz 到 20 kHz。
低音曲線之後位於 100 Hz 的鐘形頻段。顯示 -18 dB 到 +18 dB。
Mid freq / Mid gain曲線之後的鐘形頻段，500 Hz 到 2 kHz。增益顯示 -18 dB 到 +18 dB。
高音曲線之後位於 3.3 kHz 的高頻擱架。顯示 -18 dB 到 +18 dB。
LFO 形狀Sine、Saw 或 Square。
LFO 同步開啟時使用 LFO rate，並跟隨歌曲位置。關閉時使用 LFO rate free。
LFO 速率LFO sync 開啟時 LFO 週期的長度：1/8、1/4、3/8、1/2、3/4、1 拍、2 拍、1 小節、2 小節或 4 小節。
LFO 自由速率LFO sync 關閉時 LFO 的速度，0.02 Hz 到 9.92 Hz，依三次方律變化。
LFO to X / LFO to YLFO 移動 X 和 Y 的幅度，0 到 100 %。在 100 % 時，它會讓控制項向兩個方向各移動範圍的一半。

Tips

  • LFO 和 X、Y 的值每個歌曲刻度（一拍的 1/96）更新一次，而不是每個取樣更新。
  • 曲線之後的 DC 濾波器，會移除不對稱形狀和 Stereo spread 所產生的偏移。
