Pocket Comb Filter 在乾訊號上加入帶回授的短延時，使聲音在調好的音高上持續鳴響。音高可手動設定，也可跟隨通道機架上按住的最低琴鍵，或跟隨輸入中偵測到的音高。FL Studio Mobile 專案 (.flm) 的 Comb Filter 模組就是載入到這個引擎上，所有數值原樣複製，它也可以加到任何混音器插入槽。

Controls

ControlWhat it does
模式Manual、Lowest Note 或 Detect Pitch。Manual 使用 Pitch，或在 Snap 開啟時使用 Pitch oct 和 Pitch note。Lowest Note 跟隨通道機架上按住的最低琴鍵，放開後保留最後一個音。Detect Pitch 跟隨輸入的音高。
音高Snap 關閉時 Manual 模式的頻率，1 Hz 到 2.50 kHz，依四次方律變化。
回授有多少延遲訊號被回授，0 到 100 %。數值越高，鳴響越久。
混合加到乾訊號上的梳狀訊號電平，0 到 100 %。乾訊號維持滿電平。
偏移在 Lowest Note 和 Detect Pitch 模式下，將音高移動 -2 到 +2 個八度。
平滑音高滑向新數值的緩慢程度，0 到 100 %。
貼齊開啟：Manual 模式演奏由 Pitch oct 和 Pitch note 設定的音符。關閉：使用 Pitch 頻率。
極性每一側回授的正負號：Both +、Left -、Right - 或 Both -。
不對稱-5.0 到 +5.0 %。依此量降低左側頻率並提高右側頻率（負值則相反）。
音高八度音符的八度，-1 到 6。
音高音符音名，C 到 B。尚未按住任何琴鍵時，Lowest Note 也從這個音符開始（預設為 E3）。

Tips

  • Lowest Note 讀取通道機架所有通道上按住的琴鍵。在 FL Studio Mobile 中，它只讀取效果所在的那個機架。
  • Detect Pitch 在有音高的聲音上效果最好。在鼓或雜訊上它可能鎖定到錯誤的音高，FL Studio Mobile 自己的偵測器在這方面也不穩定。
  • 調音跟隨 FL Studio Mobile 的延時迴路，在同一個音符上，它與理想梳狀濾波器約差 19 音分。
  • 這個效果器有一頁簡單的旋鈕，而不是 FL Studio Mobile 的面板。
