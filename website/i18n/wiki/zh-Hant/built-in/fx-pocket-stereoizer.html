Pocket Stereoizer 把單聲道總和延遲並濾波，再把結果加到左聲道、從右聲道減去，藉此加寬聲音。可用在單聲道或較窄的音源上。FL Studio Mobile 專案（.flm）的 Stereoizer 模組就是載入這個引擎，所有數值原樣複製，它也可以加到任何混音器插槽。

Controls

ControlWhat it does
強度加入訊號的電平，依平方律變化。顯示 0 到 100。接近 0 時，加寬會被關閉。
音色單聲道總和的延時，從 0.5 ms 到 50 ms，依三次方律變化。顯示 0 到 100。
聚焦延遲訊號上的單極濾波器。顯示 -100 % 到 +100 %。中央以下是低通，中央以上是高通。
左右延遲讓一側延遲最多 25 ms，依三次方律變化。顯示 -100 % 到 +100 %。中央偏左延遲左聲道，中央偏右延遲右聲道。
聲像線性平衡，-100 % 到 +100 %。降低另一側，並滑向新的值。

Tips

  • 加入的訊號在兩側的符號相反，所以當 L/R delay 和 Pan 在中央時，輸出加總成單聲道會互相抵消。
