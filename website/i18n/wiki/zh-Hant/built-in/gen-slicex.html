Slicex 在 A 和 B 兩個取樣盤上各載入一個取樣，把它切成區域，每個區域由一個琴鍵播放。它會開啟 .flp 中 FL Studio Slicex 的設定，並在匯出時寫回去。新的實例以空的取樣盤開始，不需要 FL 安裝中的任何檔案。沒有自帶區域的 WAV 檔案，載入時會依它的打擊點切片。

Controls

ControlWhat it does
Master slidersMaster level、Master randomness level、Master LFO level 和 Master pitch，負 1200 到 1200 音分。
MODULATION一塊帶有 X 和 Y 滾輪的 X / Y 板。SMOOTH 讓調變更平滑。
LAYERING同一個琴鍵上的區域如何一起播放：All、All (gain-compensated)、Velocity-mapped、Modulation X-mapped、Modulation Y-mapped、Random、Cycle 或 Song time-synced。SAME DECK 只疊加同一個取樣盤的區域。
CROSSFADE疊加的區域之間的曲線：none、linear、balanced curve、unbalanced curve 或 adding。
REGION SETTINGS目前的區域、它的 OUT（輸出軌道偏移）和 CUT（截斷群組），以及四列：AMP（聲像和音量）、FILTER（截止和共振）、SPEED（音高）和 START（延遲和取樣起點）。每一列有一個 ART 群組編號和一個量。
ARTICULATOR選擇 8 個發音器群組之一。它的 FILTER 有類型（LP、BP、BS、HP）、模式（OFF、x1、x2、x3），以及 ENV、CUT 和 RES 滾輪。
PAN, VOL, CUT, RES, SPEED, START曲線編輯器所顯示的目標。
ENV, LFO, VEL, MOD X, MOD Y, RAND顯示發音器的哪一部分：它的波封、它的 LFO，或從力度、調變 X、調變 Y 或隨機性而來的對應。
TEMPO, GLOBALTEMPO 讓曲線的時間跟隨速度。GLOBAL 讓 LFO 相位隨歌曲運行。
ATT, DEC, SUS, REL縮放波封的起音、衰減和釋放時間，並偏移它的延音電平。
SPD, TNS, SKEW, PWLFO 的速度、張力、偏斜和脈衝寬度。
Deck tool rowLoop、Play / pause、Stop、File、Regions、Select 和 Zoom 選單，單一或雙取樣盤顯示，以及目前的取樣盤，A 或 B。
檔案New、Load sample... 和 Save sample as...，後者會儲存取樣盤的 WAV 及其區域。
區域Add region...、Add marker...、Set loop、Delete、Rename all...、Set all cut groups to... 和 Freeze all。
鍵盤彈奏琴鍵，並顯示哪些琴鍵有區域。它的選單有 Assign current region to this key 和 Select region assigned to this key。旁邊的數字設定基礎八度。
選項Sample start covers whole length、Link velocity to volume、Loop half of regions 和 HQ envelopes。

Tips

  • 把取樣拖放到取樣盤上即可載入。只有 WAV 檔案能得到自動切片產生的標記，因為標記是存在取樣盤的 WAV 裡。
  • 區域的選單有 Delete、Clone as region、Turn into marker、Rename...、Trigger note 和 Zoom on。
  • 顏色為偶數的音符播放取樣盤 A，顏色為奇數的音符播放取樣盤 B。顏色 14 和 15 以倒放播放。
  • FL 的 Snap 和 View 選單還沒有，File 和 Regions 選單也只有上面列出的項目。
