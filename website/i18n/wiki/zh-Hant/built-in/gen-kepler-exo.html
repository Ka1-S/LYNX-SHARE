Kepler Exo 是 Kepler 的雙振盪器版本，執行同一個引擎，多了第二個振盪器、交叉調變、第二個波封和 LFO、調變矩陣，以及飽和、合唱、EQ、延時和殘響的效果頁面。其表在執行時從你自己的 FL Studio 安裝中的 Kepler Exo 引擎 DLL 讀取，該安裝必須是支援的版本，這些表並未隨附。找不到該檔案時，編輯器會顯示通知，通道保持靜音，設定則保留。新的實例從你自己的 FL Studio 安裝中該外掛的預設集開始，因此新增它需要安裝 FL Studio；否則「新增」選單會將它列為需要 FL Studio。匯入的通道沒有退回轉換。

Controls

ControlWhat it does
Top bar保持、八度（-1、0 或 +1）、調變路徑的 X 和 Y 偏移、主失諧、音量和聲像。
DCO 1, DCO 2: LFO1, LFO2, Env2, PWMLFO 1、LFO 2 和波封 2 作用在振盪器上的量，每個 LFO 有寬度開關，以及脈寬和其來源：LFO、Man 或 Env。
DCO 1, DCO 2: Pulse, Saw, Sub脈衝波、鋸齒波和副波的按鈕，附副波電平和副波相位的推桿。
DCO 2: On, Semi, Fine, Sync開啟振盪器 2，以半音和微調步進調音，並使其同步。
交叉調變1>2 和 2>1 設定每個振盪器被調變的量，各有一種形狀：正弦、三角、脈衝、鋸齒、噪音或另一個振盪器。
混音器DCO1、DCO2 和噪音的電平，以及 AM 量。
VCF6、12、18 或 24 dB 的斜率、頻率、Res、附 + 或 - 極性開關的 Env1 量、LFO1、LFO2 和 Kybd 量，以及帶有自己形狀選擇的 FM。
HPF高通濾波器的開啟開關和頻率。
VCA放大器跟隨 Env1、琴鍵門限或 Env2。Vel 設定力度改變音量的程度，Smooth 切換平滑。
Env 1, Env 2每個波封的 A、D、S 和 R 推桿。
LFO 1, LFO 2速率附同步、Delay、Auto 或 Man 觸發模式，以及相位開關和其推桿。LFO 2 另有形狀：Tri、Ramp up、Ramp dn、Sine、S&H 或 Rnd glide。
聲部LFO 觸發按鈕、Exp 或 Lin 滑奏附滑音旋鈕，以及 Mono、Legato、Retrig 和 Release 開關。
琶音開啟按鈕、範圍（1 到 3）、有九種模式的模式選單（上行、下行、隨機及依彈奏順序的變體）、同步、速率和 Gate。
矩陣八個旋鈕，1 到 8，設定八條調變路徑的量。
合唱Off、I、II 或 I+II，附噪音旋鈕和 Gate 開關。
Effect pages飽和（Drive、Pre 或 Post、HQ）、合唱、EQ（低、中、高的增益、頻率和 Q）、延時和殘響的分頁。每一頁都有自己的開啟開關。

Tips

  • 匯入的 Kepler Exo 通道會保留其設定，包括調變矩陣。
  • 使用 4x 過取樣旗標的狀態會被引擎拒絕。
