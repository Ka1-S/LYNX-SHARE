BassDrum 是大鼓產生器，建立在同名 FL 外掛的引擎上：兩個波表振盪器帶下降的音高掃頻，加上 click、可選的雜訊取樣層、驅動階段和 42 Hz 高通。振盪器波表和雜訊取樣在執行時從你自己的 FL Studio 安裝中的 BassDrum 資料夾讀取，並未隨附。新的實例從你自己的 FL Studio 安裝中該外掛的預設集開始，因此新增它需要安裝 FL Studio；否則「新增」選單會將它列為需要 FL Studio。匯入 .flp 時若沒有該資料夾，通道會改用較簡單的正弦加掃頻轉換。

Controls

ControlWhat it does
輸出輸出電平。會乘上音符力度。
取樣整個聲音的重新取樣比例，從四分之一到四倍，音高和長度一起改變。彈奏的琴鍵會以相同方式移調鼓聲。
時長鼓聲電平斜坡的長度。設為 0 時鼓聲靜音。
Base, Peak, Slide音高掃頻。Base 是它最後停留的頻率（16 到 256 Hz），Peak 是高於它的掃頻深度，Slide 是掃頻所花的時間。
Var base, Var peak, Var slide第二個振盪器的 base、peak 和 slide 相對於第一個的偏移，從一半到兩倍。
變化 相位延後第二個振盪器的起始，最多 350 個內部 44.1 kHz 速率的取樣。
驅動聲音之後飽和器的量。
超低音輸出端 42 Hz 高通的共振。
起音讓打擊的起始更平滑。數值越高，上升越慢。
Click, Freq, Cut在起始時調變振盪器相位的 click。Click 是其電平，Freq 是其速度，Cut 是其起始相位。
Noise display顯示正在使用的雜訊取樣，無法讀取時顯示 Needs FL Studio's files。
Noise: A, D, S雜訊層波封的起音、衰減和延音。
Noise: Start讓雜訊相對於振盪器延後，或讓振盪器相對於雜訊延後，兩個方向最多各 100 ms。在中央時兩者同時開始。
Noise: Pitch, Filter, Mix雜訊取樣的播放速度（下兩個八度到上兩個八度）、其低通濾波器及其電平。

Tips

  • 音符長度不會縮短打擊：忽略 note-off，聲音在約 23 ms 的靜音後結束。
  • 聲音以內部 44.1 kHz 運行，並重新取樣到專案取樣率。
