Dashboard 是沒有自身聲音的通道。你自行編排控制項面板，並把每個控制項連結到專案中其他地方的旋鈕。它也能傳送 MIDI。.flp 專案中的 FL Studio Dashboard 會以同樣的面板開啟。

Controls

ControlWhat it does
編輯編輯模式：拖曳控制項可移動，按右鍵可重新命名、調整大小或刪除。
新增加入旋鈕、滑桿、按鈕、核取方塊或 XY 板。
MIDI設定 Dashboard 傳送所用的連接埠、通道、音色編號和音色庫。
傳送MIDI每個控制項：傳送控制變更、RPN、NRPN、通道壓力或音符訊息。
重新命名為控制項取一個自己的名稱。
大小更改控制項的大小。

Tips

  • 新的 Dashboard 一開始有兩個旋鈕，Knob 1 和 Knob 2。
  • 每個控制項都是輸出：在旋鈕上按右鍵，選擇「連結到內部控制器」。
