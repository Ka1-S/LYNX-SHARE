Pocket Filter 是由一對、兩對或四對相同濾波級組成的共振濾波器。FL Studio Mobile 專案 (.flm) 的 Filter 模組就是載入到這個引擎上，所有數值原樣複製，它也可以加到任何混音器插入槽。

Controls

ControlWhat it does
頻率截止頻率或中心頻率，16 Hz 到約 20 kHz。
Q共振，顯示為 0.80 到 2.80，依平方律變化。
類型LP（低通）、BP（帶通）或 HP（高通）。LP 佔範圍的下半部，BP 佔上半部，HP 只佔最頂端。
斜率24 dB/O、48 dB/O 或 96 dB/O。24 dB/O 佔範圍的下半部，48 dB/O 佔上半部，96 dB/O 只佔最頂端。

Tips

  • 與 FL Studio Mobile 相同，低通每對濾波級會降低約 2 dB 的電平：在 24、48 和 96 dB/O 時分別約為 2、4 和 8 dB。帶通會依 Q 值提高中心，最多約 9 dB。
  • Slope 的變更會立即切換，低通電平只在下一次變更 Frequency、Q 或 Type 時才跟上。FL Studio Mobile 的做法相同。
  • 每對濾波級會使聲音延遲一個取樣，這不會回報給延遲補償，與 FL Studio Mobile 相同。
