Sentry Gate 是 LYNX SHARE 原生的混音器插入軌閘門與擴展器。它切掉低於閾值的訊號，依壓縮比和範圍的不同，從輕柔的擴展到完整的閘門。顯示區在即時電平上方呈現傳輸曲線。

Controls

ControlWhat it does
風格Classic、Clean、Vocal、Guitar 或 Upward。改變閘門開啟和關閉的方式。
閾值閘門開啟的電平，從 -60 dB 到 0 dB。
壓縮比從 1:1 到 100:1，從擴展器到閘門。
範圍訊號被衰減的幅度，從 0 到 100 dB。
起音開啟時間，從 0 ms 到 1 s。
釋放關閉時間，從 0 ms 到 5 s。
保持閘門保持開啟的時間，從 0 到 250 ms。
拐點閾值的柔和程度，從 0 到 30 dB。
前視從 0 到 10 ms，附有開關。
側鏈內部或外部，附有高通和低通濾波器。
聲道模式底部列中的選單（圖中為 Left/Right）。
Oversampling, In and Out過取樣選單以及輸入和輸出增益。
模型Classic 或 Measured。Measured 加入 Vocal 風格的降噪；其他風格會忽略它。0.1.26 之前儲存的專案會載入為 Classic。
觸發Level 或 Transient。Level 是和以前一樣的門。Transient 是鼓用的門：超過閾值的敲擊會讓它完全打開，它會在 Hold 期間保持打開，並依所選形狀在 Release 內關閉，無論期間電平如何變化。Transient 模式不使用 Ratio、Knee 和風格的曲線。預設為 Level。
形狀僅限 Transient。釋放的形狀：Smooth、Mid 或 Sharp。
靈敏度僅限 Transient。1 到 10，預設為 5。數值越高，較小的敲擊也能打開門。

Tips

  • 開啟前視會增加 10 ms 的延遲。
