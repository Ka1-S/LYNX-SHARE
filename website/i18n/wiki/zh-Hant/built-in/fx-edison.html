Edison 是放在混音器插入槽中的音訊編輯器。它會原封不動地傳遞插入槽的輸入，在 Record 開啟時錄製該輸入，並把自己的播放加到輸出中。同一軌上可以有多個 Edison 插入槽。可從插入槽的外掛清單加入，或使用混音器軌道選單：Open audio editor (Ctrl+E) 會把它放進第一個空插入槽，Open audio editor and record (Shift+E) 還會以 Record 模式 On play、5 min、Append 關閉、Slave 開啟將它預備好。它的視窗就是 LYNX SHARE 的音訊編輯器，並加上插入槽的錄製控制項。視窗關閉時錄製仍會繼續。.flp 專案中的 Edison 插入槽會開啟為 Edison，保留其設定和音訊。

Controls

ControlWhat it does
錄製依模式錄製插入槽的輸入。快速鍵 R。
Now, On input, Input, On play錄製模式。Now 立即開始。On input 在輸入超過雜訊閾值時開始，並保留之前的 0.1 s。Input 只在聽到輸入時錄製，並在靜音 1 s 後暫停。On play 在歌曲播放時錄製，並在每次歌曲位置跳轉時加入一個 Song jump 標記，因此循環播放的歌曲會得到一段錄音，每一圈有一個標記。新的插入槽從 On input 開始。
最長錄製時間Forever、1、3、5、10、30 或 60 min。新的插入槽從 30 min 開始。
附加開啟：新的錄音接在已有的音訊之後。關閉：取代原有音訊。預設為開啟。

輸入靜音不傳遞插入槽的輸入，只輸出 Edison 的播放。快速鍵 I。

Tips

  • 音訊以 WAV 檔案保存在專案的錄音資料夾中，而不是在專案檔內。
  • Tools › Acquire noise threshold 在只含背景雜訊的選取範圍上執行，會設定 On input 和 Input 所偵測的電平。
  • Tools › Macros › Remove all Edison instances 會移除專案中的每個 Edison 插入槽。
  • 在 LYNX SHARE 中建立的插入槽，匯出時不會寫入 .flp。來自 .flp 且未編輯過的 Edison 插入槽會保留 FL Studio 的資料。
  • 觸發音符與區域一起儲存，並由音訊腳本讀取。尚未支援從音符播放區域。
