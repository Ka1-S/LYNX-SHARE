Sawer 是減法式產生器，建立在同名 FL 外掛的引擎上：一個鋸齒波振盪器加副鋸齒波、硬同步、噪音，4 極濾波器帶有低通、帶通、高通和陷波輸出，之後是合唱、移相、延時和殘響，另有六個插槽的調變矩陣和琶音器。振盪器週期在執行時從你自己的 FL Studio 安裝中 Sawer 資料夾的 data.saw 讀取，並未隨附。找不到該檔案時，編輯器會顯示通知，通道保持靜音，設定則保留。新的實例從你自己的 FL Studio 安裝中該外掛的預設集開始，因此新增它需要安裝 FL Studio；否則「新增」選單會將它列為需要 FL Studio。

Controls

ControlWhat it does
Voices, Bend複音數（4 到 24 個聲部）和彎音範圍（關，或 1 到 12）。
主控電平、聲像，以及音量波封的 A、D、S、R 推桿。
音高粗調（移調）和微調音高。
滑音Rate 或 Time 模式、永遠或按住的琴鍵模式，以及滑音 Time。
聲部複音或單聲道、八度器關或開，以及齊奏重新觸發的自由或同步。
齊奏1、2、4 或 8 個聲部，附失諧和擴散（聲像）。
振盪器噪音電平，以及帶有 On 開關的 Sync 頻率。
副鋸齒第二個振盪器的 Level、Phase、Harmonic（從 1/4 到 4 的比例）和 Detune。開關選擇 Free 或 Sync 重新觸發、+ 或 - 極性，以及 Saw 或 Pulse 波形。
濾波器截止、共振、Key（琴鍵追蹤）和 Vel（力度追蹤），模式有 Low、Band、High 和 Notch。
濾波器包絡A、D、S、R 和 Amount，送到 Cutoff、Sync、Sub phase 或 Pitch。
LFOSpeed、Attack、Release 和 Amount；Free 或 Sync 重新觸發、Hz 或 Beat 計時、Inv、波形（Tri、Saw、Square 或 S&H）和目的地（Cutoff、Sync、Sub phase、Pitch、Noise、Volume 或 Pan）。
Chorus and PhaserChorus 有開關、Depth、Rate 和 Mix。Phaser 有開關、Center、Rate、Depth、Fdbk 和 Mix。
Delay and ReverbDelay 有開關、Left 和 Right 時間、Fdbk、Mod、LoCut、HiCut 和 Mix。Reverb 有開關、Decay、HiCut、Damp 和 Mix。
調變六個插槽。每個都有來源（Velocity、Aftertouch、Pitch wheel 或 MIDI CC）、量旋鈕，以及從外掛參數中選擇的目的地。
琶音On 開關、模式（Up、Down、Up/dn 或 Rnd）、範圍 1 到 4，以及從 1/32 到 3/4 的音符分割。
