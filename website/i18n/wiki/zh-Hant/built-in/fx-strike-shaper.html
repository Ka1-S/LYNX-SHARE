Strike Shaper 是 LYNX 自己的暫態塑形器。它比較同一個訊號的兩條波封，並依兩者的比值設定增益，所以對輕的和重的打擊反應一致，也不需要閾值。用 Attack 讓起音更硬或更軟，用 Sustain 讓尾音變長或變短。它沒有前視，也不增加延遲。

Controls

ControlWhat it does
起音提高或降低每次打擊的起音，-15 dB 到 +15 dB，印出的刻度在 0 dB 附近較細。
延音提高或降低每次打擊之後逐漸衰減的尾音，-24 dB 到 +24 dB。
輸出增益輸出電平，-20 dB 到 +6 dB，旋鈕頂端是 0 dB。
On / Power開啟或關閉效果。ON 鍵和 Power 燈的作用相同。
連結開啟時，兩個聲道使用同一個偵測器和同一個增益，所以立體聲影像不會移動。關閉時，左右分別塑形。
偵測器高通只作用在偵測器上的高通濾波器，Off 或 20 Hz 到 1 kHz。它避免低頻觸發塑形，而且不會對音訊本身濾波。
保護輸出上的軟削波器。訊號低於約 -3 dBFS 時它不處理，也不會讓訊號超過 0 dBFS。
混合乾訊號與塑形後訊號的混合，0 到 100 %，用於並聯處理。輸出增益和 Guard 在它之後。
SIG / OVL lamps有輸入訊號時 SIG 亮起。輸出峰值達到滿刻度時 OVL 亮起。
Attack / Sustain rows兩排燈即時顯示每個增益移動了多少。左邊的藍色是衰減，右邊的紅色是提升，刻度為 1、3、6、10 和 15 dB。

Tips

  • Attack 和 Sustain 為 0 dB、Mix 為 100 %、Output gain 為 0 dB 時，訊號原樣通過。
  • 較大的 Attack 提升，在一次打擊上最多可增加 +15 dB。如果 OVL 燈亮起，請開啟 Guard 或降低 Output gain。
  • 把游標移到旋鈕上可讀取它的數值。在旋鈕上按右鍵可開啟它的數值選單。
