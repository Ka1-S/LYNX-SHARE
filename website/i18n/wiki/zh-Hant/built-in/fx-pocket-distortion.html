Pocket Distortion 用四種曲線之一塑造訊號，然後保持取樣以得到碎化的聲音，並縮放輸出。可用來為鼓、貝斯和合成器增添顆粒感。FL Studio Mobile 專案（.flm）的 Distortion 模組就是載入這個引擎，它也可以加到任何混音器插槽。

Controls

ControlWhat it does
Hard / Tube / Soft / Clip選擇曲線。Hard 是隨電平上升而變平的拐點曲線，Tube 是 tanh 曲線，Soft 是指數曲線，Clip 則在滿刻度處把訊號截掉。
偏置雙極，-100 到 100。在曲線之前加上偏移，讓波形的兩半失真得不一樣。滑桿依五次方律變化，所以主要在兩端附近起作用。曲線之後有高通濾波器移除偏移。
驅動失真量，顯示為 0 到 100。
立體聲在兩側之間分配驅動量，顯示為 -100 到 100。在 0 時兩側都得到完整驅動。低於 0 時左側得到較少驅動，高於 0 時右側得到較少。
位元粉碎把每個輸出取樣保持 1 到 257 個取樣。滑桿依四次方律變化，所以前半段變化很小。
增益輸出電平，-24 到 0 dB。

Tips

  • BitCrush 以保持取樣的方式降低取樣率。它不會降低位元深度。
  • Gain 只會降低電平。用它來補償 Drive 增加的電平。
