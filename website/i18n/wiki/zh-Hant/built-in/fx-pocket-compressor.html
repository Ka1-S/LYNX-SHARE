Pocket Compressor 降低軌道中較大聲部分的電平。帶保持的峰值偵測器讀取兩個聲道中較大的一個，並對兩個聲道套用同一個增益。FL Studio Mobile 專案（.flm）的 Compressor 模組就是載入這個引擎，所有數值原樣複製，它也可以加到任何混音器插槽。

Controls

ControlWhat it does
Thresh壓縮開始的電平，-40 dB 到 0 dB。
壓縮比1:1 到 20:1，依平方律變化。範圍頂端讀作 +inf，並把電平保持在閾值。
起音偵測器跟隨上升電平的速度，0 到 50 ms，依平方律變化。
釋放保持時間過後，被保持的峰值下降的速度，10 ms 到 500 ms，依平方律變化。
電平輸出增益。開啟 Auto gain 時範圍是 -20 dB 到 +20 dB，關閉 Auto gain 時，同樣的旋鈕行程是 0 dB 到 +40 dB。
保持偵測器在開始釋放前保留峰值的時間，0 到 50 ms，依平方律變化。
自動增益加上由 Thresh 和 Ratio 算出的補償增益，讓滿刻度的輸入以滿刻度輸出。
輸入增益只對饋入偵測器的訊號施加的增益，-20 dB 到 +20 dB。它不會改變音訊本身的電平。
RMS為了相容而儲存。FL Studio Mobile 從不開啟它，所以它永遠顯示 Off，也沒有作用。

Tips

  • 切換 Auto gain 會讓 Level 讀數移動 20 dB，輸出電平也隨之移動。更改之後請檢查 Level。
  • 沒有前視，也沒有延遲。
