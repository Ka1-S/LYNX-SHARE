Pocket Gate 在訊號低於閾值時降低它。可用來切掉音符之間的噪音，或讓鼓更緊實。控制項分在兩個頁面，LEVEL 和 ENVELOPE。FL Studio Mobile 專案（.flm）的 Gate 模組就是載入這個引擎，它也可以加到任何混音器插槽。

Controls

ControlWhat it does
LEVEL / ENVELOPE在電平頁面和時間頁面之間切換。
閾值讓閘門打開的電平，-60 到 +6 dB。任何一側高於它時，閘門就會打開。
不對稱電平要比閾值低多少，閘門才會關閉，0 到 66 dB。
Left and Right meters顯示輸入電平，閾值處有一個標記。以 dB 表示的閾值印在下方。
混合閘門的深度，-100 到 100%。在 100% 時，關閉的閘門會把訊號降低 60 dB。在 0% 時閘門沒有作用。負值會反轉閘門，使它在打開時降低訊號。
Attack and Release閘門打開和關閉各需要的時間，各為 0 到 1000 ms。
A. Curve and R. Curve雙極，-1 到 1。彎曲打開和關閉的斜坡。在 0 時斜坡是線性的，往一個方向是對數形狀，往另一個方向是指數形狀。
保持閘門打開後至少維持打開的時間，0 到 1000 ms。

Tips

  • 閘門以 256 個取樣為一區塊來量測電平，並向前看 255 個取樣。它會把這個回報為延遲。
  • 把 Asymmetry 設在 0 以上，可以避免閘門在徘徊於閾值附近的訊號上顫動。
