Keyboard Controller 會把輸出設為你為最後彈奏的琴鍵所畫的值。它不發出聲音；你把它的輸出連結到另一個控制項。你用滑鼠在鍵盤上方畫出這些值。

Controls

ControlWhat it does
Key values鍵盤上方的長條；每根長條的高度就是該琴鍵的輸出。
音符放開沒有按住任何琴鍵時輸出變成的值。
自動釋放沒有按住任何琴鍵時，輸出變成 note-off 值。
斜坡每個琴鍵的值從最低琴鍵的 0 上升到 C10 的 1。
反轉把每個值上下翻轉。
清除把每個琴鍵的值設為 0。

Tips

  • 匯入的 FL 專案會保留 Keyboard Controller 的值。
