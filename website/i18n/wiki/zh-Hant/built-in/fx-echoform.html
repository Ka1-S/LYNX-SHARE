Echoform 是回聲效果器，有十二種風格和五種回聲配置。主要頁面有三個區段：Echo 用於時間、回授和濾波器，Tap tempo 用於律動和回聲模式，Style 用於飽和度、電平和風格選單。微調頁面包含其餘控制項。

Controls

ControlWhat it does
混合乾訊號與回音之間的平衡。
回聲時間延時時間。Time、Note、Dot 和 Trip 鍵將其設為毫秒，或設為直、附點或三連音的音符時值。在雙軌和乒乓模式下，這是左側時間。
回授有多少輸出被送回。範圍最高到 200%，迴路經過軟限制，因此不會失控。
LowCut / HighCut移除回音中低於 10 Hz 到 2 kHz 的低頻，以及高於 200 Hz 到 20 kHz 的高頻。
擴散Single 模式。讓兩側在時間上錯開，以取得寬度。在其他模式下，同一位置是 Ratio、Spacing 或 Delay R。
質數將延時時間吸附到質數個取樣。
點擊速度敲擊按鍵以設定左側回音時間。讀數顯示速度。
律動將奇數次重複提早或延後，最多為回音時間的 25%。刻度從 Shuffle 到 Swing。
感覺將整串回音提早（Rushin）或延後（Draggin），最多為回音時間的 25%。
模式回音配置：Single、Ratio、Quad（四個抽頭）、Dual 或 Ping-pong。
飽和度重複的飽和度。
輸入只送入回音的電平，-24 dB 到 +24 dB。乾訊號不受影響。
輸出回音的電平，-18 dB 到 +18 dB。
老化風格所模仿機器的老化程度：噪音和變暗。
Style menu回音所模仿的機器：Tape、Lo-Fi、Hi-Fi tape、Bucket brigade、Analog、Digital、Clean、Phaser、Shifter、Pitch、Reverse 或 Detune。
磁帶選擇一種經過量測的磁帶迴路音色：Off、Ping-pong tape、Studio tape 或 Studio tape hot。
Classic / MeasuredTweak 頁面。當 Tape 選單為 Off 時，Measured 會在 Tape 風格下執行測得的磁帶級：輸出和循環的音色、磁帶的嘶聲，以及抖晃（wow）的延遲。它會多用一點 CPU。新的實例從 Measured 開始。0.1.27 之前儲存的專案和預設集會載入為 Classic，聽起來與之前相同。
時鐘Tweak 頁面。調變會以回音時間自身的一部分來擺動回音時間，在最大深度時最多 50%，左右兩側一起，就像時脈驅動的延遲線。預設為關閉。

Tips

  • 編輯器下方的狀態列會說明所選的風格。
  • 微調頁面增加寬度、擴散、風格的調變（磁帶的 Wow 和 Flutter）、閃避、重音、交叉饋送和平衡，另有凍結、帶有專屬敲擊編輯器的節奏模式，以及在專案速度與回聲自身 BPM 之間的選擇。
  • 回授高於 100% 會持續堆疊，所以請慢慢調高。
