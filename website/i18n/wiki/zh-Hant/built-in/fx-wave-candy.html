Wave Candy 是放在插入插槽上用來觀看訊號的顯示器。它不會改變聲音。新建的從頻譜模式開始；來自匯入的 FL Studio 專案的 Wave Candy，則以其儲存狀態顯示的模式開啟。顯示區下方的旋鈕隨模式而變。

Controls

ControlWhat it does
模式Auto、示波器、頻譜、頻譜圖、峰值電平表或向量示波器。Auto 在高而窄的視窗顯示電平表，在寬而矮的視窗顯示示波器，其他情況顯示頻譜。
保持凍結顯示。在顯示區按滑鼠中鍵效果相同。
增益顯示增益，-24 dB 到 +24 dB。所有模式。
示波視窗示波器。顯示的時間長度，2 ms 到 500 ms。
分離示波器。將左右分開繪製。
同步示波器。將波形鎖定在波形週期的零交越處。
速率頻譜和頻譜圖。頻譜下降或頻譜圖捲動的速度。
範圍頻譜和頻譜圖。顯示的電平範圍，30 dB 到 120 dB。
音階頻譜和頻譜圖。頻率刻度，從接近線性到對數，後者能顯示更多低頻細節。
加權頻譜和頻譜圖。從平坦到每八度 +3 dB 的傾斜。
解析度頻譜和頻譜圖。分析大小，1024 到 16384 點。
電平表模式峰值表。Peak、PPM、RMS、VU 或 LUFS。
Peak hold / Decay峰值表。峰值保持多久，0 到 5 秒，以及長條下降多快，每秒 3 到 60 dB。
電平表刻度峰值表。顯示的最低電平，-24 dB 到 -96 dB。
Persistence / Thickness向量示波器。拖尾的長度和點的大小。
染色波形的色調。所有模式。

Tips

  • 在 Auto 模式下，把視窗拉高變窄會得到表頭，拉寬變矮則得到示波器。
