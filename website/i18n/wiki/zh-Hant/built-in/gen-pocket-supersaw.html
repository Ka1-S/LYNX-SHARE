Pocket SuperSaw 是最多 8 個聲部的虛擬類比合成器。每個聲部是由 1 到 12 個失諧鋸齒波加上一個低八度副鋸齒波疊成，或是 SuperSync 振盪器，一串像硬同步一樣掃頻的脈衝。FL Studio Mobile 專案 (.flm) 的 SuperSaw 模組就是載入到這個引擎上，它也出現在外掛選擇器的 Pocket SuperSaw 下。新通道從 FL Studio Mobile 的預設值開始。這一頁是簡單的旋鈕清單，每個參數一個（共 59 個），而不是 FL Studio Mobile 自己的面板。

Controls

ControlWhat it does
Osc unison, Osc unison detune, Osc unison detune curve, Osc unison pan每個聲部的鋸齒波數量（1 到 12）、它們失諧的幅度（最多 100 音分）、失諧如何分布在各個鋸齒波上，以及它們的聲像有多寬。
Osc pulse width, Osc pulse mode, Osc sub levelPulse mode 把每個鋸齒波變成脈衝波，並有其寬度。Osc sub level 是低一個八度的鋸齒波的電平。
Osc re-trig phases, Osc phases offsetre-trig 開啟時，每個音符都以相同的相位開始鋸齒波，所以每個音符的拍頻都相同。關閉：每個音符以隨機相位開始。
SuperSync mode, Osc sync, Osc sync pulse width, Osc sync attack / decay / sustain / release, Osc sync EG amount, Osc sync kbd dirSuperSync 振盪器及其自己的波封，該波封會掃過同步量。
Filter cutoff, Filter resonance, Filter kbd, Filter vel4 極階梯式低通濾波器，最高 20 kHz，並有琴鍵和力度追蹤。
Filter EG attack / decay / sustain / release, Filter EG amount濾波器波封。量是雙極性的，-100 % 到 +100 %。
Level EG attack / decay / sustain / release, Level, Pan音量波封，以及輸出電平和聲像。波封時間從 0 到 31 秒。
LFO shape, LFO rate, LFO mode, LFO beat, LFO amount, LFO dest, LFO fade in每個聲部一個 LFO：Sine、Ramp、Square 或 Random；Free、One shot 或 Tempo sync。LFO dest 可選 Cutoff、Resonance、Pitch、Sync、Pulse width、Detune、Level 或 Pan。
Arp rate, Arp range, Arp mode琶音器：Off、Up、Down、Up-down、Up-down (ends twice) 或 Random，最多可延伸 3 個額外八度。
Monophonic mode, Number of voices, Slide held mode, Slide time, Slide time static演奏一個聲部或最多 8 個，以及音符如何滑音。
Transpose, Pitch bend range移調 -12 到 +12 個半音。彎音輪可彎 1 到 12 個半音。
Distortion, Output trimtanh 失真，以及 -18 到 0 dB 的輸出微調。
Delay time, Delay feedback, Delay mix, Delay filter與速度同步的立體聲延時，1/4 beat 到 1 beat，迴路中有低通或高通濾波器。
Mod wheel amount, Mod wheel dest調變輪移動的對象：Cutoff、Resonance、Sync、Pulse width、Detune、Level、Pan、LFO amount 或 LFO rate。

Tips

  • 每個旋鈕都可以自動化。鋸齒波經過頻寬限制，所以高音不會產生混疊。
  • 起始相位和 Random LFO 來自每個實例各自擁有的產生器，所以算繪結果永遠不會與某次 FL Studio Mobile 的算繪逐取樣相同。能量和頻譜則是相同的。
  • 通道的音高旋鈕、微調、Mono 和 Porta，以及鋼琴捲軸的滑音音符，對聲部的作用方式與它們在 FL Studio 的產生器上相同。
