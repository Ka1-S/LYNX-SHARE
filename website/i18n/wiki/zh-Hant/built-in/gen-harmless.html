Harmless 是加法式產生器，建立在同名 FL 外掛的引擎上：每個聲部最多 528 個正弦波分音，由色彩、音色等化器、諧波遮罩、濾波器、共振、移相和撥奏來塑形，後面接著由合唱、延時、殘響和壓縮器組成的機架。沒有 FL Studio 也能加入，這時它會從 LYNX SHARE 自己的預設集庫開始。機架中的壓縮器從你自己的 FL Studio 安裝載入預設集；沒有這些預設集，壓縮器就保持關閉。

ControlWhat it does
Prot and Sub 1, 3, 4Prot 是低次諧波保護。三支 Sub 推桿設定次諧波 1、3 和 4 的電平。
音色等化六支頻段推桿，用來提高或降低音色的各個區域。
顏色音色的基礎頻譜：Saw、Bright saw、Brighter saw、Dephased saw、Dephased saw 2、Squaretooth、Squaretooth 2、Mole、Double saw、Triple saw、Triple saw 2 或 Custom。
相位分音的相位隨機程度。
諧波遮罩十二支推桿設定遮罩，Mix 決定套用多少，LFO 決定 LFO 對該混合移動多少。
波封Trem 是立體聲顫音深度。Att、Dec 和 Rel 是音量波封。Vel 按鈕把力度送到起音，把釋放力度送到釋放。
撥弦Decay 設定撥奏衰減，附有力度用的 Vel 按鈕。Alt 選擇替代撥奏模式，Mask 讓撥奏使用諧波遮罩，Rel 只在釋放時套用撥奏。
音量主音量推桿，附有把力度送到音量的 Vel 按鈕。
音高音高是主音高，Det 是失諧。Grit 是粗糙感，Vib 是抖音深度，LFO 是音高 LFO 的量。滑奏和單聲道切換滑音和單音演奏；Time 是滑音時間，附有 Vel 按鈕。
濾波器Type 選擇 17 種濾波器形狀之一，Freq 和 Width 設定其頻率和寬度，Oct 或 Hz 設定刻度。Env 是濾波器波封的量，附有 Att、Dec，各有一個 Slope 旋鈕，以及一個 Adapt 開關。LFO 和 Key 設定 LFO 和琴鍵追蹤的量。
Res, Ofs, Osc, Res typeRes 是共振量，Ofs 是其偏移，Osc 是自振盪電平。Res type 選擇九種形狀之一，各有自己的 Oct 或 Hz 刻度。Motion 追蹤濾波器頻率的運動，Adapt 調整共振寬度。
齊奏Order 設定齊奏聲部的數量，Type 是 Classic、Uniform 或 Blurred。推桿設定聲像、音高厚度、相位和變化；Vel 把力度送到音高厚度。
移相Type 選擇十種形狀之一，附有 Oct 或 Hz 刻度。Mix、Width 和 Offset 設定移相器，它們下方的兩個 LFO 旋鈕移動寬度和偏移，Speed 是運動速度，Key 讓偏移隨琴鍵追蹤。
和聲器Mix、Width 和 Str（強度）、LFO 的量，以及寬度用的 Vel 按鈕。Type 是 Oct up、Oct up +1、Oct up +2、Harm up 或 Harm up +1。Position 把它放在濾波器之前、移相器之前、撥奏之前，或最後。
LFOShape 從 14 種來源中選擇，包括波形，以及濾波器包絡、濾波器頻率、聲部隨機、力度和音高。Att 是 LFO 起音，Speed 是它的速度，Global 切換全域 LFO。
效果器合唱類型附有混合；延時類型附有音量（輸入電平）、Fb 和時間；殘響類型附有濕；壓縮類型附有電平。HQ 切換高品質，Threaded 切換多執行緒處理。

Tips

  • 選擇壓縮類型時，會從 FL Studio 安裝的 Harmless 資料夾載入該類型的預設集。
  • 機架依序執行合唱、延時、殘響、壓縮器。
  • 引擎無法讀取的匯入通道，會退回到簡單的合成器近似。
