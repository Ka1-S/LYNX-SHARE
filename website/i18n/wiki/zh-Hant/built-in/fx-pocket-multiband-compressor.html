Pocket Multiband Compressor 以兩個 24 dB 分頻點把聲音分成低、中、高三個頻段，並各自獨立壓縮。它的壓縮比作用於訊號的振幅而不是分貝，所以在相同數字下比一般壓縮器更柔和。FL Studio Mobile 專案 (.flm) 的 Multiband Compressor 模組就是載入到這個引擎上，所有數值原樣複製，它也可以加到任何混音器插入槽。它的編輯器是一頁簡單的旋鈕，每個頻段（Low、Mid、High）一排名稱。

Controls

ControlWhat it does
主增益整個效果器的輸出電平，-24 dB 到 +24 dB。
低分頻點低頻段與中頻段之間的分頻點，20 Hz 到 10.2 kHz。
高分頻點中頻段與高頻段之間的分頻點，20 Hz 到 10.2 kHz。
獨奏Off、Low、Mid 或 High：只播放該頻段。這個控制項是 LYNX SHARE 自己的；FL Studio Mobile 在此處保存的是編輯器設定，.flm 匯入時會將它重設為 Off。
乾聲混合把未壓縮的頻段加到已壓縮的頻段上，0 到 100%，用於平行壓縮。
Low / Mid / High input gain進入頻段的增益，-24 dB 到 +24 dB。它同時送入偵測器和音訊。
Low / Mid / High threshold高於此電平時頻段才會被壓縮，-48 dB 到 0 dB。
Low / Mid / High ratio1 到 31。

Low / Mid / High release放開的速度，10 ms 到 1 s。
Low / Mid / High gain頻段的輸出增益，-24 dB 到 +24 dB。

Tips

  • 被旁通的頻段也會略過它的輸入增益、輸出增益和寬度。
  • 起音和釋放在每種取樣率下都以 44.1 kHz 計算，FL Studio Mobile 也是如此。在 48 kHz 或 96 kHz 時，它們比顯示值更短。
  • 製作新的混音時，Fruity Multiband Compressor 或 Prism Multiband 是更完整的工具。這個效果器的用途是讓 FL Studio Mobile 的歌曲聽起來和在手機上時一樣。
