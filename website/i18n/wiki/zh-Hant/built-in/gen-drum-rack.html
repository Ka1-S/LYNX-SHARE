Drum Rack 是一種 Instrument Rack，它的鏈就是打擊墊。每個打擊墊接收一個音符，並播放其鏈中的樂器和效果。從外掛選擇器中以 Drum Rack 加入。新的 Drum Rack 只顯示打擊墊和裝置窗格，並選取 C1。把取樣拖放到打擊墊上，或在空的打擊墊上按右鍵來載入取樣或樂器。Ableton Live 套裝 (.als) 中的 Drum Rack 會開啟為一個 Drum Rack，連同它的打擊墊、傳送和回傳鏈；匯出 Live 套裝時也會寫出 Drum Rack。

Controls

ControlWhat it does
Pads打擊墊的 4 x 4 檢視，上方有顯示全部 128 個打擊墊的概覽條：點擊、拖曳或捲動它即可移動檢視範圍。已填入的打擊墊會顯示其名稱，以及 M（靜音）、播放按鈕和 S（獨奏）。把一個打擊墊拖到另一個上即可互換。一次放入多個取樣會填入連續的打擊墊。
Pad menuRename (Ctrl+R)、Delete、Save as Default Pad、Next Similar (Ctrl+Right)、Previous Similar (Ctrl+Left)、Save as Similarity Reference (Ctrl+Up)、Return to Reference (Ctrl+Down)，以及 LYNX SHARE 的項目 Duplicate 和 Choke。
M, V, P, C, I-O, S, R, D左側的欄位可顯示或隱藏巨集、巨集變體、打擊墊、鏈清單、I-O、傳送與回傳欄，以及裝置窗格。
Receive, Play, Choke每個打擊墊：它回應的傳入音符（或 All）、它交給樂器的音符，以及它的互斥群組（None 或 1 到 16）。互斥群組中的打擊墊會切斷該群組中的其他打擊墊。
Send-a, Send-b每個打擊墊送到每條回傳鏈的電平。
Return chains由傳送饋入的音訊效果鏈，顯示為 a、b 等，例如「a Mix Bus」。
音訊輸出到打擊墊的鏈輸出到哪裡：Rack Output，或直接進入一條回傳鏈。
Vel, Chain, Hide鏈清單下方 LYNX SHARE 新增的功能：力度區和鏈選擇區。打擊墊取代琴鍵區的位置。
巨集最多 16 個巨集旋鈕，有 Map、Rand 和 Macro Variations，與 Instrument Rack 相同。

Tips

  • Sampler 通道選單中的 Slice to Drum Rack 會把其取樣的每個切片放到一個打擊墊上。對播放清單中的音訊片段使用 Slice to New MIDI Track...，會依瞬態、小節、音符值或彈性標記切片，放進新的 Drum Rack 通道，並附帶播放這些切片的樣式。
  • 在片段啟動版面中，Drum Rack 通道的鋼琴捲軸會為每個已填入的打擊墊顯示一列有名稱的列。在樣式版面中，它保留鋼琴琴鍵，並在琴鍵上標示打擊墊名稱。
  • Next Similar 和 Previous Similar 會使用瀏覽器的 Find similar samples 索引來更換打擊墊的取樣。
  • 匯出 .als 時，鏈中 LYNX SHARE 內建的效果不會寫出；打擊墊上的 Sampler 會寫成 Live 的 Simpler。尚未有任何 Live 開啟過匯出的 Drum Rack。
