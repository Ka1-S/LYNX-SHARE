Pocket Limiter Classic 是簡單的峰值限制器。當較大聲的一側超過閾值時，增益會立刻下降，然後沿著平滑的曲線恢復。FL Studio Mobile 專案（.flm）的 Limiter（舊版）模組就是載入這個引擎，它也可以加到任何混音器插槽。

Controls

ControlWhat it does
閾值高於此電平就會降低增益，-24 到 0 dB。
釋放時間增益恢復所需的時間，顯示為 0 到 100%。範圍從 0% 時約 200 ms 到 100% 時 1 秒。
輸出增益輸出電平，-24 到 +12 dB。

Tips

  • 輸出會依閾值被降低的量放大，所以被限制的峰值會以 Output Gain 的電平輸出。降低 Threshold 會讓訊號變大聲。
  • 沒有前視，也不增加延遲。峰值越過閾值時，增益會在一個取樣內下降。
