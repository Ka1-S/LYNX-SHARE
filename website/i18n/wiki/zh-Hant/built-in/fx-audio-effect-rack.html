Audio Effect Rack 是建立在 Patcher 機架模式上的混音器插槽效果器。每條鏈得到相同的輸入，各鏈的輸出會被加總，鏈之間有延遲補償。可從混音器插槽的外掛選擇器以 Audio Effect Rack 加入，或把現有的插槽組成一個機架。Ableton Live 套裝（.als）中的 Audio Effect Rack 會以機架開啟，匯出 Live 套裝時機架也會寫回去。

Controls

ControlWhat it does
Chain list每條鏈一列，有名稱、音量、聲像、一個開關和用於獨奏的 S。鏈選單有 Add chain、Rename、Duplicate、Delete、Move up 和 Move down。
裝置所選鏈的效果器。新增選單提供 Effects、Plugin effects 和 Racks，所以機架可以巢狀嵌套。
Chain, Hide顯示或隱藏鏈選擇區編輯器。Audio Effect Rack 沒有琴鍵區或力度區。
Zone bars拖曳條或它的兩端來設定鏈的區域，範圍 0 到 127。上方的條設定淡化，淡化會縮放鏈的輸出。
鏈選擇器拿來和各區域比較的數值。可以用巨集來驅動它。
巨集最多 16 個旋鈕，每個都有名牌和數值。+ 和 - 顯示更多或更少：1、2、4，依此類推，最多到 16。
映射對應模式。每個巨集會有一個 Map 按鈕，開啟由各條鏈、其裝置和參數、Chain Volume、Chain Pan 和 Chain Selector 組成的選單。對應清單顯示 Macro、Path、Name、Min 和 Max，並有 Invert Range 和 Delete。
隨機給每個已對應的巨集一個隨機值。巨集的選單有 Exclude Macro from Randomization。
巨集變體New 會儲存巨集的數值。每個變化版本有 Launch、Overwrite、Rename、Duplicate 和 Delete。
組合到音訊效果機架在混音器插槽選單中：把效果器移進只有一條鏈的新機架。Group all into Audio Effect Rack 會移動整條插槽鏈。聲音保持不變，被移動參數的自動化會驅動機架的巨集。
取消編組在只有一條鏈的機架的混音器插槽選單中：把它的裝置放回插槽。

Tips

  • 在沒有淡化就結束的區域之外，鏈的輸入會關閉，所以它的尾音會自然消散。
  • 從 Live 套裝匯入的機架，會保留它的鏈、區域、鏈音量與聲像、巨集、變化版本和巢狀機架。鏈中的第三方外掛會保留。Live 自己的裝置會被捨棄，並列在匯入報告中。
  • Live 套裝中對應到 VST3 外掛參數的巨集對應不會保留。匯出時，鏈中的 LYNX SHARE 內建效果器不會寫出；只寫出 VST2 和 VST3 外掛以及巢狀機架。
  • 有一條以上鏈的機架不能使用 Ungroup。
