Pocket Reverb 是 FL Studio Mobile 目前的殘響模組，運行在 FL Studio Mobile 自己的板式殘響上。它使用舊版模組的控制項，板式殘響的早期反射和尾音為固定電平，並自行與乾訊號混合。FL Studio Mobile 專案 (.flm) 的 Reverb 模組就是載入到這個引擎上，所有數值原樣複製，它也可以加到任何混音器插入槽。它的編輯器是一頁簡單的旋鈕。

Controls

ControlWhat it does
衰減尾音的長度，0.1 s 到 20 s。旋鈕依三次方律變化，所以行程的大部分涵蓋較短的時間。
高頻阻尼高於此頻率時，尾音的高頻衰減得更快，0.5 kHz 到 22.1 kHz。範圍的最頂端顯示為 Off。
混合乾訊號與殘響的混合。低於中間時，乾訊號維持滿電平而殘響上升；高於中間時，殘響維持滿電平而乾訊號下降。在中間時兩者都是滿電平。
聲像調整殘響的聲像，而不是乾訊號的聲像。
ER早期反射的電平，0 到 100%，依平方律變化。
預延時殘響開始之前的時間，0 到 250 ms。
房間大小板式殘響的大小，1 到 100。
擴散回音模糊成平滑尾音的快慢，0 到 100%。
寬度殘響的立體聲寬度，0 到 200%。
低切切掉進入殘響的訊號的低頻，19 Hz 到 3000 Hz。範圍的最底端顯示為 Off。
高切切掉進入殘響的訊號的高頻，0.5 kHz 到 22.1 kHz。範圍的最頂端顯示為 Off。
調變速率尾音中調變的速度，0.1 Hz 到 10 Hz。
調變深度尾音中調變的量，0 到 100%。
濕聲增益殘響的整體電平，0 到 100%。
乾聲電平乾訊號的整體電平，0 到 100%。

Tips

  • 電平的變化會在幾毫秒內平滑過渡，所以移動 Mix、Pan、ER 或兩個電平時不會產生爆音。
  • 這個板式殘響不是 Fruity Reeverb 2：在相同設定下，它的低頻鳴響更久。
  • 調變尚未與 FL Studio Mobile 用耳朵比對過：測量時用到的專案都沒有使用它。
