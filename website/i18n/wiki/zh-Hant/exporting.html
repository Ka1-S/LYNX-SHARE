所有離開 LYNX SHARE 的內容都要經過 檔案 › 匯出。音訊格式（WAV、MP3、OGG、FLAC、AIFF 和 M4A）共用同一個匯出視窗。MIDI、FL Studio 專案、Ableton Live 套裝、DAWproject 檔案和壓縮專案在同一個選單中各有自己的項目。

把歌曲匯出成 WAV

  1. 選擇 檔案 › 匯出 › Wave檔案...。
  2. 讓 範圍 維持 歌曲（播放清單），檔案 維持 一個檔案（混音）。
  3. 選一個 位元深度：16 bits、24 bits 或 32 bits (float)。
  4. 把 尾音 設為 保留餘音，讓殘響和釋放在最後一小節之後自然消退。
  5. 按一下 匯出...，選擇名稱和資料夾，然後等待算繪完成。
  6. 完成後，LYNX SHARE 會告訴你檔案放在哪裡以及它的峰值電平。

Ctrl+R 會以你上次匯出的格式開啟視窗。Ctrl+Shift+R 則以 MP3 開啟。

這些按鈕用來選擇格式。只有系統有 AAC 編碼器時才提供 M4A：Windows 和 macOS 上有，Linux 上沒有。同時儲存 會用同一次算繪、以相同名稱寫出其他格式。

分軌與軌道

檔案 有三種分軌模式：

  • 每個混音插入軌一個（分軌）：每個有聲音的插入軌各一個檔案。
  • 每個通道一個（分軌）：每個有演奏的通道各一個檔案。
  • 每個通道一個，僅樂器（不含傳送和匯流排）。

勾選 同時匯出完整混音，就能在分軌之外同時得到完整混音。底部那一行會顯示將寫出多少個檔案。

當歌曲在段落軌中有段落時，每個段落一個檔案 會依段落把它切開，並以各段落的名稱命名每個檔案。匯出分軌時，每個段落有自己的一組檔案。

檔案 › 匯出 › 所有 Playlist 軌道 和 所有 Playlist 軌道群組 會為每條播放清單軌道或每個群組寫出一個檔案。在混音器的選單中，磁碟錄音 › 將錄音預備的軌道渲染為WAV檔案...（Alt+R）只為預備錄音的插入軌開啟匯出視窗。

匯出到 FL Studio、Ableton Live 和 DAWproject

.flp 是 FL Studio 2026 專案。取樣器、音訊片段、FL Studio 自己的產生器和效果器、第三方外掛、樣式、播放清單、混音器和自動化，都會連同設定一起轉過去。對於 FL Studio 沒有的東西，你可以在 算繪為音訊（聲音相同） 和 使用最接近的 FL 外掛（仍可編輯，聲音可能不同） 之間選擇。選第二種時，僅限 LYNX 的樂器會被略過。跟隨歌曲位置的調變器會變成自動化片段：同步的 LFO 會變成 FL Studio 的片段 LFO，步進、隨機來源和巨集會變成點。跟隨器、包絡、按鍵追蹤和力度會被略過。報告會列出哪些被算繪、取代或略過。詳情見從 FL Studio 轉換。

.als 包含每個通道一條 MIDI 軌道、音訊軌道、群組、回送、傳送、機架和鼓機架、帶有狀態的 VST2 和 VST3 外掛、標記，以及音量、聲像和速度的自動化。LYNX SHARE 自己的樂器和效果器不會被轉換，但它們的軌道和音符會保留。Helix 是例外：它會變成 Live 的 Wavetable。效果器參數的自動化和插入軌之間的路由會被捨棄。詳情見從 Ableton Live 轉換。

.dawproject 包含軌道、資料夾、片段、音符、帶變速標記的音訊、自動化、速度、標記、帶傳送的混音器，以及帶狀態的 VST3、VST2 和 CLAP 外掛。LYNX SHARE 自己的樂器和效果器會以 LYNX SHARE 能再次開啟的方式寫出。片段格線、其他編排和部分逐音符的細節會被略過，並由一份報告列出。

檔案 › 將副本儲存為 FL Studio Mobile 專案 (.flm)... 會寫出供 FL Studio Mobile 使用的 .flm，並把取樣複製到旁邊的 <name> Samples 資料夾。儲存前，視窗會像 檔案 › 為舊版 LYNX 儲存副本... 那樣列出副本會遺失的內容。.flm 保留音符和模式（FL Studio Mobile 每條軌道一個模式）、速度、每小節拍數、調性和和弦組、混音器的音量、聲像、靜音、獨奏以及到匯流排的傳送、FL Studio Mobile 自帶的樂器（MiniSynth、SuperSaw、GMSynth 和 Transistor Bass，以及 FL Studio 的 MiniSynth 和 Transistor Bass）、變成鼓組的鼓取樣器、變成含多個樂器的機架的 Layer、每個帶混合量的 Pocket (FLM) 效果器，以及帶音量、聲像、音高和反轉的音訊片段。它還會寫出 DW Sampler（含其區域）和 3x Osc，以及混音器音量和聲像、Pocket (FLM) 效果器、DW Sampler 和 GMSynth 自身數值的自動化片段。其他樂器（目前也包括 FL Studio Mobile 的 Slicer 和 SoundFont Player）的音符保留在 FL Studio Mobile 的 MiniSynth 上，沒有 FLM 模組的效果器和其他目標（如合成器自身的旋鈕和第三方外掛）的自動化會被省略，全部都會列出。

須知

  • 匯出 MP3、OGG、M4A 和 32 位元 WAV 時 抖動 是灰色的，除了 WAV 以外的所有格式，速度和標記選項也都是灰色的。
  • 選了 播放清單選取範圍 但播放清單中沒有選取範圍時，會算繪整首歌。視窗會提醒你。
  • 如果主控插入軌被靜音，視窗會警告檔案將是無聲的。
  • 同時寫出帶此混音的影片 只在專案有影片軌道時出現，而且需要 FFmpeg。
  • 透過硬體即時渲染 只在專案有啟用的硬體插入軌時出現。這種匯出需要和歌曲一樣長的時間。
  • 渲染為音訊（把插入軌轉成音訊片段）在這個版本中，播放時比它取代的插入軌大聲約 5 dB。
