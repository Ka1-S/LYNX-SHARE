播放清單是樣式變成歌曲的地方。它的軌道上有三種片段：樣式片段、音訊片段和自動化片段。按 F5 可顯示或隱藏它，按 Enter 可最大化或還原。

走帶有兩種模式。樣式模式會循環播放目前樣式。歌曲模式則播放播放清單。按 L 切換。

把樣式放進歌曲

  1. 按 F5 顯示播放清單。
  2. 在選擇面板中點擊一個樣式。選擇面板會列出專案的樣式、音訊和自動化，你點擊的那個會成為片段來源。
  3. 按 P 選用鉛筆。
  4. 在軌道上點擊以放置片段。按住按鈕不放並拖曳，可調整它的位置。
  5. 按 B 選用畫筆，沿著軌道拖曳，可把片段首尾相接地畫出來。
  6. 按 L 進入歌曲模式，再按 Space 播放。

音訊檔案可以從瀏覽器拖到播放清單上。

處理片段

  • 拖曳片段可移動它。按住 Shift 拖曳會做出一份複本。
  • 拖曳片段的尾端可調整大小。拖曳片段的開頭則是修剪，內容留在原位。
  • 在片段上按右鍵可刪除。按住 Ctrl 拖曳為選取。
  • 對片段按兩下可開啟它。
  • 片段左上角的按鈕會開啟片段選單（設為唯一、重新命名並上色、切碎，音訊片段還有：音高、適應速度、倒放）。
  • 音訊片段的選單依 FL Studio 的版面分成兩欄。左欄有 音訊片段 區段（預覽、已靜音、重新命名並設定顏色...、變更顏色...、隨機顏色、變更圖示...、選取來源通道、通道設定、設為唯一、選取所有相似的片段、Delete、屬性...）和 區域 區段（選取區域、切碎）。右欄有 取樣（設為唯一取樣、編輯取樣、從取樣中提取分軌、偵測速度、適應速度）、自動化（自動化 › 聲像 或 音量、交叉淡化至）和 淡入淡出（重設淡入淡出）。LYNX SHARE 自己的項目，例如 在此拆分、倒放、正規化 和 轉換為 MIDI，放在最後，位於一條線之下。
  • 自動化 › 聲像 或 音量 會在音訊片段所在的軌道上，為通道的 Levels 調整聲像或音量，建立一個與音訊片段等長的自動化片段。
  • 拖曳時按住 Alt 可忽略貼齊。
  • 音訊片段有淡化手柄和可上下拖曳的片段增益。在淡化手柄上按右鍵可開啟它的選單，其中有 建立交叉淡化。在增益手柄上按右鍵可使用 重設增益 和 正規化。
  • Shift+M 切換拉伸：開啟後，調整音訊片段大小時會拉伸音訊，而不是裁切。
  • Shift+Left 和 Shift+Right 把所選片段移動一個貼齊步長，Shift+Up 和 Shift+Down 移動一條軌道。Alt+Left 和 Alt+Right 以目前縮放下的一個螢幕像素移動，不貼齊。沒有選取片段時，會移動所有片段。
  • 音訊片段選單中的 設為唯一取樣 會給片段一個新檔案，內容是它播放出來的聲音，其音高、伸縮和反轉已經寫進音訊裡。
  • 有彎曲標記的音訊片段，會在上緣以小旗標顯示它們。把旗標往左右拖曳即可移動標記。

Edit 與 Select 選單

Playlist 的選單有 編輯 和 選取 子選單。編輯 包含片段指令：剪下、複製和貼上、向左移動、向右移動、上移、下移、設為唯一、設為唯一取樣、插入空白、刪除空白、合併指令和淡化選項。選取 有 依所選來源選取（Shift+C）、反選（Shift+I）、取消選取（Ctrl+D）、靜音的片段和重疊的片段，以及 魔術套索。開啟 魔術套索 後，不按按鈕，把滑鼠繞著片段移動成一圈，就能選取它們。

軌道

在軌道標頭中，點擊為選取，按住 Ctrl 點擊可加入或移除，按住 Shift 點擊可選取一個範圍，按右鍵開啟軌道選單。按住 Shift 並滾動滾輪，可將軌道上移或下移。軌道的燈用來靜音（點擊）或獨奏（按住 Ctrl 點擊或按右鍵）。拖曳兩條軌道之間的分隔線可調整其中一條的大小，按住 Shift 拖曳則調整全部。

Playlist 選單中的 檢視 決定軌道標頭顯示什麼：在音訊軌道上顯示控制項、在音訊軌道上顯示電平 和 在樂器軌道上顯示電平。

軌道選單中的 軌道模式 可把軌道設為 未分配、音訊軌道 或 樂器軌道，與 FL Studio 相同。音訊軌道 先列出 新增混音軌道，再依編號和名稱列出每個混音器插入軌。所選項目會套用到所有選取的軌道。樂器軌道 有 使用現有通道、更多外掛... 和通道機架的樂器清單。

軌道標題左上角的 + 會開啟相同的選項來建立新軌道：新增音訊軌道、更多外掛... 和各種樂器。在 + 上按右鍵會立即新增一個音訊軌道。

樣式區塊

在 Playlist 選單中開啟 Pattern 區塊（目前專案） 後，軌道下方的區段每個樣式有一列。在那裡，鉛筆放置一個區塊並沿著它的列拖曳，畫筆繪製區塊，橡皮擦刪除區塊。用任何工具按右鍵都會擦除。

標尺、循環和標記

  • 點擊標尺可設定歌曲位置。
  • 在標尺上按右鍵拖曳、按住 Ctrl 拖曳，或按兩下後拖曳，可做出時間選取範圍，它同時也是循環。按住 Shift 拖曳可移動它。
  • Ctrl+Ins 會在所有軌道上插入與時間選取範圍等長的空白，Ctrl+Del 則將其移除。
  • Alt+T 新增標記。點擊標記可跳到該處。
  • 按住 Ctrl 並滾動滾輪可縮放，按住 Alt 並滾動滾輪可改變軌道高度。

自動化

在旋鈕或推桿上按右鍵，選擇 建立自動化片段。片段會出現在播放清單上。用鉛筆拖曳它的點，在曲線上點擊可新增一個點。軌道下方的自動化軌道是選用的，預設為關閉。見自動化。

在某個點上按右鍵可看到它的選單。它的 模式 清單有 FL Studio 的 13 種曲線模式，用於結束於該點的線段：平滑、保持、三種單曲線、三種雙曲線、半正弦、階梯、平滑階梯、脈衝波 和 波浪。新的點會採用最後使用的模式。模式會從 .flp 檔案讀取，也會寫入 .flp 檔案。

編排

工具列中的編排框用來在不同編排之間切換。一個專案可以有多個編排。

須知

  • 只有在歌曲模式下才能聽到播放清單。在樣式模式下，不管軌道上有什麼，Space 播放的都是目前樣式。
  • 檢視 › 版面樣式 › 片段啟動工作流程 會在播放清單旁加上片段和場景的格線。它是選用的。見版面。
  • 同一個控制項上有多個重疊的自動化片段時，播放哪一個的選擇可能與 FL Studio 不同（0.1.25 版本說明）。
  • 與 FL Studio 相同，一個樣式一次只從一個片段播放。當同一樣式的較晚片段在任何軌道上開始時，較早的片段從該處起就不再開始新的音符。不同樣式的片段則一起播放。這適用於新專案和 FL Studio 專案。0.1.27 之前儲存的 .lynx 專案仍會完整播放每個片段。
  • 由已連結的 MIDI 控制器移動的速度，不會調整音訊片段的大小。
  • 在 Linux 上，影片需要 FFmpeg。
