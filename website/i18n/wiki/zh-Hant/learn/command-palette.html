命令面板

  1. 按 ?（或 Ctrl+Shift+Y，或點擊工具列中的放大鏡）。
  2. 輸入你想要的內容的幾個字母。清單包含每個動作及其快速鍵、每個選單項目及其位置、LYNX 額外功能的開關、設定頁面和你最近的專案。在任何語言下，動作都可以用英文名稱找到。
  3. 用方向鍵選擇一列並按 Enter，或按兩下它。Esc 關閉面板。

留意 CPU

  1. 工具列中的 CPU 表顯示專案在播放時佔用了多少音訊時間。
  2. 按兩下它可以開啟外掛效能監視器：每個外掛和通道目前、平均和尖峰的負載。

讓外掛休息

  • 工具 › 切換所有外掛的智慧停用 讓每個外掛在收到靜音且不發聲時暫停，和 FL Studio 的智慧停用一樣。
  • 在片段啟動版面中，對音軌標題按右鍵並選擇 停用軌道，可以卸載它的裝置，直到你再次需要為止。
