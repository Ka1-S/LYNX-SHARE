選擇簡易版面

  1. 啟動 LYNX SHARE。第一次啟動時，歡迎卡片會問你從哪裡轉過來。
  2. 點擊 BandLab、FL Studio Mobile 或 GarageBand。視窗會切換到簡易版面，鼓音軌上會放好一段起始節拍。

不使用歡迎卡片時，選擇 檢視 › 版面樣式 › 簡易工作流程，點擊 + 新增音軌，再點擊 鼓，然後選一段起始節拍。同一個選單可以隨時切換版面。專案維持原樣。

播放節拍

  1. 按工具列中的播放鍵，或按空白鍵。
  2. 再按一次即可停止。

時間軸下方的面板顯示所選的音軌。對於鼓音軌，它會開啟 鼓機 分頁。

修改節拍

  1. 點擊鼓機中的灰色方塊，就在那裡新增一個音。點擊亮著的方塊則刪除它。
  2. 每一列是套鼓中的一種聲音：大鼓、小鼓、踩鈸、拍手和打擊樂。
  3. 長度 設定樣式有幾個小節，搖擺 把每隔一步的音往後推。

每列旁邊的字母是它在電腦鍵盤上的按鍵：按下它即可播放那個聲音。

設定速度

  1. 上下拖曳速度，或按兩下它並輸入一個數字。
  2. 再播放一次節拍，聽聽新速度的效果。

接下來

  • 接下來：值得一試的 3 件事 卡片會自動勾掉每一步。開啟循環素材 會開啟循環面板：把循環拖到時間軸上。循環會跟隨專案的速度和調。
  • 在人聲音軌上錄下你的聲音。
  • 完成 把歌曲儲存為 WAV 或 MP3。

另見簡易版面和從 BandLab、FL Studio Mobile 或 GarageBand 轉過來。
