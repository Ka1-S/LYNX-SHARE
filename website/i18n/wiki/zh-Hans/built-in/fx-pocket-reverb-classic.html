Pocket Reverb Classic 是 FL Studio Mobile 较旧的混响模块，运行在 FL Studio Mobile 自己的板式混响上，其网络接近 Fruity Reeverb 2，但并不相同。原始信号始终以满电平通过，混响叠加在它之上。FL Studio Mobile 工程 (.flm) 的 Reverb（旧版）模块就是用它作为引擎加载的，每个数值都原样复制，它也可以添加到任何混音台插槽。它的编辑器是一页普通的旋钮。

Tips

  • 原始信号从不被降低：Dry off 和 Dry level 只改变额外的干信号副本，不改变直通的信号。
  • 在三个 Pocket 混响中，只有这一个带有静音开关和以 dB 表示的电平。Pocket Reverb 2 以百分比设置电平，Pocket Reverb 只有一个 Mix 旋钮。
  • 调制尚未与 FL Studio Mobile 做过听感对比：用于实测的工程都没有使用它。
