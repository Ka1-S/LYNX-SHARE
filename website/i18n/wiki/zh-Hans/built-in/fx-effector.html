Effector 把十二种效果类型放在一个 XY 板后面，同一时间只有一种类型生效。X 和 Y 设置它的两个参数，还可以用与工程速度同步的 LFO 来移动它们。它会从导入的 .flp 工程中载入 FL Studio Effector 的设置。

Controls

ControlWhat it does
Type buttonsDistort、Lo-fi、Flanger、Phaser、Filter、Delay、Reverb、Stereo、Trans、Grain、Vox 或 Ring。
X param / Y param所选类型的两个参数。它们的含义随类型而变。
XY板通过拖动同时设置 X 和 Y。
旁通旁通该效果。
干/湿效果在输出中所占的量。
Rate buttons (8/1 to 1/8)一个 LFO 周期的长度，以拍计，从八拍到八分之一拍。Delay 类型的回声时间取自此设置，Grain 的重复长度也是。
X mod / Y modLFO 移动 X 和 Y 的幅度。两者都是双极性的。
Sine / Saw / SquareLFO 波形。
速度缩短由速率按钮设定的 LFO 周期。
Gain (left)输入电平。
Gain (right)输出增益，-24 dB 到 +24 dB。

Tips

  • Distort：X 是量，Y 是音色。Lo-fi：X 让采样保持更久，Y 降低位深。Flanger 和 Phaser：X 是扫频位置，Y 是反馈。
  • Filter：X 在中点左侧是低通，右侧是高通，Y 是共振。Delay：X 是反馈，Y 在中点以下使回声变暗，在中点以上削去回声的低频。Reverb：X 是衰减，Y 是高频阻尼。
  • Stereo：X 是声像位置，Y 决定其中有多少变成电平差。Trans：X 是释音时间，Y 是每个 LFO 周期重复一次的门限的下降电平。Vox：X 选择元音，Y 缩放共振峰频率。Ring：X 是载波频率，范围从 32 Hz 到约 13.3 kHz。
  • Grain 在每个 LFO 周期重复一小段音频，不使用 X 和 Y。
