Harmless 是加法合成发生器，基于同名 FL 插件的引擎：每个声部最多 528 个正弦分音，由色彩、音色均衡、谐波遮罩、滤波器、共振、移相器和拨弦塑形，后面接一个由合唱、延时、混响和压缩器组成的机架。没有 FL Studio 也可以添加，此时它从 LYNX SHARE 自己的预设库开始。机架里的压缩器从你自己 FL Studio 安装中载入预设；没有这些预设时，压缩器保持关闭。

Controls

ControlWhat it does
Prot and Sub 1, 3, 4Prot 是低次谐波保护。三个 Sub 推子设置子谐波 1、3 和 4 的电平。
音色均衡六个频段推子，用来提高或降低音色的各个区域。
颜色音色的基础频谱：Saw、Bright saw、Brighter saw、Dephased saw、Dephased saw 2、Squaretooth、Squaretooth 2、Mole、Double saw、Triple saw、Triple saw 2 或 Custom。
相位分音的相位随机度。
谐波遮罩十二个推子设置遮罩，Mix 决定应用多少，LFO 决定 LFO 对这个混合量的移动幅度。
包络Trem 是立体声颤音的深度。Att、Dec 和 Rel 是音量包络。Vel 按钮把力度送到起音，把释放力度送到释音。
拨弦Decay 设置拨弦衰减，带一个 Vel 力度按钮。Alt 选择另一种拨弦模式，Mask 让拨弦使用谐波遮罩，Rel 只在释放时应用拨弦。
音量主音量推子，带一个把力度送到音量的 Vel 按钮。
音高Pitch 是主音高，Det 是失谐。Grit 是粗糙度，Vib 是颤音深度，LFO 是音高 LFO 的量。Porta 和 Mono 分别切换滑音和单音演奏；Time 是滑音时间，带一个 Vel 按钮。
滤波器Type 选择 17 种滤波器形状之一，Freq 和 Width 设置其频率和宽度，Oct 或 Hz 设置刻度。Env 是滤波器包络量，带 Att、Dec，各有一个 Slope 旋钮，另有 Adapt 开关。LFO 和 Key 设置 LFO 和按键跟踪的量。
Res, Ofs, Osc, Res typeRes 是共振量，Ofs 是它的偏移，Osc 是自振荡电平。Res type 从九种形状中选择，带自己的 Oct 或 Hz 刻度。Motion 跟踪滤波器频率的运动，Adapt 调整共振宽度。
齐奏Order 设置齐奏声部的数量，Type 为 Classic、Uniform 或 Blurred。推子设置声像、音高厚度、相位和变化；Vel 把力度送到音高厚度。
移相Type 从十种形状中选择，带 Oct 或 Hz 刻度。Mix、Width 和 Offset 设置移相器，它们下方的两个 LFO 旋钮移动宽度和偏移，Speed 是运动速度，Key 让偏移跟踪按键。
和声器Mix、Width 和 Str（强度），一个 LFO 量，以及一个用于宽度的 Vel 按钮。Type 为 Oct up、Oct up +1、Oct up +2、Harm up 或 Harm up +1。Position 把它放在滤波器之前、移相器之前、拨弦之前或最后。
LFOShape 从 14 种来源中选择，包括各种波形，以及 Filter envelope、Filter frequency、Voice random、Velocity 和 Pitch。Att 是 LFO 起音，Speed 是它的速度，Global 切换全局 LFO。
效果器合唱类型带 Mix；延时类型带 Vol（输入电平）、Fb 和 Time；混响类型带 Wet；压缩器类型带 Level。HQ 切换高质量，Threaded 切换多线程处理。

Tips

  • 选择压缩器类型时，会从 FL Studio 安装的 Harmless 文件夹中载入该类型的预设。
  • 机架按合唱、延迟、混响、压缩器的顺序运行。
  • 引擎无法读取的导入通道，会退回到简单的合成器近似音色。
