Fruity Love Philter 有八个单元。每个单元有输入电平、滤波器、波形整形器，以及带声像和音量的输出，并可以馈入下一个单元。每个单元的发音器会用样式包络、LFO、Mod X 和 Mod Y 控件以及包络跟随器来调制声像、音量、截止、共振、低通、带通和高通电平，以及波形整形器的混合。它会从导入的 .flp 工程中载入 FL Studio 插件的设置。

Controls

ControlWhat it does
Unit switches and tabs 1 to 8顶部的开关启用各个单元。标签页选择显示哪个单元。
IN: VOL插件输入进入此单元的电平。负值会反转相位。
Filter type and mode类型选择器选取滤波器。模式设置串联的级数：Off、Single、Dual、Triple、Alt dual 或 Alt triple。Off 只留下增益、声像和波形整形器。
CUT / RES单元滤波器的截止和共振（或宽度）。
ENV截止发音器的深度。
L / B / HSVF 类型的低通、带通和高通输出的电平。
ALT滤波器的另一种共振或宽度响应。
WS: AMP, MIX, MODE波形整形器：进入整形器的增益、与未整形信号的混合，以及单极或双极曲线。
OUT: PAN, VOL该单元在插件输出中的声像和电平。
NEXT此单元的输出有多少馈入下一个单元。为零时各单元并行运行。
Articulator editor标签页 PAN、VOL、CUT、RES、LOW、BAND、HIGH、WS 和 WMIX 选择目标，PAT、LFO、MOD X、MOD Y 和 IEF 选择下方绘制曲线的来源。
X / Y pad设置 Mod X 和 Mod Y。SMOOTH 使它们的变化平滑滑动。
VOL / LFO / IEF sliders主电平、主 LFO 电平，以及进入包络跟随器的电平。
IEF: USE1, ATT, REL包络跟随器的起音和释音。USE1 让它跟随单元 1 的输出，而不是插件输入。
CENTER去除输出的直流偏移。
过采样引擎的过采样阶数。渲染时会加倍。

Tips

  • 新实例中只启用第一个单元。
  • 每个已启用单元的输出都会求和，所以 NEXT 为零时，多个单元相当于并行滤波器。
