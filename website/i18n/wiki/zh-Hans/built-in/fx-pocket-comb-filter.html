Pocket Comb Filter 给干信号加上带反馈的短延时，使声音在调谐的音高上持续共鸣。音高可以手动设置，可以跟随通道机架上按住的最低音，也可以跟随从输入中检测到的音高。FL Studio Mobile 工程 (.flm) 的 Comb Filter 模块就是用它作为引擎加载的，每个数值都原样复制，它也可以添加到任何混音台插槽。

Controls

ControlWhat it does
模式Manual、Lowest Note 或 Detect Pitch。Manual 使用 Pitch，吸附开启时使用 Pitch oct 和 Pitch note。Lowest Note 跟随通道机架上按住的最低音，松开后保留最后一个音。Detect Pitch 跟随输入的音高。
音高吸附关闭时 Manual 模式下的频率，1 Hz 到 2.50 kHz，遵循四次方律。
反馈有多少延时信号被反馈回去，0 到 100 %。数值越高，共鸣越长。
混合加到干信号上的梳状信号电平，0 到 100 %。干信号保持满电平。
偏移在 Lowest Note 和 Detect Pitch 模式下，把音高移动 -2 到 +2 个八度。
平滑音高滑向新值的缓慢程度，0 到 100 %。
吸附开启：Manual 模式播放由 Pitch oct 和 Pitch note 设置的音符。关闭：使用 Pitch 频率。
极性每一侧的反馈符号：Both +、Left -、Right - 或 Both -。
不对称-5.0 到 +5.0 %。按此幅度降低左侧的频率并升高右侧的频率（负值则相反）。
音高八度音符的八度，-1 到 6。
音高音符音名，C 到 B。尚未按住任何键时，Lowest Note 也从这个音符开始（默认 E3）。

Tips

  • Lowest Note 读取通道机架所有通道上按住的键。在 FL Studio Mobile 中，它只读取该效果器所在的机架。
  • Detect Pitch 对有音高的声音效果最好。对鼓或噪声，它可能锁定到错误的音高，FL Studio Mobile 自己的检测器在这里也并不稳定。
  • 调谐遵循 FL Studio Mobile 的延时回路，在同一个音符上，它比理想的梳状滤波器偏差约 19 音分。
  • 这个效果器是一页普通的旋钮，而不是 FL Studio Mobile 的面板。
