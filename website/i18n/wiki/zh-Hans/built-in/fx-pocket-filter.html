Pocket Filter 是由一对、两对或四对相同的滤波级组成的共振滤波器。FL Studio Mobile 工程 (.flm) 的 Filter 模块就是用它作为引擎加载的，每个数值都原样复制，它也可以添加到任何混音台插槽。

Controls

ControlWhat it does
频率截止频率或中心频率，16 Hz 到约 20 kHz。
Q共振，显示为 0.80 到 2.80，遵循平方律。
类型LP（低通）、BP（带通）或 HP（高通）。LP 占范围的下半部分，BP 占上半部分，HP 只占最顶端。
斜率24 dB/O、48 dB/O 或 96 dB/O。24 dB/O 占范围的下半部分，48 dB/O 占上半部分，96 dB/O 只占最顶端。

Tips

  • 与 FL Studio Mobile 一样，低通每一对滤波级把电平降低约 2 dB：在 24、48 和 96 dB/O 时分别约为 2、4 和 8 dB。带通会按 Q 值抬高中心，最多约 9 dB。
  • Slope 的改变立即切换，低通电平只在下一次改变 Frequency、Q 或 Type 时才跟上。FL Studio Mobile 的做法相同。
  • 每一对滤波级使声音延迟一个采样，这不会报告给延迟补偿，与 FL Studio Mobile 相同。
