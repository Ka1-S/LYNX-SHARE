Pocket Waveshaper 让声音通过七种曲线之一来使其失真。曲线之前有两个滤波器，之后有一个三段音色部分，LFO 可以移动两个形状控件。FL Studio Mobile 工程 (.flm) 的 Waveshaper 模块就是用它作为引擎加载的，每个数值都原样复制，它也可以添加到任何混音台插槽。

Controls

ControlWhat it does
形状曲线：Soft、Tanh、Crossover、Fold、Octaver、Rectify 或 CrossFold。
自动增益开启时，用一个缓慢的跟随器让整形后信号的电平与输入电平相匹配。
X / Y所选曲线的两个参数。它们改变什么取决于形状。显示 0 到 100。
驱动进入曲线的增益，0 dB 到 40 dB。显示 0 到 100。
后置增益整形后信号的增益，-18 dB 到 +18 dB。
立体声扩展在曲线之前给左右信号加上符号相反的偏移，使两侧的失真不同。四次方律，显示 0 到 100。
混合干信号和整形后信号的等功率混合。显示 0 到 100。
High cut / Low cut曲线之前的双极点滤波器，各为 20 Hz 到 20 kHz。
低音曲线之后位于 100 Hz 的钟形频段。显示 -18 dB 到 +18 dB。
Mid freq / Mid gain曲线之后的钟形频段，500 Hz 到 2 kHz。增益显示 -18 dB 到 +18 dB。
高音曲线之后位于 3.3 kHz 的高频搁架。显示 -18 dB 到 +18 dB。
LFO 形状Sine、Saw 或 Square。
LFO 同步开启时使用 LFO rate，并跟随歌曲位置。关闭时使用自由运行的 LFO rate。
LFO 速率开启 LFO sync 时 LFO 周期的长度：1/8、1/4、3/8、1/2、3/4、beat、2 beats、bar、2 bars 或 4 bars。
LFO 自由速率关闭 LFO sync 时 LFO 的速度，0.02 Hz 到 9.92 Hz，遵循三次方律。
LFO to X / LFO to YLFO 移动 X 和 Y 的幅度，0 到 100 %。在 100 % 时，它向两个方向各移动控件范围的一半。

Tips

  • LFO 以及 X 和 Y 的值每个歌曲 tick（一拍的 1/96）更新一次，而不是每个采样更新。
  • 曲线之后的直流滤波器会去掉不对称形状和 Stereo spread 产生的偏移。
