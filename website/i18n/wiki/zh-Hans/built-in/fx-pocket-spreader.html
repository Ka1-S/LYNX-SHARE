Pocket Spreader 通过延时侧信号并加回去来拓宽立体声像，并让低于 Low bypass 频率的部分不参与拓宽。它运行的是与 Spreader 相同的引擎，只是套用了 FL Studio Mobile 的控件范围。FL Studio Mobile 工程 (.flm) 的 Spreader 模块就是用它作为引擎加载的，每个数值都原样复制，它也可以添加到任何混音台插槽。

Controls

ControlWhat it does
宽度显示 0.0 到 2.0。到 1.0 为止，它会拉长拓宽信号的延时，最长约 6.35 ms。高于 1.0 时，延时保持在最大值，只有拓宽信号的电平继续上升。
低频旁通低于此频率的信号会从拓宽中分离出来，10 Hz 到 10 kHz。
单声道低频低于 Low bypass 频率的部分有多少以单声道输出。连续，显示 0 到 100。
分离侧信号的电平，-100 % 到 +100 %。在中心显示 Original。在 -100 % 时侧信号被去掉，在 +100 % 时加倍。

Tips

  • 该效果器向延迟补偿报告约 6.35 ms 的延迟（44.1 kHz 下为 280 个采样）。
  • 控件经过平滑，所以重置之后效果器会在几毫秒内淡入。
