Strike Shaper 是 LYNX 自己的瞬态整形器。它比较同一信号的两条包络，并根据它们的比值设置增益，所以对轻的和响的敲击反应相同，也不需要阈值。用 Attack 让起音更硬或更软，用 Sustain 拉长或缩短尾音。它没有前瞻，也不增加延迟。

Controls

ControlWhat it does
起音提高或降低每次敲击的起音，-15 dB 到 +15 dB，印出的刻度在 0 dB 附近更细。
延音提高或降低每次敲击之后衰减的尾音，-24 dB 到 +24 dB。
输出增益输出电平，-20 dB 到 +6 dB，旋钮最上方为 0 dB。
On / Power开启或关闭效果。ON 键和 Power 指示灯作用相同。
链接开启时，两个声道共用一个检测器和一个增益，所以立体声像不会移动。关闭时，左右分别整形。
检测器高通只作用于检测器的高通滤波器，Off 或 20 Hz 到 1 kHz。它避免低频触发整形，不会对音频本身滤波。
保护输出端的软削波器。低于约 -3 dBFS 时它不处理信号，也绝不让信号超过 0 dBFS。
混合干信号和整形后信号之间的混合，0 到 100 %，用于并行处理。Output gain 和 Guard 位于它之后。
SIG / OVL lamps有输入信号时 SIG 亮起。输出峰值到达满刻度时 OVL 亮起。
Attack / Sustain rows两排指示灯实时显示每个增益移动了多少。左边的蓝色是衰减，右边的红色是提升，档位为 1、3、6、10 和 15 dB。

Tips

  • Attack 和 Sustain 为 0 dB、Mix 为 100 %、Output gain 为 0 dB 时，信号原样通过。
  • 较大的 Attack 提升在一次敲击上最多可增加 +15 dB。如果 OVL 灯亮起，请开启 Guard 或降低 Output gain。
  • 把鼠标停在旋钮上可读出它的值。右键单击旋钮可打开它的数值菜单。
