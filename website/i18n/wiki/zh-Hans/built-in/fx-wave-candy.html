Wave Candy 是一个显示器，放在插入轨插槽上观察信号。它不改变声音。新建的从频谱模式开始，来自导入 FL Studio 工程的 Wave Candy 则按其保存的状态打开对应的显示模式。显示区下方的旋钮随模式而变。

Controls

ControlWhat it does
模式Auto、Oscilloscope、Spectrum、Spectrogram、Peak meter 或 Vectorscope。Auto 在高而窄的窗口里显示电平表，在宽而矮的窗口里显示示波器，其他情况显示频谱。
保持冻结显示。中键点击显示区效果相同。
增益显示增益，-24 dB 到 +24 dB。所有模式。
示波窗口示波器。显示的时间长度，2 ms 到 500 ms。
分离示波器。把左右分开绘制。
同步示波器。把波形轨迹锁定到波形的周期上，在过零点处。
速率频谱和声谱图。频谱下落或声谱图滚动的快慢。
范围频谱和声谱图。显示的电平范围，30 dB 到 120 dB。
音阶频谱和声谱图。频率刻度，从接近线性到对数，对数能显示更多低频细节。
加权频谱和声谱图。从平坦到每倍频程 +3 dB 的倾斜。
分辨率频谱和声谱图。分析大小，1024 到 16384 点。
电平表模式峰值表。Peak、PPM、RMS、VU 或 LUFS。
Peak hold / Decay峰值表。峰值保持多久，0 到 5 秒，以及条形下落的快慢，每秒 3 到 60 dB。
电平表刻度峰值表。显示的最低电平，-24 dB 到 -96 dB。
Persistence / Thickness矢量示波器。拖尾的长度和点的大小。
染色轨迹的色相。所有模式。

Tips

  • 在 Auto 模式下，把窗口拉得高而窄就得到电平表，宽而矮就得到示波器。
