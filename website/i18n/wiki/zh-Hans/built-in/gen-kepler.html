Kepler 是一个复音发生器，基于同名 FL 插件的引擎构建：八个声部，每个有一个振荡器（锯齿波、带脉宽调制的脉冲波、副方波和噪声）和一个梯形低通滤波器，之后是高通滤波器和合唱，另有一个 LFO、一个包络和一个琶音器。LFO 形状和噪声表在运行时从你自己的 FL Studio 安装里的引擎 DLL 读取，该 DLL 必须是受支持的版本，本程序并不附带。找不到该文件时，编辑器会显示提示，通道保持静音，设置保留。新实例从你自己的 FL Studio 安装中该插件的预设开始，所以添加它需要已安装 FL Studio；否则 Add 菜单会把它列为需要 FL Studio。导入 .flp 时如果没有该文件，通道会改用更简单的合成器转换。

Controls

ControlWhat it does
Hold, Octave, Volume保持按钮、-1、0 或 +1 的八度移动，以及主音量。
琶音On 按钮、Mode（Up、Up/dn 或 Down）、Range（1、2 或 3）、Sync 和 Rate。
LFO带 Sync 开关的 Rate、Delay、Auto 或 Man 触发模式（带 Trig 按钮），以及一个 Phase 开关和用于重触发相位的推子。
DCO: LFO, PWMLFO 是振荡器上的 LFO 量。PWM 设定脉宽，由 LFO 驱动、手动（Man）设定，或由包络驱动。
DCO: Pulse, Saw, Sub, Noise打开脉冲波、锯齿波和副波的按钮，一个副波电平推子和一个噪声电平推子。
HPFFreq 设定高通滤波器。
VCF低通滤波器的 Freq（截止）和 Res（共振），带 + 或 - 极性开关的 Env 量，LFO 量和 Kybd（按键跟随）。
VCA放大器跟随包络（Env）或琴键门（Gate）。
包络包络的 A、D、S 和 R 推子。
合唱Off、I、II 或 I+II。

Tips

  • 切断组不会切断这个发生器。
  • 自振荡的预设相对 FL 渲染的相位可能会漂移。
