Pocket Stereoizer 先对单声道和信号做延时和滤波，再把结果加到左声道并从右声道减去，从而拓宽声音。用在单声道或较窄的音源上。FL Studio Mobile 工程 (.flm) 的 Stereoizer 模块就是用它作为引擎加载的，每个数值都原样复制，它也可以添加到任何混音台插槽。

Controls

ControlWhat it does
强度加入信号的电平，遵循平方律。显示 0 到 100。接近 0 时拓宽被关掉。
音色单声道和信号的延时，0.5 ms 到 50 ms，遵循三次方律。显示 0 到 100。
聚焦作用于延时信号的单极点滤波器。显示 -100 % 到 +100 %。中心以下是低通，中心以上是高通。
左右延迟把一侧延时最多 25 ms，遵循三次方律。显示 -100 % 到 +100 %。偏中心左侧延时左声道，偏中心右侧延时右声道。
声像线性平衡，-100 % 到 +100 %。压低相反的一侧，并渐变到新值。

Tips

  • 加入的信号在两侧符号相反，所以当 L/R delay 和 Pan 都在中心时，输出相加为单声道会互相抵消。
