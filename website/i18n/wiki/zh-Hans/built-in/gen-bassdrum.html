BassDrum 是一个底鼓发生器，基于同名 FL 插件的引擎构建：两个表格振荡器带下降的音高扫频，加上一个咔嗒声、一个可选的噪声采样层、一级驱动和一个 42 Hz 高通。振荡器表格和噪声采样在运行时从你自己的 FL Studio 安装的 BassDrum 文件夹读取，本程序并不附带。新实例从你自己的 FL Studio 安装中该插件的预设开始，所以添加它需要已安装 FL Studio；否则 Add 菜单会把它列为需要 FL Studio。导入 .flp 时，如果没有那个文件夹，通道会改用更简单的正弦加扫频转换。

Controls

ControlWhat it does
输出输出电平。它会乘以音符力度。
采样整个声部的重采样比率，从四分之一到四倍，音高和长度一起移动。弹奏的琴键会以同样方式移调这个鼓。
时长鼓的电平斜坡的长度。为 0 时，鼓是静音的。
Base, Peak, Slide音高扫频。Base 是它最终落在的频率（16 到 256 Hz），Peak 是高于它的扫频深度，Slide 是扫频持续多久。
Var base, Var peak, Var slide第二个振荡器的 base、peak 和 slide 相对于第一个的偏移，从一半到两倍。
变化 相位推迟第二个振荡器的起点，最多 350 个采样（按内部 44.1 kHz 采样率）。
驱动声部之后饱和器的量。
超低音输出处 42 Hz 高通的共振。
起音平滑打击的起始。数值越高，上升越慢。
Click, Freq, Cut一个咔嗒声，在开头调制振荡器的相位。Click 是它的电平，Freq 是它的速度，Cut 是它的起始相位。
Noise display显示正在使用的噪声采样，无法读取时显示 Needs FL Studio's files。
Noise: A, D, S噪声层包络的起音、衰减和延音。
Noise: Start让噪声相对振荡器延后，或让振荡器相对噪声延后，两个方向各最多 100 ms。在中间位置时两者同时开始。
Noise: Pitch, Filter, Mix噪声采样的播放速度（下降两个八度到上升两个八度）、它的低通滤波器和它的电平。

Tips

  • 音符长度不会缩短一次打击：音符关闭被忽略，声部在约 23 ms 的静音后结束。
  • 声部在内部以 44.1 kHz 运行，并重采样到工程采样率。
