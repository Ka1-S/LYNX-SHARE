Echoform 是一款回声，有十二种风格和五种回声布局。Main 页面有三个部分：Echo 用于时间、反馈和滤波器，Tap tempo 用于律动和回声模式，Style 用于饱和、电平和风格菜单。其余控件在 Tweak 页面。

Controls

ControlWhat it does
混合干信号与回声之间的平衡。
回声时间延时时间。Time、Note、Dot 和 Trip 键把它设为毫秒，或设为直线、附点或三连音的音符值。在 Dual 和 Ping-pong 模式下，它是左边的时间。
反馈输出有多少回馈。范围可达 200%，回路经过软限制，因此保持有界。
LowCut / HighCut滤除回声中低于 10 Hz 到 2 kHz 的低频，以及高于 200 Hz 到 20 kHz 的高频。
扩散Single 模式。在时间上错开两侧以获得宽度。在其他模式下，同一位置是 Ratio、Spacing 或 Delay R。
质数把延时时间吸附到素数个采样。
点击速度点按该键设定左回声时间。读数显示速度。
律动把奇数次重复提前或推后，最多为回声时间的 25%。刻度从 Shuffle 到 Swing。
感觉把整串回声提前（Rushin）或推后（Draggin），最多为回声时间的 25%。
模式回声布局：单音、压缩比、四路（四个抽头）、双轨或乒乓。
饱和度重复的饱和。
输入只送入回声的电平，-24 dB 到 +24 dB。干信号不受影响。
输出回声的电平，-18 dB 到 +18 dB。
老化该风格所模仿机器的磨损：噪声和变暗。
Style menu回声所模仿的机器：Tape、Lo-Fi、Hi-Fi tape、Bucket brigade、Analog、Digital、Clean、Phaser、Shifter、Pitch、Reverse 或 Detune。
磁带选择一种实测的磁带环路音色：Off、Ping-pong tape、Studio tape 或 Studio tape hot。
Classic / MeasuredTweak 页面。当 Tape 菜单为 Off 时，Measured 在 Tape 风格下运行实测磁带级：包括输出和回路的音色、磁带嘶声，以及 wow 的滞后。它会多占用一点 CPU。新实例以 Measured 起步。0.1.27 之前保存的工程和预设会以 Classic 载入，听起来与之前相同。
时钟Tweak 页面。调制会让回声时间按自身的一个比例摆动，满深度时最多 50%，两侧同时摆动，就像时钟驱动的延时线。默认关闭。

Tips

  • 编辑器下方的状态行会描述所选的风格。
  • Tweak 页面增加了 Width、Diffusion、风格的调制（磁带是 Wow 和 Flutter）、Ducking、Accent、X-feed 和 Balance，另有 Freeze、带自己点按编辑器的 Rhythm 模式，以及在工程速度与回声自带 BPM 之间的选择。
  • 反馈高于 100% 会持续累积，所以请慢慢调高。
