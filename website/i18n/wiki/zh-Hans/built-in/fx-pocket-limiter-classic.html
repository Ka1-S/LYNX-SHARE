Pocket Limiter Classic 是一个简单的峰值限制器。当较响的一侧超过阈值时，增益立即下降，然后沿着平滑的曲线恢复。FL Studio Mobile 工程 (.flm) 的 Limiter (legacy) 模块就是用它作为引擎加载的，它也可以添加到任何混音台插槽。

Controls

ControlWhat it does
阈值高于它时增益被降低的电平，-24 到 0 dB。
释放时间增益恢复所用的时间，显示为 0 到 100%。从 0% 时约 200 ms 到 100% 时 1 秒。
输出增益输出电平，-24 到 +12 dB。

Tips

  • 输出会按阈值降低的量放大，所以被限制的峰值会出现在 Output Gain 的电平上。降低 Threshold 会让信号更响。
  • 没有前瞻，也不增加延迟。峰值越过阈值时，增益在一个采样内下降。
