Slicex 在 A 和 B 两个盘上各载入一个采样，把它切成区域，并让每个区域由一个琴键播放。它能打开 .flp 中 FL Studio 的 Slicex 的设置，并在导出时写回。新建的实例从空的盘开始，不需要 FL 安装中的任何文件。自身不带区域的 WAV 文件在载入时会按其敲击点切片。

Controls

ControlWhat it does
Master slidersMaster level、Master randomness level、Master LFO level 和 Master pitch，负 1200 到 1200 音分。
MODULATION一个带 X 和 Y 滚轮的 X / Y 面板。SMOOTH 使调制变平滑。
LAYERING同一琴键上的区域如何一起播放：All、All (gain-compensated)、Velocity-mapped、Modulation X-mapped、Modulation Y-mapped、Random、Cycle 或 Song time-synced。SAME DECK 只叠加同一个盘的区域。
CROSSFADE叠加的区域之间的曲线：none、linear、balanced curve、unbalanced curve 或 adding。
REGION SETTINGS当前区域、它的 OUT（输出轨偏移）和 CUT（切断组），以及四行：AMP（声像和音量）、FILTER（截止和共振）、SPEED（音高）和 START（延迟和采样起点）。每一行有一个 ART 组号和一个量。
ARTICULATOR选择 8 个发音器组之一。它的 FILTER 有类型 (LP、BP、BS、HP)、模式 (OFF、x1、x2、x3) 以及 ENV、CUT 和 RES 滚轮。
PAN, VOL, CUT, RES, SPEED, START曲线编辑器所显示的目标。
ENV, LFO, VEL, MOD X, MOD Y, RAND显示的发音器部分：它的包络、它的 LFO，或来自力度、调制 X、调制 Y 或随机性的映射。
TEMPO, GLOBALTEMPO 让曲线的时间跟随速度。GLOBAL 让 LFO 相位随歌曲运行。
ATT, DEC, SUS, REL缩放包络的起音、衰减和释音时间，并偏移它的延音电平。
SPD, TNS, SKEW, PWLFO 的速度、张力、偏斜和脉宽。
Deck tool rowLoop、Play / pause、Stop、File、Regions、Select 和 Zoom 菜单，单盘或双盘显示，以及当前的盘，A 或 B。
文件New、Load sample... 和 Save sample as...，后者会保存该盘的 WAV 及其区域。
区域Add region...、Add marker...、Set loop、Delete、Rename all...、Set all cut groups to... 和 Freeze all。
键盘弹奏琴键，并显示哪些琴键有区域。它的菜单有 Assign current region to this key 和 Select region assigned to this key。旁边的数字设置基础八度。
选项Sample start covers whole length、Link velocity to volume、Loop half of regions 和 HQ envelopes。

Tips

  • 把采样拖到盘上即可载入。只有 WAV 文件才会得到自动切片的标记，因为标记保存在该盘的 WAV 中。
  • 区域的菜单有 Delete、Clone as region、Turn into marker、Rename...、Trigger note 和 Zoom on。
  • 颜色为偶数的音符播放 A 盘，颜色为奇数的音符播放 B 盘。颜色 14 和 15 倒放。
  • FL 的 Snap 和 View 菜单目前还没有，File 和 Regions 菜单也只有上面列出的条目。
