MIDI Effect Rack 是基于 Patcher 机架模式的通道机架发生器。它的链只包含 MIDI 效果器。每条链得到相同的音符，各链演奏的内容会送到机架的子通道，与 Layer 通道一样。可从插件选择器中以 MIDI Effect Rack 添加。同样的 MIDI 效果器链也可以放在 Instrument Rack 链的开头。

Controls

ControlWhat it does
设置子通道在链菜单中：把通道机架中选中的通道设为此机架播放的子通道。Show children 会再次选中它们。
Chain list每条链一行。链菜单有 Add chain、Rename、Duplicate、Delete、Move up 和 Move down。
设备所选链的 MIDI 效果器，从 MIDI effects 菜单添加。
Key, Vel, Chain, Hide选择区域编辑器：琴键区、力度区、链选择区，或无。区域范围为 0 到 127。
Zone bars拖动一个条或它的两端来设置区域。条的上方窄带设置淡化。在 MIDI Effect Rack 中，三种淡化都会缩放音符的力度。
链选择器与链选择区比较的值。可以用宏来驱动它。
链选择器也过滤 MIDI 控制链菜单中的一个开关，随机架一起保存。
宏最多 16 个旋钮。+ 和 - 显示更多或更少。
映射映射模式。每个宏都有一个 Map 按钮，打开后是各链的设备参数和 Chain Selector 的菜单。映射列表显示 Macro、Path、Name、Min 和 Max。
随机给每个已映射的宏一个随机值，被排除在随机化之外的宏除外。
宏变体存储并启动成组的宏数值：New、Launch、Overwrite、Rename、Duplicate 和 Delete。

Tips

  • 在设置子通道之前，机架的标题栏会说明目前还没有子通道，机架也不播放任何内容。
  • 这些链没有音量或声像：MIDI Effect Rack 只传递音符。
  • LYNX SHARE 的 MIDI Effect Rack 会作为 MIDI Effect Rack 写入导出的 Live 套装，其中不含内置的 MIDI 效果器。打开 Live 套装时，Live 的 MIDI Effect Rack 不会被转换；它们会列在导入报告中。
