Dashboard 是一个本身不发声的通道。你布置自己的控件面板，并把每个控件链接到工程中别处的旋钮。它也可以发送 MIDI。.flp 工程中的 FL Studio Dashboard 会以同类面板打开。

Controls

ControlWhat it does
编辑编辑模式：拖动控件可移动它，右键点击可重命名、调整大小或删除它。
添加添加旋钮、滑块、按钮、复选框或 XY 面板。
MIDI设定 Dashboard 发送所用的端口、通道、程序和存储组。
发送MIDI按控件设置：发送控制变化、RPN、NRPN、通道压力或音符消息。
重命名给控件起自己的名字。
大小改变控件的大小。

Tips

  • 新的 Dashboard 起初有两个旋钮：Knob 1 和 Knob 2。
  • 每个控件都是一个输出：右键点击旋钮，选择“链接到内部控制器”（Link to internal controller）。
