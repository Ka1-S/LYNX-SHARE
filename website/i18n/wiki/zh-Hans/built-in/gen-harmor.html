Harmor 是一个加法发生器，基于同名 FL 插件的引擎构建：A 和 B 两个部分，每个部分每个齐奏声部最多有 520 个正弦分音，另有图像合成和一个效果器机架。Add 菜单把它标为 beta。新实例从你自己的 FL Studio 安装中该插件的预设开始，所以添加它需要已安装 FL Studio；否则 Add 菜单会把它列为需要 FL Studio。机架里的压缩器同样需要该安装中的预设。编辑器显示 A 或 B 部分的控件以及 Global 和 FX 条；FL 的音色和滤波器形状菜单、EQ、包络和图像页面在这里不能编辑。

Controls

ControlWhat it does
A and B tabs, A / B slider标签页选择面板显示哪个部分。滑块设定 A 部分与 B 部分之间的混合。
音色Start 和 Rand 设定相位起点和相位随机性，Mix 是音色混合，三个 Sub 推子设定副音电平，Prot 是低次谐波保护，Clip 是削波阈值。
电平FX 是该部分的效果发送，Vol 是它的音量，Env 是音量包络的量，Auto 是自动增益。
模糊Mix 设定模糊混合，Att 和 Dec 是时间模糊的起音和衰减，Harm 是谐波模糊。
颤音Depth 是颤音深度，Gap 是它的立体声间距。
棱镜Amt 是棱镜量；它从中心向两个方向都起作用。
和声器Amt、Width 和 Str 设定和声器的量、宽度和强度。
揉弦颤音的 Depth 和 Speed。
齐奏Order 为 1 到 9，Type 为 Classic、Blurred、Uniform、Random 或 Hz，Alt 切换交替相位。推子设定齐奏的音高、声像和相位。
Filter 1 and Filter 2Freq 和 Width 设定滤波器，Env 是包络量，Key 是按键跟踪，Oct 或 Hz 是音阶，Adapt 是自适应包络。
Res, Width, Ofs, Osc, Mix每个滤波器的共振由 Res（量）、Width、Ofs（偏移）、Oct 或 Hz 音阶和一个用于自适应宽度的 Adapt 开关设定。滤波器 1 上的 Osc 是自振荡。滤波器 2 上的 Mix 是滤波器 1 与滤波器 2 之间的混合。
拨弦Time 是拨弦时间。
移相Mix、Width、Ofs（偏移）、Speed 和 Key（按键跟踪），带 Oct、Hz 或 Harm 音阶。
全局Legato 和 Porta 开关连奏和滑音，Vel 让滑音跟随力度。Pre 和 Post 是效果之前和之后的音量，Pitch 是全局音高，LFO 是全局 LFO 量。
X, Y, Z and the pad调制值 X、Y 和 Z。面板同时设定 X 和 Y。
效果Delay 开关带 Fdbk（反馈）和 Vol；Reverb 开关带 Wet。

Tips

  • 重合成图像（载入时分析的采样）会被忽略：该部分改为播放它的音色。
  • 引擎不认识的滤波器、共振或相位器形状，会让该级关闭。
  • 随机取值在每个实例中使用固定种子，而 FL 以时钟为种子。
