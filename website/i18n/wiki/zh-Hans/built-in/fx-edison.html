Edison 是放在混音台插槽中的音频编辑器。它把插槽的输入原样传出，在 Record 开启时录制该输入，并把自己的回放加到输出中。一条轨道上可以有多个 Edison 插槽。可从插槽的插件列表添加，也可使用混音台轨道菜单：Open audio editor (Ctrl+E) 会把它放进第一个空插槽，Open audio editor and record (Shift+E) 还会为它设好录制准备，Record mode 为 On play，5 min，Append 关闭，Slave 开启。它的窗口就是 LYNX SHARE 音频编辑器，并加入了插槽的录制控件。关闭窗口后录制仍会继续。.flp 工程中的 Edison 插槽会作为 Edison 打开，并带有其设置和音频。

Controls

ControlWhat it does
录制根据模式录制插槽的输入。快捷键 R。
Now, On input, Input, On play录制模式。Now 立即开始。On input 在输入超过噪声阈值时开始，并保留此前 0.1 s。Input 只在听到输入时录制，静音 1 s 后暂停。On play 在歌曲播放时录制，歌曲位置每次跳转时添加一个 Song jump 标记，所以循环播放的歌曲会得到一段录音，每遍一个标记。新插槽以 On input 起步。
最长录制时间Forever、1、3、5、10、30 或 60 min。新插槽以 30 min 起步。
追加开启：新录音接在已有音频之后。关闭：替换已有音频。默认开启。
同步Slave playback to host：歌曲播放时，音频按歌曲时间播放。快捷键 H。Record 菜单中还有 Ignore own selection。
输入静音不传出插槽的输入，只输出 Edison 的回放。快捷键 I。
循环循环回放。快捷键 L。
吸附吸附到网格、区域、采样或过零点，快捷键 1 到 4。
拖动把采样或选区以 WAV 形式拖到播放列表或通道机架上。右键单击会把它复制到编辑器的剪贴板。
发送作为音频片段发送到播放列表，发送到所选通道，或发送到一个新的 Sampler 通道。
触发音符在区域的菜单中：与该区域关联的音符。Regions › Assign trigger notes to all... 和 Assign all 可为每个区域设置音符。

Tips

  • 音频以 WAV 文件保存在工程的 recordings 文件夹中，而不是工程文件内部。
  • 在只有背景噪声的选区上使用 Tools › Acquire noise threshold，可设置 On input 和 Input 所监听的电平。
  • Tools › Macros › Remove all Edison instances 会移除工程中的每个 Edison 插槽。
  • 在 LYNX SHARE 中创建的插槽不会在导出时写入 .flp。来自 .flp 且未被编辑过的 Edison 插槽会保留 FL Studio 的数据。
  • 触发音符与区域一起保存，并由音频脚本读取。尚不支持通过音符播放区域。
