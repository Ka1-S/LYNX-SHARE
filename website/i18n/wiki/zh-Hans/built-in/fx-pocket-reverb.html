Pocket Reverb 是 FL Studio Mobile 当前的混响模块，运行在 FL Studio Mobile 自己的板式混响上。它使用旧模块的控件，板的早期反射和尾音保持固定电平，并自行与干信号混合。FL Studio Mobile 工程 (.flm) 的 Reverb 模块就是用它作为引擎加载的，每个数值都原样复制，它也可以添加到任何混音台插槽。它的编辑器是一页普通的旋钮。

Controls

ControlWhat it does
衰减尾音的长度，0.1 s 到 20 s。旋钮遵循立方律，所以大部分行程对应较短的时间。
高频阻尼高于此频率时，混响尾音的高频衰减得更快，0.5 kHz 到 22.1 kHz。范围顶端显示为 Off。
混合干声与混响的混合。低于中间位置时，干声保持满电平而混响上升；高于中间位置时，混响保持满电平而干声下降。在中间位置，两者都是满电平。
声像对混响做声像，而不是干信号。
ER早期反射的电平，0 到 100%，遵循平方律。
预延时混响开始之前的时间，0 到 250 ms。
房间大小板的大小，1 到 100。
扩散回声融合成平滑尾音的快慢，0 到 100%。
宽度混响的立体声宽度，0 到 200%。
低切切除进入混响的信号的低频，19 Hz 到 3000 Hz。范围底端显示为 Off。
高切切除进入混响的信号的高频，0.5 kHz 到 22.1 kHz。范围顶端显示为 Off。
调制速率尾音中调制的速度，0.1 Hz 到 10 Hz。
调制深度尾音中调制的量，0 到 100%。
湿声增益混响的总体电平，0 到 100%。
干声电平干信号的总体电平，0 到 100%。

Tips

  • 电平变化会在几毫秒内平滑过渡，所以移动 Mix、Pan、ER 或两个电平时不会产生爆音。
  • 这块板不是 Fruity Reeverb 2：在相同设置下，它的低频共鸣更长。
  • 调制尚未与 FL Studio Mobile 做过听感对比：用于实测的工程都没有使用它。
