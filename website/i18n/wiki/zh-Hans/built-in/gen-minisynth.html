MiniSynth 是一个发生器，基于同名 FL 插件的引擎构建：带噪声的表格振荡器、一个 4 极滤波器、放大器和滤波器包络、一个 LFO，以及按固定顺序排列的失真、延时、移相和合唱。波表在运行时由你自己的 FL Studio 安装里的 oscdata.dat 构建，本程序并不附带。新实例从你自己的 FL Studio 安装中该插件的预设开始，所以添加它需要已安装 FL Studio；否则 Add 菜单会把它列为需要 FL Studio。导入 .flp 时如果没有该文件，通道会改用更简单的内部合成器转换。

Controls

ControlWhat it does
Page tabsOscillator、Amplifier、Filter、Filter env、LFO 和 Effects。每个标签页显示一组控件。
Waveform, Transpose, Modifier, Noise振荡器页面。菜单选择十种振荡器类型之一（Saw、Saw + saw、Pulse、Square + saw、Square + square、Supersaw、Bell、Deaf saw、Saw spread、Saw spread 2）。Transpose 移动音高，Modifier 改变所选波形，Noise 添加噪声。
Voice mode, Slide timePoly、Mono 或 Lead，以及音符之间的滑音时间。
Mod wheel, Amount把调制轮送往 Filter 或 LFO，按设定的量。
放大器放大器包络的 Attack、Decay、Sustain 和 Release 推子，并显示其形状。
滤波器一个同时设定 Cutoff 和 Resonance 的面板，同样的两个值也有旋钮，另有 Keyboard 和 Velocity 跟踪。
滤波器包络Attack、Decay、Sustain 和 Release 推子，以及一个双向起作用的 Amount 旋钮。
LFO形状（Sine、Saw 或 Square）、Rate、目标（Filter、Frequency 或 Osc. modifier）和 Amount。
失真On 开关、Overdrive 和 Decimator。
延时On 开关、Time、Feedback、Filter 和 Mix。
合唱On 开关、Rate、Mod（深度）和 Mix。
移相On 开关、Speed、Width、Feedback、Mix 和 Freq。

Tips

  • 噪声、抖动、漂移和随机相位来自每个实例各自拥有的发生器，所以与任何一次 FL 渲染都不同。
