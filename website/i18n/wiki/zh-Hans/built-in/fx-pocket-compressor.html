Pocket Compressor 压低轨道中响亮部分的电平。带保持的峰值检测器读取两个声道中较响的一个，并对两个声道施加同一个增益。FL Studio Mobile 工程 (.flm) 的 Compressor 模块就是用它作为引擎加载的，每个数值都原样复制，它也可以添加到任何混音台插槽。

Controls

ControlWhat it does
Thresh压缩开始的电平，-40 dB 到 0 dB。
压缩比1:1 到 20:1，遵循平方律。范围顶端显示为 +inf，会把电平保持在阈值。
起音检测器跟随上升电平的快慢，0 到 50 ms，遵循平方律。
释音保持时间过后，被保持的峰值下降的快慢，10 ms 到 500 ms，遵循平方律。
电平输出增益。开启 Auto gain 时显示为 -20 dB 到 +20 dB，关闭 Auto gain 时，同样的旋钮行程对应 0 dB 到 +40 dB。
保持释音开始之前，检测器保留峰值的时间，0 到 50 ms，遵循平方律。
自动增益加入根据 Thresh 和 Ratio 算出的补偿增益，使满刻度输入输出时仍为满刻度。
输入增益只作用于送入检测器的信号的增益，-20 dB 到 +20 dB。它不改变音频本身的电平。
RMS为兼容而保存。FL Studio Mobile 从不开启它，所以它始终显示 Off，也没有作用。

Tips

  • 切换 Auto gain 会使 Level 读数移动 20 dB，输出电平也随之移动。改动之后请检查 Level。
  • 没有前瞻，也没有延迟。
