Sawer 是一个减法发生器，基于同名 FL 插件的引擎构建：一个锯齿波振荡器加一个副锯齿波，硬同步，噪声，一个带低通、带通、高通和陷波输出的 4 极滤波器，之后是合唱、相位器、延时和混响，还有六槽调制矩阵和一个琶音器。振荡器周期在运行时从你自己的 FL Studio 安装的 Sawer 文件夹里的 data.saw 读取，本程序并不附带。找不到该文件时，编辑器会显示提示，通道保持静音，设置保留。新实例从你自己的 FL Studio 安装中该插件的预设开始，所以添加它需要已安装 FL Studio；否则 Add 菜单会把它列为需要 FL Studio。

Controls

ControlWhat it does
Voices, Bend复音数（4 到 24 个声部）和弯音范围（关闭，或 1 到 12）。
主控电平、声像，以及音量包络的 A、D、S、R 推子。
音高Coarse（移调）和 Fine 调音。
滑音Rate 或 Time 模式、Always 或 Held 琴键模式，以及滑音 Time。
声部Poly 或 Mono、八度器 Off 或 On，以及齐奏重触发的 Free 或 Sync。
齐奏1、2、4 或 8 个声部，带 Detune 和 Spread（声像）。
振荡器噪声电平，以及带 On 开关的 Sync 频率。
副锯齿第二个振荡器的 Level、Phase、Harmonic（1/4 到 4 的比率）和 Detune。开关选择 Free 或 Sync 重触发、+ 或 - 极性，以及 Saw 或 Pulse 波形。
滤波器Cutoff、Reso、Key（按键跟踪）和 Vel（力度跟踪），带 Low、Band、High 和 Notch 模式。
滤波器包络A、D、S、R 和 Amount，送往 Cutoff、Sync、Sub phase 或 Pitch。
LFOSpeed、Attack、Release 和 Amount；Free 或 Sync 重触发、Hz 或 Beat 计时、Inv、波形（Tri、Saw、Square 或 S&H）和目标（Cutoff、Sync、Sub phase、Pitch、Noise、Volume 或 Pan）。
Chorus and PhaserChorus 有开关、Depth、Rate 和 Mix。Phaser 有开关、Center、Rate、Depth、Fdbk 和 Mix。
Delay and ReverbDelay 有开关、Left 和 Right 时间、Fdbk、Mod、LoCut、HiCut 和 Mix。Reverb 有开关、Decay、HiCut、Damp 和 Mix。
调制六个槽位。每个有来源（Velocity、Aftertouch、Pitch wheel 或某个 MIDI CC）、一个量旋钮，以及从插件参数中选取的目标。
琶音On 开关、模式（Up、Down、Up/dn 或 Rnd）、1 到 4 的范围，以及 1/32 到 3/4 的音符分段。

Tips
