Pocket SuperSaw 是最多 8 个声部的虚拟模拟合成器。每个声部是 1 到 12 个失谐锯齿波的叠加，带有低一个八度的副锯齿波，或者是 SuperSync 振荡器，这是一串像硬同步一样扫动的脉冲。FL Studio Mobile 工程 (.flm) 的 SuperSaw 模块就是用它作为引擎加载的，它也出现在插件选择器的 Pocket SuperSaw 下。新通道以 FL Studio Mobile 的默认值起步。页面是一份普通的旋钮列表，每个参数一个（共 59 个），而不是 FL Studio Mobile 自己的面板。

Controls

ControlWhat it does
Osc unison, Osc unison detune, Osc unison detune curve, Osc unison pan每个声部的锯齿波数量（1 到 12）、它们的失谐幅度（最多 100 音分）、失谐如何分布在各锯齿波上，以及它们的声像宽度。
Osc pulse width, Osc pulse mode, Osc sub levelPulse mode 把每个锯齿波变成脉冲波，并带有脉宽。Osc sub level 是低一个八度的锯齿波的电平。
Osc re-trig phases, Osc phases offset开启 re-trig 时，每个音符都让锯齿波从相同的相位开始，所以每个音符的拍频相同。关闭：每个音符从随机相位开始。
SuperSync mode, Osc sync, Osc sync pulse width, Osc sync attack / decay / sustain / release, Osc sync EG amount, Osc sync kbd dirSuperSync 振荡器及其自己的包络，包络用来扫动同步量。
Filter cutoff, Filter resonance, Filter kbd, Filter vel4 极梯形低通滤波器，最高 20 kHz，带有键盘跟踪和力度跟踪。
Filter EG attack / decay / sustain / release, Filter EG amount滤波器包络。量是双极性的，-100 % 到 +100 %。
Level EG attack / decay / sustain / release, Level, Pan音量包络，以及输出电平和声像。包络时间从 0 到 31 秒。
LFO shape, LFO rate, LFO mode, LFO beat, LFO amount, LFO dest, LFO fade in每个声部一个 LFO：Sine、Ramp、Square 或 Random；Free、One shot 或 Tempo sync。LFO dest 可选 Cutoff、Resonance、Pitch、Sync、Pulse width、Detune、Level 或 Pan。

Transpose, Pitch bend range移调 -12 到 +12 个半音。弯音轮弯曲 1 到 12 个半音。
Distortion, Output trimtanh 失真和 -18 到 0 dB 的输出微调。
Delay time, Delay feedback, Delay mix, Delay filter与速度同步的立体声延时，1/4 拍到 1 拍，回路中带有低通或高通滤波器。
Mod wheel amount, Mod wheel dest调制轮控制的对象：Cutoff、Resonance、Sync、Pulse width、Detune、Level、Pan、LFO amount 或 LFO rate。

Tips

  • 每个旋钮都可以自动化。锯齿波是带限的，所以高音不会产生混叠。
  • 起始相位和 Random LFO 来自每个实例各自拥有的生成器，所以渲染结果不会与某次 FL Studio Mobile 的渲染逐采样一致。能量和频谱则是一致的。
  • 通道的音高旋钮、微调、Mono 和 Porta，以及钢琴卷帘的滑音音符，对声部的作用与它们对 FL Studio 发生器的作用相同。
