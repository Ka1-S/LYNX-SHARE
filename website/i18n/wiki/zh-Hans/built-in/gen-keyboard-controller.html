Keyboard Controller 把输出设为你为最后弹奏的琴键所画的值。它不发声；你把它的输出链接到另一个控件。你用鼠标在键盘上方画出这些值。

Controls

ControlWhat it does
Key values键盘上方的条形；每根条形的高度就是该琴键的输出。
音符松开没有琴键按住时输出变成的值。
自动释音没有琴键按住时，输出变为音符关闭值。
斜坡每个琴键的值从最低键的 0 上升到 C10 的 1。
反转把每个值上下颠倒。
清除把每个琴键的值设为 0。

Tips

  • 导入的 FL 工程会保留 Keyboard Controller 的值。
