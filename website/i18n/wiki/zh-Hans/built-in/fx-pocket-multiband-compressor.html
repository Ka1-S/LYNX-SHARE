Pocket Multiband Compressor 用两个 24 dB 分频点把声音分成低、中、高三段，并分别压缩每一段。它的压缩比作用于信号的振幅，而不是分贝，所以在相同数值下比普通压缩器更温和。FL Studio Mobile 工程 (.flm) 的 Multiband Compressor 模块就是用它作为引擎加载的，每个数值都原样复制，它也可以添加到任何混音台插槽。它的编辑器是一页普通的旋钮，每个频段（Low、Mid、High）一行名称。

Controls

ControlWhat it does
主增益整个效果器的输出电平，-24 dB 到 +24 dB。
低分频点低段与中段之间的分频点，20 Hz 到 10.2 kHz。
高分频点中段与高段之间的分频点，20 Hz 到 10.2 kHz。
独奏Off、Low、Mid 或 High：只播放该频段。这个控件是 LYNX SHARE 自己的；FL Studio Mobile 在这里保存的是一个编辑器设置，.flm 导入会把它重置为 Off。
干声混合把未压缩的频段加到压缩后的频段上，0 到 100%，用于平行压缩。
Low / Mid / High input gain进入该频段的增益，-24 dB 到 +24 dB。它同时馈入检测器和音频。
Low / Mid / High threshold高于此电平时频段被压缩，-48 dB 到 0 dB。
Low / Mid / High ratio1 到 31。
Low / Mid / High attack该频段压缩器的反应速度，0 到 50 ms，遵循平方律。
Low / Mid / High release它松开的速度，10 ms 到 1 s。
Low / Mid / High gain该频段的输出增益，-24 dB 到 +24 dB。
Low / Mid / High stateOn 压缩该频段，Bypass 按分频后的原样通过，Mute 使其静音。
Low / Mid / High width该频段的立体声宽度，0 到 200%。100% 保持原样，0% 为单声道。
宽度模式Mode 1：超过 100% 时，宽度向仅有侧信号的方向移动。Mode 2：超过 100% 时，从每一侧减去另一个声道的一部分。

Tips

  • 被旁通的频段也会跳过它的输入增益、输出增益和宽度。
  • 无论采样率是多少，起音和释音都按 44.1 kHz 计算，FL Studio Mobile 也是这样做的。在 48 kHz 或 96 kHz 下，它们比读数更短。
  • 做新的混音时，Fruity Multiband Compressor 或 Prism Multiband 是功能更全面的工具。这个效果器的存在，是为了让 FL Studio Mobile 的歌曲听起来和在手机上一样。
