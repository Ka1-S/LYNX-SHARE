Sentry Gate 是 LYNX SHARE 原生的噪声门和扩展器，用于混音台插入轨。它会切掉阈值以下的信号，根据压缩比和范围，从轻微的扩展到完全的噪声门都可以。显示区在实时电平上画出传输曲线。

Controls

ControlWhat it does
风格Classic、Clean、Vocal、Guitar 或 Upward。改变门打开和关闭的方式。
阈值门打开的电平，从 -60 dB 到 0 dB。
压缩比从 1:1 到 100:1，从扩展器到噪声门。
范围信号被衰减的幅度，从 0 到 100 dB。
起音打开时间，从 0 ms 到 1 s。
释音关闭时间，从 0 ms 到 5 s。
保持门保持打开的时间，从 0 到 250 ms。
拐点阈值处的柔和程度，从 0 到 30 dB。
前视从 0 到 10 ms，带一个开关。
侧链内部或外部，带高通和低通滤波器。
声道模式底栏中的菜单（图中为 Left/Right）。
Oversampling, In and Out过采样菜单，以及输入和输出增益。
模型Classic 或 Measured。Measured 会加入 Vocal 风格的降噪；其他风格忽略它。0.1.26 之前保存的工程以 Classic 载入。
触发Level 或 Transient。Level 是和之前一样的门限。Transient 是鼓的门限：超过阈值的一击会让它完全打开，它在 Hold 时间内保持打开，并在 Release 时间内沿所选形状关闭，期间电平如何变化都不影响。Transient 下不使用 Ratio、Knee 和风格的曲线。默认 Level。
形状仅 Transient。释音的形状：Smooth、Mid 或 Sharp。
灵敏度仅 Transient。1 到 10，默认 5。数值越高，门限在越小的敲击上就会打开。

Tips

  • 打开前视会增加 10 ms 的延迟。
