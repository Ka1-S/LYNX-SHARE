Pocket Distortion 用四种曲线之一塑造信号，然后保持采样以产生压碎的声音，并缩放输出。可用来给鼓、贝斯和合成器增加颗粒感。FL Studio Mobile 工程 (.flm) 的 Distortion 模块就是用它作为引擎加载的，它也可以添加到任何混音台插槽。

Controls

ControlWhat it does
Hard / Tube / Soft / Clip选择曲线。Hard 是随电平升高而变平的拐点曲线，Tube 是 tanh 曲线，Soft 是指数曲线，Clip 在满刻度处削掉信号。
偏置双极，-100 到 100。在曲线之前加入一个偏移，使波形的两半失真得不同。滑块遵循五次方律，所以主要在两端起作用。曲线之后有一个高通滤波器去掉偏移。
驱动失真量，显示为 0 到 100。
立体声在左右两侧之间分配驱动，显示为 -100 到 100。在 0 时两侧都得到完整的驱动。低于 0 时左侧的驱动减少，高于 0 时右侧的驱动减少。
比特粉碎把每个输出采样保持 1 到 257 个采样。滑块遵循四次方律，所以前半段变化很小。
增益输出电平，-24 到 0 dB。

Tips

  • BitCrush 通过保持采样来降低采样率。它不会降低位深。
  • Gain 只会降低电平。用它来补偿 Drive 增加的电平。
