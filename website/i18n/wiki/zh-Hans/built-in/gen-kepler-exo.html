Kepler Exo 是 Kepler 的双振荡器版本，运行在同一个引擎上，多了第二个振荡器、交叉调制、第二个包络和 LFO、一个调制矩阵，以及饱和、合唱、EQ、延时和混响的效果页面。它的表在运行时从你自己的 FL Studio 安装里的 Kepler Exo 引擎 DLL 读取，该 DLL 必须是受支持的版本，本程序并不附带。找不到该文件时，编辑器会显示提示，通道保持静音，设置保留。新实例从你自己的 FL Studio 安装中该插件的预设开始，所以添加它需要已安装 FL Studio；否则 Add 菜单会把它列为需要 FL Studio。导入的通道没有退路转换。

Controls

ControlWhat it does
Top barHold、Octave（-1、0 或 +1）、调制路径的 X 和 Y 偏移、主 Detune、Vol 和 Pan。
DCO 1, DCO 2: LFO1, LFO2, Env2, PWMLFO 1、LFO 2 和包络 2 作用于振荡器的量，每个 LFO 带一个 wide 开关，以及脉宽及其来源：LFO、Man 或 Env。
DCO 1, DCO 2: Pulse, Saw, Sub打开脉冲波、锯齿波和副波的按钮，带副波电平推子和副波 Phase 推子。
DCO 2: On, Semi, Fine, Sync打开振荡器 2，以半音和微调步进调音，并使其同步。
交叉调制1>2 和 2>1 设定每个振荡器被调制的程度，各带一种形状：Sine、Tri、Pulse、Saw、Noise 或另一个振荡器。
混音台DCO1、DCO2 和 Noise 的电平，以及 AM 量。
VCF6、12、18 或 24 dB 的斜率、Freq、带 + 或 - 极性开关的 Env1 量、LFO1、LFO2 和 Kybd 量，以及带自己形状选择的 FM。
HPF高通滤波器的 On 开关和 Freq。
VCA放大器跟随 Env1、琴键门或 Env2。Vel 设定力度改变音量的程度，Smooth 开关平滑。
Env 1, Env 2每个包络的 A、D、S 和 R 推子。
LFO 1, LFO 2带 Sync 的 Rate、Delay、Auto 或 Man 触发模式，以及一个 Phase 开关和推子。LFO 2 增加一种形状：Tri、Ramp up、Ramp dn、Sine、S&H 或 Rnd glide。
声部LFO trig 按钮、Exp 或 Lin 滑音（带 Glide 旋钮），以及 Mono、Legato、Retrig 和 Release 开关。
琶音On 按钮、Range（1 到 3）、含九种模式的 Mode 菜单（上行、下行、随机以及按弹奏顺序的变体）、Sync、Rate 和 Gate。
矩阵八个旋钮，1 到 8，设定八条调制路径的量。
合唱Off、I、II 或 I+II，带一个 Noise 旋钮和一个 Gate 开关。
Effect pages标签页：Saturation（Drive、Pre 或 Post、HQ）、Chorus、EQ（Low、Mid 和 High 的 Gain、Freq 和 Q）、Delay 和 Reverb。每个页面有自己的 On 开关。

Tips

  • 导入的 Kepler Exo 通道会保留其设置，包括调制矩阵。
  • 使用 4x 过采样标志的状态会被引擎拒绝。
