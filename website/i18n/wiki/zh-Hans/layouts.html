在 0.1.25 中，视图 › 布局样式 有两个条目：模式工作流程（默认） 和 片段启动工作流程。选项 › 常规设置 的“工作流程”下也有同样的选项。你的选择在关闭程序后会保留。

样式工作流程由通道机架、样式和播放列表构成。片段启动工作流程则在播放列表旁边增加一个带场景的片段网格。样式和通道机架仍然可用。

在网格中启动片段

  1. 选择 视图 › 布局样式 › 片段启动工作流程。片段网格会出现在播放列表旁边。
  2. 右键单击一个空槽，选择 在此放置模式，再选一个样式。双击空槽则会把当前样式放进去。
  3. 点击片段左侧的三角形来启动它。如果走带处于停止状态，它会开始播放。
  4. 点击 场景 列中某个场景的三角形，可启动那一行的所有片段。
  5. 点击 停止所有片段 来停止它们。
  6. 点击 返回播放列表，让各条轨道重新播放它们的播放列表片段。

屏幕上有什么变化

  • 片段网格显示在播放列表旁边。播放列表轨道是列，场景是行。
  • 播放列表的标题栏上多了一个 两者、网格、歌曲 切换开关。网格 只显示网格，歌曲 只显示播放列表。
  • 第一次切换时，通道机架会被隐藏。按 F6 或点击它的工具栏按钮可以显示。
  • 播放列表的自动化轨道会被打开。
  • 窗口布局按样式分别保存，所以每种样式都会恢复成你离开时的样子。

网格

被启动的片段不会立即开始。它要等到下一个启动量化点，在此之前它的三角形会闪烁。网格底部的下拉框设置全局启动量化，所有设为 全局 的片段都使用它。停止也以同样的方式等待。

右键单击片段可以打开它的设置。

设置作用
启动量化这个片段何时开始：全局、无，以及从 8小节 到 1/32
启动模式触发、门限、切换 或 重复
连奏（保持位置）片段接管该轨道上先前播放的片段的播放位置
循环开：片段重复播放。关：只播放一次，然后该轨道停止
跟随动作片段结束之后发生什么：两个动作，各有一个概率，以及它们生效前的等待时间
Delete清空这个槽

右键单击空槽可得到 停止按钮（场景在此停止该轨道）。点击空槽左侧的方块会停止该轨道。右键单击场景可得到 插入场景、在下方添加场景、删除场景、重命名场景... 和该场景的速度。

槽的菜单中还有两个作用于整个网格的选项：走带停止时将轨道交还给播放列表 和 整个网格的跟随动作。

命令按键作用

启动场景Ctrl+Enter启动所选场景

Ableton Live 套装

打开 Live 套装时，它的 Session 片段和场景会连同启动设置一起进入片段网格。文件 › 导出 › Ableton Live 套装 (.als) 会把网格作为 Session 片段写回去。选项 › 常规设置 中有 Live 工程的会话片段，选择 播放列表，编曲之后 则会改为把它们放在播放列表上。

切换回去

选择 视图 › 布局样式 › 模式工作流程（默认）。你在样式工作流程中使用的窗口布局会恢复，自动化轨道也回到之前的设置。网格中的片段仍保留在工程里。

须知

  • 启动过片段的轨道在播放列表中保持静音，直到你按下 返回播放列表。选项 走带停止时将轨道交还给播放列表 会在每次停止时替你完成这一步。
  • 在 0.1.25 中，槽要通过它的菜单或双击来填充。不能把片段或文件拖进槽里。
  • 跟随动作只用于片段，不用于场景。
  • 在片段启动工作流程中手动打开的自动化轨道，切换回去时不会保留。
  • 选择了样式工作流程时，不会加载网格中的任何内容。
