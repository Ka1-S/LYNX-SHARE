所有从 LYNX SHARE 输出的内容都通过 文件 › 导出。音频格式（WAV、MP3、OGG、FLAC、AIFF 和 M4A）共用一个导出窗口。MIDI、FL Studio 工程、Ableton Live 套装、DAWproject 文件和压缩工程在同一个菜单中各有自己的条目。

把歌曲导出为 WAV

  1. 选择 文件 › 导出 › Wave文件...。
  2. 让 范围 保持为 歌曲（播放列表），文件 保持为 一个文件（混音）。
  3. 选择 位深：16 位、24 位或 32 位（浮点）。
  4. 把 尾音 设为 保留余音，这样混响和释音会在最后一小节之后继续响完。
  5. 点击 导出...，选择名称和文件夹，等待渲染完成。
  6. 完成后，LYNX SHARE 会报告文件保存在哪里，以及它的峰值电平。

Ctrl+R 以你上次导出的格式打开窗口。Ctrl+Shift+R 以 MP3 打开。

分轨和轨道

文件 有三种分轨模式：

  • 每个混音插入轨一个（分轨）：每个有声音的插入轨一个文件。
  • 每个通道一个（分轨）：每个会发声的通道一个文件。
  • 每个通道一个，仅乐器（不含发送和总线）。

勾选 同时导出完整混音，可以在分轨之外同时得到完整混音。底部那一行会显示将写出多少个文件。

当歌曲在段落轨中有段落时，每个段落一个文件 会按段落把它切开，并以各段落的名称命名每个文件。导出分轨时，每个段落有自己的一组文件。

文件 › 导出 › 所有 Playlist 轨道 和 所有 Playlist 轨道组 会按播放列表的每条轨道或每个组各写出一个文件。在混音台的菜单中，磁盘录音 › 将录音预备的轨道渲染为WAV文件...（Alt+R）会只为已预备的插入轨打开导出窗口。

导出到 FL Studio、Ableton Live 和 DAWproject

.flp 是 FL Studio 2026 工程。采样器、音频片段、FL Studio 自己的生成器和效果器、第三方插件、样式、播放列表、混音台和自动化都会连同设置一起转过去。对于 FL Studio 没有的内容，你可以在 渲染为音频（声音相同） 和 使用最接近的 FL 插件（仍可编辑，声音可能不同） 之间选择。选第二项时，仅 LYNX 有的乐器会被舍去。跟随歌曲位置的调制器会变成自动化片段：同步的 LFO 会变成 FL Studio 的片段 LFO，步进、随机源和宏会变成点。跟随器、包络、按键跟踪和力度会被舍去。报告会列出哪些内容被渲染、替换或舍去。详情见从 FL Studio 转来。

.als 包含每个通道一条 MIDI 轨道、音频轨道、编组、返回轨、发送、机架和 Drum Rack、带状态的 VST2 和 VST3 插件、标记，以及音量、声像和速度的自动化。LYNX SHARE 自己的乐器和效果器不会被转换，但它们的轨道和音符会保留。Helix 是例外：它会变成 Live 的 Wavetable。效果器参数的自动化和插入轨之间的路由会被丢弃。详情见从 Ableton Live 转来。

.dawproject 包含轨道、文件夹、片段、音符、带扭曲标记的音频、自动化、速度、标记、带发送的混音台，以及带状态的 VST3、VST2 和 CLAP 插件。LYNX SHARE 自己的乐器和效果器会以 LYNX SHARE 能再次打开的方式写入。片段网格、其他编排和部分逐音符的细节会被舍去，并由一份报告列出。

文件 › 将副本保存为 FL Studio Mobile 工程 (.flm)... 会写出供 FL Studio Mobile 使用的 .flm，并把采样复制到旁边的 <name> Samples 文件夹。保存前，窗口会像 文件 › 为旧版 LYNX 保存副本... 那样列出副本会丢失的内容。.flm 保留音符和模式（FL Studio Mobile 每条轨道一个模式）、速度、每小节拍数、调式和和弦集、混音台的音量、声像、静音、独奏以及到总线的发送、FL Studio Mobile 自带的乐器（MiniSynth、SuperSaw、GMSynth 和 Transistor Bass，以及 FL Studio 的 MiniSynth 和 Transistor Bass）、变成鼓组的鼓采样器、变成含多个乐器的机架的 Layer、每个带混合量的 Pocket (FLM) 效果器，以及带音量、声像、音高和反转的音频片段。它还会写出 DW Sampler（含其区域）和 3x Osc，以及混音台音量和声像、Pocket (FLM) 效果器、DW Sampler 和 GMSynth 自身数值的自动化片段。其他乐器（目前也包括 FL Studio Mobile 的 Slicer 和 SoundFont Player）的音符保留在 FL Studio Mobile 的 MiniSynth 上，没有 FLM 模块的效果器和其他目标（如合成器自身的旋钮和第三方插件）的自动化会被省略，全部都会列出。

须知

  • 对 MP3、OGG、M4A 和 32 位 WAV，抖动 是灰色的；除 WAV 之外的所有格式，速度和标记选项也是灰色的。
  • 选择 播放列表选区 但播放列表中没有选区时，会渲染整首歌。窗口会提醒你。
  • 如果主控插入轨被静音，窗口会提醒你文件将是无声的。
  • 只有工程里有视频轨道时才会出现 同时写出带此混音的视频，并且它需要 FFmpeg。
  • 只有工程里有启用的硬件插入轨时才会出现 通过硬件实时渲染。这种导出需要和歌曲一样长的时间。
  • 在这个版本中，渲染为音频（把插入轨合并为音频片段）播放时，比它所替换的插入轨大约响 5 dB。
