播放列表是样式变成歌曲的地方。它的轨道上可以放三种片段：样式片段、音频片段和自动化片段。按 F5 显示或隐藏它，按 Enter 最大化或还原。

走带有两种模式。样式模式循环播放当前样式。歌曲模式播放播放列表。按 L 切换。

把样式放进歌曲

  1. 按 F5 显示播放列表。
  2. 在选择面板中单击一个样式。选择面板列出工程的样式、音频和自动化，你单击的那一个会成为片段来源。
  3. 按 P 选择铅笔。
  4. 在轨道上单击来放置片段。按住按钮拖动可调整位置。
  5. 按 B 选择画笔，沿着轨道拖动，把片段首尾相接地涂出来。
  6. 按 L 进入歌曲模式，然后按 Space 播放。

音频文件可以从浏览器拖到播放列表上。

处理片段

  • 拖动片段可移动它。Shift + 拖动则复制一份。
  • 拖动片段的末端可调整大小。拖动起点则进行修剪，内容保持在原位。
  • 右键单击会删除片段。Ctrl + 拖动为选择。
  • 双击片段可打开它。
  • 片段左上角的按钮会打开片段菜单（设为唯一、重命名并设置颜色、切碎，对音频还有：音高、适配速度、倒放）。
  • 音频片段的菜单遵循 FL Studio 的双列布局。左列有 音频片段 部分（预览、已静音、重命名并设置颜色...、更改颜色...、随机颜色、更改图标...、选择来源通道、通道设置、设为唯一、选择所有相似的片段、Delete、属性...）和 区域 部分（选择区域、切碎）。右列有 采样（设为唯一采样、编辑采样、从采样中提取分轨、检测速度、适配速度）、自动化（自动化 › 声像 或 音量、交叉淡化至）和 淡入淡出（重置淡入淡出）。LYNX SHARE 自己的项，例如 在此拆分、倒放、标准化 和 转换为 MIDI，放在最后，位于一条线下方。
  • 自动化 › 声像 或 音量 会在音频片段所在的轨道上创建一个与音频片段等长的自动化片段，用于该通道 Levels 调整的声像或音量。
  • 拖动时按住 Alt 可忽略吸附。
  • 音频片段有淡化手柄和一个可上下拖动的片段增益。右键单击淡化手柄可打开它的菜单，其中有 创建交叉淡化。右键单击增益手柄可使用 重置增益 和 标准化。
  • Shift+M 切换拉伸：此时调整音频片段的大小会拉伸音频，而不是将其裁切。
  • Shift+Left 和 Shift+Right 把所选片段移动一个吸附步长，Shift+Up 和 Shift+Down 移动一条轨道。Alt+Left 和 Alt+Right 按当前缩放把它们移动一个屏幕像素，不吸附。没有选中片段时，所有片段都会移动。
  • 音频片段菜单中的 设为唯一采样 会给该片段一个新文件，其中保存了它所播放的内容，音高、拉伸和反转已经包含在音频里。
  • 带有扭曲标记的音频片段会在上边缘用小旗显示这些标记。向侧面拖动小旗即可移动标记。

Edit 和 Select 菜单

Playlist 的菜单有 编辑 和 选择 两个子菜单。编辑 包含片段命令：剪切、复制和粘贴、向左移动、向右移动、上移、下移、设为唯一、设为唯一采样、插入空白、删除空白、合并命令和淡化选项。选择 有 按所选来源选择 (Shift+C)、反选 (Shift+I)、取消选择 (Ctrl+D)、静音的和重叠的片段，以及 魔术套索。开启 魔术套索 后，不按任何按键，在片段周围绕圈移动鼠标即可选中它们。

轨道

在轨道标头上，单击为选择，Ctrl + 单击为添加或移除，Shift + 单击选中一个范围，右键单击打开轨道菜单。Shift + 滚轮可上移或下移轨道。轨道的指示灯用于静音（单击）或独奏（Ctrl + 单击或右键单击）。拖动两条轨道之间的分隔线可调整其中一条的大小，Shift + 拖动则调整所有轨道。

Playlist 菜单中的 视图 决定轨道标题显示什么：在音频轨道上显示控件、在音频轨道上显示电平 和 在乐器轨道上显示电平。

轨道菜单中的 轨道模式 可把轨道设为 未分配、音频轨道 或 乐器轨道，与 FL Studio 中一样。音频轨道 先列出 新建混音轨道，然后按编号和名称列出每个混音台插入轨。所选项适用于所有选中的轨道。乐器轨道 有 使用现有通道、更多插件... 和通道机架的乐器列表。

轨道标题左上角的 + 会为新轨道打开同样的选项：添加音频轨道、更多插件... 和各种乐器。右键单击 + 会立即添加一条音频轨道。

样式块

在 Playlist 菜单中开启 Pattern 块（当前项目） 后，轨道下方会出现一个区域，每个样式占一行。在这里，铅笔工具放置一个块并可沿它所在的行拖动，画笔工具绘制块，橡皮擦删除块。用任何工具右键单击都是擦除。

标尺、循环和标记

  • 单击标尺可设定歌曲位置。
  • 在标尺上右键拖动、Ctrl + 拖动或双击后拖动，会生成时间选区，它同时也是循环。Shift + 拖动可移动它。
  • Ctrl+Ins 在所有轨道上插入与时间选区等长的空白，Ctrl+Del 则将其移除。
  • Alt+T 添加标记。单击标记可跳转到它。
  • Ctrl + 滚轮缩放，Alt + 滚轮改变轨道高度。

自动化

右键单击旋钮或推子，选择 创建自动化片段。片段会出现在播放列表上。用铅笔拖动它的点，在曲线上单击可添加一个点。轨道下方的自动化轨道是可选的，默认关闭。见自动化。

右键单击某个点可打开它的菜单。它的 模式 列表包含 FL Studio 的 13 种曲线模式，用于在该点结束的线段：平滑、保持、三种单曲线、三种双曲线、半正弦、阶梯、平滑阶梯、脉冲波 和 波浪。新点沿用上次使用的模式。这些模式可以从 .flp 文件读取，也会写入 .flp 文件。

须知

  • 只有在歌曲模式下才能听到播放列表。在样式模式下，无论轨道上有什么，Space 播放的都是当前样式。
  • 视图 › 布局样式 › 片段启动工作流程 会在播放列表旁边增加一个由片段和场景组成的网格。它是可选的。见布局。
  • 同一个控件上有多个相互重叠的自动化片段时，选择播放哪一个的结果可能与 FL Studio 不同（0.1.25 版本说明）。
  • 与 FL Studio 一样，一个样式每次只从一个片段播放。当同一样式的较晚片段在任何轨道上开始时，较早的片段从那里起不再开始新的音符。不同样式的片段会一起播放。这在新工程和 FL Studio 工程中都成立。0.1.27 之前保存的 .lynx 工程仍会完整播放每个片段。
  • 由已关联的 MIDI 控制器移动的速度不会改变音频片段的大小。
  • 在 Linux 上，视频需要 FFmpeg。
