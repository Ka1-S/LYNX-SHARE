打开歌曲

  1. 把歌曲复制到电脑上：FL Studio Mobile 的 .flm、下载为 .blx 的 BandLab 工程，或 GarageBand 的 .band。
  2. 选择 文件 › 打开...（Ctrl+O）并选中它，或把它拖到窗口上。

你会得到什么

  • 歌曲在简易布局中打开，每种乐器一条音轨，同时带有速度、样式或区域以及混音。
  • 按播放即可试听。
  • 点击一条音轨，就能在时间线下方的面板中编辑它。

哪些无法带过来

  • 如果有内容需要调整，歌曲打开时会弹出一份简短的报告。这里，FL Studio Mobile 的 MiniSynth 改用 LYNX SHARE 的一种合成器音色播放。
  • 帮助 › 上次工程导入报告 可以再次查看这份报告。
  • 手机应用自带、不对外开放的乐器，会使用 LYNX SHARE 的内置声音播放。

回到手机

  • 文件 › 将副本保存为 FL Studio Mobile 工程 (.flm)... 会写出一个可以在 FL Studio Mobile 中打开的 .flm。

另见从 BandLab、FL Studio Mobile 或 GarageBand 转过来和文件格式。
