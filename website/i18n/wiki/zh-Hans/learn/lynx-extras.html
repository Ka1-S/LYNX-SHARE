extras 是什么

  1. 打开 选项 › LYNX 附加功能...：每个 extra 一个开关，按区域分组（混音台、播放列表、Piano roll、编辑等）。
  2. 每个开关都会说明它的作用，以及还能在哪里找到它（通常也在某个窗口自己的菜单里）。

打开一个

  1. 按 Ctrl+F 并输入名称的一部分，这里是 "loudness"，然后点击它的开关。
  2. 改动立即生效：混音台现在会在主控旁边显示歌曲的响度。

FL-exact 或 Recommended

  1. 与 FL 相同 会关闭所有 extras，让 LYNX 的工作方式和 FL Studio 完全一样。
  2. 推荐 让每个附加功能回到默认值。默认开启的功能大多改变外观或添加 FL Studio 没有的东西，没有一个会改变 FL Studio 的按键和点击的作用。其中四项会改变声音或你的文件，它们所在的行会注明。
  • 拉长的样式片段循环其样式 (LYNX) 会在 FL Studio 播完后无声的地方再次播放样式。
  • 拖入的循环采用其音频中检测到的速度和调性 在 Simple 布局中会改变拖入循环的播放方式。
  • 拖放到播放列表的 MIDI 文件变为样式剪辑 在你拖入文件时会向歌曲添加一个样式（FL Studio 拒绝这种拖放）。
  • 多种格式安装的插件只占一行 会选择新插件以哪种格式加载，项目会保存该格式。

另一个会改变声音的设置

同时补偿推子和路由自动化 (LYNX)（混音台插入轨道菜单的 插件延迟补偿 中）在每个新项目中开启。它不在 LYNX 附加功能页面上，所以 与 FL 相同 会让它保持开启。

  1. 当有带延迟的插件（线性相位 EQ、带前瞻的限制器）时，它会把推子、声像、发送和 VCA 推子的自动化推迟到与其作用的音频同样晚的位置播放，这样淡变会落在你听到的位置。
  2. FL Studio 只推迟插件旋钮的自动化，所以在那里同样的推子动作会早一点听到。从 FL Studio 打开的项目和以前做的项目中它保持关闭。
  3. 要得到 FL Studio 的时序，请在该菜单中关闭它：这是整个项目的设置。
