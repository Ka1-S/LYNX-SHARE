Plugin-Manager

  1. Wähle Optionen › Plugin-Manager.... Er listet jedes Plugin auf, das LYNX gefunden hat, mit Hersteller, Format und Datei.
  2. Plugin-Ordner... zeigt, wo LYNX sucht: die Standardordner für VST3 und CLAP sowie jeden Ordner, den du hinzufügst.

Nach Plugins suchen

  1. Klicke auf Neue Plugins finden. Jede Datei wird in einem eigenen Prozess geprüft, ein abstürzendes Plugin kann LYNX also nicht mitreißen: Es steht dann unter Fehlerhaft.
  2. Suche nach Name, Hersteller oder Format; mit einem Stern machst du ein Plugin zum Favoriten.

Ein Plugin laden

  1. Wähle im Mixer eine Spur aus und klicke auf einen leeren Slot.
  2. Wähle Plugin (VST/VST3/CLAP), dann Weitere Plugins..., suche das Plugin nach Namen und klicke auf Hinzufügen.
  3. Das Plugin öffnet sich in einem eigenen Fenster. Drücke Wiedergabe, um es zu hören.
