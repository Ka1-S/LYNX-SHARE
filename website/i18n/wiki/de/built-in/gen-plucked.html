Plucked ist eine Engine für das Plucked von FL Studio. Jede Note regt eine Saite an, die durch eine Delay-Line modelliert wird, sodass es wie eine gezupfte Saite klingt. Es spielt importierte Projekte und seine Presets.

Controls

ControlWhat it does
DecayWie lange die Saite klingt. 0 bis 256, Standard 128.
FarbeMischt Rauschen in die Anregung. 0 bis 128, Standard 64.
Norm.Normalisiert den Decay pro Tonhöhe. Standardmäßig an.
GateNote-off macht die Stimme stumm. Aus klingt eine Note, bis sie ausgeklungen ist.
BreiterLässt eine zweite, getrennt angeregte Saite für den rechten Kanal laufen.

Tips

  • Der Zufalls-Seed ist pro Instanz verschieden, daher sind zwei Renderings derselben Noten nicht samplegenau identisch mit FL Studio, das den Seed aus der Uhr nimmt.
