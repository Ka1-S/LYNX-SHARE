Fruity Send ist ein Effekt-Slot-Plugin, das das Signal an seiner Position in der Kette an ein anderes Mixer-Insert sendet. Du nutzt es, wenn du einen Send aus der Mitte einer Kette brauchst, zum Beispiel nach einem Effekt, aber vor dem nächsten. Es wird beim Import aus FL-Studio-Projekten gelesen.

Controls

ControlWhat it does
DryPegel des Signals, das die aktuelle Kette weiterläuft.
Senden anDas Mixer-Insert, das das gesendete Signal empfängt.
PanPan des gesendeten Signals.
LautstärkePegel des gesendeten Signals.

Tips

  • Das Ziel-Insert wird im Feld Senden an gewählt; laut den Docs ist das Insert in FL Studio kein automatisierbarer Parameter.
  • Pan, Volume und Dry sind bearbeitbar und lassen sich automatisieren.
