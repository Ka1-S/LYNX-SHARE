Ein VFX-Notenprozessor aus dem Patcher von FL Studio ohne eigenen Klang. Er führt ein Python-Skript auf den Noten aus, die ihn erreichen. LYNX SHARE führt es mit einem eingebauten Python (pocketpy) mit den Modulen math, random, re, time und sys aus. Skripte können keine Dateien öffnen.

Controls

ControlWhat it does
BenutzeroberflächeDie Bedienelemente, die das Skript definiert, und seine Ausgangs-Controller.
SkriptDer Quelltext-Editor.
LogMeldungen und Fehler des Skripts.
API-ReferenzDie Funktionen und Eigenschaften, die ein Skript nutzen kann.
Apply (Ctrl+Enter), Run againFührt das bearbeitete Skript aus.
ZurücksetzenGeht zurück zum laufenden Skript.
Neu startenStartet das Skript neu.
LeerenLeert das Log.

Tips

  • LYNX SHARE führt höchstens 15 Skripte gleichzeitig aus.
  • Klicke auf den Fehler-Button, um zur Zeile eines Fehlers zu springen.
