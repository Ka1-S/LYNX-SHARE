Emphasizer ist ein Look-ahead-Limiter mit einem Hauptregler. Das Eingangsgain speist einen Spitzendetektor, die Pegelreduktion wird auf das um 2 ms verzögerte Signal angewendet, und das Ergebnis wird geclippt und an das Ausgangsgain geschickt. Er lädt die Einstellungen des FL Studio Emphasizer aus einem importierten .flp-Projekt und meldet das 2-ms-Look-ahead für den Latenzausgleich.

Controls

ControlWhat it does
Eingangs-GainGain vor dem Limiter, 0 dB bis +24 dB.
BetonungStärke, 0 bis 100 Prozent. Sie skaliert den Pegel, den der Spitzendetektor sieht.
AusgangAusgangspegel, bis 0 dB.
Soft ClippingErsetzt das harte Clipping bei Vollaussteuerung nach dem Limiter durch ein weiches Clipping, das darunter beginnt.
PegelangleichungTeilt den Ausgang durch das Eingangsgain, sodass ein höheres Input gain den Pegel nicht erhöht.
BypassBlendet zum verzögerten Dry-Signal über, statt hart zu schalten.

Tips

  • Bei eingeschaltetem Level matching kannst du Input gain erhöhen, um den Limiter härter anzutreiben, ohne dass der Ausgang um denselben Betrag lauter wird.
  • Der Meter-Streifen rechts zeigt die Pegel.
