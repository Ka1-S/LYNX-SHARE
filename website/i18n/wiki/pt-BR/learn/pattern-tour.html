O Channel Rack

  1. No cartão de boas-vindas, clique em FL Studio, ou escolha Exibir › Estilo de layout › Layout Pattern (padrão). O Channel Rack (F6) mostra os canais iniciais: Kick, Clap, Hat, Snare e Synth.
  2. Cada linha é um som e cada quadrado é um passo (uma semicolcheia). Clique num quadrado para adicionar uma batida e clique de novo para tirá-la.
  3. Um bumbo nos passos 1, 5, 9 e 13, uma palma no 5 e no 13 e hi-hats no meio formam uma batida básica.
  4. Aperte Play (ou a barra de espaço). No modo Pattern, o pattern toca em loop.

O Piano Roll

  1. Aperte F7 para abrir o Piano Roll do canal selecionado.
  2. Cada linha é uma tecla do teclado à esquerda. Clique na grade para desenhar uma nota; arraste a ponta dela para alongá-la.
  3. Clique com o botão direito numa nota para apagá-la.

A Playlist

  1. Aperte F5 para abrir a Playlist. É nela que você organiza os patterns numa música.
  2. Clique numa faixa para colocar o pattern atual. Coloque-o várias vezes para ele tocar por mais tempo.
  3. Mude o transporte de Pattern para Song (ou aperte L) e aperte Play para ouvir a Playlist.

O Mixer

  1. Aperte F9 para abrir o Mixer.
  2. Cada canal toca numa faixa do Mixer. Arraste um fader para ajustar o nível e adicione efeitos nos slots da faixa.
  3. A faixa Master, à esquerda, é o que você ouve e o que exporta.

Bom saber

  • F5, F6, F7 e F9 mostram ou escondem as quatro janelas, como no FL Studio. F8 abre o seletor de plugins (Plugin picker).
  • O mesmo projeto também abre nos layouts Simple e Clip-launch: veja Um projeto, três layouts.
