Salvar como

  1. Escolha Arquivo › Salvar como... e dê um nome ao projeto. Um projeto do LYNX (.lynx) guarda os patterns, o Mixer, os plugins e os ajustes deles, e aponta para os seus samples e gravações, que continuam sendo arquivos à parte.
  2. A partir daí Arquivo › Salvar (Ctrl+S) salva por cima. O arquivo substituído vai para os backups.

Salvar nova versão

  1. Testando uma ideia? Arquivo › Salvar nova versão (Ctrl+N no Layout Pattern, como no FL Studio; Ctrl+Alt+S em todos os layouts) salva o projeto como My beat_2, ao lado do primeiro, e você continua trabalhando nele.
  2. O LYNX também faz backups enquanto você trabalha, então uma falha ou um erro custa pouco.

Versões e backups

  1. Arquivo › Versões... lista as versões salvas e os backups deste projeto, da mais nova para a mais antiga.
  2. Escolha uma e clique em Abrir como cópia: ela abre como um projeto novo, ainda não salvo, e os arquivos continuam como estão. Rótulo... adiciona uma anotação a ela.
  3. Arquivo › Voltar ao último backup... troca o projeto aberto pelo backup mais recente dele. O arquivo do projeto só muda quando você salva.

Leve um projeto para outro computador

  1. Samples e gravações são arquivos ao lado do .lynx, não dentro dele. Arquivo › Reunir tudo e salvar copia para a pasta do projeto os que estão fora dela e salva; marque Arquivo › Sempre reunir e salvar para fazer isso a cada salvamento.
  2. Arquivo › Exportar › Pacote de loops zipado... grava um único .zip com o projeto e todos os arquivos que ele usa: copie esse arquivo para o outro computador.
  3. Arquivo › Abrir a pasta do projeto mostra onde estão o projeto e os arquivos dele.
