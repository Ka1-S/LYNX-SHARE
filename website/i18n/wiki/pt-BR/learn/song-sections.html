Adicione seções

  1. No Layout Simple, clique em Seções na barra de título. A primeira seção aparece, cobrindo o início da música.
  2. Clique em + à esquerda da faixa Sections para adicionar a próxima, com oito compassos, depois da última.
  3. As seções recebem os nomes do GarageBand em ordem: Intro, Verse, Chorus... Dê dois cliques numa para renomeá-la.

Mova e copie uma parte inteira

  1. Arraste uma seção para movê-la com todos os clipes que estão sob ela. Uma linha mostra para onde ela vai.
  2. Segure Ctrl enquanto arrasta para copiá-la. Solte-a sobre outra seção para trocar as duas de lugar.
  3. Arraste a borda direita de uma seção para mudar o comprimento dela; os clipes ficam onde estão.

O menu da seção

  • Clique com o botão direito numa seção para ver Renomear..., Duplicar, Repetir esta seção em loop, Selecionar os clipes dela e os comandos de apagar.
  • Clique com o botão direito na faixa para ver Adicionar uma seção no fim, Seções a partir dos marcadores e Criar cenas a partir das seções (para o Layout Clip-launch).

No Layout Pattern, a faixa Sections é um extra do LYNX: ligue em Opções › Extras do LYNX....
