A paleta de comandos

  1. Aperte ? (ou Ctrl+Shift+Y, ou clique na lupa da barra de ferramentas).
  2. Digite algumas letras do que você quer. A lista traz cada ação com seu atalho, cada item de menu com o lugar dele, os interruptores dos extras do LYNX, as páginas de Settings e seus projetos recentes. As ações também são encontradas pelos nomes em inglês em todos os idiomas.
  3. Escolha uma linha com as setas e aperte Enter, ou dê dois cliques nela. Esc fecha a paleta.

Vigie a CPU

  1. O medidor de CPU na barra de ferramentas mostra quanto do tempo de áudio o projeto usa enquanto toca.
  2. Dê dois cliques nele para abrir o Plugin performance monitor: a carga de cada plugin e canal, agora, na média e no pico.

Deixe os plugins descansarem

  • Ferramentas › Ativar a desativação inteligente em todos os plugins deixa cada plugin em pausa enquanto recebe silêncio e não produz som, como o Smart disable do FL Studio.
  • No Layout Clip-launch, clique com o botão direito no título de uma faixa e escolha Desativar trilha para descarregar os devices dela até você precisar deles de novo.
