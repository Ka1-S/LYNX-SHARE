O Frequency Shifter é um plugin de slot de efeito que move todas as frequências para cima ou para baixo pelo mesmo número de hertz, o que torna os sons harmônicos inarmônicos. Ele abre as configurações de um plugin Frequency Shifter do FL Studio quando um projeto .flp é importado. Sua latência é compensada.
