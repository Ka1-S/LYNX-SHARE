O EQUO é um plugin de slot de efeito construído em torno de 31 passa-bandas de terça de oitava. Ele abre as configurações de um plugin EQUO do FL Studio quando um projeto .flp é importado. Tem oito bancos mais um banco master, e cada banda tem seu próprio volume, pan e envio.

Controls

ControlWhat it does
ShiftDesloca as bandas.
MixEquilíbrio das bandas processadas.
MorphControle de morph para os bancos.
SuavizarSuavidade do movimento das bandas.
VolVolume de saída.
BancoSeleciona o banco master ou um dos oito bancos.
Vol / Pan / SendSeleciona qual valor os sliders das bandas editam.
Só envioEnvia as bandas somente para o insert escolhido.
Modo somarSoma os sinais das bandas em vez de substituir a entrada.
SobreamostragemSobreamostragem do processamento.
Larg.Largura de banda das bandas.
EnviarInsert que recebe os envios das bandas.

Tips

  • Os envios das bandas vão para o insert escolhido na caixa Enviar.
