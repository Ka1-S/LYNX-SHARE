O Keyboard Controller define a saída dele com o valor que você desenhou para a última tecla tocada. Ele não produz som; você vincula a saída dele a outro controle. Você desenha os valores com o mouse sobre o teclado.

Controls

ControlWhat it does
Key valuesBarras acima do teclado; a altura de cada barra é a saída para aquela tecla.
Nota soltaValor para o qual a saída vai quando nenhuma tecla está pressionada.
Release automáticoQuando nenhuma tecla está pressionada, a saída vai para o valor de note-off.
RampaO valor de cada tecla subindo de 0, na tecla mais grave, a 1 em C10.
InverterVira todos os valores de cabeça para baixo.
LimparDefine o valor de cada tecla como 0.

Tips

  • Os projetos do FL importados mantêm os valores do Keyboard Controller.
