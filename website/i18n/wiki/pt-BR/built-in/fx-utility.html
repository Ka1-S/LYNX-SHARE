O Utility é uma ferramenta pequena para níveis e roteamento de canais. Adicione-o a um insert para mudar o ganho, deslocar o balanço ou trocar e misturar os canais.

Controls

ControlWhat it does
GanhoGanho de saída.
BalançoBalanço entre esquerda e direita.
L -> LEntrada esquerda para a saída esquerda.
R -> LEntrada direita para a saída esquerda.
L -> REntrada esquerda para a saída direita.
R -> REntrada direita para a saída direita.

Tips

  • Com L -> R e R -> L altos e os outros baixos, os canais são trocados.
