O MIDI Effect Rack é um gerador do Channel Rack construído sobre o Patcher em modo rack. Suas cadeias guardam só efeitos MIDI. Todas as cadeias recebem as mesmas notas, e o que as cadeias tocam vai para os canais filhos do rack, como num canal Layer. Adicione-o pelo seletor de plugins como MIDI Effect Rack. As mesmas cadeias de efeitos MIDI também podem ficar no começo de uma cadeia de Instrument Rack.

Controls

ControlWhat it does
Definir filhosNo menu da cadeia: faz dos canais selecionados no Channel Rack os filhos que este rack toca. Show children os seleciona de novo.
Chain listUma linha por cadeia. O menu da cadeia tem Adicionar cadeia, Renomear, Duplicar, Excluir, Mover para cima e Mover para baixo.
DispositivosOs efeitos MIDI da cadeia selecionada, adicionados pelo menu de efeitos MIDI.
Key, Vel, Chain, HideEscolha o editor de zonas: zonas de tecla, zonas de velocity, zonas de seleção de cadeia ou nenhum. As zonas vão de 0 a 127.
Zone barsArraste uma barra ou as pontas dela para definir a zona. A faixa de cima de uma barra define os fades. Num MIDI Effect Rack, os três fades escalam a velocity das notas.
Seletor de cadeiaO valor com que as zonas de seleção de cadeia são comparadas. Um macro pode controlá-lo.
O seletor de cadeia filtra controles MIDIUma chave no menu da cadeia, guardada com o rack.
MacrosAté 16 knobs. + e - mostram mais ou menos.
MapModo de mapeamento. Cada macro ganha um botão Map que abre um menu com os parâmetros dos dispositivos das cadeias e o Seletor de cadeia. A lista de mapeamentos mostra Macro, Caminho, Nome, Mín. e Máx.
Aleat.Dá a cada macro mapeado um valor aleatório, exceto os macros excluídos da aleatorização.
Variações de macrosGuarda e lança conjuntos de valores de macros: New, Lançamento, Sobrescrever, Renomear, Duplicar e Excluir.

Tips

  • Enquanto os filhos não são definidos, a barra de título do rack diz que ainda não há nenhum e o rack não toca nada.
  • As cadeias não têm volume nem pan: um MIDI Effect Rack só repassa notas.
  • Um MIDI Effect Rack do LYNX SHARE é gravado em um set do Live exportado como um MIDI Effect Rack, sem os efeitos MIDI embutidos dentro dele. Quando um set do Live é aberto, os MIDI Effect Racks do Live não são convertidos; eles aparecem no relatório de importação.
