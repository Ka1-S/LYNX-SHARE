O Fruity HTML NoteBook não processa áudio. Ele guarda o endereço de uma página, seja um arquivo .html local ou um endereço da web, para você manter anotações, letras ou referências ao lado do projeto. É adicionado como um efeito de insert.

Controls

ControlWhat it does
AddressO arquivo .html local ou o endereço da web da página.
ProcurarEscolhe um arquivo .html local.
Abrir no navegadorAbre o endereço no seu navegador padrão.

Tips

  • As páginas locais aparecem dentro do editor como texto formatado, e os links abrem no seu navegador.
  • O LYNX SHARE nunca busca páginas da web por conta própria; os endereços da web sempre abrem no seu navegador.
