Um processador de notas VFX do Patcher do FL Studio, sem som próprio. Mapeia as teclas que você toca para outras notas, por exemplo para transformar teclas únicas em acordes ou para mover notas para uma escala. As entradas estão listadas ao longo de uma oitava, e as saídas, na horizontal.

Controls

ControlWhat it does
AtivarLiga o mapeamento.
MultimodoComo uma entrada mapeada para várias notas as toca: All, All (gain-compensated), Aleatório, Ciclo para cima ou Ciclo para baixo.
DeslocamentoMove o mapeamento.
Tom baseA tecla a que o mapeamento é relativo.
Deslize de alturaAjuste de pitch slide das notas mapeadas.

Tips

  • As saídas alcançam de uma oitava abaixo a uma oitava acima de cada entrada.
