O Pocket Distortion modela o sinal com uma de quatro curvas, depois segura amostras para um som esmagado e escala a saída. Use para dar aspereza a baterias, baixos e sintetizadores. É o motor em que os projetos do FL Studio Mobile (.flm) carregam o módulo Distortion deles, e também pode ser adicionado a qualquer slot do Mixer.

Controls

ControlWhat it does
Hard / Tube / Soft / ClipSeleciona a curva. Hard é uma curva de knee que achata conforme o nível sobe, Tube é uma curva tanh, Soft é uma curva exponencial e Clip corta o sinal na escala cheia.
BiasBipolar, de -100 a 100. Soma um offset antes da curva para que as duas metades da onda distorçam de modo diferente. O slider segue uma lei de quinta potência, então age sobretudo perto das pontas. Um filtro passa-alta remove o offset depois da curva.
DriveQuantidade de distorção, mostrada de 0 a 100.
EstéreoDivide o drive entre os lados, mostrado de -100 a 100. Em 0, os dois lados recebem o drive total. Abaixo de 0, o lado esquerdo recebe menos drive, acima de 0, o direito recebe menos.
BitCrushSegura cada amostra de saída por 1 a 257 amostras. O slider segue uma lei de quarta potência, então a primeira metade muda pouco.
GanhoNível de saída, de -24 a 0 dB.

Tips

  • BitCrush baixa a taxa de amostragem segurando amostras. Não reduz a profundidade de bits.
  • Ganho só abaixa o nível. Use para compensar o nível que o Drive acrescenta.
