Gestionnaire de plugins

  1. Choisissez Options › Gestionnaire de plugins.... Il liste tous les plugins trouvés par LYNX, avec leur éditeur, leur format et leur fichier.
  2. Dossiers de plugins... montre où LYNX cherche : les dossiers VST3 et CLAP standard, plus ceux que vous ajoutez.

Recherchez des plugins

  1. Cliquez sur Rechercher de nouveaux plugins. Chaque fichier est vérifié dans un processus séparé, donc un plugin qui plante ne peut pas faire tomber LYNX : il apparaît sous En échec.
  2. Cherchez par nom, éditeur ou format ; une étoile fait d'un plugin un favori.

Chargez un plugin

  1. Dans le Mixer, sélectionnez une piste et cliquez sur un emplacement vide.
  2. Choisissez Plugin (VST/VST3/CLAP), puis Plus de plugins..., trouvez le plugin par son nom et cliquez sur Ajouter.
  3. Le plugin s'ouvre dans sa propre fenêtre. Appuyez sur Play pour l'écouter.
