Ouvrir le morceau

  1. Copiez le morceau sur votre ordinateur : un .flm de FL Studio Mobile, un projet BandLab téléchargé en .blx, ou un .band de GarageBand.
  2. Choisissez Fichier › Ouvrir... (Ctrl+O) et sélectionnez-le, ou déposez-le sur la fenêtre.

Ce que vous obtenez

  • Le morceau s'ouvre dans la disposition Simple, avec une piste par instrument, le tempo, les patterns ou régions et le mixage.
  • Appuyez sur Lecture pour l'écouter.
  • Cliquez sur une piste pour la modifier dans le dock sous la timeline.

Ce qui n'a pas pu être importé

  • Quand quelque chose a dû changer, un court rapport s'ouvre avec le morceau. Ici, le MiniSynth de FL Studio Mobile joue avec l'un des sons de synthé de LYNX SHARE.
  • Aide › Dernier rapport d'import de projet affiche de nouveau ce rapport.
  • Les instruments que l'appli mobile garde pour elle jouent avec les sons intégrés de LYNX SHARE.

Retour sur le téléphone

  • Fichier › Enregistrer une copie comme projet FL Studio Mobile (.flm)... écrit un .flm que vous pouvez ouvrir dans FL Studio Mobile.
