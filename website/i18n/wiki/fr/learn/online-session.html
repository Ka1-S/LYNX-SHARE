Démarrer la session (l'hôte)

  1. Ouvrez le projet que vous voulez partager.
  2. Choisissez Fichier › Session en ligne › Démarrer une session en direct....
  3. Tapez votre nom. Sous Les personnes invitées peuvent modifier, gardez Seulement ses propres canaux, patterns, inserts et lignes (recommandé) ou choisissez Tout.
  4. Cliquez sur Début.

Inviter vos amis

  1. LYNX SHARE affiche le code d'invitation de la session. Cliquez sur Copier.
  2. Envoyez le code à 3 personnes au plus, par chat ou par e-mail.
  3. Fichier › Session en ligne › Afficher le code d'invitation... l'affiche de nouveau plus tard.

Rejoindre (l'invité)

  1. Choisissez Fichier › Session en ligne › Rejoindre une session en direct....
  2. Tapez votre nom, collez le code d'invitation et cliquez sur Rejoindre.
  3. Attendez que l'hôte vous laisse entrer. Le projet de l'hôte s'ouvre.

Les laisser entrer (l'hôte)

Quand quelqu'un demande à rejoindre, cliquez sur Faire entrer, ou sur Pas maintenant.

Travailler ensemble

  • Chaque modification faite par quiconque arrive chez tout le monde. Chaque invité reçoit une couleur, ses propres pistes et ses propres inserts de mixer.
  • Fichier › Session en ligne › Chat de la session... ouvre le chat.
  • L'hôte choisit Fichier › Session en ligne › Mettre fin à la session en direct pour terminer. Le projet reste sur l'ordinateur de l'hôte, et les invités gardent ce que la fenêtre de démarrage indiquait : leur propre partie ou une copie complète.

Bon à savoir

  • Jusqu'à 4 personnes participent, vous compris.
  • Tout est chiffré de bout en bout avec le code d'invitation. Le relais de LYNX SHARE ne fait que transmettre.
  • Pas d'Internet ? Fichier › Session en ligne › Envoyer le projet... crée plutôt un fichier de paquet. Voir Sessions en ligne.
