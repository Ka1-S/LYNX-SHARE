Le Channel Rack

  1. Sur la carte de bienvenue, cliquez sur FL Studio, ou choisissez Vue › Style de disposition › Disposition Pattern (par défaut). Le Channel Rack (F6) affiche les canaux de départ : Kick, Clap, Hat, Snare et Synth.
  2. Chaque ligne est un son et chaque case est un pas (une double croche). Cliquez sur une case pour ajouter un coup, cliquez de nouveau pour le retirer.
  3. Une grosse caisse sur les pas 1, 5, 9 et 13, un clap sur 5 et 13 et des charleys entre les deux forment un beat de base.
  4. Appuyez sur Lecture (ou sur la barre d'espace). En mode Pattern, le pattern boucle.

Le Piano Roll

  1. Appuyez sur F7 pour ouvrir le Piano Roll du canal sélectionné.
  2. Chaque ligne est une touche du clavier à gauche. Cliquez dans la grille pour dessiner une note ; faites glisser son extrémité pour l'allonger.
  3. Faites un clic droit sur une note pour la supprimer.

La Playlist

  1. Appuyez sur F5 pour ouvrir la Playlist. Elle sert à arranger vos patterns en morceau.
  2. Cliquez sur une piste pour y placer le pattern courant. Placez-le plusieurs fois pour qu'il joue plus longtemps.
  3. Passez le transport de Pattern à Song (ou appuyez sur L) puis sur Lecture pour écouter la Playlist.

Le Mixer

  1. Appuyez sur F9 pour ouvrir le Mixer.
  2. Chaque canal joue dans une piste du Mixer. Faites glisser un fader pour régler son niveau et ajoutez des effets dans les slots de la piste.
  3. La piste Master, à gauche, est ce que vous entendez et ce que vous exportez.

Bon à savoir

  • F5, F6, F7 et F9 affichent ou masquent les quatre fenêtres, comme dans FL Studio. F8 ouvre le sélecteur de plugins (Plugin picker).
  • Le même projet s'ouvre aussi dans les dispositions Simple et Clip-launch : voir Un projet, trois dispositions.
