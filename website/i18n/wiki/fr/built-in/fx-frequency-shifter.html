Frequency Shifter est un plugin d'emplacement d'effet qui déplace toutes les fréquences vers le haut ou vers le bas du même nombre de hertz, ce qui rend les sons harmoniques inharmoniques. Il ouvre les réglages d'un plugin Frequency Shifter de FL Studio quand un projet .flp est importé. Sa latence est compensée.
