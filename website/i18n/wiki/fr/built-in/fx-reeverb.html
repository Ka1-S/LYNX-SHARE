Reeverb est une réverb simple pour un insert du Mixer, qui utilise le moteur du premier Fruity Reeverb de FL Studio. Il ouvre les réglages de ce plugin quand un projet .flp est importé. Chaque commande est un bouton avec un affichage de valeur à côté.
