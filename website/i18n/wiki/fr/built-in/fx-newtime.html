Newtime édite le timing d'un sample en déplaçant des marqueurs de warp. Dans LYNX SHARE, il laisse passer l'audio de l'insert sans le changer, comme le plugin de FL Studio. En mode slave, il joue le sample déformé depuis le début du morceau.

Controls

ControlWhat it does
Charger un échantillonChoisit le fichier audio à éditer : WAV, AIFF, FLAC, OGG ou MP3.
Jouer avec le morceauLecture asservie à l'hôte : le sample édité joue depuis le début du morceau.
MagnétismeFait tomber les marqueurs sur la grille rythmique.
Pré-écouteJoue le sample édité.
DuréeOuvre la boîte de dialogue de longueur.
Envoyer à la PlaylistEnvoie le résultat à la Playlist sous forme de clip audio.
Enregistrer en WAVÉcrit l'audio édité dans un fichier.

Tips

  • Les marqueurs d'un projet FL Studio importé sont conservés et utilisés quand le sample joue.
  • La documentation indique que l'étirement temporel est propre à LYNX SHARE, donc les résultats diffèrent de ceux de FL Studio.
