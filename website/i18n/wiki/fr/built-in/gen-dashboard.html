Dashboard est un canal sans son propre. Vous composez votre propre panneau de commandes et vous liez chacune à un potentiomètre ailleurs dans le projet. Il peut aussi envoyer du MIDI. Les Dashboards de FL Studio dans les projets .flp s'ouvrent comme le même type de panneau.

Controls

ControlWhat it does
ÉditerMode édition : faites glisser une commande pour la déplacer, faites un clic droit pour la renommer, la redimensionner ou la supprimer.
AjouterAjoute un potentiomètre, un curseur, un bouton, une case à cocher ou un pad XY.
MIDIRègle le port, le canal, le programme et la banque sur lesquels le Dashboard envoie.
Envoyer du MIDIPar commande : envoie des messages control change, RPN, NRPN, channel pressure ou de note.
RenommerDonne à une commande son propre nom.
TailleChange la taille d'une commande.

Tips

  • Un nouveau Dashboard commence avec deux potentiomètres, Knob 1 et Knob 2.
  • Chaque commande est une sortie : faites un clic droit sur un potentiomètre, Link to internal controller.
