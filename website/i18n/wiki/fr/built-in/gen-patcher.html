Patcher est un graphe de nœuds. Ajoutez des instruments, des effets et des plugins VST3 ou CLAP comme nœuds et reliez-les par des câbles d'audio, de notes et de contrôle. Les câbles sont compensés en délai. Il existe aussi comme slot du Mixer, et les Patchers des projets FL Studio s'ouvrent avec le même graphe.

Controls

ControlWhat it does
Ouvrir le sélecteur de plugins...Ajoute un nœud de plugin depuis le sélecteur.
Parcourir la base de pluginsAjoute un nœud de plugin depuis la base de données de plugins.
Ajuster à la fenêtreZoome le graphe pour montrer tous les nœuds.
Ouvrir l'éditeurOuvre l'éditeur d'un nœud.
Renommer...Renomme un nœud.
BypassDésactive un nœud d'effet.
DéconnecterRetire tous les câbles d'un nœud.
ActivéActive ou désactive un seul câble.
GainRègle le gain d'un câble.
Désactiver les inutilisésMasque les broches de paramètre ou d'événement auxquelles rien n'est câblé.

Tips

  • Faites un clic droit sur un nœud, une broche ou un câble pour obtenir ces menus.
  • Les sorties audio supplémentaires peuvent aller vers d'autres inserts du Mixer.
