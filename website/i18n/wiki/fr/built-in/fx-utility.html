Utility est un petit outil pour les niveaux et le routage des canaux. Ajoutez-le à un insert pour changer le gain, décaler la balance ou échanger et mélanger les canaux.

Controls

ControlWhat it does
GainGain de sortie.
BalanceBalance entre gauche et droite.
L -> LEntrée gauche vers sortie gauche.
R -> LEntrée droite vers sortie gauche.
L -> REntrée gauche vers sortie droite.
R -> REntrée droite vers sortie droite.

Tips

  • Réglez L -> R et R -> L haut et les autres bas pour échanger les canaux.
