Fruity Send est un plugin de slot d'effet qui envoie le signal, à sa position dans la chaîne, vers un autre insert du Mixer. Vous l'utilisez quand il vous faut un envoi au milieu d'une chaîne, par exemple après un effet mais avant le suivant. Il est lu dans les projets FL Studio à l'import.

Controls

ControlWhat it does
DryNiveau du signal qui continue dans la chaîne actuelle.
Envoyer versL'insert du Mixer qui reçoit le signal envoyé.
PanPan du signal envoyé.
VolumeNiveau du signal envoyé.

Tips

  • L'insert cible se choisit dans la case Send to ; la documentation note que dans FL Studio l'insert n'est pas un paramètre automatisable.
  • Pan, Volume et Dry sont modifiables et peuvent être automatisés.
