Distructor est une chaîne de quatre emplacements de module pour un insert. Les modules ne se construisent pas dans l'éditeur : ils viennent d'un preset ou d'un projet Distructor de FL Studio importé. Les impulsions d'ampli et de baffle sont lues dans votre propre installation de FL Studio, donc ces modules en ont besoin.

Controls

ControlWhat it does
Module typeChaque module est une distorsion, un filtre, un chorus ou un ampli avec baffle.
IN (module 1 to 4)Volume d'entrée du module.
MIX (module 1 to 4)Équilibre entre signal dry et wet du module.
OUT (module 1 to 4)Volume de sortie du module.
Écrêtage doux en sortieActive le soft clipper final.

Tips

  • Un emplacement de module vide affiche « Modules come from an FL Studio Distructor preset or project ».
  • Les quatre jeux de boutons sont automatisables comme les autres paramètres d'effet.
