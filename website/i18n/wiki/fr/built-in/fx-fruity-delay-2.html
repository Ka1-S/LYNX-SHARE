Un délai stéréo compact pour les inserts du Mixer. La section Feedback propose les modes normal, inversé et ping-pong. Il reprend les réglages de l'effet équivalent d'un projet FL Studio importé.

Controls

ControlWhat it does
Pan d'entréePlace l'entrée dans le panoramique du délai.
Input volumeNiveau envoyé dans le délai.
DryNiveau du signal non traité.
RéinjectionQuantité de signal réinjectée.
TempsTemps de délai.
Décalage stéréoDifférence de temps entre les canaux.
ModeRéinjection Normal, Inverted ou Ping-pong.
CoupureFiltre dans le chemin de réinjection.

Tips

  • Le mode Ping-pong fait rebondir les répétitions entre la gauche et la droite.
