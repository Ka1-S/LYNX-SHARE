Export your song as MP3 or WAV

Turn your project into a file anyone can play: File › Export › MP3 file (or Wave, FLAC, OGG, AIFF), the bitrate, what to render, and where the file goes.

Any layout · 0:44 · Beginner

Chapters

Open the Export window

  1. Choose File › Export › MP3 file..., or press Ctrl+Shift+R.
  2. File › Export › Wave file... opens the same window with WAV chosen; Ctrl+R opens it with the format you used last.

Format and quality

  1. The format row shows the one you picked. WAV keeps every detail (for mastering or another program); MP3 makes a small file to share.
  2. For MP3 pick the Bitrate: 320 kbps sounds best.
  3. In What to render choose the whole song, the pattern, or the time you selected.
  4. Also save writes other formats from the same render, for example WAV and MP3 at once.

Export

  1. Click Export... and choose where to save. LYNX renders faster than real time.
  2. When it is done, the hint bar shows where the file is.

See also Exporting.
