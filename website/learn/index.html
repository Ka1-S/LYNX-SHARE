Learn LYNX SHARE

Short videos with the same steps written out, and a page for each program you may be coming from.

  1. DownloadFree for Windows, macOS and Linux. Download page
  2. Pick how you like to workThe first start asks where you are coming from and opens the layout that fits. Later: View › Layout style.
  3. Watch a first videoOne minute: make a beat in the Simple layout.
