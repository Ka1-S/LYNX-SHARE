Open an FL Studio project

Open a .flp in the Pattern layout: patterns, Playlist, channels and Mixer come over, and FL Studio's own plugins play on LYNX's engines.

Pattern layout · 0:44 · Beginner

Chapters

Open the .flp

  1. Choose File › Open... (Ctrl+O), or drop the .flp on the window.
  2. Pick the project. LYNX SHARE finds its plugins and samples, then opens it in the Pattern layout.
  3. FL Studio itself is not needed, and the .flp file is never changed.

What comes over

  • Patterns with their notes, the Playlist with its tracks and markers, the channels, the Mixer with its routes, levels and effects.
  • FL Studio's own plugins, such as 3x Osc, play on engines LYNX SHARE recreated. Click a channel's name to open its window.
  • Third-party VST3 and CLAP plugins load when the same plugin is installed.

The import report

  1. When something had to change, a report opens with the project. Help › Last project import report shows it again: what was approximated, left out or not found.
  2. Help › Missing files... lists missing samples and plugins.

Save and export

  • File › Save writes a .lynx project.
  • File › Export › FL Studio project... writes a .flp back for FL Studio.
