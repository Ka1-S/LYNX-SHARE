Themes, text size and language

Make LYNX SHARE look the way you like: theme presets and colors, a bigger or bolder text, and the interface in one of fifteen languages.

Any layout · 0:54 · Beginner

Chapters

Theme presets

  1. Open Options › Theme (colors, background)....
  2. Pick a preset: LYNX, Ocean, Emerald, Amber, Violet or Graphite. Default brings LYNX's own back.

Colors and text size

  1. The knobs shift the hue, saturation, brightness and contrast; each dot colors one part, such as the tracks or the meters.
  2. On the General page, Text size and Bold text make the interface easier to read.

Language and restart

  1. Language lists the fifteen languages of LYNX SHARE.
  2. A new language, font, text size or bold text applies when LYNX SHARE starts again.

See also Settings.
