FAQ

Short answers. The wiki has the details.

Is LYNX SHARE free?

Yes. It is free software under the GNU Affero General Public License v3.0 (AGPL-3.0). You may use, study, modify and redistribute it. Anyone who distributes a modified version must publish its source code under the same licence.

Which systems does it run on?

Windows 10 and 11 (64-bit), macOS 11 or newer (Apple Silicon and Intel) and Linux x86_64 with glibc 2.35 or newer (Ubuntu 22.04, Debian 12, Fedora 36 or newer). The files are on the download page.

Is this FL Studio, or made by Image-Line?

No. LYNX SHARE is an independent program with an FL Studio-style workflow. FL Studio's behaviour and file format were studied clean-room, no Image-Line code was copied, and LYNX SHARE is not affiliated with Image-Line.

Does it open my FL Studio projects, and what is lost?

File › Open... reads .flp files: channels, samples, patterns, arrangements, automation, the Mixer and third-party plugins you have installed. FL Studio's native plugins play on recreated engines, most of them exact or near-exact and a few approximate. FLEX packs are never opened. An import report lists what was approximated or left out. See Coming from FL Studio.

Does it open Ableton Live sets?

Yes, sets saved by Live 11 and 12 (.als): tracks, clips, mixer settings, automation and VST2 or VST3 plugins. Racks and Drum Racks come in with their chains and macros, many of Live's own effects and instruments (EQ Eight, Compressor, Reverb, Auto Filter, Simpler, Drift and more) become LYNX SHARE's own, and the others are dropped and listed in the import report. See Coming from Ableton Live.

Does it open FL Studio Mobile projects?

Partly. A .flm opens with its arrangement, samples, drum kits, DW Sampler and DirectWave programs, the Slicer, the MiniSynth, Transistor Bass, 3x Osc, GMSynth and SuperSaw instruments, FL Studio Mobile's effects, its automation and its chord sets. Other instruments play the built-in synth.

Can I send a project back to FL Studio or Live?

Yes. File › Export › FL Studio project... writes a .flp, and File › Export › Ableton Live set (.als)... writes a set for Live 12 or Live 11. What the other program does not have is rendered to audio or left out, and a report says which. The limits are on the File formats page.

Do my VST plugins work?

VST3 and CLAP plugins load on every system. VST2 loads on Windows and Linux, Audio Units on macOS and LV2 on Linux. On Windows, 32-bit VST2 and VST3 plugins run through a bridge. See Plugins.

Is it stable?

It is an alpha. It opens, plays and exports whole projects, but it is not yet a replacement for the DAW you rely on every day. Save often and report what breaks.

Why does Windows or macOS warn when I open it?

The Windows executable is not code-signed yet, so SmartScreen may warn: click More info, then Run anyway. The macOS app is not notarized by Apple: right-click it and choose Open the first time. The steps are on the Troubleshooting page.

Does it send any data?

There is no telemetry, analytics, account or licence check. It checks GitHub for a new version (you can turn this off in Settings › General › Updates), and it sends a crash report only if you agree each time or set it to always send. It also connects when you ask for a stem model download or take part in a live online session. The privacy policy has the details.

How do updates arrive?

When a newer version exists, a bar under the toolbar offers Update. The Windows installer version installs it over itself. The portable and macOS versions save the new file to your Downloads folder. The Linux AppImage updates through AppImageUpdate or Gear Lever. The Microsoft Store version is updated by the Store and has no Update button. Release notes are on the updates page.

Which languages does the interface have?

Fifteen: English, Simplified Chinese, Traditional Chinese, Dutch, French, German, Indonesian, Italian, Japanese, Korean, Polish, Brazilian Portuguese, Russian, Spanish and Turkish.

How do I report a bug or contribute?

Open an issue at github.com/Ka1-S/LYNX-SHARE/issues, or use Help › Report a problem... inside the program. The source code is in the same repository, and pull requests from contributors have been merged in past releases.

Is there a simpler layout for beginners?

Yes. View › Layout style › Simple workflow shows one window with the tracks and the timeline, and the setup wizard offers it at the first start. The Pattern workflow stays the default, and the same menu switches back. See Simple layout.

Will an update change how my projects sound?

No, not on purpose. When one of LYNX SHARE's effects is refitted to sound closer to the plugin it is modelled on, the new behaviour is a switch (Law: Classic | Measured): new instances use it, and projects and presets saved earlier keep the old one. Only real fixes, such as a limiter that went over its ceiling, change a saved project, and the release notes list them.

Can I use FL Studio's own plugins in LYNX SHARE?

Yes, through the FL Studio plugin that comes with FL Studio. FL Studio installs itself as a plugin too: FL Studio VSTi and FL Studio VSTi (Multi) (VST2) on Windows, and an Audio Unit on macOS. Put it on a channel in LYNX SHARE and FL Studio runs inside it, with its Channel rack, Patcher, Sytrus, Harmor and the other plugins your FL Studio licence covers. It needs FL Studio installed and your own licence. LYNX SHARE does not load FL Studio's plugin files directly, because they are made to run only inside FL Studio. If an older version of LYNX SHARE listed the FL Studio plugin as Failed to load, right-click it in Options › Plugin manager... and choose Try again (scan this file now).
