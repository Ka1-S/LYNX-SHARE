Settings

Every page of the Settings window and what each setting does.

The Settings window has eight pages: Audio, MIDI, General, Theme, Files, LYNX extras, Project and Info. The first six belong to the program. Project and Info belong to the open project and are saved with it. Each page has its own entry at the top of the Options menu.

Change a setting

  1. Open the Options menu and choose a page, for example General settings....
  2. Click another tab along the top to move to another page.
  3. Change the setting. It applies at once, except the language and the interface font, which apply when LYNX SHARE restarts.

F10 opens the MIDI page and F11 the Info page.

Audio

Options › Audio settings.... Driver, devices, sample rate, buffer size and recording. Audio setup describes this page. Under Recording, File format now also offers WAV 16-bit (the device's sample rate).

MIDI

Options › MIDI settings...

SettingWhat it does
Input devicesEach device can be turned off, listen to one MIDI channel only, and play a fixed channel of the Channel rack instead of the selected ones
Controller typeFor each input device: Detect automatically, Generic controller or a controller profile, such as Mackie Control. The line beside it names the port that gets the lights and display
MPE controllerAt the end of a device's MIDI channel list. Each note comes with its own bend, timbre and pressure. A second box sets the member channels
Refresh device listLooks for devices again, and reads your controller profiles again
Controller profiles folderOpens the folder for your own controller profiles (*.lynxctl)
Send master syncSends MIDI clock with Song Position Pointer, or MIDI Time Code, to an output device. Offset (ms) sends it later or earlier
Send all notes offSends all notes off to the device on init and after an export
External clock syncLYNX SHARE follows the MIDI clock of the chosen input: tempo, start, continue, stop and position
VelocityFor notes from MIDI devices: as played, soft, hard or fixed
Performance mode channelNotes on this channel launch Playlist clips in Performance mode
Song marker jumpNotes on this channel move the song to a marker instead of playing
Pickup (takeover mode)A controller moves a parameter only after reaching its current value
Foot pedal controls note offOn by default: the sustain and sostenuto pedals hold notes. Off, the pedal goes to the plugins
Use a game controllerA game controller runs the transport and can be linked like a MIDI controller. Off by default
LinksThe controller links of this project, then the global ones, with Remove link and Remove all

General

Options › General settings...

SettingWhat it does
Layout stylePattern workflow (default), Clip-launch workflow or Simple workflow
Default template, Startup projectThe template that opens with File › New, and what opens at start-up: Empty project, Default template or Last used project. File › Save as template... adds your own
Session clips of Live setsWhere the session clips of an imported Live set go: the clip grid, or the Playlist after the arrangement
Language, Interface fontApplied at the next start
Interface size, Menu densityScale of the whole interface, and compact or comfortable menus
WaveformsClean (the clip colour) or spectral colours, optionally with stereo channels apart
Note names, Black notesEnglish, Germanic or solfège names, with sharps or flats
Plugin styleThe look of the built-in plugin windows: automatic, or one style for every plugin
Animations, Animation rateInterface animations, and how often the playhead and meters move
Draw with the GPU (Direct2D)Turn off if the graphics driver crashes or the screen flickers
StartupSplash screen, startup sound, and looking for new plugins in the background at every start
EditingTyping keyboard to piano, keeping channel editors open, remembering the seek time, looping stretched pattern clips
Detach all new pluginsOn: the window of a plugin you add opens detached, on top of the panels. Off (default): it opens docked in the main window
Monophonic painting in piano rollOn: the Paint tool replaces the notes under each new note, and Shift paints over them. Off: the other way round
Auto select linked modulesFocusing a plugin window selects its mixer track. On by default
Disable typing keyboard priority by defaultFor plugins you add from then on. Off by default
Maximum undo levels25 to 1000
Manage messagesUnder Hints and warnings. Ticked messages are shown. Untick one to skip its question
BackupHow often a backup copy is saved, how many are kept per project, and Open backup folder
Run plugins in a separate processA crashing plugin does not take LYNX SHARE down. Off by default
Substitute missing plugins with LYNX SHARE equivalentsOn by default. When a project uses a third-party plugin that is not installed, LYNX SHARE's stand-in loads with matching settings where it has one. The project keeps the original plugin and uses it again once it is installed
Limit the number of open plugin editorsAt most 25 plugin editor windows stay open. On by default
Crash reportsAsk after a crash or freeze (default), always send or never send
Check for updates automaticallyThe start-up update check, with Check now

LYNX extras

Options › LYNX extras.... LYNX SHARE's own additions in one place. All are off by default. Each switch is the same setting as in the menu or page its line names.

SettingWhat it does
Loudness meter beside the Master (LYNX)Short-term and integrated loudness (LUFS) and the true peak of the Master, with a Reset button
Show only used insertsHides the Mixer inserts nothing uses
Keep links to deleted inserts, greyed (LYNX)Deleting an insert keeps the links that went into it, so they can be connected again
Mixer groups follow the Playlist (LYNX)The Mixer's groups mirror the Playlist's track groups
Automation lanesAutomation can sit in lanes under a Playlist track
Ruler: song bars (LYNX)The Piano roll's ruler shows the bar numbers of the place in the song where the pattern plays
Show a control's value next to the mouse when hovering over it (LYNX)The value shows beside the cursor, not only in the hint bar
After loop recording, only the last pass playsThe earlier passes stay under it, muted
W shows or hides the selected device's windowA key for the Device view
Selecting a device selects its insert in the MixerThe Mixer follows the device picked in the Device view
Use a game controllerThe same switch as on the MIDI page

Project

Options › Project settings (tempo, time signature)...

SettingWhat it does
Time settingsTime division (beats per bar, steps per beat) or a traditional time signature (numerator and denominator)
Tempo, Beats per barThe project's tempo and the beats in a bar
Swing, Master pitchThe global swing amount and the master pitch in cents
Automatic crossfadesOverlapping audio clips on a track crossfade over the overlap
Comp crossfadeThe crossfade length used when comping takes, in milliseconds

Info

Options › Project info.... Title, author, genre, web link and comments of the project, and Show this page when the project is opened. The foot shows when the project was created and the working time.

Good to know

  • The timebase is fixed at 960 ticks per quarter note. Projects from FL Studio are converted to it.
  • Time signature changes along the song are not on the Project page. Add a time signature marker on the Playlist ruler.
  • Run plugins in a separate process applies to plugins opened from then on. Reopen the project to move the others.
  • The update settings are absent in the Microsoft Store version, because the Store updates it.
  • Shortcuts are in Options › Manage shortcuts..., not on a Settings page.
  • Some switches are in menus, not in this window. Low latency while recording is in the recording options menu beside the record button and in the Mixer's Disk recording menu. Keyboard style is in the Piano roll's View menu.
  • The plugin database is a folder, Plugin database in the LYNX folder of your documents. You can arrange it in the file manager.
