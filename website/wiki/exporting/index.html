Exporting

Render the song to audio, stems or MIDI, or save it for another DAW.

On this page

Everything that leaves LYNX SHARE goes through File › Export. The audio formats (WAV, MP3, OGG and FLAC) share one export window. MIDI, FL Studio projects, Ableton Live sets and zipped projects have their own entries in the same menu.

Export the song as a WAV

  1. Choose File › Export › Wave file....
  2. Leave Range on Song (Playlist) and Files on One file (the mix).
  3. Pick a Bit depth: 16 bits, 24 bits or 32 bits (float).
  4. Set Tail to Leave remainder so reverbs and releases ring out after the last bar.
  5. Click Export..., choose a name and a folder, and wait for the render.
  6. When it is done, LYNX SHARE reports where the file went and its peak level.

Ctrl+R opens the window with the format you exported last. Ctrl+Shift+R opens it on MP3.

What to render

SettingWhat it does
RangeSong (Playlist), Current pattern or Playlist selection
PlayHow many times the range plays in the file, from Once to 16 times
TailCut remainder stops exactly at the end. Leave remainder lets the sound ring out. Wrap remainder mixes the tail into the start, for loops
Longest tail3, 6, 12 or 30 seconds. The tail stops earlier when the sound has faded out
FilesOne file, or stems (see below)

Output format

The four buttons choose the format. Also save writes other formats from the same render, with the same name.

FormatOptions
WAVBit depth: 16 bits, 24 bits or 32 bits (float). Dither: Off, TPDF or TPDF + noise shaping
MP3Bitrate, constant
OGGBitrate
FLACBit depth, Compression from 0 (fastest) to 8 (smallest), Dither. Lossless at every level

Sample rate and Channels apply to every format. Channels is Stereo, Mono (both sides mixed), Mono (left only) or Mono (right only).

Mix options

SettingWhat it does
Normalize (peak to 0 dB)Raises or lowers the whole file so its loudest peak reaches full scale
Master effectsOff: the Master insert's effects are bypassed
Insert effectsOff: the effects of the other inserts are bypassed
HQ for all pluginsPlugins use their render quality. Off: the export uses the playback quality
Plugin warm-upThird-party plugins process a moment of silence before the export starts
Disable maximum polyphonyLifts the channels' voice limit, so no note is cut
Trim the delay compensation's silenceRemoves the silence that plugin latency compensation adds at the start
Tempo information, Loop markers, Playlist markersWAV only: store the tempo, the loop and the Playlist's markers in the file
Show the file(s) when completeOpens the file manager on the result

Stems and tracks

Files has three stem modes:

  • One per mixer insert (stems): a file for each insert that gets sound.
  • One per channel (stems): a file for each channel that plays.
  • One per channel, instruments only (no sends or buses).

Tick Also the full mix to get the mix next to the stems. The line at the bottom shows how many files will be written.

File › Export › All playlist tracks and All playlist track groups write one file per Playlist track or per group. In the Mixer's menu, Disk recording › Render armed tracks to wave file(s)... (Alt+R) opens the export window for the armed inserts only.

Exporting to FL Studio and Ableton Live

The .flp is an FL Studio 2026 project. Samplers, audio clips, FL Studio's own generators and effects, third-party plugins, patterns, the Playlist, the Mixer and automation go over with their settings. For the things FL Studio does not have, you choose between Render them to audio (sounds the same) and Use the nearest FL plugin (stays editable, may sound different). With the second choice, LYNX-only instruments are left out. Modulators are always left out. A report lists what was rendered, replaced or left out. Details are in Coming from FL Studio.

The .als holds a MIDI track per channel, audio tracks, groups, returns, sends, racks and Drum Racks, VST2 and VST3 plugins with their state, markers, and volume, pan and tempo automation. LYNX SHARE's own instruments and effects are not converted, though their tracks and notes are kept. Automation of effect parameters and insert-to-insert routes are dropped. Details are in Coming from Ableton Live.

Good to know

  • Dither is greyed out for MP3, and the tempo and marker options are greyed out for every format but WAV.
  • With Playlist selection and no selection in the Playlist, the whole song is rendered. The window warns you.
  • If the Master insert is muted, the window warns that the file will be silent.
  • Also write a video with this mix appears only when the project has a video track, and it needs FFmpeg.
  • Render through the hardware in real time appears only when the project has an active hardware insert. That export takes as long as the song.
  • Render to audio, where an insert is bounced to an audio clip, plays about 5 dB louder than the insert it replaces in this version.
