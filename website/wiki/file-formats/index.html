File formats

Every format LYNX SHARE 0.1.25 opens, imports, saves and exports, with its limits.

The wiki pages are in English only for now.

A project opened from another program's format is an import. File › Save then asks where to write a .lynx file, and the original file is never changed.

What LYNX SHARE opens and imports

FormatWhat it isLimits
.lynxLYNX SHARE's own project format (JSON)None
.lynxpackA project or a part sent in an online sessionOpens after a summary. A part is merged into the host's project
.zipA project with its samples, exported by LYNX SHARE, or FL Studio's zipped loop packageExtracted to a folder, then the project inside is opened
.flpFL Studio projectNative plugins play on recreated engines of varying exactness. FLEX packs are never opened. See Coming from FL Studio
.alsAbleton Live set, Live 11 and 12Live's own effects are dropped and racks keep their first chain. See Coming from Ableton Live
.flmFL Studio Mobile projectPartial: FLM's effects and automation are not imported
.mid, .midiMIDI fileFile › Open... makes a new project from it. File › Import › MIDI file... and the Piano roll import it into the current one
.wav, .aif, .aiff, .flac, .ogg, .mp3Audio files, loaded as samples and audio clipsFiles longer than 30 seconds are streamed from a disk cache
.wvWavPack samples, as shipped in FL Studio's packsRead only
.sf2, .sf3SoundFonts, played by LYNX SoundfontNone stated
.fstPreset of an FL Studio native pluginOnly for the plugins LYNX SHARE has an engine for
.fscFL Studio score and automation filePiano roll and Event editor
Video fileFile › Import › Video file... puts a video on the PlaylistWindows and macOS use the system decoders. Linux needs FFmpeg

What LYNX SHARE saves and exports

FormatWhat it isLimits
.lynxThe project (File › Save), with autosaveNone stated
.zipFile › Export › Project with samples (.zip)...None stated
.lynxpackFile › Online session › Send project...Third-party plugin parts travel as audio renders plus the plugin settings
.flpFile › Export › FL Studio project..., an FL Studio 2026 project or a zipped loop packageLYNX-only instruments and effects are rendered to audio or swapped for the nearest FL plugin. Modulators are left out
.alsFile › Export › Ableton Live set (.als)..., for Live 12 or Live 11LYNX SHARE's own instruments and effects are not converted. Effect-parameter automation and insert-to-insert routes are dropped
WAVFile › Export › Wave file..., 16-bit, 24-bit or 32-bit floatOptional dither, tempo information, loop markers and Playlist markers
MP3File › Export › MP3 file...Constant bitrate
OGGFile › Export › OGG file...None stated
FLACFile › Export › FLAC file..., compression 0 to 8Lossless at every level
StemsThe Files option of the export window: one file per mixer insert, per channel, or per channel with instruments onlyFile › Export › All playlist tracks and All playlist track groups write one file per track or group
.midFile › Export › MIDI file... (Ctrl+Shift+M)None stated
Mastered fileFile › Export › Master... renders the project and masters it to a loudness target, on your computerNone stated
VideoAlso write a video with this mix in the export windowNeeds FFmpeg
Project bonesFile › Export › Project bones... writes channel and effect presets and scores to a folderNone stated

The export window renders the song, the current pattern or the Playlist selection.

From the command line

On Windows the program is LYNX.exe. On macOS and Linux it is LYNX.

LYNX.exe project.lynx                       open a project (.lynx, .flp, .als, .flm or .mid)
LYNX.exe --export project.flp out.flac      render the song (wav, flac or ogg)
LYNX.exe --stems project.flp base.wav       one WAV per mixer insert that has sound
LYNX.exe --export-flp project.lynx out.flp  write an FL Studio project

--export, --stems and --export-flp also accept an .als as the input.
