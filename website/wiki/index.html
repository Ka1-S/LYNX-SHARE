Wiki

A manual for the current release. It covers the basics first; pages marked short have little in them yet.

The wiki pages are in English only for now.

Start here

  • Getting startedInstall LYNX SHARE, set up audio, make a first pattern and save it.

The windows

  • Channel rackStep sequencer with one row per instrument, editing the current pattern.
  • Piano rollEdit the notes of one channel in the current pattern.
  • PlaylistArrange pattern, audio and automation clips on tracks to build the song.
  • MixerInserts with faders, effect slots, sends and sidechain routing.
  • BrowserFind and preview samples, presets and plugins, and drag them into the project.
