## Salvar como

![O projeto salvo como My beat](/assets/img/learn/save-backups-1.webp)

1. Escolha `Arquivo › Salvar como...` e dê um nome ao projeto. Um projeto do LYNX (.lynx) guarda tudo: patterns, o Mixer, plugins e os ajustes deles.
2. A partir daí `Arquivo › Salvar` (`Ctrl+S`) salva por cima. O arquivo substituído vai para os backups.

## Salvar nova versão

![Salvo como uma nova versão](/assets/img/learn/save-backups-2.webp)

1. Testando uma ideia? `Arquivo › Salvar nova versão` (`Ctrl+Alt+S`) salva o projeto como My beat_2, ao lado do primeiro, e você continua trabalhando nele.
2. O LYNX também faz backups enquanto você trabalha, então uma falha ou um erro custa pouco.

## Versões e backups

![A janela Versões](/assets/img/learn/save-backups-3.webp)

1. `Arquivo › Versões...` lista as versões salvas e os backups deste projeto, da mais nova para a mais antiga.
2. Escolha uma e clique em `Abrir como cópia`: ela abre como um projeto novo, ainda não salvo, e os arquivos continuam como estão. `Rótulo...` adiciona uma anotação a ela.
3. `Arquivo › Voltar ao último backup...` troca o projeto aberto pelo backup mais recente dele. O arquivo do projeto só muda quando você salva.
