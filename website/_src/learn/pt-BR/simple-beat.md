## Escolha o Layout Simple

![O cartão de boas-vindas pergunta de onde você vem](/assets/img/learn/simple-beat-1.webp)

1. Abra o LYNX SHARE. Na primeira vez, um cartão de boas-vindas pergunta de onde você vem.
2. Clique em `BandLab, FL Studio Mobile ou GarageBand`. A janela muda para o Layout Simple, e uma batida inicial é colocada numa faixa de bateria.

Sem o cartão, escolha `Exibir › Estilo de layout › Layout Simple`, clique em `+ Adicionar faixa`, depois em `Bateria` e escolha uma das batidas iniciais. O mesmo menu troca de layout a qualquer momento. O projeto continua como está.

## Toque a batida

![O Layout Simple com a batida inicial numa faixa de bateria](/assets/img/learn/simple-beat-2.webp)

1. Aperte Play na barra de ferramentas, ou a barra de espaço.
2. Aperte de novo para parar.

O dock sob a linha do tempo mostra a faixa selecionada. Numa faixa de bateria, ele abre na aba `Drum Machine`.

## Mude a batida

![A Drum Machine: uma linha por som, um quadrado por passo](/assets/img/learn/simple-beat-3.webp)

1. Clique num quadrado cinza da Drum Machine para adicionar uma batida ali. Clique num quadrado aceso para tirá-la.
2. Cada linha é um som do kit: bumbo, caixa, hi-hats, palma e percussão.
3. `Duração` define quantos compassos o pattern tem, e `Swing` atrasa um passo a cada dois.

A letra ao lado de cada linha é a tecla dela no teclado do computador: aperte-a para tocar aquele som.

## Defina o andamento

![O andamento na barra de ferramentas](/assets/img/learn/simple-beat-4.webp)

1. Arraste o andamento para cima ou para baixo, ou dê dois cliques nele e digite um número.
2. Toque a batida de novo para ouvi-la na nova velocidade.

## Próximos passos

![O painel Loops ao lado da linha do tempo](/assets/img/learn/simple-beat-5.webp)

- O cartão `Próximo: 3 coisas para testar` marca cada passo sozinho. `Abrir Loops` abre o painel Loops: arraste um loop para a linha do tempo. Um loop segue o andamento e a tonalidade do projeto.
- [Grave a sua voz](/learn/record-voice/) numa faixa de voz.
- `Concluir` salva a música como WAV ou MP3.
