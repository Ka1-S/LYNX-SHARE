## Gerenciador de plugins

![Opções › Gerenciador de plugins](/assets/img/learn/vst-plugins-1.webp)

1. Escolha `Opções › Gerenciador de plugins...`. Ele lista todos os plugins que o LYNX encontrou, com fabricante, formato e arquivo.
2. `Pastas de plugins...` mostra onde o LYNX procura: as pastas padrão de VST3 e CLAP, mais as que você adicionar.

## Procure plugins

![Os plugins encontrados](/assets/img/learn/vst-plugins-2.webp)

1. Clique em `Buscar plugins novos`. Cada arquivo é testado num processo separado, então um plugin que trava não derruba o LYNX: ele aparece em Com falha.
2. Busque por nome, fabricante ou formato; uma estrela marca o plugin como favorito.

## Carregue um plugin

![A janela de um plugin numa faixa do Mixer](/assets/img/learn/vst-plugins-3.webp)

1. No Mixer, selecione uma faixa e clique num slot vazio.
2. Escolha `Plugin (VST/VST3/CLAP)`, depois `Mais plugins...`, ache o plugin pelo nome e clique em `Adicionar`.
3. O plugin abre na própria janela. Aperte Play para ouvir.

Veja também [Plugins](/wiki/plugins/).
