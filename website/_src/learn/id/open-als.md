## Buka file .als

![File › Open...](/assets/img/learn/open-als-1.webp)

1. Pilih `File › Buka...` (`Ctrl+O`) dan pilih file `.als` set-nya, di dalam folder proyeknya.
2. LYNX SHARE membukanya di tata letak peluncuran klip. Ableton Live sendiri tidak diperlukan, dan `.als` tidak pernah diubah.

## Apa yang ikut terbawa

![Set di tata letak peluncuran klip](/assets/img/learn/open-als-2.webp)

- Track MIDI, audio, grup, dan return, tempo, birama, locator, dan loop.
- Arrangement, serta klip dan scene sesi ke kisi klip, lengkap dengan pengaturan peluncurannya.
- Mixer: volume, pan, mute, solo, send, dan otomatisasinya. Warna Live tetap dipertahankan.
- Plugin VST2 dan VST3 beserta statusnya, jika plugin yang sama terpasang.

## Putar dan lihat device

![Device view](/assets/img/learn/open-als-3.webp)

1. Tekan Play untuk mendengar arrangement, atau luncurkan klip dan scene di kisi.
2. Klik judul sebuah track di kisi, lalu `Tampilan › Tampilan perangkat` (`Ctrl+Alt+4`) menampilkan device-nya.

## Laporan impor dan ekspor

![Help › Last project import report](/assets/img/learn/open-als-4.webp)

1. Jika ada yang harus diubah, sebuah laporan terbuka bersama set. `Bantuan › Laporan impor proyek terakhir` menampilkannya lagi: apa yang didekati atau dilewati.
2. `File › Ekspor › Set Ableton Live (.als)...` menulis set untuk Live 12 atau Live 11.

Lihat juga [Pindahan dari Ableton Live](/wiki/coming-from-ableton/) dan [Format file](/wiki/file-formats/).
