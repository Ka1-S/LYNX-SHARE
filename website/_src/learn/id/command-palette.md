## Command palette

![Command palette dengan "tracker" diketik](/assets/img/learn/command-palette-1.webp)

1. Tekan `?` (atau `Ctrl+Shift+Y`, atau klik kaca pembesar di toolbar).
2. Ketik beberapa huruf dari yang kamu cari. Daftarnya memuat setiap aksi beserta pintasannya, setiap item menu beserta lokasinya, saklar tambahan LYNX, halaman Settings, dan proyek terbaru. Aksi juga bisa ditemukan lewat nama Inggrisnya di semua bahasa.
3. Pilih satu baris dengan tombol panah lalu tekan `Enter`, atau klik dua kali. `Esc` menutup palette.

## Pantau CPU

![Meter CPU di toolbar](/assets/img/learn/command-palette-2.webp)

1. Meter CPU di toolbar menunjukkan seberapa besar waktu audio yang dipakai proyek saat diputar.
2. Klik dua kali untuk membuka Plugin performance monitor: beban setiap plugin dan channel, saat ini, rata-rata, dan puncaknya.

![Plugin performance monitor](/assets/img/learn/command-palette-3.webp)

## Biarkan plugin beristirahat

- `Alat › Alihkan smart disable untuk semua plugin` membuat setiap plugin berhenti sejenak selama menerima keheningan dan tidak mengeluarkan suara, seperti Smart disable di FL Studio.
- Di tata letak peluncuran klip, klik kanan judul sebuah track dan pilih `Nonaktifkan trek` untuk membongkar device-nya sampai dibutuhkan lagi.

Lihat juga [Pintasan keyboard](/wiki/shortcuts/).
