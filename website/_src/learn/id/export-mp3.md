## Buka jendela Ekspor

![File › Export › MP3 file](/assets/img/learn/export-mp3-1.webp)

1. Pilih `File › Ekspor › File MP3...`, atau tekan `Ctrl+Shift+R`.
2. `File › Ekspor › File Wave...` membuka jendela yang sama dengan WAV terpilih; `Ctrl+R` membukanya dengan format yang terakhir kamu pakai.

## Format dan kualitas

![Jendela Ekspor dengan MP3 terpilih](/assets/img/learn/export-mp3-2.webp)

1. Baris format menampilkan format yang kamu pilih. WAV menyimpan setiap detail (untuk mastering atau program lain); MP3 menghasilkan file kecil untuk dibagikan.
2. Untuk MP3 pilih `Bitrate`: 320 kbps terdengar paling bagus.
3. Di `Apa yang di-render` pilih seluruh lagu, pattern, atau rentang waktu yang kamu seleksi.
4. `Simpan juga` menulis format lain dari render yang sama, misalnya WAV dan MP3 sekaligus.

## Ekspor

![Ekspor selesai, di bilah petunjuk](/assets/img/learn/export-mp3-3.webp)

1. Klik `Ekspor...` dan pilih tempat menyimpan. LYNX merender lebih cepat dari waktu nyata.
2. Setelah selesai, bilah petunjuk menampilkan lokasi file.

Lihat juga [Mengekspor](/wiki/exporting/).
