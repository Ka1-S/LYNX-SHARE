## Buat clip otomasi

![Menu kenop: Create automation clip](/assets/img/learn/automation-basics-1.webp)

1. Klik kanan kenop mana pun, di sini Cutoff sebuah synth, dan pilih `Buat clip otomasi`.
2. Clip masuk ke Playlist, sepanjang pattern, dan sebuah channel untuknya muncul di Channel rack.

## Bentuk kurvanya

![Editor otomasi](/assets/img/learn/automation-basics-2.webp)

1. Editor automation terbuka dengan kurva clip. Untuk membukanya nanti, klik kanan kenop dan pilih `Edit clip otomasi...`.
2. Seret titik untuk membentuk kurva; klik untuk menambah titik. Di sini Cutoff mulai tinggi dan turun sepanjang bar.

## Dengarkan

![Kenop mengikuti kurva](/assets/img/learn/automation-basics-3.webp)

1. Tekan Play di mode Song: kenop mengikuti kurva setiap kali lagu diputar.
2. Di tata letak sederhana, tombol `Otomasi` menampilkan jalur di bawah setiap track untuk digambar.

Lihat juga [Otomasi](/wiki/automation/).
