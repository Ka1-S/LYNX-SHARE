## 開啟 .als

![File › Open...](/assets/img/learn/open-als-1.webp)

1. 選擇 `檔案 › 開啟...`（`Ctrl+O`），在專案資料夾中選取該 Live Set 的 `.als` 檔案。
2. LYNX SHARE 會在片段啟動版面中開啟它。不需要安裝 Ableton Live，`.als` 也絕不會被修改。

## 會帶過來什麼

![Live Set 顯示在片段啟動版面中](/assets/img/learn/open-als-2.webp)

- MIDI、音訊、群組和返送音軌，速度、拍號、定位點和循環。
- 編排，以及工作階段片段和場景（進入片段格狀介面，連同它們的啟動設定）。
- 混音台：音量、聲像、靜音、獨奏、傳送及其自動化。Live 中的顏色會保留。
- VST2 和 VST3 外掛及其狀態（需要安裝了相同的外掛）。

## 播放並查看裝置

![裝置檢視](/assets/img/learn/open-als-3.webp)

1. 按播放聽編排，或在格狀介面中啟動片段和場景。
2. 在格狀介面中點擊音軌標題，再選擇 `檢視 › 裝置檢視`（`Ctrl+Alt+4`）即可看到它的裝置。

## 匯入報告和匯出

![Help › Last project import report](/assets/img/learn/open-als-4.webp)

1. 如果有內容需要調整，Live Set 開啟時會跳出一份報告。`說明 › 上次專案匯入報告` 可以再次查看：哪些是近似處理或被省略的。
2. `檔案 › 匯出 › Ableton Live 套裝 (.als)...` 會寫出供 Live 12 或 Live 11 使用的 Live Set。

另見[從 Ableton Live 轉過來](/wiki/coming-from-ableton/)和[檔案格式](/wiki/file-formats/)。
