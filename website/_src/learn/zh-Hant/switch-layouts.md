## 選擇你從哪裡轉過來

![歡迎卡片會問你從哪裡轉過來](/assets/img/learn/switch-layouts-1.webp)

1. 啟動 LYNX SHARE。第一次啟動時，歡迎卡片會問你從哪裡轉過來。
2. 每個回答對應一種版面：
   - `BandLab、FL Studio Mobile 或 GarageBand`：簡易版面，一個視窗裡有音軌、循環素材和快速錄音。
   - `FL Studio`：模式版面，包含 Channel rack、Piano roll、播放清單和混音器。
   - `Ableton Live 或 Bitwig`：片段啟動版面，有片段和場景組成的格狀介面。
3. 點擊其中一個。這裡我們選 BandLab：簡易版面開啟，鼓音軌上放著一段起始節拍。

## 切換版面

![View › Layout style](/assets/img/learn/switch-layouts-2.webp)

1. 選擇 `檢視 › 版面樣式`。
2. 選 `模式工作流程（預設）`、`片段啟動工作流程` 或 `簡易工作流程`。
3. 視窗變了，專案沒變。起始節拍現在是 Channel rack 中的一個樣式，也是播放清單中的一個片段。

![同一首歌在模式版面中](/assets/img/learn/switch-layouts-3.webp)

## 同一首歌在片段啟動版面中

![同一首歌在片段啟動版面中](/assets/img/learn/switch-layouts-4.webp)

1. 選擇 `檢視 › 版面樣式 › 片段啟動工作流程`。
2. 播放清單的音軌成為片段格狀介面的欄，編排檢視在它旁邊。
3. 按播放。三種版面播放和儲存的都是同一個專案。

## 小提醒

- LYNX SHARE 會記住你上次使用的版面。
- `說明 › 歡迎...` 可以再次顯示歡迎卡片。
