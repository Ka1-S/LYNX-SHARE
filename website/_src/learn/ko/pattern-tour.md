## 채널 랙

![채널 랙: 소리마다 한 줄, 스텝마다 네모 하나](/assets/img/learn/pattern-tour-1.webp)

1. 환영 카드에서 `FL Studio`를 클릭하거나 `보기 › 레이아웃 스타일 › 패턴 레이아웃 (기본)`를 선택합니다. 채널 랙(`F6`)에 기본 채널인 Kick, Clap, Hat, Snare, Synth가 보입니다.
2. 각 줄은 소리 하나이고 각 네모는 한 스텝(16분음표)입니다. 네모를 클릭하면 타격이 들어가고, 다시 클릭하면 빠집니다.
3. 킥을 1, 5, 9, 13번 스텝에, 클랩을 5와 13번에, 그 사이에 하이햇을 놓으면 기본 비트가 됩니다.
4. 재생(또는 스페이스바)을 누릅니다. 패턴 모드에서는 패턴이 반복 재생됩니다.

## 피아노 롤

![피아노 롤에 그린 노트](/assets/img/learn/pattern-tour-2.webp)

1. `F7`을 누르면 선택한 채널의 피아노 롤이 열립니다.
2. 각 줄은 왼쪽 건반의 건 하나입니다. 그리드를 클릭해 노트를 그리고, 끝을 끌어 길게 늘입니다.
3. 노트를 우클릭하면 지워집니다.

## 플레이리스트

![플레이리스트 트랙에 네 번 놓은 패턴](/assets/img/learn/pattern-tour-3.webp)

1. `F5`를 누르면 플레이리스트가 열립니다. 패턴을 늘어놓아 한 곡으로 만드는 곳입니다.
2. 트랙을 클릭하면 현재 패턴이 놓입니다. 여러 번 놓으면 그만큼 오래 재생됩니다.
3. 트랜스포트를 `패턴`에서 `송`으로 바꾸고(또는 `L`을 누르고) 재생을 누르면 플레이리스트를 들을 수 있습니다.

## 믹서

![채널마다 트랙이 있는 믹서](/assets/img/learn/pattern-tour-4.webp)

1. `F9`를 누르면 믹서가 열립니다.
2. 각 채널은 믹서 트랙으로 보내져 재생됩니다. 페이더를 끌어 레벨을 정하고, 트랙의 슬롯에 이펙트를 추가합니다.
3. 왼쪽의 마스터 트랙이 실제로 들리는 소리이자 내보내는 소리입니다.

## 알아 두면 좋은 점

- `F5`, `F6`, `F7`, `F9`는 FL Studio와 똑같이 네 창을 보이거나 숨깁니다. `F8`은 플러그인 선택기를 엽니다.
- 같은 프로젝트를 간단한 레이아웃과 클립 실행 레이아웃에서도 열 수 있습니다. [하나의 프로젝트, 세 가지 레이아웃](/learn/switch-layouts/)을 참고하세요.

[FL Studio에서 넘어오기](/wiki/coming-from-fl-studio/)와 [키보드 단축키](/wiki/shortcuts/)도 참고하세요.
