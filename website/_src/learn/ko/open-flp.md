## .flp 열기

![File › Open...](/assets/img/learn/open-flp-1.webp)

1. `파일 › 열기...`(`Ctrl+O`)을 선택하거나 `.flp`를 창에 끌어다 놓습니다.
2. 프로젝트를 고릅니다. LYNX SHARE가 플러그인과 샘플을 찾은 다음 패턴 레이아웃으로 엽니다.
3. FL Studio 자체는 필요 없고, `.flp` 파일은 절대 바뀌지 않습니다.

## 가져오는 것

![플레이리스트와 채널 랙에 열린 프로젝트](/assets/img/learn/open-flp-2.webp)

- 노트가 든 패턴, 트랙과 마커가 있는 플레이리스트, 채널, 라우팅·레벨·이펙트가 있는 믹서.
- 3x Osc 같은 FL Studio 자체 플러그인은 LYNX SHARE가 다시 만든 엔진에서 재생됩니다. 채널 이름을 클릭하면 그 창이 열립니다.
- 서드파티 VST3와 CLAP 플러그인은 같은 플러그인이 설치되어 있으면 불러옵니다.

![채널 랙에서 연 3x Osc](/assets/img/learn/open-flp-3.webp)

## 가져오기 보고서

![Help › Last project import report](/assets/img/learn/open-flp-4.webp)

1. 바뀐 부분이 있으면 프로젝트와 함께 보고서가 열립니다. `도움말 › 마지막 프로젝트 가져오기 보고서`로 다시 볼 수 있으며, 근사하게 처리한 것, 빠진 것, 찾지 못한 것이 나옵니다.
2. `도움말 › 누락된 파일...`에는 없는 샘플과 플러그인이 나열됩니다.

## 저장과 내보내기

- `파일 › 저장`는 `.lynx` 프로젝트를 저장합니다.
- `파일 › 내보내기 › FL Studio 프로젝트...`는 FL Studio용 `.flp`를 다시 만들어 줍니다.

[FL Studio에서 넘어오기](/wiki/coming-from-fl-studio/)와 [파일 형식](/wiki/file-formats/)도 참고하세요.
