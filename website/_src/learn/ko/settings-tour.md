## 설정 페이지

![MIDI 페이지가 열린 설정 창](/assets/img/learn/settings-tour-1.webp)

1. `옵션` 메뉴에서 설정을 여세요. FL Studio처럼 `F10`은 MIDI 페이지로, `Ctrl+,`는 마지막으로 쓴 페이지로 엽니다.
2. 페이지는 FL Studio의 순서를 따릅니다: `MIDI`, `오디오`, `일반`, `파일`, `테마`, `프로젝트`, `정보`.
3. 약간 떨어져서 LYNX만의 페이지가 나옵니다: `Ableton Link`와 `LYNX 추가 기능`.

## 설정 찾기

![설정 찾기가 윤곽을 그린 검색 결과](/assets/img/learn/settings-tour-2.webp)

1. 설정 창에서 `Ctrl+F`를 누르거나 아래쪽 검색 상자를 클릭하고 "metronome", "latency", "autosave" 같은 단어를 입력하세요.
2. 어느 페이지에 있든 첫 번째 결과로 이동해 윤곽을 그려 줍니다. `Enter` 또는 `F3`은 다음 결과로, `Shift+Enter`는 이전 결과로 이동하며, 결과가 없는 탭은 흐려집니다.

## 이 페이지 초기화

![Reset this page와 확인 창](/assets/img/learn/settings-tour-3.webp)

1. 바꾼 설정이 마음에 들지 않나요? `이 페이지 초기화`를 누르고 확인하면 지금 보고 있는 페이지의 모든 옵션이 기본값으로 돌아갑니다.
2. 초기화 후 몇 초 동안은 `실행 취소`로 설정을 되돌릴 수 있습니다.

[설정](/wiki/settings/)과 [모든 명령 찾기](/learn/command-palette/)도 참고하세요.
