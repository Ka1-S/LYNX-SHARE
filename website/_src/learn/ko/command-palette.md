## 명령 팔레트

!["tracker"를 입력한 명령 팔레트](/assets/img/learn/command-palette-1.webp)

1. `?`를 누릅니다(또는 `Ctrl+Shift+Y`, 또는 툴바의 돋보기를 클릭합니다).
2. 찾는 것의 몇 글자를 입력합니다. 목록에는 단축키가 붙은 모든 동작, 위치가 붙은 모든 메뉴 항목, LYNX 추가 기능의 스위치, Settings 페이지, 최근 프로젝트가 들어 있습니다. 동작은 어떤 언어에서든 영어 이름으로도 찾을 수 있습니다.
3. 화살표 키로 한 줄을 고르고 `Enter`를 누르거나 더블 클릭합니다. `Esc`는 팔레트를 닫습니다.

## CPU 살펴보기

![툴바의 CPU 미터](/assets/img/learn/command-palette-2.webp)

1. 툴바의 CPU 미터는 재생 중 프로젝트가 오디오 처리 시간을 얼마나 쓰는지 보여 줍니다.
2. 더블 클릭하면 Plugin performance monitor가 열립니다. 모든 플러그인과 채널의 부하를 현재, 평균, 최고치로 볼 수 있습니다.

![Plugin performance monitor](/assets/img/learn/command-palette-3.webp)

## 플러그인 쉬게 하기

- `도구 › 모든 플러그인 스마트 비활성화 전환`는 FL Studio의 Smart disable처럼, 무음이 들어오고 소리를 내지 않는 플러그인을 모두 잠시 멈춥니다.
- 클립 실행 레이아웃에서는 트랙 제목을 우클릭해 `트랙 비활성화`을 선택하면, 다시 필요해질 때까지 그 트랙의 디바이스가 내려갑니다.

[키보드 단축키](/wiki/shortcuts/)도 참고하세요.
