## Gestione plugin

![Opzioni › Gestione plugin](/assets/img/learn/vst-plugins-1.webp)

1. Scegli `Opzioni › Gestione plugin...`. Elenca tutti i plugin trovati da LYNX, con produttore, formato e file.
2. `Cartelle dei plugin...` mostra dove cerca LYNX: le cartelle standard di VST3 e CLAP, più quelle che aggiungi.

## Cerca i plugin

![I plugin trovati](/assets/img/learn/vst-plugins-2.webp)

1. Clicca `Trova nuovi plugin`. Ogni file viene controllato in un processo separato, quindi un plugin che va in crash non può abbattere LYNX: compare tra i Non riusciti.
2. Cerca per nome, produttore o formato; una stella rende un plugin un preferito.

## Carica un plugin

![La finestra di un plugin su una traccia del Mixer](/assets/img/learn/vst-plugins-3.webp)

1. Nel Mixer, seleziona una traccia e clicca uno slot vuoto.
2. Scegli `Plugin (VST/VST3/CLAP)`, poi `Altri plugin...`, trova il plugin per nome e clicca `Aggiungi`.
3. Il plugin si apre nella sua finestra. Premi Play per ascoltarlo.

Vedi anche [Plugin](/wiki/plugins/).
