## Apri la finestra Esporta

![File › Esporta › File MP3](/assets/img/learn/export-mp3-1.webp)

1. Scegli `File › Esporta › File MP3...`, oppure premi `Ctrl+Shift+R`.
2. `File › Esporta › File Wave...` apre la stessa finestra con WAV scelto; `Ctrl+R` la apre con l'ultimo formato che hai usato.

## Formato e qualità

![La finestra Esporta con MP3 scelto](/assets/img/learn/export-mp3-2.webp)

1. La riga del formato mostra quello che hai scelto. Il WAV conserva ogni dettaglio (per il mastering o un altro programma); l'MP3 fa un file piccolo da condividere.
2. Per l'MP3 scegli il `Bitrate`: 320 kbps suona meglio.
3. In `Cosa renderizzare` scegli il brano intero, il pattern o il tratto che hai selezionato.
4. `Salva anche` scrive altri formati dallo stesso rendering, per esempio WAV e MP3 insieme.

## Esporta

![Esportazione completata, nella barra dei suggerimenti](/assets/img/learn/export-mp3-3.webp)

1. Clicca `Esporta...` e scegli dove salvare. LYNX renderizza più veloce del tempo reale.
2. Quando ha finito, la barra dei suggerimenti mostra dove si trova il file.

Vedi anche [Esportazione](/wiki/exporting/).
