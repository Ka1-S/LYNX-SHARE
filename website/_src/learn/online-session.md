title: Start an online session
summary: Make music with friends over the internet: start a live session, send the invite code, let them in and work on one project together.
---
## Start the session (the host)

![File › Online session › Start live session...](/assets/img/learn/online-session-1.webp)

1. Open the project you want to share.
2. Choose `File › Online session › Start live session...`.
3. Type your name. Under `Guests may edit`, keep `Only their own channels, patterns, inserts and rows (recommended)` or choose `Everything`.
4. Click `Start`.

![The Start live session window](/assets/img/learn/online-session-2.webp)

## Invite your friends

![The invite code](/assets/img/learn/online-session-3.webp)

1. LYNX SHARE shows the session's invite code. Click `Copy`.
2. Send the code to up to 3 people, by chat or e-mail.
3. `File › Online session › Show invite code...` shows it again later.

## Join (the guest)

1. Choose `File › Online session › Join live session...`.
2. Type your name, paste the invite code and click `Join`.
3. Wait for the host to let you in. The host's project opens.

## Let them in (the host)

![Leo wants to join your live session](/assets/img/learn/online-session-4.webp)

When someone asks to join, click `Let them in`, or `Not now`.

## Work together

![A drum track a guest added, on the host's screen](/assets/img/learn/online-session-5.webp)

- Every change anyone makes reaches everyone. Each guest gets a colour and their own tracks and mixer inserts.
- `File › Online session › Session chat...` opens the chat.
- The host chooses `File › Online session › End live session` to end it. The project stays on the host's computer, and guests keep what the start window said: their own part or a full copy.

## Good to know

- Up to 4 people take part, you included.
- Everything is end-to-end encrypted with the invite code. The LYNX SHARE relay only passes it on.
- No internet? `File › Online session › Send project...` makes a package file instead. See [Online sessions](/wiki/online-sessions/).
