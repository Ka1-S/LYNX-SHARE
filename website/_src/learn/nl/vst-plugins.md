## Pluginbeheer

![Opties › Pluginbeheer](/assets/img/learn/vst-plugins-1.webp)

1. Kies `Opties › Pluginbeheer...`. Het toont elke plugin die LYNX vond, met fabrikant, formaat en bestand.
2. `Pluginmappen...` toont waar LYNX zoekt: de standaardmappen voor VST3 en CLAP, plus elke map die je toevoegt.

## Zoeken naar plugins

![De gevonden plugins](/assets/img/learn/vst-plugins-2.webp)

1. Klik op `Nieuwe plugins zoeken`. Elk bestand wordt in een apart proces gecontroleerd, dus een plugin die crasht kan LYNX niet meenemen: hij komt onder Mislukt te staan.
2. Zoek op naam, fabrikant of formaat; met een ster maak je een plugin tot favoriet.

## Een plugin laden

![Het venster van een plugin op een Mixer-track](/assets/img/learn/vst-plugins-3.webp)

1. Selecteer in de Mixer een track en klik op een leeg slot.
2. Kies `Plugin (VST/VST3/CLAP)`, dan `Meer plug-ins...`, zoek de plugin op naam en klik op `Toevoegen`.
3. De plugin opent in een eigen venster. Druk op Afspelen om hem te horen.

Zie ook [Plugins](/wiki/plugins/).
