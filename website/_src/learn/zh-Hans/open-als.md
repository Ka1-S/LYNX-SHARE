## 打开 .als

![File › Open...](/assets/img/learn/open-als-1.webp)

1. 选择 `文件 › 打开...`（`Ctrl+O`），在工程文件夹中选取该 Live Set 的 `.als` 文件。
2. LYNX SHARE 会在片段启动布局中打开它。不需要安装 Ableton Live，`.als` 也绝不会被修改。

## 会带过来什么

![Live Set 显示在片段启动布局中](/assets/img/learn/open-als-2.webp)

- MIDI、音频、编组和返送音轨，速度、拍号、定位点和循环。
- 编排，以及会话片段和场景（进入片段网格，连同它们的启动设置）。
- 调音台：音量、声像、静音、独奏、发送及其自动化。Live 中的颜色会保留。
- VST2 和 VST3 插件及其状态（需要安装了相同的插件）。

## 播放并查看设备

![设备视图](/assets/img/learn/open-als-3.webp)

1. 按播放听编排，或在网格中启动片段和场景。
2. 在网格中点击音轨标题，再选择 `视图 › 设备视图`（`Ctrl+Alt+4`）即可看到它的设备。

## 导入报告和导出

![Help › Last project import report](/assets/img/learn/open-als-4.webp)

1. 如果有内容需要调整，Live Set 打开时会弹出一份报告。`帮助 › 上次工程导入报告` 可以再次查看：哪些是近似处理或被省略的。
2. `文件 › 导出 › Ableton Live 套装 (.als)...` 会写出供 Live 12 或 Live 11 使用的 Live Set。

另见[从 Ableton Live 转过来](/wiki/coming-from-ableton/)和[文件格式](/wiki/file-formats/)。
