## 命令面板

![输入了 "tracker" 的命令面板](/assets/img/learn/command-palette-1.webp)

1. 按 `?`（或 `Ctrl+Shift+Y`，或点击工具栏中的放大镜）。
2. 输入你想要的内容的几个字母。列表包含每个操作及其快捷键、每个菜单项及其位置、LYNX 额外功能的开关、设置页面和你最近的工程。在任何语言下，操作都可以用英文名称找到。
3. 用方向键选择一行并按 `Enter`，或双击它。`Esc` 关闭面板。

## 关注 CPU

![工具栏中的 CPU 表](/assets/img/learn/command-palette-2.webp)

1. 工具栏中的 CPU 表显示工程在播放时占用了多少音频时间。
2. 双击它可以打开插件性能监视器：每个插件和通道当前、平均和峰值的负载。

![插件性能监视器](/assets/img/learn/command-palette-3.webp)

## 让插件休息

- `工具 › 切换所有插件的智能禁用` 让每个插件在收到静音且不发声时暂停，和 FL Studio 的智能禁用一样。
- 在片段启动布局中，右键点击音轨标题并选择 `停用轨道`，可以卸载它的设备，直到你再次需要为止。

另见[键盘快捷键](/wiki/shortcuts/)。
