title: Add your VST3 and CLAP plugins

---
## Plugin manager

![Options › Plugin manager](/assets/img/learn/vst-plugins-1.webp)

1. Choose `Options › Plugin manager...`. It lists every plugin LYNX found, with its vendor, format and file.
2. `Plugin folders...` shows where LYNX looks: the standard VST3 and CLAP folders, plus any folder you add.

## Scan for plugins

![The plugins found](/assets/img/learn/vst-plugins-2.webp)

1. Click `Find new plugins`. Each file is checked in a separate process, so a plugin that crashes can't take LYNX down: it is listed under Failed.
2. Search by name, vendor or format; a star makes a plugin a favourite.

## Load a plugin

![A plugin's window on a Mixer track](/assets/img/learn/vst-plugins-3.webp)

1. In the Mixer, select a track and click an empty slot.
2. Choose `Plugin (VST/VST3/CLAP)`, then `More plugins...`, find the plugin by name and click `Add`.
3. The plugin opens in its own window. Press Play to hear it.

See also [Plugins](/wiki/plugins/).
