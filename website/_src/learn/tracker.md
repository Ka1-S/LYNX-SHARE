---
title: Write a pattern in the Tracker
summary: The Tracker shows a pattern as rows of time and one column per channel: switch on Edit, type notes with the keyboard and play them.
---
## Open the Tracker

![View › Tracker](/assets/img/learn/tracker-1.webp)

1. Choose `View › Tracker` (`Shift+F7`). In the Clip-launch layout, right-click a clip and choose `Edit in tracker`; in the Simple layout it is a tab of the dock.
2. Time runs down the rows, one row per step. Each channel with notes, and the selected one, gets a column: `Note`, `Vol`, `Dly` and `Fx`.

## Type notes

![Notes typed in the Kick column](/assets/img/learn/tracker-2.webp)

1. Press `Ctrl+E`, or click `Edit`, so the typing keys write notes at the cursor. With Edit off they only play.
2. The keys `Z` to `M` and `Q` to `P` play and write notes, as on FL Studio's typing keyboard. `Octave` sets the octave.
3. After each note the cursor moves down by `Step` rows. Move with the arrow keys; `Tab` goes to the next channel.
4. `1` writes a note off, `Delete` clears a cell, `Insert` and `Backspace` shift the rows below. Hex digits fill the `Vol`, `Dly` and `Fx` values.

## Play and edit

![The Tracker while the pattern plays](/assets/img/learn/tracker-3.webp)

1. Press Play. With `Follow` on, the rows scroll with the playback.
2. `Ctrl+Up` and `Ctrl+Down` transpose the selection, or the note at the cursor, by a semitone; add `Shift` for an octave.
3. The Tracker, the Channel rack and the Piano roll edit the same pattern, so every change shows in all three.

See also [Keyboard shortcuts](/wiki/shortcuts/).
