## Палитра команд

![Палитра команд с введённым «tracker»](/assets/img/learn/command-palette-1.webp)

1. Нажмите `?` (или `Ctrl+Shift+Y`, или щёлкните лупу на панели инструментов).
2. Введите несколько букв того, что нужно. В списке есть каждое действие с его горячей клавишей, каждый пункт меню с его местом, переключатели дополнений LYNX, страницы Настроек и недавние проекты. Действия находятся по английским названиям и в любом другом языке.
3. Выберите строку стрелками и нажмите `Enter` или щёлкните её дважды. `Esc` закрывает палитру.

## Следите за CPU

![Индикатор CPU на панели инструментов](/assets/img/learn/command-palette-2.webp)

1. Индикатор CPU на панели инструментов показывает, какую долю аудиовремени проект занимает при воспроизведении.
2. Щёлкните его дважды, чтобы открыть монитор производительности плагинов: нагрузка каждого плагина и канала, сейчас, в среднем и в пике.

![Монитор производительности плагинов](/assets/img/learn/command-palette-3.webp)

## Дайте плагинам отдохнуть

- `Сервис › Переключить умное отключение для всех плагинов` позволяет каждому плагину приостанавливаться, пока он получает тишину и не издаёт звука, как Smart disable в FL Studio.
- В раскладке с запуском клипов щёлкните заголовок дорожки правой кнопкой и выберите `Деактивировать трек`, чтобы выгрузить её устройства, пока они снова не понадобятся.

См. также [Горячие клавиши](/wiki/shortcuts/).
