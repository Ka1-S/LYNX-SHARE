## Ouvrez la fenêtre d'export

![Fichier › Exporter › Fichier MP3](/assets/img/learn/export-mp3-1.webp)

1. Choisissez `Fichier › Exporter › Fichier MP3...`, ou appuyez sur `Ctrl+Shift+R`.
2. `Fichier › Exporter › Fichier Wave...` ouvre la même fenêtre avec WAV choisi ; `Ctrl+R` l'ouvre avec le dernier format utilisé.

## Format et qualité

![La fenêtre d'export avec MP3 choisi](/assets/img/learn/export-mp3-2.webp)

1. La ligne du format montre celui que vous avez choisi. Le WAV garde tous les détails (pour le mastering ou un autre programme) ; le MP3 donne un petit fichier à partager.
2. Pour le MP3, choisissez le `Débit` : 320 kbps sonne le mieux.
3. Dans `Que faut-il rendre`, choisissez le morceau entier, le pattern ou la zone que vous avez sélectionnée.
4. `Enregistrer aussi` écrit d'autres formats à partir du même rendu, par exemple WAV et MP3 en une fois.

## Exporter

![Export terminé, dans la barre d'aide](/assets/img/learn/export-mp3-3.webp)

1. Cliquez sur `Exporter...` et choisissez où enregistrer. LYNX fait le rendu plus vite que le temps réel.
2. Quand c'est fini, la barre d'aide indique où se trouve le fichier.

Voir aussi [Exporter](/wiki/exporting/).
