## Ouvrir le .als

![Fichier › Ouvrir...](/assets/img/learn/open-als-1.webp)

1. Choisissez `Fichier › Ouvrir...` (`Ctrl+O`) et sélectionnez le fichier `.als` du set, dans son dossier de projet.
2. LYNX SHARE l'ouvre dans la disposition Clip-launch. Ableton Live n'est pas nécessaire, et le `.als` n'est jamais modifié.

## Ce qui est importé

![Le set dans la disposition Clip-launch](/assets/img/learn/open-als-2.webp)

- Les pistes MIDI, audio, de groupe et de retour, le tempo, la signature rythmique, les locators et la boucle.
- L'arrangement, ainsi que les clips et scènes de session dans la grille de clips, avec leurs réglages de lancement.
- La table de mixage : volume, pan, mute, solo, sends et leur automation. Les couleurs de Live sont conservées.
- Les plugins VST2 et VST3 avec leur état, quand le même plugin est installé.

## Jouer et voir les devices

![La Device view](/assets/img/learn/open-als-3.webp)

1. Appuyez sur Lecture pour écouter l'arrangement, ou lancez des clips et des scènes dans la grille.
2. Cliquez sur le titre d'une piste dans la grille, puis sur `Vue › Vue des appareils` (`Ctrl+Alt+4`) pour voir ses devices.

## Rapport d'import et export

![Aide › Rapport du dernier import](/assets/img/learn/open-als-4.webp)

1. Quand quelque chose a dû changer, un rapport s'ouvre avec le set. `Aide › Dernier rapport d'import de projet` l'affiche de nouveau : ce qui a été approché ou omis.
2. `Fichier › Exporter › Set Ableton Live (.als)...` écrit un set pour Live 12 ou Live 11.

Voir aussi [Venir d'Ableton Live](/wiki/coming-from-ableton/) et [Formats de fichier](/wiki/file-formats/).
