## Patterns ou pistes

![Le Channel rack d'un nouveau projet](/assets/img/learn/track-only-1.webp)

1. Dans FL Studio, les instruments sont dans le Channel rack et jouent des patterns que vous placez dans la Playlist.
2. Si vous préférez les pistes, comme dans la plupart des autres logiciels, activez le Mode pistes seules.

## Activez le Mode pistes seules

![Le Mode pistes seules dans les LYNX extras](/assets/img/learn/track-only-2.webp)

1. Ouvrez `Options › Extras LYNX...`, appuyez sur `Ctrl+F` et tapez "track-only", puis cliquez sur l'interrupteur. `Vue › Style de disposition` l'a aussi.
2. LYNX propose à chaque instrument une piste à lui : cliquez sur `Oui`. Une seule annulation revient en arrière.

## Dessinez des clips sur les pistes

![Des clips dessinés sur des pistes d'instrument](/assets/img/learn/track-only-3.webp)

1. Cliquez sur une piste pour dessiner un clip : il joue l'instrument de cette piste. Double-cliquez sur un clip pour écrire ses notes.
2. `F6` ouvre toujours le Channel rack, avec les mêmes instruments, chacun jouant par la piste de mixage de sa piste.

Voir aussi [Playlist](/wiki/playlist/) et [Les trois dispositions](/wiki/layouts/).
