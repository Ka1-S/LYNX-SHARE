![Tata letak sederhana: track di linimasa, beat awal, dan Drum Machine](/assets/img/learn/simple-beat-2.webp)

Pilih **tata letak sederhana**. Isinya satu jendela dengan track-mu di linimasa, loop, drum machine, dan perekaman cepat, seperti cara kerja BandLab, FL Studio Mobile, dan GarageBand. Dua tata letak lainnya hanya sejauh satu klik.

## Tiga hal pertamamu

1. **Pilih tata letak.** Saat LYNX SHARE pertama kali dijalankan, sebuah kartu sambutan menanyakan dari mana kamu datang. Klik `BandLab, FL Studio Mobile, atau GarageBand`: jendela beralih ke tata letak sederhana, dengan beat awal di track Drums. Nanti, `Tampilan › Gaya tata letak › Alur kerja sederhana` beralih ke sana kapan saja.
2. **Buat beat.** Klik kotak-kotak Drum Machine di bawah linimasa. Lihat [Membuat beat di tata letak sederhana](/learn/simple-beat/).
3. **Tambahkan loop dan suaramu.** `Loop` membuka panel loop: seret sebuah loop ke linimasa. Lalu [rekam suaramu](/learn/record-voice/) di track Voice.

## Yang sama

- Track di linimasa, satu per suara atau instrumen, masing-masing dengan volume, pan, mute, solo, dan efek.
- Drum machine dengan kisi step, loop yang mengikuti tempo dan kunci nada lagu, dan perekaman di track suara.
- Efek satu kenop, dan suara jadi untuk seluruh lagu sebelum kamu menyimpan.
- Bermusik bersama teman: [sesi online](/learn/online-session/) menempatkan sampai 4 orang dalam satu proyek.

## Yang berbeda

- LYNX SHARE adalah program desktop untuk Windows, macOS, dan Linux. Program ini tidak berjalan di browser atau di ponsel.
- Proyekmu adalah file `.lynx` di komputermu. Tidak ada akun dan tidak ada cloud: simpan, cadangkan, dan kirim seperti file lainnya.
- Plugin pihak ketiga bisa dimuat (VST3 dan CLAP, Audio Units di macOS, LV2 di Linux, VST2 di Windows dan Linux), di samping instrumen dan efek bawaan LYNX SHARE.
- Kalau kamu ingin lebih, tata letak Pattern (cara kerja FL Studio, dengan Channel rack dan Piano roll) dan Mixer (`F9`) bekerja di proyek yang sama.

## Padanannya

| Di aplikasi-aplikasi itu | Di tata letak sederhana LYNX SHARE |
|---|---|
| Tampilan track atau Mix Editor | Linimasa: satu track per suara atau instrumen |
| Menambah track | `+ Tambah trek`: `Vokal / audio`, `Instrumen`, `Drum`, `Sampler`, `Gitar / bass`, `Impor`, `Loop` |
| Drum machine atau step sequencer | Tab `Drum Machine` di track Drums: kisi step, pattern A sampai H, panjang, dan swing |
| Pad drum | 16 pad track Sampler, dimainkan dengan tombol komputer |
| Pustaka loop | `Loop`: seret loop ke linimasa. Loop mengikuti tempo dan kunci nada proyek |
| Piano roll | Tab `Editor` di dock, atau `Buka di Piano Roll` untuk semua alat |
| Keyboard di layar dan chord | Tab `Keyboard` di dock: piano, `Tuts tangga nada`, atau `Pad chord` |
| Efek track dan preset | Tab `Efek` di dock: efek satu kenop, rantai siap pakai di `Preset`, dan `Blend` |
| Koreksi nada untuk vokal | LYNX Tune, pengoreksi nada dengan kunci dan skala (`+` di dock, lalu `Efek lainnya...`) |
| Mastering | `Selesai`: suara jadi untuk seluruh lagu, lalu simpan sebagai WAV atau MP3 |
| Lirik | `Lirik` |
| Tuner | `Tuner` di toolbar |
| Mixer | `F9` |
| Bagian lagu (intro, bait, refrein) | `Bagian` di bilah judul: bagian yang bisa dipindah, disalin, dan diulang sebagai satu kesatuan |
| Meredam beat di bawah vokal, send echo | `Redam di bawah` dan knob `Echo`, di samping `Reverb` di tab `Efek` pada dock |

## Proyekmu

- **FL Studio Mobile** (`.flm`): `File › Buka...` membukanya. Impornya sebagian: tempo, track, pattern, clip audio, drum kit, DW Sampler, Slicer, MiniSynth, Transistor Bass, 3x Osc, GMSynth, SuperSaw, dan efek FLM ikut masuk. Instrumen FLM lainnya dimainkan oleh synth bawaan LYNX SHARE. `File › Simpan salinan sebagai proyek FL Studio Mobile (.flm)...` menulis salinan kembali untuk FL Studio Mobile.
- **GarageBand** (`.band`, dari GarageBand 10 atau GarageBand untuk iOS): `File › Buka...` membukanya sebagai track tata letak sederhana dengan region, tempo, kunci nada, dan mix-nya. Track instrumen dimainkan oleh synth dan drum bawaan LYNX SHARE, karena GarageBand tidak menyimpan suaranya dalam bentuk yang bisa dibaca program lain.
- **BandLab** (`.blx`, proyek yang diunduh oleh Cakewalk atau Sonar): `File › Buka...` membukanya sebagai track tata letak sederhana dengan region, tempo, kunci nada, mix, otomasi volume dan pan, serta efek yang umum. Suara instrumen BandLab dan efek lainnya tercantum di laporan impor.
- **Stem dari aplikasi apa pun**: ekspor track sebagai file audio atau MIDI, taruh di satu folder, lalu klik `+ Tambah trek`, dan `Folder...` di samping `Impor`. Setiap file menjadi track yang dimulai dari awal.

`Bantuan › Laporan impor proyek terakhir` mencantumkan apa yang diperkirakan atau dilewati. Lihat [Format file](/wiki/file-formats/).

## Perlu diketahui

- `File › Simpan` menulis file `.lynx`. File yang kamu buka tidak pernah diubah.
- `Selesai` menyimpan lagu sebagai WAV atau MP3, dan `File › Ekspor` punya lebih banyak format dan stem. Lihat [Ekspor](/wiki/exporting/).
- `Bantuan › Tur lagu pertama` memandumu membuat lagu pertama dalam sekitar lima menit.

BandLab adalah merek dagang BandLab Technologies. FL Studio Mobile adalah merek dagang Image-Line Software. GarageBand adalah merek dagang Apple Inc. LYNX SHARE adalah program independen, tidak berafiliasi dengan atau didukung oleh mereka.
