![设置窗口的常规页面，顶部是七个页面标签](/assets/img/wiki/settings-general.webp)

设置窗口有七个页面：音频、MIDI、常规、主题、文件、工程和信息。前五个属于程序本身。工程和信息属于已打开的工程，并随工程一起保存。每个页面在 `选项` 菜单顶部都有各自的条目。

## 更改设置

1. 打开 `选项` 菜单，选择一个页面，例如 `常规设置...`。
2. 点击顶部的另一个标签，切换到其他页面。
3. 更改设置。它会立即生效，只有语言和界面字体例外，它们在 LYNX SHARE 重新启动后才生效。

`F10` 打开 MIDI 页面，`F11` 打开信息页面。

## 音频

`选项 › 音频设置...`。驱动程序、设备、采样率、缓冲区大小和录制。[音频设置](/wiki/audio-setup/)介绍了这个页面。

## MIDI

![MIDI 页面：输入设备、带主同步的输出设备，以及外部同步](/assets/img/wiki/settings-midi.webp)

`选项 › MIDI设置...`

| 设置 | 作用 |
|---|---|
| 输入设备 | 每个设备都可以关闭，可以只监听一个 MIDI 通道，也可以演奏通道机架中固定的一个通道，而不是所选的通道 |
| `刷新设备列表` | 重新查找设备 |
| `发送主同步` | 向输出设备发送带 Song Position Pointer 的 MIDI 时钟，或 MIDI Time Code。`偏移 (ms)` 让它更晚或更早发送 |
| `发送全部音符关闭` | 在初始化时和导出之后向设备发送全部音符关闭 |
| `外部时钟同步` | LYNX SHARE 跟随所选输入的 MIDI 时钟：速度、开始、继续、停止和位置 |
| `力度` | 用于来自 MIDI 设备的音符：按演奏、轻、重或固定 |
| `表演模式通道` | 这个通道上的音符会在表演模式下启动播放列表片段 |
| `歌曲标记跳转` | 这个通道上的音符会让歌曲跳转到某个标记，而不是发声 |
| `拾取（接管模式）` | 控制器只有在到达参数当前值之后才会移动该参数 |
| 关联 | 先是此工程的控制器关联，然后是全局关联，带有 `移除关联` 和 `全部移除` |

## 常规

`选项 › 常规设置...`

| 设置 | 作用 |
|---|---|
| `布局样式` | 样式工作流程（默认）或片段启动工作流程 |
| `Live 工程的会话片段` | 导入的 Live 套装的 Session 片段去哪里：片段网格，或编排之后的播放列表 |
| `语言`、`界面字体` | 下次启动时生效 |
| `界面大小`、`菜单密度` | 整个界面的缩放，以及紧凑或宽松的菜单 |
| `波形` | 纯色（片段颜色）或频谱色彩，还可以选择把立体声通道分开显示 |
| `音名`、`黑键` | 英语式、德语式或固定唱名式的音名，用升号或降号 |
| `插件风格` | 内置插件窗口的外观：自动，或所有插件统一一种风格 |
| `动画`、`动画速率` | 界面动画，以及播放头和电平表的刷新频率 |
| `使用GPU绘制（Direct2D）` | 如果显卡驱动崩溃或屏幕闪烁，请关闭它 |
| 启动 | 启动画面、启动音效，以及每次启动时在后台查找新插件 |
| 编辑 | 电脑键盘当钢琴、保持通道编辑器打开、记住定位时间、循环被拉伸的样式片段 |
| `最大撤销次数` | 25 到 1000 |
| 备份 | 多久保存一次备份副本、每个工程保留多少个，以及 `打开备份文件夹` |
| `在独立进程中运行插件` | 崩溃的插件不会拖垮 LYNX SHARE。默认关闭 |
| `用LYNX SHARE对应插件替代缺失的插件` | 默认开启。工程仍保留原来的插件 |
| `崩溃报告` | 崩溃或卡死后询问（默认）、始终发送或从不发送 |
| `自动检查更新` | 启动时检查更新，带有 `立即检查` |

## 主题

`选项 › 主题（颜色、背景）...`

| 设置 | 作用 |
|---|---|
| 主题框 | 选择一个预设。`导入...` 和 `导出...` 读取和写入 `.lynxtheme` 文件，`保存预设...` 保存当前主题，`默认` 将其重置 |
| `强调色`、`背景`、`工作区` | 主题的三种颜色。工作区颜色可以自动跟随背景 |
| 工作区图像 | 窗口后面的 PNG、JPEG 或 GIF 图像，带有 `图像适配`、`图像不透明度` 和 `变暗` |
| 启动音效 | 你自己的 30 秒或更短的声音，或 LYNX SHARE 自带的声音 |

## 文件

`选项 › 文件设置（搜索文件夹）...`

| 设置 | 作用 |
|---|---|
| 缺失采样的搜索文件夹 | 缺失的文件窗口会自动在这些文件夹及其子文件夹中查找 |
| 浏览器文件夹 | 显示在浏览器的文件夹列表中，也会用来搜索缺失的采样 |
| 插件文件夹 | 由 `选项 › 扫描插件` 扫描其中的插件 |

## 工程

![工程页面：时间设置、律动与调音、时基和播放列表选项](/assets/img/wiki/settings-project.webp)

`选项 › 工程设置（速度、拍号）...`

| 设置 | 作用 |
|---|---|
| `时间设置` | 时间划分（每小节的拍数、每拍的步数），或传统的拍号（分子和分母） |
| `速度`、`每小节拍数` | 工程的速度，以及每小节的拍数 |
| `摇摆`、`主控音高` | 全局摇摆量，以及以音分计的主控音高 |
| `自动交叉淡化` | 轨道上重叠的音频片段会在重叠部分交叉淡化 |
| `合成轨交叉淡化` | 合成录音时使用的交叉淡化长度，以毫秒计 |
| `播放片段中被截断的音符` | 在样式片段开始之前就已开始的音符，会从片段的起点开始播放 |
| `切断组快速去咔嗒` | 切断组切断音符时使用更快的渐变 |
| `声像定律` | 圆形（中间 0 dB，声像所在一侧 +3 dB）或三角形（较响的一侧保持原电平）。用于混音台插入轨和采样器通道 |

## 信息

`选项 › 工程信息...`。工程的标题、作者、流派、网页链接和备注，以及 `打开工程时显示此页面`。底部显示工程的创建时间和工作时间。

## 须知

- 时基固定为每四分音符 960 tick。来自 FL Studio 的工程会被转换到这个时基。
- 沿着歌曲变化的拍号不在工程页面上设置。请在播放列表标尺上添加拍号标记。
- `在独立进程中运行插件` 只对此后打开的插件生效。重新打开工程才能移动其余的插件。
- Microsoft Store 版本没有更新设置，因为 Store 会负责更新它。
- 快捷键在 `选项 › 管理快捷键...` 中，不在设置页面上。
