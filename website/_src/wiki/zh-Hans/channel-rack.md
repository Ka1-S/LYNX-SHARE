![带有步进行的通道机架](/assets/img/rack.webp)

通道机架列出工程中的每个乐器（通道），每个占一行，并显示当前样式的各个步。按 `F6` 显示或隐藏它。右键单击走带栏中的样式按钮也会显示它。

## 制作鼓点样式

1. 按 `F6` 显示通道机架。
2. 单击最后一行下方的 `+ 添加通道` 框，从菜单中选一个乐器。你也可以在[浏览器](/wiki/browser/)中双击一个采样，得到新的采样器通道。
3. 单击通道那一行里的步，将其打开。拖动可画出连续的一串步。
4. 右键单击某一步可将其擦除。
5. 按 `Space` 播放。在样式模式下，样式会循环播放。
6. 拖动该行的音量旋钮来设定电平。

## 输入步

- 单击某一步将其打开。拖动可画出连续的一串步。如果拖动从一个已亮起的步开始，则改为擦除。
- 右键单击或右键拖动即擦除。
- 在样式末尾之后单击会添加一个步，并使样式变长。
- 如果某一行的音符不是普通的步（其他琴键、更长的音符、滑音），则显示这些音符的缩略图。单击它会在[钢琴卷帘](/wiki/piano-roll/)中打开这些音符。
- 你可以把音频文件拖放到机架上来创建通道。

通道菜单（右键单击通道名称）中有 `每2步填充`、`每4步填充`、`每8步填充`、`高级填充`，以及 `向左轮转` 和 `向右轮转`。

## 图形栏

![图形栏在 Kick 通道下方打开，每一步对应一根力度条](/assets/img/wiki/rack-graph.webp)

`Ctrl+K` 在所选通道下方显示图形栏。它左侧的按钮用来选择编辑的内容：力度、声像、释音、微调音高、Mod X 或 Mod Y。拖动可为每一步设定数值，右键拖动画出斜坡，`Alt` + 单击则重置某一步。

## 一行的各个部分

| 部分 | 作用 |
|---|---|
| 静音灯 | 单击静音。`Ctrl` + 单击或右键单击为独奏。 |
| 声像和音量旋钮 | 拖动或使用滚轮。 |
| 路由框 | 拖动或滚轮选择混音台插入轨。双击会在混音台中显示该插入轨。右键单击选取下一个空闲插入轨。 |
| 名称按钮 | 单击打开或关闭通道的编辑器。`Alt` + 单击会让其他编辑器保持打开。`Ctrl` + 单击试听。上下拖动调整顺序。右键单击打开通道菜单。 |
| 选择器 | 单击选中一个通道。`Ctrl` + 单击或右键单击添加或移除。`Shift` + 单击选中一个范围。双击全选。 |

## 样式

机架始终编辑当前样式。机架的样式选择器显示其名称：单击名称可打开列表，也可以使用箭头。在机架标题上按 `Shift` + 滚轮同样可以切换样式。

机架的样式长度框以小节为单位设定长度（拖动或使用滚轮）。双击它可根据音符自动得出长度。

主工具栏中的摇摆旋钮作用于所有通道。通道菜单中的 `摇摆混合` 设定某个通道跟随它的程度。

| 命令 | 按键 | 作用 |
|---|---|---|
| 下一个样式 | `Numpad +` | 将下一个样式设为当前样式 |
| 上一个样式 | `Numpad -` | 将上一个样式设为当前样式 |
| 下一个空样式 | `F4` | 转到下一个空样式并询问名称 |
| 重命名并设置颜色 | `F2` | 重命名当前样式并为其设置颜色 |

## 用电脑键盘弹奏音符

`Ctrl+T` 把打字键盘变成钢琴：`Z` 到 `M` 以及 `Q` 到 `P` 演奏所选通道。开启期间，各编辑器的单字母快捷键会暂停。

## 按键

这些在通道机架处于焦点时有效。

| 命令 | 按键 | 作用 |
|---|---|---|
| 选择通道 | `Up` / `Down` | 选中上方或下方的通道 |
| 扩展选区 | `Shift+Up` / `Shift+Down` | 把上方或下方的通道加入选区 |
| 移动通道 | `Alt+Up` / `Alt+Down` | 上移或下移所选通道 |
| 全选 | `Ctrl+A` | 选中所有通道 |
| 剪切、复制、粘贴 | `Ctrl+X` / `Ctrl+C` / `Ctrl+V` | 剪切、复制或粘贴所选通道的步 |
| 轮转步 | `Ctrl+Shift+Left` / `Ctrl+Shift+Right` | 轮转所选通道的步 |
| 克隆 | `Alt+C` | 克隆所选通道 |
| 删除 | `Alt+Del` | 删除所选通道 |
| 编组 | `Alt+G` | 把所选通道放入新的过滤组 |
| 路由到混音台 | `Ctrl+L` | 把所选通道发送到空闲的混音台插入轨 |
| 静音 | `1` 到 `0` | 对通道 1 到 10 静音或取消静音 |
| 独奏 | `Ctrl+1` 到 `Ctrl+0` | 对通道 1 到 10 独奏 |
| 图形栏 | `Ctrl+K` | 显示或隐藏图形栏 |

## 通道菜单中的其他项目

`钢琴卷帘`、`重命名并设置颜色`、`替换`（更换乐器）、`克隆`、`Delete`、`琶音器`、`循环点`、`MIDI 写入到`、`通道排序`、`选择未使用的通道` 和 `通道设置`。

## 须知

- 只有 `+ 添加通道` 框会打开添加菜单。
- 机架本身没有样式。在任何地方更改当前样式，机架显示的内容就会随之改变。
- 显示音符缩略图的行无法按步编辑。请用钢琴卷帘来编辑。
- 数字键只对前十个通道有效。
- 表中的按键需要机架处于焦点。请先单击机架。
