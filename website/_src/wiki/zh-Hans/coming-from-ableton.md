LYNX SHARE 默认以样式工作流程启动：通道机架、样式和播放列表。片段启动工作流程是可选的，它会在播放列表旁边增加一个带有场景的片段网格。LYNX SHARE 可以读取和写入 `.als` 套装。它与 Ableton 没有任何关联。

## 打开 Live 套装

1. 选择 `文件 › 打开...`（`Ctrl+O`），然后选取 `.als` 文件。Live 11 和 Live 12 保存的套装都可以读取。
2. 选择 `视图 › 布局样式 › 片段启动工作流程`，即可使用片段网格；套装中的会话片段和场景会放在这里。
3. 用播放列表标题栏中的 `Grid / Both / Song` 开关来显示网格、播放列表，或两者同时显示。
4. 选择 `文件 › 保存`。它会询问把 `.lynx` 文件写到哪里。`.als` 文件不会被更改。

`视图 › 布局样式 › 模式工作流程（默认）` 可以切换回去。`选项 › 常规设置...` 中也有同样的选项。两种布局下，样式和通道机架都仍然可用。

## 对应关系

| 在 Live 中 | 在 LYNX SHARE 中 |
|---|---|
| 会话视图 | 片段启动工作流程的片段网格 |
| 编排视图 | 播放列表 |
| 轨道 | 播放列表轨道，也就是片段网格的各列 |
| 场景 | 场景，即片段网格的各行。场景在启动时可以设定速度 |
| 启动量化 | `全局`、`无`、从 8 小节到 1 小节，或从 1/2 到 1/32 的音符时值，需要的话可以按片段设置 |
| 启动模式 | `触发`、`门限`、`切换` 和 `重复` |
| 跟随动作 | 动作 A 和动作 B，各有各的概率 |
| 片段停止按钮 | 空槽位可以有停止按钮 |
| 返回编排视图 | `返回播放列表` |
| 扭曲模式 | `通道设置 › 时间拉伸` 中的 `拍`、`音调`、`纹理` 和 `复杂` |
| Simpler、Sampler 和鼓机架 | LYNX SHARE 采样器 |
| `.als` 套装 | `.lynx` 工程文件 |

## 片段网格

一个槽位里可以放一个样式片段或一个音频片段。

- 一条轨道一次只播放一个片段。新启动的片段会取代正在播放的那个。
- 启动会等到启动量化的下一个步点。
- `连奏` 让新片段从被取代片段已播放到的位置开始。`循环` 是按片段设置的。
- 场景可以插入、删除和重命名。
- 启动过片段的轨道在播放列表中保持静默，直到你按下 `返回播放列表`。有一个选项可以在走带停止时把轨道交还回去。

跟随动作在片段播放若干小节或若干遍之后执行。动作有 `无动作`、`停止`、`再次播放`、`上一个`、`下一个`、`第一个`、`最后`、`任意` 和 `其他`。一个开关可为整个网格打开或关闭跟随动作。

## 从 .als 导入的内容

- MIDI 轨道、音频轨道、编组轨道和返回轨道，速度、拍号、定位点、循环、混音台设置（音量、声像、静音、独奏、发送）及其自动化。
- VST2 和 VST3 插件及其状态，前提是安装了相同的插件。见[第三方插件](/wiki/plugins/)。
- 会话片段和场景，导入到片段网格中，带着它们的启动模式、量化、连奏、循环、跟随动作和停止按钮。如果想改为把它们放到播放列表上（每个场景一个区段），请更改 `选项 › 常规设置...` 中的 `Live 工程的会话片段`。
- 扭曲标记。

## 导出 .als

1. 选择 `文件 › 导出 › Ableton Live 套装 (.als)...`。
2. 在 `保存为` 下选择 `Live 12` 或 `Live 11（也可在 Live 12 中打开）`。
3. 在 `采样` 下，选择把采样复制到套装的工程文件夹中，或者引用它们当前所在的位置。
4. 选择一个文件夹。套装会保存为 `<name> Project/<name>.als`。

| 会写入 | 不会写入 |
|---|---|
| 每个通道一条 MIDI 轨道，其音符作为 MIDI 片段 | LYNX SHARE 自己的乐器和效果器。它们的轨道和音符会保留 |
| 带有拉伸、移调、增益、淡化和扭曲模式的音频轨道 | 效果器参数的自动化 |
| 编组、返回轨道和发送 | 插入轨到插入轨的路由 |
| 带状态的 VST2 和 VST3 插件 | |
| 标记，以及音量、声像和速度自动化 | |
| 片段网格，作为会话片段和场景，机架和 Drum Rack | |

导出之后会有一份报告，列出被略去的内容。

## 须知

- Live 自己的许多设备会作为 LYNX SHARE 自己的设备导入，连同设置和自动化：EQ Eight、EQ Three、Channel EQ、Compressor、Glue Compressor、Multiband Dynamics、Limiter、Gate、Utility、Reverb、Delay、Echo、Auto Filter、Saturator、Overdrive、Chorus-Ensemble、Redux、Auto Pan、Drum Buss、Simpler、Drift 和 Operator（不含 FM）。其余的会被丢弃并列在导入报告中。
- Instrument Rack 和 Audio Effect Rack 会连同链、区域和宏一起导入，Drum Rack 会变成 LYNX SHARE 的 Drum Rack。Live 的 MIDI Effect Rack 还不能转换，会列在导入报告中。
- 导入报告会列出被略去的内容。
- 在导出的套装中，Live 会修剪相互重叠的音频片段。
- Live 套装中的扭曲标记在导入时保留，导出时写回。
