这些是 0.1.25 alpha 中的默认按键。`帮助 › 快捷键`（`F1`）在应用内显示快捷键一览。`选项 › 管理快捷键...` 打开图中的编辑器，你可以在那里更改它们。

> 在 macOS 上，应用以 Mac 的名称显示按键：Ctrl 显示为 ⌘，Alt 显示为 ⌥。

## 更改快捷键

1. 选择 `选项 › 管理快捷键...`。
2. 在搜索框中输入动作或按键，例如 `Ctrl+L`。它旁边的列表可把搜索限制在某一处，`仅已更改` 则只显示你更改过的。
3. 单击该动作。
4. 单击 `更改` 替换它的按键，或单击 `添加快捷键` 再给它一个，然后按下新的按键。`Esc` 取消。
5. 如果这些按键在同一处已被使用，会有一条消息说出另一个动作的名称，并让你把按键转移过来。

`移除` 清除该动作的按键。`重置为默认` 恢复一个动作，`全部重置...` 恢复所有动作。你的更改保存在设置文件夹里的 `keys.json` 中（Windows 上是 `%APPDATA%\LYNX`，macOS 上是 `~/Library/Application Support/LYNX`，Linux 上是 `~/.config/LYNX`）。`打开keys.json` 会打开该文件。

## 走带控制和录制

| 按键 | 作用 |
|---|---|
| `Space` | 播放，或停止并回到播放开始的位置 |
| `Ctrl+Space` | 播放或暂停 |
| `Shift+Space` | 播放，或停止在歌曲或样式的开头 |
| `L` | 在样式模式和歌曲模式之间切换 |
| `R` | 开启或关闭录制 |
| `Shift+R` | 立即录制音频：预备所选插入轨并开始录制 |
| `Ctrl+M` | 开启或关闭节拍器 |
| `Ctrl+P` | 开启或关闭录制前的预备拍 |
| `Ctrl+I` | 开启或关闭“录制等待第一个音符” |
| `Ctrl+B` | 开启或关闭混合录制的音符 |
| `Ctrl+E` | 开启或关闭步进输入 |
| `Ctrl+H` | 停止声音（所有音符关闭） |
| `Ctrl+T` | 开启或关闭电脑键盘当钢琴 |
| `Alt+Numpad *` / `Alt+Numpad /` | 跳到下一个或上一个歌曲标记 |

其中有些按键，在处于焦点的编辑器里另有用途。在钢琴卷帘中，`Ctrl+M` 导入 MIDI 文件，`Ctrl+B` 复制。在播放列表中，`Ctrl+P` 是表演模式。

## 须知

- 电脑键盘钢琴开启时，它的按键演奏音符，大多数单字母快捷键会暂停（`L` 仍然有效）。用 `Ctrl+T` 将其关闭。
- 一个快捷键要么在所有地方有效，要么只在一个窗口中有效。当该窗口处于焦点时，属于该窗口的快捷键优先于在所有地方有效的相同按键。
- 有些动作没有默认按键，例如快速添加面板。请在编辑器中给它们设一个。
