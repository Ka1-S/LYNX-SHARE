和别人一起做一个工程有两种方式，都在 `文件 › 在线会话` 下。工程包是一个你发给朋友的文件，朋友再发回他的一部分。它不需要网络、账号或服务器。实时会话则通过 LYNX SHARE 中继在互联网上把所有人连在一起，每一处改动都会传到每个人那里。一个工程最多有 4 人参与，包括你自己。

## 把工程发给朋友

![发送工程](/assets/img/wiki/session-send.webp)

1. 打开工程，选择 `文件 › 在线会话 › 发送工程...`。
2. 输入你的名字和朋友的名字。
3. 选择会话结束时朋友保留什么：`仅自己的部分（推荐）` 或 `工程的完整副本`。
4. 保存 `.lynxpack` 文件。
5. 用任何你喜欢的方式发送这个文件：电子邮件、共享文件夹、U 盘。

工程包里有工程本身、它用到的所有采样和录音，以及使用第三方插件的那些部分的音频渲染（“替身”）。你的朋友不需要拥有你的插件，也能听到这些部分。

## 录制一部分并发回

朋友这样做：

1. 用 `文件 › 打开...` 打开 `.lynxpack`。摘要会显示是谁发来的，以及哪些混音台插入轨和播放列表轨道属于你。点击 `打开`。
2. 在你自己的插入轨和播放列表轨道上添加你自己的通道、样式和音频。主持人的内容保持原样。
3. 选择 `文件 › 在线会话 › 发回我的部分...`，把新的工程包发给主持人。

每位访客会得到一种颜色、20 个混音台插入轨和 16 条播放列表轨道。

## 合并一部分

主持人这样做：

1. 打开当初发出去的工程。
2. 选择 `文件 › 在线会话 › 合并部分...`，选取朋友发回来的工程包。
3. 朋友的通道、样式、音符、片段和插入轨会以他的颜色加入。你的内容不会有任何改动。

合并算作一步撤销。同一位朋友较新的部分会替换较早的部分。

## 开始或加入实时会话

![开始实时会话](/assets/img/wiki/session-start.webp)

主持人开始会话：

1. 打开工程，选择 `文件 › 在线会话 › 开始实时会话...`。
2. 输入你的名字。
3. 在 `访客可编辑` 下，选择 `仅自己的通道、样式、插入轨和行（推荐）` 或 `全部`。在 `会话结束时，访客保留` 下，选择他们自己的部分或完整副本。
4. 点击 `起点`，然后复制邀请码，发给最多 3 个人。
5. 有人请求加入时，点击 `允许加入`。

访客加入：

1. 选择 `文件 › 在线会话 › 加入实时会话...`。
2. 输入你的名字，粘贴邀请码，点击 `加入`。
3. 等待主持人放你进来。主持人的工程会打开。

## 实时会话期间

![会话聊天](/assets/img/wiki/session-chat.webp)

会话进行时，`文件 › 在线会话` 菜单中有这些命令：

| 命令 | 作用 |
|---|---|
| `会话聊天...` | 打开聊天。菜单项会显示未读消息的数量 |
| `跟随主持人的走带` | 供访客使用：播放、停止和位置都跟随主持人 |
| `成员和权限...` | 供主持人使用：每个人可以更改什么，以及结束时各自保留什么 |
| `显示邀请码...` | 供主持人使用：再次显示邀请码，并带有 `复制` 按钮 |
| `结束实时会话` | 供主持人使用。所有人离开，邀请码失效 |
| `离开实时会话` | 供访客使用。工程中属于你的部分仍留在你手里 |

在 `成员和权限...` 中，每个人会得到四种角色之一：`自己的通道、样式、插入轨和行`、`自己的部分 + 速度和工程设置`、`全部` 或 `仅收听（不可编辑）`。关闭某项权限永远不会删除任何内容。

## 别人有而你没有的插件

如果某个通道或插入轨的插件没有安装在你的电脑上，它会播放替身，并在通道机架和混音台中显示一个琥珀色的 `R` 标记。

- 在工程包中，替身是保存工程包时生成的音频渲染。它们会跟随你移动的片段，但不会跟随你没有的那个插件的音符编辑。请向插件的所有者要一个新的工程包。
- 在实时会话中，使用了某人没有的插件的部分，由拥有该插件的人渲染，并以音频形式流式传送给其他人。

## 网络上传送什么

工程包是文件。不会向任何地方上传任何内容。

实时会话只在你处于其中时才会连接。所有内容都经过中继 `relay.lynx-share.com`，并用由邀请码生成的密钥进行端到端加密。中继只负责转发数据，无法读取。它能看到你的 IP 地址、你连接的时间以及经过的字节数。会话中的其他人能看到你的名字、你的编辑、你的部分用到的采样，以及你正在播放还是录音。他们看不到你的 IP 地址。详情见[隐私政策](https://github.com/Ka1-S/LYNX-SHARE/blob/main/PRIVACY.md)。

## 须知

- `仅自己的部分` 是音乐人之间的一种礼让，而不是防复制保护。工程包就是一个普通的 zip。
- 双方应使用相同版本的 LYNX SHARE。版本不同时，工程包摘要会提醒。
- 连接中断的访客会自动重新连接，并保留自己的编辑。
- 如果会话期间主持人的 LYNX SHARE 关闭了，下次启动时会提示恢复会话，访客会自动重新连接。
- 在实时会话中，撤销和重做只会恢复你自己的编辑。
- 任何拿到邀请码的人都可以请求加入，但必须等主持人放行才能进入。
