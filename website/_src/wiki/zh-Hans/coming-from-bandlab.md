![简易布局：时间线上的音轨、起始节拍和鼓机](/assets/img/learn/simple-beat-2.webp)

选择 **简易布局**。它是一个窗口，里面有时间线上的音轨、循环、鼓机和快速录音，和 BandLab、FL Studio Mobile 与 GarageBand 的工作方式一样。另外两种布局只需点一下就能用。

## 最先做的三件事

1. **选择布局。** 第一次启动 LYNX SHARE 时，欢迎卡片会问你从哪里转过来。点击 `BandLab、FL Studio Mobile 或 GarageBand`：窗口会切换到简易布局，鼓音轨上有一段起始节拍。之后，`视图 › 布局样式 › 简易工作流程` 可随时切换到它。
2. **做一段节拍。** 点击时间线下方鼓机的方块。见[在简易布局中做一段节拍](/learn/simple-beat/)。
3. **添加循环和你的声音。** `循环素材` 会打开循环面板：把循环拖到时间线上。然后在人声音轨上[录下你的声音](/learn/record-voice/)。

## 哪些相同

- 时间线上的音轨，每个声音或乐器一条，各有音量、声像、静音、独奏和效果器。
- 带步进网格的鼓机、跟随歌曲速度和调的循环，以及人声音轨上的录音。
- 单旋钮效果器，以及保存之前给整首歌一个完成的声音。
- 和朋友一起做音乐：[在线会话](/learn/online-session/)可让最多 4 个人在同一个工程里工作。

## 哪些不同

- LYNX SHARE 是适用于 Windows、macOS 和 Linux 的桌面程序。它不能在浏览器或手机上运行。
- 你的工程是电脑上的 `.lynx` 文件。没有账号，也没有云端：像其他文件一样保存、备份和发送即可。
- 可以加载第三方插件（VST3 和 CLAP，macOS 上的 Audio Units，Linux 上的 LV2，Windows 和 Linux 上的 VST2），与 LYNX SHARE 自己的乐器和效果器并用。
- 需要更多功能时，模式布局（FL Studio 的工作方式，带通道机架和钢琴卷帘）和混音台（`F9`）可以处理同一个工程。

## 对应关系

| 在那些应用中 | 在 LYNX SHARE 的简易布局中 |
|---|---|
| 音轨视图或混音编辑器 | 时间线：每个声音或乐器一条音轨 |
| 添加音轨 | `+ 添加音轨`：`人声 / 音频`、`乐器`、`鼓`、`采样器`、`吉他 / 贝斯`、`导入`、`循环素材` |
| 鼓机或步进音序器 | 鼓音轨的 `鼓机` 标签页：步进网格、样式 A 到 H、长度和摇摆 |
| 鼓垫 | 采样器音轨的 16 个鼓垫，用电脑按键演奏 |
| 循环库 | `循环素材`：把循环拖到时间线上。它会跟随工程的速度和调 |
| 钢琴卷帘 | 面板的 `编辑器` 标签页，或用 `在钢琴卷帘中打开` 打开全部工具 |
| 屏幕键盘和和弦 | 面板的 `键盘` 标签页：钢琴、`音阶键` 或 `和弦垫` |
| 音轨效果器和预设 | 面板的 `效果器` 标签页：单旋钮效果器、`预设` 下的现成效果链，以及 `混合` |
| 人声音高校正 | LYNX Tune，带调和音阶的音高校正器（面板中的 `+`，然后选 `更多效果器...`） |
| 母带处理 | `完成`：给整首歌一个完成的声音，然后保存为 WAV 或 MP3 |
| 歌词 | `歌词` |
| 调音器 | 工具栏中的 `调音器` |
| 混音台 | `F9` |
| 歌曲段落（前奏、主歌、副歌） | 标题栏中的 `段落`：段落作为整体移动、复制和重复 |
| 让节拍在人声之下闪避、回声发送 | 面板 `效果器` 标签页中 `混响` 旁的 `闪避于` 和 `回声` 旋钮 |

## 你的工程

- **FL Studio Mobile**（`.flm`）：`文件 › 打开...` 可以打开。导入是部分的：速度、音轨、样式、音频片段、鼓组、DW Sampler、Slicer、MiniSynth、Transistor Bass、3x Osc、GMSynth、SuperSaw 和 FLM 的效果器都会带过来。FLM 的其他乐器用 LYNX SHARE 内置的合成器播放。 `文件 › 将副本保存为 FL Studio Mobile 工程 (.flm)...` 会写回一份给 FL Studio Mobile 使用的副本。
- **GarageBand**（`.band`，来自 GarageBand 10 或 iOS 版 GarageBand）：`文件 › 打开...` 会把它作为简易布局的音轨打开，带有区域、速度、调和混音。乐器音轨用 LYNX SHARE 内置的合成器和鼓播放，因为 GarageBand 没有以其他程序能读取的形式保存它们的音色。
- **BandLab**（`.blx`，由 Cakewalk 或 Sonar 下载的工程）：`文件 › 打开...` 会把它作为简易布局的音轨打开，带有区域、速度、调、混音、音量和声像自动化以及常见的效果器。BandLab 的乐器音色和其他效果器会列在导入报告中。
- **来自任何应用的分轨**：把音轨导出为音频或 MIDI 文件，放进同一个文件夹，然后点击 `+ 添加音轨`，再点击 `导入` 旁边的 `文件夹...`。每个文件会成为一条从开头开始的音轨。

`帮助 › 上次工程导入报告` 会列出哪些内容被近似处理或舍去。见[文件格式](/wiki/file-formats/)。

## 须知

- `文件 › 保存` 会写入一个 `.lynx` 文件。你打开的文件永远不会被更改。
- `完成` 把歌曲保存为 WAV 或 MP3，`文件 › 导出` 提供更多格式和分轨。见[导出](/wiki/exporting/)。
- `帮助 › 首支歌曲导览` 会带你在大约五分钟内做完第一首歌。

BandLab 是 BandLab Technologies 的商标。FL Studio Mobile 是 Image-Line Software 的商标。GarageBand 是 Apple Inc. 的商标。LYNX SHARE 是一个独立的程序，与它们没有关联，也未获其认可。
