![混音台](/assets/img/mixer.webp)

每个通道都经过一个混音台插入轨播放。每个插入轨都有推子、声像、静音和独奏、峰值电平表、十个各带干/湿量的效果器插槽，以及一个内置 EQ。除非你把插入轨路由到别处，所有插入轨最终都汇入主控。按 `F9` 显示或隐藏混音台。

一个工程最多可以有 127 个插入轨。混音台上有一个用来添加新插入轨的添加条。混音台标题栏中的下拉框可以在八种轨道条布局中选择，从 `紧凑` 到 `特大`。

## 给通道加效果器

1. 在[通道机架](/wiki/channel-rack/)中选择通道，按 `Ctrl+L`。通道会被送到一个空闲的插入轨，该插入轨会采用通道的名称和颜色。
2. 按 `F9` 显示混音台，点击那个插入轨的轨道条。
3. 在效果器面板中，点击一个空插槽，选择一个效果器。
4. 点击插槽的名称，可显示或隐藏该效果器的窗口。
5. 点击插槽的指示灯可旁通该效果器，方便对比。

## 把通道送到某个插入轨

在通道机架中，拖动通道的路由框（或在上面使用滚轮）来选择插入轨编号。双击该框会在混音台中显示那个插入轨。

通道机架中的 `Ctrl+L` 可以同时作用于多个所选通道。每个通道各自进入一个空闲的插入轨。

当混音台处于焦点时，`Ctrl+L` 会把所选通道链接到所选插入轨，`Ctrl+Shift+L` 则把它们链接到从该插入轨开始的连续插入轨。

## 选择和移动插入轨

- 点击一个轨道条来选中它。
- `Ctrl`+点击，或在多个轨道条上拖动，可选择一个范围。`Ctrl+Shift`+点击可添加或取消一个。
- 向两侧拖动轨道条，或按 `Alt+Left` 和 `Alt+Right`，可移动所选插入轨。
- 右键单击轨道条打开插入轨菜单。`F2` 为所选插入轨重命名并设置颜色。
- `Del`，或插入轨菜单中的 `Delete`，会删除所选的插入轨。LYNX SHARE 会先询问。勾选 `记住我的选择` 可在下次跳过询问。

移动、插入或删除插入轨时，发送、侧链和自动化都会跟着它们所在的插入轨走。

插入轨菜单的 `混音台` 部分和 `选项 › 混音台` 还有两个命令。`按 Playlist 排列插入轨` 会把与 Playlist 轨道相连的插入轨按 Playlist 的顺序移到最前面。开启 `保留指向已删除插入轨的链接（灰色，LYNX）` 后，送入已删除插入轨的发送会以灰色保留，方便你重新连接。

## 静音和独奏

点击静音指示灯可让插入轨静音。右键单击它或 `Ctrl`+点击则为独奏。`S` 让所选插入轨独奏，`Alt+S` 让它们连同输入给它们的插入轨一起独奏。

静音的插入轨仍会让它的电平表跳动。在新工程和导入的 FL Studio 工程中，它还会继续运行自己的效果器，只切断到 Master 的输出和它的发送。要让静音的插入轨不再处理，请开启插入轨菜单 `混音台` 部分或 `选项 › 混音台` 中的 `静音的插入轨不处理（LYNX，节省 CPU；此项目）`。这样它的电平表会停止，取消静音时它的效果器会从头开始。

## 效果器

效果器面板显示所选插入轨的十个插槽。

- 拖动插槽，或在其上使用滚轮，可向上或向下移动它。
- 右键单击插槽可得到它的选项（替换、移动、删除）。
- 插槽菜单打开时，`Del` 会删除该插槽中的插件。
- 插槽菜单中的 `组合到音频效果机架` 会把该效果器放进一个新的机架，`全部组合到音频效果机架` 则对整条链这样做。`取消编组` 会把只有一条链的机架中的效果器放回插槽。
- 面板标题栏中的开关可打开或关闭该插入轨的所有效果器。
- 你可以把效果器从[浏览器](/wiki/browser/)的插件数据库拖到插入轨或效果器插槽上。
- 插入轨菜单中的 `清晰人声` 会在该插入轨上放置一条现成的人声清理链。

## 插槽中的 Edison

Edison 是音频编辑器和录音器，可以放在任何效果器插槽中，每个插入轨可放多个。它的窗口是带有一排录制控件的音频编辑器。

- 插入轨菜单中的 `打开音频编辑器`（`Ctrl+E`）会把 Edison 载入该插入轨的第一个空插槽并打开它。`打开音频编辑器并录音`（`Shift+E`）载入后会准备好在歌曲播放时录制。
- 录制模式有 `当前`、`有输入时`（默认：等待输入超过阈值）、`输入` 和 `播放时`。`追加` 把新录音放在已有音频之后。最长录制时间为 `无限制` 或 1、3、5、10、30 或 60 分钟：新插槽从 30 开始，`打开音频编辑器并录音` 设为 5。
- `同步` 在歌曲播放时按歌曲时间播放 Edison 的音频。
- 关闭 Edison 的窗口后，它仍会继续录制。
- `工具 › 宏 › 移除所有 Edison 实例` 会在询问之后清空工程中的每个 Edison 插槽。
- FL Studio 工程 (.flp) 中的 Edison 插槽会连同其音频一起打开。

## 插入轨 EQ

每个插入轨都有自己的 EQ。拖动一个频段来设定它的频率和电平，用滚轮调整宽度，双击频段可把它恢复到 0 dB。右键单击 EQ 的标题可将其旁通。如果你想要一个没有内置 EQ 的混音台，可以让新工程以干净的混音台开始。

## 路由、发送和侧链

![选中了 Kick 插入轨的混音台，它的发送在轨道条下方画成连线，效果器面板在右侧](/assets/img/wiki/mixer-sends.webp)

选中你想要路由的插入轨。这时其他每个轨道条上都会出现一个路由开关：

- 点击另一个轨道条上的开关，可把所选插入轨发送到那里。启用后拖动可设定发送电平。
- `Ctrl`+点击只路由到那个插入轨。
- `Shift`+点击建立侧链发送。`Ctrl+Shift`+点击则建立仅侧链发送。
- 右键单击会以菜单形式打开同样的选项。
- 若要使用推子前发送，请右键单击路由开关或发送的电平旋钮，并勾选 `推子前发送（不受此轨道推子影响）`。该发送随后会标为 `PRE`。

带侧输入的效果器，例如压缩器，有一个 `侧链来源` 选择器，列出可供监听的插入轨。选择其中一个会自动为你建立路由。

## 编组和 VCA 推子

混音台的编组可以用它的折叠箭头折叠（或用 `Alt`+点击折叠所有编组）。VCA 推子会移动其成员插入轨的电平，而这些插入轨仍保留各自的推子。从插入轨菜单创建：在“编组”下选择 `VCA › 用所选新建 VCA`。

## 录音

每个插入轨都有一个录音预备按钮。预备了一个插入轨后，按录制和播放会把它的音频输入录到一个播放列表片段中。`Shift+R` 一步完成预备所选插入轨并开始录音。见[录音](/wiki/recording/)。

当你为一个还会录制其他音频的插入轨选择外部输入时，LYNX SHARE 会询问是否把它切换为 `仅外部输入`，这样录音中只有该输入。插入轨菜单中的 `混音台 › 磁盘录音 › 延迟补偿` 默认开启。关闭后，录好的录音完全不做延迟补偿就被放置。

## 按键

`Ctrl+L` 和 `Ctrl+Shift+L` 只有在混音台具有焦点时才是这个含义。

| 命令 | 按键 | 作用 |
|---|---|---|
| 链接通道 | `Ctrl+L` | 把所选通道链接到所选插入轨 |
| 链接到连续插入轨 | `Ctrl+Shift+L` | 把所选通道链接到从所选插入轨开始的各个插入轨 |
| 移动插入轨 | `Alt+Left` / `Alt+Right` | 移动所选插入轨 |
| 重命名并设置颜色 | `F2` | 为所选插入轨重命名并设置颜色 |
| 独奏 | `S` | 让所选插入轨独奏 |
| 连同来源独奏 | `Alt+S` | 让所选插入轨和输入给它们的插入轨一起独奏 |
| 删除插入轨 | `Del` | 询问后删除所选的插入轨 |
| 预备并录音 | `Shift+R` | 预备所选插入轨并开始录音 |
| Open audio editor | `Ctrl+E` | 把 Edison 载入该插入轨的第一个空插槽并打开它 |
| Open audio editor and record | `Shift+E` | 同上，并准备好在歌曲播放时录制 |

## 须知

- `选项 › 混音台` 中的 `在 Master 旁显示响度表（LYNX）` 会显示 Master 输出的短期响度和整体响度 (LUFS) 以及真峰值，并带一个 `重置` 按钮。
- 有多个输出的乐器插件可以让每个输出在各自的插入轨上播放。见[第三方插件](/wiki/plugins/)。
- `Ctrl+L` 在通道机架和混音台中的作用不同。在机架中它挑选空闲的插入轨；在混音台中它使用所选的插入轨。
- 路由开关出现在其他轨道条上，而不是所选的那个上。
- 上限为每个工程 127 个插入轨，每个插入轨十个效果器插槽。
- Edison 的录音以 WAV 文件保存在工程的文件夹中，而不是工程文件内部。
- 片段网格下方的 Session 混音台只属于片段启动工作流程。它显示与这个混音台相同的插入轨。参见[布局](/wiki/layouts/)。
