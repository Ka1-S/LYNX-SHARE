LYNX SHARE 可以接收来自任何 MIDI 输入设备的音符和控制器动作。设备在设置的 MIDI 页面中配置：`选项 › MIDI设置...`，或按 `F10`。没有硬件时，电脑键盘和触摸键盘也可以演奏音符。

## 连接键盘

1. 插上键盘，打开 `选项 › MIDI设置...`（`F10`）。
2. 在 `输入设备` 下找到它并勾选。如果列表里没有，点击 `刷新设备列表`。
3. 让两个下拉框保持为 `任意MIDI通道` 和 `演奏所选通道`。
4. 关闭设置，在[通道机架](/wiki/channel-rack/)中选择一个通道。
5. 演奏。所选通道会发声。

## 输入设备

| 设置 | 作用 |
|---|---|
| 勾选框 | 打开或关闭该设备 |
| `任意MIDI通道` | 监听所有 MIDI 通道，或只监听一个通道 |
| `演奏所选通道` | 音符发往通道机架中所选的通道，或始终发往一个固定的通道 |
| `力度` | `按演奏`、`轻（轻弹也更响）`、`重（需要更用力弹奏）` 或 `固定（每个音符都是满力度）` |
| `表演模式通道` | 表演模式开启时，这个 MIDI 通道上的音符会启动播放列表片段 |
| `歌曲标记跳转` | 这个 MIDI 通道上的音符会让歌曲跳转到某个标记，而不是发声 |

## 把旋钮关联到控件

1. 在 LYNX SHARE 中右键单击旋钮或推子。
2. 选择 `关联到MIDI控制器（转动控制器上的旋钮）`。
3. 转动硬件上的旋钮或推子。关联就建立了。

关联会随工程一起保存。要移除它，再次右键单击该控件并选择 `取消关联控制器`。菜单项会显示正在使用的 CC 编号。

| 命令 | 按键 | 作用 |
|---|---|---|
| `Override global link...` | 无 | 建立一个在所有工程中都有效的关联。它保存在设置中，而不是工程中 |
| `移除全局关联` | 无 | 再把它移除 |
| `多重链接到控制器` | `Ctrl+J` | 开启后，你移动的控件会依次与你接下来移动的硬件控件建立关联。它位于 `选项` 菜单中 |
| `拾取（接管模式）` | 无 | 位于 MIDI 页面。控制器只有在到达参数当前值之后才会移动该参数，所以不会突变 |

MIDI 页面在 `关联（此工程，然后全局）` 下列出这些关联。同一页面上的 `控制器类型` 显示为 `通用控制器`。

第三方插件的参数可通过通道菜单或效果器插槽菜单中的 `自动化插件参数` 访问。那里的每个参数都有同样的关联菜单项。见[自动化](/wiki/automation/)。

## 电脑键盘

`Ctrl+T` 或 `选项 › 电脑键盘当钢琴` 会把电脑键盘变成钢琴。从 `Z` 到 `M` 以及从 `Q` 到 `P` 的两排键会演奏所选通道。

- 开启时，字母键和数字键都是音符。钢琴卷帘和播放列表中的单字母工具键只有在它关闭时才有效。
- 它始终以钢琴卷帘的力度演奏。MIDI 页面上的 `力度` 设置是给 MIDI 设备用的。
- 同样的开关也在 `选项 › 常规设置...` 中。

## 触摸键盘

![触摸键盘：八度按钮、琴键大小、力度模式，以及从 C4 开始的一排钢琴键](/assets/img/wiki/touch-keyboard.webp)

`视图 › 触摸键盘`（`Alt+F7`）会打开一个用鼠标或触摸屏演奏的钢琴。它演奏通道机架中所选的通道，并在右侧显示该通道的名称。

| 设置 | 作用 |
|---|---|
| `-` 和 `+` | 降低或升高一个八度 |
| 琴键大小 | `小琴键`、`中琴键` 或 `大琴键` |
| `力度：按触摸位置` | 点在琴键靠上的位置声音轻，靠下的位置声音响 |
| `力度：固定` | 每个音符都使用滑块设定的力度 |
| `音名` | 在琴键上显示音名 |

## MIDI 同步

MIDI 页面上的 `输出设备` 会把走带发送给硬件和其他软件。为某个设备勾选 `发送主同步`，然后选择 `MIDI时钟`（含 Start、Continue、Stop 和 Song Position Pointer）或 MIDI Time Code。`偏移 (ms)` 为正值时延后发送同步，为负值时提前发送。`发送全部音符关闭` 会在初始化时和导出之后向设备发送该消息。

`外部时钟同步` 则反过来：LYNX SHARE 跟随你所选输入的 MIDI 时钟，包括其速度、Start、Continue、Stop 和 Song Position Pointer。`外部同步偏移（毫秒）` 为正值时让 LYNX SHARE 延后播放，为负值时提前播放。`状态` 会显示时钟是否在运行。

## 须知

- 为 `外部时钟同步` 选择一个输入，会在 `输入设备` 下打开该设备。
- 由关联的 MIDI 控制器移动的速度不会调整音频片段的大小。请直接输入或设定最终速度。
- 要录下你的演奏，见[录音](/wiki/recording/)。传入的音符可以在[钢琴卷帘](/wiki/piano-roll/)中吸附到某个音阶。
- 发送给插件的 MIDI CC、通道触后和弯音可以用 `自动化MIDI控制器（CC、触后、弯音）` 进行自动化。
