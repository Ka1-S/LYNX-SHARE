LYNX SHARE 可以接收来自任何 MIDI 输入设备的音符和控制器动作。设备在设置的 MIDI 页面中配置：`选项 › MIDI设置...`，或按 `F10`。没有硬件时，电脑键盘和触摸键盘也可以演奏音符。

## 连接键盘

1. 插上键盘，打开 `选项 › MIDI设置...`（`F10`）。
2. 在 `输入设备` 下找到它并勾选。如果列表里没有，点击 `刷新设备列表`。
3. 让两个下拉框保持为 `任意MIDI通道` 和 `演奏所选通道`。
4. 关闭设置，在[通道机架](/wiki/channel-rack/)中选择一个通道。
5. 演奏。所选通道会发声。

## 输入设备

| 设置 | 作用 |
|---|---|
| 勾选框 | 打开或关闭该设备 |
| `任意MIDI通道` | 监听所有 MIDI 通道，或只监听一个通道。`MPE 控制器` 在这个列表的末尾 |
| `演奏所选通道` | 音符发往通道机架中所选的通道，或始终发往一个固定的通道 |
| `力度` | `按演奏`、`轻（轻弹也更响）`、`重（需要更用力弹奏）` 或 `固定（每个音符都是满力度）` |
| `表演模式通道` | 表演模式开启时，这个 MIDI 通道上的音符会启动播放列表片段 |
| `歌曲标记跳转` | 这个 MIDI 通道上的音符会让歌曲跳转到某个标记，而不是发声 |
| `控制器类型` | `自动检测`、`通用控制器` 或某个控制器配置文件 |
| `踏板控制音符释放` | 默认开启。延音踏板 (CC 64) 或持音踏板 (CC 66) 会保持音符。关闭后，踏板作为控制器发送给插件 |

## 把旋钮关联到控件

1. 在 LYNX SHARE 中右键单击旋钮或推子。
2. 选择 `关联到MIDI控制器（转动控制器上的旋钮）`。
3. 转动硬件上的旋钮或推子。关联就建立了。

关联会随工程一起保存。要移除它，再次右键单击该控件并选择 `取消关联控制器`。菜单项会显示正在使用的 CC 编号。

| 命令 | 按键 | 作用 |
|---|---|---|
| `关联到控制器...` | 无 | 为该控件打开 `远程控制设置` 窗口，在其中可以手动查看和设置它的链接（见下文） |
| `覆盖全局关联...` | 无 | 建立一个在所有工程中都有效的关联。它保存在设置中，而不是工程中 |
| `覆盖全局关联...（适用于所有工程：转动控制器上的旋钮）` | 无 | 一步建立全局链接：接着移动硬件控件即可。不带括号的项会改为打开 `全局关联设置` 窗口 |
| `移除全局关联` | 无 | 再把它移除 |
| `多重链接到控制器` | `Ctrl+J` | 开启后，你移动的控件会依次与你接下来移动的硬件控件建立关联。它位于 `选项` 菜单中 |
| `拾取（接管模式）` | 无 | 位于 MIDI 页面。控制器只有在到达参数当前值之后才会移动该参数，所以不会突变 |

MIDI 页面在 `关联（此工程，然后全局）` 下列出这些关联。`控制器类型` 为 `通用控制器` 的设备只会执行你手动关联的内容。

第三方插件的参数可通过通道菜单或效果器插槽菜单中的 `自动化插件参数` 访问。那里的每个参数都有同样的关联菜单项。见[自动化](/wiki/automation/)。

## 远程控制设置

`关联到控制器...` 会打开这个窗口，与 FL Studio 中一样。`全局关联设置`（来自 `覆盖全局关联...`）的字段与它相同，只是没有链接列表、`Omni`、内部控制器和 `移除冲突`。在 MIDI 页的列表中双击某个链接也会打开它。

| 设置 | 作用 |
|---|---|
| `端口`、`通道`、`Ctrl` | MIDI 输入端口号、MIDI 通道和控制器号。右键单击 `Ctrl` 可按名称选择标准控制器。该列表中的 `音符 C0` 会建立音符链接：从那里往上调数字即可换成其他琴键 |
| `自动检测` | 默认开启。在设备上移动一个控件，数字就会自动填入 |
| `Omni` | 链接跟随所选通道，对于混音台插槽中的效果器，则跟随所选混音台轨道 |
| `模式` | 音符或按钮链接的作用方式。`默认` 和 `保持` 跟随琴键：按住时为它的力度，松开时为零。`锁存` 每按一次就在两端之间切换。`Inc` 每按一次就把数值上调一步。`保持` 设置力度，并在松开后保持 |
| 内部控制器 | 改为把控件链接到工程的某个内部控制器。仅在工程有内部控制器时显示。`录制自动化` 可让该控制器的动作被录制为自动化 |
| `映射公式` | 输入如何映射到控件，使用变量 `输入`。`预设` 里有 FL 的公式列表。输入公式后按 `Enter` 应用。旁边的曲线显示结果 |
| `平滑` | 平滑控件的动作。`时间` 设置时长：负值为 1 极，正值为 3 极 |
| `移除冲突` | 默认开启。点击 `接受` 时，移除使用同一控制器的其他链接。存在这样的链接时，它会变红 |
| `重置`、`跳过`、`接受` | `接受` 保存链接（一个撤销步骤）。当多重链接排了多个控件时，`跳过` 转到下一个 |

## 控制器配置文件

控制器配置文件会设置好设备的走带按钮、推子、旋钮、打击垫、指示灯和显示屏，无需手动关联。

1. 打开 `选项 › MIDI设置...` (`F10`)，并在 `输入设备` 下勾选该设备。
2. 让它的 `控制器类型` 保持为 `自动检测`。括号中的名称是根据设备端口名称找到的配置文件。
3. 如果显示 `通用控制器`，请自己从列表中选择配置文件。
4. 阅读框旁边的那一行。`Feedback to` 给出接收指示灯、电动推子和显示文字的输出端口。

| 配置文件 | 映射的内容 |
|---|---|
| `Mackie Control Universal` | 推子对应插入轨的音量和 Master。V-Pot 对应声像、所选通道插件的参数或通道机架的音量。每条通道带有录音待命、独奏、静音和选择，另有推子组切换、播放、停止、录制、倒带、快进、Pattern 或 Song 模式、节拍器、撤销和滚轮。显示屏显示名称和数值 |
| `Mackie Control Extender (XT)` | 对另外 8 条通道带做同样的事。这些设备共用一个组，顺序按 `输入设备` 列表的顺序 |
| `Novation Launchkey MK3 (DAW mode)` | 旋钮对应声像、音量或插件参数，推子对应音量，推子按钮选择一个插入轨。有切换组、播放、停止、录制、循环、节拍器和撤销按钮。Session 打击垫是所选通道的 16 步。请在键盘的第二个端口上使用 |
| `Akai APC Key 25 mk2` | 旋钮对应音量、声像或插件参数。上面两排打击垫是所选通道的 16 步，下面三排弹奏音符。Track 按钮选择一个插入轨。有停止、播放和录制。请在第二个端口上使用 |
| `Arturia KeyLab Essential mk3 (Mackie Control port)` | Mackie Control 映射，在键盘的 MCU/HUI 端口上 |
| `Korg nanoKONTROL2 (Mackie Control mode)` | Mackie Control 映射。它不会被自动检测：请让设备以 Mackie Control 模式启动，并手动选择此类型 |

发送位置的旋钮和推子使用软接管：只有到达控件的值之后，它们才会移动该控件。你手动关联的控件保持原有关联。`控制器配置文件文件夹` 会打开存放你自己配置文件 (`*.lynxctl`) 的文件夹，`刷新设备列表` 会重新读取它们。

内置配置文件是根据各厂商的文档编写的。它们还没有在硬件上试过。

## MPE 控制器

MPE 处于初级阶段。MPE 控制器弹奏的每个音符都有自己的弯音、音色 (CC 74) 和压力。

1. 在 MIDI 页面中，打开设备上显示 `任意MIDI通道` 的框，并选择 `MPE 控制器`。
2. 在旁边出现的框中选择成员通道，从 `通道 2` 到 `Channels 2-16`。
3. 开始弹奏。录制方法见[录制](/wiki/recording/)。

- 录制的音符对每一项只保留一个值：弯音保存为微调音高，音色保存为 Mod X，最强的压力保存为 Mod Y。它不是曲线。
- 内置乐器中，Sampler 和内置合成器会跟随这些值。
- 当插件窗口 `封装器设置` 中 `MIDI` 下的 `MPE` 开启时，第三方插件会收到 MPE。这时每个音符都在自己的 MIDI 通道上发出，通道为 2 到 16。
- 还没有用真实的 MPE 控制器试过。

## MIDI Map Mode 和 Key Map Mode

在[片段启动工作流程](/wiki/layouts/)中，可以像在 Ableton Live 中一样映射片段、场景和按钮。`两者`、`网格`、`歌曲` 开关旁边的 `MIDI` 和 `调` 按钮会开启这些模式，`Ctrl+M` 和 `Ctrl+K` 也可以。

1. 按 `Ctrl+M` 进入 MIDI Map Mode，或按 `Ctrl+K` 进入 Key Map Mode。每个可映射的元素都会着色，MIDI 为蓝色，按键为橙色。
2. 点击一个元素：片段插槽、场景、轨道的停止按钮、`停止所有片段`、播放、停止、录音、`会话录音`、节拍器，或 Session 混音台或 Device View 的旋钮。
3. 在 MIDI 设备上移动控件或按一个键，或者在 Key Map Mode 中按电脑键盘上的键。该元素会显示它的分配，例如 `1/19`（通道和控制器）。
4. 映射会列在原来浏览器的位置：Channel、Note/Control 或 Key、Path、Name、Min 和 Max。拖动 Min 或 Max，或双击输入数值。右键单击某一行可选 `反转范围` 和 `Delete`。
5. 再按一次同一个键即可结束该模式。

## 电脑键盘

`Ctrl+T` 或 `选项 › 电脑键盘当钢琴` 会把电脑键盘变成钢琴。从 `Z` 到 `M` 以及从 `Q` 到 `P` 的两排键会演奏所选通道。

- 开启时，字母键和数字键都是音符。钢琴卷帘和播放列表中的单字母工具键只有在它关闭时才有效。
- 它始终以钢琴卷帘的力度演奏。MIDI 页面上的 `力度` 设置是给 MIDI 设备用的。
- 同样的开关也在 `选项 › 常规设置...` 中。

## 触摸键盘

![触摸键盘：八度按钮、琴键大小、力度模式，以及从 C4 开始的一排钢琴键](/assets/img/wiki/touch-keyboard.webp)

`视图 › 触摸键盘`（`Alt+F7`）会打开一个用鼠标或触摸屏演奏的钢琴。它演奏通道机架中所选的通道，并在右侧显示该通道的名称。

| 设置 | 作用 |
|---|---|
| `-` 和 `+` | 降低或升高一个八度 |
| 琴键大小 | `小琴键`、`中琴键` 或 `大琴键` |
| `力度：按触摸位置` | 点在琴键靠上的位置声音轻，靠下的位置声音响 |
| `力度：固定` | 每个音符都使用滑块设定的力度 |
| `音名` | 在琴键上显示音名 |

## MIDI 同步

MIDI 页面上的 `输出设备` 会把走带发送给硬件和其他软件。为某个设备勾选 `发送主同步`，然后选择 `MIDI时钟`（含 Start、Continue、Stop 和 Song Position Pointer）或 MIDI Time Code。`偏移 (ms)` 为正值时延后发送同步，为负值时提前发送。`发送全部音符关闭` 会在初始化时和导出之后向设备发送该消息。

`外部时钟同步` 则反过来：LYNX SHARE 跟随你所选输入的 MIDI 时钟，包括其速度、Start、Continue、Stop 和 Song Position Pointer。`外部同步偏移（毫秒）` 为正值时让 LYNX SHARE 延后播放，为负值时提前播放。`状态` 会显示时钟是否在运行。

## 须知

- 为 `外部时钟同步` 选择一个输入，会在 `输入设备` 下打开该设备。
- 由关联的 MIDI 控制器移动的速度不会调整音频片段的大小。请直接输入或设定最终速度。
- 要录下你的演奏，见[录音](/wiki/recording/)。传入的音符可以在[钢琴卷帘](/wiki/piano-roll/)中吸附到某个音阶。
- 发送给插件的 MIDI CC、通道触后和弯音可以用 `自动化MIDI控制器（CC、触后、弯音）` 进行自动化。
- 被踏板保持的音符会一直录到踏板抬起的那一刻。
- 当你从控制器移动某个控件时，自动化片段不会把该控件收回。下次开始播放时，该控件会重新跟随它的自动化。
- 在 `远程控制设置` 中建立的音符链接不会写入 .flp 导出。
- `Ctrl+M` 和 `Ctrl+K` 只在片段启动工作流程中启动映射模式。Map Mode 尚不支持宏映射或音符范围。
