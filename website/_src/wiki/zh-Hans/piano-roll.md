![钢琴卷帘](/assets/img/pianoroll.webp)

钢琴卷帘显示当前样式中某一个通道的音符，左侧是键盘，底部是用于每个音符数值的轨。按 `F7` 显示或隐藏它，或在[通道机架](/wiki/channel-rack/)中通道的菜单里选择 `钢琴卷帘`。

工具栏中的通道框用来选择你要编辑哪个通道。在这个样式中有音符的通道会被标出。在框上滚动滚轮会在有音符的通道之间切换，`Ctrl`+滚轮则在所有通道之间切换。

## 写几个音符

1. 在通道机架中右键单击通道的名称，选择 `钢琴卷帘`。
2. 按 `P` 选择铅笔。
3. 在网格中单击来添加音符。按住按键并拖动可调整它的位置。
4. 拖动音符的末端可让它变长或变短。
5. 右键单击音符可删除它。
6. 按 `Space` 试听样式。

## 工具

![钢琴卷帘的工具栏，包含通道框、各个工具和吸附框](/assets/img/wiki/pianoroll-tools.webp)

每个工具都有一个字母键。这些字母键只有在电脑键盘钢琴（`Ctrl+T`）关闭时才有效。

| 工具 | 按键 | 作用 |
|---|---|---|
| 铅笔 | `P` | 单击添加音符，拖动调整位置 |
| 画笔 | `B` | 拖动绘制一连串音符。按住 `Shift` 则一次一个 |
| 鼓刷 | `N` | 在鼠标下方的琴键上，每个网格单元一个击打 |
| 橡皮擦 | `D` | 单击或拖动删除 |
| 静音 | `T` | 单击或拖动让音符静音或取消静音 |
| 刀片 | `C` | 拖出一条线来切开音符，单击则在该点切开 |
| 套索 | `E` | 拖动画出选择框。`Shift` 为添加 |
| 缩放 | `Z` | 单击放大，拖出一个范围可缩放到该范围，右键单击缩小 |
| 侦听 | `Y` | 单击或拖动会播放光标下的音符 |

## 处理音符

- 拖动音符来移动它。`Shift`+拖动则制作一个副本。
- 拖动音符的末端来调整大小。起点也可以拖动，末端保持原位。
- 在任何工具下，右键单击都会删除音符。
- 双击音符打开它的属性。
- 在音符上按住 `Alt` 并滚动滚轮可改变它的力度。
- `Ctrl`+拖动用于选择。`Ctrl`+单击可把音符加入选区或从选区移除。
- 拖动时按住 `Alt` 可忽略吸附。`Backspace` 关闭或打开吸附。
- 选中多个音符后，拉伸手柄可以在时间上拉长或压缩它们。

## 键盘和标尺

单击键盘上的一个琴键可试听。点在琴键越靠右的位置，声音越响。`Ctrl`+单击琴键会选中它的音符。在键盘上中键拖动可让琴键变高或变矮。垂直缩放轮也有同样的作用，它是时间滚动条末端的小方块：向上或向下拖动它，或在它上面使用鼠标滚轮。

钢琴卷帘菜单中的 `视图 › 键盘样式` 可在 `平面琴键` 和 `钢琴琴键（白键之间有分隔线）` 之间选择，后者绘制传统的键盘。

单击标尺来设定位置。在标尺上 `Ctrl`+拖动、右键拖动或双击后拖动，可选中一段时间范围内的音符。`Ctrl`+滚轮缩放，`Shift`+滚轮滚动。

## 工具栏

| 设置 | 作用 |
|---|---|
| 吸附 | “主要”跟随主工具栏中的吸附，也可以为这个窗口单独选一个。 |
| 和弦 | 单击会创建所选的和弦，被单击的音符为根音。`Shift+N` 回到单个音符。同一个列表就是钢琴卷帘菜单中的 `和弦印章`。 |
| 音阶 | 高亮显示某个音阶的音符。另一个按钮会把新建和移动的音符以及传入的 MIDI 吸附到所选音阶。这时移动的音符按音阶步进移动，所以和弦会留在音阶内，`Up` 和 `Down` 移动一个音阶步。 |
| 滑音（`S`） | 新音符是滑音音符。正在发声的音符会滑向它们（808 滑音）。 |
| 幽灵音符（`Alt+V`） | 在你的音符后面显示其他通道的音符。 |
| 音符颜色 | 新音符使用这个颜色。共有 16 种。 |
| 跟随 | 样式播放时，视图随播放头滚动。 |
| 轨选择框 | 选择底部轨编辑什么：Velocity、Pan、Fine pitch、Release、Mod X、Mod Y、Chance 或 Velocity range。 |

## Chance 和 Velocity range

每个音符都有 Chance 和 Velocity range。Chance 是该音符每次轮到时播放的可能性。Velocity range 让它的力度在音符力度与该力度加上范围之间变化。在轨选择框中选择 `概率` 或 `力度范围 (LYNX)` 即可编辑它们。钢琴卷帘菜单中的 `工具 › 概率 (LYNX)` 会把所选音符编成一组，使它们全部播放或只有其中一个播放，并有 `重置概率和力度范围`。

## 音符工具

钢琴卷帘的 `工具` 菜单会以对话框的形式打开 FL Studio 的音符工具。它们作用于所选音符，没有选择时则作用于所有音符。其中一些：

| 工具 | 键 | 作用 |
|---|---|---|
| Limit | `Alt+K` | 按八度把音符移入一个音域，然后加以限制。在 `调 / 音阶限制` 下，它把音符保持在一个基础音以及 FL Studio 的某个和弦或音阶上，`吸附` 可设为 `上方`、`下方` 或 `交替`。`折返到顶部 / 底部` 和 `移调` 决定音域之外的音符去向 |
| Flip | `Alt+Y` | `水平翻转` 在时间上镜像音符。开启 `保留起始时间`（起初为开启）时，起始时间被镜像，音符保持原有长度。`垂直翻转` 围绕音域中间镜像琴键 |
| Randomise | `Alt+R` | 对力度、声像、微调音高、时值和长度，以及 Mod X、Mod Y 和释音做随机改变 |
| Scale levels | `Alt+X` | 从选区的开头到结尾缩放音符的电平，带有 `偏移`、`中心`（缩放所围绕的值）和 `张力` |
| LFO | `Alt+O` | 把 LFO 形状写入音符电平。右键单击 `周期` 滑块可得到从 1 步到 512 步的列表 |

## MIDI 工具和脚本

钢琴卷帘菜单中的 `工具 › MIDI 工具...` 会打开一个面板，其中有 Arpeggiate、Chop、Connect、Ornament、Quantize、Recombine、Span、Strum、Time Warp 和 Velocity Shaper。

`工具` 菜单的 `脚本` 列列出钢琴卷帘脚本：LYNX SHARE 自带的和 `.pyscript` 文件，如果安装了 FL Studio，也包括 FL Studio 脚本文件夹中的脚本。`打开脚本文件夹...` 会打开存放你自己脚本的文件夹，`再次运行上一个脚本` 会重复运行上一个脚本。

## 须知

- 钢琴卷帘显示一个样式中的一个通道。切换当前样式后，它就显示那个样式的音符。
- 电脑键盘钢琴（`Ctrl+T`）开启时，工具字母键不起作用。
- 所有工具下右键单击都能删除，所以删一个音符不需要切换到橡皮擦。
- 在这里 `S` 是滑音开关。在播放列表中，同一个字母是滑移工具。
- 如果音符不是普通的步（其他琴键、更长的音符、滑音），通道机架中该通道所在的行会显示缩略图，而不是步进按钮。
