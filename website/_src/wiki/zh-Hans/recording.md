![录制窗口询问要录什么：音频、音符和自动化、全部，或录入音频编辑器的音频](/assets/img/wiki/record-dialog.webp)

走带中的录制按钮或 `R` 键会开启录制。第一次时，会有一个窗口询问你想录什么。音频会作为音频片段进入[播放列表](/wiki/playlist/)。音符会进入当前样式。你移动的控件会变成自动化。

## 录制话筒或乐器

1. 打开 `选项 › 音频设置...`，选择一个输入设备。
2. 打开[混音台](/wiki/mixer/)（`F9`），选择一个空的插入轨。
3. 点击插入轨效果器插槽上方的输入框，选择一个输入。立体声对排在前面，单个通道标有 `（单声道）`。
4. 点击输入框旁边的录音预备按钮。
5. 按 `R`，选择 `音频，作为音频片段录入播放列表`。
6. 如果播放没有自动开始，就按播放，然后演奏。
7. 按停止。这一遍录音就成了播放列表上的一个音频片段。

`Shift+R` 用一个键完成第 4 到 6 步：它预备所选插入轨，只录制音频，并开始播放。再按一次则停止。

## 录制窗口提供什么

| 选项 | 作用 |
|---|---|
| `音频，作为音频片段录入播放列表` | 预备所选的混音台插入轨，如果它没有输入，会询问输入 |
| `音符和自动化` | 录制来自 MIDI 键盘或电脑键盘的音符，以及你移动的控件 |
| `全部` | 音符、自动化，以及来自已预备插入轨的音频 |
| `音频，录入音频编辑器` | 在歌曲播放时，把输入录入一个新的音频编辑器 |

勾选 `不再询问` 可保留你的选择。之后，右键单击录制按钮可打开录制过滤器：`自动化`、`音符`、`音频`、`片段`，以及用来重新显示该窗口的 `开始录制时询问录制内容`。

## 插入轨的输入框

![插入轨 3 已预备、输入框设为输入 1 和 2 的混音台](/assets/img/wiki/mixer-input.webp)

| 设置 | 作用 |
|---|---|
| `音频输入源` | 这个插入轨播放和录制的设备输入，或 `（无）` |
| `录制` | 从哪里截取录音：`仅外部输入`、`外部和混音器输入`、`效果后`、`EQ 后`、`电平和声像后` 或 `轨道后` |
| `同时将干输入录为第二个录音（LYNX）` | 在处理过的录音旁边保留未经处理的输入 |
| `监听外部输入` | `关`、`预备时`、`自动（预备时，回放时除外）` 或 `开` |
| `录音保护（无法预备）` | 防止这个插入轨被误预备 |

## 录制音符

音符来自 MIDI 键盘、电脑键盘（`Ctrl+T`）或触摸键盘，并进入当前样式中所选的通道。见 [MIDI 控制器](/wiki/midi-controllers/)。

- `混合录制的音符`（`Ctrl+B`）决定是叠录还是替换。开：新音符加入样式原有的音符。关：被录制通道的旧音符会被清除。
- `将录制的音符量化到全局吸附` 在录制选项中。
- `步进输入`（`Ctrl+E`）在停止时可用：你弹的每个音符会依次以一个吸附步长为间隔进入样式。
- `捕获 MIDI`（`Ctrl+Shift+Alt+R`）会把你刚刚弹过的音符放进样式，即使当时没有开启录制。

录制时你移动的控件，在歌曲模式下写成自动化片段，在样式模式下写成样式事件。见[自动化](/wiki/automation/)。

## 录制选项

这些选项在 `选项 › 录制` 和录制按钮的右键菜单中。

| 命令 | 按键 | 作用 |
|---|---|---|
| `预备拍` | `Ctrl+P` | 录制开始前播放 0、1、2 或 4 小节节拍器 |
| `节拍器` | `Ctrl+M` | 播放时发出咔嗒声 |
| `等待第一个音符再开始` | `Ctrl+I` | 录制等到你开始演奏才开始 |
| `循环录音` | 无 | 录制循环进行，而不是一直往后走 |
| `音频：在循环区域上插入录音` | 无 | 播放整个循环区域，只保留其中的音频 |
| `音频：预滚` 和 `post-roll` | 无 | 在切入之前和切出之后播放 0、1、2 或 4 小节 |
| `录制时开始播放` | 无 | 开启录制的同时也按下播放 |
| `停止录制时取消插入轨的预备` | 无 | 每遍录音之后释放已预备的插入轨 |

## 循环录制和录音

开启 `循环录音` 后，在歌曲模式下录制会在循环区域内循环，在样式模式下则在样式内循环。关闭时，录制会一直往后播放。

音频循环录制的每一遍都会落在下一条空闲的播放列表轨道上，这些轨道构成一个组。`混合录制的音符` 决定停止后播放什么：关闭时每一遍都静音，开启时全部播放。右键单击该组中的一条轨道并选择 `用这些录音合成`，可以用这些录音合成出一个完整录音。录制选项中的 `循环录音后仅播放最后一遍` 则退回到单条轨道。

## 录音保存在哪里

- 已保存的工程把它的录音放在工程文件旁边的 `Audio/Recorded` 中。
- 未保存的工程录到你的音乐文件夹里的 `LYNX/Recordings`。
- 录音是 WAV 文件，采样率与音频设备相同，为 24 位或 32 位浮点。格式和录音名称在 `选项 › 音频设置...` 的 `录制` 下设置。
- `打开录音文件夹` 在录制按钮的右键菜单中。`文件 › 删除未使用的录音并保存...` 会移除工程不再使用的录音。

## 须知

- 没有输入的已预备插入轨什么也录不到。LYNX SHARE 会告诉你，并指向输入框。
- 磁盘剩余空间不足 30 秒时，录制会拒绝开始；不足 10 分钟时会发出警告。
- 没有预备任何东西时，`选项 › 录制输入音频` 会把前两个输入通道录入一个新的插入轨。
- 在 macOS 上，第一次录音时系统会请求麦克风权限。
- 如果录音时 LYNX SHARE 关闭了，下次启动时会提示把恢复的录音放到播放列表上。
