![带有演示工程的主窗口：顶部是工具栏，左侧是浏览器，后面是播放列表，通道机架浮在它上面](/assets/img/wiki/desktop.webp)

LYNX SHARE 只有一个主窗口。工具栏沿顶部排列。它下面是一个桌面，里面放着五个窗口：浏览器、播放列表、通道机架、钢琴卷帘和混音台。刚启动时，浏览器在左侧，播放列表占满其余部分，通道机架浮在它上面。钢琴卷帘和混音台是隐藏的，直到你调出它们。

## 熟悉环境

1. 把鼠标指向任何控件。菜单下方的提示栏会说明它的作用，以及它接受哪些鼠标按键和按键。
2. 按 `F6` 隐藏通道机架，再按一次 `F6` 显示它。
3. 按 `F9` 显示混音台，再按 `F7` 显示钢琴卷帘。
4. 拖动窗口的标题条可移动它。双击标题可将其最大化，再双击则还原。
5. 选择 `视图 › 重置布局`，把一切恢复原样。

## 工具栏

![工具栏：菜单和提示栏、走带、主控旋钮、录制选项、吸附和样式、窗口按钮、文件按钮、和弦显示、电平表和输出监视器](/assets/img/wiki/toolbar-1920.webp)

从左到右，采用默认布局：

| 分组 | 包含什么 |
|---|---|
| 菜单和提示栏 | 菜单 `文件`、`编辑`、`添加`、`样式`、`视图`、`选项`、`工具` 和 `帮助`，下方是提示栏。始终排在最前 |
| 走带控制 | `样式` 和 `歌曲` 模式按钮、播放、停止和录制，以 BPM 表示的速度，以及以小节、拍和步表示的位置 |
| 主控音量和音高 | `主控` 音量旋钮和以音分为单位的 `音高` 旋钮 |
| 录制选项 | 节拍器、预备拍、循环录音、步进输入和其他录制开关 |
| 吸附和样式 | 主吸附（默认是 `线（跟随缩放）`）、当前样式、新建样式的按钮和样式菜单 |
| 窗口快捷键 | 每个窗口一个按钮，外加插件选择器 |
| 文件和撤销 | 新建、打开、保存、导出、撤销和重做 |
| 和弦检测 | 说出 MIDI 设备或打字键盘上正在弹奏的和弦名称 |
| CPU、内存和复音 | 音频 CPU 负载、已用内存和发声数 |
| 输出监视器 | 输出的示波器。单击可依次切换它的其他模式 |

还有一个名为 `多重链接到控制器` 的分组，默认是隐藏的。

`选项 › 工具栏` 可更改工具栏：`编辑工具栏（拖动面板以移动、添加或移除）`、`分隔符`、`隐藏工具栏面板`、`预设`、每个分组各一个开关，以及 `图标大小`（小、中或大）。

## 走带控制

| 控件 | 按键 | 作用 |
|---|---|---|
| 样式模式 | `L` | 循环播放当前样式。右键单击该按钮可显示通道机架 |
| 歌曲模式 | `L` | 播放播放列表中的编排。右键单击该按钮可显示播放列表 |
| 播放 | `Space` | 播放。再按一次则停止并回到起始位置。`Ctrl+Space` 暂停 |
| 停止 | | 停止并回到开头。双击还会发送所有音符关闭 |
| 录制 | `R` | 开启或关闭录制。见[录音](/wiki/recording/) |

## 提示栏

空闲时，提示栏显示 `Point at anything for help`，并提示 `F1` 打开快捷键表、`F5` 到 `F9` 对应各窗口、`Space` 播放和停止。指向某个控件时，它会说出该控件的名称，并列出拖动、`Ctrl`、`Alt` 和右键单击在那里的作用。后台插件扫描这类耗时的任务会在其中报告进度。

## 五个窗口

| 窗口 | 按键 | 用途 |
|---|---|---|
| [播放列表](/wiki/playlist/) | `F5` | 把样式、音频和自动化片段编排成歌曲 |
| [通道机架](/wiki/channel-rack/) | `F6` | 每个乐器一行，显示当前样式的各个步 |
| [钢琴卷帘](/wiki/piano-roll/) | `F7` | 当前样式中某个通道的音符 |
| [混音台](/wiki/mixer/) | `F9` | 带推子的插入轨、效果器和路由 |
| [浏览器](/wiki/browser/) | `Alt+F8` | 采样、预设、工程的内容和插件数据库 |

每个按键都会显示对应窗口并使其获得焦点，如果该窗口已有焦点则将其隐藏。单独按 `F8` 会打开插件选择器，它不属于这五个窗口。工具栏的窗口按钮与这些按键作用相同。右键单击其中一个，会以最大化方式显示该窗口。`Enter` 最大化或还原播放列表。

## 窗口如何移动和停靠

每个窗口都有一个标题条。它的左侧是一个菜单按钮，里面是该窗口自己的选项，随后是 `已分离（独立窗口）`、`已最大化` 和 `关闭`。右侧是最大化和关闭按钮。

- 拖动标题条可移动窗口。它会吸附到其他窗口和边缘。按住 `Alt` 移动可不吸附。
- 拖动边缘可调整大小。
- `已分离（独立窗口）` 会把窗口变成独立的系统窗口，适合第二台显示器。分离后的窗口有一个 `停靠` 按钮，可把它放回去。`视图 › 分离的面板（独立窗口）` 列出这五个窗口。
- `视图 › 找回屏幕外的面板` 可找回跑到桌面之外的窗口。
- `视图 › 布局另存为...` 以一个名称保存当前排列，`视图 › 加载布局` 则把某个排列调回来。

浏览器是桌面的背景：它始终停靠在一侧，其他窗口总是位于它之上。

## 须知

- 在你移动、调整大小或分离任何东西之前，每当主窗口改变大小，各窗口都会回到它们的默认位置。之后，你的排列会被记住，并随窗口缩放。
- `F12` 关闭插件、通道设置和工具窗口。它不会关闭这五个主窗口。
- 打字键盘钢琴开启时（`Ctrl+T`），字母键演奏音符，大多数单字母快捷键会暂停。
- `视图 › 布局样式` 在样式工作流程（默认）和片段启动工作流程之间切换，后者会在播放列表旁边增加一个片段网格。
