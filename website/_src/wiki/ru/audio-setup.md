На странице «Аудио» окна «Настройки» выбирается, куда идёт звук и откуда приходят записи. Откройте её через `Опции › Настройки аудио...`. Мастер настройки (`Опции › Мастер настройки (язык, аудио, папки плагинов)...`) тоже проверяет аудиовыход.

## Как получить звук

1. Откройте `Опции › Настройки аудио...`.
2. Выберите `Драйвер`. Примечание под списком объясняет, для чего хорош этот драйвер.
3. Выберите `Устройство вывода`.
4. Нажмите `Тестовый звук`.
5. Посмотрите раздел `Статус`. В нём указаны работающий драйвер, частота дискретизации и задержка на выходе либо надпись `Аудиоустройство не открыто: выберите устройство вывода.`

## Драйверы

В списке `Драйвер` перечислены типы драйверов вашей системы.

| Система | Драйвер | Что он делает |
|---|---|---|
| Windows | Windows Audio (общий) | Другие программы сохраняют звук. Windows смешивает все программы шагами фиксированной длины, поэтому буфер не может быть меньше этого шага |
| Windows | Windows Audio (общий, короткий период) | Общий режим, но у Windows запрашивается более короткий период смешивания. Поддерживается лишь некоторыми драйверами |
| Windows | Windows Audio (монопольный, минимальная задержка) | LYNX SHARE использует устройство в одиночку. Пока он играет, остальные программы молчат |
| Windows | DirectSound (устаревший) | Старый звуковой тракт Windows с большой задержкой. На случай, когда остальные не работают |
| Windows | ASIO | Драйверы с низкой задержкой. ASIO-драйвер производителя работает со своим устройством |
| Windows | LYNX ASIO (встроенный) | Собственный ASIO-драйвер LYNX SHARE для любого устройства, на воспроизведение и запись. В `Настройки драйвера...` выбираются общий или монопольный режим и устройства |
| macOS | Core Audio | Штатный звук системы, общий с другими программами |
| Linux | PipeWire (нативный) | LYNX SHARE работает с PipeWire напрямую. `System default` следует выходу, выбранному в системных настройках звука |
| Linux | JACK / PipeWire | Для запущенного сервера JACK или PipeWire с `pipewire-jack` |
| Linux | ALSA | Работает со звуковой картой напрямую. `default` или `pipewire` делят устройство, устройство `hw:` отдаёт карту только LYNX SHARE |

В Linux при первом запуске открывается первый из PipeWire, JACK и ALSA, у которого есть устройства. Сохранённый выбор запоминается.

## Настройки на странице

| Настройка | Что она делает |
|---|---|
| `Драйвер` | Тип драйвера, из таблицы выше |
| `Устройство вывода` | Куда играет Мастер |
| `Устройство ввода` | Источник для записи аудио и для входов инсертов Mixer. По умолчанию `(нет)` |
| `Частота дискретизации` | Частоты, которые предлагает устройство |
| `Размер буфера` | Размеры, которые предлагает устройство, каждый с задержкой в миллисекундах. Малые буферы быстрее откликаются при игре. Большие оставляют процессору больше запаса, щелчков меньше |
| `Настройки драйвера...` | Открывает собственное окно драйвера (драйверы ASIO) |
| `Тестовый звук` | Проигрывает тестовый звук через устройство вывода |
| `Записывать аудио со входа` | Записывает первые два входных канала в новый инсерт, если ни один инсерт не готов к записи |
| `Формат файла` | Записи сохраняются как WAV 24 бит или WAV 32 бит float на частоте дискретизации устройства |
| `Измерить круговую задержку` | Проигрывает 8 щелчков с `Выход пинга` на `Вход пинга` через кабель или loopback и измеряет задержку, чтобы дубли ложились туда, где вы играли |
| `Точная подстройка (сэмплы)` | Сдвигает каждый новый дубль. Положительное значение ставит его на Playlist раньше |
| `Дорожка метронома` | Дорожка Mixer, через которую играет метроном. `---` означает Мастер. Щелчок никогда не попадает в экспорт |
| `Играть усечённые ноты при запуске` | Играет ноты, пересекающие стартовую позицию |
| `Сбрасывать плагины при запуске` | Сбрасывает хвосты эффектов при запуске или переходе воспроизведения |

## Если нет звука

- Сначала посмотрите на `Статус`. Если ни одно устройство не открыто, выберите устройство вывода.
- Попробуйте другой драйвер. В Windows `Windows Audio (общий)` оставляет звук другим программам, а `DirectSound (устаревший)` нужен на случай, когда остальные не работают.
- Проверьте фейдер Мастера в [Mixer](/wiki/mixer/) и ручку `МАСТЕР` на панели инструментов.
- В режиме паттерна играет только текущий паттерн. Если он пуст, вы ничего не услышите. Нажмите `L` для режима песни.
- В Linux, если звук рвётся, `Статус` показывает, получил ли аудиопоток приоритет реального времени. Решение есть в разделе [Устранение неполадок](/wiki/troubleshooting/).

## Что полезно знать

- ASIO есть только в Windows.
- В `Windows Audio (общий)` наименьший буфер равен шагу смешивания в системе. Примечание под списком `Драйвер` называет значение для вашего устройства. Для меньшей задержки используйте монопольный режим или драйвер ASIO.
- В PipeWire буфер составляет от 32 до 2048 сэмплов, а частота дискретизации от 44,1 до 192 кГц. Если PipeWire держит свою частоту, он ресэмплирует поток LYNX SHARE.
- В PipeWire при отключении именованного устройства LYNX SHARE переходит на `System default` и сохраняет размер буфера.
- `Статус` также показывает загрузку процессора звуком и считает пропуски (опустошения буфера).
- Список драйверов и устройств можно получить, не открывая окно. См. `--devices` в разделе [Командная строка](/wiki/command-line/).
