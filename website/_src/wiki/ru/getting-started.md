LYNX SHARE — бесплатная DAW с открытым исходным кодом для Windows, macOS и Linux. Она работает с паттернами: вы программируете их в Channel Rack и Piano Roll, расставляете в Playlist и сводите в Mixer. Она открывает проекты FL Studio (`.flp`) и сеты Ableton Live (`.als`) и сохраняет свой собственный формат `.lynx`.

Это альфа-версия. Ждите ошибок и сохраняйтесь почаще.

## Запуск

1. Проверьте по таблице ниже, поддерживается ли ваша система.
2. Скачайте и установите программу. Шаги для каждой системы описаны в статье [Установка](/wiki/install/).
3. Запустите ее. Короткий мастер настройки выбирает язык, проверяет аудиовыход и перечисляет папки плагинов, которые затем сканируются в фоне. Его можно пропустить и открыть позже через `Опции › Мастер настройки (язык, аудио, папки плагинов)...`.
4. Если вы ничего не слышите, перейдите к [Настройке звука](/wiki/audio-setup/).
5. Прочитайте [Обзор окна](/wiki/tour/), затем сделайте [Свою первую песню](/wiki/first-song/).

## Что нужно

| Система | Требования |
|---|---|
| Windows | Windows 10 или 11, 64-разрядная |
| macOS | macOS 11 Big Sur или новее, Intel или Apple silicon |
| Linux | x86_64 с glibc 2.35 или новее (Ubuntu 22.04+, Debian 12+, Fedora 36+, актуальный Arch или Manjaro), X11 или XWayland |

Аудиоинтерфейс не нужен. LYNX SHARE играет через звуковое устройство, которое ваша система уже использует. FL Studio тоже не нужна. Если она установлена на том же компьютере, LYNX SHARE находит ее сэмплы и для проектов `.flp` использует те же файлы плагинов.

Сторонние плагины необязательны. У LYNX SHARE есть собственные инструменты и эффекты, они перечислены в [каталоге](/instruments-and-effects/).

## Сохранение работы

`Ctrl+S` сохраняет, `Ctrl+Shift+S` сохраняет под новым именем, а `Ctrl+Alt+S` сохраняет новую версию (Song_2, Song_3 и так далее). Есть автосохранение, доступное через `Файл › Открыть папку автосохранений` и `Файл › Вернуться к последней резервной копии...`.

В `Файл › Новый из шаблона` есть четыре отправные точки: Empty, Basic beat, Trap with 808 и House.

## Демонстрационный проект

Установщик и zip для Windows, `.dmg` для macOS и `.tar.gz` для Linux включают демонстрационный проект `Demo.lynx`. Откройте его через `Файл › Открыть...` (`Ctrl+O`). В Windows он лежит в папке установки рядом с `LYNX.exe`.

Его можно также создать из терминала. См. [Командная строка](/wiki/command-line/).

```
LYNX.exe --showcase out.lynx
```

## Что стоит знать

- Файл программы называется `LYNX.exe` в Windows и `LYNX` в macOS и Linux. Папка настроек тоже называется `LYNX`.
- В Windows и macOS при первом запуске может появиться системное предупреждение: сборка для Windows пока не подписана цифровой подписью, а сборка для macOS не прошла нотаризацию. Что нажимать, объясняет статья [Установка](/wiki/install/).
- В системе, язык которой в LYNX SHARE отсутствует, интерфейс по умолчанию английский. Его можно изменить в `Опции › Общие настройки...`. Новый язык применяется после перезапуска.
- Пакеты FLEX в проектах FL Studio зашифрованы и никогда не открываются. Таким каналам подбирается патч синтезатора по имени пресета.
