LYNX SHARE сохраняет проекты в файлы `.lynx`. Он также открывает проекты других программ, загружает обычные аудиофайлы и экспортирует аудио, MIDI и проекты для других программ. В таблице перечислены все форматы версии 0.1.26 alpha.

Проект, открытый из формата другой программы, считается импортом. `Файл › Сохранить` тогда спрашивает, куда записать файл `.lynx`, а исходный файл никогда не меняется.

## Открытие проекта другой программы

1. Выберите `Файл › Открыть...` (`Ctrl+O`).
2. Укажите файл `.flp`, `.als`, `.flm`, `.mid` или `.zip`.
3. Для `.flp` выберите `Справка › Last FL Studio import report`, чтобы прочитать, что было приближено или пропущено.
4. Выберите `Файл › Сохранить` и укажите, куда записать файл `.lynx`.

## Форматы

| Формат | Открытие | Сохранение / экспорт | Примечания |
|---|---|---|---|
| `.lynx` | `Файл › Открыть...` | `Файл › Сохранить`, с автосохранением | Собственный формат проектов LYNX SHARE (JSON) |
| `.zip` | `Файл › Открыть...` распаковывает его в папку и открывает проект внутри | `Файл › Экспорт › Проект с сэмплами (.zip)...` | Открывает и архив лупов FL Studio |
| `.lynxpack` | Открывается после сводки. Партия сливается с проектом хоста | `Файл › Онлайн-сессия › Отправить проект...` | Проект или партия, отправленные в [онлайн-сессии](/wiki/online-sessions/). Партии сторонних плагинов передаются как аудиорендеры вместе с настройками плагина |
| `.flp` | `Файл › Открыть...` | `Файл › Экспорт › Проект FL Studio...`, проект FL Studio 2026 или архив лупов | Нативные плагины играют на воссозданных движках разной точности. Паки FLEX не открываются никогда. При экспорте инструменты и эффекты только для LYNX рендерятся в аудио или заменяются ближайшим плагином FL, а модуляторы пропускаются. См. [Переход с FL Studio](/wiki/coming-from-fl-studio/) |
| `.flm` | `Файл › Открыть...` | Нет | Проект FL Studio Mobile. Частично: инструменты, кроме MiniSynth, Transistor Bass, 3x Osc, GMSynth, SuperSaw, DW Sampler, Slicer и DirectWave, играют на встроенном синте |
| `.als` | `Файл › Открыть...`, сеты Live 11 и 12 | `Файл › Экспорт › Сет Ableton Live (.als)...`, для Live 12 или Live 11 | При импорте устройства Live, у которых нет аналога в LYNX SHARE, отбрасываются. При экспорте собственные инструменты и эффекты LYNX SHARE не конвертируются, а автоматизация параметров эффектов и маршруты между инсертами отбрасываются. См. [Переход с Ableton Live](/wiki/coming-from-ableton/) |
| `.mid`, `.midi` | `Файл › Открыть...` создаёт новый проект. `Файл › Импорт › Файл MIDI...` и Piano Roll импортируют в текущий | `Файл › Экспорт › Файл MIDI...` (`Ctrl+Shift+M`) | |
| `.wav` | Как сэмпл или аудиоклип | `Файл › Экспорт › Файл WAV...`, 16 бит, 24 бита или 32 бита float | Необязательные дизеринг, информация о темпе, маркеры цикла и маркеры Playlist |
| `.mp3` | Как сэмпл или аудиоклип | `Файл › Экспорт › Файл MP3...` | Постоянный битрейт |
| `.ogg` | Как сэмпл или аудиоклип | `Файл › Экспорт › Файл OGG...` | |
| `.flac` | Как сэмпл или аудиоклип | `Файл › Экспорт › Файл FLAC...`, сжатие от 0 до 8 | Без потерь на любом уровне |
| `.aif`, `.aiff` | Как сэмпл или аудиоклип | Нет | |
| `.wv` | Как сэмпл | Нет | Сэмплы WavPack, какие поставляются в паках FL Studio |
| `.sf2`, `.sf3` | Играет LYNX Soundfont | Нет | SoundFont |
| `.fst` | Из Browser | Нет | Пресет нативного плагина FL Studio. Только для плагинов, для которых в LYNX SHARE есть движок |
| `.fsc` | Piano Roll и редактор событий | Piano Roll и редактор событий | Файл партитуры и автоматизации FL Studio |
| `.lynxpreset`, `.fxp`, `.fxb`, `.vstpreset` | `Загрузить файл пресета...` в меню пресетов загруженного плагина | `Сохранить пресет...` и `Экспорт файла пресета...` | Пресеты сторонних плагинов. `.fxp` и `.fxb` относятся к плагинам VST2, а `.vstpreset` к плагинам VST3, и только пока плагин работает внутри LYNX SHARE |
| Видеофайл | `Файл › Импорт › Видеофайл...` кладёт видео на Playlist | `Также записать видео с этим миксом` в окне экспорта | Импорт использует системные декодеры в Windows и macOS, в Linux нужен FFmpeg. Для экспорта нужен FFmpeg |

## Другие виды экспорта

| Команда | Что она делает |
|---|---|
| Параметр `Файлы` окна экспорта | Стемы: по файлу на инсерт микшера, на канал или на канал только с инструментами |
| `Файл › Экспорт › Все дорожки Playlist` | По файлу на дорожку Playlist |
| `Файл › Экспорт › Все группы дорожек Playlist` | По файлу на группу дорожек |
| `Файл › Экспорт › Мастеринг...` | Рендерит проект и мастерит его до целевой громкости, на вашем компьютере |
| `Файл › Экспорт › «Кости» проекта...` | Записывает пресеты и партитуры каналов и эффектов в папку |

Окно экспорта рендерит песню, текущий паттерн или выделение в Playlist.

## Из командной строки

В Windows программа называется `LYNX.exe`. В macOS и Linux — `LYNX`.

```
LYNX.exe project.lynx                       open a project (.lynx, .flp, .als, .flm or .mid)
LYNX.exe --export project.flp out.flac      render the song (wav, flac or ogg)
LYNX.exe --stems project.flp base.wav       one WAV per mixer insert that has sound
LYNX.exe --export-flp project.lynx out.flp  write an FL Studio project
```

`--export`, `--stems` и `--export-flp` принимают на входе и `.als`.

## Что полезно знать

- Аудиофайлы длиннее 30 секунд читаются потоком с дискового кэша.
- `.flp`, `.als` или `.flm` при сохранении никогда не записываются. Новые файлы создают команды экспорта.
- Файлы `.wv` только для чтения.
- Сначала `.zip` распаковывается в папку, затем открывается проект внутри.
