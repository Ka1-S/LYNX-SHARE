Для каждого релиза есть сборки для Windows, macOS и Linux на [странице релизов](https://github.com/Ka1-S/LYNX-SHARE/releases). Файлы собираются из помеченного тегом исходного кода в GitHub Actions и перечислены вместе с SHA-256 в `SHA256SUMS.txt`. Страница [Скачать](/download/) ведет на актуальные.

## Установка в Windows

Windows 10 или 11, 64-разрядная.

1. Скачайте `LYNX-<version>-setup-x64.exe`.
2. Запустите его. Установка выполняется только для вашего пользователя и не требует прав администратора.
3. SmartScreen может выдать предупреждение, потому что исполняемый файл пока не подписан цифровой подписью. Выберите `More info`, затем `Run anyway`.
4. Запустите LYNX SHARE из меню «Пуск» или с ярлыка на рабочем столе.

Установщик делает LYNX SHARE программой, которая открывает проекты `.lynx`. Для файлов `.flp` он предлагает LYNX SHARE в списке *Открыть с помощью*, не меняя программу FL Studio по умолчанию.

Есть еще два способа:

| Способ | Файл или место | Что делает |
|---|---|---|
| Портативный zip | `LYNX-<version>-windows-x64.zip` | Распакуйте его куда угодно и запустите `LYNX.exe`. Ничего не устанавливается. |
| Microsoft Store | [LYNX SHARE в Store](https://apps.microsoft.com/detail/9NQRFBFDCX6N) | Store устанавливает программу и обновляет ее. |

## Установка в macOS

macOS 11 Big Sur или новее. Один универсальный `LYNX-<version>-macos-universal.dmg` подходит и для Intel, и для Apple silicon.

1. Откройте `.dmg` и перетащите LYNX SHARE в *Программы*.
2. Приложение не нотаризовано Apple и не имеет подписи Developer ID, поэтому при первом запуске нужен дополнительный шаг. Щелкните LYNX SHARE в *Программах* правой кнопкой (или с Control), выберите *Открыть*, затем снова *Открыть*.
3. В macOS 15 Sequoia или новее попробуйте открыть программу один раз, затем перейдите в *Системные настройки › Конфиденциальность и безопасность* и нажмите *Все равно открыть*.

Вариант через Терминал:

```
xattr -dr com.apple.quarantine /Applications/LYNX.app
```

macOS запрашивает доступ к микрофону при первой записи.

## Установка в Linux

x86_64 с glibc 2.35 или новее (Ubuntu 22.04+, Debian 12+, Fedora 36+, актуальный Arch или Manjaro). LYNX SHARE нужны X11 или XWayland. Звук идет через PipeWire, JACK или ALSA, и для этого не нужно ничего доустанавливать.

AppImage (`LYNX-<version>-x86_64.AppImage`):

```
chmod +x LYNX-*.AppImage
./LYNX-*.AppImage
```

Некоторым дистрибутивам для запуска AppImage нужен libfuse2 (`libfuse2` в Ubuntu 22.04, `libfuse2t64` в 24.04, `fuse2` в Arch, `fuse-libs` в Fedora). При первом запуске мастер настройки предлагает добавить LYNX SHARE в меню приложений и открывать им файлы `.lynx`. Это можно изменить позже в `Опции › Общие настройки...` или из терминала командой `./LYNX-*.AppImage --menu-entry on` (или `выкл.`).

Если вы не хотите ставить libfuse2, используйте `LYNX-<version>-linux-x86_64.tar.gz`: распакуйте его и запустите `./install.sh`. Это установит LYNX SHARE для вашего пользователя в `~/.local` с пунктом меню, значком и типом файла `.lynx`.

## Где хранятся настройки

| Система | Папка настроек |
|---|---|
| Windows | `%APPDATA%\LYNX` |
| macOS | `~/Library/Application Support/LYNX` |
| Linux | `~/.config/LYNX` (или в `$XDG_CONFIG_HOME`) |

В этой папке лежат ваши опции, выбранный язык (`language.txt`), ваши сочетания клавиш (`keys.json`), ваши папки плагинов (`plugin-folders.txt`) и список просканированных плагинов (`plugins.xml`).

## Обновление

При запуске LYNX SHARE запрашивает у GitHub номер последней версии. Никаких сведений о вас не отправляется. Когда выходит новая версия, появляется полоса с текстом `LYNX SHARE <version> is available`, кнопкой `Что нового` и кнопкой обновления. `Справка › Проверить обновления...` проверяет наличие обновлений в любой момент.

| Сборка | Как обновляется |
|---|---|
| Установщик для Windows | `Обновить` скачивает новый установщик, спрашивает о несохраненных изменениях, устанавливает и перезапускает |
| Портативный zip для Windows, macOS | `Обновить` скачивает новый файл и показывает его в папке |
| Linux AppImage | `Обновить` обновляет файл AppImage на месте. То же могут делать Gear Lever и AppImageUpdate снаружи |
| Linux `.tar.gz` | `Скачать...` открывает страницу загрузки |
| Microsoft Store | Обновляет Store. В этой сборке нет собственной проверки обновлений |

Чтобы отключить проверку, откройте `Опции › Общие настройки...` и снимите флажок `Автоматически проверять обновления`.

## Удаление

- Установщик для Windows: удалите LYNX SHARE через список *Приложения и возможности* в Windows.
- Портативный zip: удалите папку, в которую вы распаковали архив.
- Linux `.tar.gz`: выполните `./install.sh --uninstall`.

## Что стоит знать

- Сборки для Windows остаются неподписанными, пока заявка проекта на подпись кода не будет принята. У приложения для macOS только ad-hoc подпись. Пакеты для Linux не подписаны.
- Чтобы проверить загрузку, сравните ее SHA-256 со строкой в `SHA256SUMS.txt` на странице релиза.
- Установщик, zip, `.dmg` и `.tar.gz` включают демонстрационный проект `Demo.lynx`.
- Закрытие полосы обновления кнопкой закрытия пропускает эту версию.
