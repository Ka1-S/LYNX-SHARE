В `Вид › Стиль раскладки` три пункта: `Работа с паттернами (по умолчанию)`, `Работа с запуском клипов` и `Простой режим работы`. Тот же выбор есть в `Опции › Общие настройки`, в разделе «Рабочий процесс». Выбор сохраняется при закрытии программы.

Работа с паттернами — это Channel Rack, паттерны и Playlist. Работа с запуском клипов добавляет рядом с Playlist сетку клипов со сценами. Паттерны и Channel Rack остаются доступными.

## Запуск клипов в сетке

1. Выберите `Вид › Стиль раскладки › Работа с запуском клипов`. Рядом с Playlist появится сетка клипов.
2. Щёлкните правой кнопкой по пустому слоту, выберите `Поместить сюда паттерн` и укажите паттерн. Двойной щелчок по пустому слоту ставит туда текущий паттерн.
3. Нажмите на треугольник слева от клипа, чтобы запустить его. Если транспорт остановлен, он стартует.
4. Нажмите на треугольник сцены в столбце `Сцены`, чтобы запустить все клипы в этой строке.
5. Нажмите `Остановить все клипы`, чтобы остановить их.
6. Нажмите `Вернуться к плейлисту`, чтобы дорожки снова играли свои клипы Playlist.

## Что меняется на экране

- Сетка клипов показана рядом с Playlist. Дорожки Playlist — это столбцы, а сцены — строки.
- В заголовке Playlist появляется переключатель `Оба`, `Сетка`, `Песня`. `Сетка` показывает только сетку, `Песня` только Playlist.
- В первый раз Channel Rack скрыт. Показать его можно по `F6` или кнопкой на панели инструментов.
- Дорожки автоматизации в Playlist включены.
- Раскладка окон хранится отдельно для каждого стиля, поэтому каждый стиль возвращается в том виде, в каком вы его оставили.

## Сетка

Запущенный клип стартует не сразу. Он ждёт ближайшей точки квантования запуска, и его треугольник до этого мигает. Поле внизу сетки задаёт глобальное квантование запуска, которым пользуются все клипы со значением `Глобально`. Остановка ждёт точно так же.

Настройки клипа открываются правым кликом по нему.

| Настройка | Что она делает |
|---|---|
| `Квантование запуска` | Когда стартует этот клип: `Глобально`, `Нет`, от `8 тактов` до `1/32` |
| `Режим запуска` | `Триггер`, `Гейт`, `Переключение` или `Повтор` |
| `Легато (сохранять позицию)` | Клип перенимает позицию воспроизведения клипа, игравшего на этой дорожке до него |
| `Цикл` | Вкл.: клип повторяется. Выкл.: играет один раз, затем дорожка останавливается |
| `Следующее действие` | Что происходит после клипа: два действия, у каждого свой шанс, и время, через которое они срабатывают |
| `Delete` | Очищает слот |

Правый клик по пустому слоту открывает `Кнопка стоп (сцена останавливает здесь эту дорожку)`. Щелчок по квадрату слева от пустого слота останавливает эту дорожку. Правый клик по сцене даёт `Вставить сцену`, `Добавить сцену ниже`, `Удалить сцену`, `Переименовать сцену...` и темп сцены.

В меню слота есть ещё два параметра для всей сетки: `Возвращать дорожки плейлисту при остановке транспорта` и `Следующие действия во всей сетке`.

| Команда | Клавиша | Что она делает |
|---|---|---|
| Перемещение | Стрелки | Выбирает другой слот |
| Запуск клипа | `Enter` | Запускает выбранный клип |
| Запуск сцены | `Ctrl+Enter` | Запускает выбранную сцену |
| Удаление клипа | `Del` | Очищает выбранный слот |

## Сеты Ableton Live

Когда вы открываете сет Live, его клипы и сцены Session попадают в сетку клипов вместе с настройками запуска. `Файл › Экспорт › Сет Ableton Live (.als)` записывает сетку обратно как клипы Session. В `Опции › Общие настройки` есть `Клипы сессии из сетов Live`, где `Плейлист, после аранжировки` вместо этого размещает их на Playlist.

## Возврат назад

Выберите `Вид › Стиль раскладки › Работа с паттернами (по умолчанию)`. Раскладка окон, которая была у вас при работе с паттернами, возвращается, а дорожки автоматизации принимают прежнюю настройку. Клипы в сетке остаются в проекте.

## Что полезно знать

- Дорожка, запустившая клип, молчит в Playlist, пока вы не нажмёте `Вернуться к плейлисту`. Параметр `Возвращать дорожки плейлисту при остановке транспорта` делает это за вас при каждой остановке.
- В 0.1.25 слот заполняется из своего меню или двойным щелчком. Перетащить клип или файл в слот нельзя.
- Следующие действия есть у клипов, но не у сцен.
- Дорожки автоматизации, включённые вручную при работе с запуском клипов, при возврате не сохраняются.
- Если выбрана работа с паттернами, ничего из сетки не загружается.
