LYNX SHARE는 모든 MIDI 입력 장치의 노트와 컨트롤러 움직임을 받습니다. 장치는 설정의 MIDI 페이지에서 구성합니다. `옵션 › MIDI 설정...` 또는 `F10`입니다. 하드웨어가 없어도 타이핑 키보드와 터치 키보드로 노트를 연주할 수 있습니다.

## 키보드 연결하기

1. 키보드를 꽂고 `옵션 › MIDI 설정...`(`F10`)를 엽니다.
2. `입력 장치`에서 키보드를 찾아 체크합니다. 목록에 없으면 `장치 목록 새로 고침`를 클릭합니다.
3. 두 상자는 `모든 MIDI 채널`과 `선택한 채널 연주`로 둡니다.
4. 설정을 닫고 [채널 랙](/wiki/channel-rack/)에서 채널을 선택합니다.
5. 연주합니다. 선택한 채널에서 소리가 납니다.

## 입력 장치

| 설정 | 기능 |
|---|---|
| 체크 상자 | 장치를 켜거나 끕니다 |
| `모든 MIDI 채널` | 모든 MIDI 채널 또는 한 채널만 듣습니다. `MPE 컨트롤러`는 이 목록의 맨 끝에 있습니다 |
| `선택한 채널 연주` | 노트가 채널 랙에서 선택한 채널로 가거나, 항상 고정된 채널 하나로 갑니다 |
| `벨로시티` | `연주한 그대로`, `소프트(약하게 쳐도 크게)`, `하드(더 세게 쳐야 함)`, `고정(모든 노트 최대 벨로시티)` 중에서 고릅니다 |
| `퍼포먼스 모드 채널` | 퍼포먼스 모드가 켜져 있으면 이 MIDI 채널의 노트가 플레이리스트 클립을 실행합니다 |
| `송 마커 점프` | 이 MIDI 채널의 노트는 연주되지 않고 곡을 마커로 이동시킵니다 |
| `컨트롤러 유형` | `자동 감지`, `일반 컨트롤러` 또는 컨트롤러 프로필 |
| `풋 페달이 노트 오프를 제어` | 기본값은 켜짐입니다. 서스테인 페달(CC 64)이나 소스테누토 페달(CC 66)이 노트를 붙잡습니다. 꺼 두면 페달이 컨트롤러로서 플러그인에 전달됩니다 |

## 노브를 컨트롤에 연결하기

1. LYNX SHARE에서 노브나 페이더를 우클릭합니다.
2. `MIDI 컨트롤러에 연결(컨트롤러의 노브를 움직이세요)`를 선택합니다.
3. 하드웨어의 노브나 페이더를 움직입니다. 연결이 만들어집니다.

연결은 프로젝트와 함께 저장됩니다. 제거하려면 컨트롤을 다시 우클릭하고 `컨트롤러 연결 해제`를 선택합니다. 메뉴 항목에 사용 중인 CC 번호가 표시됩니다.

| 명령 | 키 | 기능 |
|---|---|---|
| `컨트롤러에 연결...` | 없음 | 컨트롤의 `리모트 컨트롤 설정` 창을 열어, 연결을 직접 보고 설정할 수 있습니다(아래) |
| `글로벌 연결 덮어쓰기...` | 없음 | 모든 프로젝트에서 작동하는 연결을 만듭니다. 프로젝트가 아니라 설정에 보관됩니다 |
| `전역 연결 재정의...(모든 프로젝트용: 컨트롤러의 노브를 움직이세요)` | 없음 | 한 번에 전역 연결을 만듭니다. 이어서 하드웨어 컨트롤을 움직이세요. 괄호가 없는 항목은 대신 `글로벌 연결 설정` 창을 엽니다 |
| `전역 연결 제거` | 없음 | 그 연결을 다시 제거합니다 |
| `컨트롤러에 멀티링크` | `Ctrl+J` | 켜져 있는 동안, 움직인 컨트롤이 그다음에 움직이는 하드웨어 컨트롤에 순서대로 연결됩니다. `옵션` 메뉴에 있습니다 |
| `픽업(테이크오버 모드)` | 없음 | MIDI 페이지에 있습니다. 컨트롤러가 파라미터의 현재 값에 도달한 뒤에야 파라미터를 움직이므로 값이 튀지 않습니다 |

MIDI 페이지의 `연결(이 프로젝트, 그다음 전역)`에 연결 목록이 나옵니다. `컨트롤러 유형`이 `일반 컨트롤러`인 장치는 직접 연결한 것만 처리합니다.

서드파티 플러그인의 파라미터는 채널 메뉴나 이펙트 슬롯 메뉴의 `플러그인 파라미터 오토메이션`로 접근합니다. 거기 있는 각 파라미터에도 같은 연결 항목이 있습니다. [오토메이션](/wiki/automation/)을 참고하세요.

## 원격 제어 설정

`컨트롤러에 연결...`는 FL Studio처럼 이 창을 엽니다. `글로벌 연결 설정`(`글로벌 연결 덮어쓰기...`에서 엽니다)에는 연결 목록, `Omni`, 내부 컨트롤러, `충돌 제거`를 제외하고 같은 항목이 있습니다. MIDI 페이지 목록에서 연결을 더블 클릭해도 열립니다.

| 설정 | 하는 일 |
|---|---|
| `포트`, `채널`, `Ctrl` | MIDI 입력 포트 번호, MIDI 채널, 컨트롤러 번호입니다. `Ctrl`을 우클릭하면 표준 컨트롤러가 이름으로 나옵니다. 그 목록의 `노트 C0`은 노트 연결을 만듭니다. 다른 키를 쓰려면 거기서부터 번호를 올리세요 |
| `자동 감지` | 기본값은 켜짐입니다. 장치의 컨트롤을 움직이면 번호가 채워집니다 |
| `Omni` | 연결이 선택한 채널을 따르며, 믹서 슬롯의 이펙트라면 선택한 믹서 트랙을 따릅니다 |
| `모드` | 노트나 버튼 연결이 동작하는 방식입니다. `기본값`와 `홀드`는 키를 따릅니다. 누르는 동안은 벨로시티, 뗄 때는 0입니다. `래치`는 누를 때마다 양 끝 값을 오갑니다. `Inc`는 누를 때마다 값을 올립니다. `유지`는 벨로시티를 설정하고 뗀 뒤에도 유지합니다 |
| Internal controller | 컨트롤을 대신 프로젝트의 내부 컨트롤러 하나에 연결합니다. 프로젝트에 내부 컨트롤러가 있을 때만 표시됩니다. `오토메이션 녹음`을 켜면 그 컨트롤러의 움직임을 오토메이션으로 녹음할 수 있습니다 |
| `매핑 공식` | 입력이 컨트롤에 매핑되는 방식이며 변수 `입력`을 씁니다. `프리셋`에는 FL의 공식 목록이 있습니다. 입력한 공식을 적용하려면 `Enter`를 누르세요. 옆의 커브가 결과를 보여 줍니다 |
| `스무딩` | 컨트롤의 움직임을 부드럽게 합니다. `시간`은 그 길이를 정하며, 음수 값은 1폴, 양수 값은 3폴입니다 |
| `충돌 제거` | 기본값은 켜짐입니다. `적용`를 클릭하면 같은 컨트롤러를 쓰는 다른 연결을 제거합니다. 그런 연결이 있는 동안은 빨간색이 됩니다 |
| `초기화`, `건너뛰기`, `적용` | `적용`는 연결을 저장합니다(실행 취소 한 단계). 멀티링크로 컨트롤 여러 개가 대기 중이면 `건너뛰기`이 다음 컨트롤로 넘어갑니다 |

## 컨트롤러 프로필

컨트롤러 프로필은 연결할 것 없이 장치의 트랜스포트 버튼, 페이더, 노브, 패드, 표시등, 디스플레이를 설정합니다.

1. `옵션 › MIDI 설정...`(`F10`)를 열고 `입력 장치` 아래에서 장치를 체크합니다.
2. `컨트롤러 유형`을 `자동 감지`로 그대로 둡니다. 괄호 안의 이름은 장치의 포트 이름에서 찾은 프로필입니다.
3. `일반 컨트롤러`로 나오면 목록에서 프로필을 직접 고릅니다.
4. 상자 옆의 줄을 읽어 보세요. `Feedback to`는 표시등, 모터 페이더, 디스플레이 텍스트를 받는 출력 포트의 이름입니다.

| 프로필 | 매핑하는 내용 |
|---|---|
| `Mackie Control Universal` | 페이더는 인서트의 볼륨과 마스터에 연결됩니다. V-Pot은 팬, 선택한 채널 플러그인의 파라미터, 채널 랙의 볼륨에 연결됩니다. 스트립별 암, 솔로, 뮤트, 선택, 페이더 뱅크, 재생, 정지, 녹음, 되감기, 빨리 감기, 패턴 모드와 송 모드, 메트로놈, 실행 취소, 조그 휠이 있습니다. 디스플레이에는 이름과 값이 나옵니다 |
| `Mackie Control Extender (XT)` | 스트립 8개를 더한 같은 구성입니다. 유닛들이 뱅크 하나를 공유하며, 순서는 `입력 장치` 목록의 순서입니다 |
| `Novation Launchkey MK3 (DAW mode)` | 팟은 팬, 볼륨, 플러그인 파라미터에, 페이더는 볼륨에 연결되고, 페이더 버튼은 인서트를 선택합니다. 뱅크, 재생, 정지, 녹음, 루프, 메트로놈, 실행 취소 버튼이 있습니다. Session 패드는 선택한 채널의 16스텝입니다. 키보드의 두 번째 포트에서 쓰세요 |
| `Akai APC Key 25 mk2` | 노브는 볼륨, 팬, 플러그인 파라미터에 연결됩니다. 위쪽 패드 두 줄은 선택한 채널의 16스텝이고 그 아래 세 줄은 노트를 연주합니다. 트랙 버튼은 인서트를 선택합니다. 정지, 재생, 녹음이 있습니다. 두 번째 포트에서 쓰세요 |
| `Arturia KeyLab Essential mk3 (Mackie Control port)` | 키보드의 MCU/HUI 포트에서 쓰는 Mackie Control 맵입니다 |
| `Korg nanoKONTROL2 (Mackie Control mode)` | Mackie Control 맵입니다. 자동으로 감지되지 않습니다. 장치를 Mackie Control 모드로 시작하고 이 유형을 직접 고르세요 |

위치 값을 보내는 노브와 페이더는 소프트 테이크오버를 씁니다. 컨트롤의 값에 도달한 뒤에야 그 컨트롤을 움직입니다. 직접 연결한 컨트롤은 연결이 그대로 유지됩니다. `컨트롤러 프로필 폴더`는 직접 만든 프로필(`*.lynxctl`)용 폴더를 열고, `장치 목록 새로 고침`는 프로필을 다시 읽습니다.

내장 프로필은 각 제조사의 문서를 바탕으로 작성했습니다. 아직 실제 하드웨어에서는 시험해 보지 않았습니다.

## MPE 컨트롤러

MPE는 첫 단계에 있습니다. MPE 컨트롤러는 노트마다 자기 피치 벤드, 음색(CC 74), 압력으로 연주합니다.

1. MIDI 페이지에서 장치의 `모든 MIDI 채널` 상자를 열고 `MPE 컨트롤러`를 고릅니다.
2. 옆에 나타나는 상자에서 멤버 채널을 `채널 2`부터 `Channels 2-16`까지 중에서 고릅니다.
3. 연주합니다. 녹음하려면 [녹음](/wiki/recording/)을 참고하세요.

- 녹음된 노트는 각각 값을 하나씩만 유지합니다. 벤드는 미세 피치로, 음색은 Mod X로, 가장 강한 압력은 Mod Y로 남습니다. 곡선은 아닙니다.
- 내장 악기 중에서는 Sampler와 내장 신스가 이 값을 따릅니다.
- 서드파티 플러그인은 플러그인 창의 `래퍼 설정`에서 `MIDI` 아래의 `MPE`가 켜져 있을 때 MPE를 받습니다. 그러면 노트마다 자기 MIDI 채널, 2번부터 16번으로 나갑니다.
- 실제 MPE 컨트롤러로는 아직 시험해 보지 않았습니다.

## MIDI Map Mode와 Key Map Mode

[클립 실행 워크플로](/wiki/layouts/)에서는 Ableton Live처럼 클립, 씬, 버튼을 매핑할 수 있습니다. `둘 다`, `그리드`, `송` 스위치 옆의 `MIDI`와 `키` 버튼이 모드를 켜며, `Ctrl+M`과 `Ctrl+K`도 같습니다.

1. MIDI Map Mode는 `Ctrl+M`, Key Map Mode는 `Ctrl+K`를 누릅니다. 매핑할 수 있는 모든 요소가 색으로 표시되며, MIDI는 파랑, 키는 주황입니다.
2. 요소를 클릭합니다. 클립 슬롯, 씬, 트랙의 정지 버튼, `모든 클립 정지`, 재생, 정지, 녹음, `세션 녹음`, 메트로놈, 또는 Session 믹서나 Device View의 노브입니다.
3. MIDI 장치의 컨트롤을 움직이거나 키를 누릅니다. Key Map Mode에서는 컴퓨터 키를 누릅니다. 요소에 할당이 표시됩니다. 예를 들어 `1/19`(채널과 컨트롤러)입니다.
4. 브라우저 자리에 매핑 목록이 나옵니다. Channel, Note/Control 또는 Key, Path, Name, Min, Max입니다. Min이나 Max를 드래그하거나, 더블 클릭해 값을 입력하세요. 행을 우클릭하면 `범위 반전`와 `Delete`가 있습니다.
5. 같은 키를 다시 누르면 모드가 끝납니다.

## 타이핑 키보드

`Ctrl+T` 또는 `옵션 › 타이핑 키보드 피아노`로 컴퓨터 키보드를 피아노로 바꿉니다. `Z`부터 `M`까지의 줄과 `Q`부터 `P`까지의 줄이 선택한 채널을 연주합니다.

- 켜져 있는 동안은 글자 키와 숫자 키가 노트입니다. 피아노 롤과 플레이리스트의 글자 한 개짜리 도구 키는 꺼져 있을 때만 작동합니다.
- 항상 피아노 롤의 벨로시티로 연주합니다. MIDI 페이지의 `벨로시티` 설정은 MIDI 장치용입니다.
- 같은 스위치가 `옵션 › 일반 설정...`에도 있습니다.

## 터치 키보드

![터치 키보드: 옥타브 버튼, 건반 크기, 벨로시티 모드, C4부터 시작하는 건반 한 줄](/assets/img/wiki/touch-keyboard.webp)

`보기 › 터치 키보드`(`Alt+F7`)는 마우스나 터치스크린으로 연주하는 피아노를 엽니다. 채널 랙에서 선택한 채널을 연주하며, 그 이름이 오른쪽에 표시됩니다.

| 설정 | 기능 |
|---|---|
| `-`와 `+` | 한 옥타브 내리기/올리기 |
| 건반 크기 | `작은 건반`, `중간 건반`, `큰 건반` |
| `벨로시티: 터치 위치` | 건반 위쪽 근처를 누르면 약하게, 아래쪽 근처를 누르면 세게 연주됩니다 |
| `벨로시티: 고정` | 모든 노트를 슬라이더로 정한 벨로시티로 연주합니다 |
| `노트 이름` | 건반에 이름을 표시합니다 |

## MIDI 동기화

MIDI 페이지의 `출력 장치`는 트랜스포트를 하드웨어와 다른 소프트웨어로 보냅니다. 장치의 `마스터 동기화 전송`를 체크하고 `MIDI 클럭`(Start, Continue, Stop, Song Position Pointer 포함) 또는 MIDI Time Code를 고릅니다. `오프셋(ms)`는 양수면 동기화를 늦게, 음수면 일찍 보냅니다. `All notes off 전송`는 초기화할 때와 내보낸 뒤에 장치로 그 메시지를 보냅니다.

`외부 클럭 동기화`는 반대로 동작합니다. LYNX SHARE가 고른 입력의 MIDI 클럭을 템포, Start, Continue, Stop, Song Position Pointer까지 따라갑니다. `외부 동기화 오프셋(밀리초)`는 양수면 LYNX SHARE가 늦게, 음수면 일찍 재생됩니다. `상태`에 클럭이 동작 중인지 표시됩니다.

## 알아 두기

- `외부 클럭 동기화`의 입력을 고르면 그 장치가 `입력 장치`에서 켜집니다.
- 연결된 MIDI 컨트롤러로 템포를 움직여도 오디오 클립의 길이는 바뀌지 않습니다. 최종 템포는 직접 입력하거나 설정하세요.
- 연주를 녹음하려면 [녹음](/wiki/recording/)을 참고하세요. 들어오는 노트를 [피아노 롤](/wiki/piano-roll/)에서 스케일에 맞춰 스냅할 수 있습니다.
- 플러그인으로 보내는 MIDI CC, 채널 애프터터치, 피치 벤드는 `MIDI 컨트롤러 오토메이션(CC, 애프터터치, 피치 벤드)`로 오토메이션할 수 있습니다.
- 페달로 붙잡은 노트는 페달을 놓는 순간까지 녹음됩니다.
- 오토메이션 클립은 컨트롤러로 컨트롤을 움직이는 동안에는 컨트롤을 되찾지 않습니다. 다음에 재생이 시작되면 컨트롤이 다시 오토메이션을 따릅니다.
- `리모트 컨트롤 설정`에서 만든 노트 연결은 .flp 내보내기에 기록되지 않습니다.
- `Ctrl+M`과 `Ctrl+K`는 클립 실행 워크플로에서만 맵 모드를 시작합니다. Map Mode에는 아직 매크로 매핑과 노트 범위가 없습니다.
