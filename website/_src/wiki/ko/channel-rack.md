![스텝 행이 있는 채널 랙](/assets/img/rack.webp)

채널 랙에는 프로젝트의 모든 악기(채널)가 한 행에 하나씩 나열되고, 현재 패턴의 스텝이 표시됩니다. `F6` 키로 표시하거나 숨깁니다. 트랜스포트의 패턴 버튼을 우클릭해도 표시됩니다.

## 드럼 패턴 만들기

1. `F6` 키를 눌러 채널 랙을 표시합니다.
2. 마지막 행 아래의 `+ 채널 추가` 상자를 클릭하고 메뉴에서 악기를 고릅니다. [브라우저](/wiki/browser/)에서 샘플을 더블 클릭해 새 샘플러 채널을 만들어도 됩니다.
3. 채널 행의 스텝을 클릭해 켭니다. 끌면 스텝이 연속으로 그려집니다.
4. 스텝을 우클릭하면 지워집니다.
5. `Space` 키를 눌러 재생합니다. 패턴 모드에서는 패턴이 반복됩니다.
6. 행의 볼륨 노브를 끌어 레벨을 정합니다.

## 스텝 입력하기

- 스텝을 클릭하면 켜집니다. 끌면 스텝이 연속으로 그려집니다. 켜져 있는 스텝에서 끌기 시작하면 반대로 지워집니다.
- 우클릭하거나 우클릭한 채 끌면 지워집니다.
- 패턴 끝 뒤를 클릭하면 스텝이 추가되고 패턴이 길어집니다.
- 노트가 단순한 스텝이 아닌 행(다른 건반, 긴 노트, 슬라이드)에는 노트의 축소 그림이 표시됩니다. 클릭하면 [피아노 롤](/wiki/piano-roll/)에서 열립니다.
- 오디오 파일을 랙에 놓아 채널을 만들 수 있습니다.

채널 메뉴(채널 이름을 우클릭)에는 `2스텝마다 채우기`, `4스텝마다 채우기`, `8스텝마다 채우기`, `고급 채우기`, `왼쪽으로 회전`, `오른쪽으로 회전`가 있습니다.

## 그래프 레인

![Kick 채널 아래에 열린 그래프 레인. 스텝마다 벨로시티 막대가 하나씩 있다](/assets/img/wiki/rack-graph.webp)

`Ctrl+K` 키를 누르면 선택한 채널 아래에 그래프 레인이 표시됩니다. 왼쪽의 버튼으로 편집할 항목을 고릅니다. 벨로시티, 팬, 릴리스, 미세 피치, Mod X, Mod Y 중 하나입니다. 끌면 스텝마다 값이 정해지고, 우클릭한 채 끌면 램프가 그려지며, `Alt` 키를 누른 채 클릭하면 스텝이 초기화됩니다.

## 행의 구성 요소

| 부분 | 동작 |
|---|---|
| 뮤트 라이트 | 클릭하면 뮤트됩니다. `Ctrl` 키를 누른 채 클릭하거나 우클릭하면 솔로가 됩니다. |
| 팬 및 볼륨 노브 | 끌거나 휠을 사용합니다. |
| 라우팅 상자 | 끌거나 휠로 믹서 인서트를 고릅니다. 더블 클릭하면 믹서에 그 인서트가 표시됩니다. 우클릭하면 다음 빈 인서트가 지정됩니다. |
| 이름 버튼 | 클릭하면 채널의 에디터가 열리거나 닫힙니다. `Alt` 키를 누른 채 클릭하면 다른 에디터가 열린 채로 유지됩니다. `Ctrl` 키를 누른 채 클릭하면 미리 듣습니다. 위아래로 끌면 순서가 바뀝니다. 우클릭하면 채널 메뉴가 열립니다. |
| 선택기 | 클릭하면 채널 하나가 선택됩니다. `Ctrl` 키를 누른 채 클릭하거나 우클릭하면 추가하거나 제거합니다. `Shift` 키를 누른 채 클릭하면 범위가 선택됩니다. 더블 클릭하면 모두 선택됩니다. |

## 패턴

랙은 항상 현재 패턴을 편집합니다. 랙의 패턴 선택기에 패턴 이름이 표시됩니다. 이름을 클릭하면 목록이 나오고, 화살표를 써도 됩니다. 랙의 제목 위에서 `Shift` 키를 누른 채 휠을 돌려도 패턴이 바뀝니다.

랙의 패턴 길이 상자에서 길이를 마디 단위로 정합니다(끌거나 휠을 사용). 더블 클릭하면 노트에서 길이를 자동으로 가져옵니다.

메인 툴바의 스윙 노브는 모든 채널에 적용됩니다. 채널 메뉴의 `스윙 믹스`는 한 채널이 스윙을 얼마나 따를지 정합니다.

| 명령 | 키 | 동작 |
|---|---|---|
| 다음 패턴 | `Numpad +` | 다음 패턴을 현재 패턴으로 만듭니다 |
| 이전 패턴 | `Numpad -` | 이전 패턴을 현재 패턴으로 만듭니다 |
| 다음 빈 패턴 | `F4` | 다음 빈 패턴으로 이동하고 이름을 묻습니다 |
| 이름 및 색상 변경 | `F2` | 현재 패턴의 이름과 색상을 바꿉니다 |

## PC 키보드로 노트 연주하기

`Ctrl+T` 키를 누르면 타이핑 키보드가 피아노로 바뀝니다. `Z`부터 `M`까지와 `Q`부터 `P`까지의 키로 선택한 채널을 연주합니다. 켜 둔 동안에는 에디터의 한 글자 단축키가 일시 중지됩니다.

## 키

채널 랙에 포커스가 있을 때 동작합니다.

| 명령 | 키 | 동작 |
|---|---|---|
| 채널 선택 | `Up` / `Down` | 위 또는 아래 채널을 선택합니다 |
| 선택 확장 | `Shift+Up` / `Shift+Down` | 위 또는 아래 채널을 선택에 추가합니다 |
| 채널 이동 | `Alt+Up` / `Alt+Down` | 선택한 채널을 위나 아래로 옮깁니다 |
| 모두 선택 | `Ctrl+A` | 모든 채널을 선택합니다 |
| 잘라내기, 복사, 붙여넣기 | `Ctrl+X` / `Ctrl+C` / `Ctrl+V` | 선택한 채널의 스텝을 잘라내거나 복사하거나 붙여넣습니다 |
| 스텝 회전 | `Ctrl+Shift+Left` / `Ctrl+Shift+Right` | 선택한 채널의 스텝을 회전합니다 |
| 복제 | `Alt+C` | 선택한 채널을 복제합니다 |
| 삭제 | `Alt+Del` | 선택한 채널을 삭제합니다 |
| 그룹 | `Alt+G` | 선택한 채널을 새 필터 그룹에 넣습니다 |
| 믹서로 라우팅 | `Ctrl+L` | 선택한 채널을 빈 믹서 인서트로 보냅니다 |
| 뮤트 | `1`부터 `0` | 채널 1~10을 뮤트하거나 해제합니다 |
| 솔로 | `Ctrl+1`부터 `Ctrl+0` | 채널 1~10을 솔로로 만듭니다 |
| 그래프 레인 | `Ctrl+K` | 그래프 레인을 표시하거나 숨깁니다 |

## 채널 프리즈

프리즈는 채널을 오디오로 렌더링하고 그 오디오를 대신 재생합니다. 악기는 서드파티 플러그인이라도 언로드되므로 CPU와 메모리를 쓰지 않습니다.

1. 채널을 오른쪽 클릭하고 `프리즈`를 고릅니다. 채널을 여러 개 선택했으면 항목이 `선택한 채널 프리즈`로 나옵니다.
2. 행에 눈송이 태그가 붙습니다. 채널의 볼륨, 팬, 인서트의 이펙트는 전과 같이 작동합니다.
3. 노트나 악기를 다시 바꾸려면 채널을 오른쪽 클릭하고 `프리즈 해제`를 고릅니다. 악기는 이전 설정 그대로 돌아옵니다.

프리즈된 채널은 편집할 수 없습니다. 스텝이 잠기고 악기 창도 열리지 않습니다. 프리즈 뒤에 노트, 템포, 어레인지먼트가 바뀌면 태그 색이 바뀌고, `다시 프리즈`를 고를 때까지 전에 만든 오디오가 계속 재생됩니다. 렌더링된 오디오 파일이 없으면 대신 악기가 재생됩니다.

프리즈는 채널에서만 작동합니다. 믹서 인서트는 프리즈할 수 없습니다.

## 채널 메뉴의 다른 항목

`피아노 롤`, `이름 및 색상 변경`, `교체`(악기 교체), `복제`, `Delete`, `아르페지에이터`, `루프 지점`, `MIDI 기록 대상`, `채널 정렬`, `사용하지 않는 채널 선택`, `채널 설정`.

## 알아 두면 좋은 점

- `+ 채널 추가` 상자만 추가 메뉴를 엽니다.
- 랙에는 자체 패턴이 없습니다. 어디서든 현재 패턴을 바꾸면 랙에 표시되는 내용이 바뀝니다.
- 노트의 축소 그림이 표시된 행은 스텝으로 편집할 수 없습니다. 피아노 롤을 사용하세요.
- 숫자 키는 처음 10개 채널에만 적용됩니다.
- 표의 키는 랙에 포커스가 있어야 동작합니다. 먼저 랙을 클릭하세요.
