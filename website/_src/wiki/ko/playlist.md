![트랙에 클립이 놓인 플레이리스트](/assets/img/playlist.webp)

플레이리스트는 패턴이 곡이 되는 곳입니다. 트랙에는 세 종류의 클립이 놓입니다. 패턴 클립, 오디오 클립, 오토메이션 클립입니다. `F5` 키로 표시하거나 숨기고, `Enter` 키로 최대화하거나 복원합니다.

트랜스포트에는 모드가 두 가지 있습니다. 패턴 모드는 현재 패턴을 반복 재생합니다. 송 모드는 플레이리스트를 재생합니다. `L` 키로 전환합니다.

## 패턴을 곡에 배치하기

1. `F5` 키를 눌러 플레이리스트를 표시합니다.
2. 피커 패널에서 패턴을 클릭합니다. 피커에는 프로젝트의 패턴, 오디오, 오토메이션이 나열되며, 클릭한 항목이 클립 소스가 됩니다.
3. `P` 키를 눌러 연필을 고릅니다.
4. 트랙을 클릭해 클립을 배치합니다. 버튼을 누른 채 끌면 위치를 정할 수 있습니다.
5. `B` 키를 눌러 브러시를 고르고 트랙을 따라 끌면 클립이 끝에서 끝으로 이어 붙어 칠해집니다.
6. `L` 키를 눌러 송 모드로 바꾼 다음 `Space` 키로 재생합니다.

오디오 파일은 [브라우저](/wiki/browser/)에서 플레이리스트로 끌어다 놓을 수 있습니다.

## 도구

![어레인지먼트 상자, 도구, 스냅 상자가 있는 플레이리스트 툴바](/assets/img/wiki/playlist-tools.webp)

글자 키는 타이핑 키보드 피아노(`Ctrl+T`)가 꺼져 있을 때 동작합니다.

| 도구 | 키 | 동작 |
|---|---|---|
| 연필 | `P` | 클릭하면 피커의 클립을 배치합니다 |
| 브러시 | `B` | 끌면 클립이 끝에서 끝으로 이어 붙어 칠해집니다 |
| 지우개 | `D` | 클릭하거나 끌어서 삭제합니다 |
| 뮤트 | `T` | 클릭하거나 끌어서 클립을 뮤트하거나 해제합니다 |
| 칼 | `C` | 선을 그리며 끌면 클립을 가로질러 자르고, 클릭하면 그 지점에서 자릅니다 |
| 올가미 | `E` | 끌어서 선택 상자를 그립니다. `Shift` 키로 추가합니다 |
| 줌 | `Z` | 클릭하면 확대하고, 범위를 끌면 그 범위로 확대하며, 우클릭하면 축소합니다 |
| 듣기 | `Y` | 클릭하거나 끌면 그 지점부터 재생합니다 |
| 슬립 | `S` | 끌면 클립 안에서 내용이 미끄러집니다 |

## 클립 다루기

- 클립을 끌면 이동합니다. `Shift` 키를 누른 채 끌면 복사본이 만들어집니다.
- 클립의 끝을 끌면 크기가 바뀝니다. 시작을 끌면 내용은 제자리에 둔 채 다듬어집니다.
- 클립을 우클릭하면 삭제됩니다. `Ctrl` 키를 누른 채 끌면 선택됩니다.
- 클립을 더블 클릭하면 열립니다.
- 클립 왼쪽 위의 버튼은 클립 메뉴를 엽니다(고유하게 만들기, 이름 및 색상 변경, 자르기, 오디오의 경우 피치, 템포에 맞추기, 리버스).
- 오디오 클립의 메뉴는 FL Studio의 레이아웃처럼 두 열로 되어 있습니다. 왼쪽 열에는 `오디오 클립` 섹션(`미리 보기`, `뮤트됨`, `이름 및 색상 변경...`, `색상 변경...`, `랜덤 색상`, `아이콘 변경...`, `소스 채널 선택`, `채널 설정`, `고유하게 만들기`, `비슷한 클립 모두 선택`, `Delete`, `속성...`)과 `영역` 섹션(`리전 선택`, `자르기`)이 있습니다. 오른쪽 열에는 `샘플`(`샘플로 고유하게 만들기`, `샘플 편집`, `샘플에서 스템 추출`, `템포 감지`, `템포에 맞추기`), `오토메이션`(`자동화 › 팬` 또는 `볼륨`, `크로스페이드 대상`), `페이드`(`페이드 초기화`)가 있습니다. `여기서 분할`, `리버스`, `노멀라이즈`, `MIDI로 변환` 같은 LYNX SHARE 고유 항목은 구분선 아래 맨 마지막에 있습니다.
- `자동화 › 팬` 또는 `볼륨`은 트랙 위에 오디오 클립과 같은 길이의 오토메이션 클립을 만들며, 채널의 Levels 조정 팬 또는 볼륨용입니다.
- 끄는 동안 `Alt` 키를 누르고 있으면 스냅이 무시됩니다.
- 오디오 클립에는 페이드 핸들과, 위아래로 끄는 클립 게인이 있습니다. 페이드 핸들을 오른쪽 클릭하면 `크로스페이드 만들기`가 있는 메뉴가 나옵니다. 게인 핸들을 오른쪽 클릭하면 `게인 초기화`과 `노멀라이즈`가 나옵니다.
- `Shift+M` 키는 스트레치를 전환합니다. 켜면 오디오 클립의 크기를 바꿀 때 오디오를 자르는 대신 늘이거나 줄입니다.
- `Shift+Left`와 `Shift+Right`는 선택한 클립을 스냅 한 단계씩, `Shift+Up`과 `Shift+Down`은 한 트랙씩 옮깁니다. `Alt+Left`와 `Alt+Right`는 현재 줌에서 화면 픽셀 하나씩, 스냅 없이 옮깁니다. 선택한 클립이 없으면 모든 클립이 움직입니다.
- 오디오 클립 메뉴의 `샘플로 고유하게 만들기`은 클립이 재생하던 소리를 담은 새 파일을 클립에 줍니다. 피치, 스트레치, 리버스는 이미 오디오에 반영됩니다.
- 워프 마커가 있는 오디오 클립은 윗변에 작은 깃발로 마커를 보여 줍니다. 깃발을 옆으로 드래그하면 마커가 움직입니다.

## Edit 메뉴와 Select 메뉴

Playlist 메뉴에는 `편집`와 `선택` 하위 메뉴가 있습니다. `편집`에는 클립 명령이 있습니다. 잘라내기, 복사, 붙여넣기, `왼쪽으로 이동`, `오른쪽으로 이동`, `위로 이동`, `아래로 이동`, `고유하게 만들기`, `샘플로 고유하게 만들기`, `공간 삽입`, `공간 삭제`, 병합 명령, 페이드 옵션입니다. `선택`에는 `선택한 소스로 선택`(`Shift+C`), `선택 반전`(`Shift+I`), `선택 해제`(`Ctrl+D`), 뮤트된 클립과 겹치는 클립, `매직 올가미`가 있습니다. `매직 올가미`를 켜면 버튼을 누르지 않고 마우스를 클립 둘레로 원을 그리듯 움직여 클립을 선택합니다.

## 트랙

트랙 헤더에서 클릭하면 선택되고, `Ctrl` 키를 누른 채 클릭하면 추가하거나 제거하며, `Shift` 키를 누른 채 클릭하면 범위가 선택되고, 우클릭하면 트랙 메뉴가 열립니다. `Shift` 키를 누른 채 휠을 돌리면 트랙이 위아래로 움직입니다. 트랙의 라이트는 클릭하면 뮤트하고, `Ctrl` 키를 누른 채 클릭하거나 우클릭하면 솔로로 만듭니다. 두 트랙 사이의 구분선을 끌면 한 트랙의 크기가 바뀌고, `Shift` 키를 누른 채 끌면 모든 트랙의 크기가 바뀝니다.

Playlist 메뉴의 `보기`에서 트랙 헤더에 보일 내용을 고릅니다. `오디오 트랙에 컨트롤 표시`, `오디오 트랙에 레벨 표시`, `악기 트랙에 레벨 표시`입니다.

트랙 메뉴의 `트랙 모드`는 FL Studio처럼 트랙을 `할당 안 됨`, `오디오 트랙`, `악기 트랙`으로 만듭니다. `오디오 트랙`에는 먼저 `새 믹서 트랙`가 나오고, 이어서 모든 믹서 인서트가 번호와 이름으로 나옵니다. 선택은 선택한 모든 트랙에 적용됩니다. `악기 트랙`에는 `기존 채널 사용`, `더 많은 플러그인...`, 채널 랙의 악기 목록이 있습니다.

트랙 헤더 왼쪽 위의 `+`는 새 트랙을 위한 같은 선택지를 엽니다. `오디오 트랙 추가`, `더 많은 플러그인...`, 악기들입니다. `+`를 우클릭하면 오디오 트랙이 바로 추가됩니다.

## 패턴 블록

Playlist 메뉴에서 `패턴 블록(현재 프로젝트)`를 켜면 트랙 아래 구역에 패턴마다 한 줄이 생깁니다. 거기서 연필은 블록을 하나 놓고 그 줄을 따라 끌 수 있으며, 브러시는 블록을 칠하고 지우개는 블록을 지웁니다. 어떤 도구를 쓰고 있든 오른쪽 클릭하면 지워집니다.

## 눈금자, 루프, 마커

- 눈금자를 클릭하면 송 위치가 정해집니다.
- 눈금자에서 우클릭한 채 끌거나, `Ctrl` 키를 누른 채 끌거나, 더블 클릭한 채 끌면 시간 선택이 만들어지며, 이것이 루프도 됩니다. `Shift` 키를 누른 채 끌면 옮깁니다.
- `Ctrl+Ins` 키는 시간 선택의 길이만큼 모든 트랙에 공간을 삽입하고, `Ctrl+Del` 키는 그 길이를 제거합니다.
- `Alt+T` 키는 마커를 추가합니다. 마커를 클릭하면 그 위치로 이동합니다.
- `Ctrl` 키를 누른 채 휠을 돌리면 확대/축소되고, `Alt` 키를 누른 채 휠을 돌리면 트랙 높이가 바뀝니다.

## 오토메이션

노브나 페이더를 우클릭하고 `오토메이션 클립 만들기` 항목을 선택합니다. 클립이 플레이리스트에 나타납니다. 연필로 포인트를 끌고, 곡선을 클릭하면 포인트가 추가됩니다. 트랙 아래의 오토메이션 레인은 선택 사항이며 기본값은 꺼짐입니다. [오토메이션](/wiki/automation/)을 참고하세요.

점을 우클릭하면 메뉴가 나옵니다. 그 `모드` 목록에는 그 점에서 끝나는 구간을 위한 FL Studio의 13가지 커브 모드가 있습니다. `스무스`, `홀드`, 단일 커브 세 가지, 이중 커브 세 가지, `하프 사인`, `계단`, `부드러운 계단`, `펄스`, `웨이브`입니다. 새 점은 마지막에 쓴 모드를 따릅니다. 모드는 .flp 파일에서 읽고 .flp 파일에 기록됩니다.

## 어레인지먼트

툴바의 어레인지먼트 상자에서 어레인지먼트를 전환합니다. 프로젝트에는 어레인지먼트가 여러 개 있을 수 있습니다.

## 키

| 명령 | 키 | 동작 |
|---|---|---|
| 모두 선택 | `Ctrl+A` | 모든 클립을 선택합니다 |
| 복사, 잘라내기, 붙여넣기 | `Ctrl+C` / `Ctrl+X` / `Ctrl+V` | 클립을 복사하거나 잘라내거나 붙여넣습니다 |
| 복제 | `Ctrl+B` | 선택한 항목을 복제합니다 |
| 삭제 | `Del` | 선택한 클립을 삭제합니다 |
| 리플 삭제 | `Shift+Del` | 선택한 클립을 삭제하고 빈 공간을 메웁니다 |
| 리플 편집 | `Shift+S` | 리플 편집을 켜거나 끕니다 |
| 뮤트, 뮤트 해제 | `Alt+M` / `Shift+Alt+M` | 선택한 클립을 뮤트하거나 해제합니다 |
| 클립 이동 | `Shift+Left` / `Shift+Right` | 선택한 클립을 스냅 한 단계 옮깁니다 |
| 다른 트랙으로 이동 | `Shift+Up` / `Shift+Down` | 선택한 클립을 한 트랙 옮깁니다 |
| 클립 미세 이동 | `Alt+Left` / `Alt+Right` | 선택한 클립을 스냅 없이 화면 픽셀 하나 옮깁니다 |
| 고유하게 만들기 | `Ctrl+Shift+V` | 선택한 클립을 고유하게 만듭니다 |
| 병합 | `Ctrl+G` | 패턴 클립을 병합합니다 |
| 스트레치 | `Shift+M` | 오디오 클립 크기 조절 시 스트레치를 전환합니다 |
| 시간 삽입 | `Ctrl+Ins` | 시간 선택의 길이만큼 모든 트랙에 공간을 삽입합니다 |
| 시간 삭제 | `Ctrl+Del` | 모든 트랙에서 시간 선택을 제거합니다 |
| 마커 추가 | `Alt+T` | 마커를 추가합니다 |
| 줌 | `PageUp` / `PageDown` | 확대하거나 축소합니다 |
| 전체 보기 | `Shift+4` | 모든 내용이 보이도록 확대/축소합니다 |
| 최대화 | `Enter` | 플레이리스트를 최대화하거나 복원합니다 |

## 알아 두면 좋은 점

- 플레이리스트는 송 모드에서만 들립니다. 패턴 모드에서는 트랙에 무엇이 있든 `Space` 키가 현재 패턴을 재생합니다.
- `보기 › 레이아웃 스타일 › 클립 실행 워크플로` 메뉴를 선택하면 플레이리스트 옆에 클립과 장면의 그리드가 추가됩니다. 선택 사항입니다. [레이아웃](/wiki/layouts/)을 참고하세요.
- 한 컨트롤에 오토메이션 클립이 여러 개 겹치면 어느 것이 재생되는지가 FL Studio와 다를 수 있습니다(0.1.25 릴리스 노트).
- FL Studio처럼 패턴은 한 번에 한 클립에서만 재생됩니다. 같은 패턴의 나중 클립이 어느 트랙에서든 시작되면, 앞의 클립은 그 지점부터 새 노트를 시작하지 않습니다. 서로 다른 패턴의 클립은 함께 재생됩니다. 새 프로젝트와 FL Studio 프로젝트 모두에 적용됩니다. 0.1.27 이전에 저장된 .lynx 프로젝트는 모든 클립을 끝까지 계속 재생합니다.
- 연결된 MIDI 컨트롤러로 바꾼 템포는 오디오 클립의 크기를 바꾸지 않습니다.
- Linux에서 비디오에는 FFmpeg가 필요합니다.
