![피아노 롤](/assets/img/pianoroll.webp)

피아노 롤은 현재 패턴에서 채널 하나의 노트를 보여 줍니다. 왼쪽에 건반이 있고 아래쪽에는 노트별 값을 다루는 레인이 있습니다. `F7`을 누르면 표시하거나 숨기며, [채널 랙](/wiki/channel-rack/)의 채널 메뉴에서 `피아노 롤`을 선택해도 됩니다.

툴바의 채널 상자에서 편집할 채널을 고릅니다. 이 패턴에 노트가 있는 채널에는 표시가 붙습니다. 상자 위에서 휠을 돌리면 노트가 있는 채널을 차례로 넘어가고, `Ctrl`+휠은 모든 채널을 넘어갑니다.

## 노트 쓰기

1. 채널 랙에서 채널 이름을 우클릭하고 `피아노 롤`을 선택합니다.
2. `P`를 눌러 연필을 고릅니다.
3. 그리드를 클릭하면 노트가 추가됩니다. 버튼을 누른 채 드래그하면 위치를 정할 수 있습니다.
4. 노트의 끝을 드래그해 길이를 늘이거나 줄입니다.
5. 노트를 우클릭하면 삭제됩니다.
6. `Space`를 눌러 패턴을 듣습니다.

## 도구

![채널 상자, 도구, 스냅 상자가 있는 피아노 롤의 툴바](/assets/img/wiki/pianoroll-tools.webp)

도구마다 글자 키가 있습니다. 글자 키는 타이핑 키보드 피아노(`Ctrl+T`)가 꺼져 있을 때 작동합니다.

| 도구 | 키 | 기능 |
|---|---|---|
| 연필 | `P` | 클릭하면 노트가 추가되고 드래그하면 위치를 정합니다 |
| 브러시 | `B` | 드래그하면 노트 여러 개를 이어서 칠합니다. `Shift`를 누르면 하나씩 칠합니다 |
| 드럼 브러시 | `N` | 마우스 아래 건반에 그리드 칸마다 타격 하나를 놓습니다 |
| 지우개 | `D` | 클릭이나 드래그로 삭제합니다 |
| 뮤트 | `T` | 클릭이나 드래그로 노트를 뮤트하거나 뮤트를 풉니다 |
| 칼 | `C` | 선을 드래그하면 노트를 가로질러 자르고, 클릭하면 그 지점에서 자릅니다 |
| 올가미 | `E` | 드래그하면 선택 상자가 그려집니다. `Shift`는 추가합니다 |
| 줌 | `Z` | 클릭하면 확대하고, 범위를 드래그하면 그 범위로 확대하며, 우클릭하면 축소합니다 |
| 듣기 | `Y` | 클릭이나 드래그로 커서 아래 노트를 재생합니다 |

## 노트 다루기

- 노트를 드래그하면 이동합니다. `Shift`+드래그는 복사본을 만듭니다.
- 노트의 끝을 드래그하면 길이가 바뀝니다. 끝은 그대로 두고 시작을 드래그할 수도 있습니다.
- 우클릭하면 어떤 도구에서든 노트가 삭제됩니다.
- 노트를 더블 클릭하면 속성이 열립니다.
- 노트 위에서 `Alt`+휠을 돌리면 벨로시티가 바뀝니다.
- `Ctrl`+드래그는 선택하고, `Ctrl`+클릭은 노트를 선택에 추가하거나 뺍니다.
- 드래그하는 동안 `Alt`를 누르면 스냅을 무시합니다. `Backspace`는 스냅을 끄고 켭니다.
- 노트를 여러 개 선택하면 스트레치 핸들로 시간 방향으로 늘이거나 줄일 수 있습니다.

## 건반과 눈금자

건반의 키를 클릭하면 소리를 들을 수 있습니다. 키의 오른쪽일수록 큰 소리가 납니다. `Ctrl`+클릭은 그 키의 노트를 선택합니다. 건반 위에서 가운데 버튼으로 드래그하면 키가 높아지거나 낮아집니다.

눈금자를 클릭하면 위치가 정해집니다. 눈금자에서 `Ctrl`+드래그, 우클릭 드래그, 더블 클릭 후 드래그를 하면 그 시간 범위의 노트가 선택됩니다. `Ctrl`+휠은 줌이고 `Shift`+휠은 스크롤입니다.

## 툴바

| 설정 | 기능 |
|---|---|
| 스냅 | "메인"은 메인 툴바의 스냅을 따르며, 이 창에만 적용할 값을 따로 고를 수도 있습니다. |
| 코드 | 클릭하면 고른 코드가 만들어지며, 클릭한 노트가 근음이 됩니다. `Shift+N`을 누르면 단일 노트로 돌아갑니다. |
| 스케일 | 스케일의 음을 강조합니다. 별도의 버튼은 새 노트, 이동한 노트, 들어오는 MIDI를 고른 스케일에 스냅합니다. |
| 슬라이드(`S`) | 새 노트가 슬라이드 노트가 됩니다. 울리고 있는 노트가 그 노트로 미끄러져 이어집니다(808 글라이드). |
| 고스트 노트(`Alt+V`) | 다른 채널의 노트를 내 노트 뒤에 표시합니다. |
| 노트 색상 | 새 노트에 이 색상이 적용됩니다. 16가지가 있습니다. |
| 따라가기 | 패턴이 재생되는 동안 보기가 재생 헤드와 함께 스크롤됩니다. |
| 레인 상자 | 아래쪽 레인이 편집할 대상을 고릅니다. 벨로시티, 팬, 미세 피치 중 하나입니다. |

## 키

| 명령 | 키 | 기능 |
|---|---|---|
| 모두 선택 | `Ctrl+A` | 모든 노트를 선택합니다 |
| 선택 해제 | `Ctrl+D` 또는 `Esc` | 선택을 해제합니다 |
| 복사, 잘라내기, 붙여넣기 | `Ctrl+C` / `Ctrl+X` / `Ctrl+V` | 노트를 복사, 잘라내기, 붙여넣기 합니다 |
| 복제 | `Ctrl+B` | 선택한 노트를 복제합니다 |
| 삭제 | `Del` | 선택한 노트를 삭제합니다 |
| 트랜스포즈 | `Up` / `Down` | 선택한 노트를 반음 옮깁니다 |
| 옥타브 트랜스포즈 | `Ctrl+Up` / `Ctrl+Down` | 선택한 노트를 한 옥타브 옮깁니다 |
| 넛지 | `Left` / `Right` | 선택한 노트를 그리드 한 칸 옮깁니다 |
| 빠른 퀀타이즈 | `Ctrl+Q` | 시작 위치와 길이를 퀀타이즈합니다 |
| 시작 위치 퀀타이즈 | `Shift+Q` | 시작 위치만 퀀타이즈합니다 |
| 자르기 | `Ctrl+U` | 노트를 그리드에 맞춰 자릅니다 |
| 붙이기 | `Ctrl+G` | 맞닿은 노트를 하나로 합칩니다 |
| 레가토 | `Ctrl+L` | 각 노트가 다음 노트까지 이어지게 합니다 |
| 뮤트, 뮤트 해제 | `Alt+M` / `Shift+Alt+M` | 선택한 노트를 뮤트하거나 뮤트를 풉니다 |
| MIDI 가져오기 | `Ctrl+M` | MIDI 파일을 이 채널로 가져옵니다 |
| MIDI 내보내기 | `Ctrl+Shift+M` | 패턴을 MIDI 파일로 내보냅니다 |
| 줌 | `PageUp` / `PageDown` | 확대하거나 축소합니다 |

노트 도구(아르페지오, 스트럼, 뒤집기, 랜덤화, 퀀타이즈, 자르기 등)는 대화상자를 엽니다. 그 키는 [단축키](/wiki/shortcuts/) 페이지에 있습니다.

## 알아 두기

- 피아노 롤은 한 패턴에서 채널 하나를 보여 줍니다. 현재 패턴을 바꾸면 그 패턴의 노트가 표시됩니다.
- 타이핑 키보드 피아노(`Ctrl+T`)가 켜져 있으면 도구 글자 키는 아무 일도 하지 않습니다.
- 어떤 도구에서든 우클릭으로 삭제되므로, 노트 하나를 지우려고 지우개로 바꿀 필요가 없습니다.
- 여기서 `S`는 슬라이드 스위치입니다. 플레이리스트에서는 같은 글자가 슬립 도구입니다.
- 단순한 스텝이 아닌 노트(다른 키, 긴 노트, 슬라이드)가 있으면 채널 랙에서 그 채널의 행에 스텝 버튼 대신 축소판이 표시됩니다.
