![위쪽에 페이지 탭이 늘어선 설정 창의 일반 페이지](/assets/img/wiki/settings-general.webp)

설정 창에는 오디오, MIDI, 일반, 테마, 파일, LYNX extras, 프로젝트, 정보의 여덟 페이지가 있습니다. 앞의 여섯은 프로그램에 속합니다. 프로젝트와 정보는 열려 있는 프로젝트에 속하며 프로젝트와 함께 저장됩니다. 각 페이지는 `옵션` 메뉴 맨 위에 자기 항목이 있습니다.

## 설정 바꾸기

1. `옵션` 메뉴를 열고 `일반 설정...` 같은 페이지를 고릅니다.
2. 위쪽의 다른 탭을 클릭하면 다른 페이지로 넘어갑니다.
3. 설정을 바꿉니다. 바로 적용되지만, 언어와 인터페이스 글꼴은 LYNX SHARE를 다시 시작할 때 적용됩니다.

`F10`은 MIDI 페이지를, `F11`은 정보 페이지를 엽니다.

## 오디오

`옵션 › 오디오 설정...`. 드라이버, 장치, 샘플 레이트, 버퍼 크기, 녹음을 다룹니다. 이 페이지는 [오디오 설정](/wiki/audio-setup/)에서 설명합니다. `녹음` 아래의 `파일 형식`에는 이제 `WAV 16비트(장치의 샘플 레이트)`도 있습니다.

## MIDI

![MIDI 페이지: 입력 장치, 마스터 동기화가 있는 출력 장치, 외부 동기화](/assets/img/wiki/settings-midi.webp)

`옵션 › MIDI 설정...`

| 설정 | 기능 |
|---|---|
| 입력 장치 | 장치마다 끄거나, MIDI 채널 하나만 듣게 하거나, 선택한 채널 대신 채널 랙의 고정 채널을 연주하게 할 수 있습니다 |
| `컨트롤러 유형` | 입력 장치마다 `자동 감지`, `일반 컨트롤러` 또는 Mackie Control 같은 컨트롤러 프로필을 고릅니다. 옆의 줄에는 표시등과 디스플레이를 받는 포트의 이름이 나옵니다 |
| `MPE 컨트롤러` | 장치의 MIDI 채널 목록 맨 끝에 있습니다. 노트마다 자기 벤드, 음색, 압력이 함께 옵니다. 두 번째 상자에서 멤버 채널을 정합니다 |
| `장치 목록 새로 고침` | 장치를 다시 찾고 컨트롤러 프로필도 다시 읽습니다 |
| `컨트롤러 프로필 폴더` | 직접 만든 컨트롤러 프로필(`*.lynxctl`)용 폴더를 엽니다 |
| `마스터 동기화 전송` | Song Position Pointer가 있는 MIDI 클럭 또는 MIDI Time Code를 출력 장치로 보냅니다. `오프셋(ms)`로 늦게 또는 일찍 보냅니다 |
| `All notes off 전송` | 초기화할 때와 내보낸 뒤에 장치로 all notes off를 보냅니다 |
| `외부 클럭 동기화` | LYNX SHARE가 고른 입력의 MIDI 클럭(템포, 시작, 계속, 정지, 위치)을 따라갑니다 |
| `벨로시티` | MIDI 장치에서 들어오는 노트용: 연주한 그대로, 소프트, 하드, 고정 |
| `퍼포먼스 모드 채널` | 이 채널의 노트가 퍼포먼스 모드에서 플레이리스트 클립을 실행합니다 |
| `송 마커 점프` | 이 채널의 노트는 연주되지 않고 곡을 마커로 이동시킵니다 |
| `픽업(테이크오버 모드)` | 컨트롤러가 파라미터의 현재 값에 도달한 뒤에야 파라미터를 움직입니다 |
| `풋 페달이 노트 오프를 제어` | 기본값은 켜짐입니다. 서스테인 페달과 소스테누토 페달이 노트를 붙잡습니다. 꺼 두면 페달이 플러그인에 전달됩니다 |
| `게임 컨트롤러 사용` | 게임 컨트롤러로 트랜스포트를 조작하며, MIDI 컨트롤러처럼 연결할 수 있습니다. 기본값은 꺼짐입니다 |
| 링크 | 이 프로젝트의 컨트롤러 링크, 그다음 전역 링크이며, `연결 제거`와 `모두 제거`이 있습니다 |

## 일반

`옵션 › 일반 설정...`

| 설정 | 기능 |
|---|---|
| `레이아웃 스타일` | 패턴 워크플로(기본), 클립 실행 워크플로 또는 간단한 워크플로 |
| `기본 템플릿`, `시작 프로젝트` | `파일 › 새로 만들기`로 열리는 템플릿과 시작할 때 열리는 것으로, `빈 프로젝트`, `기본 템플릿`, `마지막으로 사용한 프로젝트` 중에서 고릅니다. `파일 › 템플릿으로 저장...`로 직접 만든 템플릿을 추가할 수 있습니다 |
| `Live 세트의 세션 클립` | 가져온 Live 세트의 세션 클립이 갈 곳: 클립 그리드 또는 어레인지먼트 뒤의 플레이리스트 |
| `언어`, `인터페이스 글꼴` | 다음에 시작할 때 적용됩니다 |
| `인터페이스 크기`, `메뉴 간격` | 인터페이스 전체의 배율, 그리고 촘촘한 메뉴나 여유 있는 메뉴 |
| `파형` | 깔끔한 모양(클립 색상) 또는 스펙트럼 색상이며, 스테레오 채널을 따로 표시할 수도 있습니다 |
| `노트 이름`, `검은 건반` | 영어식, 독일식, 계이름 표기와 샤프 또는 플랫 표기 |
| `플러그인 스타일` | 내장 플러그인 창의 모양: 자동, 또는 모든 플러그인에 하나의 스타일 |
| `애니메이션`, `애니메이션 속도` | 인터페이스 애니메이션, 그리고 재생 헤드와 미터가 움직이는 빈도 |
| `GPU로 그리기(Direct2D)` | 그래픽 드라이버가 충돌하거나 화면이 깜박이면 끕니다 |
| 시작 | 스플래시 화면, 시작 사운드, 시작할 때마다 백그라운드에서 새 플러그인 찾기 |
| 편집 | 타이핑 키보드 피아노, 채널 에디터 열어 두기, 탐색 시간 기억하기, 늘린 패턴 클립 반복하기 |
| `새 플러그인 모두 분리` | 켜짐: 추가하는 플러그인의 창이 패널 위에 분리되어 열립니다. 꺼짐(기본): 메인 창에 도킹되어 열립니다 |
| `피아노 롤에서 모노포닉 페인팅` | 켜짐: 페인트 도구가 새 노트 아래에 있던 노트를 대체하고, Shift를 누르면 그 위에 덧칠합니다. 꺼짐: 반대로 동작합니다 |
| `연결된 모듈 자동 선택` | 플러그인 창에 포커스를 두면 그 믹서 트랙이 선택됩니다. 기본값은 켜짐입니다 |
| `타이핑 키보드 우선순위를 기본으로 끄기` | 이후에 추가하는 플러그인에 적용됩니다. 기본값은 꺼짐입니다 |
| `최대 실행 취소 단계` | 25~1000 |
| `메시지 관리` | `힌트와 경고` 아래에 있습니다. 체크한 메시지는 표시됩니다. 체크를 풀면 그 질문을 건너뜁니다 |
| 백업 | 백업 사본을 저장하는 주기, 프로젝트당 보관 개수, `백업 폴더 열기` |
| `플러그인을 별도 프로세스에서 실행` | 플러그인이 충돌해도 LYNX SHARE는 멈추지 않습니다. 기본값은 꺼짐입니다 |
| `누락된 플러그인을 LYNX SHARE 대체 플러그인으로 교체` | 기본값은 켜짐입니다. 프로젝트가 설치되지 않은 서드파티 플러그인을 쓰면, 대체 플러그인이 있는 경우 LYNX SHARE의 대체 플러그인이 맞는 설정으로 로드됩니다. 프로젝트에는 원래 플러그인이 남아 있고, 설치하면 다시 그 플러그인을 씁니다 |
| `열린 플러그인 편집기 수 제한` | 플러그인 에디터 창이 최대 25개까지만 열려 있습니다. 기본값은 켜짐입니다 |
| `충돌 보고서` | 충돌이나 멈춤 뒤에 묻기(기본값), 항상 보내기, 보내지 않기 |
| `자동으로 업데이트 확인` | 시작할 때 업데이트를 확인하며, `지금 확인`도 있습니다 |

## 테마

`옵션 › 테마(색상, 배경)...`

| 설정 | 기능 |
|---|---|
| 테마 상자 | 프리셋을 고릅니다. `가져오기...`와 `내보내기...`는 `.lynxtheme` 파일을 읽고 쓰며, `프리셋 저장...`은 현재 테마를 보관하고, `기본값`는 초기 상태로 되돌립니다 |
| `강조 색상`, `배경`, `작업 공간` | 테마의 세 가지 색상입니다. 작업 공간 색상은 배경을 자동으로 따라갈 수 있습니다 |
| 작업 공간 이미지 | 창 뒤에 깔리는 PNG, JPEG, GIF이며, `이미지 맞춤`, `이미지 불투명도`, `어둡게`이 있습니다 |
| 시작 사운드 | 30초 이하의 내 사운드 또는 LYNX SHARE 자체 사운드 |

## LYNX extras

`옵션 › LYNX 추가 기능...`. LYNX SHARE만의 추가 기능을 한곳에 모았습니다. 모두 기본값은 꺼짐입니다. 각 스위치는 그 줄에 적힌 메뉴나 페이지에 있는 것과 같은 설정입니다.

| 설정 | 하는 일 |
|---|---|
| `마스터 옆에 라우드니스 미터(LYNX)` | 마스터의 단기 라우드니스와 통합 라우드니스(LUFS), 트루 피크를 Reset 버튼과 함께 보여 줍니다 |
| `사용 중인 인서트만 표시` | 아무것도 쓰지 않는 믹서 인서트를 숨깁니다 |
| `삭제된 인서트로 가는 링크를 회색으로 유지(LYNX)` | 인서트를 삭제해도 그 인서트로 들어가던 연결이 남아 있어, 다시 연결할 수 있습니다 |
| `믹서 그룹이 플레이리스트를 따름(LYNX)` | 믹서의 그룹이 Playlist의 트랙 그룹을 그대로 따릅니다 |
| `오토메이션 레인` | 오토메이션을 Playlist 트랙 아래의 레인에 둘 수 있습니다 |
| `눈금자: 곡 마디 (LYNX)` | 피아노 롤의 눈금자에 패턴이 재생되는 송 위치의 마디 번호가 표시됩니다 |
| `컨트롤 위에 마우스를 올리면 값을 마우스 옆에 표시 (LYNX)` | 값이 힌트 막대에만이 아니라 커서 옆에도 표시됩니다 |
| `루프 녹음 후 마지막 패스만 재생` | 이전 패스는 그 아래에 뮤트된 채로 남습니다 |
| `W로 선택한 장치의 창 표시 또는 숨기기` | Device 뷰용 키입니다 |
| `장치를 선택하면 믹서에서 해당 인서트가 선택됩니다` | 믹서가 Device 뷰에서 고른 장치를 따라갑니다 |
| `게임 컨트롤러 사용` | MIDI 페이지에 있는 것과 같은 스위치입니다 |

## 프로젝트

![프로젝트 페이지: 시간 설정, 그루브와 튜닝, 타임베이스, 플레이리스트 옵션](/assets/img/wiki/settings-project.webp)

`옵션 › 프로젝트 설정(템포, 박자)...`

| 설정 | 기능 |
|---|---|
| `시간 설정` | 시간 분할(마디당 박 수, 박당 스텝 수) 또는 전통적인 박자(분자와 분모) |
| `템포`, `마디당 박 수` | 프로젝트의 템포와 한 마디의 박 수 |
| `스윙`, `마스터 피치` | 전역 스윙의 양과 센트 단위의 마스터 피치 |
| `자동 크로스페이드` | 트랙에서 겹치는 오디오 클립이 겹친 구간에서 크로스페이드됩니다 |
| `컴프 크로스페이드` | 테이크를 컴핑할 때 쓰는 크로스페이드 길이(밀리초) |
| `클립의 잘린 노트 재생` | 패턴 클립보다 앞에서 시작하는 노트는 클립의 시작부터 재생됩니다 |
| `컷 그룹 빠른 디클릭` | 컷 그룹이 노트를 자를 때 더 빠르게 램프합니다 |
| `패닝 법칙` | 서큘러(중앙이 0 dB, 패닝한 쪽이 +3 dB) 또는 트라이앵귤러(더 큰 쪽이 레벨 유지). 믹서 인서트와 샘플러 채널에 적용됩니다 |

## 정보

`옵션 › 프로젝트 정보...`. 프로젝트의 제목, 작성자, 장르, 웹 링크, 코멘트와 `프로젝트를 열 때 이 페이지 표시`가 있습니다. 아래쪽에는 프로젝트를 만든 시점과 작업 시간이 표시됩니다.

## 알아 두기

- 타임베이스는 4분음표당 960틱으로 고정되어 있습니다. FL Studio의 프로젝트는 이 값으로 변환됩니다.
- 곡 중간의 박자 변경은 프로젝트 페이지에 없습니다. 플레이리스트 눈금자에 박자 마커를 추가하세요.
- `플러그인을 별도 프로세스에서 실행`는 그 뒤에 여는 플러그인에 적용됩니다. 나머지 플러그인도 옮기려면 프로젝트를 다시 여세요.
- Microsoft Store 버전에는 업데이트 설정이 없습니다. Store가 업데이트하기 때문입니다.
- 단축키는 설정 페이지가 아니라 `옵션 › 단축키 관리...`에 있습니다.
- 일부 스위치는 이 창이 아니라 메뉴에 있습니다. `녹음 중 저지연`은 녹음 버튼 옆의 녹음 옵션 메뉴와 믹서의 `디스크 녹음` 메뉴에 있습니다. `건반 스타일`은 피아노 롤의 View 메뉴에 있습니다.
- 플러그인 데이터베이스는 폴더입니다. 내 문서의 `LYNX` 폴더에 있는 `플러그인 데이터베이스`입니다. 파일 관리자에서 정리할 수 있습니다.
