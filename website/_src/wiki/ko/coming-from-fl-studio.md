LYNX SHARE는 익숙한 작업 방식을 그대로 유지합니다. 채널 랙, 패턴, 플레이리스트, 믹서가 있고 키도 같습니다. `.flp` 프로젝트를 바로 열고, 같은 형식으로 다시 쓸 수도 있습니다.

LYNX SHARE는 독립된 프로그램입니다. Image-Line과 제휴, 보증, 후원 관계가 없으며 Image-Line의 코드도 들어 있지 않습니다. FL Studio는 Image-Line Software의 등록 상표입니다.

## .flp 프로젝트 열기

1. `파일 › 열기...`(`Ctrl+O`)을 선택하고 `.flp`를 고릅니다.
2. LYNX SHARE가 프로젝트의 플러그인과 샘플을 찾은 뒤 프로젝트를 엽니다. 제목에 "(imported from FL Studio)"가 표시됩니다.
3. `도움말 › Last FL Studio import report`를 선택하면 근사치로 처리했거나, 빼 버렸거나, 찾지 못한 항목을 볼 수 있습니다.
4. `도움말 › 누락된 파일...`를 선택하면 없는 샘플과 플러그인을 볼 수 있습니다.
5. `파일 › 저장`를 선택합니다. `.lynx` 파일을 어디에 쓸지 묻습니다. `.flp` 자체는 절대 덮어쓰지 않습니다.

## 대응 관계

| FL Studio | LYNX SHARE |
|---|---|
| 플레이리스트, 채널 랙, 피아노 롤, 믹서 | 같은 이름이며 `F5`, `F6`, `F7`, `F9`입니다 |
| 플러그인 선택기 | `F8` |
| 브라우저 | `Alt+F8` |
| 패턴 / 송 모드 | `L` |
| 실행 취소 | `Ctrl+Z`는 실행 취소하고, 실행 취소 직후에는 다시 실행합니다. `Ctrl+Alt+Z`는 뒤로 실행 취소합니다 |
| 새 버전 저장 | `Ctrl+Alt+S` |
| 내보내기 | `Ctrl+R`, MP3는 `Ctrl+Shift+R`, MIDI는 `Ctrl+Shift+M` |
| 믹서 인서트, 센드, 사이드체인 | 같으며, 인서트마다 이펙트 슬롯이 10개입니다 |
| Fruity Wrapper | 서드파티 플러그인을 직접 호스팅합니다. [서드파티 플러그인](/wiki/plugins/)을 참고하세요 |
| 기본 제너레이터와 이펙트 | LYNX SHARE가 다시 만든 엔진으로 재생합니다. 아래를 참고하세요 |
| `.flp` 프로젝트 파일 | `.lynx` 프로젝트 파일 |

`도움말 › 단축키`에 모든 키가 나와 있습니다.

## 가져오는 항목

- 채널, 샘플, 패턴, 슬라이드 노트와 포르타 노트, 모든 어레인지먼트, 마커, 박자 변경, 오토메이션, 컨트롤러 링크.
- 믹서: 라우팅, 레벨, 사이드체인, 트랙 EQ, 저장된 설정이 있는 기본 이펙트.
- Fruity Wrapper 안의 서드파티 VST3, VST2, CLAP 플러그인: 컴퓨터에 설치된 같은 플러그인으로 대체되며 저장된 상태도 그대로 가져옵니다.

## FL Studio 기본 플러그인

FL Studio 자체의 제너레이터와 이펙트는 불러오지 않습니다. LYNX SHARE가 다시 만든 엔진으로 재생하며, 엔진마다 품질 등급이 있습니다.

| 등급 | 의미 |
|---|---|
| Exact | 테스트한 모든 상태에서 원본과 비트까지 동일합니다 |
| Near-exact | 대부분의 상태에서 비트까지 동일하고, 나머지는 약 -100 dB 아래의 차이만 있습니다 |
| Close | 같은 알고리즘이며, 테스트한 거의 모든 상태에서 원본과 -60 dB 이내입니다 |
| Approximate | 저장된 설정을 LYNX SHARE 내장 신스나 이펙트에 대응시킵니다 |
| Placeholder | 상태는 보존하고, 플러그인은 소리가 나지 않거나 오디오를 그대로 통과시킵니다 |

모든 엔진의 등급과 아직 빠진 부분은 [PLUGINS.md](https://github.com/Ka1-S/LYNX-SHARE/blob/main/docs/PLUGINS.md)에 있습니다. [내장 악기와 이펙트](/wiki/built-in/)도 참고하세요.

## 직접 설치한 FL Studio가 필요한 경우

`.flp`는 FL Studio가 없어도 열립니다. 같은 컴퓨터에 설치되어 있으면 두 가지가 더해집니다.

- FL Studio의 공장 샘플과 플러그인 데이터베이스가 있으면 스캔 없이도 샘플과 플러그인을 찾습니다.
- 일부 엔진에 필요한 내장 웨이브, 샘플, 임펄스, 테이블(FL Keys, Soundgoodizer, Maximus와 PLUGINS.md에서 칼 표시가 붙은 나머지)입니다. 이것들은 실행할 때 설치된 곳에서 읽으며 LYNX SHARE에 포함되어 있지 않습니다.

Linux에서는 Wine으로 설치한 Windows용 FL Studio를 찾습니다. macOS에서는 앱 번들을 찾지만 테스트하지 않았습니다.

## .flp로 다시 내보내기

1. `파일 › 내보내기 › FL Studio 프로젝트...`를 선택합니다.
2. `FL Studio 프로젝트 (.flp)` 또는 `압축 루프 패키지 (.zip, 모든 샘플 포함)`를 고릅니다.
3. FL Studio에 없는 것을 어떻게 처리할지 고릅니다. 오디오로 렌더링하거나(소리는 같음), 가장 가까운 FL 플러그인을 쓸 수 있습니다(편집은 계속 가능하지만 소리가 다를 수 있고, LYNX 전용 악기는 빠집니다).

파일은 FL Studio 2026 프로젝트입니다. 샘플러, 오디오 클립, FL 자체의 제너레이터와 이펙트, 서드파티 플러그인(Fruity Wrapper 안), 패턴, 플레이리스트, 믹서, 오토메이션이 설정과 함께 넘어갑니다. 보고서에 정확히 넘어간 것, 렌더링한 것, 대체한 것, 뺀 것이 정리됩니다.

## FL Studio Mobile (.flm)

`파일 › 열기...`은 `.flm` 프로젝트도 엽니다. 가져오기는 일부만 됩니다.

- 가져오는 것: 템포, 박자, FLM 채널마다 믹서 인서트 하나, 레인마다 플레이리스트 트랙 하나, 패턴(루프를 한 번 돌 때마다 클립 하나), 오프셋과 피치가 있는 오디오 클립, 드럼 키트, DW Sampler와 `.dwp` 프로그램과 Slicer(FLM 자체 엔진으로), MiniSynth, Transistor Bass, 3x Osc, GMSynth, SuperSaw 악기, FLM의 이펙트(Pocket 이펙트로), 레벨, 팬, 뮤트, 솔로, 피치 벤드, 센드, 악기 파라미터의 오토메이션, 코드 세트와 키 보관함.
- 가져오지 않는 것: FLM의 다른 악기. 내장 신스로 재생됩니다.
- 샘플은 `.flm` 옆과 FL Studio의 FLM 리소스 사본에서 찾습니다. 찾지 못한 `.dwp`는 대역 사운드로 재생됩니다.

## 알아 두기

- FLEX 팩은 암호화되어 있어 열지 않습니다. FLEX 채널에는 프리셋 이름으로 고른 신스 패치가 적용됩니다.
- 모듈레이터는 `.flp`로 내보낼 때 빠지며, 내보내기 보고서에도 그렇게 적힙니다.
- 가져오기 보고서에는 내장 신스로 근사한 것, 대응하는 것이 없던 것, 찾았거나 설치되지 않은 플러그인, 빠졌거나 일부만 재현한 이펙트, 없는 샘플의 개수가 나옵니다.
- 설치되지 않은 서드파티 이펙트는 역할이 같은 LYNX SHARE 이펙트로 대체됩니다. 원본은 프로젝트에 남아 있습니다.
