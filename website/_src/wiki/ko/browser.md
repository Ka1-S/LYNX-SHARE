브라우저에는 샘플 폴더, 현재 프로젝트의 내용, LYNX SHARE가 아는 플러그인이 나열됩니다. `Alt+F8` 키로 표시하거나 숨깁니다. `F8` 키만 누르면 플러그인 선택기가 열립니다. 모든 악기와 이펙트를 보여 주는 별도의 전체 화면 보기입니다.

## 샘플을 프로젝트에 불러오기

1. `Alt+F8` 키를 눌러 브라우저를 표시합니다.
2. `전체` 탭에서 폴더를 클릭해 엽니다.
3. 오디오 파일을 클릭하면 소리를 들을 수 있습니다. `Up`과 `Down` 키로 파일을 차례로 넘기며 하나씩 미리 듣습니다.
4. 파일을 더블 클릭하면 샘플이 담긴 새 채널이 [채널 랙](/wiki/channel-rack/)에 생깁니다.
5. 아니면 파일을 [플레이리스트](/wiki/playlist/)로 끌어다 놓아 오디오 클립을 만듭니다.

## 탭

| 탭 | 보여 주는 것 |
|---|---|
| 전체 | 현재 프로젝트, 플러그인 데이터베이스, 모든 샘플 폴더 |
| 프로젝트 | 현재 프로젝트가 쓰는 것만: 패턴, 이펙트, 제너레이터, 오토메이션, 오디오 파일 |
| 별표 | 별표를 붙인 파일과 폴더(우클릭한 다음 `별표`) |

## 탐색과 미리 듣기

- 폴더를 클릭하면 열리거나 닫힙니다. 우클릭하면 메뉴가 나옵니다(모두 접기, 파일 관리자에서 보기).
- 오디오 파일을 클릭하면 소리가 납니다. 목록 아래의 미리 듣기 막대에 파형이 표시됩니다. 막대를 클릭하면 파일을 다시 들을 수 있고, 막대에서 끌면 파일을 끄는 것과 같습니다.
- 미리 듣기 막대 위의 패널에는 선택한 파일의 날짜, 크기, 경로가 표시됩니다.

## 샘플 사용하기

| 동작 | 결과 |
|---|---|
| 더블 클릭 | 샘플이 담긴 새 채널 |
| 채널 랙으로 끌기 | 새 채널. 행에 놓으면 그 행에 불러옴 |
| 플레이리스트로 끌기 | 오디오 클립 |
| `Enter` | 선택한 채널에 파일을 불러옴 |
| `Shift+Up` / `Shift+Down` | 이전 또는 다음 파일로 넘어가 선택한 채널에 불러옴 |

마지막 방법을 쓰면 패턴이 재생되는 동안 그 자리에서 여러 샘플을 바꿔 가며 들어 볼 수 있습니다.

## 그 밖의 파일 형식

- **프로젝트**: 더블 클릭하면 열립니다.
- **MIDI 파일**: 더블 클릭하면 프로젝트로 열립니다.
- **SoundFont 또는 SFZ**: 클릭하면 미리 듣고, 더블 클릭하면 LYNX Soundfont 채널을 만듭니다(선택한 채널이 있으면 거기에 불러옵니다).
- **믹서 프리셋**: 더블 클릭하면 선택한 믹서 인서트에 불러오고, 인서트로 끌어다 놓아도 됩니다.
- **이펙트 프리셋**: 믹서 인서트로 끌어다 놓습니다.

## 플러그인 데이터베이스

플러그인 데이터베이스 항목에는 LYNX SHARE의 내장 악기와 이펙트, 설치된 플러그인이 나열됩니다. `Shift+F8` 키를 누르면 바로 이동합니다.

- 악기를 더블 클릭하면 새 채널로 추가되고, 채널 랙으로 끌어다 놓아도 됩니다.
- 이펙트를 더블 클릭하면 선택한 [믹서](/wiki/mixer/) 인서트에 추가되고, 인서트나 이펙트 슬롯으로 끌어다 놓아도 됩니다.
- `F2` 키는 선택한 플러그인의 이름을 바꿉니다.
- 플러그인을 우클릭하고 `폴더로 이동` 항목을 선택하면 플러그인을 폴더별로 정리할 수 있습니다. 그러면 믹서의 슬롯 메뉴와 채널 랙의 추가 메뉴에 최상위 폴더가 하나씩 나타납니다.

## 프로젝트 탭

여기에 나열된 패턴은 클릭하면 현재 패턴이 되고, 더블 클릭하면 [피아노 롤](/wiki/piano-roll/)에서 열리며, 플레이리스트로 끌어다 놓을 수도 있습니다. 현재 프로젝트 섹션에는 실행 취소 기록도 나옵니다. 단계를 클릭하면 그 시점으로 돌아갑니다.

## 검색

`Ctrl+F` 키를 누르면 커서가 검색 상자로 이동합니다. 선택한 폴더(또는 모든 폴더)와 그 하위 폴더를 검색합니다. 프로젝트 탭에서는 프로젝트의 항목을 검색합니다.

모든 단어가 일치해야 합니다. 검색 상자에서는 `OR`, 단어를 제외하는 빼기 기호, `*` 와일드카드도 쓸 수 있습니다.

```
kick -loop
snare OR clap
hat*.wav
```

폴더는 백그라운드에서 색인됩니다. 브라우저 메뉴의 `검색 색인 새로 고침` 항목을 선택하면 색인을 다시 만듭니다.

## 나만의 폴더

브라우저의 폴더 목록에서 `폴더 추가` 항목을 선택하면 샘플, 프로젝트, SoundFont가 들어 있는 폴더를 추가할 수 있습니다. 검색 폴더는 `옵션 › 파일 설정(검색 폴더)` 메뉴에 있습니다.

## 키

방향키, `Enter`, `F2` 키는 브라우저에 포커스가 있어야 동작합니다.

| 명령 | 키 | 동작 |
|---|---|---|
| 브라우저 표시 | `Alt+F8` | 브라우저를 표시하거나 숨깁니다 |
| 플러그인 선택기 | `F8` | 전체 화면 플러그인 선택기를 엽니다 |
| 플러그인 데이터베이스 | `Shift+F8` | 플러그인 데이터베이스 항목으로 이동합니다 |
| 검색 | `Ctrl+F` | 커서를 검색 상자에 둡니다 |
| 넘기며 미리 듣기 | `Up` / `Down` | 이전 또는 다음 파일을 선택하고 재생합니다 |
| 폴더 닫기 | `Left` | 폴더를 닫거나 상위 폴더로 이동합니다 |
| 폴더 열기 | `Right` | 폴더를 엽니다 |
| 불러오기 | `Enter` | 선택한 채널에 파일을 불러옵니다 |
| 넘기며 불러오기 | `Shift+Up` / `Shift+Down` | 이전 또는 다음 파일로 넘어가 선택한 채널에 불러옵니다 |
| 플러그인 이름 변경 | `F2` | 플러그인 데이터베이스에서 선택한 플러그인의 이름을 바꿉니다 |

## 알아 두면 좋은 점

- 목록에서 폴더를 제거해도 디스크에서 삭제되지는 않습니다.
- `F8`과 `Alt+F8`은 다릅니다. `F8`은 플러그인 선택기이고, `Alt+F8`은 브라우저입니다.
- 검색 결과는 백그라운드에서 만든 색인에서 나옵니다. 브라우저 메뉴의 `검색 색인 새로 고침` 항목을 선택하면 색인을 다시 만듭니다.
- `Enter`는 선택한 채널에 파일을 불러옵니다. 더블 클릭하면 새 채널이 만들어집니다.
