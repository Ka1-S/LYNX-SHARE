LYNX SHARE는 패턴 레이아웃으로 시작합니다. 채널 랙, 패턴, 플레이리스트로 이루어진 구성입니다. 클립 실행 레이아웃은 선택 사항이며, 플레이리스트 옆에 장면이 있는 클립 그리드를 추가합니다. LYNX SHARE는 `.als` 세트를 읽고 씁니다. Ableton과는 제휴 관계가 없습니다.

Bitwig Studio 사용자도 이 페이지를 참고하세요. 클립 그리드는 같은 방식으로 작동하고, Bitwig의 DAWproject 파일(`.dawproject`)은 `파일 › 열기...`으로 열리며 `파일 › 내보내기 › DAWproject (.dawproject)...`로 저장됩니다.

## 첫 단계

1. **레이아웃 고르기.** LYNX SHARE를 처음 시작하면 환영 카드가 어디서 넘어오는지 묻습니다. `Ableton Live 또는 Bitwig`를 클릭하면 클립 실행 레이아웃이 열립니다. 나중에 `보기 › 레이아웃 스타일 › 클립 실행 레이아웃` 메뉴로 언제든 전환할 수 있습니다.
2. **슬롯 채우기.** 브라우저에서 샘플이나 패턴을 슬롯으로 끌어다 놓거나, 빈 슬롯을 우클릭하고 `여기에 패턴 넣기`를 선택하세요.
3. **실행하기.** 클립 왼쪽의 삼각형을 클릭하거나, `장면` 열에서 장면의 삼각형을 클릭해 그 행 전체를 실행합니다. 아니면 가지고 있는 `.als` 세트(아래 참고)를 여세요.

Live와 다른 점:

- 플레이리스트가 어레인지먼트이고, 플레이리스트 트랙이 그리드의 열입니다. 클립을 실행한 트랙은 `플레이리스트로 돌아가기`를 누를 때까지 그리드에 남습니다.
- 그리드 밖에서는 키가 FL Studio를 따릅니다. `Ctrl+Z`는 한 단계를 실행 취소하고, 한 번 더 누르면 다시 실행합니다.
- Live 자체 디바이스는 일부만 변환됩니다(알아 두면 좋은 점 참고). 서드파티 플러그인은 상태와 함께 넘어옵니다.
- 채널 랙과 패턴으로 작업하는 FL Studio 방식의 패턴 레이아웃도 같은 프로젝트에서 쓸 수 있습니다.

## Live 세트 열기

1. `파일 › 열기...` (`Ctrl+O`) 메뉴를 선택하고 `.als` 파일을 고릅니다. Live 11과 Live 12에서 저장한 세트를 읽을 수 있습니다.
2. 클립 그리드로 작업하려면 `보기 › 레이아웃 스타일 › 클립 실행 레이아웃` 메뉴를 선택합니다. 세트의 세션 클립과 장면이 여기에 들어옵니다.
3. 플레이리스트 제목 표시줄의 `Grid / Both / Song` 스위치로 그리드, 플레이리스트, 또는 둘 다 표시합니다.
4. `파일 › 저장` 메뉴를 선택합니다. `.lynx` 파일을 어디에 쓸지 묻습니다. `.als` 파일은 바뀌지 않습니다.

`보기 › 레이아웃 스타일 › 패턴 레이아웃 (기본)` 메뉴를 선택하면 되돌아갑니다. 같은 선택이 `옵션 › 일반 설정...` 메뉴에도 있습니다. 어느 레이아웃에서든 패턴과 채널 랙을 계속 쓸 수 있습니다.

## 무엇이 무엇에 대응하나

| Live | LYNX SHARE |
|---|---|
| 세션 뷰 | 클립 실행 레이아웃의 클립 그리드 |
| 어레인지먼트 뷰 | 플레이리스트 |
| 트랙 | 플레이리스트 트랙. 클립 그리드에서는 열에 해당합니다 |
| 장면 | 장면. 클립 그리드의 행이며, 장면을 실행할 때 템포를 지정할 수 있습니다 |
| 실행 퀀타이즈 | `전역`, `없음`, 8마디에서 1마디까지, 또는 1/2에서 1/32까지의 음표 길이. 원하면 클립마다 지정 |
| 실행 모드 | `트리거`, `게이트`, `토글`, `반복` |
| 팔로 액션 | 액션 A와 액션 B. 각각 확률을 지정 |
| 클립 정지 버튼 | 빈 슬롯에 정지 버튼을 둘 수 있습니다 |
| 어레인지먼트로 돌아가기 | `플레이리스트로 돌아가기` |
| 워프 모드 | `박`의 `톤`, `텍스처`, `컴플렉스`, `채널 설정 › 타임 스트레치` |
| Simpler, Sampler, 드럼 랙 | LYNX SHARE 샘플러 |
| `.als` 세트 | `.lynx` 프로젝트 파일 |

## 클립 그리드

슬롯 하나에는 패턴 클립이나 오디오 클립이 들어갑니다.

- 트랙은 한 번에 클립 하나만 재생합니다. 실행한 클립이 재생 중인 클립을 대체합니다.
- 실행하면 실행 퀀타이즈의 다음 스텝까지 기다립니다.
- `레가토`는 새 클립을 대체된 클립이 도달해 있던 위치에서 시작합니다. `루프`는 클립마다 지정합니다.
- 장면은 삽입, 삭제, 이름 변경을 할 수 있습니다.
- 클립을 실행한 트랙은 `플레이리스트로 돌아가기` 항목을 누를 때까지 플레이리스트에서 소리가 나지 않습니다. 옵션을 켜면 트랜스포트가 멈출 때 트랙을 돌려줍니다.

팔로 액션은 클립이 정해진 마디 수나 횟수만큼 재생된 뒤에 실행됩니다. 액션은 `액션 없음`, `정지`, `다시 재생`, `이전`, `다음`, `처음`, `마지막`, `아무거나`, `기타`입니다. 스위치 하나로 그리드 전체의 팔로 액션을 켜고 끕니다.

## .als에서 가져오는 것

- MIDI, 오디오, 그룹, 리턴 트랙, 템포, 박자, 로케이터, 루프, 믹서 설정(볼륨, 팬, 뮤트, 솔로, 센드)과 그 오토메이션.
- 같은 플러그인이 설치되어 있으면 VST2와 VST3 플러그인과 그 상태. [서드파티 플러그인](/wiki/plugins/)을 참고하세요.
- 세션 클립과 장면은 실행 모드, 퀀타이즈, 레가토, 루프, 팔로 액션, 정지 버튼과 함께 클립 그리드로 들어옵니다. 장면마다 한 섹션씩 플레이리스트에 배치하려면 `Live 세트의 세션 클립` 메뉴의 `옵션 › 일반 설정...` 옵션을 바꿉니다.
- 워프 마커.

## .als로 내보내기

1. `파일 › 내보내기 › Ableton Live 세트 (.als)...` 메뉴를 선택합니다.
2. `저장 대상` 항목에서 `Live 12` 또는 `Live 11 (Live 12에서도 열림)` 옵션을 고릅니다.
3. `샘플` 항목에서 샘플을 세트의 프로젝트 폴더로 복사할지, 현재 위치를 그대로 참조할지 고릅니다.
4. 폴더를 선택합니다. 세트는 `<name> Project/<name>.als`로 저장됩니다.

| 기록되는 것 | 기록되지 않는 것 |
|---|---|
| 채널마다 MIDI 트랙 하나와 MIDI 클립으로 된 노트 | LYNX SHARE 자체 악기와 이펙트. 단, Helix는 Wavetable이 됩니다. 해당 트랙과 노트는 유지됩니다 |
| 스트레치, 트랜스포즈, 게인, 페이드, 워프 모드가 있는 오디오 트랙 | 이펙트 파라미터의 오토메이션 |
| 그룹, 리턴, 센드 | 인서트에서 인서트로 가는 라우팅 |
| 상태를 포함한 VST2와 VST3 플러그인 | |
| 마커, 볼륨, 팬, 템포 오토메이션 | |
| 세션 클립과 장면으로 변환한 클립 그리드, 랙과 Drum Rack | |

내보낸 뒤에는 제외된 항목이 담긴 보고서가 나옵니다.

## 알아 두면 좋은 점

- Live 자체 디바이스 중 많은 수는 설정과 오토메이션과 함께 LYNX SHARE 자체의 것으로 들어옵니다. EQ Eight, EQ Three, Channel EQ, Compressor, Glue Compressor, Multiband Dynamics, Limiter, Gate, Utility, Reverb, Hybrid Reverb, Delay, Echo, Grain Delay, Auto Filter, Saturator, Overdrive, Roar, Erosion, Vinyl Distortion, Corpus, Chorus-Ensemble, Redux, Auto Pan, Drum Buss, Spectral Time, Spectral Resonator, Looper, Simpler, Sampler, Drift, Operator, Wavetable, Meld입니다. 나머지는 빠지고 가져오기 보고서에 나열됩니다.
- Instrument Rack과 Audio Effect Rack은 체인, 존, 매크로와 함께 들어오고, Drum Rack은 LYNX SHARE의 Drum Rack이 됩니다. Live의 Arpeggiator는 채널의 아르페지에이터가 됩니다. Pitch, Velocity, Chord, Note Length와 MIDI Effect Rack은 노트에 기록됩니다.
- 제외된 항목은 가져오기 보고서에 나열됩니다.
- 장치 보기에서 랙은 체인의 장치를 인라인으로 보여 주며, Map 모드(랙의 `Map` 버튼)로 Live처럼 장치 파라미터를 매크로에 할당할 수 있습니다.
- 세션 믹서에는 Live의 솔로 / 큐 스위치가 있고, 헤드폰용 `Cue Out`과 `큐 볼륨`이 있습니다.
- Live는 내보낸 세트에서 겹치는 오디오 클립을 잘라 냅니다.
- Live 세트의 워프 마커는 가져올 때 유지되고, 내보낼 때 다시 기록됩니다.
