LYNX SHARE 밖으로 나가는 모든 것은 `파일 › 내보내기`를 거칩니다. 오디오 형식(WAV, MP3, OGG, FLAC)은 내보내기 창 하나를 함께 씁니다. MIDI, FL Studio 프로젝트, Ableton Live 세트, 압축 프로젝트는 같은 메뉴에 각자 항목이 있습니다.

## 곡을 WAV로 내보내기

1. `파일 › 내보내기 › Wave 파일...`을 선택합니다.
2. `범위`는 `송(플레이리스트)`, `파일`는 `파일 하나(믹스)`로 둡니다.
3. `비트 심도`를 고릅니다. 16비트, 24비트, 32비트(부동소수점) 중에서 선택합니다.
4. 마지막 마디 뒤에도 리버브와 릴리스가 울리도록 `테일`을 `나머지 남기기`로 설정합니다.
5. `내보내기...`를 클릭하고 이름과 폴더를 정한 뒤 렌더링이 끝나기를 기다립니다.
6. 끝나면 LYNX SHARE가 파일이 저장된 위치와 피크 레벨을 알려 줍니다.

`Ctrl+R`은 마지막으로 내보낸 형식으로 창을 엽니다. `Ctrl+Shift+R`은 MP3로 엽니다.

## 렌더링 대상

| 설정 | 기능 |
|---|---|
| `범위` | `송(플레이리스트)`, `현재 패턴`, `플레이리스트 선택 영역` 중에서 고릅니다 |
| `재생` | 파일에서 범위를 몇 번 재생할지 정합니다. `1회`부터 16번까지입니다 |
| `테일` | `나머지 자르기`는 정확히 끝에서 멈춥니다. `나머지 남기기`는 소리가 끝까지 울리게 합니다. `나머지 감싸기`는 테일을 처음에 섞어 넣으며, 루프에 씁니다 |
| `최대 테일` | 3초, 6초, 12초, 30초. 소리가 먼저 사라지면 테일도 거기서 멈춥니다 |
| `파일` | 파일 하나, 또는 스템(아래 참고) |

## 출력 형식

버튼 네 개로 형식을 고릅니다. `함께 저장`는 같은 렌더링으로 다른 형식도 같은 이름으로 씁니다.

| 형식 | 옵션 |
|---|---|
| WAV | `비트 심도`: 16비트, 24비트, 32비트(부동소수점). `디더`: `끔`, `TPDF`, `TPDF + 노이즈 셰이핑` |
| MP3 | `비트레이트`, 고정 비트레이트 |
| OGG | 비트레이트 |
| FLAC | `비트 심도`, `0(가장 빠름)`부터 `8(가장 작음)`까지의 `압축`, `디더`. 어느 단계든 무손실입니다 |

`샘플 레이트`와 `채널`는 모든 형식에 적용됩니다. `채널`는 `스테레오`, `모노(양쪽 믹스)`, `모노(왼쪽만)`, `모노(오른쪽만)` 중에서 고릅니다.

## 믹스 옵션

| 설정 | 기능 |
|---|---|
| `노멀라이즈(피크를 0 dB로)` | 가장 큰 피크가 풀 스케일에 닿도록 파일 전체를 키우거나 줄입니다 |
| `마스터 이펙트` | 끄면 마스터 인서트의 이펙트가 바이패스됩니다 |
| `인서트 이펙트` | 끄면 다른 인서트의 이펙트가 바이패스됩니다 |
| `모든 플러그인 HQ` | 플러그인이 렌더링 품질을 사용합니다. 끄면 내보내기에도 재생 품질을 씁니다 |
| `플러그인 워밍업` | 내보내기를 시작하기 전에 서드파티 플러그인이 잠깐의 무음을 처리합니다 |
| `최대 폴리포니 해제` | 채널의 보이스 제한을 풀어서 잘리는 노트가 없게 합니다 |
| `지연 보정 무음 트림` | 플러그인 레이턴시 보정 때문에 시작 부분에 생기는 무음을 제거합니다 |
| `템포 정보`, `루프 마커`, `플레이리스트 마커` | WAV 전용: 템포, 루프, 플레이리스트의 마커를 파일에 저장합니다 |
| `완료되면 파일 보기` | 완료되면 파일 관리자에서 결과를 보여 줍니다 |

## 스템과 트랙

![믹서 인서트마다 파일 하나, 모두 아홉 개 파일로 설정된 FLAC 내보내기 창](/assets/img/wiki/export-flac-stems.webp)

`파일`에는 스템 모드가 세 가지 있습니다.

- `믹서 인서트마다 하나(스템)`: 소리가 나는 인서트마다 파일 하나.
- `채널마다 하나(스템)`: 재생되는 채널마다 파일 하나.
- `채널마다 하나, 악기만 (센드·버스 제외)`.

`전체 믹스도 포함`를 체크하면 스템과 함께 믹스도 받습니다. 아래쪽 줄에 만들어질 파일 수가 표시됩니다.

`파일 › 내보내기 › 모든 Playlist 트랙`와 `모든 Playlist 트랙 그룹`는 플레이리스트 트랙마다, 또는 그룹마다 파일 하나를 씁니다. 믹서 메뉴의 `디스크 녹음 › 녹음 대기 트랙을 WAV 파일로 렌더링...`(`Alt+R`)는 녹음 대기 중인 인서트만 대상으로 내보내기 창을 엽니다.

## 내보내기 메뉴의 다른 항목

| 명령 | 키 | 기능 |
|---|---|---|
| `MIDI 파일...` | `Ctrl+Shift+M` | 노트를 표준 MIDI 파일(`.mid`)로 씁니다 |
| `마스터링...` | `Ctrl+Alt+M` | 프로젝트를 렌더링하고 LUFS 라우드니스 목표에 맞춰 마스터링합니다. 컴퓨터 안에서 처리됩니다 |
| `샘플 포함 프로젝트(.zip)...` | 없음 | 프로젝트와 샘플을 압축 파일 하나로 만듭니다 |
| `FL Studio 프로젝트...` | 없음 | `.flp`, 또는 모든 샘플이 든 압축 루프 패키지 |
| `Ableton Live 세트 (.als)...` | 없음 | Live 12 또는 Live 11용 세트 |
| `프로젝트 본...` | 없음 | 채널과 이펙트 프리셋, 스코어를 폴더에 씁니다 |

## FL Studio와 Ableton Live로 내보내기

`.flp`는 FL Studio 2026 프로젝트입니다. 샘플러, 오디오 클립, FL Studio 자체의 제너레이터와 이펙트, 서드파티 플러그인, 패턴, 플레이리스트, 믹서, 오토메이션이 설정과 함께 넘어갑니다. FL Studio에 없는 것은 `오디오로 렌더링 (같은 소리)`와 `가장 가까운 FL 플러그인 사용 (편집 가능, 소리가 다를 수 있음)` 중에서 고릅니다. 두 번째를 고르면 LYNX 전용 악기는 빠집니다. 모듈레이터는 항상 빠집니다. 보고서에 렌더링한 것, 대체한 것, 뺀 것이 정리됩니다. 자세한 내용은 [FL Studio에서 넘어오기](/wiki/coming-from-fl-studio/)에 있습니다.

`.als`에는 채널마다 MIDI 트랙, 오디오 트랙, 그룹, 리턴, 센드, 랙, Drum Rack, 상태가 있는 VST2와 VST3 플러그인, 마커, 볼륨, 팬, 템포 오토메이션이 들어갑니다. LYNX SHARE 자체의 악기와 이펙트는 변환되지 않지만 트랙과 노트는 유지됩니다. 이펙트 파라미터의 오토메이션과 인서트 간 라우트는 빠집니다. 자세한 내용은 [Ableton Live에서 넘어오기](/wiki/coming-from-ableton/)에 있습니다.

## 알아 두기

- MP3에서는 `디더`가 회색으로 비활성화되고, WAV 외의 모든 형식에서는 템포와 마커 옵션이 회색으로 비활성화됩니다.
- `플레이리스트 선택 영역`인데 플레이리스트에 선택 영역이 없으면 곡 전체를 렌더링합니다. 창이 경고를 표시합니다.
- 마스터 인서트가 뮤트되어 있으면 파일이 무음이 된다고 창이 경고합니다.
- `이 믹스로 비디오도 쓰기`는 프로젝트에 비디오 트랙이 있을 때만 나타나며 FFmpeg이 필요합니다.
- `하드웨어를 거쳐 실시간으로 렌더링`은 프로젝트에 활성화된 하드웨어 인서트가 있을 때만 나타납니다. 이 내보내기는 곡 길이만큼 걸립니다.
- 인서트를 오디오 클립으로 바운스하는 오디오로 렌더링은, 이 버전에서는 대체하는 인서트보다 약 5 dB 크게 재생됩니다.
