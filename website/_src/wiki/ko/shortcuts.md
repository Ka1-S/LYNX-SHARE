0.1.25 알파의 기본 키입니다. `도움말 › 단축키` (`F1`) 메뉴는 앱 안에서 단축키 목록을 보여 줍니다. `옵션 › 단축키 관리...` 메뉴는 그림의 편집기를 열며, 여기서 키를 바꿉니다.

> macOS에서는 앱이 Mac 이름으로 키를 표시합니다. Ctrl은 ⌘로, Alt는 ⌥로 표시됩니다.

## 단축키 바꾸기

1. `옵션 › 단축키 관리...` 메뉴를 선택합니다.
2. 검색 상자에 동작이나 `Ctrl+L` 같은 키를 입력합니다. 옆의 목록으로 검색을 한 곳으로 제한할 수 있고, `변경된 항목만` 옵션은 바꾼 항목만 보여 줍니다.
3. 동작을 클릭합니다.
4. `변경` 버튼을 클릭하면 키가 교체되고, `단축키 추가` 버튼을 클릭하면 두 번째 키가 추가됩니다. 그런 다음 새 키를 누릅니다. `Esc` 키로 취소합니다.
5. 같은 위치에서 이미 쓰는 키라면 메시지가 다른 동작의 이름을 알려 주고 키를 옮길 수 있게 합니다.

`제거` 버튼은 동작의 키를 지웁니다. `기본값으로 초기화` 버튼은 동작 하나를, `모두 초기화...` 버튼은 모든 동작을 기본값으로 되돌립니다. 변경 사항은 설정 폴더의 `keys.json`에 저장됩니다(Windows는 `%APPDATA%\LYNX`, macOS는 `~/Library/Application Support/LYNX`, Linux는 `~/.config/LYNX`). `keys.json 열기` 버튼은 그 파일을 엽니다.

## 트랜스포트와 녹음

| 키 | 동작 |
|---|---|
| `Space` | 재생하거나, 정지하고 재생을 시작한 위치로 돌아갑니다 |
| `Ctrl+Space` | 재생 또는 일시 정지 |
| `Shift+Space` | 재생하거나, 곡 또는 패턴의 시작에서 정지합니다 |
| `L` | 패턴 모드와 송 모드를 전환합니다 |
| `R` | 녹음 켜기/끄기 |
| `Shift+R` | 지금 오디오 녹음: 선택한 인서트를 녹음 대기시키고 녹음합니다 |
| `Ctrl+M` | 메트로놈 켜기/끄기 |
| `Ctrl+P` | 녹음 전 카운트인 켜기/끄기 |
| `Ctrl+I` | 첫 노트까지 녹음 대기 켜기/끄기 |
| `Ctrl+B` | 녹음한 노트 블렌드 켜기/끄기 |
| `Ctrl+E` | 스텝 입력 켜기/끄기 |
| `Ctrl+H` | 소리 정지(모든 노트 끄기) |
| `Ctrl+T` | 타이핑 키보드 피아노 켜기/끄기 |
| `Alt+Numpad *` / `Alt+Numpad /` | 다음 또는 이전 송 마커로 이동합니다 |

이 키 중 일부는 포커스가 있는 에디터 안에서는 다른 일을 합니다. 피아노 롤에서 `Ctrl+M`은 MIDI 파일을 가져오고 `Ctrl+B`는 복제합니다. 플레이리스트에서 `Ctrl+P`는 퍼포먼스 모드입니다.

## 알아 두면 좋은 점

- 타이핑 키보드 피아노가 켜져 있는 동안에는 그 키가 노트를 연주하고 대부분의 한 글자 단축키는 일시 중지됩니다(`L`은 계속 동작합니다). `Ctrl+T` 키로 끕니다.
- 단축키는 어디서나 동작하거나 한 창에서만 동작합니다. 창에 속한 단축키는 그 창에 포커스가 있는 동안, 어디서나 동작하는 같은 키보다 우선합니다.
- 빠른 추가 팔레트처럼 기본 키가 없는 동작도 있습니다. 편집기에서 키를 지정하세요.
