0.1.25의 `보기 › 레이아웃 스타일`에는 `패턴 워크플로 (기본)`와 `클립 실행 워크플로` 두 항목이 있습니다. 같은 선택이 `옵션 › 일반 설정`의 워크플로 항목에도 있습니다. 선택한 내용은 프로그램을 닫아도 유지됩니다.

패턴 워크플로는 채널 랙, 패턴, 플레이리스트로 작업하는 방식입니다. 클립 실행 워크플로는 플레이리스트 옆에 씬이 있는 클립 그리드를 더합니다. 패턴과 채널 랙도 그대로 쓸 수 있습니다.

## 그리드에서 클립 실행하기

1. `보기 › 레이아웃 스타일 › 클립 실행 워크플로`를 선택합니다. 플레이리스트 옆에 클립 그리드가 나타납니다.
2. 빈 슬롯을 우클릭하고 `여기에 패턴 넣기`를 선택한 뒤 패턴을 고릅니다. 빈 슬롯을 더블 클릭하면 현재 패턴이 들어갑니다.
3. 클립 왼쪽의 삼각형을 클릭하면 실행됩니다. 트랜스포트가 멈춰 있으면 재생이 시작됩니다.
4. `장면` 열에서 씬의 삼각형을 클릭하면 그 행의 모든 클립이 실행됩니다.
5. `모든 클립 정지`를 클릭하면 모두 멈춥니다.
6. `플레이리스트로 돌아가기`를 클릭하면 트랙이 다시 플레이리스트 클립을 재생합니다.

## 화면에서 달라지는 점

- 클립 그리드가 플레이리스트 옆에 표시됩니다. 플레이리스트 트랙이 열, 씬이 행입니다.
- 플레이리스트 제목 표시줄에 `둘 다`, `그리드`, `송` 스위치가 생깁니다. `그리드`는 그리드만, `송`은 플레이리스트만 보여 줍니다.
- 처음에는 채널 랙이 숨겨져 있습니다. `F6`이나 툴바 버튼으로 표시합니다.
- 플레이리스트의 오토메이션 레인이 켜집니다.
- 창 레이아웃은 스타일마다 따로 저장되므로, 각 스타일은 마지막으로 두었던 모습으로 돌아옵니다.

## 그리드

실행한 클립은 바로 시작하지 않습니다. 다음 실행 퀀타이즈 지점을 기다리며, 그때까지 삼각형이 깜박입니다. 그리드 아래쪽 상자에서 전역 실행 퀀타이즈를 정하며, `전역`로 설정된 모든 클립이 이 값을 씁니다. 정지도 같은 방식으로 기다립니다.

클립을 우클릭하면 클립의 설정이 나옵니다.

| 설정 | 기능 |
|---|---|
| `실행 퀀타이즈` | 이 클립이 시작되는 시점: `전역`, `없음`, `8마디`부터 `1/32`까지 |
| `실행 모드` | `트리거`, `게이트`, `토글`, `반복` |
| `레가토 (위치 유지)` | 클립이 그 트랙에서 앞서 재생되던 클립의 재생 위치를 이어받습니다 |
| `루프` | 켜면 클립이 반복됩니다. 끄면 한 번 재생한 뒤 트랙이 멈춥니다 |
| `팔로우 액션` | 클립이 끝난 뒤의 동작: 각각 확률이 있는 두 가지 동작과, 동작이 일어나기까지의 시간 |
| `Delete` | 슬롯을 비웁니다 |

빈 슬롯을 우클릭하면 `정지 버튼 (씬이 여기서 이 트랙을 정지)`가 나옵니다. 빈 슬롯 왼쪽의 사각형을 클릭하면 그 트랙이 멈춥니다. 씬을 우클릭하면 `씬 삽입`, `아래에 씬 추가`, `씬 삭제`, `씬 이름 변경...`과 씬의 템포가 나옵니다.

슬롯 메뉴에는 그리드 전체에 적용되는 옵션도 두 개 있습니다. `트랜스포트가 멈추면 트랙을 플레이리스트로 되돌리기`와 `그리드 전체의 팔로우 액션`입니다.

| 명령 | 키 | 기능 |
|---|---|---|
| 이동 | 방향키 | 다른 슬롯을 선택합니다 |
| 클립 실행 | `Enter` | 선택한 클립을 실행합니다 |
| 씬 실행 | `Ctrl+Enter` | 선택한 씬을 실행합니다 |
| 클립 삭제 | `Del` | 선택한 슬롯을 비웁니다 |

## Ableton Live 세트

Live 세트를 열면 세션 클립과 씬이 실행 설정과 함께 클립 그리드에 들어갑니다. `파일 › 내보내기 › Ableton Live 세트 (.als)`는 그리드를 세션 클립으로 다시 씁니다. `옵션 › 일반 설정`의 `Live 세트의 세션 클립`에서 `플레이리스트, 어레인지먼트 뒤`를 고르면 대신 플레이리스트에 놓습니다.

## 되돌아가기

`보기 › 레이아웃 스타일 › 패턴 워크플로 (기본)`를 선택합니다. 패턴 워크플로에서 쓰던 창 레이아웃이 돌아오고, 오토메이션 레인도 이전 설정으로 돌아갑니다. 그리드의 클립은 프로젝트에 남아 있습니다.

## 알아 두기

- 클립을 실행한 트랙은 `플레이리스트로 돌아가기`를 누를 때까지 플레이리스트에서 소리가 나지 않습니다. `트랜스포트가 멈추면 트랙을 플레이리스트로 되돌리기` 옵션을 켜면 정지할 때마다 자동으로 돌려놓습니다.
- 0.1.25에서는 슬롯을 메뉴나 더블 클릭으로 채웁니다. 클립이나 파일을 슬롯으로 드래그할 수는 없습니다.
- 팔로우 액션은 클립에만 있고 씬에는 없습니다.
- 클립 실행 워크플로에서 직접 켠 오토메이션 레인은 되돌아갈 때 유지되지 않습니다.
- 패턴 워크플로를 선택하면 그리드의 내용은 전혀 불러오지 않습니다.
