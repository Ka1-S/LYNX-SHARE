LYNX SHARE에는 메인 창이 하나 있습니다. 위쪽을 따라 툴바가 있고, 그 아래의 데스크톱에는 창 다섯 개가 놓입니다. 브라우저, 플레이리스트, 채널 랙, 피아노 롤, 믹서입니다. 처음 시작하면 브라우저가 왼쪽에 있고, 플레이리스트가 나머지를 채우며, 채널 랙이 그 위에 떠 있습니다. 피아노 롤과 믹서는 불러올 때까지 숨겨져 있습니다.

## 화면 익히기

1. 마우스를 아무 컨트롤에나 가져갑니다. 메뉴 아래의 힌트 바에 그 컨트롤이 하는 일과 쓸 수 있는 마우스 버튼, 키가 표시됩니다.
2. `F6` 키를 눌러 채널 랙을 숨기고, `F6` 키를 다시 누르면 표시합니다.
3. `F9` 키를 눌러 믹서를 표시한 다음 `F7` 키로 피아노 롤을 표시합니다.
4. 제목 줄을 끌어서 창을 옮깁니다. 제목을 더블 클릭하면 최대화되고, 다시 더블 클릭하면 복원됩니다.
5. `보기 › 레이아웃 초기화` 메뉴를 선택하면 모든 것이 제자리로 돌아갑니다.

## 툴바

![툴바: 메뉴와 힌트 바, 트랜스포트, 마스터 노브, 녹음 옵션, 스냅과 패턴, 창 버튼, 파일 버튼, 코드 표시, 미터, 출력 모니터](/assets/img/wiki/toolbar-1920.webp)

기본 레이아웃에서 왼쪽부터 오른쪽으로:

| 그룹 | 들어 있는 것 |
|---|---|
| 메뉴 및 힌트 바 | 메뉴 `파일`, `편집`, `추가`, `패턴`, `보기`, `옵션`, `도구`, `도움말`와 그 아래의 힌트 바. 항상 맨 앞입니다 |
| 트랜스포트 | `패턴`, `송` 모드 버튼, 재생, 정지, 녹음, BPM 단위의 템포, 마디, 박, 스텝으로 표시한 위치 |
| 마스터 볼륨 및 피치 | `마스터` 볼륨 노브와 센트 단위의 `피치` 노브 |
| 녹음 옵션 | 메트로놈, 카운트인, 루프 녹음, 스텝 입력, 그 밖의 녹음 스위치 |
| 스냅 및 패턴 | 메인 스냅(기본값은 `선(줌을 따름)`), 현재 패턴, 새 패턴 버튼, 패턴 메뉴 |
| 창 바로 가기 | 창마다 버튼 하나와 플러그인 선택기 |
| 파일 및 실행 취소 | 새로 만들기, 열기, 저장, 내보내기, 실행 취소, 다시 실행 |
| 코드 감지 | MIDI 장치나 타이핑 키보드로 연주하는 코드의 이름을 표시합니다 |
| CPU, 메모리, 폴리포니 | 오디오 CPU 부하, 사용 중인 메모리, 보이스 수 |
| 출력 모니터 | 출력의 오실로스코프. 클릭하면 다른 모드로 넘어갑니다 |

`컨트롤러에 멀티링크`라는 그룹도 있으며 기본값은 숨김입니다.

`옵션 › 툴바` 메뉴에서 툴바를 바꿀 수 있습니다. `툴바 편집(패널을 드래그하여 이동, 추가, 제거)`, `구분선`, `툴바 패널 숨기기`, `프리셋`, 그룹마다 하나씩 있는 스위치, `아이콘 크기`(작게, 보통, 크게)가 있습니다.

## 트랜스포트

| 컨트롤 | 키 | 동작 |
|---|---|---|
| 패턴 모드 | `L` | 현재 패턴을 반복 재생합니다. 버튼을 우클릭하면 채널 랙이 표시됩니다 |
| 송 모드 | `L` | 플레이리스트 어레인지먼트를 재생합니다. 버튼을 우클릭하면 플레이리스트가 표시됩니다 |
| 재생 | `Space` | 재생합니다. 다시 누르면 정지하고 시작한 위치로 돌아갑니다. `Ctrl+Space` 키는 일시 정지합니다 |
| 정지 | | 정지하고 처음으로 돌아갑니다. 더블 클릭하면 모든 노트 끄기도 보냅니다 |
| 녹음 | `R` | 녹음 켜기/끄기. [녹음](/wiki/recording/)을 참고하세요 |

## 힌트 바

대기 중일 때 힌트 바에는 `Point at anything for help` 문구가 표시되고, 단축키 목록은 `F1`, 창은 `F5`부터 `F9`, 재생과 정지는 `Space` 키라고 알려 줍니다. 컨트롤 위에서는 그 컨트롤의 이름과, 끌기, `Ctrl`, `Alt`, 우클릭이 거기서 하는 일을 나열합니다. 백그라운드 플러그인 스캔 같은 긴 작업은 진행 상황을 여기에 보고합니다.

## 다섯 개의 창

| 창 | 키 | 용도 |
|---|---|---|
| [플레이리스트](/wiki/playlist/) | `F5` | 패턴, 오디오, 오토메이션 클립을 곡으로 편곡합니다 |
| [채널 랙](/wiki/channel-rack/) | `F6` | 악기마다 한 행씩, 현재 패턴의 스텝과 함께 표시합니다 |
| [피아노 롤](/wiki/piano-roll/) | `F7` | 현재 패턴에서 한 채널의 노트 |
| [믹서](/wiki/mixer/) | `F9` | 페이더가 있는 인서트, 이펙트, 라우팅 |
| [브라우저](/wiki/browser/) | `Alt+F8` | 샘플, 프리셋, 프로젝트의 내용, 플러그인 데이터베이스 |

각 키는 창을 표시하고 포커스를 주며, 이미 포커스가 있으면 숨깁니다. `F8` 키만 누르면 플러그인 선택기가 열리는데, 다섯 개 창에 속하지 않습니다. 툴바의 창 버튼은 키와 같은 일을 합니다. 버튼을 우클릭하면 그 창이 최대화되어 표시됩니다. `Enter` 키는 플레이리스트를 최대화하거나 복원합니다.

## 창을 옮기고 도킹하는 방법

모든 창에는 제목 줄이 있습니다. 왼쪽에는 창 자체의 옵션이 있는 메뉴 버튼이 있고, 그다음에 `분리됨(별도 창)`, `최대화됨`, `닫기`가 있습니다. 오른쪽에는 최대화 버튼과 닫기 버튼이 있습니다.

- 제목 줄을 끌어서 창을 옮깁니다. 다른 창과 가장자리에 달라붙습니다. `Alt` 키를 누르고 있으면 달라붙지 않고 움직입니다.
- 가장자리를 끌면 크기가 바뀝니다.
- `분리됨(별도 창)` 항목은 창을 별도의 시스템 창으로 바꾸며, 두 번째 모니터에서 쓸 때 유용합니다. 분리된 창에는 다시 붙여 주는 `도킹` 버튼이 있습니다. `보기 › 분리된 패널(별도 창)` 메뉴에는 다섯 개가 모두 나열됩니다.
- `보기 › 화면 밖 패널 되돌리기` 메뉴는 데스크톱 밖으로 나가 버린 창을 되찾습니다.
- `보기 › 다른 이름으로 레이아웃 저장...` 메뉴는 배치를 이름을 붙여 저장하고, `보기 › 레이아웃 불러오기` 메뉴는 저장한 배치를 불러옵니다.

브라우저는 데스크톱의 배경입니다. 옆쪽에 도킹된 채로 유지되며 다른 창은 항상 그 위에 놓입니다.

## 알아 두면 좋은 점

- 창을 옮기거나 크기를 바꾸거나 분리하기 전에는, 메인 창의 크기가 바뀔 때마다 창이 기본 위치로 돌아갑니다. 그 후에는 사용자의 배치가 기억되고 창 크기에 맞춰 조정됩니다.
- `F12` 키는 플러그인, 채널 설정, 도구 창을 닫습니다. 다섯 개의 메인 창은 닫지 않습니다.
- 타이핑 키보드 피아노가 켜져 있는 동안(`Ctrl+T`)에는 글자 키가 노트를 연주하고 대부분의 한 글자 단축키는 일시 중지됩니다.
- `보기 › 레이아웃 스타일` 메뉴는 패턴 워크플로(기본값)와 클립 실행 워크플로를 전환합니다. 클립 실행 워크플로는 플레이리스트 옆에 클립 그리드를 추가합니다.
