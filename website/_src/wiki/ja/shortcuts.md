0.1.26 alphaの既定のキーです。`ヘルプ › ショートカット` (`F1`) で、アプリ内にショートカット一覧が表示されます。`オプション › ショートカットを管理...` を開くと、画像のエディターで変更できます。

> macOSでは、アプリはMacの呼び方でキーを表示します。Ctrlは⌘、Altは⌥と表示されます。

## ショートカットを変更する

1. `オプション › ショートカットを管理...` を選びます。
2. 検索ボックスに、アクション名か `Ctrl+L` のようなキーを入力します。横のリストで検索範囲を1か所に絞れ、`変更済みのみ` では、変更したものだけが表示されます。
3. アクションをクリックします。
4. `変更` をクリックするとキーを置き換え、`ショートカットを追加` をクリックすると2つ目のキーを加えます。そのあと、新しいキーを押します。`Esc` で取り消します。
5. 同じ場所ですでに使われているキーの場合は、もう一方のアクションの名前がメッセージに表示され、キーを移すことができます。

`削除` は、そのアクションのキーを消します。`デフォルトに戻す` は1つのアクションを元に戻し、`すべてリセット...` はすべてのアクションを元に戻します。変更は、設定フォルダーの `keys.json` に保存されます (Windowsでは `%APPDATA%\LYNX`、macOSでは `~/Library/Application Support/LYNX`、Linuxでは `~/.config/LYNX`)。`keys.jsonを開く` で、そのファイルを開きます。

## トランスポートと録音

| キー | 働き |
|---|---|
| `Space` | 再生する。または停止して、再生を始めた位置に戻る |
| `Ctrl+Space` | 再生または一時停止する |
| `Shift+Space` | 再生する。または、ソングまたはパターンの先頭で停止する |
| `L` | パターンモードとソングモードを切り替える |
| `R` | 録音のオンとオフ |
| `Shift+R` | 今すぐオーディオを録音する: 選択中のインサートを録音待機にして録音する |
| `Ctrl+M` | メトロノームのオンとオフ |
| `Ctrl+P` | 録音前のカウントインのオンとオフ |
| `Ctrl+I` | 最初のノートまで録音が待つ設定のオンとオフ |
| `Ctrl+B` | 録音したノートのブレンドのオンとオフ |
| `Ctrl+E` | ステップ入力のオンとオフ |
| `Ctrl+H` | サウンドを停止する (オールノートオフ) |
| `Ctrl+T` | タイピングキーボードをピアノにするオンとオフ |
| `Alt+Numpad *` / `Alt+Numpad /` | 次または前のソングマーカーへジャンプする |

これらのキーの一部は、フォーカスのあるエディターの中では別の動作をします。ピアノロールでは、`Ctrl+M` はMIDIファイルの読み込み、`Ctrl+B` は複製です。プレイリストでは、`Ctrl+P` はパフォーマンスモードです。

## 知っておくと便利なこと

- タイピングキーボードのピアノがオンの間は、そのキーがノートを鳴らし、1文字のショートカットのほとんどが一時停止します (`L` は使えます)。`Ctrl+T` でオフにします。
- ショートカットは、どこでも働くものと、1つのウィンドウだけで働くものがあります。ウィンドウに属するショートカットは、そのウィンドウにフォーカスがある間、どこでも働く同じキーより優先されます。
- クイック追加パレットのように、既定のキーがないアクションもあります。エディターでキーを割り当ててください。
- プレイリストでは、クリップを動かすキーは、何も選択していないときはすべてのクリップを動かします。`Alt+Left` と `Alt+Right` の細かいステップは、現在のズームでの1ピクセルです。
- LYNX SHAREのショートカットは、プラグインウィンドウにフォーカスがあるときも使えます。たとえば `Space` です。通常の文字と数字は先にプラグインに渡され、`Esc` でそのウィンドウが閉じます。
