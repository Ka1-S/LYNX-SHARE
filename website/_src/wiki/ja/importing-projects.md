`ファイル › 開く...` (`Ctrl+O`) では、LYNX SHARE独自の `.lynx` プロジェクトのほか、`.flp`、`.als`、`.flm`、`.mid` のファイルも開けます。ほかのプログラムのプロジェクトは読み込みとして扱われ、保存されていない新しいLYNX SHAREプロジェクトになります。元のファイルに書き込むことはありません。

## ほかのプログラムのプロジェクトを開く

1. `ファイル › 開く...` を選んで、`.flp`、`.als`、`.flm`、`.mid` のファイルを指定します。
2. LYNX SHAREがプロジェクトのプラグインとサンプルを探す間、待ちます。
3. 見つからないものがあると、`見つからないファイル` ウィンドウが開きます。サンプルの場所を指定するか、閉じてください。
4. タイトルバーに、プロジェクトの元の場所が表示されます。例: 「(FL Studioからインポート)」。
5. `ファイル › 保存` を選びます。`.lynx` ファイルの保存先を尋ねられます。

## 読み込まれるもの

| 形式 | 変換されるもの | 変換されないもの |
|---|---|---|
| `.flp` (FL Studio) | チャンネル、サンプル、パターン、スライドとポルタのノート、すべてのアレンジ、マーカー、拍子の変更、オートメーション、コントローラーのリンク、ルーティング付きのミキサー、サイドチェーン、トラックEQ、ネイティブエフェクト | FLEXパックは暗号化されていて、開くことはありません。FLEXのチャンネルには、プリセット名から選ばれたシンセのパッチが付きます |
| `.als` (Live 11と12) | MIDI、オーディオ、グループ、リターンの各トラック、テンポ、拍子、ロケーター、ループ、ボリューム、パン、ミュート、ソロ、センドとそのオートメーション、セッションクリップとシーン、ワープマーカー、ラックとDrum Rack、Live標準のデバイスの多く (EQ Eight、Compressor、Glue Compressor、Reverb、Delay、Auto Filter、Saturator、Utility、Simpler、Driftなど) がLYNX SHARE独自のものとして | LYNX SHAREに同等のものがないLiveのデバイス (Hybrid Reverb、Grain Delay、Amp、Roar、FM Operatorのパッチなど) は外され、一覧で示されます。MIDI Effect Rackは変換されません |
| `.flm` (FL Studio Mobile) | テンポ、拍子、チャンネルごとに1つのミキサーインサート、レーンごとに1つのプレイリストトラック、パターン、オフセットとピッチ付きのオーディオクリップ、ドラムキット、DW Samplerと `.dwp` プログラム、Slicer、MiniSynth、Transistor Bass、3x Osc、GMSynth、SuperSaw、エフェクト、オートメーション、コードセット | FLMのほかのジェネレーターは、内蔵シンセで鳴ります |
| `.mid` | ノート、拍子、すべてのテンポ変更 | MIDIファイルには音が含まれません。チャンネルには、LYNX SHAREのシンセかMIDI Outチャンネルが付きます |

`.flp` の中のサードパーティのVST2、VST3、CLAPのプラグイン、および `.als` の中のVST2とVST3のプラグインは、同じプラグインがお使いのコンピューターにインストールされていれば、保存された状態のまま読み込まれます。

## FL Studio自身のプラグイン

FL Studioのジェネレーターとエフェクトは読み込まれません。LYNX SHAREは保存された設定を読み、作り直したエンジンで再生します。各エンジンには品質レベルがあり、`Exact` (テストしたすべての状態で元のものとビット単位で一致) から `Placeholder` (設定は保持されるが、プラグインは無音か、オーディオをそのまま通すだけ) までの段階です。レベルの意味は[FL Studioから移る方へ](/wiki/coming-from-fl-studio/)で説明しています。

`.flp` は、FL Studioがインストールされていなくても開けます。一部のエンジンは、波形、サンプル、インパルスを必要とし、実行時にお使いのFL Studioのインストールから読み込みます。

## 見つからないサンプル

![見つからないファイルのウィンドウのサンプルタブ: 見つかったファイルは緑、見つからないものは琥珀色で、フォルダーを検索、場所を指定、スキップのボタンがある](/assets/img/wiki/missing-files.webp)

`サンプル` タブに、見つからなかったすべてのサンプルが、保存されていたパスとそれを使っているものとともに並びます。

| コマンド | 働き |
|---|---|
| `フォルダーを検索...` | フォルダーとそのサブフォルダーから、見つからないサンプルをすべて探す |
| `場所を指定...` | 1つのサンプルの場所を尋ねる。同じフォルダーにあるほかのサンプルも、一緒に見つかる |
| `スキップ` | そのサンプルを外す。チャンネルは無音のままになる |

`適用` を押すと、見つかったファイルが使われます。

`自動検出` タブには、LYNX SHAREが別のフォルダーで自動的に見つけたファイルが並びます。新しい場所を残すには、プロジェクトを保存してください。

## 見つからないプラグイン

LYNX SHAREは、サードパーティのプラグインを、識別子、ファイル、名前の順で探します。VST2で保存したプロジェクトは同じ製品のVST3で開け、その逆も同様ですが、設定はデフォルトになります。

エフェクトがインストールされていない場合、同じ役割のLYNX SHAREのエフェクトがそのスロットに入ります。リバーブにはリバーブ、コンプレッサーにはコンプレッサーです。

- スロットには、元のプラグインの名前とLYNX SHAREのバッジが表示されます。
- 保存された状態が読める場合は、設定が変換されます。読めない場合、代替はデフォルトのプリセットから始まります。製品、その代替、それぞれで何が変換されるかの一覧は、[PLUGIN_FALLBACK.md](https://github.com/Ka1-S/LYNX-SHARE/blob/main/docs/PLUGIN_FALLBACK.md)にあります。
- 元のプラグインのパラメーターのオートメーションは残りますが、代替は動かしません。
- 元のプラグインの参照と状態はプロジェクトに残ります。そのプラグインをインストールすれば、次からは元のプラグインでプロジェクトが開きます。
- 代替スロットの右クリックメニューにある `このプロジェクトのLYNX SHARE代替をすべてバイパス` で、すべての代替を一度にオフにできます。

切り替えは `オプション › 全般設定...` の `見つからないプラグインをLYNX SHAREの同等品で代替` で、初期設定ではオンです。オフにすると、見つからないエフェクトのスロットはミキサーから外れます。見つからないインストゥルメントの代替はありません。チャンネル名から選ばれたプリセットを持つ内蔵シンセになります。

本物のプラグインを戻すには、インストールして `オプション › プラグインをスキャン` を選び、プロジェクトをもう一度開いてください。

## MIDIファイル

![MIDIデータのインポートウィンドウ: トラック、チャンネル、チャンネルタイプ、オプション](/assets/img/wiki/midi-import-dialog.webp)

`ファイル › 開く...` は、MIDIファイルから新しいプロジェクトを作ります。`ファイル › インポート › MIDIファイル...` は、先に `MIDIデータをインポート` ウィンドウを開き、取り込む内容を選べます。

| 設定 | 働き |
|---|---|
| `インポートするトラックは？` | すべてのトラック、または1つ |
| `インポートするチャンネルは？` | MIDIチャンネルをクリックすると、除外される。右クリックすると、そのチャンネルだけが残る |
| `チャンネルタイプ` | `LYNX SHAREシンセ` または `MIDI Out` |
| `新規プロジェクトを開始` | 空のプロジェクトを始める。オフ: 開いているプロジェクトに追加する |
| `トラックごとに1チャンネルを作成` | オフ: MIDIチャンネルごとに1つのチャンネル |
| `新しいチャンネルにミキサートラックを設定` | 新しいチャンネルを、連続したミキサーのインサートにルーティングする |
| `拍子をインポート` | ファイルの拍子が、プロジェクトの拍子になる |

[ピアノロール](/wiki/piano-roll/)で `Ctrl+M` を押すと、MIDIファイルを現在のチャンネルに読み込みます。

## 知っておくと便利なこと

- `ヘルプ › 見つからないファイル...` で、あとから見つからないファイルのウィンドウをもう一度開けます。`ヘルプ › Last FL Studio import report` には、近似されたもの、省かれたもの、インストールされていないものが一覧で出ます。
- Liveのセットのセッションクリップは、クリップ起動レイアウトのクリップグリッドに入ります。代わりにプレイリストに置くには、`オプション › 全般設定...` の `Live セットのセッションクリップ` を使います。
