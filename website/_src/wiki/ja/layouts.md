`表示 › レイアウトスタイル` には、3つの項目があります。`パターンワークフロー (既定)`、`クリップ起動ワークフロー`、`シンプルワークフロー` です。同じ選択は、`オプション › 全般設定` のワークフローにもあります。選んだ内容は、プログラムを閉じても保たれます。

パターンワークフローは、チャンネルラック、パターン、プレイリストで構成されます。クリップ起動ワークフローでは、プレイリストの横にシーン付きのクリップグリッドが加わります。パターンとチャンネルラックも引き続き使えます。

## グリッドでクリップを起動する

1. `表示 › レイアウトスタイル › クリップ起動ワークフロー` を選びます。プレイリストの隣にクリップグリッドが現れます。
2. 空のスロットを右クリックし、`ここにパターンを置く` を選んで、パターンを指定します。空のスロットをダブルクリックすると、現在のパターンがそこに置かれます。
3. クリップの左にある三角をクリックして起動します。トランスポートが止まっている場合は、再生が始まります。
4. `シーン` 列にあるシーンの三角をクリックすると、その行のすべてのクリップが起動します。
5. `すべてのクリップを停止` をクリックすると、すべて停止します。
6. `プレイリストに戻る` をクリックすると、トラックが再びプレイリストのクリップを再生します。

## 画面で変わること

- クリップグリッドが、プレイリストの横に表示されます。プレイリストのトラックが列、シーンが行になります。
- プレイリストのタイトルバーに、`両方`、`グリッド`、`ソング` の切り替えが加わります。`グリッド` はグリッドだけ、`ソング` はプレイリストだけを表示します。
- 初回は、チャンネルラックが隠れています。`F6` かツールバーのボタンで表示できます。
- プレイリストのオートメーションレーンがオンになります。
- ウィンドウのレイアウトはスタイルごとに保存されるので、各スタイルは最後に使ったままの状態で戻ります。

## グリッド

起動したクリップは、すぐには始まりません。次の起動クオンタイズのポイントまで待ち、それまで三角が点滅します。グリッド下部のボックスでグローバルの起動クオンタイズを設定し、`グローバル` に設定されたすべてのクリップがそれを使います。停止も同じように待ちます。

クリップを右クリックすると、そのクリップの設定が出ます。

| 設定 | 働き |
|---|---|
| `起動クオンタイズ` | このクリップがいつ始まるか: `グローバル`、`なし`、`8小節` から `1/32` まで |
| `起動モード` | `トリガー`、`ゲート`、`トグル`、`リピート` |
| `レガート (位置を維持)` | そのトラックで直前に再生していたクリップの再生位置を、クリップが引き継ぎます |
| `ループ` | オン: クリップを繰り返します。オフ: 1回再生してから、トラックが止まります |
| `フォローアクション` | クリップの後に起こること: それぞれ確率を持つ2つのアクションと、実行までの時間 |
| `Delete` | スロットを空にします |

空のスロットを右クリックすると、`停止ボタン (シーンがここでこのトラックを停止)` があります。空のスロットの左にある四角をクリックすると、そのトラックが止まります。シーンを右クリックすると、`シーンを挿入`、`下にシーンを追加`、`シーンを削除`、`シーン名を変更...`、そしてシーンのテンポが出ます。

スロットのメニューには、グリッド全体に関わるオプションが2つあります。`トランスポート停止時にトラックをプレイリストに戻す` と `グリッド全体のフォローアクション` です。

| コマンド | キー | 働き |
|---|---|---|
| 移動 | 矢印キー | 別のスロットを選びます |
| クリップを起動 | `Enter` | 選択したクリップを起動します |
| シーンを起動 | `Ctrl+Enter` | 選択したシーンを起動します |
| クリップを削除 | `Del` | 選択したスロットを空にします |

## Ableton Liveのセット

Liveのセットを開くと、そのセッションクリップとシーンが、起動設定ごとクリップグリッドに入ります。`ファイル › エクスポート › Ableton Live セット (.als)` は、グリッドをセッションクリップとして書き戻します。`オプション › 全般設定` には `Live セットのセッションクリップ` があり、`プレイリスト、アレンジメントの後` を選ぶと、代わりにプレイリストに配置されます。

## 元に戻す

`表示 › レイアウトスタイル › パターンワークフロー (既定)` を選びます。パターンワークフローで使っていたウィンドウのレイアウトが戻り、オートメーションレーンも以前の設定に戻ります。グリッドのクリップはプロジェクトに残ります。

## 知っておくと便利なこと

- クリップを起動したトラックは、`プレイリストに戻る` を押すまで、プレイリストでは無音のままです。`トランスポート停止時にトラックをプレイリストに戻す` オプションを使うと、停止のたびにこれが自動で行われます。
- 0.1.25では、スロットはメニューかダブルクリックで埋めます。クリップやファイルをスロットにドラッグすることはできません。
- フォローアクションはクリップにあり、シーンにはありません。
- クリップ起動ワークフローの間に手動で切り替えたオートメーションレーンは、戻したときには保たれません。
- パターンワークフローを選んでいる間は、グリッドは何も読み込まれません。
