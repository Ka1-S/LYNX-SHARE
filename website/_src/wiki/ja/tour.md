LYNX SHAREのメインウィンドウは1つです。上端にツールバーがあり、その下のデスクトップに5つのウィンドウがあります。ブラウザー、プレイリスト、チャンネルラック、ピアノロール、ミキサーです。起動直後は、ブラウザーが左に、プレイリストが残りの領域全体に、チャンネルラックがその上に浮かんで表示されます。ピアノロールとミキサーは、呼び出すまで隠れています。

## 画面の見方

1. マウスをどのコントロールにも合わせてみてください。メニューの下のヒントバーに、そのコントロールの働きと、使えるマウスボタンやキーが表示されます。
2. `F6` を押すとチャンネルラックが隠れ、もう一度 `F6` を押すと表示されます。
3. `F9` を押してミキサーを表示し、`F7` でピアノロールを表示します。
4. ウィンドウは、タイトルバーをドラッグして動かします。タイトルをダブルクリックすると最大化され、もう一度ダブルクリックすると元に戻ります。
5. `表示 › レイアウトをリセット` を選ぶと、すべてが元の配置に戻ります。

## ツールバー

![ツールバー: メニューとヒントバー、トランスポート、マスターのノブ、録音オプション、スナップとパターン、ウィンドウボタン、ファイルボタン、コード表示、メーター、出力モニター](/assets/img/wiki/toolbar-1920.webp)

既定のレイアウトで、左から右へ並びます。

| グループ | 内容 |
|---|---|
| メニューとヒントバー | `ファイル`、`編集`、`追加`、`パターン`、`表示`、`オプション`、`ツール`、`ヘルプ` の各メニューと、その下のヒントバー。常に先頭にある |
| トランスポート | `パターン` と `ソング` のモードボタン、再生、停止、録音、BPMで表したテンポ、小節・拍・ステップで表した位置 |
| マスターのボリュームとピッチ | `マスター` のボリュームノブと、セント単位の `ピッチ` ノブ |
| 録音オプション | メトロノーム、カウントイン、ループ録音、ステップ入力、その他の録音スイッチ |
| スナップとパターン | メインのスナップ (初期設定は `ライン (ズームに追従)`)、現在のパターン、新しいパターンのボタン、パターンメニュー |
| ウィンドウのショートカット | ウィンドウごとに1つのボタンと、プラグインピッカー |
| ファイルと元に戻す | 新規、開く、保存、エクスポート、元に戻す、やり直し |
| コード検出 | MIDIデバイスやタイピングキーボードで弾いているコードの名前を表示する |
| CPU、メモリ、ポリフォニー | オーディオのCPU負荷、使用中のメモリ、ボイス数 |
| 出力モニター | 出力のオシロスコープ。クリックするたびに、ほかのモードへ切り替わる |

`コントローラーへのマルチリンク` というグループもありますが、初期設定では隠れています。

ツールバーは `オプション › ツールバー` で変更できます。項目は `ツールバーを編集 (パネルをドラッグして移動、追加、削除)`、`区切り`、`ツールバーパネルを非表示`、`プリセット`、グループごとのスイッチ、そして `アイコンサイズ` (小、中、大) です。

## トランスポート

| コントロール | キー | 働き |
|---|---|---|
| パターンモード | `L` | 現在のパターンをループ再生する。ボタンを右クリックすると、チャンネルラックが表示される |
| ソングモード | `L` | プレイリストのアレンジメントを再生する。ボタンを右クリックすると、プレイリストが表示される |
| 再生 | `Space` | 再生する。もう一度押すと、停止して開始位置に戻る。`Ctrl+Space` で一時停止する |
| 停止 | | 停止して先頭に戻る。ダブルクリックすると、オールノートオフも送る |
| 録音 | `R` | 録音のオンとオフ。[録音](/wiki/recording/)を参照 |

## ヒントバー

何も操作していないとき、ヒントバーには `Point at anything for help` と表示され、ショートカット一覧は `F1`、ウィンドウは `F5` から `F9`、再生と停止は `Space` と案内されます。コントロールの上にマウスを置くと、そのコントロールの名前と、ドラッグ、`Ctrl`、`Alt`、右クリックの働きが一覧で出ます。バックグラウンドのプラグインスキャンのような長い処理も、ここに進行状況が出ます。

## 5つのウィンドウ

| ウィンドウ | キー | 用途 |
|---|---|---|
| [プレイリスト](/wiki/playlist/) | `F5` | パターン、オーディオ、オートメーションのクリップを並べて、曲にする |
| [チャンネルラック](/wiki/channel-rack/) | `F6` | インストゥルメントごとに1行で、現在のパターンのステップを表示する |
| [ピアノロール](/wiki/piano-roll/) | `F7` | 現在のパターンにある1つのチャンネルのノート |
| [ミキサー](/wiki/mixer/) | `F9` | フェーダー付きのインサート、エフェクト、ルーティング |
| [ブラウザー](/wiki/browser/) | `Alt+F8` | サンプル、プリセット、プロジェクトの内容、プラグインデータベース |

各キーは、ウィンドウを表示してフォーカスを与え、すでにフォーカスがあれば隠します。`F8` だけを押すとプラグインピッカーが開きますが、これは5つのウィンドウには含まれません。ツールバーのウィンドウボタンも、キーと同じ働きをします。ボタンを右クリックすると、そのウィンドウが最大化されて表示されます。`Enter` で、プレイリストを最大化、または元に戻します。

## ウィンドウの動かし方とドッキング

どのウィンドウにもタイトルバーがあります。左側にはそのウィンドウ独自のオプションのメニューボタンがあり、続いて `切り離し (専用ウィンドウ)`、`最大化`、`閉じる` があります。右側には、最大化ボタンと閉じるボタンがあります。

- タイトルバーをドラッグして、ウィンドウを動かします。ほかのウィンドウや端にスナップします。`Alt` を押しながら動かすと、スナップしません。
- 端をドラッグして、サイズを変えます。
- `切り離し (専用ウィンドウ)` を選ぶと、ウィンドウがシステム上の独立したウィンドウになります。2台目のモニターで使うときに便利です。切り離したウィンドウには `ドッキング` ボタンがあり、元に戻せます。`表示 › 切り離したパネル (専用ウィンドウ)` に、5つすべてが並びます。
- `表示 › 画面外のパネルを戻す` で、デスクトップの外に出てしまったウィンドウを呼び戻せます。
- `表示 › レイアウトに名前を付けて保存...` で配置に名前を付けて保存し、`表示 › レイアウトを読み込む` で呼び戻します。

ブラウザーはデスクトップの背景にあたります。側面にドッキングしたままで、ほかのウィンドウは常にその上に表示されます。

## 知っておくと便利なこと

- 何も動かしたり、サイズを変えたり、切り離したりしていない間は、メインウィンドウのサイズが変わるたびに、ウィンドウが既定の位置に戻ります。いったん動かしたあとは、あなたの配置が記憶され、ウィンドウに合わせて拡大縮小されます。
- `F12` は、プラグイン、チャンネル設定、ツールのウィンドウを閉じます。5つのメインウィンドウは閉じません。
- タイピングキーボードのピアノがオンの間 (`Ctrl+T`)、文字キーがノートを鳴らし、1文字のショートカットのほとんどが一時停止します。
- `表示 › レイアウトスタイル` で、パターンワークフロー (既定) と、プレイリストの横にクリップグリッドが加わるクリップ起動ワークフローを切り替えます。
