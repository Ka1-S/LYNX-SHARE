LYNX SHAREは、Windows、macOS、Linuxで使える、無料のオープンソースDAWです。パターンを中心に作業します。チャンネルラックとピアノロールでパターンを打ち込み、プレイリストでアレンジし、ミキサーでミックスします。FL Studioのプロジェクト (`.flp`) とAbleton Liveのセット (`.als`) を開け、独自の `.lynx` 形式で保存します。

アルファ版です。バグがあることを前提に、こまめに保存してください。

## 起動するまで

1. 下の表で、お使いのシステムが対応していることを確認します。
2. ダウンロードしてインストールします。各システムの手順は[インストール](/wiki/install/)にあります。
3. 起動します。短いセットアップウィザードで、言語の選択、オーディオ出力のテスト、プラグインフォルダーの一覧表示を行い、そのフォルダーはバックグラウンドでスキャンされます。ウィザードはスキップでき、あとから `オプション › セットアップウィザード (言語、オーディオ、プラグインフォルダー)...` で開き直せます。
4. 音が出ないときは、[オーディオの設定](/wiki/audio-setup/)へ進んでください。
5. [ウィンドウの紹介](/wiki/tour/)を読んでから、[最初の1曲](/wiki/first-song/)を作ります。

## 必要なもの

| システム | 要件 |
|---|---|
| Windows | Windows 10または11、64ビット |
| macOS | macOS 11 Big Sur以降、Intel版またはApple silicon版 |
| Linux | glibc 2.35以降のx86_64 (Ubuntu 22.04以降、Debian 12以降、Fedora 36以降、最新のArchまたはManjaro)、X11またはXWayland |

オーディオインターフェースは必要ありません。LYNX SHAREは、システムがすでに使っているサウンドデバイスで再生します。FL Studioも必要ありません。同じコンピューターにFL Studioがインストールされていれば、LYNX SHAREはそのサンプルを見つけ、`.flp` プロジェクトにも同じプラグインファイルを使います。

サードパーティのプラグインは任意です。LYNX SHAREには独自のインストゥルメントとエフェクトがあり、[カタログ](/instruments-and-effects/)に載っています。

## 作業を保存する

`Ctrl+S` で保存、`Ctrl+Shift+S` で名前を付けて保存、`Ctrl+Alt+S` で新しいバージョンの保存 (Song_2、Song_3 と続く) です。自動保存もあり、`ファイル › 自動保存フォルダーを開く` と `ファイル › 最新のバックアップに戻す...` から利用できます。

`ファイル › テンプレートから新規作成` には、4つの出発点があります。空、ベーシックビート、808入りのトラップ、ハウスです。

## デモプロジェクト

Windowsのインストーラーとzip、macOSの `.dmg`、Linuxの `.tar.gz` には、デモプロジェクトの `Demo.lynx` が入っています。`ファイル › 開く...` (`Ctrl+O`) で開きます。Windowsでは、インストール先のフォルダーの `LYNX.exe` の隣にあります。

ターミナルから生成することもできます。[コマンドライン](/wiki/command-line/)を参照してください。

```
LYNX.exe --showcase out.lynx
```

## 知っておくと便利なこと

- プログラムのファイル名は、Windowsでは `LYNX.exe`、macOSとLinuxでは `LYNX` です。設定フォルダーの名前も `LYNX` です。
- WindowsとmacOSでは、初回起動時にシステムの警告が出ることがあります。Windows版にはまだコード署名がなく、macOS版は公証されていないためです。何をクリックするかは[インストール](/wiki/install/)で説明しています。
- LYNX SHAREが対応していない言語のシステムでは、インターフェースは初期設定で英語になります。`オプション › 全般設定...` で変更できます。新しい言語は、再起動後に反映されます。
- FL Studioプロジェクトの中のFLEXパックは暗号化されていて、開くことはありません。そのチャンネルには、プリセット名から選ばれたシンセのパッチが付きます。
