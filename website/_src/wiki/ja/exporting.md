![WAVを選んだエクスポートウィンドウ。左に範囲、テール、ファイル、右に形式、下にミックスのオプション](/assets/img/wiki/export.webp)

LYNX SHAREから出ていくものはすべて `ファイル › エクスポート` を通ります。オーディオ形式 (WAV、MP3、OGG、FLAC、AIFF、M4A) は、1つのエクスポートウィンドウを共有します。MIDI、FL Studioのプロジェクト、Ableton Live セット、DAWprojectファイル、Zip圧縮したプロジェクトは、同じメニューにそれぞれ専用の項目があります。

## 曲をWAVにエクスポートする

1. `ファイル › エクスポート › WAVファイル...` を選びます。
2. `レンジ` は `ソング (プレイリスト)`、`ファイル` は `1ファイル (ミックス)` のままにします。
3. `ビット深度` を選びます。16ビット、24ビット、32ビット (浮動小数点) のいずれかです。
4. `テール` を `残りを残す` にすると、最後の小節の後もリバーブやリリースが鳴り切ります。
5. `エクスポート...` をクリックし、名前とフォルダーを選んで、レンダリングが終わるのを待ちます。
6. 終わると、LYNX SHAREがファイルの保存先とピークレベルを知らせます。

`Ctrl+R` は、最後にエクスポートした形式でウィンドウを開きます。`Ctrl+Shift+R` はMP3でウィンドウを開きます。

## レンダリングする対象

| 設定 | 働き |
|---|---|
| `レンジ` | `ソング (プレイリスト)`、`現在のパターン`、`プレイリストの選択範囲` |
| `再生` | 範囲をファイルの中で何回再生するか。`1回` から16回まで |
| `テール` | `残りをカット` は終わりぴったりで止めます。`残りを残す` は音を鳴り切らせます。`残りを先頭に回す` はテールを先頭にミックスします。ループ向けです |
| `最長テール` | 3、6、12、30秒。音が消えたら、テールはそこで止まります |
| `ファイル` | 1ファイル、またはステム (下を参照) |

## 出力フォーマット

ボタンで形式を選びます。M4Aは、システムにAACエンコーダーがある場合にだけ選べます。WindowsとmacOSでは使え、Linuxでは使えません。`同時に保存` は、同じレンダリングから、同じ名前で別の形式も書き出します。

| フォーマット | オプション |
|---|---|
| WAV | `ビット深度`: 16ビット、24ビット、32ビット (浮動小数点)。`ディザー`: `オフ`、`TPDF`、`TPDF + ノイズシェーピング` |
| MP3 | `ビットレート`、固定 |
| OGG | ビットレート |
| FLAC | `ビット深度`、`圧縮` は `0 (最速)` から `8 (最小)`、`ディザー`。どのレベルでもロスレスです |
| AIFF | `ビット深度`: 16ビットまたは24ビット。`ディザー` |
| M4A | `ビットレート`: 96、128、160、192 kbps。AACで、システムのエンコーダーが書き出します |

`サンプルレート` と `チャンネル` は、すべての形式に適用されます。`チャンネル` は `ステレオ`、`モノ (左右をミックス)`、`モノ (左のみ)`、`モノ (右のみ)` から選びます。

## ミックスのオプション

| 設定 | 働き |
|---|---|
| `ノーマライズ (ピークを0 dBに)` | ファイル全体を上げ下げして、最大のピークをフルスケールに合わせます |
| `マスターエフェクト` | オフ: マスターインサートのエフェクトをバイパスします |
| `インサートのエフェクト` | オフ: ほかのインサートのエフェクトをバイパスします |
| `すべてのプラグインをHQで` | プラグインはレンダリング品質を使います。オフ: エクスポートは再生時の品質を使います |
| `プラグインのウォームアップ` | エクスポートを始める前に、サードパーティのプラグインが短い無音を処理します |
| `最大ポリフォニーを無効化` | チャンネルの発音数の上限を外し、ノートが切られないようにします |
| `遅延補正による無音をトリム` | プラグインのレイテンシー補正が先頭に加える無音を取り除きます |
| `テンポ情報`、`ループマーカー`、`プレイリストマーカー` | WAVのみ: テンポ、ループ、プレイリストのマーカーをファイルに保存します |
| `完了時にファイルを表示` | 完了後に、結果のあるファイルマネージャーを開きます |

## ステムとトラック

![ミキサーのインサートごとに1ファイル、合計9ファイルに設定したFLACのエクスポートウィンドウ](/assets/img/wiki/export-flac-stems.webp)

`ファイル` には、ステムのモードが3つあります。

- `ミキサーインサートごと (ステム)`: 音が出るインサートごとに1ファイル。
- `チャンネルごと (ステム)`: 鳴るチャンネルごとに1ファイル。
- `チャンネルごと、楽器のみ (センドとバスなし)`。

`フルミックスも出力` にチェックを入れると、ステムと並んでミックスも書き出されます。下の行に、書き出されるファイル数が表示されます。

曲にセクションレーンのセクションがあるときは、`セクションごとに 1 ファイル` でセクションごとに切り分け、各ファイルにセクション名を付けます。ステムの場合は、セクションごとに1組ずつ書き出されます。

`ファイル › エクスポート › Playlist のすべてのトラック` と `Playlist のすべてのトラックグループ` は、プレイリストのトラックごと、またはグループごとに1ファイルを書き出します。ミキサーのメニューにある `ディスク録音 › 録音待機中のトラックをWAVファイルにレンダリング...` (`Alt+R`) は、録音待機中のインサートだけを対象にエクスポートウィンドウを開きます。

## エクスポートメニューのほかの項目

| コマンド | キー | 働き |
|---|---|---|
| `MIDIファイル...` | `Ctrl+Shift+M` | ノートを標準MIDIファイル (`.mid`) として書き出します |
| `マスタリング...` | `Ctrl+Alt+M` | プロジェクトをレンダリングし、お使いのコンピューター上で、LUFSのラウドネス目標にマスタリングします |
| `Zip ループパッケージ...` | なし | プロジェクトと使用するすべてのサンプルを、FL StudioのZipループパッケージとして1つの `.zip` に |
| `プロジェクトのデータファイル...` | なし | プロジェクトが使うすべてのファイルを選んだフォルダーにコピーします。プロジェクトは元のファイルを使い続けます |
| `FL Studio プロジェクト...` | なし | `.flp`、またはすべてのサンプル入りのZipループパッケージ |
| `Ableton Live セット (.als)...` | なし | Live 12またはLive 11用のセット |
| `DAWproject (.dawproject)...` | なし | Bitwig Studio、Studio One、CubaseなどDAWprojectを読めるアプリ用のプロジェクト |
| `他のアプリ用...` | なし | ステム、MIDIファイル、Liveセット、FL Studioのプロジェクト、ミックスダウン、READMEを1つのフォルダーに。必要ならZipにします |
| `プロジェクトのボーン...` | なし | チャンネルとエフェクトのプリセットとスコアを、フォルダーに |

## FL Studio、Ableton Live、DAWprojectへのエクスポート

`.flp` はFL Studio 2026のプロジェクトです。サンプラー、オーディオクリップ、FL Studio自身のジェネレーターとエフェクト、サードパーティのプラグイン、パターン、プレイリスト、ミキサー、オートメーションが、設定ごと移ります。FL Studioにないものについては、`オーディオにレンダリング（同じ音）` と `最も近い FL プラグインを使う（編集可能のまま、音が変わる場合あり）` から選びます。後者を選ぶと、LYNX専用のインストゥルメントは省かれます。曲の位置に追従するモジュレーターはオートメーションクリップになります。同期したLFOはFL Studioのクリップ LFOに、ステップ、ランダムソース、マクロはポイントになります。フォロワー、エンベロープ、キートラック、ベロシティは省かれます。レポートには、レンダリングされたもの、置き換えられたもの、省かれたものが一覧されます。詳しくは[FL Studioから移る方へ](/wiki/coming-from-fl-studio/)をご覧ください。

`.als` には、チャンネルごとのMIDIトラック、オーディオトラック、グループ、リターン、センド、ラックとDrum Rack、状態付きのVST2とVST3プラグイン、マーカー、ボリューム、パン、テンポのオートメーションが入ります。LYNX SHARE独自のインストゥルメントとエフェクトは変換されませんが、そのトラックとノートは保たれます。例外はHelixで、LiveのWavetableになります。エフェクトのパラメーターのオートメーションと、インサート間のルートは省かれます。詳しくは[Ableton Liveから移る方へ](/wiki/coming-from-ableton/)をご覧ください。

`.dawproject` には、トラック、フォルダー、クリップ、ノート、ワープマーカー付きのオーディオ、オートメーション、テンポ、マーカー、センド付きのミキサー、状態付きのVST3、VST2、CLAPプラグインが入ります。LYNX SHARE独自のインストゥルメントとエフェクトは、LYNX SHAREでもう一度開けるように書き出されます。クリップグリッド、ほかのアレンジメント、ノートごとの細かな情報の一部は省かれ、レポートに一覧されます。

`ファイル › FL Studio Mobileプロジェクト(.flm)としてコピーを保存...` は、FL Studio Mobile用の `.flm` を書き出し、サンプルを隣の `<name> Samples` フォルダーにコピーします。保存の前に、`ファイル › 古いLYNX用にコピーを保存...` と同じように、コピーで失われるものがウィンドウに一覧表示されます。`.flm` には、ノートとパターン(FL Studio Mobileではトラックごとに1つのパターン)、テンポ、1小節の拍数、キーとコードセット、ミキサーのレベル、パン、ミュート、ソロ、バスへのセンド、FL Studio Mobile独自のインストゥルメント(MiniSynth、SuperSaw、GMSynth、Transistor Bass、およびFL StudioのMiniSynthとTransistor Bass)、ドラムキットになるドラムサンプラー、複数のインストゥルメントを持つラックになるレイヤー、ミックス付きのすべてのPocket(FLM)エフェクト、レベル、パン、ピッチ、リバース付きのオーディオクリップが残ります。DW Sampler(ゾーン付き)と3x Oscのほか、ミキサーのレベルとパン、Pocket(FLM)エフェクト、DW SamplerとGMSynth自身の値のオートメーションクリップも書き出されます。それ以外のインストゥルメント(今のところFL Studio MobileのSlicerとSoundFont Playerを含む)はノートがFL Studio MobileのMiniSynthに残り、FLMのモジュールがないエフェクトと、シンセ自身のノブやサードパーティ製プラグインなど他の対象のオートメーションは省かれます。すべて一覧に載ります。

## 知っておくと便利なこと

- MP3、OGG、M4A、32ビットWAVでは `ディザー` がグレーアウトされ、WAV以外のすべての形式ではテンポとマーカーのオプションがグレーアウトされます。
- `プレイリストの選択範囲` で、プレイリストに選択範囲がないと、曲全体がレンダリングされます。ウィンドウが警告します。
- マスターインサートがミュートされていると、ファイルが無音になるとウィンドウが警告します。
- `このミックスでビデオも書き出す` は、プロジェクトにビデオトラックがあるときだけ表示され、FFmpegが必要です。
- `ハードウェア経由でリアルタイムにレンダリング` は、プロジェクトに有効なハードウェアインサートがあるときだけ表示されます。このエクスポートは曲の長さと同じ時間がかかります。
- インサートをオーディオクリップにバウンスするオーディオへのレンダリングは、このバージョンでは、置き換え前のインサートより約5 dB大きく再生されます。
