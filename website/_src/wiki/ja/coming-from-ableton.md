LYNX SHAREは、パターンワークフローで起動します。チャンネルラック、パターン、プレイリストという構成です。クリップ起動ワークフローは任意で使えるもので、プレイリストの横にシーン付きのクリップグリッドが加わります。LYNX SHAREは `.als` セットを読み書きできます。Abletonとは無関係です。

## Liveのセットを開く

1. `ファイル › 開く...` (`Ctrl+O`) を選んで、`.als` を指定します。Live 11とLive 12で保存したセットを読み込めます。
2. クリップグリッドで作業するには、`表示 › レイアウトスタイル › クリップ起動ワークフロー` を選びます。セットのセッションクリップとシーンは、ここに入ります。
3. プレイリストのタイトルバーにある `Grid / Both / Song` スイッチで、グリッド、プレイリスト、またはその両方を表示します。
4. `ファイル › 保存` を選びます。`.lynx` ファイルの保存先を尋ねられます。元の `.als` は変更されません。

元に戻すには、`表示 › レイアウトスタイル › パターンワークフロー (既定)` を選びます。同じ選択は `オプション › 全般設定...` にもあります。パターンとチャンネルラックは、どちらのレイアウトでも使えます。

## 対応表

| Liveでは | LYNX SHAREでは |
|---|---|
| セッションビュー | クリップ起動ワークフローのクリップグリッド |
| アレンジメントビュー | プレイリスト |
| トラック | プレイリストのトラック。クリップグリッドの列にあたる |
| シーン | シーン。クリップグリッドの行にあたる。シーンは、起動時にテンポを設定できる |
| 起動クオンタイズ | `グローバル`、`なし`、8小節から1小節まで、または1/2から1/32までの音価。必要ならクリップごとに設定できる |
| 起動モード | `トリガー`、`ゲート`、`トグル`、`リピート` |
| フォローアクション | アクションAとアクションB。それぞれに確率を設定できる |
| クリップ停止ボタン | 空のスロットに停止ボタンを付けられる |
| アレンジメントに戻る | `プレイリストに戻る` |
| ワープモード | `チャンネル設定 › タイムストレッチ` の `拍`、`トーン`、`テクスチャ`、`コンプレックス` |
| Simpler、Sampler、ドラムラック | LYNX SHAREのサンプラー |
| `.als` セット | `.lynx` プロジェクトファイル |

## クリップグリッド

スロットには、パターンクリップかオーディオクリップが入ります。

- 1つのトラックが同時に再生できるクリップは1つです。起動したクリップが、再生中のクリップに取って代わります。
- 起動は、起動クオンタイズの次のステップまで待ちます。
- `レガート` は、置き換えられたクリップが到達していた位置から、新しいクリップを始めます。`ループ` はクリップごとの設定です。
- シーンは、挿入、削除、名前の変更ができます。
- クリップを起動したトラックは、`プレイリストに戻る` を押すまで、プレイリストでは無音のままです。トランスポートが止まったときにトラックを戻すオプションもあります。

フォローアクションは、クリップの一定の小節数または周回数のあとに実行されます。アクションは `アクションなし`、`停止`、`再度再生`、`前`、`次へ`、`最初`、`最後`、`任意`、`その他` です。スイッチ1つで、グリッド全体のフォローアクションをオンまたはオフにできます。

## .alsから読み込まれるもの

- MIDI、オーディオ、グループ、リターンの各トラック、テンポ、拍子、ロケーター、ループ、ミキサー設定 (ボリューム、パン、ミュート、ソロ、センド) とそのオートメーション。
- VST2とVST3のプラグインと、その状態。同じプラグインがインストールされている場合に限ります。[サードパーティのプラグイン](/wiki/plugins/)を参照してください。
- セッションクリップとシーンは、起動モード、クオンタイズ、レガート、ループ、フォローアクション、停止ボタンとともに、クリップグリッドに入ります。代わりにプレイリストに、シーンごとに1つのセクションとして配置したいときは、`オプション › 全般設定...` の `Live セットのセッションクリップ` を変更します。
- ワープマーカー。

## .alsをエクスポートする

1. `ファイル › エクスポート › Ableton Live セット (.als)...` を選びます。
2. `保存先のバージョン` で、`Live 12` か `Live 11（Live 12 でも開けます）` を選びます。
3. `サンプル` では、セットのプロジェクトフォルダーにコピーするか、今ある場所を参照するかを選びます。
4. フォルダーを選びます。セットは `<name> Project/<name>.als` として保存されます。

| 書き出されるもの | 書き出されないもの |
|---|---|
| チャンネルごとのMIDIトラック。ノートはMIDIクリップになる | LYNX SHARE独自のインストゥルメントとエフェクト。そのトラックとノートは残る |
| ストレッチ、トランスポーズ、ゲイン、フェード、ワープモードを含むオーディオトラック | エフェクトのパラメーターのオートメーション |
| グループ、リターン、センド | インサートからインサートへのルート |
| 状態を含むVST2とVST3のプラグイン | |
| マーカーと、ボリューム、パン、テンポのオートメーション | |
| クリップグリッド。セッションクリップとシーンになる。ラックとDrum Rackも | |

エクスポートのあとに出るレポートに、省かれたものが一覧で載ります。

## 知っておくと便利なこと

- Live標準のデバイスの多くは、設定とオートメーションごと、LYNX SHARE独自のものとして読み込まれます: EQ Eight、EQ Three、Channel EQ、Compressor、Glue Compressor、Multiband Dynamics、Limiter、Gate、Utility、Reverb、Delay、Echo、Auto Filter、Saturator、Overdrive、Chorus-Ensemble、Redux、Auto Pan、Drum Buss、Simpler、Drift、Operator (FMなし)。ほかは外され、インポートレポートに一覧で出ます。
- Instrument RackとAudio Effect Rackは、チェーン、ゾーン、マクロごと読み込まれ、Drum RackはLYNX SHAREのDrum Rackになります。LiveのMIDI Effect Rackはまだ変換されず、インポートレポートに一覧で出ます。
- 省かれたものは、読み込みレポートに一覧で載ります。
- 書き出したセットでは、重なっているオーディオクリップをLiveがトリムします。
- Liveのセットのワープマーカーは、読み込み時に保持され、エクスポート時に書き戻されます。
