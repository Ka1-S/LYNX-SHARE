このページでは、ドラムパターン、メロディ、アレンジ、ミックス、エクスポートしたファイルまでの流れを、一通り順に説明します。各部分から、そのウィンドウを詳しく説明したページにリンクしています。途中で音が出なくなったら、[オーディオの設定](/wiki/audio-setup/)を見てください。

## ドラムパターンを作る

1. `ファイル › テンプレートから新規作成 › 空` を選びます。プロジェクトは、キック、クラップ、ハット、スネア、シンセの5つのチャンネルで始まり、ステップは何も入っていません。
2. [チャンネルラック](/wiki/channel-rack/)が表示されていなければ、`F6` を押します。
3. キックの行のステップをいくつかクリックします。ドラッグすると複数を描け、右クリックで消せます。
4. `Space` を押します。トランスポートはパターンモードなので、パターンがループ再生されます。もう一度 `Space` を押すと停止します。
5. クラップ、ハット、スネアの行にも、それぞれステップを入れます。
6. `F2` を押して、パターンに名前とカラーを付けます。

足りない音を加えるには、最後の行の下にある `+ チャンネルを追加` ボックスをクリックして、メニューからインストゥルメントを選びます。手持ちのサンプルを使うには、`Alt+F8` で[ブラウザー](/wiki/browser/)を開き、オーディオファイルをクリックして聴き、ダブルクリックで新しいチャンネルとして追加します。

## メロディを書く

1. `F4` を押します。LYNX SHAREは次の空のパターンへ移り、名前を尋ねます。
2. シンセチャンネルの名前を右クリックして、`ピアノロール` を選びます。
3. ペンシル (`P`) で、グリッドをクリックしてノートを追加します。
4. ノートをドラッグすると移動し、端をドラッグすると長さが変わります。右クリックでノートを削除します。
5. 編集しながらパターンを聴くには、`Space` を押します。

`Ctrl+T` でタイピングキーボードがピアノになるので、`Z` から `M` と `Q` から `P` で先に音を試せます。`P` のような文字のショートカットを使うときは、もう一度オフにしてください。

## パターンをアレンジする

1. `F5` を押して[プレイリスト](/wiki/playlist/)を表示します。
2. プレイリストの左にあるピッカーパネルで、ドラムのパターンをクリックします。これがクリップソースになります。
3. ペンシル (`P`) で、トラックをクリックしてパターンを置きます。さらに右でもう一度クリックすると、もう一度置けます。ブラシ (`B`) でドラッグして、クリップを端から端まで並べることもできます。
4. ピッカーでメロディのパターンをクリックし、別のトラックに置きます。
5. `L` を押してソングモードに切り替え、`Space` を押します。プレイリストが、ソングの位置から再生されます。ルーラーをクリックすると、位置を設定できます。

## ミックスしてエフェクトを加える

1. `F9` を押して[ミキサー](/wiki/mixer/)を表示します。最初の5つのチャンネルは、すでにインサート1から5を通って再生されます。`+ チャンネルを追加` メニューから追加したチャンネルは、空いているインサートを使います。どれを使うかは、チャンネルラックのチャンネルのルートボックスの数字でわかります。
2. チャンネルを専用の空きインサートに移すには、チャンネルラックでそれらを選択して `Ctrl+L` を押します。各インサートに、チャンネルの名前とカラーが付きます。
3. インサートのフェーダーをドラッグして、レベルを決めます。
4. インサートをクリックして選択します。右側のエフェクトパネルに、10個のスロットが表示されます。
5. 空のスロットをクリックして、エフェクトを選びます。スロットの名前をクリックすると、エフェクトのウィンドウを表示または非表示にできます。スロットのライトは、エフェクトのバイパスです。

## 曲をエクスポートする

![エクスポートウィンドウ: 左に範囲とテール、右に形式、ビット深度、サンプルレート、下にミックスのオプション](/assets/img/wiki/export.webp)

1. `Ctrl+S` を押して、先にプロジェクトを保存します。
2. `ファイル › エクスポート › WAVファイル...` を選びます。ほかの形式には、同じメニューに `MP3ファイル...`、`OGGファイル...`、`FLACファイル...` があります。
3. `レンジ` を `ソング (プレイリスト)` にします。ほかの選択肢は `現在のパターン` と `プレイリストの選択範囲` です。
4. ほかのオプションは、そのままにします。
5. `エクスポート...` をクリックして、ファイル名を決め、レンダリングが終わるのを待ちます。

## 各キーの働き

| コマンド | キー | 働き |
|---|---|---|
| チャンネルラック | `F6` | チャンネルラックを表示または非表示にする |
| 次の空のパターン | `F4` | 次の空のパターンへ移り、名前を付ける |
| ピアノロール | `F7` | ピアノロールを表示または非表示にする |
| プレイリスト | `F5` | プレイリストを表示または非表示にする |
| パターンモードまたはソングモード | `L` | `Space` で再生する対象を切り替える |
| ミキサー | `F9` | ミキサーを表示または非表示にする |
| 空きインサートへ送る | `Ctrl+L` | 選択中のチャンネルに、専用のミキサーのインサートを割り当てる |
| 保存 | `Ctrl+S` | プロジェクトを `.lynx` として保存する |
| エクスポート | `Ctrl+R` | 最後に使った形式でエクスポートウィンドウを開く |

## 知っておくと便利なこと

- パターンモードで聞こえるのは、現在のパターンだけです。アレンジしたのに曲が無音なら、トランスポートがソングモードになっているか確認してください。
- エクスポートウィンドウは、トランスポートがソングモードで、プレイリストにクリップがあるとき、`ソング (プレイリスト)` で始まります。そうでなければ `現在のパターン` で始まります。
- メトロノームのクリックは、エクスポートには含まれません。
- エクスポートウィンドウの下部に、曲の長さ (小節数)、全体の時間、ファイルに必要なディスク容量が表示されます。
- 新しいプロジェクトには、初期設定でマスターのインサートにリミッターが入っています。聞こえる音にも、エクスポートする音にも含まれます。
- 元に戻すは `Ctrl+Z` です。もう一度押すと、そのステップをやり直します。`Ctrl+Alt+Z` なら、さらにさかのぼれます。
