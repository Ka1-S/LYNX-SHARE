トランスポートの録音ボタンか `R` キーで、録音がオンになります。初回は、何を録音するかを尋ねるウィンドウが開きます。オーディオは、オーディオクリップとして[プレイリスト](/wiki/playlist/)に入ります。ノートは、現在のパターンに入ります。動かしたコントロールは、オートメーションになります。

## マイクや楽器を録音する

1. `オプション › オーディオ設定...` を開いて、入力デバイスを選びます。
2. [ミキサー](/wiki/mixer/) (`F9`) を開いて、空のインサートを選びます。
3. インサートのエフェクトスロットの上にある入力ボックスをクリックして、入力を選びます。ステレオのペアが先に並び、1チャンネルだけのものには `(モノ)` が付きます。
4. 入力ボックスの隣にある録音待機ボタンをクリックします。
5. `R` を押して、`オーディオ、プレイリストにオーディオクリップとして` を選びます。
6. 再生が自動で始まらなかったときは再生を押して、演奏します。
7. 停止を押します。テイクは、プレイリスト上のオーディオクリップになります。

`Shift+R` は、手順4から6を1つのキーで行います。選択中のインサートを録音待機にして、オーディオだけを録音し、再生を始めます。もう一度押すと止まります。

## 録音ウィンドウの選択肢

| 選択肢 | 働き |
|---|---|
| `オーディオ、プレイリストにオーディオクリップとして` | 選択中のミキサーインサートを録音待機にし、入力がなければ入力を尋ねます |
| `ノートとオートメーション` | MIDIキーボードやタイピングキーボードのノートと、動かしたコントロールを録音します |
| `すべて` | ノート、オートメーション、録音待機中のインサートのオーディオ |
| `オーディオ、オーディオエディターへ` | 曲の再生中に、入力を新しいオーディオエディターに録音します |

`今後は確認しない` にチェックを入れると、選択が保たれます。その後は、録音ボタンを右クリックして録音フィルターを開きます。`オートメーション`、`ノート`、`オーディオ`、`クリップ` があり、`録音開始時に録音する対象を確認` でウィンドウを元に戻せます。

## インサートの入力ボックス

![インサート3が録音待機になり、入力ボックスが入力1と2に設定されたミキサー](/assets/img/wiki/mixer-input.webp)

| 設定 | 働き |
|---|---|
| `オーディオ入力ソース` | このインサートが再生、録音するデバイス入力。または `(なし)` |
| `録音` | テイクを取り出す位置: `外部入力のみ`、`外部入力とミキサー入力`、`エフェクト後`、`EQ 後`、`レベルとパン後`、`トラック後` |
| `ドライ入力も 2 つ目のテイクとして録音 (LYNX)` | 処理済みのテイクと並べて、未処理の入力も残します |
| `外部入力をモニター` | `オフ`、`録音待機時`、`自動 (録音待機時、再生中を除く)`、`オン` |
| `録音保護 (録音待機不可)` | インサートが誤って録音待機にならないよう保護します |

## ノートを録音する

ノートは、MIDIキーボード、タイピングキーボード (`Ctrl+T`)、タッチキーボードから入り、現在のパターンの選択中のチャンネルに送られます。[MIDIコントローラー](/wiki/midi-controllers/)をご覧ください。

- `録音ノートをブレンド` (`Ctrl+B`) は、オーバーダブにするか置き換えにするかを決めます。オンでは、新しいノートがパターンのノートに加わります。オフでは、録音したチャンネルの古いノートが消されます。
- `録音したノートをグローバルスナップにクオンタイズ` は、録音オプションにあります。
- `ステップ入力` (`Ctrl+E`) は停止中に使えます。弾いたノートが、スナップの1ステップずつ順にパターンに入ります。
- `MIDIキャプチャ` (`Ctrl+Shift+Alt+R`) は、録音がオフでも、直前に弾いたノートをパターンに入れます。

録音中に動かしたコントロールは、ソングモードではオートメーションクリップに、パターンモードではパターンのイベントとして書き込まれます。[オートメーション](/wiki/automation/)をご覧ください。

## 録音オプション

オプションは、`オプション › 録音` と、録音ボタンの右クリックメニューにあります。

| コマンド | キー | 働き |
|---|---|---|
| `カウントイン` | `Ctrl+P` | 録音が始まる前のメトロノームを、オフ、1小節、2小節、4小節から選びます |
| `メトロノーム` | `Ctrl+M` | 再生中にクリックを鳴らします |
| `最初のノートで開始` | `Ctrl+I` | 弾くまで録音が待ちます |
| `ループ録音` | なし | 録音が先へ進まず、ループします |
| `オーディオ: ループ範囲でパンチイン/アウト` | なし | ループ範囲を通して再生し、その内側のオーディオだけを残します |
| `オーディオ: プリロール` と `post-roll` | なし | パンチインの前とパンチアウトの後に再生する長さを、オフ、1小節、2小節、4小節から選びます |
| `録音で再生を開始` | なし | 録音をオンにすると、再生も押されます |
| `録音停止時にインサートの録音待機を解除` | なし | 録音待機中のインサートは、テイクのたびに解除されます |

## ループ録音とテイク

`ループ録音` をオンにすると、録音はソングモードではループ範囲、パターンモードではパターンの上でループします。オフなら、録音はそのまま先へ進みます。

オーディオのループ録音では、各パスが次の空いているプレイリストのトラックに入り、それらのトラックはグループになります。停止後に何が再生されるかは `録音ノートをブレンド` で決まります。オフならすべてのパスがミュートされ、オンならすべて再生されます。グループのトラックを右クリックして `これらのテイクでコンプを作成` を選ぶと、複数のパスから1つのテイクを作れます。録音オプションの `ループ録音後は最後のパスのみ再生` を使うと、1つのトラックに戻ります。

## 録音の保存先

- 保存済みのプロジェクトでは、テイクはプロジェクトファイルの隣の `Audio/Recorded` に保存されます。
- 未保存のプロジェクトでは、ミュージックフォルダー内の `LYNX/Recordings` に録音されます。
- テイクは、オーディオデバイスのサンプルレートで、24ビットまたは32ビット浮動小数点のWAVファイルです。形式とテイクの名前は、`オプション › オーディオ設定...` の `録音` で設定します。
- `録音フォルダーを開く` は、録音ボタンの右クリックメニューにあります。`ファイル › 未使用の録音を削除して保存...` は、プロジェクトがもう使っていないテイクを削除します。

## 知っておくと便利なこと

- 入力のない録音待機中のインサートは、何も録音しません。LYNX SHAREがそれを知らせ、入力ボックスを示します。
- ドライブの空きが30秒分に満たないと、録音は始まりません。10分分を下回ると警告が出ます。
- `オプション › 入力オーディオを録音` は、何も録音待機になっていないとき、入力の最初の2チャンネルを新しいインサートに録音します。
- macOSでは、初めて録音するときに、システムがマイクへのアクセスを求めます。
- 録音中にLYNX SHAREが閉じても、次回の起動時に、復旧したテイクをプレイリストに置くかどうかを尋ねられます。
