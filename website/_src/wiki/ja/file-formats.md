LYNX SHAREは、プロジェクトを `.lynx` ファイルとして保存します。ほかのプログラムのプロジェクトを開いたり、一般的なオーディオファイルを読み込んだり、オーディオ、MIDI、他のプログラム向けのプロジェクトをエクスポートしたりもできます。表には、0.1.26 alphaのすべての形式を載せています。

ほかのプログラムの形式から開いたプロジェクトは、インポートになります。`ファイル › 保存` では `.lynx` ファイルの保存先を尋ねられ、元のファイルが変更されることはありません。

## ほかのプログラムのプロジェクトを開く

1. `ファイル › 開く...` (`Ctrl+O`) を選びます。
2. `.flp`、`.als`、`.flm`、`.mid`、`.zip` のいずれかのファイルを指定します。
3. `.flp` の場合は、`ヘルプ › Last FL Studio import report` を選ぶと、近似されたものや省かれたものが読めます。
4. `ファイル › 保存` を選び、`.lynx` ファイルの保存先を指定します。

## 形式

| フォーマット | 開く | 保存 / エクスポート | 備考 |
|---|---|---|---|
| `.lynx` | `ファイル › 開く...` | `ファイル › 保存`、自動保存あり | LYNX SHARE独自のプロジェクト形式 (JSON) |
| `.zip` | `ファイル › 開く...` でフォルダーに展開し、中のプロジェクトを開きます | `ファイル › エクスポート › サンプルを含むプロジェクト (.zip)...` | FL StudioのZipループパッケージも開けます |
| `.lynxpack` | 概要を表示してから開きます。パートはホストのプロジェクトに統合されます | `ファイル › オンラインセッション › プロジェクトを送信...` | [オンラインセッション](/wiki/online-sessions/)で送られるプロジェクトまたはパート。サードパーティのプラグインのパートは、オーディオのレンダリングとプラグインの設定で受け渡されます |
| `.flp` | `ファイル › 開く...` | `ファイル › エクスポート › FL Studio プロジェクト...`。FL Studio 2026のプロジェクト、またはZipループパッケージ | ネイティブプラグインは、再現されたエンジンで再生され、精度はまちまちです。FLEXパックは開かれません。エクスポートでは、LYNX専用のインストゥルメントとエフェクトはオーディオにレンダリングされるか、最も近いFLプラグインに置き換えられ、モジュレーターは省かれます。[FL Studioから移る方へ](/wiki/coming-from-fl-studio/)をご覧ください |
| `.flm` | `ファイル › 開く...` | 不可 | FL Studio Mobileのプロジェクト。部分対応: MiniSynth、Transistor Bass、3x Osc、GMSynth、SuperSaw、DW Sampler、Slicer、DirectWave以外のインストゥルメントは、内蔵シンセで再生されます |
| `.als` | `ファイル › 開く...`。Live 11と12のセット | `ファイル › エクスポート › Ableton Live セット (.als)...`。Live 12またはLive 11用 | インポートでは、LYNX SHAREに同等のものがないLiveのデバイスは外されます。エクスポートでは、LYNX SHARE独自のインストゥルメントとエフェクトは変換されず、エフェクトのパラメーターのオートメーションとインサート間のルートは外されます。[Ableton Liveから移る方へ](/wiki/coming-from-ableton/)をご覧ください |
| `.mid`、`.midi` | `ファイル › 開く...` で新しいプロジェクトになります。`ファイル › インポート › MIDIファイル...` とピアノロールでは、現在のプロジェクトに取り込まれます | `ファイル › エクスポート › MIDIファイル...` (`Ctrl+Shift+M`) | |
| `.wav` | サンプルまたはオーディオクリップとして | `ファイル › エクスポート › WAVファイル...`。16ビット、24ビット、32ビット浮動小数点 | ディザー、テンポ情報、ループマーカー、プレイリストマーカーは任意です |
| `.mp3` | サンプルまたはオーディオクリップとして | `ファイル › エクスポート › MP3ファイル...` | 固定ビットレート |
| `.ogg` | サンプルまたはオーディオクリップとして | `ファイル › エクスポート › OGGファイル...` | |
| `.flac` | サンプルまたはオーディオクリップとして | `ファイル › エクスポート › FLACファイル...`。圧縮は0～8 | どのレベルでもロスレスです |
| `.aif`、`.aiff` | サンプルまたはオーディオクリップとして | 不可 | |
| `.wv` | サンプルとして | 不可 | WavPackのサンプル。FL Studioのパックに入っているものです |
| `.sf2`、`.sf3` | LYNX Soundfontで再生 | 不可 | SoundFont |
| `.fst` | ブラウザーから | 不可 | FL Studioのネイティブプラグインのプリセット。LYNX SHAREにエンジンがあるプラグイン限定です |
| `.fsc` | ピアノロールとイベントエディター | ピアノロールとイベントエディター | FL Studioのスコアとオートメーションのファイル |
| `.lynxpreset`、`.fxp`、`.fxb`、`.vstpreset` | ホストしたプラグインのプリセットメニューの `プリセットファイルを読み込む...` | `プリセットを保存...` と `プリセットファイルをエクスポート...` | サードパーティのプラグインのプリセット。`.fxp` と `.fxb` はVST2プラグイン用、`.vstpreset` はVST3プラグイン用で、プラグインがLYNX SHARE内で動作している間だけ使えます |
| ビデオファイル | `ファイル › インポート › ビデオファイル...` でプレイリストにビデオを置きます | エクスポートウィンドウの `このミックスでビデオも書き出す` | インポートは、WindowsとmacOSではシステムのデコーダーを使い、LinuxではFFmpegが必要です。エクスポートにはFFmpegが必要です |

## そのほかのエクスポート

| コマンド | 働き |
|---|---|
| エクスポートウィンドウの `ファイル` オプション | ステム: ミキサーのインサートごと、チャンネルごと、またはインストゥルメントのみのチャンネルごとに1ファイル |
| `ファイル › エクスポート › Playlist のすべてのトラック` | プレイリストのトラックごとに1ファイル |
| `ファイル › エクスポート › Playlist のすべてのトラックグループ` | トラックグループごとに1ファイル |
| `ファイル › エクスポート › マスタリング...` | プロジェクトをレンダリングし、お使いのコンピューター上でラウドネス目標にマスタリングします |
| `ファイル › エクスポート › プロジェクトのボーン...` | チャンネルとエフェクトのプリセットとスコアをフォルダーに書き出します |

エクスポートウィンドウは、曲、現在のパターン、プレイリストの選択範囲をレンダリングします。

## コマンドラインから

Windowsではプログラムは `LYNX.exe`、macOSとLinuxでは `LYNX` です。

```
LYNX.exe project.lynx                       open a project (.lynx, .flp, .als, .flm or .mid)
LYNX.exe --export project.flp out.flac      render the song (wav, flac or ogg)
LYNX.exe --stems project.flp base.wav       one WAV per mixer insert that has sound
LYNX.exe --export-flp project.lynx out.flp  write an FL Studio project
```

`--export`、`--stems`、`--export-flp` は、入力に `.als` も受け付けます。

## 知っておくと便利なこと

- 30秒より長いオーディオファイルは、ディスクキャッシュからストリーミングされます。
- 保存しても、`.flp`、`.als`、`.flm` に書き込まれることはありません。エクスポートのコマンドは新しいファイルを書き出します。
- `.wv` ファイルは読み取り専用です。
- `.zip` はまずフォルダーに展開され、そのあと中のプロジェクトが開かれます。
