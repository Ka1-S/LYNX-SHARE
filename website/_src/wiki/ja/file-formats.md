LYNX SHAREは、プロジェクトを `.lynx` ファイルとして保存します。ほかのプログラムのプロジェクトを開いたり、一般的なオーディオファイルを読み込んだり、オーディオ、MIDI、他のプログラム向けのプロジェクトをエクスポートしたりもできます。表には、0.1.31 alphaのすべての形式を載せています。

ほかのプログラムの形式から開いたプロジェクトは、インポートになります。`ファイル › 保存` では `.lynx` ファイルの保存先を尋ねられ、元のファイルが変更されることはありません。

## ほかのプログラムのプロジェクトを開く

1. `ファイル › 開く...` (`Ctrl+O`) を選びます。
2. `.flp`、`.als`、`.flm`、`.dawproject`、`.band`、`.blx`、`.mid`、`.zip` のいずれかのファイルを指定します。
3. `ヘルプ › 前回のプロジェクトインポートレポート` を選ぶと、近似されたものや省かれたものが読めます。
4. `ファイル › 保存` を選び、`.lynx` ファイルの保存先を指定します。

## 形式

| フォーマット | 開く | 保存 / エクスポート | 備考 |
|---|---|---|---|
| `.lynx` | `ファイル › 開く...` | `ファイル › 保存`、自動保存あり | LYNX SHARE独自のプロジェクト形式 (JSON)。`ファイル › 古いLYNX用にコピーを保存...` は、0.1.27や0.1.28で開けるコピーを書き出し、そのバージョンで保てないものを一覧にします |
| `.zip` | `ファイル › 開く...` でフォルダーに展開し、中のプロジェクトを開きます | `ファイル › エクスポート › Zip ループパッケージ...` | FL StudioのZipループパッケージも開けます |
| `.lynxpack` | 概要を表示してから開きます。パートはホストのプロジェクトに統合されます | `ファイル › オンラインセッション › プロジェクトを送信...` | [オンラインセッション](/wiki/online-sessions/)で送られるプロジェクトまたはパート。サードパーティのプラグインのパートは、オーディオのレンダリングとプラグインの設定で受け渡されます |
| `.flp` | `ファイル › 開く...` | `ファイル › エクスポート › FL Studio プロジェクト...`。FL Studio 2026のプロジェクト、またはZipループパッケージ | ネイティブプラグインは、再現されたエンジンで再生され、精度はまちまちです。FLEXパックは開かれません。エクスポートでは、LYNX専用のインストゥルメントとエフェクトはオーディオにレンダリングされるか、最も近いFLプラグインに置き換えられ、モジュレーターは省かれます。[FL Studioから移る方へ](/wiki/coming-from-fl-studio/)をご覧ください |
| `.flm` | `ファイル › 開く...` | `ファイル › FL Studio Mobileプロジェクト(.flm)としてコピーを保存...` | FL Studio Mobileのプロジェクト。部分対応: MiniSynth、Transistor Bass、3x Osc、GMSynth、SuperSaw、DW Sampler、Slicer、DirectWave以外のインストゥルメントは、内蔵シンセで再生されます。書き出しはコピーです。ノート、テンポ、ミキサー、FL Studio Mobile独自のインストゥルメント、DW Sampler、3x Osc、ドラムキット、エフェクト、そしてミキサーのレベルとパン、エフェクト、DW SamplerとGMSynthのオートメーションが残り、サンプルは隣に置かれます。コピーでは、それ以外のインストゥルメントはノートがMiniSynthに残り、FLMのモジュールがないエフェクトと、それ以外の対象(シンセ自身のノブ、サードパーティ製プラグイン)のオートメーションは省かれます。保存の前にウィンドウで一覧が表示されます。 |
| `.als` | `ファイル › 開く...`。Live 11と12のセット | `ファイル › エクスポート › Ableton Live セット (.als)...`。Live 12またはLive 11用 | インポートでは、LYNX SHAREに同等のものがないLiveのデバイスは外されます。エクスポートでは、LYNX SHARE独自のインストゥルメントとエフェクトは変換されず (HelixはWavetableになります)、エフェクトのパラメーターのオートメーションとインサート間のルートは外されます。[Ableton Liveから移る方へ](/wiki/coming-from-ableton/)をご覧ください |
| `.dawproject` | `ファイル › 開く...` | `ファイル › エクスポート › DAWproject (.dawproject)...` | Bitwig、Studio One、Cubaseなどのオープンな交換形式: トラック、フォルダー、クリップ、ノート、ワープマーカー付きのオーディオ、オートメーション、テンポ、マーカー、センド付きのミキサー、状態つきのVST3、VST2、CLAPプラグイン。インポートではノートエフェクトとMIDIエクスプレッションが外され、エクスポートではクリップグリッド、ほかのアレンジメント、ノートごとの細かな情報の一部が外されます。どちらの方向でも、外されたものが一覧に出ます |
| `.band` | `ファイル › 開く...` (パッケージ、その `projectData` ファイル、またはそのZip) | 不可 | GarageBand 10またはGarageBand for iOSのプロジェクトを、シンプルなワークフローのトラックとして開きます。部分対応: インストゥルメントトラックは内蔵シンセとドラムで再生されます (GarageBand for iOSで作ったSamplerインストゥルメントを除く)。GarageBand 11以前のプロジェクトは読めません |
| `.blx` | `ファイル › 開く...`、またはそのフォルダーをシンプルなワークフローの `フォルダー...` インポートで | 不可 | CakewalkまたはSonarでダウンロードしたBandLabプロジェクトを、リージョン、テンポ、キー、ミックス、ボリュームとパンのオートメーション、よく使うエフェクトとともにシンプルなワークフローのトラックとして開きます。部分対応: BandLabの楽器の音とそのほかのペダルはインポートレポートに一覧されます |
| `.mid`、`.midi` | `ファイル › 開く...` で新しいプロジェクトになります。`ファイル › インポート › MIDIファイル...` とピアノロールでは、現在のプロジェクトに取り込まれます | `ファイル › エクスポート › MIDIファイル...` (`Ctrl+Shift+M`) | |
| `.mod`, `.xm`, `.s3m`, `.it` | `ファイル › 開く...` | 不可 | トラッカーモジュール (ProTracker、FastTracker 2、Scream Tracker 3、Impulse Tracker)。楽器はサンプル付きのサンプラーチャンネルになり、曲はテンポの変化を含めてパターンクリップになり、`表示 › トラッカー`でノートを編集できます。一部：スライド、ビブラート、アルペジオなどのエフェクト、エンベロープ、鳴っているノートの音量変化はインポートレポートに記載されます |
| `.wav` | サンプルまたはオーディオクリップとして | `ファイル › エクスポート › WAVファイル...`。16ビット、24ビット、32ビット浮動小数点 | ディザー、テンポ情報、ループマーカー、プレイリストマーカーは任意です |
| `.mp3` | サンプルまたはオーディオクリップとして | `ファイル › エクスポート › MP3ファイル...` | 固定ビットレート |
| `.ogg` | サンプルまたはオーディオクリップとして | `ファイル › エクスポート › OGGファイル...` | |
| `.flac` | サンプルまたはオーディオクリップとして | `ファイル › エクスポート › FLACファイル...`。圧縮は0～8 | どのレベルでもロスレスです |
| `.aif`、`.aiff` | サンプルまたはオーディオクリップとして | `ファイル › エクスポート › AIFFファイル...`。16ビットまたは24ビット | |
| `.m4a` | – | `ファイル › エクスポート › M4Aファイル...` | エクスポート専用。WindowsとmacOSではシステムのエンコーダーによるAAC。Linuxでは使えません |
| `.wv` | サンプルとして | 不可 | WavPackのサンプル。FL Studioのパックに入っているものです |
| `.sf2`、`.sf3` | LYNX Soundfontで再生 | 不可 | SoundFont |
| `.dwp`、`.dwb` | ブラウザーでダブルクリック、チャンネルラックへのドロップ、またはDirectWaveの `プログラム / バンクを開く...` | DirectWaveのプログラムとバンクの保存 | DirectWaveのプログラムとバンク。サンプルはDirectWaveが探す場所から探されます |
| `.gig` | DirectWaveチャンネルとして | 不可 | GigaStudioのインストゥルメント: ベロシティレイヤー、ラウンドロビン、ループ、チューニング、アンプエンベロープ。リリーストリガーのサンプル、キースイッチ、圧縮サンプルはまだ読めません |
| `.ncw` | サンプルまたはオーディオクリップとして | 不可 | Kontaktの圧縮サンプル。Kontaktの `.nki` インストゥルメントにはプラグインとしてのKontakt本体が必要で、保護されたライブラリが復号されることはありません |
| `.fst` | ブラウザーから | 不可 | FL Studioのネイティブプラグインのプリセット。LYNX SHAREにエンジンがあるプラグイン限定です |
| `.fsc` | ピアノロールとイベントエディター | ピアノロールとイベントエディター | FL Studioのスコアとオートメーションのファイル |
| `.lynxpreset`、`.fxp`、`.fxb`、`.vstpreset` | ホストしたプラグインのプリセットメニューの `プリセットファイルを読み込む...` | `プリセットを保存...` と `プリセットファイルをエクスポート...` | サードパーティのプラグインのプリセット。`.fxp` と `.fxb` はVST2プラグイン用、`.vstpreset` はVST3プラグイン用で、プラグインがLYNX SHARE内で動作している間だけ使えます |
| ビデオファイル | `ファイル › インポート › ビデオファイル...` でプレイリストにビデオを置きます | エクスポートウィンドウの `このミックスでビデオも書き出す` | インポートは、WindowsとmacOSではシステムのデコーダーを使い、LinuxではFFmpegが必要です。エクスポートにはFFmpegが必要です |

## そのほかのエクスポート

| コマンド | 働き |
|---|---|
| エクスポートウィンドウの `ファイル` オプション | ステム: ミキサーのインサートごと、チャンネルごと、またはインストゥルメントのみのチャンネルごとに1ファイル |
| `ファイル › エクスポート › Playlist のすべてのトラック` | プレイリストのトラックごとに1ファイル |
| `ファイル › エクスポート › Playlist のすべてのトラックグループ` | トラックグループごとに1ファイル |
| `ファイル › エクスポート › マスタリング...` | プロジェクトをレンダリングし、お使いのコンピューター上でラウドネス目標にマスタリングします |
| `ファイル › エクスポート › 他のアプリ用...` | ステム、MIDIファイル、Ableton Liveセット、FL Studioのプロジェクト、ミックスダウン、READMEを1つのフォルダーに。必要ならZipにします |
| `ファイル › エクスポート › プロジェクトのボーン...` | チャンネルとエフェクトのプリセットとスコアをフォルダーに書き出します |

エクスポートウィンドウは、曲、現在のパターン、プレイリストの選択範囲をレンダリングします。

## コマンドラインから

Windowsではプログラムは `LYNX.exe`、macOSとLinuxでは `LYNX` です。

```
LYNX.exe project.lynx                       open a project (any file File › Open takes)
LYNX.exe --export project.flp out.flac      render the song (wav, flac, ogg, mp3, aif; m4a on Windows and macOS)
LYNX.exe --stems project.flp base.wav       one WAV per mixer insert that has sound
LYNX.exe --export-flp project.lynx out.flp  write an FL Studio project
```

`--export`、`--stems`、`--export-flp` は、入力に `.als` も受け付けます。

## 知っておくと便利なこと

- 30秒より長いオーディオファイルは、ディスクキャッシュからストリーミングされます。
- 保存しても、`.flp`、`.als`、`.flm`、`.dawproject`、`.band`、`.blx` に書き込まれることはありません。エクスポートのコマンドは新しいファイルを書き出します。
- `.wv` ファイルは読み取り専用です。
- `.zip` はまずフォルダーに展開され、そのあと中のプロジェクトが開かれます。
