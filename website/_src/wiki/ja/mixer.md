![ミキサー](/assets/img/mixer.webp)

すべてのチャンネルは、ミキサーインサートを通して鳴ります。各インサートには、フェーダー、パン、ミュート、ソロ、ピークメーター、ドライ/ウェット量付きのエフェクトスロット10個、内蔵EQがあります。別の場所にルーティングしない限り、すべてのインサートはマスターに行き着きます。`F9` でミキサーの表示と非表示を切り替えます。

1つのプロジェクトには、最大127個のインサートを置けます。ミキサーには、新しいインサートを追加するためのストリップがあります。ミキサーのタイトルバーにあるボックスで、`コンパクト` から `特大` まで、8種類のストリップのレイアウトから選べます。

## チャンネルにエフェクトをかける

1. [チャンネルラック](/wiki/channel-rack/)でチャンネルを選び、`Ctrl+L` を押します。チャンネルが空いているインサートに入り、そのインサートがチャンネルの名前とカラーを引き継ぎます。
2. `F9` でミキサーを表示し、そのインサートのストリップをクリックします。
3. エフェクトパネルで、空のスロットをクリックしてエフェクトを選びます。
4. スロットの名前をクリックすると、エフェクトのウィンドウが表示または非表示になります。
5. スロットのライトをクリックすると、エフェクトをバイパスして聴き比べられます。

## チャンネルをインサートに送る

チャンネルラックで、チャンネルのルートボックスをドラッグする (またはその上でホイールを使う) と、インサート番号を選べます。ボックスをダブルクリックすると、そのインサートがミキサーに表示されます。

チャンネルラックの `Ctrl+L` は、選んだ複数のチャンネルに同時に働きます。それぞれ、空いているインサートに入ります。

ミキサーにフォーカスがあるときの `Ctrl+L` は、選んだチャンネルを選択中のインサートにリンクし、`Ctrl+Shift+L` は、そこから始まる連続したインサートにリンクします。

## インサートを選んで動かす

- ストリップをクリックすると選択されます。
- `Ctrl` + クリック、またはストリップをまたいでドラッグすると、範囲を選択します。`Ctrl+Shift` + クリックで1つ追加または除外します。
- ストリップを横にドラッグするか、`Alt+Left` と `Alt+Right` を押すと、選んだインサートが動きます。
- ストリップを右クリックすると、インサートのメニューが出ます。`F2` は、選択中のインサートの名前とカラーを変更します。
- `Del`、またはインサートメニューの `Delete` で、選択中のインサートを削除します。LYNX SHAREは先に確認します。次回から確認を省くには、`選択を記憶する` にチェックを入れます。

インサートを移動、挿入、削除しても、センド、サイドチェーン、オートメーションは、そのインサートについたままです。

インサートメニューの `ミキサー` セクションと `オプション › ミキサー` には、さらに2つのコマンドがあります。`インサートをプレイリストの順に並べる` は、プレイリストのトラックにリンクされたインサートを、プレイリストの順で先頭に移します。`削除したインサートへのリンクをグレーで残す（LYNX）` をオンにすると、削除されたインサートに入っていたセンドが、グレー表示で残り、あとでつなぎ直せます。

## ミュートとソロ

ミュートのライトをクリックすると、インサートがミュートされます。右クリックか `Ctrl` + クリックでソロになります。`S` は選択中のインサートをソロにし、`Alt+S` は、そのインサートと、それに信号を送るインサートをまとめてソロにします。

ミュートしたインサートでも、メーターは動き続けます。新しいプロジェクトと、インポートしたFL Studioのプロジェクトでは、エフェクトも動き続け、マスターへの出力とセンドだけが切られます。ミュートしたインサートの処理を止めるには、インサートメニューの `ミキサー` セクションか `オプション › ミキサー` で `ミュートしたインサートは処理しない（LYNX、CPU節約、このプロジェクト）` をオンにします。すると、メーターが止まり、ミュートを解除したときにエフェクトが最初の状態から始まります。

## エフェクト

エフェクトパネルには、選択中のインサートの10個のスロットが表示されます。

- スロットをドラッグするか、その上でホイールを使うと、上下に動かせます。
- スロットを右クリックすると、オプション (置き換え、移動、削除) が出ます。
- スロットのメニューを開いている間、`Del` でそのスロットのプラグインを削除します。
- スロットのメニューの `オーディオエフェクトラックにグループ化` は、そのエフェクトを新しいラックに入れ、`すべてをオーディオエフェクトラックにグループ化` はチェーン全体を入れます。`グループ解除` は、1チェーンのラックのエフェクトをスロットに戻します。
- パネルのヘッダーにあるスイッチで、そのインサートのすべてのエフェクトをオンまたはオフにします。
- [ブラウザー](/wiki/browser/)のプラグインデータベースから、インサートやエフェクトスロットにエフェクトをドラッグできます。
- インサートメニューの `クリーンボイス` は、あらかじめ用意されたボーカルのクリーンアップチェーンをインサートに入れます。

## スロット内のEdison

オーディオエディターでありレコーダーでもあるEdisonは、どのエフェクトスロットにも、1つのインサートに複数置けます。そのウィンドウは、録音コントロールの行が付いたオーディオエディターです。

- インサートメニューの `オーディオエディターを開く` (`Ctrl+E`) は、インサートの最初の空きスロットにEdisonを読み込んで開きます。`オーディオエディターを開いて録音` (`Shift+E`) は、曲の再生時に録音できる状態で読み込みます。
- 録音モードは `現在`、`入力時`(既定: 入力がスレッショルドを超えるのを待ちます)、`入力`、`再生時` です。`追加` は、新しい録音を、すでにあるオーディオの後ろに置きます。最大録音時間は `無制限` または1、3、5、10、30、60分です。新しいスロットは30分で始まり、`オーディオエディターを開いて録音` は5分に設定します。
- `同期` は、曲の再生中、Edisonのオーディオを曲の時間に合わせて再生します。
- Edisonは、ウィンドウを閉じても録音を続けます。
- `ツール › マクロ › すべてのEdisonインスタンスを削除` は、確認のあと、プロジェクト内のすべてのEdisonスロットを空にします。
- FL Studioプロジェクト(.flp)のEdisonスロットは、オーディオごと開きます。

## インサートのEQ

各インサートには、それぞれのEQがあります。バンドをドラッグして周波数とレベルを決め、ホイールで幅を変え、バンドをダブルクリックすると0 dBに戻ります。EQのタイトルを右クリックすると、バイパスされます。内蔵EQのないミキサーにしたい場合は、新しいプロジェクトをクリーンなミキサーで始めるように設定できます。

## ルーティング、センド、サイドチェーン

![Kickインサートを選び、センドをストリップの下のケーブルで描き、右にエフェクトパネルを置いたミキサー](/assets/img/wiki/mixer-sends.webp)

ルーティングしたいインサートを選びます。すると、ほかのすべてのストリップにルートスイッチが現れます。

- ほかのストリップのスイッチをクリックすると、選んだインサートがそこに送られます。有効にした後にドラッグすると、センドレベルを設定できます。
- `Ctrl` + クリックでは、そのインサートだけにルーティングします。
- `Shift` + クリックでサイドチェーンのセンドになります。`Ctrl+Shift` + クリックでサイドチェーンのみになります。
- 右クリックすると、同じ選択肢がメニューで出ます。
- プリフェーダーのセンドにするには、ルートスイッチかセンドのレベルノブを右クリックして、`プリフェーダーセンド (このトラックのフェーダーの影響を受けません)` にチェックを入れます。そのセンドには `PRE` と表示されます。

コンプレッサーなど、サイド入力のあるエフェクトには、聴き取るインサートを一覧する `サイドチェーン元` のピッカーがあります。1つ選ぶと、ルートが自動で作られます。

## グループとVCAフェーダー

ミキサーのグループは、シェブロンで折りたためます (すべてのグループは `Alt` + クリック)。VCAフェーダーは、メンバーのインサートがそれぞれのフェーダーを保ったまま、そのレベルを動かします。インサートのメニューから作ります。グループの下で `VCA › 選択から新しい VCA` を選びます。

## 録音

各インサートには、録音待機ボタンがあります。インサートが録音待機のとき、録音と再生を押すと、そのオーディオ入力がプレイリストのクリップに録音されます。`Shift+R` は、選択中のインサートの録音待機と録音開始を、一度に行います。[録音](/wiki/recording/)をご覧ください。

同じインサートで、ほかのオーディオも録音する場合に外部入力を選ぶと、LYNX SHAREは `外部入力のみ` に切り替えるかどうかを尋ねるので、テイクには入力だけが入ります。インサートメニューの `ミキサー › ディスク録音 › レイテンシー補正` は、既定でオンです。オフにすると、録音したテイクはレイテンシー補正がまったくない状態で配置されます。

## キー

`Ctrl+L` と `Ctrl+Shift+L` は、ミキサーにフォーカスがあるときだけ、この意味になります。

| コマンド | キー | 働き |
|---|---|---|
| チャンネルをリンク | `Ctrl+L` | 選んだチャンネルを、選択中のインサートにリンクします |
| 連続するインサートにリンク | `Ctrl+Shift+L` | 選んだチャンネルを、選択中のインサートから始まるインサートにリンクします |
| インサートを移動 | `Alt+Left` / `Alt+Right` | 選んだインサートを動かします |
| 名前とカラーを変更 | `F2` | 選択中のインサートの名前とカラーを変更します |
| ソロ | `S` | 選んだインサートをソロにします |
| ソースと一緒にソロ | `Alt+S` | 選んだインサートと、それに信号を送るインサートをソロにします |
| インサートを削除 | `Del` | 選択中のインサートを、確認のあとで削除します |
| 録音待機して録音 | `Shift+R` | 選択中のインサートを録音待機にして、録音を始めます |
| オーディオエディターを開く | `Ctrl+E` | インサートの最初の空きスロットにEdisonを読み込んで開きます |
| オーディオエディターを開いて録音 | `Shift+E` | 同じですが、曲の再生時に録音できる状態です |

## 知っておくと便利なこと

- `オプション › ミキサー` の `マスターの横にラウドネスメーター（LYNX）` は、マスター出力のショートターム・ラウドネスとインテグレーテッド・ラウドネス (LUFS)、およびトゥルーピークを表示し、`リセット` ボタンがあります。
- 複数の出力を持つインストゥルメントプラグインは、出力ごとに別のインサートで鳴らせます。[サードパーティ製プラグイン](/wiki/plugins/)を参照してください。
- `Ctrl+L` は、チャンネルラックとミキサーで動作が異なります。ラックでは空いているインサートを選び、ミキサーでは選択中のインサートを使います。
- ルートスイッチは、選択中のストリップではなく、ほかのストリップに現れます。
- 上限は、1プロジェクトあたり127個のインサートと、1インサートあたり10個のエフェクトスロットです。
- Edisonの録音は、プロジェクトファイルの中ではなく、プロジェクトのフォルダーにWAVファイルとして保存されます。
- クリップグリッドの下のセッションミキサーは、クリップ起動ワークフローだけのものです。このミキサーと同じインサートを表示します。[レイアウト](/wiki/layouts/)をご覧ください。
