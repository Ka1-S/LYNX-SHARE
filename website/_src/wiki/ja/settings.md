![上部にページタブが並ぶ設定ウィンドウの全般ページ](/assets/img/wiki/settings-general.webp)

設定ウィンドウには8つのページがあります。オーディオ、MIDI、全般、テーマ、ファイル、LYNX extras、プロジェクト、情報です。最初の6つはプログラムに属します。プロジェクトと情報は、開いているプロジェクトに属し、プロジェクトと一緒に保存されます。各ページには、`オプション` メニューの先頭に専用の項目があります。

## 設定を変更する

1. `オプション` メニューを開いて、ページを選びます。たとえば `全般設定...` です。
2. 上部の別のタブをクリックすると、別のページに移ります。
3. 設定を変更します。変更はすぐに反映されます。言語とインターフェイスのフォントだけは、LYNX SHAREの再起動時に反映されます。

`F10` でMIDIページ、`F11` で情報ページが開きます。

## オーディオ

`オプション › オーディオ設定...`。ドライバー、デバイス、サンプルレート、バッファーサイズ、録音を設定します。このページについては、[オーディオの設定](/wiki/audio-setup/)で説明しています。`録音` の `ファイル形式` には、`WAV 16ビット（デバイスのサンプルレート）` も選べるようになりました。

## MIDI

![MIDIページ。入力デバイス、マスター同期付きの出力デバイス、外部同期](/assets/img/wiki/settings-midi.webp)

`オプション › MIDI設定...`

| 設定 | 働き |
|---|---|
| 入力デバイス | デバイスごとに、オフにする、1つのMIDIチャンネルだけを受け付ける、選択中のチャンネルではなくチャンネルラックの固定のチャンネルを鳴らす、を設定できます |
| `コントローラータイプ` | 入力デバイスごとに、`自動検出`、`汎用コントローラー`、またはMackie Controlなどのコントローラープロファイルを選びます。横の行に、ライトとディスプレイを受け取るポートの名前が表示されます |
| `MPEコントローラー` | デバイスのMIDIチャンネルのリストの末尾にあります。各ノートが、独自のベンド、音色、圧力を伴って届きます。2つ目のボックスでメンバーチャンネルを設定します |
| `デバイスリストを更新` | デバイスをもう一度探し、コントローラープロファイルも読み直します |
| `コントローラープロファイルのフォルダー` | 自分のコントローラープロファイル (`*.lynxctl`) 用のフォルダーを開きます |
| `マスター同期を送信` | ソングポジションポインター付きのMIDIクロック、またはMIDIタイムコードを、出力デバイスに送ります。`オフセット (ms)` で遅らせたり早めたりできます |
| `オールノートオフを送信` | 初期化時とエクスポート後に、オールノートオフをデバイスに送ります |
| `外部クロック同期` | LYNX SHAREが、選んだ入力のMIDIクロックに追従します。テンポ、スタート、コンティニュー、ストップ、位置が対象です |
| `ベロシティ` | MIDIデバイスからのノート用: 演奏どおり、ソフト、ハード、固定 |
| `パフォーマンスモードのチャンネル` | このチャンネルのノートで、パフォーマンスモード中にプレイリストのクリップを起動します |
| `ソングマーカージャンプ` | このチャンネルのノートは、演奏せず、曲をマーカーまで移動させます |
| `ピックアップ (テイクオーバーモード)` | コントローラーは、現在の値に達してからパラメーターを動かします |
| `フットペダルでノートオフを制御` | 既定ではオンです。サステインペダルとソステヌートペダルがノートを保持します。オフにすると、ペダルはプラグインに渡されます |
| `ゲームコントローラーを使う` | ゲームコントローラーでトランスポートを操作でき、MIDIコントローラーと同じようにリンクできます。既定ではオフです |
| リンク | このプロジェクトのコントローラーリンク、次にグローバルのもの。`リンクを削除` と `すべて削除` があります |

## 全般

`オプション › 全般設定...`

| 設定 | 働き |
|---|---|
| `レイアウトスタイル` | パターンワークフロー (既定)、クリップ起動ワークフロー、またはシンプルワークフロー |
| `デフォルトのテンプレート`、`起動時のプロジェクト` | `ファイル › 新規` で開くテンプレートと、起動時に開くもの。`空のプロジェクト`、`デフォルトのテンプレート`、`最後に使用したプロジェクト` から選びます。`ファイル › テンプレートとして保存...` で自分のテンプレートを追加できます |
| `Live セットのセッションクリップ` | インポートしたLiveセットのセッションクリップの行き先: クリップグリッド、またはアレンジメントの後のプレイリスト |
| `言語`、`インターフェイスのフォント` | 次回の起動時に反映されます |
| `インターフェースのサイズ`、`メニューの密度` | インターフェース全体のスケールと、メニューのコンパクト表示またはゆったり表示 |
| `波形` | クリーン (クリップのカラー) またはスペクトラルのカラー。ステレオチャンネルを分けて表示することもできます |
| `音名`、`黒鍵` | 英語式、ドイツ式、固定ドの音名。シャープまたはフラット |
| `プラグインのスタイル` | 内蔵プラグインのウィンドウの見た目: 自動、またはすべてのプラグインで1つのスタイル |
| `アニメーション`、`アニメーションレート` | インターフェースのアニメーションと、再生ヘッドやメーターが動く頻度 |
| `GPU (Direct2D) で描画` | グラフィックドライバーがクラッシュしたり、画面がちらついたりする場合はオフにします |
| 起動 | スプラッシュ画面、起動音、起動のたびにバックグラウンドで新しいプラグインを探すか |
| 編集 | タイピングキーボードをピアノに、チャンネルエディターを開いたままにする、シーク時間を記憶する、引き伸ばしたパターンクリップをループさせる |
| `新しいプラグインをすべて切り離す` | オン: 追加したプラグインのウィンドウが、パネルの上に独立して開きます。オフ (既定): メインウィンドウにドッキングして開きます |
| `ピアノロールでモノフォニックペイント` | オン: ペイントツールは、新しいノートの下にあるノートを置き換え、Shiftを押すとその上に重ねて描きます。オフ: その逆です |
| `リンクされたモジュールを自動選択` | プラグインウィンドウにフォーカスすると、そのミキサートラックが選択されます。既定ではオンです |
| `タイピングキーボードの優先をデフォルトで無効にする` | 以降に追加するプラグインに適用されます。既定ではオフです |
| `元に戻すの最大回数` | 25～1000 |
| `メッセージの管理` | `ヒントと警告` の下にあります。チェックを入れたメッセージが表示されます。チェックを外すと、そのメッセージの確認を省きます |
| バックアップ | バックアップコピーを保存する頻度、プロジェクトごとに保持する数、`バックアップフォルダーを開く` |
| `プラグインを別プロセスで実行` | プラグインがクラッシュしても、LYNX SHAREは落ちません。既定ではオフです |
| `見つからないプラグインをLYNX SHAREの同等品で代替` | 既定ではオンです。プロジェクトが、インストールされていないサードパーティ製プラグインを使っている場合、対応するものがあれば、LYNX SHAREの代替が同じ設定で読み込まれます。プロジェクトは元のプラグインを保持し、インストールされれば再びそれを使います |
| `開いているプラグインエディターの数を制限` | 開いたままにできるプラグインエディターのウィンドウは最大25個です。既定ではオンです |
| `クラッシュレポート` | クラッシュやフリーズの後に確認する (既定)、常に送信する、送信しない |
| `アップデートを自動で確認` | 起動時のアップデート確認。`今すぐ確認` もあります |

## テーマ

`オプション › テーマ (カラー、背景)...`

| 設定 | 働き |
|---|---|
| テーマのボックス | プリセットを選びます。`インポート...` と `エクスポート...` は `.lynxtheme` ファイルを読み書きし、`プリセットを保存...` は現在のテーマを保存し、`デフォルト` はリセットします |
| `アクセントカラー`、`背景`、`ワークスペース` | テーマの3色。ワークスペースのカラーは、背景に自動で合わせることもできます |
| ワークスペースの画像 | ウィンドウの後ろに置くPNG、JPEG、GIF。`画像のフィット`、`画像の不透明度`、`暗く` があります |
| 起動音 | 30秒以内の自分の音、またはLYNX SHARE標準の音 |

## ファイル

`オプション › ファイル設定 (検索フォルダー)...`

| 設定 | 働き |
|---|---|
| 不足しているサンプルの検索フォルダー | 「見つからないファイル」ウィンドウが、これらのフォルダーとそのサブフォルダーを自動で探します |
| ブラウザーのフォルダー | ブラウザーのフォルダー一覧に表示され、不足しているサンプルの検索にも使われます |
| プラグインフォルダー | `オプション › プラグインをスキャン` でプラグインがスキャンされます |

## LYNX extras

`オプション › LYNX の追加機能...`。LYNX SHARE独自の追加機能を1か所にまとめたページです。すべて既定ではオフです。各スイッチは、その行に書かれたメニューやページにある設定と同じものです。

| 設定 | 内容 |
|---|---|
| `マスターの横にラウドネスメーター（LYNX）` | マスターのショートターム・ラウドネスとインテグレーテッド・ラウドネス (LUFS)、およびトゥルーピーク。リセットボタン付き |
| `使用中のインサートのみ表示` | 何にも使われていないミキサーのインサートを隠します |
| `削除したインサートへのリンクをグレーで残す（LYNX）` | インサートを削除しても、そこに入っていたリンクが残り、つなぎ直せます |
| `ミキサーのグループをプレイリストに合わせる（LYNX）` | ミキサーのグループが、プレイリストのトラックグループと同じになります |
| `オートメーションレーン` | オートメーションをプレイリストのトラックの下のレーンに置けます |
| `ルーラー: ソングの小節 (LYNX)` | ピアノロールのルーラーに、パターンがソングで鳴る位置の小節番号を表示します |
| `コントロールにマウスを重ねたとき、その値をマウスの横に表示 (LYNX)` | 値が、ヒントバーだけでなくカーソルの横にも表示されます |
| `ループ録音後は最後のパスのみ再生` | それ以前のパスは、ミュートされたまま下に残ります |
| `W で選択中のデバイスのウィンドウを表示 / 非表示` | デバイスビュー用のキーです |
| `デバイスを選択するとミキサーでそのインサートを選択` | デバイスビューで選んだデバイスに、ミキサーが追従します |
| `ゲームコントローラーを使う` | MIDIページと同じスイッチです |

## プロジェクト

![プロジェクトページ。時間の設定、グルーヴとチューニング、タイムベース、プレイリストのオプション](/assets/img/wiki/settings-project.webp)

`オプション › プロジェクト設定 (テンポ、拍子)...`

| 設定 | 働き |
|---|---|
| `時間の設定` | 時間分割 (1小節あたりの拍数、1拍あたりのステップ数)、または従来の拍子 (分子と分母) |
| `テンポ`、`1小節あたりの拍数` | プロジェクトのテンポと、1小節の拍数 |
| `スウィング`、`マスターピッチ` | グローバルのスウィング量と、セント単位のマスターピッチ |
| `自動クロスフェード` | トラック上で重なるオーディオクリップが、重なった部分でクロスフェードします |
| `コンプのクロスフェード` | テイクをコンプするときに使うクロスフェードの長さ (ミリ秒) |
| `クリップ内の途切れたノートを再生` | パターンクリップより前から始まるノートを、クリップの先頭から再生します |
| `カットグループの高速デクリック` | カットグループがノートを切るとき、より速くランプします |
| `パンニング則` | 円形 (センターが0 dB、パンした側が+3 dB) または三角形 (大きいほうの側がレベルを保つ)。ミキサーのインサートとサンプラーのチャンネル用 |

## 情報

`オプション › プロジェクト情報...`。プロジェクトのタイトル、作者、ジャンル、Webリンク、コメントと、`プロジェクトを開いたときにこのページを表示` があります。下部には、プロジェクトの作成日時と作業時間が表示されます。

## 知っておくと便利なこと

- タイムベースは、4分音符あたり960ティックに固定されています。FL Studioのプロジェクトは、これに変換されます。
- 曲の途中での拍子の変更は、プロジェクトページにはありません。プレイリストのルーラーに拍子マーカーを追加してください。
- `プラグインを別プロセスで実行` は、その後に開くプラグインに適用されます。ほかのプラグインを切り替えるには、プロジェクトを開き直します。
- アップデートの設定は、Microsoft Storeのバージョンにはありません。Storeが更新するためです。
- ショートカットは設定のページではなく、`オプション › ショートカットを管理...` にあります。
- スイッチの一部は、このウィンドウではなくメニューにあります。`録音中は低レイテンシー` は、録音ボタンの横にある録音オプションメニューと、ミキサーの `ディスク録音` メニューにあります。`鍵盤のスタイル` は、ピアノロールのViewメニューにあります。
- Plugin databaseは、ドキュメントの `LYNX` フォルダー内にある `プラグインデータベース` というフォルダーです。ファイルマネージャーで整理できます。
