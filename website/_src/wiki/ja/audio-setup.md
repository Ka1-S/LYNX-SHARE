設定ウィンドウのオーディオページでは、音の出力先と録音の入力元を選びます。`オプション › オーディオ設定...` で開きます。セットアップウィザード (`オプション › セットアップウィザード (言語、オーディオ、プラグインフォルダー)...`) でもオーディオ出力をテストできます。

## 音を出す

1. `オプション › オーディオ設定...` を開きます。
2. `ドライバー` を選びます。ボックスの下の注記に、そのドライバーの向いている用途が書かれています。
3. `出力デバイス` を選びます。
4. `テストサウンドを再生` をクリックします。
5. `状態` の欄を読みます。動作中のドライバー、サンプルレート、出力レイテンシーが表示されます。デバイスが開いていない場合は `開いているオーディオデバイスがありません: 出力デバイスを選択してください。` と表示されます。

## ドライバー

`ドライバー` ボックスには、お使いのシステムのドライバーの種類が並びます。

| システム | ドライバー | 働き |
|---|---|---|
| Windows | Windows Audio (共有) | 他のプログラムの音も鳴り続けます。Windowsがすべてのプログラムを一定の間隔でミックスするため、バッファーはその間隔より小さくできません |
| Windows | Windows Audio (共有、低レイテンシー周期) | 共有ですが、Windowsにより短いミックス周期を要求します。対応しているドライバーは一部だけです |
| Windows | Windows Audio (排他、最低レイテンシー) | LYNX SHAREがデバイスを単独で使います。再生中は他のプログラムが無音になります |
| Windows | DirectSound (レガシー) | レイテンシーの高い、古いWindowsのオーディオ経路です。他のドライバーがうまく動かないときに使います |
| Windows | ASIO | 低レイテンシーのドライバーです。メーカー製のASIOドライバーは、そのメーカーのデバイスで動作します |
| Windows | LYNX ASIO (内蔵) | LYNX SHARE独自のASIOドライバーで、どのデバイスでも再生と録音に使えます。`ドライバー設定...` で共有モードか排他モードか、使うデバイスを選びます |
| macOS | Core Audio | システム標準のオーディオで、他のプログラムと共有されます |
| Linux | PipeWire (ネイティブ) | LYNX SHAREがPipeWireと直接やり取りします。`System default` は、システムのサウンド設定で選んだ出力に従います |
| Linux | JACK / PipeWire | 起動中のJACKサーバー、または `pipewire-jack` を使うPipeWire向けです |
| Linux | ALSA | サウンドカードと直接やり取りします。`default` や `pipewire` はデバイスを共有し、`hw:` デバイスはカードをLYNX SHAREだけで使います |

Linuxでは、初回起動時にPipeWire、JACK、ALSAのうち、デバイスのある最初のものが開きます。選んだ内容は保存されます。

## ページの設定項目

| 設定 | 働き |
|---|---|
| `ドライバー` | ドライバーの種類。上の表から選びます |
| `出力デバイス` | マスターを再生する先 |
| `入力デバイス` | オーディオ録音とミキサーインサート入力の入力元。既定は `(なし)` です |
| `サンプルレート` | デバイスが対応するレート |
| `バッファーサイズ` | デバイスが対応するサイズ。それぞれのレイテンシーがミリ秒で表示されます。バッファーが小さいほど、演奏への反応が速くなります。大きいとCPUに余裕ができ、クリック音が出にくくなります |
| `ドライバー設定...` | ドライバー独自のウィンドウを開きます (ASIOドライバー) |
| `テストサウンドを再生` | 出力デバイスからテストサウンドを再生します |
| `入力オーディオを録音` | 録音待機中のインサートがないとき、入力の最初の2チャンネルを新しいインサートに録音します |
| `ファイル形式` | 録音は、デバイスのサンプルレートで、WAV 24ビットまたはWAV 32ビット浮動小数点になります |
| `ラウンドトリップを計測` | `Ping出力` から `Ping入力` へケーブルまたはループバック経由で8回のクリックを再生して遅延を測り、テイクが演奏した位置に収まるようにします |
| `微調整 (サンプル)` | 新しいテイクすべてをずらします。正の値ほどプレイリスト上で前になります |
| `メトロノームのトラック` | メトロノームを鳴らすミキサーのトラック。`---` はマスターです。クリックがエクスポートに入ることはありません |
| `トランスポート時に途中のノートを再生` | 開始位置をまたぐノートを再生します |
| `トランスポート時にプラグインをリセット` | 再生の開始時やジャンプ時に、エフェクトのテールを消去します |

## 音が出ないとき

- まず `状態` を見ます。デバイスが開いていなければ、出力デバイスを選びます。
- 別のドライバーを試します。Windowsでは、`Windows Audio (共有)` なら他のプログラムの音が鳴り続け、`DirectSound (レガシー)` は他のドライバーがうまく動かないときのためにあります。
- [ミキサー](/wiki/mixer/)のマスターフェーダーと、ツールバーの `マスター` ノブを確認します。
- パターンモードでは、現在のパターンだけが鳴ります。空なら何も聞こえません。`L` を押すとソングモードになります。
- Linuxで音が途切れる場合は、オーディオスレッドがリアルタイム優先度を得られたかどうかが `状態` に表示されます。対処法は[トラブルシューティング](/wiki/troubleshooting/)にあります。

## 知っておくと便利なこと

- ASIOはWindowsにしかありません。
- `Windows Audio (共有)` では、最小のバッファーはシステムのミックス間隔です。お使いのデバイスでの値は、`ドライバー` ボックスの下の注記に出ています。レイテンシーをもっと下げるには、排他モードかASIOドライバーを使います。
- PipeWireでは、バッファーは32～2048サンプル、サンプルレートは44.1～192 kHzです。PipeWireが独自のレートを保つ場合は、LYNX SHAREのストリームがリサンプリングされます。
- PipeWireで名前を指定したデバイスを取り外すと、LYNX SHAREは `System default` に切り替わり、バッファーサイズはそのまま保たれます。
- `状態` には、オーディオのCPU負荷も表示され、音切れ (バッファーアンダーラン) も数えられます。
- ウィンドウを開かなくても、ドライバーとデバイスの一覧を表示できます。[コマンドライン](/wiki/command-line/)の `--devices` をご覧ください。
