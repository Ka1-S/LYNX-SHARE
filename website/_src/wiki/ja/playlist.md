![トラックにクリップが並ぶプレイリスト](/assets/img/playlist.webp)

プレイリストは、パターンを曲にする場所です。トラックには3種類のクリップを置けます。パターンクリップ、オーディオクリップ、オートメーションクリップです。`F5` で表示と非表示を切り替え、`Enter` で最大化と元のサイズへの復帰ができます。

トランスポートには2つのモードがあります。パターンモードは現在のパターンをループ再生し、ソングモードはプレイリストを再生します。`L` で切り替えます。

## パターンを曲に置く

1. `F5` を押してプレイリストを表示します。
2. ピッカーパネルで、パターンをクリックします。ピッカーにはプロジェクトのパターン、オーディオ、オートメーションが並び、クリックしたものがクリップソースになります。
3. `P` を押してペンシルにします。
4. トラックをクリックして、クリップを置きます。ボタンを押したままドラッグすると、位置を調整できます。
5. `B` を押してブラシにし、トラックに沿ってドラッグすると、クリップを端から端まで並べて描けます。
6. `L` でソングモードにして、`Space` で再生します。

オーディオファイルは、[ブラウザー](/wiki/browser/)からプレイリストにドラッグできます。

## ツール

![プレイリストのツールバー。アレンジメントボックス、ツール、スナップボックスがある](/assets/img/wiki/playlist-tools.webp)

文字キーは、タイピングキーボードのピアノ (`Ctrl+T`) がオフのときに働きます。

| ツール | キー | 働き |
|---|---|---|
| ペンシル | `P` | クリックで、ピッカーのクリップを置く |
| ブラシ | `B` | ドラッグで、クリップを端から端まで並べて描く |
| 消しゴム | `D` | クリックまたはドラッグで削除する |
| ミュート | `T` | クリックまたはドラッグで、クリップをミュートまたは解除する |
| ナイフ | `C` | ドラッグした線でクリップを横切って切る。クリックでその位置で切る |
| 投げ縄 | `E` | ドラッグで選択ボックスを描く。`Shift` で追加する |
| ズーム | `Z` | クリックでズームイン、範囲をドラッグでその範囲にズーム、右クリックでズームアウト |
| リッスン | `Y` | クリックまたはドラッグで、その位置から再生する |
| スリップ | `S` | ドラッグで、クリップの中身をクリップ内でずらす |

## クリップの扱い

- クリップをドラッグすると移動します。`Shift`+ドラッグでコピーを作ります。
- クリップの端をドラッグすると、サイズが変わります。始点をドラッグすると、中身はそのままでトリムされます。
- 右クリックで、クリップを削除します。`Ctrl`+ドラッグで選択します。
- クリップをダブルクリックすると、開きます。
- クリップの左上のボタンで、クリップメニューが開きます (ユニーク化、名前とカラーの変更、チョップ、オーディオの場合はピッチ、テンポに合わせる、リバース)。
- オーディオクリップのメニューは、FL Studioの構成に従った2列です。左の列には、`オーディオクリップ` セクション(`プレビュー`、`ミュート中`、`名前とカラーを変更...`、`色を変更...`、`ランダムなカラー`、`アイコンを変更...`、`ソースチャンネルを選択`、`チャンネル設定`、`ユニーク化`、`類似クリップをすべて選択`、`Delete`、`プロパティ...`)と `リージョン` セクション(`リージョンを選択`、`チョップ`)があります。右の列には、`サンプル`(`サンプルとしてユニーク化`、`サンプルを編集`、`サンプルからステムを抽出`、`テンポを検出`、`テンポに合わせる`)、`オートメーション`(`オートメーション › パン` または `ボリューム`、`クロスフェード先`)、`フェード`(`フェードをリセット`)があります。`ここで分割`、`リバース`、`ノーマライズ`、`MIDI に変換` など、LYNX SHARE独自の項目は、線の下の最後に置かれます。
- `オートメーション › パン` または `ボリューム` は、チャンネルのLevels adjustmentのパンまたはボリューム用に、そのトラック上へオーディオクリップと同じ長さのオートメーションクリップを作ります。
- ドラッグ中に `Alt` を押し続けると、スナップを無視します。
- オーディオクリップには、フェードハンドルと、上下にドラッグするクリップゲインがあります。フェードハンドルを右クリックすると、`クロスフェードを作成` を含むメニューが開きます。ゲインハンドルを右クリックすると、`ゲインをリセット` と `ノーマライズ` があります。
- `Shift+M` でストレッチを切り替えます。オンのときにオーディオクリップのサイズを変えると、オーディオが切り取られず、引き伸ばされます。
- `Shift+Left` と `Shift+Right` は、選択したクリップをスナップ1つ分、`Shift+Up` と `Shift+Down` は1トラック分動かします。`Alt+Left` と `Alt+Right` は、スナップなしで、現在のズームでの画面1ピクセル分動かします。クリップを選択していないときは、すべてのクリップが動きます。
- オーディオクリップのメニューにある `サンプルとしてユニーク化` は、そのクリップが鳴らしていた内容を持つ新しいファイルをクリップに割り当てます。ピッチ、ストレッチ、リバースは、すでにオーディオに反映されています。
- ワープマーカーを持つオーディオクリップでは、上端に小さな旗として表示されます。旗を横にドラッグすると、マーカーが動きます。

## EditメニューとSelectメニュー

プレイリストのメニューには、`編集` と `選択` のサブメニューがあります。`編集` にはクリップのコマンドがあります。カット、コピー、ペースト、`左へシフト`、`右へシフト`、`上へずらす`、`下へずらす`、`ユニーク化`、`サンプルとしてユニーク化`、`スペースを挿入`、`スペースを削除`、結合のコマンド、フェードのオプションです。`選択` には、`選択したソースで選択` (`Shift+C`)、`選択を反転` (`Shift+I`)、`選択解除` (`Ctrl+D`)、ミュートされたクリップと重なっているクリップ、`マジックラッソ` があります。`マジックラッソ` をオンにすると、ボタンを押さずにマウスをクリップの周りで輪を描くように動かして、クリップを選択できます。

## トラック

トラックのヘッダーでは、クリックで選択、`Ctrl`+クリックで追加または解除、`Shift`+クリックで範囲を選択、右クリックでトラックメニューが開きます。`Shift`+ホイールで、トラックを上下に動かします。トラックのライトは、クリックでミュート、`Ctrl`+クリックまたは右クリックでソロです。2つのトラックの間の区切りをドラッグすると片方のサイズが変わり、`Shift`+ドラッグではすべてのトラックのサイズが変わります。

プレイリストのメニューの `表示` で、トラックヘッダーに何を表示するかを選びます。`オーディオトラックにコントロールを表示`、`オーディオトラックにレベルを表示`、`インストゥルメントトラックにレベルを表示` です。

トラックメニューの `トラックモード` は、FL Studioと同じように、トラックを `未割り当て`、`オーディオトラック`、`インストゥルメントトラック` のいずれかにします。`オーディオトラック` は、最初に `新しいミキサートラック` を、続いて、すべてのミキサーインサートを番号と名前の順に並べます。選択はすべての選択中のトラックに適用されます。`インストゥルメントトラック` には、`既存のチャンネルを使用`、`その他のプラグイン...`、チャンネルラックのインストゥルメントのリストがあります。

トラックヘッダーの左上にある `+` は、新しいトラックについて同じ選択肢を開きます。`オーディオトラックを追加`、`その他のプラグイン...`、インストゥルメントです。`+` を右クリックすると、すぐにオーディオトラックが追加されます。

## パターンブロック

プレイリストのメニューで `パターンブロック（現在のプロジェクト）` をオンにすると、トラックの下のセクションに、パターンごとに1行が並びます。ここでは、鉛筆ツールでブロックを1つ置いて行に沿ってドラッグでき、ブラシでブロックを塗り、消しゴムでブロックを削除します。どのツールでも、右クリックで消せます。

## ルーラー、ループ、マーカー

- ルーラーをクリックすると、ソングの位置が決まります。
- ルーラーで右ドラッグ、`Ctrl`+ドラッグ、またはダブルクリックしてドラッグすると、時間選択ができ、それがそのままループになります。`Shift`+ドラッグで動かせます。
- `Ctrl+Ins` で、時間選択の長さ分を全トラックに挿入し、`Ctrl+Del` で取り除きます。
- `Alt+T` でマーカーを追加します。マーカーをクリックすると、そこへジャンプします。
- `Ctrl`+ホイールでズーム、`Alt`+ホイールでトラックの高さが変わります。

## オートメーション

ノブまたはフェーダーを右クリックして、`オートメーションクリップを作成` を選びます。クリップがプレイリストに現れます。ペンシルで、ポイントをドラッグして動かし、カーブをクリックしてポイントを追加します。トラックの下のオートメーションレーンは任意で、初期設定ではオフです。[オートメーション](/wiki/automation/)を参照してください。

点を右クリックすると、そのメニューが開きます。`モード` リストには、その点で終わるセグメント用の、FL Studioの13種類のカーブモードがあります。`スムーズ`、`ホールド`、3種類のシングルカーブ、3種類のダブルカーブ、`ハーフサイン`、`階段`、`スムーズな階段`、`パルス`、`ウェーブ` です。新しい点には、最後に使ったモードが適用されます。モードは.flpファイルから読み込まれ、.flpファイルへ書き込まれます。

## アレンジメント

ツールバーのアレンジメントボックスで、アレンジメントを切り替えます。1つのプロジェクトに複数のアレンジメントを持てます。

| コマンド | キー | 働き |
|---|---|---|
| すべて選択 | `Ctrl+A` | すべてのクリップを選択する |
| コピー、カット、貼り付け | `Ctrl+C` / `Ctrl+X` / `Ctrl+V` | クリップをコピー、カット、貼り付けする |
| 複製 | `Ctrl+B` | 選択範囲を複製する |
| 削除 | `Del` | 選択中のクリップを削除する |
| リップル削除 | `Shift+Del` | 選択中のクリップを削除して、隙間を詰める |
| リップル編集 | `Shift+S` | リップル編集をオンまたはオフにする |
| ミュート、ミュート解除 | `Alt+M` / `Shift+Alt+M` | 選択中のクリップをミュートまたは解除する |
| クリップをシフト | `Shift+Left` / `Shift+Right` | 選択したクリップをスナップ1つ分動かします |
| 別のトラックへシフト | `Shift+Up` / `Shift+Down` | 選択したクリップを1トラック分動かします |
| クリップをナッジ | `Alt+Left` / `Alt+Right` | 選択したクリップを、スナップなしで画面1ピクセル分動かします |
| ユニーク化 | `Ctrl+Shift+V` | 選択中のクリップをユニークにする |
| 結合 | `Ctrl+G` | パターンクリップを結合する |
| ストレッチ | `Shift+M` | オーディオクリップのサイズ変更時のストレッチを切り替える |
| 時間を挿入 | `Ctrl+Ins` | 時間選択の長さ分を、全トラックに挿入する |
| 時間を削除 | `Ctrl+Del` | 時間選択の範囲を、全トラックから取り除く |
| マーカーを追加 | `Alt+T` | マーカーを追加する |

| 最大化 | `Enter` | プレイリストを最大化、または元に戻す |

## 知っておくと便利なこと

- プレイリストが聞こえるのは、ソングモードのときだけです。パターンモードでは、トラックに何があっても、`Space` は現在のパターンを再生します。
- `表示 › レイアウトスタイル › クリップ起動ワークフロー` で、プレイリストの横にクリップとシーンのグリッドが加わります。任意の機能です。[レイアウト](/wiki/layouts/)を参照してください。
- 1つのコントロールに重なったオートメーションクリップが複数あるとき、どれが働くかの選択は、FL Studioと異なることがあります (0.1.25のリリースノート)。
- FL Studioと同じく、パターンは一度に1つのクリップから再生されます。同じパターンの後のクリップが、どのトラックでも始まると、先のクリップは、そこからは新しいノートを始めなくなります。異なるパターンのクリップは一緒に再生されます。これは新しいプロジェクトにもFL Studioプロジェクトにも当てはまります。0.1.27より前に保存した.lynxプロジェクトは、すべてのクリップを最後まで再生し続けます。
- リンクしたMIDIコントローラーで動かしたテンポは、オーディオクリップのサイズを変えません。
- Linuxでビデオを扱うには、FFmpegが必要です。
