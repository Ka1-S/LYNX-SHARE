LYNX SHAREは、慣れ親しんだワークフローをそのまま残しています。チャンネルラック、パターン、プレイリスト、ミキサーがあり、キーも同じです。`.flp` プロジェクトを直接開け、書き戻すこともできます。

LYNX SHAREは独立したプログラムです。Image-Lineとは提携しておらず、承認も後援も受けておらず、Image-Lineのコードは含まれていません。FL Studioは、Image-Line Softwareの登録商標です。

## .flpプロジェクトを開く

1. `ファイル › 開く...` (`Ctrl+O`) を選び、`.flp` を指定します。
2. LYNX SHAREがプロジェクトのプラグインとサンプルを解決してから開きます。タイトルには「(imported from FL Studio)」と表示されます。
3. `ヘルプ › Last FL Studio import report` を選ぶと、近似されたもの、省かれたもの、見つからなかったものが読めます。
4. `ヘルプ › 見つからないファイル...` を選ぶと、見つからないサンプルとプラグインが分かります。
5. `ファイル › 保存` を選びます。`.lynx` ファイルの保存先を尋ねられます。`.flp` 自体が書き換えられることはありません。

## 何が何に対応するか

| FL Studio | LYNX SHARE |
|---|---|
| プレイリスト、チャンネルラック、ピアノロール、ミキサー | 同じ名前で、`F5`、`F6`、`F7`、`F9` |
| プラグインピッカー | `F8` |
| ブラウザー | `Alt+F8` |
| パターン / ソングモード | `L` |
| 元に戻す | `Ctrl+Z` で元に戻し、元に戻した後はやり直します。`Ctrl+Alt+Z` はさかのぼって元に戻します |
| 新しいバージョンを保存 | `Ctrl+Alt+S` |
| エクスポート | `Ctrl+R`、MP3は `Ctrl+Shift+R`、MIDIは `Ctrl+Shift+M` |
| ミキサーのインサート、センド、サイドチェーン | 同じです。インサートごとのエフェクトスロットは10個 |
| Fruity Wrapper | サードパーティのプラグインは直接ホストします。[サードパーティのプラグイン](/wiki/plugins/)をご覧ください |
| ネイティブのジェネレーターとエフェクト | LYNX SHAREが再現したエンジンで再生します。下を参照してください |
| `.flp` プロジェクトファイル | `.lynx` プロジェクトファイル |

すべてのキーは `ヘルプ › ショートカット` に一覧があります。

## インポートされるもの

- チャンネル、サンプル、パターン、スライドノートとポルタノート、すべてのアレンジメント、マーカー、拍子の変更、オートメーション、コントローラーのリンク。
- ミキサー: ルーティング、レベル、サイドチェーン、トラックEQ、保存された設定付きのネイティブエフェクト。
- Fruity Wrapper内のサードパーティのVST3、VST2、CLAPプラグイン: お使いのコンピューターにインストールされている同じプラグインに、保存された状態ごと置き換えられます。

## FL Studioのネイティブプラグイン

FL Studio自身のジェネレーターとエフェクトは読み込まれません。LYNX SHAREは、再現したエンジンでそれらを再生し、それぞれに品質レベルがあります。

| レベル | 意味 |
|---|---|
| Exact | テストしたすべての状態で、オリジナルとビット単位で一致 |
| Near-exact | ほとんどの状態でビット単位で一致し、残りの差は約 -100 dB以下 |
| Close | 同じアルゴリズムで、テストしたほぼすべての状態でオリジナルとの差が -60 dB以内 |
| Approximate | 保存された設定を、LYNX SHAREの内蔵シンセまたはエフェクトに割り当て |
| Placeholder | 状態は保持され、プラグインは無音か、オーディオをそのまま通します |

すべてのエンジンのレベルと、それぞれにまだ足りないものは、[PLUGINS.md](https://github.com/Ka1-S/LYNX-SHARE/blob/main/docs/PLUGINS.md)にあります。[内蔵のインストゥルメントとエフェクト](/wiki/built-in/)もご覧ください。

## お使いのFL Studioのインストールが必要なもの

`.flp` を開くのに、FL Studioのインストールは必要ありません。同じコンピューターにインストールがあると、次の2つが加わります。

- FL Studioの付属サンプルとプラグインデータベース。これにより、スキャンなしでサンプルとプラグインが見つかります。
- 一部のエンジンが必要とする内蔵の波形、サンプル、インパルス、テーブル (FL Keys、Soundgoodizer、Maximus、そのほかPLUGINS.mdで剣標が付いているもの)。実行時にお使いのインストールから読み込まれ、LYNX SHAREには同梱されていません。

Linuxでは、LYNX SHAREはWine上のWindows版FL Studioを探します。macOSではアプリバンドルを探しますが、動作は未確認です。

## .flpへ書き出して戻す

1. `ファイル › エクスポート › FL Studio プロジェクト...` を選びます。
2. `FL Studio プロジェクト (.flp)` または `Zip ループパッケージ (.zip、すべてのサンプル付き)` を選びます。
3. FL Studioにないものの扱いを選びます。オーディオにレンダリングする (同じ音になります)、または最も近いFLプラグインを使う (編集可能のままですが、音が変わることがあります。LYNX専用のインストゥルメントは省かれます) のどちらかです。

ファイルはFL Studio 2026のプロジェクトです。サンプラー、オーディオクリップ、FL自身のジェネレーターとエフェクト、サードパーティのプラグイン (Fruity Wrapper内)、パターン、プレイリスト、ミキサー、オートメーションが、設定ごと移ります。レポートには、正確に移ったもの、レンダリングされたもの、置き換えられたもの、省かれたものが一覧されます。

## FL Studio Mobile (.flm)

`ファイル › 開く...` は `.flm` プロジェクトも開けます。インポートは部分的です。

- インポートされるもの: テンポ、拍子、FLMのチャンネルごとに1つのミキサーインサート、レーンごとに1つのプレイリストのトラック、パターン (ループの各パスが1つのクリップ)、オフセットとピッチ付きのオーディオクリップ、ドラムキット、DW Samplerと `.dwp` プログラムとSlicer (FLM自身のエンジンで)、MiniSynth、Transistor Bass、3x Osc、GMSynth、SuperSawのインストゥルメント、FLMのエフェクト (Pocketエフェクトとして)、レベル、パン、ミュート、ソロ、ピッチベンド、センド、インストゥルメントのパラメーターのオートメーション、そしてコードセットとキーロッカー。
- インポートされないもの: FLMのほかのインストゥルメント。内蔵シンセで再生されます。
- サンプルは、`.flm` の隣と、FL StudioにあるFLMリソースのコピーから探されます。見つからない `.dwp` は、代用品で再生されます。

## 知っておくと便利なこと

- FLEXパックは暗号化されており、開かれることはありません。FLEXのチャンネルには、プリセット名から選ばれたシンセのパッチが付きます。
- モジュレーターは `.flp` のエクスポートから除外され、エクスポートレポートにもそう書かれます。
- インポートレポートには、内蔵シンセで近似されたもの、対応するものがなかったもの、見つかったプラグインとインストールされていないプラグイン、省かれた、または部分的に再現されたエフェクト、見つからないサンプルの数が一覧されます。
- インストールされていないサードパーティのエフェクトは、同じ役割のLYNX SHAREのエフェクトに置き換えられます。元のエフェクトはプロジェクトに残ります。
