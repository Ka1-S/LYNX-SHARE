![ピアノロール](/assets/img/pianoroll.webp)

ピアノロールには、現在のパターンにある1つのチャンネルのノートが表示されます。左に鍵盤、下にノートごとの値のレーンがあります。`F7` で表示と非表示を切り替えるか、[チャンネルラック](/wiki/channel-rack/)のチャンネルのメニューで `ピアノロール` を選びます。

ツールバーのチャンネルボックスで、編集するチャンネルを選びます。このパターンにノートがあるチャンネルには印が付きます。ボックスの上でホイールを回すと、ノートのあるチャンネルを順に切り替え、`Ctrl` + ホイールではすべてのチャンネルを順に切り替えます。

## ノートを書く

1. チャンネルラックで、チャンネル名を右クリックして `ピアノロール` を選びます。
2. `P` を押してペンシルにします。
3. グリッドをクリックしてノートを追加します。ボタンを押したままドラッグすると、位置を決められます。
4. ノートの端をドラッグして、長くしたり短くしたりします。
5. ノートを右クリックすると削除されます。
6. `Space` を押すと、パターンが聴けます。

## ツール

![チャンネルボックス、ツール、スナップボックスのあるピアノロールのツールバー](/assets/img/wiki/pianoroll-tools.webp)

各ツールには文字キーがあります。この文字キーは、タイピングキーボードのピアノ (`Ctrl+T`) がオフのときに働きます。

| ツール | キー | 働き |
|---|---|---|
| ペンシル | `P` | クリックでノートを追加し、ドラッグで位置を決めます |
| ブラシ | `B` | ドラッグでノートの列を描きます。`Shift` を押すと1つずつです |
| ドラムブラシ | `N` | マウス下の鍵で、グリッドのセルごとに1回のヒットを置きます |
| 消しゴム | `D` | クリックまたはドラッグで削除します |
| ミュート | `T` | クリックまたはドラッグで、ノートをミュートまたは解除します |
| ナイフ | `C` | ドラッグで線を引いてノートを横切って切ります。クリックでその点で切ります |
| 投げ縄 | `E` | ドラッグで選択ボックスを描きます。`Shift` で追加します |
| ズーム | `Z` | クリックでズームイン、範囲をドラッグするとその範囲にズームし、右クリックでズームアウトします |
| リッスン | `Y` | クリックまたはドラッグで、カーソル下のノートを鳴らします |

## ノートの操作

- ノートをドラッグして動かします。`Shift` + ドラッグでコピーを作ります。
- ノートの端をドラッグして、サイズを変えます。始点もドラッグでき、その場合は終点が動きません。
- どのツールでも、右クリックでノートを削除します。
- ノートをダブルクリックすると、そのプロパティが開きます。
- ノートの上で `Alt` + ホイールを回すと、ベロシティが変わります。
- `Ctrl` + ドラッグで選択します。`Ctrl` + クリックで、ノートを選択に加えたり、外したりします。
- `Alt` を押しながらドラッグすると、スナップを無視します。`Backspace` でスナップをオフ、オンに切り替えます。
- 複数のノートを選んでいるときは、ストレッチハンドルで、時間方向に伸ばしたり縮めたりできます。

## 鍵盤とルーラー

鍵盤のキーをクリックすると、その音が聴けます。キーの右寄りほど音が大きくなります。キーを `Ctrl` + クリックすると、そのキーのノートが選択されます。鍵盤の上で中ボタンをドラッグすると、キーが高く、または低くなります。

ルーラーをクリックして、位置を決めます。ルーラーの上で `Ctrl` + ドラッグ、右ドラッグ、またはダブルクリックしてドラッグすると、時間範囲のノートが選択されます。`Ctrl` + ホイールでズーム、`Shift` + ホイールでスクロールします。

## ツールバー

| 設定 | 働き |
|---|---|
| スナップ | 「メイン」はメインツールバーのスナップに従います。このウィンドウ専用のものを選ぶこともできます。 |
| コード | クリックすると、クリックしたノートをルートとして、選んだコードが作られます。`Shift+N` で単音に戻ります。 |
| スケール | スケールのノートをハイライトします。別のボタンで、新しいノート、動かしたノート、入力されるMIDIを、選んだスケールにスナップします。 |
| スライド (`S`) | 新しいノートがスライドノートになります。鳴っているノートが、そこへ滑らかに移ります (808グライド)。 |
| ゴーストノート (`Alt+V`) | ほかのチャンネルのノートを、自分のノートの後ろに表示します。 |
| ノートカラー | 新しいノートにこのカラーが付きます。全部で16色です。 |
| 追従 | パターンの再生中、表示が再生ヘッドに合わせてスクロールします。 |
| レーンボックス | 下のレーンで何を編集するかを選びます。ベロシティ、パン、ファインピッチです。 |

## キー

| コマンド | キー | 働き |
|---|---|---|
| すべて選択 | `Ctrl+A` | すべてのノートを選択します |
| 選択解除 | `Ctrl+D` または `Esc` | 選択をクリアします |
| コピー、カット、ペースト | `Ctrl+C` / `Ctrl+X` / `Ctrl+V` | ノートをコピー、カット、ペーストします |
| 複製 | `Ctrl+B` | 選択範囲を複製します |
| 削除 | `Del` | 選択範囲を削除します |
| トランスポーズ | `Up` / `Down` | 選択範囲を半音動かします |
| オクターブ単位でトランスポーズ | `Ctrl+Up` / `Ctrl+Down` | 選択範囲を1オクターブ動かします |
| ナッジ | `Left` / `Right` | 選択範囲をグリッド1つ分動かします |
| クイッククオンタイズ | `Ctrl+Q` | 開始位置と長さをクオンタイズします |
| 開始位置をクオンタイズ | `Shift+Q` | 開始位置だけをクオンタイズします |
| チョップ | `Ctrl+U` | ノートをグリッドで切り分けます |
| グルー | `Ctrl+G` | 接しているノートをつなげます |
| レガート | `Ctrl+L` | 各ノートを、次のノートまで伸ばします |
| ミュート、ミュート解除 | `Alt+M` / `Shift+Alt+M` | 選択範囲をミュート、またはミュート解除します |
| MIDIをインポート | `Ctrl+M` | MIDIファイルをこのチャンネルにインポートします |
| MIDIをエクスポート | `Ctrl+Shift+M` | パターンをMIDIファイルとしてエクスポートします |
| ズーム | `PageUp` / `PageDown` | ズームインまたはズームアウトします |

ノートのツール (アルペジエート、ストラム、反転、ランダム化、クオンタイズ、チョップなど) はダイアログを開きます。そのキーは[ショートカット](/wiki/shortcuts/)のページにあります。

## 知っておくと便利なこと

- ピアノロールには、1つのパターンの1つのチャンネルが表示されます。現在のパターンを切り替えると、そのパターンのノートが表示されます。
- タイピングキーボードのピアノ (`Ctrl+T`) がオンの間は、ツールの文字キーは何もしません。
- どのツールでも右クリックで削除できるので、ノート1つのために消しゴムに切り替える必要はありません。
- ここでは `S` がスライドのスイッチです。プレイリストでは同じ文字がスリップツールです。
- 通常のステップでないノート (別のキー、長いノート、スライド) があると、チャンネルラックのそのチャンネルの行には、ステップボタンではなくミニチュアが表示されます。
