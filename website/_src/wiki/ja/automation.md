![6小節かけて上昇するカーブを表示したオートメーションエディター](/assets/img/wiki/automation.webp)

オートメーションクリップは、[プレイリスト](/wiki/playlist/)上のカーブで、曲の再生中に1つのコントロールを動かします。対象はチャンネルのボリューム、ミキサーのフェーダー、プラグインのパラメーター、テンポなどです。クリップには専用のエディターウィンドウ、オートメーションエディターがあります。

コントロールを動かす方法は、ほかに3つあります。イベントは、パターンの中に保存された値です。リンクは、MIDIのノブや内部コントローラーでコントロールを動かします。モジュレーターは、ノブを元の値のまわりで揺らします。

## ノブをオートメーションする

1. オートメーションを始めたい位置に再生ヘッドを動かすか、プレイリストで時間範囲を選びます。
2. ノブまたはフェーダーを右クリックして、`オートメーションクリップを作成` を選びます。
3. クリップは最初の空いているプレイリストのトラックに置かれ、オートメーションエディターが開きます。カーブは、コントロールの現在値の平らな線から始まります。
4. エディター内をクリックしてポイントを追加し、ドラッグして位置を決めます。
5. `Alt` を押しながらセグメントを上下にドラッグすると、カーブを曲げられます。
6. ソングモードで曲を再生します。コントロールがカーブに沿って動きます。

同じクリップは、次の方法でも作れます。

- `追加 › 最後に操作したパラメーターのオートメーション` は、最後に動かしたコントロールのクリップを作ります。
- 最後に操作したコントロールの表示欄と `ツール › 最後に操作` は、コントロールを右クリックしたときと同じメニューを開きます。
- サードパーティのプラグインでは、チャンネルラックのチャンネルメニューか、ミキサーのエフェクトスロットのメニューを開いて `プラグインのパラメーターをオートメーション` を使います。その隣に `MIDIコントローラーをオートメーション (CC、アフタータッチ、ピッチベンド)` があります。

エディターをもう一度開くには、クリップをダブルクリックするか、右クリックして `ポイントを編集...` を選びます。コントロール自身のメニューにある `オートメーションクリップを編集...` でも同じです。

## オートメーションエディター

| コマンド | キー | 働き |
|---|---|---|
| 新しいポイント | クリックまたは右クリックしてからドラッグ | ポイントを追加し、ボタンを押している間は動かせます |
| ポイントを動かす | ドラッグ | `Shift` で時間を固定、`Ctrl` で値を固定、`Alt` でスナップを無視します |
| セグメントを曲げる | `Alt` + 上下にドラッグ | マウス下のセグメントのテンションを変えます |
| テンションハンドル | 上下にドラッグ | セグメントを曲げます。`Ctrl` でより細かく、右クリックで直線になります |
| カーブ上のポイント | `Shift` + 右クリック | 線の上にポイントを追加します |
| ポイントメニュー | ポイントを右クリック | `値を入力...`、`値をコピー`、`値を貼り付け`、`ポイントを削除`、そして全体をスケール、反転、直線化する `カーブ全体` |
| ズーム | `Ctrl` + ホイール | 表示をズームします |
| スクロール | 中ボタンでドラッグ | 表示を動かします |

## LFOモード

![三角波と SPD、TNS、SKEW、PW、AMNT のノブを表示した、LFOモードのオートメーションエディター](/assets/img/wiki/automation-lfo.webp)

エディター上部の `LFO` にチェックを入れます。すると波形がクリップの値を形づくり、描いたポイントは値そのものではなくLFOの振幅を決めます。

| 設定 | 働き |
|---|---|
| `SPD` | 1周期の長さ (拍単位) |
| `TNS` | 波のテンション |
| `SKEW` | 波の歪み |
| `PW` | パルス幅 |
| `AMNT` | LFOが値を動かす幅 |
| `MUL` | オン: LFOにエンベロープのレベルを掛けます。オフ: 加算します |

## パターン内のイベント

![ボリュームのイベントをバーで描いたイベントエディター](/assets/img/wiki/eventeditor.webp)

イベントはパターンに属し、そのパターンが再生される場所ならどこでも再生されます。コントロールを右クリックして `パターン内のイベントを編集` を選ぶと、そのコントロールのイベントエディターが開きます。

- `描画` はドラッグに合わせて値を設定し、右ドラッグで消去します。`ライン` は直線のランプを描きます。`選択` は下部のツール用に時間範囲を選びます。
- `スナップ` は 1/2 ステップから 1 小節まで選べます。
- `スケール`、`オフセット`、`ランダム化` は、選択範囲、またはパターン全体のイベントを変更します。
- `LFO` は、1 拍から 4 小節までのサイン波、三角波、矩形波を書き込みます。
- `クリア` はイベントを削除します。
- `オートメーションへ...` はイベントをオートメーションクリップに変換し、パターンから削除します。
- `ファイル` はイベントを `.fsc` ファイルとして開いたり保存したりでき、MIDIファイルのインポートもできます。

同じ右クリックメニューにある `この位置でソングを初期化` は、曲が始まるたびにコントロールがリセットされる値を保存します。

## 動きを録音する

録音フィルターで `オートメーション` にチェックを入れて録音をオンにし、再生を押してコントロールを動かします。ソングモードでは、動きがオートメーションクリップになります。パターンモードでは、現在のパターンのイベントになります。[録音](/wiki/recording/)をご覧ください。

## リンクとモジュレーター

- `MIDIコントローラーにリンク (コントローラーのノブを動かす)` については、[MIDIコントローラー](/wiki/midi-controllers/)で説明しています。
- `内部コントローラーにリンク` を使うと、プロジェクト内のエンベロープ、Formula、Peak Controllerでコントロールを動かせます。先にそのいずれかを追加しておきます。
- `モジュレート` は、LYNX SHAREのノブを元の値のまわりで動かすモジュレーター (LFOまたはランダムソース) を取り付けます。`ツール › モジュレーター...` で一覧を見られます。

## オートメーションレーン

レーンは既定ではオフです。プレイリストのメニューで `オートメーションレーン` をオンにします。すると各トラックヘッダーに、トラックの下にレーンを追加するボタンが現れ、コントロールのメニューに `レーンでオートメーション` が加わります。レーンでは、クリックまたはドラッグでポイントを追加し、右クリックで削除し、`Alt` + ドラッグで線を曲げます。レーンのメニューには `オートメーションクリップに変換` があります。

## 知っておくと便利なこと

- 新しいクリップは、時間選択があればその位置から、なければソングモードでは再生ヘッドの位置から始まります。曲の先頭から始めたい場合は、`オプション › 全般設定...` の `オートメーションクリップを再生位置に作成` をオフにします。
- 1つのコントロールに複数のクリップがあると、それぞれ自分の位置で再生されます。最初のクリップより前では、コントロールは元の値のままです。
- クリップの開始時に、コントロールは約8 msで新しい値に達します。FL Studioはそこへなめらかに移動するため、読み込んだプロジェクトではその箇所がわずかに異なる場合があります。
- 同じコントロールのクリップが重なる場所では、LYNX SHAREが選ぶクリップとFL Studioが選ぶクリップが異なることがあります。
- モジュレーターはLYNX SHARE独自のノブでのみ動作し、`.flp` にエクスポートするときは除外されます。
