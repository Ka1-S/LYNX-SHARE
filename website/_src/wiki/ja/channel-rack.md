![ステップの行が並ぶチャンネルラック](/assets/img/rack.webp)

チャンネルラックには、プロジェクト内のすべてのインストゥルメント (チャンネル) が1行に1つずつ並び、現在のパターンのステップが表示されます。`F6` で表示と非表示を切り替えます。トランスポートのパターンボタンを右クリックしても表示されます。

## ドラムパターンを作る

1. `F6` を押してチャンネルラックを表示します。
2. 最後の行の下にある `+ チャンネルを追加` ボックスをクリックして、メニューからインストゥルメントを選びます。[ブラウザー](/wiki/browser/)でサンプルをダブルクリックしても、新しいサンプラーチャンネルができます。
3. チャンネルの行のステップをクリックして、オンにします。ドラッグすると、連続したステップを描けます。
4. ステップを右クリックすると、消えます。
5. `Space` で再生します。パターンモードでは、パターンがループします。
6. 行のボリュームノブをドラッグして、レベルを決めます。

## ステップを打ち込む

- ステップをクリックすると、オンになります。ドラッグすると連続したステップを描けます。点灯しているステップからドラッグを始めたときは、描く代わりに消します。
- 右クリックまたは右ドラッグで消します。
- パターンの終わりより後ろをクリックすると、ステップが追加され、パターンが長くなります。
- ノートが単純なステップではない行 (別のキー、長いノート、スライド) には、ノートのミニチュアが表示されます。クリックすると、[ピアノロール](/wiki/piano-roll/)でそのノートが開きます。
- オーディオファイルをラックにドロップして、チャンネルを作ることもできます。

チャンネルメニュー (チャンネル名を右クリック) には、`2ステップごとに埋める`、`4ステップごとに埋める`、`8ステップごとに埋める`、`高度なフィル`、`左に回転`、`右に回転` があります。

## グラフレーン

![Kickチャンネルの下に開いたグラフレーン。ステップごとに1本のベロシティバーがある](/assets/img/wiki/rack-graph.webp)

`Ctrl+K` で、選択中のチャンネルの下にグラフレーンが表示されます。左側のボタンで、編集する項目を選びます。ベロシティ、パン、リリース、ファインピッチ、Mod X、Mod Yのどれかです。ドラッグするとステップごとの値を設定でき、右ドラッグでランプを描けます。`Alt`+クリックで、そのステップをリセットします。

## 行の各部分

| パート | 働き |
|---|---|
| ミュートライト | クリックでミュートします。`Ctrl`+クリックまたは右クリックでソロにします。 |
| パンとボリュームのノブ | ドラッグまたはホイールで操作します。 |
| ルートボックス | ドラッグまたはホイールで、ミキサーのインサートを選びます。ダブルクリックすると、そのインサートがミキサーに表示されます。右クリックすると、次の空きインサートが割り当てられます。 |
| 名前ボタン | クリックで、チャンネルのエディターを開閉します。`Alt`+クリックなら、ほかのエディターを開いたままにします。`Ctrl`+クリックで試聴します。上下にドラッグすると並べ替えられます。右クリックでチャンネルメニューが開きます。 |
| セレクター | クリックで1つのチャンネルを選択します。`Ctrl`+クリックまたは右クリックで、追加または解除します。`Shift`+クリックで範囲を選択します。ダブルクリックですべて選択します。 |

## パターン

ラックが編集するのは、常に現在のパターンです。ラックのパターンセレクターに名前が表示されます。名前をクリックするとリストが出て、矢印でも切り替えられます。ラックのタイトルの上で `Shift`+ホイールを使っても、パターンが変わります。

ラックのパターン長ボックスで、長さを小節数で決めます (ドラッグまたはホイール)。ダブルクリックすると、ノートから自動で長さが決まります。

メインツールバーのスウィングノブは、すべてのチャンネルに効きます。チャンネルメニューの `スウィングミックス` で、1つのチャンネルがそれにどれだけ従うかを決めます。

| コマンド | キー | 働き |
|---|---|---|
| 次のパターン | `Numpad +` | 次のパターンを現在のパターンにする |
| 前のパターン | `Numpad -` | 前のパターンを現在のパターンにする |
| 次の空のパターン | `F4` | 次の空のパターンへ移り、名前を尋ねる |
| 名前とカラーを変更 | `F2` | 現在のパターンの名前とカラーを変更する |

## PCキーボードでノートを弾く

`Ctrl+T` で、タイピングキーボードがピアノになります。`Z` から `M` と `Q` から `P` までのキーで、選択中のチャンネルを演奏します。オンの間は、エディターの1文字ショートカットが一時停止します。

## キー

チャンネルラックにフォーカスがあるときに働きます。

| コマンド | キー | 働き |
|---|---|---|
| チャンネルを選択 | `Up` / `Down` | 上または下のチャンネルを選択する |
| 選択範囲を広げる | `Shift+Up` / `Shift+Down` | 上または下のチャンネルを選択に加える |
| チャンネルを移動 | `Alt+Up` / `Alt+Down` | 選択中のチャンネルを上または下へ動かす |
| すべて選択 | `Ctrl+A` | すべてのチャンネルを選択する |
| カット、コピー、貼り付け | `Ctrl+X` / `Ctrl+C` / `Ctrl+V` | 選択中のチャンネルのステップをカット、コピー、貼り付けする |
| ステップを回転 | `Ctrl+Shift+Left` / `Ctrl+Shift+Right` | 選択中のチャンネルのステップを回転する |
| 複製 | `Alt+C` | 選択中のチャンネルを複製する |
| 削除 | `Alt+Del` | 選択中のチャンネルを削除する |
| グループ化 | `Alt+G` | 選択中のチャンネルを新しいフィルターグループに入れる |
| ミキサーへルーティング | `Ctrl+L` | 選択中のチャンネルを、空いているミキサーのインサートへ送る |
| ミュート | `1` から `0` | チャンネル1から10をミュートまたは解除する |
| ソロ | `Ctrl+1` から `Ctrl+0` | チャンネル1から10をソロにする |
| グラフレーン | `Ctrl+K` | グラフレーンを表示または非表示にする |

## チャンネルメニューのその他の項目

`ピアノロール`、`名前とカラーを変更`、`置き換え` (インストゥルメントの入れ替え)、`複製`、`Delete`、`アルペジエーター`、`ループポイント`、`MIDIの書き込み先`、`チャンネルを並べ替え`、`未使用のチャンネルを選択`、`チャンネル設定`。

## 知っておくと便利なこと

- 追加メニューが開くのは、`+ チャンネルを追加` ボックスだけです。
- ラック自体にはパターンがありません。どこで現在のパターンを変えても、ラックの表示が変わります。
- ノートのミニチュアが表示されている行は、ステップとしては編集できません。ピアノロールで編集してください。
- 数字キーが届くのは、最初の10チャンネルだけです。
- 表のキーが働くには、ラックにフォーカスが必要です。先にラックをクリックしてください。
