![設定のMIDIページ。入力デバイス、マスター同期付きの出力デバイス、外部同期](/assets/img/wiki/settings-midi.webp)

LYNX SHAREは、あらゆるMIDI入力デバイスからノートとコントローラーの動きを受け取ります。デバイスは、設定のMIDIページで設定します。`オプション › MIDI設定...` か `F10` で開きます。ハードウェアがなくても、タイピングキーボードとタッチキーボードでノートを弾けます。

## キーボードをつなぐ

1. キーボードをつないで、`オプション › MIDI設定...` (`F10`) を開きます。
2. `入力デバイス` の中から見つけて、チェックを入れます。一覧にない場合は、`デバイスリストを更新` をクリックします。
3. 2つのボックスは `すべてのMIDIチャンネル` と `選択中のチャンネルを演奏` のままにします。
4. 設定を閉じて、[チャンネルラック](/wiki/channel-rack/)でチャンネルを選びます。
5. 弾きます。選んだチャンネルが鳴ります。

## 入力デバイス

| 設定 | 働き |
|---|---|
| チェックボックス | デバイスをオンまたはオフにします |
| `すべてのMIDIチャンネル` | すべてのMIDIチャンネル、または1つのチャンネルだけを受け付けます |
| `選択中のチャンネルを演奏` | ノートは、チャンネルラックで選んだチャンネル、または常に固定の1チャンネルに送られます |
| `ベロシティ` | `演奏どおり`、`ソフト (軽いタッチで大きく鳴る)`、`ハード (強いタッチが必要)`、`固定 (すべてのノートを最大ベロシティで)` |
| `パフォーマンスモードのチャンネル` | パフォーマンスモードがオンの間、このMIDIチャンネルのノートでプレイリストのクリップを起動します |
| `ソングマーカージャンプ` | このMIDIチャンネルのノートは、演奏せず、曲をマーカーまで移動させます |

## ノブをコントロールにリンクする

1. LYNX SHARE上のノブまたはフェーダーを右クリックします。
2. `MIDIコントローラーにリンク (コントローラーのノブを動かす)` を選びます。
3. ハードウェアのノブまたはフェーダーを動かします。これでリンクができます。

リンクはプロジェクトと一緒に保存されます。外すには、そのコントロールをもう一度右クリックして `コントローラーのリンクを解除` を選びます。メニュー項目には、使われているCC番号が表示されます。

| コマンド | キー | 働き |
|---|---|---|
| `Override global link...` | なし | すべてのプロジェクトで有効なリンクを作ります。プロジェクトではなく設定に保存されます |
| `グローバルリンクを削除` | なし | そのリンクを外します |
| `コントローラーへのマルチリンク` | `Ctrl+J` | オンの間、動かしたコントロールが、次に動かしたハードウェアのコントロールに順番にリンクされます。`オプション` メニューにあります |
| `ピックアップ (テイクオーバーモード)` | なし | MIDIページにあります。コントローラーは現在の値に達してからパラメーターを動かすので、値が飛びません |

MIDIページでは、リンクが `リンク (このプロジェクト、次にグローバル)` に一覧されます。同じページの `コントローラータイプ` は `汎用コントローラー` です。

サードパーティのプラグインのパラメーターには、チャンネルのメニューかエフェクトスロットのメニューにある `プラグインのパラメーターをオートメーション` から行けます。そこにある各パラメーターには、同じリンクの項目があります。[オートメーション](/wiki/automation/)をご覧ください。

## タイピングキーボード

`Ctrl+T` か `オプション › タイピングキーボードをピアノに` で、コンピューターのキーボードがピアノになります。`Z` から `M` の段と、`Q` から `P` の段が、選んだチャンネルを鳴らします。

- オンの間は、文字キーと数字キーがノートになります。ピアノロールとプレイリストの1文字のツールキーは、オフのときだけ使えます。
- 常にピアノロールのベロシティで鳴ります。MIDIページの `ベロシティ` 設定は、MIDIデバイス用です。
- 同じスイッチが `オプション › 全般設定...` にもあります。

## タッチキーボード

![タッチキーボード。オクターブボタン、鍵盤のサイズ、ベロシティモード、C4から始まる鍵盤の列](/assets/img/wiki/touch-keyboard.webp)

`表示 › タッチキーボード` (`Alt+F7`) は、マウスやタッチスクリーンで弾けるピアノを開きます。チャンネルラックで選んだチャンネルを鳴らし、右側にその名前を表示します。

| 設定 | 働き |
|---|---|
| `-` と `+` | 1オクターブ下げる、または上げる |
| 鍵盤のサイズ | `小さい鍵盤`、`中くらいの鍵盤`、`大きい鍵盤` |
| `ベロシティ: タッチ位置` | 鍵盤の上寄りは弱く、下寄りは強く鳴ります |
| `ベロシティ: 固定` | すべてのノートが、スライダーで設定したベロシティになります |
| `音名` | 鍵盤に音名を表示します |

## MIDI同期

MIDIページの `出力デバイス` は、トランスポートをハードウェアやほかのソフトウェアに送ります。デバイスの `マスター同期を送信` にチェックを入れ、`MIDIクロック` (スタート、コンティニュー、ストップ、ソングポジションポインター付き) かMIDIタイムコードを選びます。`オフセット (ms)` は、正の値で同期を遅らせ、負の値で早めて送ります。`オールノートオフを送信` は、初期化時とエクスポート後に、そのメッセージをデバイスに送ります。

`外部クロック同期` は逆向きです。LYNX SHAREは、選んだ入力のMIDIクロックに、そのテンポ、スタート、コンティニュー、ストップ、ソングポジションポインターごと追従します。`外部同期のオフセット (ミリ秒)` は、正の値でLYNX SHAREの再生を遅らせ、負の値で早めます。クロックが動いているかどうかは `状態` に表示されます。

## 知っておくと便利なこと

- `外部クロック同期` の入力を選ぶと、そのデバイスが `入力デバイス` でオンになります。
- リンクしたMIDIコントローラーでテンポを動かしても、オーディオクリップのサイズは変わりません。最終的なテンポは、入力するか設定してください。
- 弾いたものを録音するには、[録音](/wiki/recording/)をご覧ください。入力されたノートは、[ピアノロール](/wiki/piano-roll/)でスケールにスナップできます。
- プラグインに送られるMIDI CC、チャンネルアフタータッチ、ピッチベンドは、`MIDIコントローラーをオートメーション (CC、アフタータッチ、ピッチベンド)` でオートメーションできます。
