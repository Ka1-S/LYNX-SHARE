![設定視窗的一般頁面，頂部有各頁面的分頁](/assets/img/wiki/settings-general.webp)

設定視窗有八個頁面：音訊、MIDI、一般、主題、檔案、LYNX 額外功能、專案和資訊。前六個屬於程式本身。專案和資訊屬於目前開啟的專案，會隨專案一起儲存。每個頁面在 `選項` 選單的頂部都有自己的項目。

## 變更設定

1. 開啟 `選項` 選單並選擇一個頁面，例如 `一般設定...`。
2. 點擊頂部的其他分頁，切換到另一個頁面。
3. 變更設定。設定會立即生效，只有語言和介面字型要等 LYNX SHARE 重新啟動後才會生效。

`F10` 開啟 MIDI 頁面，`F11` 開啟資訊頁面。

## 音訊

`選項 › 音訊設定...`。驅動程式、裝置、取樣率、緩衝區大小和錄音。[音訊設定](/wiki/audio-setup/)說明了這個頁面。在 `錄製` 下，`檔案格式` 現在也提供 `WAV 16 位元（裝置的取樣率）`。

## MIDI

![MIDI 頁面：輸入裝置、帶有主同步的輸出裝置，以及外部同步](/assets/img/wiki/settings-midi.webp)

`選項 › MIDI設定...`

| 設定 | 作用 |
|---|---|
| 輸入裝置 | 每個裝置可以關閉、只聆聽某一個 MIDI 通道，並彈奏通道機架中固定的通道，而不是所選的通道 |
| `控制器類型` | 每個輸入裝置可選：`自動偵測`、`通用控制器` 或控制器設定檔，例如 Mackie Control。旁邊的那一行指出接收燈號和顯示器的連接埠 |
| `MPE 控制器` | 在裝置 MIDI 通道清單的最後。每個音符都帶有自己的彎音、音色和壓力。另一個方塊設定成員通道 |
| `重新整理裝置清單` | 重新尋找裝置，並重新讀取你的控制器設定檔 |
| `控制器設定檔資料夾` | 開啟放你自己控制器設定檔（`*.lynxctl`）的資料夾 |
| `傳送主同步` | 把帶有 Song Position Pointer 的 MIDI 時鐘或 MIDI Time Code 傳送到輸出裝置。`偏移 (ms)` 讓它較晚或較早送出 |
| `傳送全部音符關閉` | 在初始化時以及匯出之後，向裝置傳送全部音符關閉 |
| `外部時鐘同步` | LYNX SHARE 跟隨所選輸入的 MIDI 時鐘：速度、開始、繼續、停止和位置 |
| `力度` | 用於來自 MIDI 裝置的音符：按演奏、輕、重或固定 |
| `表演模式通道` | 在表演模式下，這個通道上的音符會啟動播放清單片段 |
| `歌曲標記跳轉` | 這個通道上的音符不演奏，而是把歌曲移到某個標記 |
| `拾取（接管模式）` | 控制器要到達參數目前的數值之後才會移動它 |
| `踏板控制音符釋放` | 預設開啟：延音踏板和持續音踏板會保持音符。關閉時，踏板會送給外掛 |
| `使用遊戲手把` | 遊戲控制器可操作傳輸，也能像 MIDI 控制器一樣連結。預設為關閉 |
| 關聯 | 這個專案的控制器關聯，然後是全域的，附有 `移除關聯` 和 `全部移除` |

## 一般

`選項 › 一般設定...`

| 設定 | 作用 |
|---|---|
| `版面樣式` | 樣式工作流程（預設）、片段啟動工作流程或簡易工作流程 |
| `預設範本`, `啟動專案` | 用 `檔案 › 新增` 開啟的範本，以及啟動時開啟的內容：`空白專案`、`預設範本` 或 `上次使用的專案`。`檔案 › 另存為範本...` 可加入你自己的範本 |
| `Live 專案的工作階段片段` | 匯入的 Live 套裝的 Session 片段放到哪裡：片段網格，或編排之後的播放清單 |
| `語言`、`介面字型` | 下次啟動時套用 |
| `介面大小`、`選單密度` | 整個介面的縮放比例，以及緊湊或寬鬆的選單 |
| `波形` | 簡潔（使用片段顏色）或頻譜顏色，可選擇將立體聲聲道分開顯示 |
| `音名`、`黑鍵` | 英文、德文或固定唱名的音名，使用升記號或降記號 |
| `外掛風格` | 內建外掛視窗的外觀：自動，或為所有外掛使用同一種風格 |
| `動畫`、`動畫速率` | 介面動畫，以及播放頭和電平表移動的頻率 |
| `使用GPU繪製（Direct2D）` | 如果顯示驅動程式當機或畫面閃爍，請關閉 |
| 啟動 | 啟動畫面、啟動音效，以及每次啟動時在背景尋找新外掛 |
| 編輯 | 電腦鍵盤當鋼琴、保持通道編輯器開啟、記住搜尋時間、讓被拉長的樣式片段循環 |
| `分離所有新外掛` | 開啟：你新增的外掛，其視窗以分離方式開啟，位於面板之上。關閉（預設）：停靠在主視窗中開啟 |
| `鋼琴捲簾中的單音繪製` | 開啟：繪製工具會取代每個新音符下方的音符，按住 Shift 則在它們上面繪製。關閉：相反 |
| `自動選擇連結的模組` | 讓外掛視窗取得焦點時，會選取它的混音器軌道。預設為開啟 |
| `預設停用打字鍵盤優先` | 對之後新增的外掛生效。預設為關閉 |
| `最大復原次數` | 25 到 1000 |
| `管理訊息` | 在 `提示和警告` 之下。勾選的訊息會顯示。取消勾選某一則，就會略過它的詢問 |
| 備份 | 多久儲存一次備份副本、每個專案保留幾份，以及 `開啟備份資料夾` |
| `在獨立處理程序中執行外掛` | 外掛當機不會拖垮 LYNX SHARE。預設為關閉 |
| `用LYNX SHARE對應外掛替代缺失的外掛` | 預設為開啟。當專案使用未安裝的第三方外掛時，LYNX SHARE 若有對應的替代品，就會以相符的設定載入。專案會保留原本的外掛，安裝後就會再次使用它 |
| `限制開啟的外掛編輯器數量` | 最多保持開啟 25 個外掛編輯器視窗。預設為開啟 |
| `崩潰報告` | 當機或停止回應後詢問（預設）、一律傳送或從不傳送 |
| `自動檢查更新` | 啟動時的更新檢查，附有 `立即檢查` |

## 主題

`選項 › 主題（顏色、背景）...`

| 設定 | 作用 |
|---|---|
| 主題選單 | 選擇一個預設集。`匯入...` 和 `匯出...` 讀取和寫入 `.lynxtheme` 檔案，`儲存預設集...` 保存目前的主題，`預設` 將它重設 |
| `強調色`、`背景`、`工作區` | 主題的三種顏色。工作區顏色可以自動跟隨背景 |
| 工作區圖像 | 視窗後方的 PNG、JPEG 或 GIF，附有 `圖像適應`、`圖像不透明度` 和 `變暗` |
| 啟動音效 | 你自己長度在 30 秒以內的音效，或 LYNX SHARE 自己的 |

## 檔案

`選項 › 檔案設定（搜尋資料夾）...`

| 設定 | 作用 |
|---|---|
| 缺失取樣的搜尋資料夾 | 缺失的檔案視窗會自動在這些資料夾及其子資料夾中尋找 |
| 瀏覽器資料夾 | 顯示在瀏覽器的資料夾清單中，也會用來搜尋缺失的取樣 |
| 外掛資料夾 | 由 `選項 › 掃描外掛` 掃描外掛 |

## LYNX 額外功能

`選項 › LYNX 附加功能...`。LYNX SHARE 自己的新增功能集中在一處。全部預設為關閉。每個開關與其那一行所指的選單或頁面中的設定是同一個設定。

| 設定 | 作用 |
|---|---|
| `在 Master 旁顯示響度表（LYNX）` | Master 的短期與整合響度（LUFS）和真實峰值，並有 Reset 按鈕 |
| `僅顯示已使用的插入軌` | 隱藏沒有被使用的混音器插入軌 |
| `保留指向已刪除插入軌的連結（灰色，LYNX）` | 刪除插入軌時，保留原本送進它的連結，以便重新連接 |
| `混音器分組跟隨 Playlist（LYNX）` | 混音器的群組會對應 Playlist 的軌道群組 |
| `自動化軌道` | 自動化可以放在 Playlist 軌道下方的軌道列中 |
| `尺規：歌曲小節 (LYNX)` | 鋼琴捲軸的尺規顯示樣式在歌曲中播放位置的小節編號 |
| `滑鼠停在控制項上時，在滑鼠旁顯示其數值 (LYNX)` | 數值顯示在游標旁邊，而不只是在提示列中 |
| `循環錄音後僅播放最後一遍` | 之前的幾遍留在它下方，並靜音 |
| `W 顯示或隱藏選取裝置的視窗` | 裝置檢視用的按鍵 |
| `選擇裝置時在混音器中選擇其插入通道` | 混音器會跟隨在裝置檢視中選取的裝置 |
| `使用遊戲手把` | 與 MIDI 頁面上的是同一個開關 |

## 專案

![專案頁面：時間設定、律動與調音、時基，以及播放清單選項](/assets/img/wiki/settings-project.webp)

`選項 › 專案設定（速度、拍號）...`

| 設定 | 作用 |
|---|---|
| `時間設定` | 時間分割（每小節幾拍、每拍幾步）或傳統拍號（分子和分母） |
| `速度`、`每小節拍數` | 專案的速度，以及一小節的拍數 |
| `搖擺`、`主控音高` | 全域搖擺程度，以及以音分表示的主控音高 |
| `自動交叉淡化` | 軌道上重疊的音訊片段會在重疊部分交叉淡化 |
| `合成軌交叉淡化` | 合成錄音時使用的交叉淡化長度，以毫秒表示 |
| `播放片段中被截斷的音符` | 開始於樣式片段之前的音符，會從片段的起點開始播放 |
| `切斷群組快速去咔嗒` | 切斷群組切斷音符時更快的漸變 |
| `聲像定律` | 圓形（中央為 0 dB，被推向的那一側 +3 dB）或三角形（較大聲的一側維持原電平）。用於混音器插入軌和取樣器通道 |

## 資訊

`選項 › 專案資訊...`。專案的標題、作者、類型、網站連結和備註，以及 `開啟專案時顯示此頁面`。底部顯示專案建立的時間和工作時間。

## 須知

- 時基固定為每四分音符 960 tick。來自 FL Studio 的專案會被轉換成這個時基。
- 歌曲中途的拍號變化不在專案頁面上。請在播放清單的尺規上加入拍號標記。
- `在獨立處理程序中執行外掛` 只對之後開啟的外掛有效。請重新開啟專案，才能移動其他外掛。
- Microsoft Store 版本沒有更新設定，因為由 Store 負責更新。
- 快速鍵在 `選項 › 管理快速鍵...` 中，不在設定頁面上。
- 有些開關在選單中，不在這個視窗裡。`錄音時低延遲` 在錄製按鈕旁的錄製選項選單中，也在混音器的 `磁碟錄音` 選單中。`鍵盤樣式` 在鋼琴捲軸的 View 選單中。
- 外掛資料庫是一個資料夾，即文件中 `LYNX` 資料夾裡的 `外掛資料庫`。你可以在檔案管理員中整理它。
