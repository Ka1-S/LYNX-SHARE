![載入展示專案的主視窗：頂部是工具列，左側是瀏覽器，後面是播放清單，通道機架浮在上方](/assets/img/wiki/desktop.webp)

LYNX SHARE 只有一個主視窗。工具列沿著頂部延伸。它下面是一塊桌面，容納五個視窗：瀏覽器、播放清單、通道機架、鋼琴捲軸和混音器。剛啟動時，瀏覽器在左側，播放清單佔滿其餘空間，通道機架浮在它上面。鋼琴捲軸和混音器則是隱藏的，等你叫出來。

## 熟悉環境

1. 把滑鼠指向任何控制項。選單下方的提示列會說明它的作用，以及它接受哪些滑鼠按鍵和按鍵。
2. 按 `F6` 隱藏通道機架，再按一次 `F6` 顯示。
3. 按 `F9` 顯示混音器，再按 `F7` 顯示鋼琴捲軸。
4. 拖曳視窗的標題列可移動它。對標題按兩下可最大化，再按兩下還原。
5. 選擇 `檢視 › 重設佈局` 可把一切恢復原狀。

以預設版面，從左到右：

| 走帶控制 | `樣式` 和 `歌曲` 模式按鈕、播放、停止和錄製、以 BPM 表示的速度，以及以小節、拍和步表示的位置 |
| 主控音量和音高 | `主控` 音量旋鈕和以音分為單位的 `音高` 旋鈕 |

| 視窗快速鍵 | 每個視窗一個按鈕，外加外掛選擇器 |

`選項 › 工具列` 可更改工具列：`編輯工具列（拖曳面板以移動、新增或移除）`、`分隔線`、`隱藏工具列面板`、`預設集`、每個群組各一個開關，以及 `圖示大小`（小、中或大）。

## 走帶控制

| 控制項 | 按鍵 | 作用 |
|---|---|---|
| 樣式模式 | `L` | 循環播放目前樣式。在按鈕上按右鍵可顯示通道機架 |
| 歌曲模式 | `L` | 播放播放清單中的編排。在按鈕上按右鍵可顯示播放清單 |
| 播放 | `Space` | 播放。再按一次會停止並回到起點。`Ctrl+Space` 為暫停 |
| 停止 | | 停止並回到開頭。按兩下還會讓所有音符關閉 |
| 錄製 | `R` | 開啟或關閉錄製。見[錄音](/wiki/recording/) |

## 提示列

閒置時，提示列顯示 `Point at anything for help`，並提示用 `F1` 開啟快速鍵一覽，用 `F5` 到 `F9` 開啟各視窗，用 `Space` 播放和停止。滑鼠移到控制項上時，它會寫出控制項的名稱，並列出在那裡拖曳、按 `Ctrl`、按 `Alt` 和按右鍵各有什麼作用。背景掃描外掛這類耗時的工作，也會在其中回報進度。

## 五個視窗

| 視窗 | 按鍵 | 用途 |
|---|---|---|
| [播放清單](/wiki/playlist/) | `F5` | 把樣式、音訊和自動化片段編排成一首歌 |
| [通道機架](/wiki/channel-rack/) | `F6` | 每件樂器一列，並顯示目前樣式的步 |
| [鋼琴捲軸](/wiki/piano-roll/) | `F7` | 目前樣式中某個通道的音符 |
| [混音器](/wiki/mixer/) | `F9` | 帶推桿的插入軌、效果器和路由 |
| [瀏覽器](/wiki/browser/) | `Alt+F8` | 取樣、預設集、專案的內容和外掛資料庫 |

每個按鍵都會顯示該視窗並讓它取得焦點；若它已有焦點，則會將其隱藏。單按 `F8` 會開啟外掛選擇器，它不屬於這五個視窗。工具列的視窗按鈕與按鍵作用相同。在按鈕上按右鍵會以最大化顯示該視窗。`Enter` 可最大化或還原播放清單。

## 視窗如何移動與停駐

每個視窗都有標題列。它的左側是一個選單按鈕，裡面有該視窗自己的選項，然後是 `已分離（獨立視窗）`、`已最大化` 和 `關閉`。右側是最大化和關閉按鈕。

- 拖曳標題列可移動視窗。它會貼齊其他視窗和邊緣。按住 `Alt` 移動則不貼齊。
- 拖曳邊緣可調整大小。
- `已分離（獨立視窗）` 會把視窗變成獨立的系統視窗，適合第二個螢幕。分離的視窗有一個 `停駐` 按鈕，可把它放回去。`檢視 › 分離的面板（獨立視窗）` 列出全部五個。
- `檢視 › 找回螢幕外的面板` 可找回跑到桌面之外的視窗。
- `檢視 › 佈局另存新檔...` 會以一個名稱儲存目前的排列，`檢視 › 載入佈局` 則可把它找回來。

瀏覽器是桌面的背景：它固定停駐在側邊，其他視窗永遠位於它的上方。

## 須知

- 在你移動、調整大小或分離任何東西之前，每當主視窗改變大小，視窗都會回到預設位置。之後，你的排列會被記住，並隨視窗縮放。
- `F12` 會關閉外掛、通道設定和工具視窗。它不會關閉五個主視窗。
- 打字鍵盤鋼琴開啟時（`Ctrl+T`），字母鍵會彈奏音符，大多數單字母快速鍵會暫停。
- `檢視 › 版面樣式` 可在樣式工作流程（預設）和片段啟動工作流程之間切換，後者會在播放清單旁加上片段格線。
