LYNX SHARE 可以代管其他廠商的樂器和效果器外掛。它透過掃描外掛資料夾來找到它們，`選項 › 外掛管理器...` 會顯示找到的內容。LYNX SHARE 自己的樂器和效果器，在[內建樂器與效果器](/wiki/built-in/)中說明。

## 掃描並新增外掛

1. 選擇 `選項 › 掃描外掛`。進度會顯示在提示列中，你可以繼續工作。
2. 如果外掛在它自己的資料夾裡，請開啟 `選項 › 外掛管理器...`，點擊 `外掛資料夾...`，加入該資料夾，然後點擊 `尋找新外掛`。
3. 按 `F8` 開啟外掛選擇器，輸入外掛名稱的一部分。
4. 對它按兩下或按 `Enter`。樂器會成為新通道。效果器會放入所選的混音插入軌。

第一次啟動時，設定精靈會列出外掛資料夾，並在背景掃描它們。`選項 › 設定精靈（語言、音訊、外掛資料夾）...` 可以再次開啟它。LYNX SHARE 也會在每次啟動幾秒後尋找新外掛。

## 各系統的格式

| 系統 | 代管的格式 |
|---|---|
| Windows | VST3、CLAP、VST2 |
| macOS | VST3、CLAP、Audio Units |
| Linux | VST3、CLAP、LV2、VST2 |

macOS 上不代管 VST2。在 Linux 上，Windows 外掛可透過 [yabridge](https://github.com/robbert-vdh/yabridge) 和 Wine 運作，這兩者需要你自行安裝：請把 yabridge 同步的資料夾加為外掛資料夾。

## 外掛管理器

| 控制項 | 作用 |
|---|---|
| 搜尋框 | 依名稱、廠商、格式或檔案篩選 |
| `全部`、`樂器`、`效果器`、`我的最愛`、`失敗` | 選擇要列出哪些外掛 |
| 星號欄 | 標記為我的最愛 |
| `位數` 欄 | 32、64 或 32+64（Windows） |
| `狀態` 欄 | `確定`、`未找到檔案` 或 `載入失敗` |
| `尋找新外掛` | 掃描清單中還沒有的檔案 |
| `全部重新掃描...` | 忘記失敗的檔案，並重新檢查每個檔案 |
| `外掛資料夾...` | 編輯要掃描的資料夾 |
| `新增外掛檔案...` | 新增單一外掛檔案 |

每個外掛檔案都在獨立的處理程序中檢查。當機或停止回應 30 秒的檔案會被標記為失敗，之後會略過。在 Windows 上，失敗的檔案及原因列在 `%APPDATA%\LYNX\scan-failures.log` 中。

標準資料夾和你加入的資料夾都會被掃描：

- Windows：`Common Files\VST3`、`Common Files\CLAP`、`Common Files\VST2`、Program Files 下的 `VSTPlugins` 和 `Steinberg\VSTPlugins`，以及（若已安裝 FL Studio）FL Studio 使用的資料夾。
- macOS：`~/Library/Audio/Plug-Ins` 和 `/Library/Audio/Plug-Ins` 中的 `VST3`、`Components` 和 `CLAP`。
- Linux：`~/.vst3`、`~/.clap`、`~/.lv2`、`~/.vst`，以及 `/usr/lib` 和 `/usr/local/lib` 下的同名資料夾。

## 停靠與分離的外掛視窗

外掛的編輯器和其他面板一樣，在主視窗內開啟。外掛視窗選單中的 `已分離` 會讓該外掛有自己的視窗，同一選單中的 `固定在最前` 則讓分離的視窗保持在 LYNX SHARE 其他視窗之上。

`選項 › 一般設定...` 中的 `分離所有新外掛` 會讓你新增的每個外掛都以分離方式開啟。`工具 › 將所有外掛編輯器切換為` 可為專案的所有外掛設定 `已停靠` 或 `已分離`。

## 在獨立處理程序中執行外掛

預設情況下，外掛在 LYNX SHARE 內部執行，所以當掉的外掛可能會讓整個程式一起當掉。你可以選擇讓每個外掛在自己的處理程序中執行。

1. 開啟 `選項 › 一般設定...`。
2. 開啟 `在獨立處理程序中執行外掛（防止外掛崩潰影響LYNX SHARE）`。
3. 重新開啟專案，讓這項設定套用到已開啟的外掛。

如果這樣的外掛當掉或停止回應，它會被靜音，並出現一則訊息，LYNX SHARE 則繼續執行。訊息中的 `重新載入` 會用上次儲存或備份的設定重新啟動該外掛，不必重新開啟專案。外掛的編輯器會在自己的視窗中開啟，無法停靠或固定。

若只想對單一外掛這麼做，請使用外掛視窗封裝器選單中的 `在獨立處理程序中執行` 或 `Always run <plugin> in a separate process`。當外掛的編輯器當掉時，出現的訊息也提供第二個選項。

這在 Windows 和 Linux 上可用，從 0.1.25 起 macOS 也可用。

在 LYNX SHARE 內當掉的外掛會被關閉，它的訊息也提供 `重新載入`。之後可以使用通道選單或效果器插槽選單中的 `重新載入已崩潰的外掛`。

## 32 位元外掛（僅限 Windows）

在 Windows 上，32 位元的 VST2 和 VST3 外掛透過橋接程式（`LYNX-bridge32.exe`）執行。橋接程式不增加延遲。在其中當掉的外掛會自行停止，LYNX SHARE 則繼續播放。橋接外掛的編輯器會在自己的視窗中開啟，無法停靠或固定。當同一個外掛同時安裝了 32 位元和 64 位元版本時，外掛視窗 `封裝器設定` 中的 `位元數` 決定載入哪一個。

## 外掛效能監視器

![外掛效能監視器：每個樂器和效果器一列，顯示其佔用的處理時間比例](/assets/img/wiki/plugin-monitor.webp)

`工具 › 外掛效能監視器...` 會列出每個樂器和效果器所花的處理時間：目前值、平均值和峰值。100% 表示在音訊持續的整段時間裡，一個處理器核心都處於忙碌狀態。

| 設定 | 作用 |
|---|---|
| `尋找` | 依外掛、通道或插入軌篩選 |
| `僅外掛` | 隱藏 LYNX SHARE 自己的樂器和效果器 |
| `凍結` | 停止更新數字 |
| `播放時重設` | 每次開始播放時，重新計算平均值和峰值 |
| `重設` | 立即清除平均值和峰值 |

## 把樂器的輸出送到各別的插入軌

有多個輸出的樂器外掛，可以讓每個輸出在自己的混音器插入軌上播放。在外掛視窗中點擊 `封裝器設定`，再點 `處理` 分頁。在 `連接` 下，每個輸出有一個開關燈號和一個數字：它在通道自己的插入軌之後第幾個插入軌上播放。`自動對應輸出` 會讓每個輸出使用下一個插入軌，`重設` 則回到預設值。

## 外掛資料庫資料夾

[瀏覽器](/wiki/browser/)的外掛資料庫、外掛選擇器和外掛選單中的資料夾，對應磁碟上的一個資料夾：文件資料夾中的 `LYNX/Plugin database`。要開啟它，在瀏覽器中對 `外掛資料庫` 按右鍵並選擇 `開啟`。

- `效果器` 和 `產生器` 中每個外掛有一個 `.lynxplugin` 檔案。可以建立資料夾和子資料夾（最多 4 層），再把檔案移進去。
- 重新命名檔案，就會改變外掛在選單中的名稱。刪除檔案，就會把外掛從選單中拿掉，但不會解除安裝。
- `已安裝` 裡有每個外掛的項目。把其中一個複製到 `效果器` 或 `產生器`，就能把外掛找回來。

## 不載入外掛開啟專案

`檔案 › 不載入第三方外掛開啟...` 會在關閉所有第三方外掛的情況下開啟 LYNX SHARE 專案，適用於無法開啟或載入時當掉的專案。外掛已儲存的設定會保留。`檔案 › 重新開啟外掛...` 會再把它們開啟。

## 外掛未安裝時

LYNX SHARE 會先依識別碼尋找同一個外掛，再依檔案，最後依名稱。以 VST2 儲存的專案，可以用同一產品的 VST3 開啟，反之亦然，但這時外掛會以預設設定播放。

如果效果器完全沒有安裝，會由角色相同的 LYNX SHARE 效果器接手它的插槽，原外掛則保留在專案中。在能讀取外掛已儲存設定的情況下，替代的效果器會以相符的設定開始。開關是 `選項 › 一般設定...` 中的 `用LYNX SHARE對應外掛替代缺失的外掛`。見[內建樂器與效果器](/wiki/built-in/)。`說明 › 缺失的檔案...` 會列出被取代的外掛。

## 須知

- 被代管外掛的視窗有預設集列：外掛自己的程式、你的預設集、`儲存預設集...`、`載入預設集檔案...` 和 `匯出預設集檔案...`。`.fxp`、`.fxb` 和 `.vstpreset` 檔案只能載入在 LYNX SHARE 內部執行的外掛，不能載入在獨立處理程序中執行的外掛。
- 監視器只在它的視窗開啟時才測量。
- 外掛視窗取得焦點時，外掛不使用的按鍵會彈奏打字鍵盤鋼琴。在 Windows 上，如果視窗標題列中的鍵盤按鈕是關閉的，LYNX SHARE 會先於外掛處理按鍵，包括快速鍵。
- VST3 外掛自己的參數選單，開頭是 LYNX SHARE 的項目，例如 `建立自動化片段`。見[自動化](/wiki/automation/)。
- 外掛 `封裝器設定` 中 `MIDI` 下的 `MPE`，會讓每個音符在自己的 MIDI 通道上送出。見 [MIDI 控制器](/wiki/midi-controllers/)。
- 缺少的樂器目前不會被替代。缺少的樂器外掛會變成依通道名稱選出的內建合成器。
