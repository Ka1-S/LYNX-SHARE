![鋼琴捲軸](/assets/img/pianoroll.webp)

鋼琴捲軸顯示目前樣式中某一個通道的音符，左邊是琴鍵，底部是放每個音符數值的軌道。按 `F7` 顯示或隱藏它，或在[通道機架](/wiki/channel-rack/)的通道選單中選擇 `鋼琴捲軸`。

工具列上的通道選單用來選擇你要編輯哪個通道。在這個樣式中有音符的通道會有標記。在選單上使用滾輪會逐一切換有音符的通道，`Ctrl`+滾輪則切換所有通道。

## 寫下一些音符

1. 在通道機架中，於通道名稱上按右鍵，選擇 `鋼琴捲軸`。
2. 按 `P` 選用鉛筆。
3. 在網格中點擊以新增音符。按住按鈕並拖曳可調整它的位置。
4. 拖曳音符的尾端，讓它變長或變短。
5. 在音符上按右鍵可刪除它。
6. 按 `Space` 聽聽這個樣式。

## 工具

![鋼琴捲軸的工具列，有通道選單、各種工具和貼齊選單](/assets/img/wiki/pianoroll-tools.webp)

每個工具都有一個字母鍵。這些字母在打字鍵盤鋼琴（`Ctrl+T`）關閉時才有效。

| 工具 | 按鍵 | 作用 |
|---|---|---|
| 鉛筆 | `P` | 點擊新增音符，拖曳調整位置 |
| 畫筆 | `B` | 拖曳畫出一連串音符。按住 `Shift` 則一次一個 |
| 鼓刷 | `N` | 在滑鼠下方的琴鍵上，每個網格單元一個擊打 |
| 橡皮擦 | `D` | 點擊或拖曳即刪除 |
| 靜音 | `T` | 點擊或拖曳可將音符靜音或取消靜音 |
| 刀片 | `C` | 拖曳一條線可橫切多個音符，點擊則在該點切開 |
| 套索 | `E` | 拖曳畫出選取框。按住 `Shift` 可加選 |
| 縮放 | `Z` | 點擊放大，拖曳一個範圍可縮放到該範圍，按右鍵縮小 |
| 偵聽 | `Y` | 點擊或拖曳會播放游標下的音符 |

## 處理音符

- 拖曳音符可移動它。`Shift`+拖曳會做出一份複本。
- 拖曳音符的尾端可調整大小。開頭也可以拖曳，尾端會留在原位。
- 在任何工具下，按右鍵都會刪除音符。
- 在音符上按兩下可開啟它的屬性。
- 在音符上按住 `Alt` 並使用滾輪，可改變它的力度。
- `Ctrl`+拖曳是選取。`Ctrl`+點擊可將音符加入選取範圍或從中移除。
- 拖曳時按住 `Alt` 可忽略貼齊。`Backspace` 可關閉和開啟貼齊。
- 選取多個音符後，用拉伸手柄可以在時間上拉伸或壓縮它們。

## 琴鍵與尺規

點擊琴鍵上的一個鍵即可聽到它。點在鍵的越右邊，聲音越大。`Ctrl`+點擊琴鍵會選取它的音符。在琴鍵上以中鍵拖曳，可讓琴鍵變高或變矮。

點擊尺規可設定位置。在尺規上 `Ctrl`+拖曳、右鍵拖曳或按兩下後拖曳，可選取一段時間範圍內的音符。`Ctrl`+滾輪縮放，`Shift`+滾輪捲動。

## 工具列

| 設定 | 作用 |
|---|---|
| 貼齊 | 「主要」跟隨主工具列的貼齊，也可以為這個視窗另外選一個。 |
| 和弦 | 點擊會建立所選的和弦，被點擊的音符為根音。`Shift+N` 回到單一音符。 |
| 音階 | 標出某個音階的音符。另一個按鈕會讓新增和移動的音符以及輸入的 MIDI 貼齊到所選的音階。 |
| 滑音（`S`） | 新音符是滑音音符。正在發聲的音符會滑向它們（808 滑音）。 |
| 幽靈音符（`Alt+V`） | 在你的音符後方顯示其他通道的音符。 |
| 音符顏色 | 新音符會得到這個顏色。共有 16 種。 |
| 跟隨 | 樣式播放時，檢視會跟著播放頭捲動。 |
| 軌道選單 | 選擇底部軌道編輯什麼：力度、聲像或微調音高。 |

## 按鍵

| 指令 | 按鍵 | 作用 |
|---|---|---|
| 全選 | `Ctrl+A` | 選取所有音符 |
| 取消選取 | `Ctrl+D` 或 `Esc` | 清除選取範圍 |
| 複製、剪下、貼上 | `Ctrl+C` / `Ctrl+X` / `Ctrl+V` | 複製、剪下或貼上音符 |
| 再製 | `Ctrl+B` | 再製選取範圍 |
| 刪除 | `Del` | 刪除選取範圍 |
| 移調 | `Up` / `Down` | 將選取範圍移動一個半音 |
| 移調一個八度 | `Ctrl+Up` / `Ctrl+Down` | 將選取範圍移動一個八度 |
| 微移 | `Left` / `Right` | 將選取範圍移動一個網格步 |
| 快速量化 | `Ctrl+Q` | 量化起點和長度 |
| 量化起點 | `Shift+Q` | 只量化起點 |
| 切碎 | `Ctrl+U` | 把音符依網格切碎 |
| 黏合 | `Ctrl+G` | 連接相鄰的音符 |
| 連奏 | `Ctrl+L` | 讓每個音符持續到下一個音符 |
| 靜音、取消靜音 | `Alt+M` / `Shift+Alt+M` | 將選取範圍靜音或取消靜音 |
| 匯入 MIDI | `Ctrl+M` | 把 MIDI 檔案匯入這個通道 |
| 匯出 MIDI | `Ctrl+Shift+M` | 把樣式匯出成 MIDI 檔案 |
| 縮放 | `PageUp` / `PageDown` | 放大或縮小 |

音符工具（琶音化、掃弦、翻轉、隨機化、量化、切碎等）會開啟對話框。它們的按鍵在[快速鍵](/wiki/shortcuts/)頁面。

## 須知

- 鋼琴捲軸顯示的是一個樣式中的一個通道。換了目前的樣式，它就顯示那個樣式的音符。
- 打字鍵盤鋼琴（`Ctrl+T`）開啟時，工具字母鍵不會有任何作用。
- 所有工具都能用按右鍵來刪除，所以只刪一個音符時不需要切換到橡皮擦。
- 在這裡 `S` 是滑音開關。在播放清單中，同一個字母是滑移工具。
- 如果音符不只是單純的步（其他音高、較長的音符、滑音），通道機架中該通道的那一列就會顯示縮圖，而不是步進按鈕。
