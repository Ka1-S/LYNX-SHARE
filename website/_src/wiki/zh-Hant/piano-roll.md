![鋼琴捲軸](/assets/img/pianoroll.webp)

鋼琴捲軸顯示目前樣式中某一個通道的音符，左邊是琴鍵，底部是放每個音符數值的軌道。按 `F7` 顯示或隱藏它，或在[通道機架](/wiki/channel-rack/)的通道選單中選擇 `鋼琴捲軸`。

工具列上的通道選單用來選擇你要編輯哪個通道。在這個樣式中有音符的通道會有標記。在選單上使用滾輪會逐一切換有音符的通道，`Ctrl`+滾輪則切換所有通道。

## 寫下一些音符

1. 在通道機架中，於通道名稱上按右鍵，選擇 `鋼琴捲軸`。
2. 按 `P` 選用鉛筆。
3. 在網格中點擊以新增音符。按住按鈕並拖曳可調整它的位置。
4. 拖曳音符的尾端，讓它變長或變短。
5. 在音符上按右鍵可刪除它。
6. 按 `Space` 聽聽這個樣式。

## 工具

![鋼琴捲軸的工具列，有通道選單、各種工具和貼齊選單](/assets/img/wiki/pianoroll-tools.webp)

每個工具都有一個字母鍵。這些字母在打字鍵盤鋼琴（`Ctrl+T`）關閉時才有效。

| 工具 | 按鍵 | 作用 |
|---|---|---|
| 鉛筆 | `P` | 點擊新增音符，拖曳調整位置 |
| 畫筆 | `B` | 拖曳畫出一連串音符。按住 `Shift` 則一次一個 |
| 鼓刷 | `N` | 在滑鼠下方的琴鍵上，每個網格單元一個擊打 |
| 橡皮擦 | `D` | 點擊或拖曳即刪除 |
| 靜音 | `T` | 點擊或拖曳可將音符靜音或取消靜音 |
| 刀片 | `C` | 拖曳一條線可橫切多個音符，點擊則在該點切開 |
| 套索 | `E` | 拖曳畫出選取框。按住 `Shift` 可加選 |
| 縮放 | `Z` | 點擊放大，拖曳一個範圍可縮放到該範圍，按右鍵縮小 |
| 偵聽 | `Y` | 點擊或拖曳會播放游標下的音符 |

## 處理音符

- 拖曳音符可移動它。`Shift`+拖曳會做出一份複本。
- 拖曳音符的尾端可調整大小。開頭也可以拖曳，尾端會留在原位。
- 在任何工具下，按右鍵都會刪除音符。
- 在音符上按兩下可開啟它的屬性。
- 在音符上按住 `Alt` 並使用滾輪，可改變它的力度。
- `Ctrl`+拖曳是選取。`Ctrl`+點擊可將音符加入選取範圍或從中移除。
- 拖曳時按住 `Alt` 可忽略貼齊。`Backspace` 可關閉和開啟貼齊。
- 選取多個音符後，用拉伸手柄可以在時間上拉伸或壓縮它們。

## 琴鍵與尺規

點擊琴鍵上的一個鍵即可聽到它。點在鍵的越右邊，聲音越大。`Ctrl`+點擊琴鍵會選取它的音符。在琴鍵上以中鍵拖曳，可讓琴鍵變高或變矮。垂直縮放滾輪也一樣，它是時間捲軸末端的小方塊：上下拖曳它，或在它上面使用滑鼠滾輪。

鋼琴捲軸選單中的 `檢視 › 鍵盤樣式` 可在 `平面琴鍵` 和 `鋼琴琴鍵（白鍵之間有分隔線）` 之間選擇，後者會畫出傳統的鍵盤。

點擊尺規可設定位置。在尺規上 `Ctrl`+拖曳、右鍵拖曳或按兩下後拖曳，可選取一段時間範圍內的音符。`Ctrl`+滾輪縮放，`Shift`+滾輪捲動。

## 工具列

| 設定 | 作用 |
|---|---|
| 貼齊 | 「主要」跟隨主工具列的貼齊，也可以為這個視窗另外選一個。 |
| 和弦 | 點擊會建立所選的和弦，被點擊的音符為根音。`Shift+N` 回到單一音符。同一份清單也在鋼琴捲軸選單的 `和弦印章` 中。 |
| 音階 | 標出某個音階的音符。另一個按鈕會讓新增和移動的音符以及輸入的 MIDI 貼齊到所選的音階。這時移動的音符會以音階的級數移動，所以和弦會留在音階內，`Up` 和 `Down` 則移動一個音階級數。 |
| 滑音（`S`） | 新音符是滑音音符。正在發聲的音符會滑向它們（808 滑音）。 |
| 幽靈音符（`Alt+V`） | 在你的音符後方顯示其他通道的音符。 |
| 音符顏色 | 新音符會得到這個顏色。共有 16 種。 |
| 跟隨 | 樣式播放時，檢視會跟著播放頭捲動。 |
| 軌道選單 | 選擇底部軌道編輯什麼：Velocity、Pan、Fine pitch、Release、Mod X、Mod Y、Chance 或 Velocity range。 |

## 機率與力度範圍

每個音符都有機率和力度範圍。機率是音符每次輪到時會播放的可能性。力度範圍讓它的力度在音符的力度，和該力度加上範圍之間變化。在軌道選單中選擇 `機率` 或 `力度範圍 (LYNX)` 即可編輯它們。鋼琴捲軸選單中的 `工具 › 機率 (LYNX)` 會把所選音符編成一組，讓它們全部播放或只播放其中一個，並有 `重設機率和力度範圍`。

## 音符工具

鋼琴捲軸的 `工具` 選單會以對話方塊開啟 FL Studio 的音符工具。它們作用於所選的音符，沒有選取時則作用於所有音符。其中一些：

| 工具 | 按鍵 | 作用 |
|---|---|---|
| Limit | `Alt+K` | 以八度為單位把音符移入一個琴鍵範圍，然後限制它們。在 `調 / 音階限制` 下，它會把音符保持在一個根音和 FL Studio 的某個和弦或音階上，`貼齊` 可設為 `上方`、`下方` 或 `交替`。`折返到頂部 / 底部` 和 `移調` 設定範圍外的音符的去處 |
| Flip | `Alt+Y` | `水平翻轉` 在時間上鏡射音符。使用 `保留起始時間`（一開始為開啟）時，起始時間會被鏡射，音符則保持各自的長度。`垂直翻轉` 以琴鍵範圍的中間為軸鏡射琴鍵 |
| Randomise | `Alt+R` | 隨機改變力度、聲像、微調音高、時間和長度，以及 Mod X、Mod Y 和釋放 |
| Scale levels | `Alt+X` | 從選取範圍的開頭到結尾縮放音符的某個電平，有 `偏移`、`中心`（縮放所圍繞的數值）和 `張力` |
| LFO | `Alt+O` | 把 LFO 形狀寫入音符的某個電平。在 `週期` 滑桿上按右鍵可看到從 1 步到 512 步的清單 |

## MIDI 工具與腳本

鋼琴捲軸選單中的 `工具 › MIDI 工具...` 會開啟一個面板，有 Arpeggiate、Chop、Connect、Ornament、Quantize、Recombine、Span、Strum、Time Warp 和 Velocity Shaper。

`工具` 選單的 `指令碼` 欄列出鋼琴捲軸腳本：LYNX SHARE 自己的和 `.pyscript` 檔案，如果安裝了 FL Studio，也包括 FL Studio 腳本資料夾中的檔案。`開啟指令碼資料夾...` 會開啟放自己腳本的資料夾，`再次執行上一個指令碼` 會重複上一個腳本。

## 須知

- 鋼琴捲軸顯示的是一個樣式中的一個通道。換了目前的樣式，它就顯示那個樣式的音符。
- 打字鍵盤鋼琴（`Ctrl+T`）開啟時，工具字母鍵不會有任何作用。
- 所有工具都能用按右鍵來刪除，所以只刪一個音符時不需要切換到橡皮擦。
- 在這裡 `S` 是滑音開關。在播放清單中，同一個字母是滑移工具。
- 如果音符不只是單純的步（其他音高、較長的音符、滑音），通道機架中該通道的那一列就會顯示縮圖，而不是步進按鈕。
