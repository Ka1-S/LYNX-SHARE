![帶有步進列的通道機架](/assets/img/rack.webp)

通道機架列出專案中的每一件樂器（通道），一列一個，並顯示目前樣式的各步。按 `F6` 可顯示或隱藏它。在走帶區的樣式按鈕上按右鍵，也會顯示它。

## 做一個鼓樣式

1. 按 `F6` 顯示通道機架。
2. 點擊最後一列下方的 `+ 新增通道` 方框，從選單中選一個樂器。你也可以在[瀏覽器](/wiki/browser/)中對取樣按兩下，新增一個取樣器通道。
3. 在通道所在的列中點擊各步，將其開啟。拖曳可畫出連續的一串步。
4. 在某一步上按右鍵可將其清除。
5. 按 `Space` 播放。在樣式模式下，樣式會循環播放。
6. 拖曳該列的音量旋鈕來設定電平。

## 編寫步

- 點擊某一步可將其開啟。拖曳會畫出連續的步。如果拖曳是從已亮起的步開始，則改為清除。
- 按右鍵或按右鍵拖曳可清除。
- 在樣式結尾之後點擊，會新增一步，並讓樣式變長。
- 如果某列的音符不是單純的步（其他音高、較長的音符、滑音），就會顯示音符的縮圖。點擊它會在[鋼琴捲軸](/wiki/piano-roll/)中開啟這些音符。
- 你可以把音訊檔案拖進機架來建立通道。

通道選單（在通道名稱上按右鍵）有 `每2步填充`、`每4步填充`、`每8步填充`、`進階填充`，以及 `向左輪轉` 和 `向右輪轉`。

## 圖形欄

![圖形欄在 Kick 通道下方展開，每一步有一根力度長條](/assets/img/wiki/rack-graph.webp)

`Ctrl+K` 會在所選通道下方顯示圖形欄。左側的按鈕用來選擇它編輯的內容：力度、聲像、釋放、微調音高、Mod X 或 Mod Y。拖曳可為每一步設定數值，按右鍵拖曳可畫出斜坡，按住 `Alt` 點擊可重設某一步。

## 一列的各個部分

| 部分 | 作用 |
|---|---|
| 靜音燈 | 點擊為靜音。按住 `Ctrl` 點擊或按右鍵為獨奏。 |
| 聲像和音量旋鈕 | 拖曳或使用滾輪。 |
| 路由框 | 拖曳或滾輪可選擇混音插入軌。按兩下會在混音器中顯示該插入軌。按右鍵會選下一個空閒的插入軌。 |
| 名稱按鈕 | 點擊可開啟或關閉通道的編輯器。按住 `Alt` 點擊會保持其他編輯器開啟。按住 `Ctrl` 點擊為試聽。上下拖曳可重新排序。按右鍵開啟通道選單。 |
| 選擇器 | 點擊選取單一通道。按住 `Ctrl` 點擊或按右鍵可加入或移除。按住 `Shift` 點擊可選取一個範圍。按兩下全選。 |

## 樣式

機架編輯的永遠是目前樣式。機架的樣式選擇器會顯示樣式名稱：點擊名稱可開啟清單，也可以使用箭頭。在機架標題上按住 `Shift` 並滾動滾輪，也能切換樣式。

機架的樣式長度框以小節為單位設定長度（拖曳或使用滾輪）。按兩下則會依音符自動取得長度。

主工具列中的搖擺旋鈕對所有通道生效。通道選單中的 `搖擺混合` 用來設定單一通道跟隨它的程度。

| 指令 | 按鍵 | 作用 |
|---|---|---|
| 下一個樣式 | `Numpad +` | 把下一個樣式設為目前樣式 |
| 上一個樣式 | `Numpad -` | 把上一個樣式設為目前樣式 |
| 下一個空樣式 | `F4` | 跳到下一個空樣式，並詢問名稱 |
| 重新命名並上色 | `F2` | 重新命名目前樣式並為它上色 |

## 用電腦鍵盤彈奏音符

`Ctrl+T` 會把打字鍵盤變成鋼琴：`Z` 到 `M` 以及 `Q` 到 `P` 會演奏所選通道。開啟期間，編輯器的單字母快速鍵會暫停。

## 快速鍵

通道機架取得焦點時，這些按鍵才有效。

| 指令 | 按鍵 | 作用 |
|---|---|---|
| 選取通道 | `Up` / `Down` | 選取上方或下方的通道 |
| 擴大選取 | `Shift+Up` / `Shift+Down` | 把上方或下方的通道加入選取範圍 |
| 移動通道 | `Alt+Up` / `Alt+Down` | 將所選通道上移或下移 |
| 全選 | `Ctrl+A` | 選取所有通道 |
| 剪下、複製、貼上 | `Ctrl+X` / `Ctrl+C` / `Ctrl+V` | 剪下、複製或貼上所選通道的步 |
| 輪轉步 | `Ctrl+Shift+Left` / `Ctrl+Shift+Right` | 輪轉所選通道的步 |
| 再製 | `Alt+C` | 再製所選通道 |
| 刪除 | `Alt+Del` | 刪除所選通道 |
| 群組 | `Alt+G` | 把所選通道放進新的篩選群組 |
| 路由到混音器 | `Ctrl+L` | 把所選通道送到空閒的混音插入軌 |
| 靜音 | `1` 到 `0` | 將通道 1 到 10 靜音或取消靜音 |
| 獨奏 | `Ctrl+1` 到 `Ctrl+0` | 獨奏通道 1 到 10 |
| 圖形欄 | `Ctrl+K` | 顯示或隱藏圖形欄 |

## 通道選單中的其他項目

`鋼琴捲軸`、`重新命名並設定顏色`、`取代`（更換樂器）、`再製`、`Delete`、`琶音器`、`循環點`、`MIDI 寫入到`、`通道排序`、`選取未使用的通道` 和 `通道設定`。

## 須知

- 只有 `+ 新增通道` 方框會開啟新增選單。
- 機架本身沒有樣式。在任何地方切換目前樣式，機架顯示的內容就會跟著改變。
- 顯示音符縮圖的列，不能當作步來編輯。請用鋼琴捲軸。
- 數字鍵只對前十個通道有效。
- 表中的按鍵需要機架取得焦點。請先點擊機架。
