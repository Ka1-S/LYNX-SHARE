`檢視 › 版面樣式` 有三個項目：`模式工作流程（預設）`、`片段啟動工作流程` 和 `簡易工作流程`。同樣的選擇也在 `選項 › 一般設定` 的「工作流程」下。這個選擇在你關閉程式後仍會保留。

樣式工作流程由通道機架、樣式和播放清單組成。片段啟動工作流程則在播放清單旁邊加上一個帶有場景的片段網格。樣式和通道機架仍然可用。

## 在網格中啟動片段

1. 選擇 `檢視 › 版面樣式 › 片段啟動工作流程`。片段網格會出現在播放清單旁邊。
2. 在空的格子上按右鍵，選擇 `在此放置模式`，再選一個樣式。在空格子上按兩下，則會把目前的樣式放進去。
3. 點擊片段左側的三角形來啟動它。如果走帶是停止的，它就會開始。
4. 點擊 `場景` 欄中場景的三角形，啟動那一列的所有片段。
5. 按一下 `停止所有片段` 來停止它們。
6. 按一下 `返回播放清單`，讓軌道再次播放它們的播放清單片段。

## 畫面上有什麼變化

- 片段網格顯示在播放清單旁邊。播放清單軌道是欄，場景是列。
- 播放清單的標題列多了一個 `兩者`、`網格`、`歌曲` 切換。`網格` 只顯示網格，`歌曲` 只顯示播放清單。
- 第一次進入時，通道機架是隱藏的。按 `F6` 或它的工具列按鈕即可顯示。
- 播放清單的自動化軌道會被開啟。
- 視窗佈局是依樣式分別儲存的，所以每種樣式都會回到你離開時的樣子。
- 在網格下方，`混音器` 按鈕會顯示或隱藏 Session 混音器，與 Ableton Live 相同：`輸入/輸出`（`音訊來源`、`監聽`、`音訊輸出到`）、`傳送`、`軌道延遲`，以及每個軌道的音量（附啟用開關、獨奏、預備按鈕和電平表），另外還有 `主要` 軌。
- 網格下方的 `律動` 會顯示 Groove Pool。`將律動套用到音符` 會把律動寫入 MIDI 片段的音符中。
- `MIDI` 和 `調` 按鈕會啟動 MIDI 對應模式和按鍵對應模式。請參閱 [MIDI 控制器](/wiki/midi-controllers/)。

## 網格

被啟動的片段不會馬上開始。它要等到下一個啟動量化點，在那之前它的三角形會閃爍。網格底部的選單設定全域啟動量化，所有設為 `全域` 的片段都使用它。停止也是同樣等待。

在片段上按右鍵可看它的設定。

| 設定 | 作用 |
|---|---|
| `啟動量化` | 這個片段何時開始：`全域`、`無`、`8小節` 一直到 `1/32` |
| `啟動模式` | `觸發`、`門限`、`切換` 或 `重複` |
| `連奏（保持位置）` | 片段接手同一軌道上前一個播放中片段的播放位置 |
| `循環` | 開啟：片段重複。關閉：播放一次，然後軌道停止 |
| `跟隨動作` | 片段結束後會發生什麼：兩個動作，各有一個機率，以及動作觸發前經過的時間 |
| `Delete` | 清空格子 |

在空格子上按右鍵可看到 `停止按鈕（場景在此停止該音軌）`。點擊空格子左側的方塊會停止該軌道。在場景上按右鍵可看到 `插入場景`、`在下方新增場景`、`刪除場景`、`重新命名場景...` 以及場景的速度。

片段可以從其選單剪下、複製、貼上和複製一份（`Ctrl+D`），也可以在格子之間拖曳，或拖曳到播放清單或從播放清單拖出。從瀏覽器拖來的樣式或取樣，或從外部放入的音訊檔案，會填入它們落下的那個格子。場景的選單中還有 `複製` 和 `擷取並插入場景`，後者會把目前正在播放的片段放進新的場景。`檢視 › 場景速度與拍號` 會為每個場景顯示速度和拍號。

格子選單中還有兩個作用於整個網格的選項：`走帶停止時將音軌交還給播放清單` 和 `整個格線的跟隨動作`。

| 指令 | 按鍵 | 作用 |
|---|---|---|
| 移動 | 方向鍵 | 選取另一個格子 |
| 啟動片段 | `Enter` | 啟動所選的片段 |
| 啟動場景 | `Ctrl+Enter` | 啟動所選的場景 |
| 刪除片段 | `Del` | 清空所選的格子 |
| 繪製模式 | `B` | 在自動化軌道中拖曳，會繪製與網格同寬的階梯，或在貼齊關閉或按住 `Alt` 時手繪，與 Ableton Live 相同。也在 `選項` 中 |

## Ableton Live 套裝

開啟 Live 套裝時，它的 Session 片段和場景會連同啟動設定一起進入片段網格。`檔案 › 匯出 › Ableton Live 套裝 (.als)` 會把網格寫回成 Session 片段。`選項 › 一般設定` 中有 `Live 專案的工作階段片段`，選 `播放清單，編曲之後` 則會改把它們放到播放清單上。

## 簡易工作流程

`檢視 › 版面樣式 › 簡易工作流程` 是一個含有軌道和時間軸的視窗，適合第一首歌。`檢視 › 音軌面板` 會在時間軸下方顯示所選軌道的面板，有 `效果器`、`樂器`、`鍵盤` 和 `編輯器` 分頁。在這個工作流程中，`說明` 選單有 `首支歌曲導覽` 和 `歡迎畫面...`，後者提供七步驟的第一首歌、示範歌曲或空白專案。請參閱 [簡易版面](/wiki/simple-layout/)。

`檢視` 選單中的 `歌詞和筆記` 和 `參考比對...`，以及混音器插入軌選單中的 `清晰人聲`，在每種版面中都有。在簡易工作流程中，`清晰人聲` 也在軌道的選單中。

## 切換回來

選擇 `檢視 › 版面樣式 › 模式工作流程（預設）`。你在樣式工作流程中的視窗佈局會回來，自動化軌道也回到之前的設定。網格中的片段仍留在專案裡。

## 須知

- 啟動過片段的軌道，在你按下 `返回播放清單` 之前，在播放清單中會保持靜音。選項 `走帶停止時將音軌交還給播放清單` 會在每次停止時替你做這件事。
- 網格的新按鍵（`B`、`Q`、`Ctrl+M`、`Ctrl+K` 等）只在片段啟動工作流程中這樣運作。在樣式工作流程中，它們保持 FL Studio 的意義。
- 6/8 的場景會播放三拍一小節，因為拍號是以四分音符計算。
- 跟隨動作只有片段才有，場景沒有。
- 在片段啟動工作流程中手動開啟的自動化軌道，切換回去時不會保留。
- 選擇樣式工作流程時，不會載入網格的任何內容。
