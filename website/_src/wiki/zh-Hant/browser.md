瀏覽器會列出你的取樣資料夾、目前專案的內容，以及 LYNX SHARE 認得的外掛。按 `Alt+F8` 可顯示或隱藏它。單按 `F8` 會開啟外掛選擇器，這是一個獨立的全螢幕檢視，列出所有樂器和效果器。

## 把取樣載入專案

1. 按 `Alt+F8` 顯示瀏覽器。
2. 在 `全部` 分頁中，點擊資料夾將其開啟。
3. 點擊音訊檔案即可試聽。用 `Up` 和 `Down` 逐一切換檔案，每個檔案都會預覽。
4. 對檔案按兩下，會在[通道機架](/wiki/channel-rack/)中新增一個載入該取樣的通道。
5. 或者把檔案拖到[播放清單](/wiki/playlist/)，得到一個音訊片段。

## 分頁

| 分頁 | 顯示內容 |
|---|---|
| ALL | 目前專案、外掛資料庫和所有取樣資料夾 |
| PROJECT | 只顯示目前專案用到的內容：樣式、效果器、產生器、自動化、音訊檔案 |
| STARRED | 你加上星標的檔案和資料夾（按右鍵，再選 `已加星標`） |

## 瀏覽與預覽

- 點擊資料夾可展開或收合。按右鍵會出現選單（全部摺疊、在檔案管理器中顯示）。
- 點擊音訊檔案即可試聽。清單下方的預覽條會顯示它的波形。點擊預覽條可再聽一次，也可以從預覽條拖曳，效果等同拖曳檔案本身。
- 預覽條上方的面板會顯示所選檔案的日期、大小和路徑。

## 使用取樣

| 操作 | 作用 |
|---|---|
| 按兩下 | 新增載入該取樣的通道 |
| 拖到通道機架 | 新增通道；放在某一列上則載入到該列 |
| 拖到播放清單 | 音訊片段 |
| `Enter` | 把檔案載入所選通道 |
| `Shift+Up` / `Shift+Down` | 切換到上一個或下一個檔案，並載入所選通道 |

最後一項讓你在樣式播放的同時，原地試聽不同的取樣。

## 其他檔案類型

- **專案**：按兩下即可開啟。
- **MIDI 檔案**：按兩下會把它當作專案開啟。
- **SoundFont 或 SFZ**：點擊可預覽，按兩下會建立 LYNX Soundfont 通道（或載入到所選通道）。
- **混音器預設集**：按兩下會載入到所選的混音插入軌，也可以拖到某個插入軌上。
- **效果器預設集**：拖到混音插入軌上。

## 外掛資料庫

外掛資料庫項目會列出 LYNX SHARE 的內建樂器和效果器，以及已安裝的外掛。按 `Shift+F8` 可直接跳到這裡。

- 對樂器按兩下可新增為通道，也可以把它拖到通道機架。
- 對效果器按兩下可加到[混音器](/wiki/mixer/)中所選的插入軌，也可以把它拖到插入軌或效果插槽上。
- `F2` 可重新命名所選外掛。
- 對外掛按右鍵並選擇 `移到資料夾`，即可把外掛分類到資料夾。混音器的插槽選單和通道機架的新增選單隨後會列出每個頂層資料夾。

## PROJECT 分頁

這裡列出的樣式，點擊可設為目前樣式，按兩下會在[鋼琴捲軸](/wiki/piano-roll/)中開啟，也可以拖進播放清單。目前專案區段還會列出復原記錄：點擊其中一步即可回到那個狀態。

## 搜尋

按 `Ctrl+F` 可把游標移到搜尋框。它會搜尋所選資料夾（或所有資料夾）及其下層。在 PROJECT 分頁中，它搜尋的是專案裡的項目。

所有詞都必須符合。搜尋框也接受 `OR`、用減號排除某個詞，以及 `*` 萬用字元：

```
kick -loop
snare OR clap
hat*.wav
```

資料夾會在背景建立索引。瀏覽器選單中的 `重新整理搜尋索引` 會重建索引。

## 你自己的資料夾

用瀏覽器資料夾清單中的 `新增資料夾`，可以新增放有取樣、專案或 SoundFont 的資料夾。搜尋資料夾在 `選項 › 檔案設定（搜尋資料夾）` 中設定。

## 快速鍵

方向鍵、`Enter` 和 `F2` 需要瀏覽器取得焦點才有效。

| 指令 | 按鍵 | 作用 |
|---|---|---|
| 顯示瀏覽器 | `Alt+F8` | 顯示或隱藏瀏覽器 |
| 外掛選擇器 | `F8` | 開啟全螢幕外掛選擇器 |
| 外掛資料庫 | `Shift+F8` | 跳到外掛資料庫項目 |
| 搜尋 | `Ctrl+F` | 把游標移到搜尋框 |
| 切換並預覽 | `Up` / `Down` | 選取上一個或下一個檔案並播放 |
| 關閉資料夾 | `Left` | 關閉資料夾，或回到上一層 |
| 開啟資料夾 | `Right` | 開啟資料夾 |
| 載入 | `Enter` | 把檔案載入所選通道 |
| 切換並載入 | `Shift+Up` / `Shift+Down` | 切換到上一個或下一個檔案，並載入所選通道 |
| 重新命名外掛 | `F2` | 重新命名外掛資料庫中所選的外掛 |

## 須知

- 從清單中移除資料夾，不會把它從磁碟刪除。
- `F8` 和 `Alt+F8` 不一樣。`F8` 是外掛選擇器，`Alt+F8` 是瀏覽器。
- 搜尋結果來自在背景建立的索引。瀏覽器選單中的 `重新整理搜尋索引` 可重建索引。
- `Enter` 會把檔案載入所選通道。按兩下則會新增通道。
