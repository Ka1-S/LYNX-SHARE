![選取 WAV 的匯出視窗：左側是範圍、尾音和檔案，右側是格式，下方是混音選項](/assets/img/wiki/export.webp)

所有離開 LYNX SHARE 的內容都要經過 `檔案 › 匯出`。音訊格式（WAV、MP3、OGG 和 FLAC）共用同一個匯出視窗。MIDI、FL Studio 專案、Ableton Live 套裝和壓縮專案在同一個選單中各有自己的項目。

## 把歌曲匯出成 WAV

1. 選擇 `檔案 › 匯出 › Wave檔案...`。
2. 讓 `範圍` 維持 `歌曲（播放清單）`，`檔案` 維持 `一個檔案（混音）`。
3. 選一個 `位元深度`：16 bits、24 bits 或 32 bits (float)。
4. 把 `尾音` 設為 `保留餘音`，讓殘響和釋放在最後一小節之後自然消退。
5. 按一下 `匯出...`，選擇名稱和資料夾，然後等待算繪完成。
6. 完成後，LYNX SHARE 會告訴你檔案放在哪裡以及它的峰值電平。

`Ctrl+R` 會以你上次匯出的格式開啟視窗。`Ctrl+Shift+R` 則以 MP3 開啟。

## 要算繪什麼

| 設定 | 作用 |
|---|---|
| `範圍` | `歌曲（播放清單）`、`目前樣式` 或 `播放清單選取範圍` |
| `播放` | 範圍在檔案中播放幾次，從 `一次` 到 16 次 |
| `尾音` | `切掉餘音` 剛好在結尾停止。`保留餘音` 讓聲音自然消退。`迴繞餘音` 把尾音混入開頭，適合循環 |
| `最長尾音` | 3、6、12 或 30 秒。聲音提前消失時，尾音會更早停止 |
| `檔案` | 一個檔案，或分軌（見下方） |

## 輸出格式

四個按鈕用來選擇格式。`同時儲存` 會用同一次算繪、以相同名稱寫出其他格式。

| 格式 | 選項 |
|---|---|
| WAV | `位元深度`：16 bits、24 bits 或 32 bits (float)。`抖動`：`關`、`TPDF` 或 `TPDF + 噪音整形` |
| MP3 | `位元率`，固定位元率 |
| OGG | 位元率 |
| FLAC | `位元深度`、`壓縮`（從 `0（最快）` 到 `8（最小）`）、`抖動`。每個等級都是無損 |

`取樣率` 和 `聲道` 適用於所有格式。`聲道` 可以是 `立體聲`、`單聲道（兩側混合）`、`單聲道（僅左）` 或 `單聲道（僅右）`。

## 混音選項

| 設定 | 作用 |
|---|---|
| `正規化（峰值到0 dB）` | 整體調高或調低檔案，讓最大的峰值達到滿刻度 |
| `主控效果` | 關閉：主控插入軌的效果器被旁通 |
| `插槽效果` | 關閉：其他插入軌的效果器被旁通 |
| `所有外掛使用HQ` | 外掛使用它們的算繪品質。關閉：匯出時使用播放品質 |
| `外掛預熱` | 匯出開始前，第三方外掛先處理一小段靜音 |
| `停用最大複音數` | 解除通道的發聲數限制，所以不會有音符被切掉 |
| `修剪延遲補償產生的靜音` | 移除外掛延遲補償在開頭加入的靜音 |
| `速度資訊`、`循環標記`、`播放清單標記` | 僅限 WAV：把速度、循環和播放清單的標記存進檔案 |
| `完成後顯示檔案` | 在檔案管理員中顯示結果 |

## 分軌與軌道

![匯出視窗設為 FLAC，每個混音插入軌一個檔案，共九個檔案](/assets/img/wiki/export-flac-stems.webp)

`檔案` 有三種分軌模式：

- `每個混音插入軌一個（分軌）`：每個有聲音的插入軌各一個檔案。
- `每個通道一個（分軌）`：每個有演奏的通道各一個檔案。
- `每個通道一個，僅樂器（不含傳送和匯流排）`。

勾選 `同時匯出完整混音`，就能在分軌之外同時得到完整混音。底部那一行會顯示將寫出多少個檔案。

`檔案 › 匯出 › 所有 Playlist 軌道` 和 `所有 Playlist 軌道群組` 會為每條播放清單軌道或每個群組寫出一個檔案。在混音器的選單中，`磁碟錄音 › 將錄音預備的軌道渲染為WAV檔案...`（`Alt+R`）只為預備錄音的插入軌開啟匯出視窗。

## 匯出選單的其他項目

| 指令 | 按鍵 | 作用 |
|---|---|---|
| `MIDI檔案...` | `Ctrl+Shift+M` | 把音符寫成標準 MIDI 檔案（`.mid`） |
| `母帶處理...` | `Ctrl+Alt+M` | 算繪專案並在你的電腦上母帶處理到以 LUFS 表示的響度目標 |
| `專案及取樣（.zip）...` | 無 | 專案及其取樣打包成一個壓縮檔 |
| `FL Studio 專案...` | 無 | 一個 `.flp`，或含有全部取樣的壓縮循環包 |
| `Ableton Live 套裝 (.als)...` | 無 | 適用於 Live 12 或 Live 11 的套裝 |
| `專案骨架...` | 無 | 通道與效果器預設集及樂譜，存放在一個資料夾中 |

## 匯出到 FL Studio 和 Ableton Live

`.flp` 是 FL Studio 2026 專案。取樣器、音訊片段、FL Studio 自己的產生器和效果器、第三方外掛、樣式、播放清單、混音器和自動化，都會連同設定一起轉過去。對於 FL Studio 沒有的東西，你可以在 `算繪為音訊（聲音相同）` 和 `使用最接近的 FL 外掛（仍可編輯，聲音可能不同）` 之間選擇。選第二種時，僅限 LYNX 的樂器會被略過。調變器一律會被略過。報告會列出哪些被算繪、取代或略過。詳情見[從 FL Studio 轉換](/wiki/coming-from-fl-studio/)。

`.als` 包含每個通道一條 MIDI 軌道、音訊軌道、群組、回送、傳送、機架和鼓機架、帶有狀態的 VST2 和 VST3 外掛、標記，以及音量、聲像和速度的自動化。LYNX SHARE 自己的樂器和效果器不會被轉換，但它們的軌道和音符會保留。效果器參數的自動化和插入軌之間的路由會被捨棄。詳情見[從 Ableton Live 轉換](/wiki/coming-from-ableton/)。

## 須知

- 匯出 MP3 時 `抖動` 是灰色的，除了 WAV 以外的所有格式，速度和標記選項也都是灰色的。
- 選了 `播放清單選取範圍` 但播放清單中沒有選取範圍時，會算繪整首歌。視窗會提醒你。
- 如果主控插入軌被靜音，視窗會警告檔案將是無聲的。
- `同時寫出帶此混音的影片` 只在專案有影片軌道時出現，而且需要 FFmpeg。
- `透過硬體即時渲染` 只在專案有啟用的硬體插入軌時出現。這種匯出需要和歌曲一樣長的時間。
- 渲染為音訊（把插入軌轉成音訊片段）在這個版本中，播放時比它取代的插入軌大聲約 5 dB。
