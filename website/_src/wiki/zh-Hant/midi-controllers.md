LYNX SHARE 可以從任何 MIDI 輸入裝置接收音符和控制器動作。裝置在設定的 MIDI 頁面中設定：`選項 › MIDI設定...`，或按 `F10`。沒有硬體時，電腦鍵盤和觸控鍵盤也能彈奏音符。

## 連接鍵盤

1. 接上鍵盤，開啟 `選項 › MIDI設定...`（`F10`）。
2. 在 `輸入裝置` 下找到它並勾選。如果沒有列出，請按一下 `重新整理裝置清單`。
3. 讓兩個選單維持 `任意MIDI通道` 和 `演奏所選通道`。
4. 關閉設定，在[通道機架](/wiki/channel-rack/)中選取一個通道。
5. 彈奏。所選的通道就會發聲。

## 輸入裝置

| 設定 | 作用 |
|---|---|
| 勾選框 | 開啟或關閉該裝置 |
| `任意MIDI通道` | 聆聽所有 MIDI 通道，或只聆聽某一個通道。`MPE 控制器` 在這份清單的最後 |
| `演奏所選通道` | 音符送到通道機架中所選的通道，或永遠送到某個固定的通道 |
| `力度` | `按演奏`、`輕（輕彈也更響）`、`重（需要更用力彈奏）` 或 `固定（每個音符都是滿力度）` |
| `表演模式通道` | 表演模式開啟時，這個 MIDI 通道上的音符會啟動播放清單片段 |
| `歌曲標記跳轉` | 這個 MIDI 通道上的音符不演奏，而是把歌曲移到某個標記 |
| `控制器類型` | `自動偵測`、`通用控制器` 或某個控制器設定檔 |
| `踏板控制音符釋放` | 預設開啟。延音踏板（CC 64）或持續音踏板（CC 66）會保持音符。關閉時，踏板會作為控制器送給外掛 |

## 把旋鈕關聯到控制項

1. 在 LYNX SHARE 中的旋鈕或推桿上按右鍵。
2. 選擇 `關聯到MIDI控制器（轉動控制器上的旋鈕）`。
3. 轉動硬體上的旋鈕或推桿。關聯就建立了。

關聯會隨專案一起儲存。要移除它，請再次在控制項上按右鍵並選擇 `取消關聯控制器`。選單項目會顯示正在使用的 CC 編號。

| 指令 | 按鍵 | 作用 |
|---|---|---|
| `Override global link...` | 無 | 建立一個在所有專案中都有效的關聯。它存放在設定中，而不是專案中 |
| `移除全域關聯` | 無 | 再把它移除 |
| `多重連結到控制器` | `Ctrl+J` | 開啟時，你移動的控制項會依序與你接下來移動的硬體控制器關聯起來。它位於 `選項` 選單中 |
| `拾取（接管模式）` | 無 | 在 MIDI 頁面上。控制器要到達參數目前的數值之後才會移動它，所以數值不會突然跳動 |

MIDI 頁面會在 `關聯（此專案，然後全域）` 下列出這些關聯。`控制器類型` 為 `通用控制器` 的裝置，只會做你手動連結的事。

第三方外掛的參數可以透過通道選單或效果器插槽選單中的 `自動化外掛參數` 找到。那裡的每個參數都有同樣的關聯項目。見[自動化](/wiki/automation/)。

## 控制器設定檔

控制器設定檔會設定裝置的傳輸按鈕、推子、旋鈕、打擊墊、燈號和顯示器，不需要自己連結。

1. 開啟 `選項 › MIDI設定...`（`F10`），並在 `輸入裝置` 下勾選該裝置。
2. 讓它的 `控制器類型` 保持在 `自動偵測`。括號中的名稱，是從裝置的連接埠名稱找到的設定檔。
3. 如果顯示 `通用控制器`，請自己從清單中選擇設定檔。
4. 讀一下方塊旁邊的那一行。`Feedback to` 指出接收燈號、電動推子和顯示文字的輸出連接埠。

| 設定檔 | 對應內容 |
|---|---|
| `Mackie Control Universal` | 推子對應插入軌的音量和 Master。V-Pot 對應聲像、所選通道外掛的參數，或通道機架的音量。每個通道條的預備錄音、獨奏、靜音和選取，推子組、播放、停止、錄製、倒轉、快轉、Pattern 或 Song 模式、節拍器、復原和搓盤。顯示器顯示名稱和數值 |
| `Mackie Control Extender (XT)` | 同樣的功能，多 8 個通道條。這些裝置共用一組推子組，順序依 `輸入裝置` 清單而定 |
| `Novation Launchkey MK3 (DAW mode)` | 旋鈕對應聲像、音量或外掛參數，推子對應音量，推子按鈕選取插入軌。有組切換、播放、停止、錄製、循環、節拍器和復原按鈕。Session 打擊墊是所選通道的 16 個步。請在鍵盤的第二個連接埠上使用 |
| `Akai APC Key 25 mk2` | 旋鈕對應音量、聲像或外掛參數。上面兩排打擊墊是所選通道的 16 個步，下面三排彈奏音符。軌道按鈕選取插入軌。停止、播放和錄製。請在第二個連接埠上使用 |
| `Arturia KeyLab Essential mk3 (Mackie Control port)` | Mackie Control 對應，在鍵盤的 MCU/HUI 連接埠上 |
| `Korg nanoKONTROL2 (Mackie Control mode)` | Mackie Control 對應。它不會被自動偵測：請以 Mackie Control 模式啟動裝置，並手動選擇這個類型 |

送出位置的旋鈕和推子使用軟接管：要到達控制項的數值後才會移動它。你手動連結的控制項保持原有的連結。`控制器設定檔資料夾` 會開啟放自己設定檔（`*.lynxctl`）的資料夾，`重新整理裝置清單` 會重新讀取它們。

內建的設定檔是依各廠商的文件寫成的。它們還沒有在實際硬體上試過。

## MPE 控制器

MPE 還在第一階段。MPE 控制器演奏的每個音符都有自己的彎音、音色（CC 74）和壓力。

1. 在 MIDI 頁面上，開啟該裝置寫著 `任意MIDI通道` 的方塊，並選擇 `MPE 控制器`。
2. 在旁邊出現的方塊中，選擇成員通道，從 `通道 2` 到 `Channels 2-16`。
3. 演奏。要錄製的話，見[錄製](/wiki/recording/)。

- 錄下的音符每一項只保留一個值：彎音作為微調音高，音色作為 Mod X，最強的壓力作為 Mod Y。它不是曲線。
- 內建樂器中，Sampler 和內建合成器會跟隨這些值。
- 在外掛視窗 `封裝器設定` 的 `MIDI` 下開啟 `MPE` 時，第三方外掛會收到 MPE。每個音符會在自己的 MIDI 通道（2 到 16）上送出。
- 還沒有用真正的 MPE 控制器試過。

## 電腦鍵盤

`Ctrl+T`，或 `選項 › 電腦鍵盤當鋼琴`，會把電腦鍵盤變成鋼琴。從 `Z` 到 `M` 以及從 `Q` 到 `P` 的按鍵列會彈奏所選的通道。

- 開啟時，字母和數字鍵都是音符。鋼琴捲軸和播放清單中單一字母的工具鍵，只有在它關閉時才有效。
- 它永遠以鋼琴捲軸的力度彈奏。MIDI 頁面上的 `力度` 設定是給 MIDI 裝置用的。
- 同一個開關也在 `選項 › 一般設定...` 中。

## 觸控鍵盤

![觸控鍵盤：八度按鈕、琴鍵大小、力度模式，以及從 C4 開始的一排鋼琴琴鍵](/assets/img/wiki/touch-keyboard.webp)

`檢視 › 觸控鍵盤`（`Alt+F7`）會開啟一個用滑鼠或觸控螢幕彈奏的鋼琴。它彈奏通道機架中所選的通道，並在右側顯示通道名稱。

| 設定 | 作用 |
|---|---|
| `-` 和 `+` | 降低或升高一個八度 |
| 琴鍵大小 | `小琴鍵`、`中琴鍵` 或 `大琴鍵` |
| `力度：按觸控位置` | 靠近琴鍵上方彈得輕，靠近下方彈得重 |
| `力度：固定` | 每個音符都使用滑桿設定的力度 |
| `音名` | 在琴鍵上顯示音名 |

## MIDI 同步

MIDI 頁面的 `輸出裝置` 會把走帶傳送給硬體和其他軟體。為某個裝置勾選 `傳送主同步`，再選擇 `MIDI時鐘`（含 Start、Continue、Stop 和 Song Position Pointer）或 MIDI Time Code。`偏移 (ms)` 設為正值時同步較晚送出，負值則較早。`傳送全部音符關閉` 會在初始化時以及匯出之後，把該訊息送給裝置。

`外部時鐘同步` 的方向相反：LYNX SHARE 跟隨你所選輸入的 MIDI 時鐘，包括它的速度、Start、Continue、Stop 和 Song Position Pointer。`外部同步偏移（毫秒）` 設為正值時 LYNX SHARE 播放較晚，負值則較早。`狀態` 會顯示時鐘是否正在運作。

## 須知

- 為 `外部時鐘同步` 選擇一個輸入，會在 `輸入裝置` 下開啟該裝置。
- 由已關聯的 MIDI 控制器移動的速度，不會調整音訊片段的大小。請輸入或設定最終的速度。
- 要錄製你彈奏的內容，見[錄音](/wiki/recording/)。輸入的音符可以在[鋼琴捲軸](/wiki/piano-roll/)中貼齊到音階。
- 送到外掛的 MIDI CC、通道觸後和彎音，可以用 `自動化MIDI控制器（CC、觸後、彎音）` 做成自動化。
- 被踏板保持的音符，會錄到踏板放開的那一刻。
- 當你用控制器移動控制項時，自動化片段不會把它收回去。下次開始播放時，控制項會再次跟隨它的自動化。
