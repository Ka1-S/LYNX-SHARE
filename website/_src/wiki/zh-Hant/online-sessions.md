與其他人共同處理專案有兩種方式，都在 `檔案 › 線上工作階段` 之下。封裝檔是你寄給朋友的一個檔案，朋友再把他的部分寄回來。它不需要網路、帳號或伺服器。即時工作階段則透過 LYNX SHARE 中繼伺服器，經由網際網路把所有人連在一起，每一項變更都會傳到每個人那裡。一個專案最多 4 人參與，包括你自己。

## 把專案寄給朋友

![傳送專案](/assets/img/wiki/session-send.webp)

1. 開啟專案，選擇 `檔案 › 線上工作階段 › 傳送專案...`。
2. 輸入你的名字和朋友的名字。
3. 選擇工作階段結束時朋友保留什麼：`僅自己的部分（建議）` 或 `專案的完整副本`。
4. 儲存 `.lynxpack` 檔案。
5. 用任何你喜歡的方式把檔案寄出：電子郵件、共用資料夾、隨身碟。

封裝檔中有專案、它用到的所有取樣和錄音，以及使用第三方外掛的部分的音訊算繪（「替身」）。你的朋友不需要擁有你的外掛，也能聽到這些部分。

## 錄一個部分再寄回

朋友要做的事：

1. 用 `檔案 › 開啟...` 開啟 `.lynxpack`。摘要會顯示是誰寄來的，以及哪些混音器插入軌和播放清單軌道屬於你。按一下 `開啟`。
2. 在屬於你的插入軌和播放清單軌道上，加入你自己的通道、樣式和音訊。主持人的內容保持原樣。
3. 選擇 `檔案 › 線上工作階段 › 傳回我的部分...`，把新的封裝檔寄給主持人。

每位訪客會分配到一種顏色、20 條混音器插入軌和 16 條播放清單軌道。

## 合併一個部分

主持人要做的事：

1. 開啟當初寄出的專案。
2. 選擇 `檔案 › 線上工作階段 › 合併部分...`，並選取朋友寄回的封裝檔。
3. 朋友的通道、樣式、音符、片段和插入軌會以他的顏色加入。你的內容完全不會被更改。

合併算作一個復原步驟。同一位朋友較新的部分會取代較早的。

## 開始或加入即時工作階段

![開始即時工作階段](/assets/img/wiki/session-start.webp)

主持人開始工作階段：

1. 開啟專案，選擇 `檔案 › 線上工作階段 › 開始即時工作階段...`。
2. 輸入你的名字。
3. 在 `訪客可編輯` 下，選擇 `僅自己的通道、樣式、插入軌和列（建議）` 或 `全部`。在 `工作階段結束時，訪客保留` 下，選擇他們自己的部分或完整副本。
4. 按一下 `起點`，然後複製邀請碼，寄給最多 3 個人。
5. 有人要求加入時，按一下 `允許加入`。

訪客加入：

1. 選擇 `檔案 › 線上工作階段 › 加入即時工作階段...`。
2. 輸入你的名字，貼上邀請碼，然後按一下 `加入`。
3. 等待主持人讓你進入。主持人的專案會開啟。

## 即時工作階段進行中

![工作階段聊天](/assets/img/wiki/session-chat.webp)

工作階段進行時，`檔案 › 線上工作階段` 選單中有這些指令：

| 指令 | 作用 |
|---|---|
| `工作階段聊天...` | 開啟聊天。選單項目會顯示未讀訊息的數量 |
| `跟隨主持人的走帶` | 給訪客：播放、停止和位置跟隨主持人 |
| `成員和權限...` | 給主持人：每個人可以更改什麼，以及結束時各自保留什麼 |
| `顯示邀請碼...` | 給主持人：再次顯示邀請碼，並附有 `複製` 按鈕 |
| `結束即時工作階段` | 給主持人。所有人離開，邀請碼失效 |
| `離開即時工作階段` | 給訪客。專案中屬於你的部分會留給你 |

在 `成員和權限...` 中，每個人會得到四種角色之一：`自己的通道、樣式、插入軌和列`、`自己的部分 + 速度和專案設定`、`全部` 或 `僅收聽（不可編輯）`。關閉某項權限絕不會刪除任何內容。

## 其他人沒有的外掛

如果通道或插入軌的外掛沒有安裝在你的電腦上，就會播放替身，並在通道機架和混音器中顯示琥珀色的 `R` 徽章。

- 在封裝檔中，替身是儲存封裝檔時製作的音訊算繪。它們會跟著你移動的片段，但不會反映對你沒有的外掛的音符所做的編輯。請向外掛的擁有者要一份新的封裝檔。
- 在即時工作階段中，使用某人沒有的外掛的部分，由擁有該外掛的人算繪，再以音訊串流給其他人。

## 網路上傳送什麼

封裝檔就是檔案。不會上傳到任何地方。

即時工作階段只在你參與期間才會連線。一切都透過中繼伺服器 `relay.lynx-share.com`，並以由邀請碼衍生的金鑰進行端對端加密。中繼伺服器轉送資料，但無法讀取。它看得到你的 IP 位址、你連線的時間，以及通過了多少位元組。工作階段中的其他人看得到你的名字、你的編輯、你的部分用到的取樣，以及你正在播放還是錄製。他們看不到你的 IP 位址。詳情見[隱私權政策](https://github.com/Ka1-S/LYNX-SHARE/blob/main/PRIVACY.md)。

## 須知

- `僅自己的部分` 是音樂人之間的禮貌，不是防拷保護。封裝檔就是一般的 zip。
- 雙方應使用相同版本的 LYNX SHARE。版本不同時，封裝檔摘要會提出警告。
- 連線中斷的訪客會自動重新連線，並保留他的編輯。
- 如果主持人的 LYNX SHARE 在工作階段中關閉，下次啟動時會提示是否繼續，訪客也會自動重新連線。
- 在即時工作階段中，復原和重做只會還原你自己的編輯。
- 任何擁有邀請碼的人都可以要求加入，但必須由主持人讓他們進入。
