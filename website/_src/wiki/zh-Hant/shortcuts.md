這裡列的是 0.1.26 alpha 的預設按鍵。`說明 › 快速鍵`（`F1`）會在程式內顯示快速鍵一覽。`選項 › 管理快速鍵...` 會開啟圖中的編輯器，你可以在那裡更改它們。

> 在 macOS 上，程式會用 Mac 的名稱顯示按鍵：Ctrl 顯示為 ⌘，Alt 顯示為 ⌥。

## 更改快速鍵

1. 選擇 `選項 › 管理快速鍵...`。
2. 在搜尋框中輸入動作或按鍵，例如 `Ctrl+L`。旁邊的清單可以把搜尋限制在某一處，`僅已變更` 則顯示你改過的項目。
3. 點擊該動作。
4. 點擊 `變更` 可取代它的按鍵，或點擊 `新增快速鍵` 為它再加一組，然後按下新的按鍵。`Esc` 取消。
5. 如果這些按鍵在同一處已被使用，會出現一則訊息，指出另一個動作的名稱，並讓你把按鍵移過來。

`移除` 會清除該動作的按鍵。`重設為預設` 會還原單一動作，`全部重設...` 則還原全部。你的更改儲存在設定資料夾的 `keys.json` 中（Windows 上是 `%APPDATA%\LYNX`，macOS 上是 `~/Library/Application Support/LYNX`，Linux 上是 `~/.config/LYNX`）。`開啟keys.json` 會開啟該檔案。

## 走帶控制與錄音

| 按鍵 | 作用 |
|---|---|
| `Space` | 播放，或停止並回到開始播放的位置 |
| `Ctrl+Space` | 播放或暫停 |
| `Shift+Space` | 播放，或停在歌曲或樣式的開頭 |
| `L` | 在樣式模式和歌曲模式之間切換 |
| `R` | 開啟或關閉錄製 |
| `Shift+R` | 立即錄製音訊：預備所選插入軌並開始錄製 |
| `Ctrl+M` | 開啟或關閉節拍器 |
| `Ctrl+P` | 開啟或關閉錄製前的預備拍 |
| `Ctrl+I` | 開啟或關閉錄製等待第一個音符 |
| `Ctrl+B` | 開啟或關閉混合錄製的音符 |
| `Ctrl+E` | 開啟或關閉步進輸入 |
| `Ctrl+H` | 停止聲音（所有音符關閉） |
| `Ctrl+T` | 開啟或關閉電腦鍵盤當鋼琴 |
| `Alt+Numpad *` / `Alt+Numpad /` | 跳到下一個或上一個歌曲標記 |

其中一些按鍵在取得焦點的編輯器內有不同的作用。在鋼琴捲軸中，`Ctrl+M` 匯入 MIDI 檔案，`Ctrl+B` 是複製一份。在播放清單中，`Ctrl+P` 是表演模式。

## 須知

- 打字鍵盤鋼琴開啟時，它的按鍵會彈奏音符，大多數單字母快速鍵會暫停（`L` 仍然有效）。用 `Ctrl+T` 關閉它。
- 快速鍵要麼在任何地方都有效，要麼只在某個視窗內有效。當該視窗取得焦點時，屬於該視窗的快速鍵優先於在任何地方都有效的相同按鍵。
- 有些動作沒有預設按鍵，例如快速新增面板。請在編輯器中為它們指定一組。
- 在 Playlist 中，沒有選取任何片段時，移動片段的按鍵會移動所有片段。`Alt+Left` 和 `Alt+Right` 的細微步長，是目前縮放下的一個像素。
- 外掛視窗取得焦點時，LYNX SHARE 的快速鍵也有效，例如 `Space`。單純的字母和數字會先交給外掛，`Esc` 則關閉它的視窗。
