LYNX SHARE 預設採用樣式工作流程：通道機架、樣式和播放清單。片段啟動工作流程是選用的，會在播放清單旁加上帶場景的片段格線。LYNX SHARE 可讀寫 `.als` 套裝，但與 Ableton 沒有任何隸屬關係。

## 開啟 Live 套裝

1. 選擇 `檔案 › 開啟...`（`Ctrl+O`），選取 `.als` 檔案。Live 11 和 Live 12 儲存的套裝都能讀取。
2. 選擇 `檢視 › 版面樣式 › 片段啟動工作流程`，即可使用片段格線，套裝中的 Session 片段和場景會放在這裡。
3. 用播放清單標題列中的 `Grid / Both / Song` 切換，可顯示格線、播放清單或兩者。
4. 選擇 `檔案 › 儲存`。它會詢問要把 `.lynx` 檔案寫到哪裡。`.als` 不會被更動。

`檢視 › 版面樣式 › 模式工作流程（預設）` 可以切回去。`選項 › 一般設定...` 中也有同樣的選項。兩種版面下都能使用樣式和通道機架。

## 對應關係

| 在 Live 中 | 在 LYNX SHARE 中 |
|---|---|
| Session 檢視 | 片段啟動工作流程的片段格線 |
| Arrangement 檢視 | 播放清單 |
| 軌道 | 播放清單軌道，也就是片段格線的各欄 |
| 場景 | 場景，片段格線的各列。場景啟動時可以設定速度 |
| 啟動量化 | `全域`、`無`、8 小節到 1 小節，或 1/2 到 1/32 的音符長度，需要的話可以逐片段設定 |
| 啟動模式 | `觸發`、`門限`、`切換` 和 `重複` |
| 跟隨動作 | 動作 A 和動作 B，各有機率 |
| 片段停止按鈕 | 空插槽可以有停止按鈕 |
| 返回 Arrangement | `返回播放清單` |
| 變速模式 | `通道設定 › 時間伸縮` 中的 `拍`、`音調`、`紋理` 和 `複雜` |
| Simpler、Sampler 和鼓機架 | LYNX SHARE 取樣器 |
| `.als` 套裝 | `.lynx` 專案檔案 |

## 片段格線

一個插槽可放一個樣式片段或音訊片段。

- 一條軌道一次只播放一個片段。啟動的片段會取代正在播放的那個。
- 啟動會等到啟動量化的下一個節點。
- `連奏` 會讓新片段從被取代片段播放到的位置開始。`循環` 是逐片段設定的。
- 場景可以插入、刪除和重新命名。
- 啟動過片段的軌道，在播放清單中會保持無聲，直到你按 `返回播放清單`。有一個選項可以在走帶停止時把軌道交還。

跟隨動作會在片段播放若干小節或若干遍之後執行。動作有 `無動作`、`停止`、`再次播放`、`上一個`、`下一個`、`第一個`、`最後`、`任意` 和 `其他`。有一個開關可為整個格線開啟或關閉跟隨動作。

## 從 .als 匯入的內容

- MIDI、音訊、群組和回傳軌道，速度、拍號、定位點、循環、混音設定（音量、聲像、靜音、獨奏、傳送）及其自動化。
- VST2 和 VST3 外掛及其狀態，前提是裝有同一個外掛。見[第三方外掛](/wiki/plugins/)。
- Session 片段和場景，會匯入片段格線，連同其啟動模式、量化、連奏、循環、跟隨動作和停止按鈕。若想改放到播放清單上，每個場景一個區段，請修改 `選項 › 一般設定...` 中的 `Live 專案的工作階段片段`。
- 變速標記。

## 匯出 .als

1. 選擇 `檔案 › 匯出 › Ableton Live 套裝 (.als)...`。
2. 在 `儲存為` 下選擇 `Live 12` 或 `Live 11（也可在 Live 12 中開啟）`。
3. 在 `取樣` 下，選擇把取樣複製到套裝的專案資料夾，或是直接引用它們所在的位置。
4. 選擇一個資料夾。套裝會存為 `<name> Project/<name>.als`。

| 會寫出 | 不會寫出 |
|---|---|
| 每個通道一條 MIDI 軌道，音符以 MIDI 片段呈現 | LYNX SHARE 自己的樂器和效果器。它們的軌道和音符會保留 |
| 帶有拉伸、移調、增益、淡化和變速模式的音訊軌道 | 效果器參數的自動化 |
| 群組、回傳和傳送 | 插入軌到插入軌的路由 |
| VST2 和 VST3 外掛及其狀態 | |
| 標記，以及音量、聲像和速度的自動化 | |
| 片段格線，以 Session 片段和場景呈現，機架和鼓機架 | |

匯出之後的報告會列出被省略的內容。

## 須知

- Live 自己的許多裝置會變成 LYNX SHARE 自己的，並保留其設定和自動化：EQ Eight、EQ Three、Channel EQ、Compressor、Glue Compressor、Multiband Dynamics、Limiter、Gate、Utility、Reverb、Delay、Echo、Auto Filter、Saturator、Overdrive、Chorus-Ensemble、Redux、Auto Pan、Drum Buss、Simpler、Drift 和 Operator（不含 FM）。其他的會被捨棄並列在匯入報告中。
- 樂器機架和音訊效果器機架會連同其鏈、區域和巨集一起匯入，鼓機架會變成 LYNX SHARE 的鼓機架。Live 的 MIDI Effect Rack 還不會轉換，會列在匯入報告中。
- 匯入報告會列出被省略的內容。
- 在匯出的套裝中，Live 會修剪彼此重疊的音訊片段。
- Live 套裝中的變速標記在匯入時會保留，匯出時會寫回去。
