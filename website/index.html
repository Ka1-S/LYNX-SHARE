A lightweight DAW, fully open source.

LYNX SHARE is a lightweight, fully open-source DAW with the FL Studio workflow you already know — Channel Rack, Piano Roll, Playlist and Mixer — built in modern C++ to run smoothly on any PC. It even opens your .flp projects.

// inspired by the classics

The plugins you know, rebuilt natively.

LYNX SHARE ships its own native plugins inspired by the third-party plugins producers use most: EQs, limiters, reverbs, vocal tuning, channel strips. Open a project that uses one you don't have installed and LYNX SHARE loads its equivalent in that slot, keeping the original's settings for when it's back.

Crash reports

        
Opt-in only. After a crash or freeze LYNX SHARE asks before sending a report (Settings › General › Crash reports: Ask / Always send / Never). A report holds the LYNX SHARE version, operating system, CPU, graphics card and driver, audio device, the crash or freeze file and the last steps; user names in paths become <user> and file names are dropped. No audio, no projects, no machine name, no IP address is stored. Reports are kept only to fix bugs. To have one deleted, open an issue with its id (LYNX SHARE shows it after sending; every sent id is also listed in crash-reports/sent.log in LYNX SHARE's settings folder).
