# Live 13 (beta) watch list

Live 13 public beta announced 2026-11-10 (beta 13.0b25 per press), full release planned early 2027. Beta is limited to eligible Standard/Suite owners; Live 12 purchases upgrade free.

- MusicRadar, 2026-11-10 (full feature list)

- Ableton Live product page (Live 13 section, fetched 2026-11-21)

## Live 13 (beta) Clips
- Step Sequencer clip type [live13-001, v5, LYNX partial]: New MIDI clip type: X0X-style lanes, 8-128 steps, per-lane step count, rate (1/2..1/64T), direction (fwd/back/bounce) and swing; one-click convert to/from MIDI notes.
- Step Sequencer per-step parameters [live13-002, v4, LYNX unknown]: Per-step velocity plus offset, length, repeat, pitch bend/pitch and probability/chance, shown as editable rows.
- Fold to Scale in step lanes / fold to used [live13-003, v3, LYNX partial]: Fold option keeps lanes in key or only shows used notes.
- Default clip type on double-click setting [live13-004, v2, LYNX partial]: Settings option chooses whether double-click creates a Notes or Step Sequencer clip; empty slot shows clip-type choices (audio / automation on returns / MIDI).
- Envelope Clips on Return tracks [live13-005, v4, LYNX partial]: Return tracks and mixer settings can hold clips containing automation or modulation envelopes.

## Live 13 (beta) Devices
- Drum Synth [live13-006, v4, LYNX partial]: New monophonic drum synth: nine voices (kick, snare, rimshot, hi-hat, clap, tom, percussion, cymbal, FX), 20+ engines, tune/decay/colour/volume dials, 25 presets.
- Looplet (Max for Live, Suite) [live13-007, v2, LYNX missing]: Four-playhead sample looper with per-playhead direction, transpose, time-stretch, mixer section and tape-style glide.
- Clipper [live13-008, v4, LYNX partial]: Stock peak-clipping effect: soft/hard modes, input/output/ceiling/lift, Delta listen, clip visualisation.
- Transient Shaper [live13-009, v4, LYNX partial]: Attack/Sustain control with sidechain input.
- Softube Classic Dynamics & EQ pack [live13-010, v2, LYNX missing]: Five hardware-modelled compression/EQ/drive effects (free with Suite).
- Phaser-Flanger new interface [live13-011, v1, LYNX unknown]: Updated UI for the existing Phaser-Flanger.

## Live 13 (beta) Racks
- Multiband Rack [live13-012, v4, LYNX partial]: Dedicated rack type splitting a signal into frequency bands, each with its own chain.
- Mid-Side Rack [live13-013, v3, LYNX missing]: Rack type with separate chains for mid and side.
- 32 Macros per rack [live13-014, v3, LYNX partial]: Macro count doubled from 16; macros as dials or on/off buttons.
- Macro custom response curves + Modulation mode [live13-015, v4, LYNX partial]: Mapping curves per macro target; Modulation mode offsets mapped controls while the base value stays editable.
- Round Robin mode for Instrument/MIDI racks [live13-016, v3, LYNX covered]: Cycles incoming notes through chains in turn.

## Live 13 (beta) Audio
- ARA 2 plug-in support [live13-017, v4, LYNX covered]: ARA 2 plug-ins (Melodyne, VocAlign) edit audio clips directly in Clip View on the timeline.
- Melodyne Essential bundled with Suite [live13-018, v1, LYNX unknown]: Bundled pitch editor.

## Live 13 (beta) Workflow
- Contextual Browsing [live13-019, v4, LYNX partial]: '+' in the device chain / Device Slots shows relevant devices and presets; Option+arrows swap presets without the main browser.
- Capture Automation [live13-020, v5, LYNX missing]: Records parameter movements in the background; press Capture to turn them into editable automation, like Capture MIDI.

## Live 13 (beta) Mixer
- Device Slots in the Mixer [live13-021, v3, LYNX covered]: Mixer shows every device on a track at a glance.
- Send sliders, persistent Mixer Configuration menu, Unsolo on Main, smoother resize [live13-022, v2, LYNX partial]: Mixer polish items.

## Live 13 (beta) Sync
- Arrangement sync for Ableton Link [live13-023, v3, LYNX partial]: Link can follow arrangement start/stop and position.

## Live 13 (beta) Formats
- Export: tempo automation and time-signature changes, tighter MIDI timing [live13-024, v3, LYNX unknown]: Exported MIDI/stems carry tempo and meter changes; MIDI event timing more precise.

## Live 13 (beta) Library
- Core Library update [live13-025, v3, LYNX unknown]: New presets and racks (vocals, guitars, mixing, mastering), drum racks, samples and MIDI clips.

## Live 13 (beta) Interface
- Flatter visual refresh [live13-026, v1, LYNX unknown]: Crisper, slightly flatter UI.

## Live 13 (beta) Push
- Push 3 Custom Layouts, Step Sequencer layout, Performance Mixer, device-mode jog wheel [live13-027, v1, LYNX missing]: Hardware features for Push 3; Push 2 gets the step sequencer and most device mode changes.

## Live 13 (beta) Live 12.x beta
- Live 12.4.15 small changes (shipped 2026-10-28) [live13-028, v2, LYNX unknown]: Browser Ctrl+F selects term, EQ Eight Adaptive Q for shelving, plug-ins up to 32 audio output buses, Max clip scale properties, Launchkey MK4 88 / MPK Mini Plus II support.
